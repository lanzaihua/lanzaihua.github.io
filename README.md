## 功能

### 错题记录

- 册内唯一编号：高代 <code>A-001</code>、数分 <code>M-001</code>、解几 <code>G-001</code>、西经 <code>E-001</code>。
- 记录原题、考试标准解答、详细解析、答案、模板、章节、知识要点、难度和错因。
- 已掌握 / 未掌握状态会同步到首页和科目页统计。
- 支持关键词、章节、模板、难度、状态筛选，以及编辑、删除和展开阅读。

### 模板与题库

- 118 张模板按科目和章节组织，顶部章节目录可直接跳转。
- 模板固定四段：识别特征 / 首选方法 / 步骤骨架 / 易错点。
- 8350 道考研同型题 + 590 道教材课后习题 + 223 道习题集题，可以展开查看标准解答、详细解析、答案、解题要点和易错点。
- 模板、题库、错题条目都支持复制 Markdown 源码；题库由 8350 道考研同型题、590 道教材课后题与 223 道习题集题组成。基础 8250 道按每章 1–5★ 各 10 客观 + 10 填空 + 10 主观配置，教材 590 道为补充、不占该配额。

### 统一笔记库

- **手写笔记本**：笔、荧光笔、橡皮、直线、套索；10 种纸张；多页；插入文字和图片。
- **知识笔记**：Markdown、<code>[[双链]]</code>、反向链接、标签、全文搜索和关系图谱。
- **统一入口**：全部 / 笔记本 / 知识笔记切换，共用同一个搜索框。
- **智能扫描**：自动裁边、滤镜、旋转、连续扫描多页、OCR，保存后可导出 PDF。
- **导入导出**：图片、PDF 转页面；PNG / PDF 导出；数据随 JSON 备份。

### AI 智能录入

配置模型后，可以输入文字或上传题目图片，让 AI 一次生成考试标准解答、详细解析、答案、模板四段和 1–2 道变式。

- 支持 OpenAI 兼容接口、DeepSeek / DeepSeek Harness、Claude、Gemini、Grok、通义千问、Moonshot Kimi。
- 可选错解诊断：先指出错在哪一步、真正卡点、怎么改、下次怎么防，再给标准解答。
- DeepSeek 峰谷提示按官方规则：工作日 09:00–12:00、14:00–18:00 为峰时，周末和法定节假日全天谷时。
- 峰时可先暂存题目和图片，谷时再送入生成；暂存只存在本机。
- 新错题可自动进入补全队列；页面关闭后队列保留，下次打开继续。

### 期末复习

- 设定考试日期和时长，自动拆成基础回顾、强化训练、冲刺模拟三段，并排进每日任务。
- 错题和题库题可加入期末材料；模拟卷按时长和章节选题，分值按题型和难度智能分配（客观题单题不超过 7 分，主观题按难度加权，总分 100），可手动修改。
- 卷子可在线改题、改答案、改分值、调顺序、补题或删题。
- AI 批改的错误点、要点、易错点和用户作答统一按 Markdown + LaTeX 渲染；加入错题时保留完整选项、用户错选、作答与卡点，不再出现原始 $$...$$。手写图片以白底 PNG 随题发送并要求 AI 先转写再批改，未识别时保守复核。
- 导出 DOCX，或打开打印窗口另存为 PDF。

### 文案原则

- **学术与题目文本**：题目、证明、解答、解析、模板和知识要点使用正式、准确、克制的学术书面语；术语按目标语言教材与期刊惯例，不用网络口语、卖萌、感叹号或表情。
- **欢迎、提醒与询问**：欢迎、引导、提醒、确认和空状态使用温和、亲切、具体的第二人称；不命令、不责备、不夸张承诺。
- **多语言语气一致**：界面翻译与 AI 生成使用同一套语气规则；翻译缓存升级到 v11 后重新生成。

### 数据、备份与语言

- 数据默认只在本机浏览器；换设备或清缓存前请先导出备份。
- JSON 备份默认只含用户错题、用户自建模板/题库、笔记和设置；内置 9163 道题库与 118 张模板由页面自带，不写入备份，导入也不会回滚内置题库。支持合并或覆盖导入。
- 当前语言备份会预翻译内容并输出 gzip 压缩的 <code>.json.gz</code>，文件更小。
- 界面内置简体中文；繁體中文部分内置；English、Français、Deutsch、日本語、한국어、Português、Русский、Español 需要在设置里配置 AI 后生成并缓存，未配置时仍可正常使用简体中文。
- 语言选择持久化；界面、题库、规范、笔记和弹窗使用同一套翻译缓存（v11）。
- 单文件页面首次打开需要联网加载；首次成功打开后，浏览器会注册离线缓存，断网刷新可回到最近一次成功页面，数据仍只在本机。
