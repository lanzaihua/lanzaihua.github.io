## 二、真实缺陷与修复

### AUD-01【P0】同步首启用空状态覆盖云端

- 现象：全新浏览器首次连接已有 `data/state.json` 的服务器，页面自动 PUT，云端条目被清空。
- 根因：首次启动写入欢迎通知时 `markDirty()`；同步初始化在“本机为空”的情况下先走冲突/推送，而不是采用远端。
- 修复：`src/js/05-sync.js` 在冲突分支前增加 `isFreshLocal && !localHasContent()` 的 adopt 分支；欢迎通知与“今天已提醒”只写本机；冲突提示改用 `syncToast()`，不再反向标脏。
- 回归：`tools/qa-sync.js` 预置 1 条云端题，全新 Chromium 打开后断言 rev 不变、条目为 1、零 PUT；CI 执行。

### AUD-02【P1】长错题标题溢出卡片

- 现象：160 个连续字母的标题在 390/768/1440 都伸出卡片，压住“未掌握”胶囊。
- 修复：`.entry-title` 及其子元素 `overflow-wrap:anywhere; word-break:break-word; min-width:0`。
- 回归：`tests/fixes.test.js` 断言三端标题右缘不越出卡片。

### AUD-03【P1】手机/平板笔记编辑器整体超宽

- 现象：390 宽下 `#main` 811.9px、工具栏 775.9px、画布 766px，右侧工具不可达。
- 根因：`#app,.main{width:auto}` 与后置 `.main{max-width:var(--maxw);margin:0 auto}` 组合，flex 子项 shrink-to-fit。
- 修复：≤900px 时 `.main` 100% 拉伸并去掉 auto margin；工具栏、画布、画板 `min-width:0`、`max-width:100%`。
- 回归：实测 390/768/1440 的 main/toolbar/canvas 均在视口内。

### AUD-04【P1】题库 LaTeX 双反斜杠与集合花括号丢失

- 现象：`\\infty`、`\\xi` 渲染成字面文本；`U={0}`、`S={2,3}` 的花括号被 Temml 吞掉。
- 修复：数据层把双反斜杠降为单反斜杠、集合花括号转义；新增 `tools/qa-bank-latex.js` 扫描双反斜杠命令、`$...$` 内未转义集合括号、重复选项、缺 `correct`。
- 结果：18 条 LaTeX、107 条缺 `correct`、1 组重复选项修复；`BANK LATEX PASS`。

### AUD-05【P1】GA-B0868 解答不严谨

- 问题：解析用“任意 v 可写 0+v 与 v+0”证明表示不唯一，但 v 未必属于 U。
- 修复：改为取非零 `u∈U`，说明 `(u,0)` 与 `(0,u)` 是两种不同表示；答案 C 不变。

### AUD-06【P1】AI 结果不完整仍自动入库

- 修复：`aiResultIssues` 增加“原题题干”“变式题题目与答案”校验；新增 `aiShouldAutoSave`，只有结果完整、无需澄清才自动保存。
- 回归：`tests/audit-20261106.test.js` 7/7。

### AUD-07【P1】导入上限 30MB 与 GB 级存储不匹配

- 修复：`IMPORT_MAX_CHARS` 提高到 512MB，错误文案动态显示 MB，避免“能存不能回导”。

### AUD-08【P1】source.zip 不完整导致 CI 无法构建

- 现象：Release 的 source.zip 缺 `skills.js`、根静态文件和分片，解压后构建失败。
- 修复：`make-release-assets.py` 改用 `git archive HEAD` 全部 tracked 文件；静态包补 `skills.js`、`_headers`、`.nojekyll` 与全部分片。
- 回归：`verify-release` 下载每个资产并按 `SHA256SUMS` 核算。

### AUD-09【P1】CI 用旧 Release 覆盖源码数据

- 修复：`quality.yml` 删除 hydration；新增 `git diff --exit-code` 检查 `index.html`、`data`、`sw.js` 等构建产物，防止“源码改了但发布旧文件”。

### AUD-10【P1】Service Worker 按 query 无限缓存

- 修复：只缓存 html/css/js/json/image/font 的 200；cache key 去掉 query；`?utm`、`?token` 不再产生 17MB 级重复条目；同步修改 `src/static/sw.js`（构建真正复制的源）。

### AUD-11【P1】构建残留 14.7MB 调试页

- 修复：`build.js` 写入前删除 `dist/matrix-test.html`、`matrix-test-2.html`；非 Pages 构建删除陈旧 `dist/data`。

### AUD-12【中】Host 头不校验（DNS rebinding）

- 修复：`allowedHostNames()` 校验 localhost、回环、主机名、所有网卡地址；非法 Host 返回 421。
- 回归：`Host: evil.example` → 421。

### AUD-13【中】AI 上游错误正文回显

- 修复：`aiUpstreamError` 只返回固定文案；上游 body 仅写服务端日志前 500 字符。

### AUD-14【中低】text/plain 简单请求可触发 solve/ocr

- 修复：两个 POST 要求 `application/json`，否则 415。

### AUD-15【低】健康检查/状态接口泄露绝对路径

- 修复：备份路径只返回 basename；删除 `detail: cur.error`。

### AUD-16【P1】采用云端状态后丢失当前路由

- 现象：带模拟考状态的云端账号下，直接打开 `#/final` 会显示“模拟考进行中”或科目总览，模拟卷编辑卡不渲染；qa:paper 全部宽度失败。
- 根因：`adoptRemote()` 整体替换 `state`，把当前 `activeView/activeSubject` 一并换成远端值。
- 修复：替换前保存路由字段，替换后恢复；qa:sync 新增 `#/final` 断言，qa:paper/qa:filters/qa:perf/qa:a11y 改为阻断 `/api/state`，避免测试机云端状态污染布局门禁。
- 回归：`qa:sync` 输出 `routeOk:true`；qa:paper 18 宽度 0 failures；qa:filters 22 宽度 0 failures。

### AUD-17【P1】解析几何 21 道证明题答案占位

- 现象：GE-TX027 等 21 道教材课后证明题的 answer 是“证明成立（详见标准解答）。”，无法独立判分。
- 修复：按每题标准解答补成具体数学结论，保留完整证明；qa:bank-consistency 新增 placeholder-answer 检查，占位文案再次出现直接失败。

### AUD-18【P1】22 组选择题与主观题同题干

- 现象：GE-B019/B021 等 19 组 choice/subjective 同题干，另有 GE-TX275/TX296、GE-B499/B801、GE-B774/B864。
- 修复：把主观题改为真正不同的变式（反例要求两组反例、曲面改参数化、含参题给一般参数），不删除任何题型；qa:bank-consistency 的 duplicate 门禁保持 0。
- 说明：其中 GE-B538/B868 曾被误改为证明题，已从 D:/dsh-tmp/bank-geometry.before-fix.json 恢复，仅改主观题。

### AUD-19【P1】525 处「答案：」尾注与 answer 字段不一致

- 现象：standardSolution 末尾“答案：”常缺选项字母或句号，与权威 answer 不同。
- 修复：四科统一以 answer 为准重写尾注，共 525 处；当前 3202 条带尾注、0 不一致；qa:bank-consistency 永久检查。

### AUD-20【P1】AI Key 明文存 localStorage

- 现象：sanke-ai-config-v1 直接保存 apiKey，同源脚本、扩展或本机恶意软件可读。
- 修复：Key 改存 IndexedDB sanke-ai-secrets-v1，AES-GCM 256 加密、随机 IV；localStorage 只留 keyStored 元数据；旧明文与 sanke-dsh-token 启动时迁移并删除；无 IndexedDB/crypto 时仅本次会话内存保存。设置页文案同步。
- 回归：tests/ai-secret.test.js 3 项 + 真浏览器探针，断言 localStorage 无明文、密文不含明文、刷新后可解密。

### AUD-21【P1】AI 上游 DNS rebinding TOCTOU

- 现象：解析校验与 fetch 之间可重新绑定到私网/元数据地址，原 assertSafeAiBaseUrl 只做预检。
- 修复：新增 lib/ai-http.js，requestJson 用自定义 lookup 固定到已校验 IP，保留 Host/SNI，禁止重定向，32MB 上限；server 只在启动解析一次。tests/ai-http.test.js 断言只解析一次且 Host 保持原值。

## 三、自动化门禁

新增或加强了以下门禁，并全部接入 `npm run check` 或 CI：

- `qa:baseline`：四科数量、id 摘要、题干摘要；删题/换题/改题干必须显式更新基线。
- `qa:latex`：双反斜杠、集合花括号、重复选项、缺 correct。
- `qa:sync`：全新浏览器不得覆盖云端。
- `qa:render`：9651 题全字段渲染，失败 exit 1。
- `qa:formulas`：12 个界面面（含知识点、模拟考、模拟卷）检测裸 $、LaTeX 残留、容器溢出。
- `qa:paper` / `qa:filters`：18 / 22 个宽度的真实浏览器布局。
- `qa:pages`：首访 network、二次 idb、分片断供回退。
- `verify-release --self-test`：发布链自检。
