# Warm Academic 3.2 · 视觉审查

审查对象：本地候选构建 `2026.11.14-3b0bc353`（构建时间 2026-11-14；未部署）。
截图目录：`docs/3.2/screenshots/`。after 为 3.2 构建，before 为 3.1 线上浅色截图（`debug/warm31-review/3.1-*-light.png` 复制）。
设备：Chromium 真实渲染，390×844（DPR 2）与 1440×1000（DPR 1）。深色在 before 缺图，仅以 after/现有 3.1 深色截图对照；不声称覆盖真实手机。

## 1. 总览

3.2 没有换设计方向，只在 Warm Academic 3.0/3.1 的暖白纸面、砖红强调、衬线标题、细分隔线上做收口。首页工作台、统计、规范、题库筛选、设置等页面结构未动；改动集中在触控尺寸、搜索面板键盘可达性、首页纵向节奏，以及测试门禁。

## 3. 逐页结论

### 首页
- 层级：问候标题 → 工作台 → 四科入口 → 页脚，顺序清楚；工作台四指标 + 今日建议视觉权重高于四科入口，符合“先决定今天做什么”。
- 1440×1000：四科卡完整进首屏（3.2 修复）；工作台与四科区之间用 1px 分隔线 + 24px 间距，不拥挤。
- 390：单列卡片、右侧题数不换行；页脚四个图标（更新/语言/设置/通知）在文档流内，不悬浮压卡。
- 问题：截图中的“本机与云端都有数据”toast 是测试环境同时存在本机/服务端数据导致，不是页面缺陷；正式空数据环境无此提示。

### 总览 / 统计
- 总览 hero、四格统计、按章索引、错因分布保持 3.1 布局；手机上按章索引横向滚动有“左右滑动查看完整表格”提示。
- 统计在无数据时给出“先建立今天的手感”与入口，不画假进度；有数据时四科对比条与近 14 天柱状图使用真实记录。

### 错题
- 空态三步卡（从题库挑一道/手动新增/智能录入）清楚；条目展开后标准解答、详细解析、答案、要点、易错点分区明确。
- 行内公式与正文共基线，长公式横向滚动；选项字母悬挂，不把 A./B. 挤成单独一行。

### 题库
- 来源四段（全部/考研同型/教材课后/习题集）在桌面同排，手机折叠进“筛选”；筛选后当前范围与命中题数同步。
- 题干、选项、标签的层级稳定；题目卡不在手机端强制两列。
- 修复后“筛选”按钮 40px，展开后筛选项仍保持完整，不因折叠丢失状态。

### 模板库 / 规范
- 模板库章节索引双列，展开卡片正文按 Markdown + LaTeX 渲染；手机单列。
- 规范四格要点 + 字段表 + 右侧目录；手机字段表改为纵向卡片，不再三列硬挤。深色下表格边线与文字对比正常。

### 笔记 / 期末 / 模拟考
- 笔记库空态与知识笔记卡分层；编辑器弹窗在 390 下占满安全宽度，工具栏可横向滚动。
- 期末复习“出模拟卷/进行模拟考”为 01/02 阶段卡，不再像重复入口；复习材料空态给“页面顶部入口”说明。
- 模拟考章节弹窗为单列大卡片，章/小节展开不整页跳动；答题卡 27 个 34px 方块，手机上可点。

### 设置 / 更新记录 / 通知
- 设置分区 header 有 PROFILE/LANGUAGE/AI/SYNC/ABOUT 英文注记，作为辅助信息不抢中文标题；触控统一 40px。
- 更新记录最近 8 组展开、历史折叠；日期/标题/摘要/分组卡三层，长文不挤成一段。
- 通知中心全部/未读、单条已读、一键已读、删除选中、清空；同日同组不重复。

## 4. 深色与状态

- 深色以 `#1D1B18` 页面、`#26231F` 面板、`#F2EEE6` 主文字、`#3A352F` 边框为基准；无纯黑大面积、无浅色卡片残留。
- 组件状态：默认/悬停/焦点/按下/禁用/选中均有可见差异；键盘焦点环 2px 砖红，不被 overflow 裁切。
- 空态、加载、错误、成功、离线均有文案；错误不覆盖已有数据。

## 5. 仍需关注

- 首页 390 首屏未见完整四卡（手机端不要求），但工作台把四科入口推到第二屏；若未来要求“手机首屏见四科”，需要另做移动端工作台折叠，不在本轮擅自改结构。
- 设置页英文分区注记在最窄 360 下会更贴近右边缘，已确认无溢出；若再增加字号需重新量测。
- 15MB 单文件导致首屏资源重，视觉上无问题但性能风险见 risk-register。
- 截图中的 toast/同步提示受本地测试数据影响，不作为视觉结论。
