WELCOME

先按自己的节奏来

欢迎使用四科错题本。错题、模板、题库和笔记都可以直接使用，不需要先配置任何服务。

如果你之后想用 AI 智能录入、题目翻译或自动补全，再到「设置与同步」里配置一个 API 服务就好。现在不配置也完全没关系。

AI 智能录入把题目整理成解答、模板和变式
界面与内容翻译切换语言时生成完整译文
暂存箱与自动补全峰谷时段排队，后台慢慢补齐

这些是锦上添花的功能。先逛逛，等真正需要时再配置也来得及。
