# 题库录入规范（内部工作稿）

目标：把教材/习题集题目整理成 `src/data/bank-*.json` 可直接合并的条目数组。

## 输出

- 每个文件是一个 JSON 数组（`[...]`），UTF-8，无 BOM。
- 不要写顶层 `items` 包装。
- `id` 先写占位符，如 `"GA-TMP-ch01-001"`、`"MA-TMP-001"`、`"GE-TMP-001"`、`"WE-TMP-001"`；合并脚本会统一重编号。

## 单题字段（全部必填，除注明外）

```json
{
  "id": "GA-TMP-ch01-001",
  "subject": "gaodai",
  "chapter": "第一章 多项式",
  "section": "带余除法",
  "type": "subjective",
  "category": "计算题",
  "templateId": "",
  "title": "用 g(x) 除 f(x) 求商与余式",
  "question": "用 $g(x)=3x^2-2x+1$ 除 $f(x)=x^3-3x^2-x-1$，求商 $q(x)$ 与余式 $r(x)$。",
  "answer": "$q(x)=\\frac13x-\\frac79$，$r(x)=-\\frac{26}9x-\\frac29$。",
  "standardSolution": "解：\n1. ……\n2. ……\n\n所以 $q(x)=…$，$r(x)=…$。",
  "detailedAnalysis": "本题考查……；关键……；易错点……。",
  "points": ["带余除法", "比较系数"],
  "pitfalls": ["忘记数域", "余式次数不低于除式"],
  "options": [],
  "correct": "",
  "source": "教材课后习题（第一章 多项式）· 习题 1",
  "examOrigin": "教材课后习题",
  "tags": ["第一章 多项式", "教材课后", "习题"],
  "relatedEntries": [],
  "difficulty": 2,
  "solution": ["解：……"],
  "pointKeys": ["带余除法"]
}
```

- `subject`：高等代数 `gaodai`；数学分析 `shufen`；解析几何 `jieji`；西方经济学 `xijing`。
- `chapter`：必须与给定章节名逐字一致（见任务里列出的清单）。
- `type`：`subjective`（默认）/ `fill` / `choice`。
  - `fill`：题干必须恰好一个 `____`；`answer` 只给填空结果。
  - `choice`：`options` 必须正好 4 项 `{"key":"A","text":"..."}`（A–D），`correct` 填 A–D；`answer` 以 `A．` 开头。
- `category` 只能取：计算题、证明题、概念辨析题、公式填空题、应用题、综合题、反例与存在性题、分类讨论题、误差分析题、多解比较题。
  - 证明题只能 `subjective`；公式填空题只能 `fill`；概念辨析题只能 `choice` 或 `subjective`。
- `standardSolution` 必须以 `解：`、`证明：` 或 `答：` 开头；主观题必须是**可判分的完整解答**（不能只写“提示”或“略”），且不能与 `answer` 完全相同。
- 公式一律 LaTeX：行内 `$...$`，独立 `$$...$$`。JSON 中反斜杠双写（`\\frac` 在 JSON 源里写作 `\\\\frac`？——直接写 `"\\frac"` 表示一个反斜杠，注意用 JSON 生成器，不要手写转义出错）。
- 中文题干中**不要**在汉字之间插入空格；公式与汉字之间也不要多余空格。
- 不要出现 `【】` 题型标记；不要把“题型/模板编号”等元信息写进题干。
- `source`：教材课后统一 `教材课后习题（<章节名>）· 习题 N` 或 `· 补充题 N`；习题集统一 `习题集（高等代数习题精选精解）· §x.y 第 N 题`。
- `examOrigin`：教材课后填 `教材课后习题`；习题集填 `习题集`。
- `title`：≤30 字，概括题型与对象，不要与题干重复。
- `points` / `pitfalls` 至少各 1 条，具体，不许“注意细节”这类空话。
- `difficulty`：1–5 整数（1 基础，5 压轴）。
- `solution`：与 `standardSolution` 同内容的字符串数组（可按步骤拆成 1–8 段）。
- `pointKeys`：与 `points` 相同即可。
- `templateId`：可留空。
- `section`：教材小节名或习题所属节；不确定时用章节内主题词，不要瞎编节号。

## 质量红线

1. **题面必须来自给定 OCR/PDF 原文**，允许把 OCR 压平的公式按标准记法重建，但不得改数字、条件、结论。
2. **答案必须独立验算**：多项式运算、行列式、矩阵、极限、积分等用 `python3 -c "import sympy..."` 实算；证明题必须逐步可验证，不得跳步或循环论证。
3. OCR 残缺到无法确定题意的题：跳过，记入 `*.skipped.md`（题号 + 残缺原因），**不许猜题**。
4. 与已有题库重复的题：如果题干/数字几乎相同，跳过并在 skipped 里记录；不要为了凑数改数字。
5. 同一道题不要拆成多个条目；多小问的题作为一个条目，在解答中分小问写。
6. 不要输出 Markdown 代码块包裹的 JSON 文件内容之外的任何东西到 JSON 里。

## 交付

完成后回复：
- 每个文件题数、题号覆盖范围；
- 跳过题号与原因；
- 你用 sympy/独立计算验算了哪些题（列 3–5 个代表）；
- 任何你不确定的地方（不许隐瞒）。
