# Patterns / 方法与算法

马工程《西方经济学》（第二版）的**具体计算与推导技术**。格式：**何时用 → 怎么做 → 代价与陷阱**。
章节引用以 `(Ch N)` 标明。

---

## 求均衡价格与数量
**何时用**：给出 `Qd` 与 `Qs` 的函数，求市场均衡。
**How**：① 令 `Qd = Qs`；② 解出 `P*`；③ 代回任一函数得 `Q*`；④ **验算 `P*, Q* > 0`**。
**陷阱**：解出负值说明该市场在此参数下不存在均衡（或供给/需求函数有定义域限制）。含参数的题要讨论参数范围。

## 求弹性（点弹性 vs 弧弹性）
**何时用**：题目给函数求某点弹性，或给两点求平均弹性。
**How**：
- **点弹性**：`Ed = −(dQ/dP)·(P/Q)`；先求导，再代入该点。
- **弧弹性（中点公式）**：`Ed = −[(Q₂−Q₁)/((Q₁+Q₂)/2)] ÷ [(P₂−P₁)/((P₁+P₂)/2)]`。
- **收入弹性** `Em = (ΔQ/Q)/(ΔM/M)`；**交叉弹性** `Exy = (ΔQx/Qx)/(ΔPy/Py)`。
**陷阱**：**需求价格弹性按惯例取正值**（所以公式前有负号），但推导过程中的负号不能丢。线性需求曲线上**各点弹性不同**（不是常数），只有 `Q = AP^(−b)` 型才有常数弹性。

## 税收归宿与无谓损失
**何时用**：对某商品征税，问谁承担多少、福利损失多大。
**How**：① 设税后价格为 `Pd = Ps + t`，令 `Qd(Pd) = Qs(Ps)` 解出 `Ps, Pd`；② **消费者承担 `(Pd − P*)`，生产者承担 `(P* − Ps)`**，两者之和 = `t`；③ 用弹性比例快速校验：**消费者份额 = `Es/(Ed+Es)`**，生产者份额 = `Ed/(Ed+Es)`；④ 无谓损失 = 税收楔形三角形的面积。
**陷阱**：**弹性小的一方承担得多**（跑不掉）。份额公式的分子是**对方**的弹性——这是最容易记反的地方。

## 消费者均衡
**何时用**：给定效用函数与预算约束，求最优消费组合。
**How**：① 写预算约束 `P₁X₁ + P₂X₂ = I`；② 列拉格朗日函数 `L = U(X₁,X₂) + λ(I − P₁X₁ − P₂X₂)`；③ 一阶条件给出 **`MU₁/P₁ = MU₂/P₂ = λ`**（等价于 `MRS = P₁/P₂`）；④ 与预算约束联立求解；⑤ 回代求 `U*`。
**陷阱**：**角点解**（一种商品买 0）时等边际条件不成立，要检查边界。完全替代/完全互补的效用函数不能用一阶条件硬解。

## 替代效应与收入效应分解（希克斯）
**何时用**：价格变动后，问其中多少来自替代效应、多少来自收入效应；判吉芬商品。
**How**（希克斯四步）：
1. 原价格下求初始均衡 `E₀` 与效用 `U₀`。
2. 新价格下求最终均衡 `E₂`。
3. **求"补偿收入"**：在新价格下，找到使效用仍等于 `U₀` 的最小收入 `I'`；该收入下的均衡为 `E₁`。
4. **替代效应 = `E₁ − E₀`**，**收入效应 = `E₂ − E₁`**，总效应 = `E₂ − E₀`。
**陷阱**：**替代效应恒与价格反向**；方向差异**只来自收入效应**。判据：正常品（收入效应与替代效应同向）、普通低档品（反向但弱于替代效应）、**吉芬商品（低档 + 收入效应强于替代效应）**。斯勒茨基分解用"购买力不变"（原组合仍买得起），与希克斯的"效用不变"不同。

## 生产者均衡与成本最小化
**何时用**：给生产函数与要素价格，求最优要素组合或最小成本。
**How**：① 等产量线斜率 = 等成本线斜率：**`MRTS = w/r`**，即 **`MP_L/w = MP_K/r`**；② 与产量约束 `Q = f(L,K)` 联立；③ 解出 `L*, K*`，代回求 `C = wL* + rK*`。
**陷阱**：与消费者均衡的形式完全同构（`MU₁/MU₂ = P₁/P₂` ↔ `MP_L/MP_K = w/r`），**不要写串**。规模报酬影响解是否唯一。

## 短期成本函数的推导
**何时用**：给 `TC` 或 `MC` 求各成本曲线，或反之。
**How**：① 若给 `MC(Q)`，则 `TC = ∫MC dQ + FC`，用已知点定 `FC`；② `TVC = TC − FC`；③ `AC = TC/Q`，`AVC = TVC/Q`，`AFC = FC/Q`。
**陷阱**：**积分常数是固定成本**，必须用题目给的点确定，不能默认 `FC = 0`。`MC` 穿过 `AC` 与 `AVC` 的最低点——可用来验算。

## 利润最大化（各市场结构通用）
**How**：① 写 `TR = P(Q)·Q`；② 求 `MR = dTR/dQ`；③ 令 **`MR = MC`** 解 `Q*`；④ 代回需求函数求 `P*`；⑤ `π = TR − TC`；⑥ 检查是否 `P ≥ AVC`（否则应停业）。
**陷阱**：
- **完全竞争**：`P` 是常数，`MR = P`，条件退化为 `P = MC`。
- **垄断**：需求线向右下，**`MR` 斜率是需求线斜率的 2 倍**（`P = a − bQ` ⟹ `MR = a − 2bQ`）。**垄断下 `P > MC`**。
- 利润最大化不等于收益最大化——`TR` 最大在 `MR = 0` 处，不是 `MR = MC`。

## 完全竞争短期均衡的五状态判别
**How**（两级判据）：
1. **`P` vs `AC_min`** 定盈亏：`P > AC` 盈利、`P = AC` 盈亏平衡、`P < AC` 亏损。
2. **`P` vs `AVC_min`** 定开工：`P ≥ AVC_min` 继续生产（即使亏损）、`P < AVC_min` **停产**。
3. 特殊点：`P = AVC_min` 是**停止营业点**。
**陷阱**：**判断是否停业看 `AVC` 不看 `AC`**——因为固定成本是沉没成本，无论生产与否都要付。

## 古诺均衡与斯塔克尔伯格均衡
**How**（古诺）：① 设两企业产量 `q₁, q₂`，总产量 `Q = q₁+q₂` 代入需求函数得价格；② 各企业利润 `πᵢ = P·qᵢ − Cᵢ(qᵢ)`；③ 对 `qᵢ` 求导得**反应函数** `qᵢ = f(qⱼ)`；④ 两反应函数联立解 `(q₁*, q₂*)`。
**How**（斯塔克尔伯格）：领导者先选产量，把跟随者反应函数代入自己的利润函数后求导。
**陷阱**：**产量顺序**：卡特尔（联合垄断）< 斯塔克尔伯格 < 古诺 < 完全竞争。反应函数的联立是解二元一次方程组，代错方向是最常见的失分点。

## 要素使用原则
**How**：`MRP = MFC`（一般形式）。
- **完全竞争（要素与产品市场都完全竞争）**：`VMP = W`，即 `P·MP = W`。
- **卖方垄断（产品市场垄断）**：`MRP = W`，其中 `MRP = MR·MP < VMP`。
- **买方垄断（要素市场垄断）**：`VMP = MFC`，其中 `MFC > W`，均衡要素使用量低于竞争水平。
**陷阱**：**`VMP` 与 `MRP` 只在产品市场不完全竞争时不同**。买方垄断**没有要素需求曲线**（只有一点）。

## 帕累托最优条件检验
**How**（三个层次）：
1. **交换**：`MRS_A = MRS_B`（所有消费者的边际替代率相等）。
2. **生产**：`MRTS_x = MRTS_y`（所有产品的边际技术替代率相等）。
3. **生产与交换**：`MRS = MRT`（消费者愿付的替代率 = 生产的转换率）。
**陷阱**：三层条件**不能混**。"帕累托最优"与"公平"是两件事；平均分配未必有效。

## GDP 核算（三种方法）
**How**：
- **支出法**：`GDP = C + I + G + NX`。
- **收入法**：`GDP = 工资 + 利息 + 租金 + 利润 + 间接税 + 折旧`。
- **生产法（增值法）**：各部门增加值之和。
**陷阱**：**GDP 排除**二手交易、转移支付、金融交易、自产自用、非法经济——因为不是**当期新生产的最终产品**。名义/实际 GDP 的区别在于用**当期价格**还是**基期价格**。

## 乘数计算
**How**（两部门，`β` = MPC）：
| 乘数 | 公式 |
|---|---|
| 投资乘数 | `1/(1−β)` |
| 政府购买乘数 | `1/(1−β)` |
| 税收乘数 | **`−β/(1−β)`**（负！） |
| 转移支付乘数 | `β/(1−β)` |
| 平衡预算乘数 | **`1`** |
| 对外贸易乘数 | `1/(1−β+γ)`（`γ` = 边际进口倾向） |
**陷阱**：**税收乘数为负**、**平衡预算乘数等于 1**（不是 0）——这两个是最常见的错。有税率 `t` 时乘数变为 `1/[1−β(1−t)]`。

## IS / LM 曲线推导
**How**：
- **IS**：产品市场均衡 `Y = C + I + G`；把 `C = α+βY`、`I = e − dr` 代入，整理成 `r` 与 `Y` 的关系式（向右下）。
- **LM**：货币市场均衡 `M/P = kY − hr`，整理成 `r` 与 `Y` 的关系式（向右上）。
- **IS-LM 均衡**：两式联立解 `(Y*, r*)`。
**陷阱**：`IS` 与 `LM` 的横纵轴**都是 `Y` 与 `r`**（不是 `P`）。斜率决定政策效果：**`LM` 越陡，财政政策越无效（挤出越大）**；`IS` 越陡，货币政策越有效。

## 蒙代尔-弗莱明模型的政策效果
**How**（资本完全流动，`r = r*`）：
| | 财政政策 | 货币政策 |
|---|---|---|
| **固定汇率制** | **有效** | **无效** |
| **浮动汇率制** | **无效** | **有效** |
**陷阱**：**两种制度下政策有效性完全对调**——这是本章唯一必背的表。机理：固定汇率下货币扩张 → 资本外流 → 汇率贬值压力 → 央行干预回笼货币，扩张被抵消。

## 新古典（索洛）增长模型稳态
**How**：① 生产函数 `y = f(k)`（人均形式）；② 资本积累方程 **`Δk = sf(k) − (n+δ)k`**；③ **稳态令 `Δk = 0`**，得 **`sf(k*) = (n+δ)k*`**；④ 解出 `k*`，代回求 `y*, c* = (1−s)f(k*)`；⑤ 黄金律：最大化 `c*`，条件 **`f′(k_gold) = n + δ`**。
**陷阱**：稳态条件是 `sf(k*) = (n+δ)k*`，**不是 `sf(k*) = k*`**（漏了折旧率 `δ` 与人口增长率 `n`）。**储蓄率提高只有水平效应，没有增长效应**——长期增长率仍为 0（人均产出的稳态值提高，但停止增长）。

## 增长核算
**How**：`产出增长率 = 技术进步率 + α·资本增长率 + (1−α)·劳动增长率`，其中 `α` 是资本产出弹性。
**How**（求 TFP）：**全要素生产率增长率 = 产出增长率 − α·资本增长率 − (1−α)·劳动增长率**（"索洛余值"）。
**陷阱**：余值包含了所有未观测因素（制度、管理、测量误差），不只是技术进步。
