# Glossary / 术语表

马工程《西方经济学》（第二版）第0–16章。`(Ch N)` 指向展开该术语的章节。
上册 = 导论 + 微观（Ch 0–8），下册 = 宏观（Ch 9–16）。


## A

- **绝对优势 / absolute advantage** — 用更少的资源生产同样产品的能力（Ch 14 相关）
- **加速原理 / acceleration principle** — 产量（收入）的变动会引起投资更大幅度的变动，是乘数-加速数模型的核心机制（Ch 13）
- **加速数 / accelerator** — 投资对产出变动的反应系数；乘数-加速数模型的核心参数（Ch 13）
- **适应性预期 / adaptive expectations** — 人们根据过去的经验修正对未来的预期；是短期菲利普斯曲线向右下、长期垂直的解释之一（Ch 13）
- **逆向选择 / adverse selection** — **事前的**信息不对称：买方无法辨别质量，劣质品驱逐优质品（柠檬市场）（Ch 8）
- **总需求 / aggregate demand (AD)** — 一定价格水平下经济对产品和服务的总需求量；向右下方倾斜（Ch 12）
- **总供给 / aggregate supply (AS)** — 一定价格水平下经济能提供的总产出；短期向右上、长期垂直（Ch 12）
- **弧弹性 / arc elasticity** — 用中点公式计算的弹性，衡量一段区间上的平均反应程度（Ch 1）
- **自动稳定器 / automatic stabilizer** — 无需政府主动决策就能逆周期调节的财政机制（累进所得税、失业保险）（Ch 15）
- **平均成本 / average cost (AC)** — `AC = TC/Q`；短期 `AC = AFC + AVC`（Ch 3）
- **平均固定成本 / average fixed cost (AFC)** — `AFC = TFC/Q`；单调递减（Ch 3）
- **平均产量 / average product (AP)** — `AP = TP/L`；与 MP 的关系：MP > AP 时 AP 递增（Ch 3）
- **平均可变成本 / average variable cost (AVC)** — `AVC = TVC/Q`；**其最低点是停止营业点**（Ch 3, Ch 4）

## B

- **后弯的劳动供给曲线 / backward-bending labor supply curve** — 工资高到一定程度后，劳动供给反而减少；因收入效应超过替代效应（Ch 6）
- **国际收支平衡表 / balance of payments** — 一国一定时期对外经济往来的系统记录（经常账户 + 资本与金融账户）（Ch 14）
- **平衡预算乘数 / balanced-budget multiplier** — 政府购买与税收同额变动时的乘数，**恒等于 1**（Ch 10）
- **物物交换 / barter** — 无货币的交换（Ch 9 背景）
- **BP 曲线 / BP curve** — 国际收支平衡曲线；资本完全流动时水平（Ch 14）
- **预算线 / budget line** — `P₁X₁ + P₂X₂ = I`；斜率为 `−P₁/P₂`（Ch 2）
- **经济周期 / business cycle** — 经济活动围绕长期趋势的周期性波动，分繁荣/衰退/萧条/复苏四阶段（Ch 13）

## C

- **剑桥方程 / Cambridge equation** — 货币需求 `Md = k·PY`，即交易动机下货币需求与名义收入成比例（Ch 11 背景）
- **资本 / capital** — 生产出来的生产要素（机器、厂房）；与"金融资本"不同（Ch 6）
- **卡特尔 / cartel** — 寡头间的公开合谋，联合定产定价以最大化共同利润（Ch 5）
- **古典总供给曲线 / classical AS curve** — 长期总供给曲线，垂直于充分就业产出（Ch 12）
- **科斯定理 / Coase theorem** — 产权清晰且交易成本为零时，外部性可通过市场交易自行解决，且结果与产权初始分配无关（Ch 8）
- **蛛网模型 / cobweb model** — 供给取决于上一期价格的动态模型；收敛 ⟺ δ<β ⟺ 均衡点上 Ed>Es（Ch 1）
- **共谋 / collusion** — 寡头间的合作行为（Ch 5）
- **比较优势 / comparative advantage** — 以更低的**机会成本**生产某产品的能力（Ch 14 相关）
- **比较静态分析 / comparative statics** — 外生变量变动前后**两个均衡状态**的对比，不考察调整过程（Ch 0, Ch 1）
- **消费者均衡 / consumer equilibrium** — 预算约束下效用最大：`MU₁/P₁ = MU₂/P₂ = λ` 或 `MRS = P₁/P₂`（Ch 2）
- **消费者剩余 / consumer surplus** — 消费者愿付价格与实际支付之差（Ch 4, Ch 8）
- **消费函数 / consumption function** — `C = α + βY`；`α` 自发消费、`β` 边际消费倾向（Ch 10）
- **契约曲线 / contract curve** — 埃奇沃思盒中所有帕累托最优点构成的轨迹（Ch 7）
- **古诺模型 / Cournot model** — 双寡头以产量为策略变量的博弈；均衡由两反应函数联立得出（Ch 5）
- **交叉价格弹性 / cross-price elasticity** — `Exy = (ΔQx/Qx)/(ΔPy/Py)`；替代品为正、互补品为负（Ch 1）
- **挤出效应 / crowding out** — 财政扩张推高利率，从而减少私人投资（Ch 11, Ch 15）
- **周期性失业 / cyclical unemployment** — 经济衰退导致的失业（Ch 9, Ch 13）
- **规模经济 / economies of scale** — 产量增加使长期平均成本下降；**自然垄断的成因**（Ch 3, Ch 8）
- **规模报酬 / returns to scale** — 全部要素同比例变动时产出的反应（递增/不变/递减）（Ch 3）

## D

- **无谓损失 / deadweight loss** — 因产量偏离最优水平而损失的福利（垄断、税收、外部性都会造成）（Ch 5, Ch 8）
- **需求 / demand** — 其他条件不变时，消费者在各价格下**愿意且能够**购买的数量（两层含义：欲望 + 购买力）（Ch 1）
- **需求函数 / demand function** — `Qd = D(P)`；线性形式 `Qd = α − βP`（Ch 1）
- **存款乘数 / deposit multiplier** — 基础货币经银行体系派生存款放大的倍数，`= 1/法定准备金率`（Ch 15）
- **动态分析 / dynamic analysis** — 引入时间，考察均衡的调整过程与路径（Ch 0）
- **需求规律 / law of demand** — 价格与需求量反向变动；**吉芬商品是例外**（Ch 1）
- **边际报酬（产量）递减规律 / law of diminishing marginal returns** — 其他要素不变时，连续增加一种要素，MP 最终递减（Ch 3）
- **边际成本 / marginal cost (MC)** — `MC = dTC/dQ`；**穿过 AC 与 AVC 的最低点**（Ch 3）
- **边际要素成本 / marginal factor cost (MFC)** — 增加一单位要素投入所增加的总成本（Ch 6）
- **边际消费倾向 / marginal propensity to consume (MPC, β)** — `MPC = ΔC/ΔY`；`0 < MPC < 1`（Ch 10）
- **边际储蓄倾向 / marginal propensity to save (MPS)** — `MPS = 1 − MPC`（Ch 10）
- **边际替代率 / marginal rate of substitution (MRS)** — 维持效用不变时，增加一单位 X 愿放弃的 Y 数量；`MRS = MUx/MUy`；递减（Ch 2）
- **边际技术替代率 / marginal rate of technical substitution (MRTS)** — 维持产量不变时，替代一单位劳动所需的资本量；`MRTS = MP_L/MP_K`（Ch 3）
- **边际转换率 / marginal rate of transformation (MRT)** — 生产可能性边界的斜率绝对值，等于 `MCx/MCy`（Ch 7）
- **边际收益 / marginal revenue (MR)** — `MR = dTR/dQ`；**垄断时 MR 斜率是需求线的两倍**（Ch 4, Ch 5）
- **边际收益产品 / marginal revenue product (MRP)** — `MRP = MR × MP`（Ch 6）
- **货币需求 / money demand** — 交易、预防、投机三种动机（Ch 11）
- **垄断竞争 / monopolistic competition** — 厂商众多、产品有差别、进出自由（Ch 5）
- **垄断 / monopoly** — 市场上只有一个卖者且无相近替代品（Ch 5）
- **道德风险 / moral hazard** — **事后的**信息不对称：一方在交易后改变行为（Ch 8）
- **乘数 / multiplier** — 自发支出变动引起的收入变动的倍数；`k = 1/(1−β)`（Ch 10）
- **需求价格弹性 / price elasticity of demand (Ed)** — `Ed = −(ΔQ/Q)/(ΔP/P)`；惯用正值（Ch 1）
- **边际产品价值 / value of marginal product (VMP)** — `VMP = P × MP`；产品市场完全竞争时 `VMP = MRP`（Ch 6）
- **引致需求（派生需求）/ derived demand** — 对生产要素的需求来源于对产品的需求（Ch 6）

## E

- **规模不经济 / diseconomies of scale** — 产量增加使长期平均成本上升（Ch 3）
- **经济人 / economic man** — 完全理性 + 自利的人格化抽象；西方经济学的基本假设与逻辑起点（Ch 0）
- **经济利润 / economic profit** — 总收益减去**全部机会成本**（含正常利润）；与会计利润不同（Ch 3）
- **经济租金 / economic rent** — 要素收入中超过其机会成本的部分（Ch 6）
- **埃奇沃思盒 / Edgeworth box** — 分析两人两商品交换（或两要素生产）的矩形图示工具（Ch 7）
- **效率工资 / efficiency wage** — 厂商主动支付高于市场出清的工资以提高生产率、降低流动；是工资刚性与失业的一种解释（Ch 13）
- **内生增长理论 / endogenous growth theory** — 把技术进步内生化，解释持续增长（AK 模型、人力资本、R&D）（Ch 16）
- **恩格尔曲线 / Engel curve** — 收入与某商品需求量的关系曲线（Ch 2）
- **均衡价格 / equilibrium price** — 需求量等于供给量时的价格（Ch 1）
- **汇率 / exchange rate (e)** — 一国货币兑换另一国货币的比率（Ch 14）
- **外部性 / externality** — 一方的行为对第三方造成的未通过价格反映的影响；分外部经济与外部不经济（Ch 8）
- **超额供给（过剩）/ excess supply** — 价格高于均衡价时 `Qs > Qd`（Ch 1）
- **超额需求（短缺）/ excess demand** — 价格低于均衡价时 `Qd > Qs`（Ch 1）

## F

- **要素市场 / factor market** — 交易生产要素的市场；要素需求是**引致需求**（Ch 6）
- **财政政策 / fiscal policy** — 用政府购买、转移支付、税收调节总需求（Ch 15）
- **固定成本 / fixed cost (FC)** — 不随产量变动的成本；**长期不存在固定成本**（Ch 3）
- **固定汇率制 / fixed exchange rate** — 央行承诺维持汇率不变；**货币政策失效、财政政策有效**（Ch 14）
- **浮动汇率制 / floating exchange rate** — 汇率由市场供求决定；**货币政策有效、财政政策失效**（Ch 14）
- **搭便车 / free rider** — 不付费而享用公共物品（Ch 8）
- **摩擦性失业 / frictional unemployment** — 求职与转换工作过程中的失业（Ch 9）

## G

- **GDP 折算指数（平减指数）/ GDP deflator** — `名义 GDP / 实际 GDP`（Ch 9）
- **GDP（国内生产总值）/ gross domestic product** — 一国（地区）一定时期内生产的**全部最终产品和服务**的**市场价值**（Ch 9）
- **一般均衡 / general equilibrium** — 所有市场**同时**达到供求均衡（Ch 7）
- **吉芬商品 / Giffen good** — 价格下降需求量反而减少的低档品；**收入效应超过替代效应**（Ch 2）
- **基尼系数 / Gini coefficient** — 洛伦兹曲线与对角线之间面积 / 对角线以下总面积；0（完全平等）到 1（完全不平等）（Ch 8）
- **GNP（国民生产总值）/ gross national product** — 一国**国民**一定时期内生产的最终产品市场价值；与 GDP 的差别是**国土原则 vs 国民原则**（Ch 9）
- **黄金律资本存量 / golden-rule capital stock** — 使**人均消费最大**的稳态资本存量（Ch 16）
- **增长核算 / growth accounting** — 把产出增长分解为资本、劳动、技术进步的贡献（Ch 16）

## H

- **希克斯分解 / Hicksian decomposition** — 在保持效用不变的前提下把价格变动的总效应拆为替代效应与收入效应（Ch 2）
- **基础货币（高能货币）/ high-powered money** — 流通中现金 + 商业银行准备金；经货币乘数放大为货币供给（Ch 15）

## I

- **激励相容 / incentive compatibility** — 机制设计使代理人说真话、按委托人目标行动（Ch 8 信息不对称）
- **收入效应 / income effect** — 价格变动通过实际收入变化引起的需求量变化（Ch 2）
- **需求收入弹性 / income elasticity of demand** — `Em = (ΔQ/Q)/(Δm/m)`；>0 正常品，0~1 必需品，>1 奢侈品，<0 低档品（Ch 1）
- **无差异曲线 / indifference curve** — 给消费者带来同等效用的商品组合轨迹；向右下、凸向原点、互不相交（Ch 2）
- **低档品 / inferior good** — 收入增加需求量减少的商品（Ch 2）
- **通货膨胀 / inflation** — 一般价格水平的持续上涨（Ch 13）
- **通货膨胀税 / inflation tax** — 政府以多发货币的方式向货币持有者征收的隐性税（Ch 13）
- **IS 曲线 / IS curve** — 产品市场均衡时 `r` 与 `Y` 的组合；向右下方倾斜（Ch 11）
- **等成本线 / isocost line** — `C = wL + rK`；斜率 `−w/r`（Ch 3）
- **等产量线 / isoquant** — 生产同一产量的要素组合轨迹（Ch 3）

## J

- **J 曲线效应 / J-curve effect** — 本币贬值后贸易收支先恶化、后改善的时滞现象（Ch 14）

## K

- **凯恩斯总供给曲线 / Keynesian AS curve** — 短期总供给曲线，水平段（Ch 12）
- **凯恩斯交叉图 / Keynesian cross** — 总支出线与 45° 线的交点决定均衡收入（收入-支出模型）（Ch 10）
- **凯恩斯区域 / Keynesian range** — LM 曲线的水平段；**流动性陷阱**所在，货币政策无效（Ch 11）

## L

- **拉弗曲线 / Laffer curve** — 税率与税收收入的关系（供给学派）（Ch 15）
- **拉氏指数 / Laspeyres index** — 用固定篮子计算的物价指数（CPI 属此类）（Ch 9）
- **边际效用递减规律 / law of diminishing marginal utility** — 其他条件不变，连续消费同一商品，每增加一单位带来的效用增量递减（Ch 2）
- **流动性陷阱 / liquidity trap** — 利率极低时货币需求无限，**货币政策失效**（Ch 11）
- **LM 曲线 / LM curve** — 货币市场均衡时 `r` 与 `Y` 的组合；向右上方倾斜（Ch 11）
- **长期 / long run** — 所有生产要素都可调整的时期（Ch 3）
- **洛伦兹曲线 / Lorenz curve** — 横轴人口累计百分比、纵轴收入累计百分比；越弯不平等越严重（Ch 8）
- **卢卡斯批判 / Lucas critique** — 基于历史数据估计的参数会随政策规则改变而改变，故不能直接用历史关系评估新政策（Ch 13）
- **流动偏好（流动性偏好）/ liquidity preference** — 凯恩斯的货币需求理论（交易 + 预防 + 投机）（Ch 11）

## M

- **边际分析 / marginal analysis** — 决策看"多做一单位"的增量收益与增量成本（全书方法论）
- **边际效用 / marginal utility (MU)** — 增加一单位商品消费所增加的效用；`MU = dTU/dQ`，递减（Ch 2）
- **市场失灵 / market failure** — 市场机制无法实现帕累托最优（垄断、外部性、公共物品、信息不对称）（Ch 8）
- **菜单成本 / menu costs** — 厂商调整价格本身带来的成本；价格黏性的微观基础之一（Ch 12）
- **方法论个人主义 / methodological individualism** — 把社会现象化约为个体行为的分析方法；西方经济学最基本的方法论（Ch 0）
- **混合策略均衡 / mixed-strategy equilibrium** — 博弈方以概率分布随机选择策略时的纳什均衡（Ch 5）
- **货币幻觉 / money illusion** — 人们只看名义量而忽略物价变动的行为偏差（Ch 13）
- **货币乘数 / money multiplier** — 货币供给与基础货币之比，`m = (1+rc)/(rd+re+rc)`（Ch 15）
- **蒙代尔-弗莱明模型 / Mundell-Fleming model** — 开放经济下的 IS-LM（`IS*`/`LM*`/`BP`）（Ch 14）

## N

- **纳什均衡 / Nash equilibrium** — 给定他人策略，自己无法通过单方改变而变好的策略组合（Ch 5）
- **自然垄断 / natural monopoly** — 因规模经济而由一家经营最经济的市场结构（Ch 8）
- **自然失业率 / natural rate of unemployment** — 摩擦性 + 结构性失业之和；与周期性失业相对（Ch 9, Ch 13）
- **名义 GDP / nominal GDP** — 用**当期价格**计算的 GDP（Ch 9）
- **名义工资 / nominal wage** — 以货币单位表示的工资；与实际工资（购买力）相对（Ch 13）
- **正常品 / normal good** — 收入增加需求量增加的商品（Ch 2）
- **正常利润 / normal profit** — 企业家才能的机会成本，包含在成本中；**长期均衡时经济利润为零但正常利润照拿**（Ch 3, Ch 4）
- **规范分析 / normative analysis** — 以价值判断为出发点，回答「应该是什么」，提出行为标准（Ch 0）

## O

- **奥肯定律 / Okun's law** — 失业率高于自然率 1 个百分点，产出缺口约 2 个百分点（Ch 9, Ch 13）
- **寡头 / oligopoly** — 少数几家厂商的市场；相互依存是其特征（Ch 5）
- **公开市场操作 / open market operations** — 央行在金融市场上买卖政府债券以调节基础货币；最常用的货币政策工具（Ch 15）
- **机会成本 / opportunity cost** — 选择某方案所放弃的最高价值（全书基础概念）
- **生产者剩余 / producer surplus** — 实际收到价格与愿接受价格之差（Ch 4, Ch 8）

## P

- **正（正常）利润 / normal profit** — 见「正常利润」
- **帕累托改进 / Pareto improvement** — 不损害任何人而使至少一人变好的变化（Ch 7）
- **完全竞争 / perfect competition** — 厂商众多、产品同质、进出自由、信息完全；企业是**价格接受者**（Ch 4）
- **菲利普斯曲线 / Phillips curve** — 通货膨胀率与失业率的关系：短期向右下倾斜、长期垂直于自然失业率（Ch 13）
- **庇古税 / Pigouvian tax** — 按边际外部成本征收的矫正税（Ch 8）
- **实证分析 / positive analysis** — 回答「是什么」，描述、解释、预测经济现象，不含价值判断，结论可被事实检验（Ch 0）
- **潜在产出 / potential output** — 充分就业（自然失业率）下经济所能生产的最大产出（Ch 13, Ch 16）
- **价格歧视 / price discrimination** — 同一商品对不同买者定不同价；一级（完全）、二级、三级（Ch 5）
- **囚徒困境 / prisoner's dilemma** — 个人理性导致集体非理性的博弈（Ch 5）
- **生产者价格指数 / producer price index (PPI)** — 衡量生产者出厂价格的指数（Ch 9）
- **生产可能性边界 / production possibility frontier (PPF)** — 给定资源与技术下两种产品最大产量组合的轨迹；边界上有效率，内部无效率（Ch 0, Ch 7）
- **公共物品 / public good** — 同时具有**非排他性**与**非竞用性**（Ch 8）
- **购买力平价 / purchasing power parity (PPP)** — 长期汇率由两国物价水平之比决定（Ch 14）
- **帕累托最优（帕累托效率）/ Pareto optimality** — 不存在任何帕累托改进的状态（Ch 7）

## Q

- **准租金 / quasi-rent** — 对**短期供给固定**的生产要素的支付，即固定要素的收益（Ch 6）

## R

- **规模报酬不变 / constant returns to scale** — 全部要素同比例增加，产出同比例增加（Ch 3, Ch 16）
- **理性预期 / rational expectations** — 人们利用一切可得信息（含政策规则）形成预期，预期无系统性偏差（Ch 13）
- **实际余额效应 / real balance effect** — 价格下降使实际货币余额上升、利率下降、投资增加；是 AD 向右下倾斜的机制之一（Ch 12）
- **实际汇率 / real exchange rate** — `ε = e·P*/P`；衡量本国商品的相对价格（Ch 14）
- **实际 GDP / real GDP** — 用**基期价格**计算的 GDP（Ch 9）
- **实际工资 / real wage** — 工资的购买力，`= 名义工资 / 价格水平`（Ch 13）
- **再贴现率 / rediscount rate** — 商业银行向央行再贴现票据的利率；提高它会收缩货币供给（Ch 15）
- **法定准备金率 / reserve requirement ratio** — 央行规定的准备金比率；**提高则货币供给减少**（Ch 15）

## S

- **储蓄函数 / saving function** — `S = −α + (1−β)Y`（Ch 10）
- **萨伊定律 / Say's law** — 供给自动创造自己的需求；古典学派「市场自动出清」的信念基础（Ch 12）
- **稀缺性 / scarcity** — 资源相对于人类无穷欲望的有限性；**经济学的出发点**（Ch 1）
- **甄别 / screening** — 信息劣势方设计机制诱导对方披露类型（保险体检、试用期）（Ch 8）
- **铸币税 / seigniorage** — 政府因发行货币而获得的实际资源（Ch 13）
- **短期 / short run** — 至少有一种生产要素不可调整的时期（Ch 3）
- **信号传递 / signaling** — 信息优势方主动发送可观察信号以显示类型（教育文凭、保修）（Ch 8）
- **斯塔克尔伯格模型 / Stackelberg model** — 寡头按**先后顺序**决策的产量博弈；领导者有先动优势（Ch 5）
- **静态分析 / static analysis** — 给定外生变量，求解内生变量的均衡状态及其特征（Ch 0）
- **稳态 / steady state** — 人均资本不再变动的状态（Ch 16）
- **结构性失业 / structural unemployment** — 经济结构变化导致技能与岗位不匹配（Ch 9, Ch 13）
- **替代效应 / substitution effect** — 价格变动使相对价格改变引起的需求量变化（Ch 2）
- **斯威齐模型 / Sweezy model** — 折弯的需求曲线模型，解释寡头价格刚性（Ch 5）
- **索洛模型（新古典增长模型）/ Solow model** — 稳态条件 `sf(k*) = (n+δ)k*`（Ch 16）
- **黏性（价格黏性/工资黏性）/ stickiness** — 价格或工资调整缓慢、不能瞬时出清市场的性质；短期总供给向右上倾斜的前提（Ch 12）

## T

- **泰勒规则 / Taylor rule** — 央行按通胀缺口与产出缺口系统性调整利率的政策规则（Ch 15）
- **托宾 q 比率 / Tobin's q** — 企业市值与资本重置成本之比；q>1 时投资扩张（Ch 15）
- **总成本 / total cost (TC)** — `TC = TFC + TVC`（Ch 3）
- **全要素生产率 / total factor productivity (TFP)** — 增长核算中扣掉资本与劳动贡献后的"余值"，反映技术进步（Ch 16）
- **总产量 / total product (TP)** — 一定投入下的总产出（Ch 3）
- **总效用 / total utility (TU)** — 消费一定量商品获得的总满足（Ch 2）
- **公地悲剧 / tragedy of the commons** — 公共资源因自由使用而过度消耗（Ch 8）
- **转移支付 / transfer payment** — 政府无需对应产品与服务的支出（救济金、养老金）（Ch 10, Ch 15）

## U

- **失业率 / unemployment rate** — `失业人数 / 劳动力总数`；**分母是劳动力，不是总人口**（Ch 9）
- **效用 / utility** — 消费者从商品中获得的满足感；主观评价（Ch 2）

## V

- **可变成本 / variable cost (VC)** — 随产量变动的成本（Ch 3）

## W

- **福利经济学第一定理 / first welfare theorem** — 完全竞争的一般均衡是帕累托最优的（Ch 7）
- **福利经济学第二定理 / second welfare theorem** — 任何帕累托最优都可通过初始禀赋的再分配 + 竞争均衡实现（Ch 7）
- **工资刚性 / wage rigidity** — 工资不能随劳动市场供求及时调整；是凯恩斯失业与短期 AS 向右上倾斜的原因之一（Ch 13）
- **瓦尔拉斯定律 / Walras's law** — 所有市场超额需求的总和恒等于零；故 n 个市场中只有 n−1 个独立（Ch 7）
