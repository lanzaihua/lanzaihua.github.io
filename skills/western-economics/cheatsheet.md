## 题型 → 首选方法

| 看到什么题 | 先做什么 | 别做什么 |
|---|---|---|
| 名词解释 | 定义 + 关键特征 + 一句经济学含义 | 只背定义不写特征 |
| 简答题「影响 X 的因素」 | 分点列（通常 3–5 点），每点一句 | 写成一段散文 |
| 求均衡价格与数量 | 令 `Qd = Qs` 解方程，再回代求 P | 忘了验算 Q > 0 |
| 求弹性 | 分清**点弹性**（`−(dQ/dP)·(P/Q)`）与**弧弹性**（中点公式） | 漏负号，或点/弧混用 |
| 税收归宿 | 消费者份额 = `Es/(Ed+Es)`，生产者份额 = `Ed/(Ed+Es)` | 把 Ed、Es 的分子分母弄反 |
| 求消费者均衡 | `MU₁/P₁ = MU₂/P₂ = λ` 或 `MRS = P₁/P₂` | 忘记预算约束联立 |
| 求生产者均衡 | `MRTS = w/r` 或 `MP_L/w = MP_K/r` | 与消费者均衡的公式混用 |
| 求利润最大化产量 | `MR = MC`（一切市场结构通用） | 在完全竞争下误把 `P` 当 `MR` 以外的量 |
| 求垄断均衡 | 先求 `MR`（**斜率是需求线两倍**），再 `MR = MC` | 直接用 `P = MC` |
| 求古诺均衡 | 写两个反应函数联立 | 把两企业产量当同一变量 |
| 求短期均衡状态 | `P` vs `AC` 定盈亏；`P` vs `AVC` 定开工 | 用 `AC` 判断是否停业 |
| 求 IS/LM 曲线 | IS：`Y = C + I + G` 消 `r`；LM：`M/P = L₁(Y) + L₂(r)` | 混淆横纵轴（都是 `Y` 与 `r`） |
| 求乘数 | 记牢：投资 `1/(1−β)`、税收 `−β/(1−β)`、平衡预算 **`= 1`** | 把税收乘数当正数；把平衡预算乘数当 0 |
| 菲利普斯曲线 | 短期向右下、**长期垂直** | 用短期替代关系推长期 |
| 蒙代尔-弗莱明 | **固定汇率：财政有效/货币无效；浮动汇率：反过来** | 记反两个制度 |
| 新古典增长模型稳态 | `sf(k*) = (n+δ)k*` | 写成 `sf(k*) = k*`（漏折旧与人口增长） |

## 符号约定（全技能统一）

| 符号 | 含义 | 符号 | 含义 |
|---|---|---|---|
| `Qd / Qs` | 需求量 / 供给量 | `Ed / Es` | 需求 / 供给价格弹性 |
| `TU / MU` | 总效用 / 边际效用 | `MRS` | 边际替代率 |
| `TP / AP / MP` | 总/平均/边际产量 | `MRTS` | 边际技术替代率 |
| `TC / AC / MC` | 总/平均/边际成本 | `MR` | 边际收益 |
| `VMP / MRP` | 边际产品价值 / 边际收益产品 | `MFC` | 边际要素成本 |
| `Y / C / I / G / NX` | 收入/消费/投资/政府购买/净出口 | `β` | 边际消费倾向 MPC |
| `MPC / MPS` | 边际消费/储蓄倾向 | `k` | 乘数 |
| `r / e` | 利率 / 汇率 | `u / π` | 失业率 / 通胀率 |

⚠️ **`β` 在本书里就是 MPC**（不是"贝塔系数"）；**`α` 是自发消费**。这是 OCR 最容易认错的两个符号。

## 三条跨章铁律

1. **`MR = MC` 是唯一通用的利润最大化判据**——完全竞争下它退化为 `P = MC`，垄断下 `P > MC`。所有市场结构的均衡都是它的特例。
2. **一切"最优"都是边际相等**：消费者 `MU/P` 相等、生产者 `MP/w` 相等、帕累托 `MRS = MRT`。**找到"两种用途的边际收益相等"就找到了答案。**
3. **弹性决定谁承担**：税负、汇率传递、成本转嫁——**弹性小的一方承担得多**（因为跑不掉）。

## Tells & smells（看到即警觉）

- 把税收乘数写成正数 → 应是 `−β/(1−β)`（增税减少收入）
- 平衡预算乘数写成 0 → 应为 **1**（政府购买乘数 + 税收乘数 = 1）
- 用 `AC` 判断是否停业 → 应看 `AVC`（固定成本是沉没成本）
- 垄断下用 `P = MC` 求最优产量 → 应用 `MR = MC`，且 `P > MC`
- 忘了 `MR` 斜率是需求线的两倍 → 垄断题会全错
- 新古典稳态漏 `(n+δ)` → 稳态条件错
- 菲利普斯曲线用短期替代关系推长期 → 长期是**垂直**的
- 固定汇率下说货币政策有效 → 恰恰相反
- `VMP` 与 `MRP` 混用 → 只在**产品市场不完全竞争**时两者不同
- 公共物品最优供给写 `MRS = MRT` → 应是 **`ΣMRS = MRT`**（垂直加总）
- 帕累托最优当成公平 → 效率与公平是两件事
- 弹性漏负号 → 需求价格弹性按惯例取正值，但推导里负号不能丢

**三个读法**：
1. **真题密度与 ★ 权重不一致时，以真题密度排"先做哪章的题"、以 ★ 排"先背哪章的书"。** 典型：ch13、ch15 的 ★ 不算最高（13★、17★），但真题条数排前二——因为它们**适合出简答/论述**，而论述题最容易重复。
2. **ch05 是双料重点**：四个五星考点 + 12 条真题，是全册"书要背、题要练"都躲不开的一章。
3. **中央财经、东北财经、中南财经政法** 三校贡献最多真题——这三家的历年真题可作为主练场（但注意各校参考书与马工程教材的章节口径可能不同）。

## 练题路线

**只有 3 天（考前突击）**
1. 打开本表"真题数"前四章（ch13、ch15、ch11、ch03）→ 各做对应 exercises 文件的"计算题精解"与"真题精选"。
2. 每章做完，回 chapters 文件读一遍 `Anti-patterns`（易错点就是判卷点）。
3. 最后一天只做"自测：判断与选择"，把错题对应的章节段落重读一遍。

**有 1 周（正常复习）**
按册顺序过：上册 ch01→ch08、下册 ch09→ch16。每章节奏固定为 **读 chapter（30 min）→ 做 exercises 课后习题（20 min）→ 对答案并标出错点（10 min）**。ch05、ch02、ch06、ch10 四章（★ 最高）各留两轮。

**只背名词解释（考前一天）**
先 [ch00 exercises](exercises/ch00-introduction.md) 的"名词解释速背"12 条（导论是全卷第一题的高发区），再按章翻各 exercises 文件的"自测"栏——判断题的解析通常就是名词解释的答案。
