# 第9章 练习与真题 — 宏观经济的基本指标及其衡量

> 题源：教材课后习题（笔记详解）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10）

**1｜流量和存量的联系与区别。**
- 流量是**一定时期内发生的变量**（GDP、投资、消费、工资）；存量是**一定时点上存在的变量**（货币存量、资本总额、国民财富）。
- 联系：流量来自存量、又归于存量（新财富靠新创造的收入累积），存量只能经由流量而变。
- 不对称：**有存量必有对应流量，有流量未必有对应存量**（工资、进口就没有）；判据是"时期 vs 时点"。

**2｜买股票对个人是投资，为什么经济学不算投资、不计入 GDP？**
- 经济学投资 = 增加或替换**资本资产**的支出（新厂房、新设备、存货、新住宅），要形成新的生产能力。
- 买股票只是**产权转移**，没有新资本形成；券商经纪服务才是当期劳务（计入 GDP）。募资真去买设备建厂房，那笔支出才算投资。

**3｜说明核算 GDP 的支出法。**
- `GDP = C + I + G + NX`。
- **C**：耐用＋非耐用消费品＋服务；**不含个人购买住宅**（归投资）。
- **I**：固定资产投资（厂房、设备、商业用房、**新住宅**）＋存货投资（可正可负）；公式中的 I 是**总投资 = 净投资 + 重置投资（折旧）**；买股票债券不计入。
- **G**：各级政府购买产品与服务的支出；**不含转移支付与公债利息**（没有交换产品）。判据是**购买者类型**：同一辆车，家庭买是 C、企业买是 I、政府买是 G；唯一例外是住宅，谁买都算投资。
- **NX = X − M**：进口要减（收入流向国外、买的不是本国产品），出口要加。

**4｜名义 GDP 与实际 GDP，哪一个更能描述经济活动变化与福利？**
- 名义用**当年价格**、实际用**基期价格**；实际 GDP 的变化只反映产量变化。
- 结论：**实际 GDP 更好**——名义上升既可能来自产量，也可能只是涨价；产量不变而价格翻倍时名义翻倍、实际不变。
- 比较生活水平用**实际人均 GDP = 实际 GDP ÷ 人口**，但它不足以单独作政策目标（不说明产量怎么用）。

**5｜GDP 指标的缺陷（六条）。**
- ①不反映社会成本（赌博、黑市也能推高 GDP）；②不反映增长方式付出的代价（污染、生态破坏）；③不反映效率与效益；④不反映生活质量（闲暇、健康、寿命）；⑤不反映分配状况；⑥不反映重要的**非市场活动**（家务、照顾老人、养育儿童），损害客观性与可比性。
- 答题时把第⑥条挂到"GDP 只算市场价值"这个限定词上，最容易被漏。

**6｜比较 GDP 平减指数和消费价格指数。**
- 相同：都提供一组产品与服务的价格水平信息，都能算通胀率。
- 差异三条：①**覆盖范围**——平减指数含**全部国内生产**的最终产品，CPI 只含**消费者购买**的；②**进口品**——平减指数不含，CPI 篮子含；③**权数**——CPI 固定篮子（拉氏），平减指数用当期产量加权（帕氏）。

**7｜篮子为 5 千克大米＋2 个橘子，2010 年为基期，写出 2018 年 CPI 的表达式。**
- `CPI₂₀₁₈ = (5×P米,2018 + 2×P橘,2018) ÷ (5×P米,2010 + 2×P橘,2010) × 100`。
- 要点：**分子当年价格、分母基期价格，数量（5、2）两边都固定**——篮子固定正是 CPI 的全部要点：同一篮子在两期各要花多少钱之比。
- 源文这条公式在 OCR 中丢失，按定义补回。

**8｜失业有哪些类型？哪种是政府最关注的？**
- **摩擦性**：岗位与劳动力**匹配需要时间**，一定程度的摩擦性失业不可避免。
- **结构性**：**技能或地域**与岗位需求持续不匹配，特点是失业与职位空缺并存；**工资刚性**是重要原因，持续期长于摩擦性。
- **周期性**（总需求不足失业）：随衰退升、随扩张降，源于**总需求下降**；**政府最关注**——它是否为零是判断充分就业的标志。

**9｜中国目前使用的失业率指标及评价。**
- 主体是**调查失业率**：劳动力调查/抽样推算的失业人口 ÷ 劳动力（就业＋失业）。
- 另一渠道是**城镇登记失业率**：只统计"符合条件且自愿去登记"的失业者，覆盖面窄，越来越难全面反映失业状况。

**10｜衡量失业的工作中可能面临哪些问题？**
- 核心是**沮丧劳动者**：屡屡碰壁后放弃找工作，既不算失业、也不算劳动力 → 失业率**下降**，但劳动力市场并未改善。
- 长期衰退中尤甚：失业率可能**低估**紧张程度——劳动力缩小会同时压低分子与分母。

## 二、考研真题精选（6 题）

**1｜国内生产总值**〔广东外语外贸大学2022研；浙江大学2019研；安徽师范大学2021研〕
- 考点：9.1 GDP 的四个限定词。
- 骨架：①定义（一国境内、一定时期、最终产品与服务、市场价值）；②GDP 是**地域概念**、GNP 是**国民概念**：`GNP = GDP + 国外要素净收入`；③核算：支出法 `C+I+G+NX`、收入法 `工资+利息+租金+利润+间接税+折旧`；④收口：用 GDP 是因国际口径统一、数据易得、更能衡量本国就业潜力。

**2｜GDP 折算（平减）指数**〔厦门大学2019研；南京大学2018研〕
- 骨架：①`平减指数 = 名义 GDP ÷ 实际 GDP × 100`；②权数是**当期产量**（帕氏），随商品份额改变，不像 CPI 固定；③用途：覆盖面广的价格指数，可算 `π=(P_t−P_{t−1})/P_{t−1}`；④局限：资料难搜集、受价格结构影响。

**3｜CPI**〔中央财经大学2015研〕
- 骨架：①固定篮子加权，`CPI = 现期篮子费用 ÷ 基期篮子费用 × 100`；②优点：及时、资料易得、直接反映居民生活成本；③缺点：只含消费品；三种偏差——**替代偏向、新产品引进、质量变动无法衡量**，故可能夸大物价上涨。

**4｜简述 GDP 的三种核算方法**〔中南大学2018研〕
- 骨架：①**生产法（增值法）**：加总各部门增加值 = 总产值 − 中间消耗，避免重复计算；②**支出法**：`C+I+G+(X−M)`；③**收入法**：`工资+利息+租金+利润+间接税+折旧`；④理论上三者相等，实践差额叫**统计误差**。易错：收入法别漏**间接税**与**折旧**。

**5｜支出法 GDP 的构成；什么是最终消费率？中国最终消费率为什么偏低**〔华南理工大学2012研〕
- 骨架：①`Y=C+I+G+NX` 四项定义各一句；②最终消费率 = 最终消费（居民＋社会）÷ GDP，衡量消费在总产出中的比重；③偏低五因：居民收入增速慢、分配格局不合理（劳动报酬占比低）、物价与房价挤压、公共服务不足（预防性储蓄）、城镇化质量不高。

**6｜GDP 核算原则、缺陷与绿色 GDP**〔武汉大学2011、2009研〕
- 骨架：①原则：当期、境内、最终产品、市场价值（时间／地域／产品／计价四重限定）；②缺陷见课后第 5 题六条；③绿色 GDP：扣除自然资源消耗与环境损失后的净值，比重越高说明增长正效应越高；④收口：它修补的正是"GDP 不反映增长代价"这一条。

## 四、计算题精解（3 题）

**题 1** 一经济只生产手机和蔬菜。2017 年：手机 10 部、价格 100 元；蔬菜 20 吨、价格 100 元。2018 年：手机 20 部、价 50 元；蔬菜 25 吨、价 200 元。以 2017 年为基期，求两年名义 GDP、2018 年实际 GDP、两年平减指数；篮子为 1 部手机＋2 吨蔬菜，求两年 CPI。〔中国海洋大学2020研〕

**解** ① 名义 GDP：2017 = 10×100＋20×100 = **3000 元**；2018 = 20×50＋25×200 = **6000 元**。
② 实际 GDP：2017 = 3000；2018 = 20×100＋25×100 = **4500 元**。
③ 平减指数：2017 = 3000/3000×100 = **100**；2018 = 6000/4500×100 ≈ **133**。
④ CPI：2017 = (1×100＋2×100)/(1×100＋2×100)×100 = **100**；2018 = (1×50＋2×200)/300×100 = **150**。
**答：名义 3000→6000，实际 3000→4500，平减 100→133，CPI 100→150。**
两者为何不同：平减指数按**当期产量**加权（涨价蔬菜权重大），CPI 按**固定篮子**（蔬菜固定 2 吨）。

**题 2** 某国：净出口 150、净投资 1250、消费 1600、资本折旧 500、政府税收 1000、企业间接税 750、政府购买 2000、社保基金 1500、未分配利润 1000、公司所得税 500、个人所得税 800（亿美元）。求 GDP、NDP、NI、PI、DPI。〔武汉大学2014研〕

**解** ① `GDP = C + (净投资＋折旧) + G + NX = 1600 + (1250+500) + 2000 + 150 = `**5500**。
② `NDP = 5500 − 500 = `**5000**。
③ `NI = NDP − 间接税 = 5000 − 750 = `**4250**。
④ `PI = NI − 未分配利润 − 公司所得税 − 社保 + 转移支付 = 4250 − 1000 − 500 − 1500 = `**1250**。
⑤ `DPI = PI − 个税 = 1250 − 800 = `**450**。
**答：5500 / 5000 / 4250 / 1250 / 450 亿美元。**
易错：支出法的 I 用净投资时必须补回折旧；这条链 `GDP−折旧→NDP−间接税→NI−(利润+社保)+转移支付→PI−个税→DPI` 每一刀都在剔"不属于家庭的钱"，别跳步。

**题 3** 采矿公司采矿石售价 100 亿元、付工资 50 亿元；炼钢厂买矿炼钢，售价 420 亿元、付工资 300 亿元；轧钢厂买钢材造钢轨，售价 500 亿元、付工资 30 亿元，均无其他成本。用增值法、收入法、最终产品法分别求 GDP。〔山东大学2014研〕

**解** ① **增值法**：各环节增值 = 售价 − 中间投入 → 100＋(420−100)＋(500−420) = **500 亿元**。
② **收入法**：工资 50＋300＋30 = 380；利润 (100−50)＋(420−100−300)＋(500−420−30) = 50＋20＋50 = 120；合计 **500 亿元**。
③ **最终产品法**：钢轨是最终产品（卖给铁路公司修路），价值 **500 亿元**。
**答：三法同为 500 亿元——"产出＝收入＝支出"。**

**本章题眼**：本章题都归结为**守口径**——先问"是否当期、境内、最终产品、经过市场"，再问价格指数用基期还是当期数量加权。
