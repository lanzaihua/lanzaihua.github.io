# 第13章 练习与真题 — 失业、通货膨胀和经济周期

> 题源：教材课后习题（笔记详解版）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10 题）

**1｜西方经济学如何解释失业？失业的影响表现在哪些方面？**
- 四派一句话：古典（萨伊定律）只承认**摩擦性失业**与**自愿失业**，"没有真正的失业"；凯恩斯承认**非自愿失业**，根源是**有效需求不足**；新凯恩斯用**工资黏性**解释非自愿失业（合同论、隐含合同、局内人-局外人、效率工资）；货币主义归结为**自然失业率假说**——增发货币短期能骗出劳动供给，长期只涨物价。
- 影响三端：个人与家庭（收入中断、健康与声望受损）、社会稳定、经济（资源闲置，损失＝潜在 GDP − 实际 GDP）。

**2｜什么是自然失业率？决定因素是什么？它是否就是充分就业的失业率？**
- 定义：无货币因素干扰、劳动与商品市场自发供求均衡时的失业率；即**摩擦性＋结构性失业率**。
- 决定因素两个：**失业持续时间**（取决于经济周期与劳动力市场结构：市场组织、人口构成、救济金制度等）与**失业频率**（一定时期沦为失业者的平均次数，取决于企业对劳动需求的变化幅度、新劳动力增长速度）。二者越高，自然率越高。
- 是。自然失业率又称充分就业的失业率，也称**不加速通胀的失业率（NAIRU）**；但它是**锚不是常数**，把失业压到它以下只换来加速的通胀。

**3｜西方经济学怎样分析经济周期的原因？**
- 七种传统解释：消费不足论、投资过度论（资本品部门跑在消费品部门前面）、货币信用过度论、创新周期论（熊彼特：创新是不连续的）、太阳黑子论、政治经济周期论、**乘数-加速数理论**（投资↔收入相互放大）。
- 第八种：**实际经济周期理论（RBC）**——生产率的随机冲击（技术、国际动乱、气候）是波动源泉，货币短期中性。

**4｜通货膨胀有哪几种类型？成因如何解释？**
- 按程度：爬行、加速（奔腾）、超速；按原因：需求拉上、成本推动、结构型。
- **需求拉上**："过多的货币追逐过少的商品"。AS 在充分就业产量处转为垂直后，只有价格涨、产量不增，这才是"真正的通货膨胀"。
- **成本推动**：没有超额需求，AS 左移 → 价格升、产量降（**滞胀**）。三来源：工资推动（工会集体议价，工资涨幅超生产率，形成工资-物价螺旋）、利润推动（垄断寡头提价快于成本）、进口型（进口原材料涨价）。
- **结构型**：总供求大体平衡，仅因需求结构变动与各部门劳动生产率增速差异（工资按"公平"看齐）而涨价。
- **货币主义**：`MV = PY` ⇒ `π = m + v − y`，通胀主要是货币供给过快。

**5｜"通货膨胀最根本的原因是货币因素"对不对？用 AD-AS 与 IS-LM 分析。**
- 教材口径：**对**。货币供给↑ → LM 右移 → r↓ → I↑ → AD 右移 → P↑，即"过多的货币追逐过少的商品"。
- 必须补长期一环：AD 右移短期提价又提产；长期预期上调、SRAS 上移，产出回到潜在水平、价格更高 ⇒ **货币长期中性，只决定价格水平**。
- 易错：别答成"任何物价上涨都是货币现象"——成本推动、结构型涨价在 M 不变时也能发生。

**6｜什么是菲利普斯曲线？不同形状反映资本主义经济发生了哪些变化？**
- 三形态：①**原始**（失业-工资，菲利普斯 1958，英国 1861—1957 数据，u 与货币工资变化率负相关）；②**改造**（失业-物价，萨缪尔森-索洛，用 π 替换工资上涨率，仍向右下）；③**引申**（产出-物价，经奥肯定律用增长率替换 u，增长率与 π **同向**）。
- 变化：五六十年代曲线稳定、可"菜单式"操作 → 七十年代滞胀使曲线右移、旧关系失效 → 附加预期后短期向右下、长期垂直。

**7｜菲利普斯曲线与总供给曲线是什么关系？**
- 同一关系的两种写法。由 `Y = Y_f + α(P − P^e)` 得 `P = P^e + (Y − Y_f)/α`；两边减 `P₋₁`，令 `π = P − P₋₁`、`π^e = P^e − P₋₁`，用奥肯定律把产出缺口换成 `−β(u − u*)`，再加供给冲击 μ：
```
π = π^e − β(u − u*) + μ,  β > 0
```
- 三项读法：预期项定曲线位置、周期性失业定沿曲线移动、μ 定冲击。故与 AS 一样，它描述的是**实际波动与未被预期到的价格波动**之间的关系。

**8｜能否用菲利普斯曲线分别解释失业率的决定和通胀率的决定？**
- 不能。它只给出二者的**替代关系**（统计相关），不含因果机制；失业由自然率与周期性因素决定，通胀由货币、成本与预期决定。用一条相关性曲线同时"解释"两个变量，等于循环论证。

**9｜西方国家用菲利普斯曲线做政策操作时，是否像 AD-AS 那样考虑总需求方面的影响？**
- 考虑了。短期的通胀-失业组合正是 AD 沿短期 AS 移动的结果：AD↑ → 产量↑ → 就业↑ → u↓、π↑。财政与货币政策推动 AD，于是 PC 成了"通胀-失业菜单"——**但只在短期成立**。

**10｜怎么理解奥肯定律所解释的失业与产出关系？**
- `(Y − Y_f)/Y_f = −α(u − u*)`，α > 0：失业率每高于自然率 1 个百分点，实际 GDP 低于潜在 GDP 约 **2 个百分点**。
- 两条推论：GDP 未达充分就业时，实际 GDP 须与潜在 GDP **同速**增长才能不让失业率上升；想让失业率下降，实际增速必须**快于**潜在增速。α 是经验系数，因国因时而异。

## 二、考研真题精选（6 题）

**1｜结构性失业 / 摩擦性失业** 〔广东外语外贸大学2022研；中国人民大学2019研〕
- 考点：13.1 失业类型与自然失业率。
- 骨架：①摩擦性＝工作搜寻中难以避免的短期、局部性失业，源于劳动力正常流动（毕业、搬迁），失业者**能胜任**空缺；②结构性＝供给与需求**不匹配**（技能、地点、行业），特点是**失业与空位并存**，来源之一是**工资刚性**；③治理不同：前者靠信息与服务机构，后者靠培训、迁移；④收口：前者"匹配要时间"，后者"匹配不上"，故结构性更严重。

**2｜自然失业率** 〔湖南大学2022研；北京理工大学2021研；暨南大学2017研〕
- 骨架：①定义（无货币因素干扰、自发供求均衡时的失业率）；②构成：摩擦性＋结构性；③决定：持续时间与频率；④性质：与通胀无替代关系，压低它只带来加速通胀；⑤别称：充分就业失业率、NAIRU。

**3｜奥肯定律** 〔西北大学2022研；武汉大学2019研；中央财经大学2015研〕
- 骨架：①奥肯用美国 55 个季度数据回归；②内容＋公式；③两条推论（同速增长才不恶化、快于潜在才下降）；④评价：经验规律、有国别差异，但确立了增长与就业的相关性。

**4｜成本推动型通货膨胀的形成机理** 〔北京林业大学2018研〕
- 骨架：①定义：无超额需求，仅因供给成本上升而涨价；②两源：工资推动（不完全竞争劳动市场、工会议价，工资涨幅超生产率 → 工资-物价螺旋）、利润推动（垄断寡头限产提价，涨价快于成本）；③AD 不动、AS 左移，交点沿 AD 向左上 → 价格升、产量降，即滞胀；④政策困境：紧缩则加深衰退，扩张则加剧通胀。

**5｜预期到与未预期到的通货膨胀成本** 〔合肥工业大学2017研；厦门大学2014研〕
- 骨架：①预期到的：鞋底成本、菜单成本、相对价格与资源配置扭曲、税收扭曲、生活不便；②未预期到的：不确定性上升＋**财富再分配**（不利于固定收入者与储蓄者，不利于债权人、有利于债务人）＋相对价格变动性增加；③收口：越被预期、平衡，实际效应越小。

**6｜短期与长期菲利普斯曲线的区别** 〔中央财经大学2019研〕
- 骨架：①图形：短期向右下、长期垂直；②含义：短期 `π ≠ π^e` 时存在替代，长期 `π = π^e` ⇒ `u = u*`；③机制：适应性预期逐期上调，短期曲线整体上移，连接各期均衡点得垂线；④政策：短期有效、长期无效，只换来更高通胀。

## 四、计算题精解（2 题）

**题 1**（劳动市场与失业，〔北京邮电大学2013研〕）劳动需求 `N_d = 20 − 0.5(W/P)`，劳动供给 `N_s = 0.5(W/P)`，寻找工作的人数 `J_s = 0.2(W/P)`。求均衡实际工资、均衡就业量、寻找工作人数、失业人数、劳动力总人数。

**解**
① 均衡：`20 − 0.5(W/P) = 0.5(W/P)` ⇒ `W/P = 20`。
② 就业：`N = 0.5 × 20 = 10`。
③ 寻找工作：`J_s = 0.2 × 20 = 4`。
④ 失业人数＝寻找工作而未被雇佣者＝4。
⑤ 劳动力总数＝10＋4＝14。
**答：W/P = 20；就业 10；寻找工作 4；失业 4；劳动力 14。**

**题 2**（菲利普斯曲线与牺牲率，〔题库〕）`π = π^e − 3(u − u*)`，`u* = 5%`，预期为适应性预期。当前通胀 5%，央行下一年目标 2%。
（1）实现该目标引起的失业率；（2）次年继续 2% 目标时的失业率；（3）按奥肯定律（失业率每高 1 点、产出低 2 点）算产出牺牲率；（4）若为理性预期，牺牲率是多少？

**解**
① `π^e = π₋₁ = 5%`：`2% = 5% − 3(u − 5%)` ⇒ `u = 6%`，周期性失业 1 个百分点。
② 次年 `π^e = 2% = π`：`2% = 2% − 3(u − 5%)` ⇒ `u = u* = 5%`。
③ 通胀降 3 个百分点的代价是失业高 1 个百分点 → 产出低于潜在 2 个百分点。牺牲率＝产出损失/通胀降幅＝`2%/3% ≈ 0.67`。
④ 理性预期下 `π = π^e` 立即成立，`u = u*` 不变，产出不变 ⇒ 牺牲率＝0。
**答：6%；5%；约 0.67（即每降 1 个百分点通胀损失约 0.67 个百分点产出）；0。**

**本章题眼**：凡问"政策能否降低失业"，先问**有没有骗过预期**——短期能（沿曲线移动），长期不能（曲线垂直），这是本章所有论述题的落点。
