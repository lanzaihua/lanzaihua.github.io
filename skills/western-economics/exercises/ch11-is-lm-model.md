# 第11章 练习与真题 — 国民收入的决定：IS-LM 模型

> 题源：教材课后习题（笔记详解）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10）

**1｜IS 曲线向右下方倾斜的依据是什么？**
- IS 是产品市场均衡 `I(r)=S(Y)` 的轨迹：`r↓→` 投资成本降、`I↑→` 经乘数 `Y↑`，故 r 与 Y 反向。
- 反解 `r=(α+e)/d−[(1−β)/d]Y`，斜率 `−(1−β)/d`。
- 判读：IS 右上方 `I<S`（超额产品供给），左下方 `I>S`。

**2｜凯恩斯货币需求理论与新古典货币需求理论有何不同？**
- 新古典（可贷资金说）：利率由 I 与 S 共同决定，S 是利率的增函数，货币只是交易媒介，市场自动均衡。
- 凯恩斯：储蓄主要取决于**收入**而非利率，利率改由**货币市场供求**（流动偏好 vs 货币供给）决定；货币需求分三动机，投机需求取决于利率。
- 这是 IS-LM 能成立的关键一步：利率从"产品市场的产物"变成"货币市场的产物"。

**3｜"流动性陷阱"概念意义何在？**
- 内容：r 极低时人人预期债券只跌不涨，愿持有任意数量货币 → 货币需求对 r 弹性无穷大（`h→∞`），LM 水平。
- 意义：指出**货币政策有下限**——增发货币只被持有、压不低 r、刺激不了投资；此时财政政策极有效（无挤出）。为萧条中的政府干预提供依据。

**4｜LM 曲线为什么向右上方倾斜？**
- 由 `M/P=kY−hr`：`Y↑→` 交易性货币需求↑ → M 既定 → 必须让 L2↓ → `r↑`（卖债券→债券价格跌→r 升）。
- 斜率 `k/h`：k 越大越陡、h 越大越平。判读：LM 右下方 `L>M`，左上方 `L<M`。

**5｜IS-LM 是否已克服产品市场与货币市场的循环决定问题？**
- 不是"消除"依赖，而是把依赖写成**联立方程组**：I 依赖 r、r 依赖 Y 的循环被两线交点一次求解。
- 但它仍是**比较静态**：只给均衡值，不解释走向均衡的过程，也不处理预期与动态。

**6｜教材算例：`C=130+0.6Y`，`I=750−2000r`，G=750。**
(1) I 变为 `750−3000r` 后比较 IS 斜率；(2) 增加 G 时哪种收入变化大；(3) 增加货币供给时哪种影响大。
- ①变化前 `Y=130+0.6Y+750−2000r+750` → `r=0.815−0.0002Y`；变化后 → `r=0.543−0.000133Y`，**更平缓**（d：2000→3000）。
- ②IS 越平缓，同一 ΔG 使 r 涨得更多、挤出更多 → **变化前的收入变化更大**。
- ③扩张货币降 r，d 越大投资反应越大 → **变化后的收入变动更大**。
- 一句话：d 大时"财政被挤出、货币更有力"。

**7｜教材算例：`C=800+0.63Y`，`I=7500−20000r`，`L=0.1625Y−10000r`，M=6000，P=1，G 由 7500 增至 8500，挤出多少私人投资？**
- ①初始：`0.37Y=15800−20000r`；`6000=0.1625Y−10000r` → `Y₁=40000`、`r₁=5%`、`I₁=6500`。
- ②G=8500：`0.37Y=16800−20000r` → `Y₂≈41427.7`、`r₂≈7.32%`、`I₂≈6036`。
- ③挤出 `I₁−I₂≈`**464**。ΔY 仅约 1428，而乘数口径应有 `ΔG/(1−0.63)≈2703` —— 差额即挤出。
- 易错：挤出要算**私人投资的实际减少**，不等于 ΔG。

**8｜为什么价格水平上升会提高利率？**
- `P↑→` 同样交易量需要更多名义货币 → 货币名义需求↑；M 不变 → 卖债券 → 债券价格跌 → `r↑`。
- 这就是 ch12 的**利率效应**；本章先把 P 锁死，只把它当给定。

**9｜依靠 IS-LM 模型就能说明全部宏观经济政策吗？**
- 能说明**需求管理**政策：财政政策移 IS、货币政策移 LM，效果由两线斜率与所处区域决定。
- 不能说明：供给面（劳动市场、价格决定）、开放经济（汇率与资本流动）、动态与预期、政策时滞与制度约束。

**10｜IS-LM 模型的错误与局限性。**
- ①两线交点有偶然性、稳定性不足；②只有需求、排除供给（只适合短期萧条）；③强调利率而忽略价格；④静态分析、无动态；⑤忽略消费需求的作用与资本边际效率对投资不确定性的影响；⑥只要求价值总量相等，丢掉了供求在实物结构上的相等。

## 二、考研真题精选（6 题）

**1｜IS 曲线**〔浙江大学2019研〕
- 骨架：①定义（产品市场均衡 `I=S` 时 r 与 Y 的组合轨迹，右下倾斜）；②推导 `Y=(α+e−dr)/(1−β)`；③斜率三因素（d、β、t）；④右上方 `I<S`、左下方 `I>S`。

**2｜流动性陷阱**〔厦门大学2022研；中央财经大学2019研〕
- 骨架：①定义（r 极低、货币需求弹性无穷大、LM 水平）；②机理（债券价格已到顶、只跌不涨→持币待购）；③政策含义（货币政策无效、财政政策极有效、无挤出）；④留一句：经验上未被证实，90 年代日本被疑为近似情形。

**3｜流动性陷阱中扩张性货币政策是否有效？**〔浙江财经大学2021研〕
- 骨架：①无效——M↑ 全被持有，r 不降，I 与 Y 不动；②图形语言：LM 水平段右移，与 IS 的交点 Y 不变；③反向结论：此区间财政政策最有效，IS 右移只增 Y、不抬 r、无挤出。

**4｜LM 曲线的三个区域及其经济含义**〔中南财经政法大学2013研〕
- 骨架：①凯恩斯区域（`h→∞`，水平，萧条）：货币政策无效、财政政策极有效；②中间区域（`0<h<∞`）：两种政策都有效；③古典区域（`h=0`，垂直，繁荣）：财政政策无效（完全挤出）、货币政策有效。

**5｜减税在"央行保持利率不变"与"保持货币供给不变"下效果有何不同？**〔中国人民大学2019研〕
- 骨架：①减税 → IS 右移 `ΔT·β/(1−β)`；②保利率不变：央行须增货币、LM 右移同等幅度，产出 `Y₁` 增得最多（无挤出）；③保 M 不变：沿 LM 上移，r↑、挤出，产出 `Y₂<Y₁`；④结论：**货币配合与否决定财政政策效果**。

**6｜三部门 IS-LM 联立，及平衡预算下"增税"与"减支出"哪个对产出影响小**〔中央财经大学2016研〕
- 题：`C=100+0.9(Y−T)`，`I=190−10r`，NX=−200，G=200，T=100；M=2000，P=5，`L=Y−100r`。
- 解：①IS `Y=2000−100r`，LM `Y=400+100r` → `Y=1200`、`r=8`；②G→100：IS `Y=1000−100r` → `Y=700`；③T→200：IS `Y=1100−100r` → `Y=750`。
- 答：**增税影响更小**（−450 < −500）——减支出是整笔减少需求，增税只减少 β 倍消费。

| 4 | IS 右上方、LM 右下方的点表示产品超额供给、货币超额需求 | 对 | IS 右上 `I<S`；LM 右下 `L>M`（〔题库〕） |

## 四、计算题精解（3 题）

**题 1** 两部门：`C=100+0.8Y`，`I=150−6r`，M=150，`L=0.2Y−4r`。(1) IS、LM；(2) 共同均衡；(3) 若为三部门 `T=0.25Y`、G=100、`L=0.2Y−2r`，求均衡。〔广西民族大学2021研〕

**解** ①`Y=100+0.8Y+150−6r` → **IS：`Y=1250−30r`**；`0.2Y−4r=150` → **LM：`Y=750+20r`**。
②`1250−30r=750+20r` → **r=10**、**Y=950**。
③`Y=100+0.8(Y−0.25Y)+150−6r+100` → **IS：`Y=875−15r`**；`0.2Y−2r=150` → **LM：`Y=750+10r`** → `875−15r=750+10r` → **r=5、Y=800**。
**答：①IS `Y=1250−30r`、LM `Y=750+20r`；②r=10、Y=950；③r=5、Y=800。**

**题 2** 挤出效应定量：`C=800+0.63Y`，`I=7500−20000r`，`L=0.1625Y−10000r`，M=6000，P=1，G 由 7500 增至 8500。

**解** ①初始：IS `0.37Y=15800−20000r`，LM `0.1625Y−10000r=6000` → `Y₁=40000`、`r₁=0.05`、`I₁=6500`。
②G=8500：IS `0.37Y=16800−20000r` → `Y₂≈41427.7`、`r₂≈0.0732`、`I₂≈6036`。
③挤出 `I₁−I₂=`**464**；对照乘数口径 `k=1/(1−0.63)≈2.70`，ΔG=1000 本应带来约 2703 的 ΔY，实际只有约 1428。
**答：私人投资被挤出约 464，ΔY≈1428 而非 2703。**

**题 3** 四部门：`C=150+0.7Y_d`，`I=350−1500r`，G=250，t=0.1，`NX=100−0.03Y−500r`，P=5，`L=0.5Y−2000r`，`M/P=500`。〔浙江工商大学2021研〕

**解** ①IS：`Y=150+0.7(0.9Y)+350−1500r+250+100−0.03Y−500r` → **`Y=2125−5000r`**；LM：`0.5Y−2000r=500` → **`Y=1000+4000r`**。
②联立 → **r=0.125、Y=1500**，`I=350−1500×0.125=`**162.5**。
③G→520：IS `Y=2800−5000r` → **r=0.2、Y=1800**。乘数 `1/(1−0.63+0.03)=2.5`，ΔG=270 本应带来 ΔY=675，实际 300。
**答：存在挤出效应**——r 由 0.125 升到 0.2，私人投资被压低，收入只增 300。

**本章题眼**：IS-LM 题只有三件事——①把 IS、LM 各写成 `Y=…` 的方程；②联立解 `(Y,r)`；③凡问政策效果，先看曲线怎么移，再看移完 r 怎么变：**r 一动，投资必动，就有挤出**。
