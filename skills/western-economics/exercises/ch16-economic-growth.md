# 第16章 练习与真题 — 经济增长

> 题源：教材课后习题（笔记详解版）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10 题）

**1｜说明经济增长与经济发展的关系。**
- 经济增长：产量的持续增加，可用总量（GDP）或人均量表示，程度以增长率衡量。
- 经济发展：内涵更丰富，是"质"的概念，除增长外还包括生活质量与社会各方面的总体进步。
- 关系一句话：**经济增长是经济发展的前提、基础和核心**，但增长不等于发展。

**2｜推导总产量、人均产量和人口增长三者的增长率关系。**
- `Y = y × N`，两边取对数 `lnY = lny + lnN`，对 t 求导：`ġ_Y = ġ_y + ġ_N`。
- 即**总量增长率＝人均增长率＋人口增长率**，这是"总量/人均"换算的枢纽（积→相加、商→相减、幂→乘方次）。

**3｜什么是新古典增长模型的基本公式？它有什么含义？**
- 基本公式：`Δk = sf(k) − (n + δ)k`（有技术进步时为 `Δk = sf(k) − (n + δ + g_A)k`）。
- 含义：**资本深化＝人均储蓄（投资）− 资本广化**。`(n+δ)k` 是"临界投资"：δk 抵折旧、nk 为新工人配资本，合称**资本广化**，作用是让人均资本不下降；`sf(k)` 超出它的部分才使 k 上升。
- 几何：横轴 k、纵轴 y，`f(k)` 与 `sf(k)` 斜率递减，`(n+δ)k` 是斜率 n+δ 的直线，两线交点即稳态。

**4｜在新古典增长模型中，人口增长对经济有哪些影响？**
- 图形：`(n+δ)k` 变陡 → 稳态交点左移，**稳态人均资本 k* 与人均产出 y* 下降**（人口"稀释"资本）。
- 但总产量的稳态增长率**上升**为 n；储蓄率相同的两国，仅因 n 不同就会有很大的人均收入差距。
- 政策含义：计划生育（降低 n）能提高 k* 与人均收入，但**只带来水平效应，不改变长期增长率**。

**5｜`y = 2k − 0.5k²`，s = 0.1，n = 0.05，δ = 0.05：求稳态 k、y 与稳态时的人均储蓄、人均消费。**
- 稳态 `sf(k) = (n+δ)k`：`0.1(2k − 0.5k²) = 0.1k` ⇒ `0.2k − 0.05k² = 0.1k` ⇒ k = 0（舍）或 **k = 2**。
- `y = 2×2 − 0.5×4 = 2`；人均储蓄 `sy = 0.1×2 = 0.2`；人均消费 `(1−s)y = 0.9×2 = 1.8`。

**6｜推导增长率的分解式，并说明它对增长问题的意义。**
- 设 `Y_t = A_t f(L_t, K_t)`，全微分后同除 Y，定义劳动产出弹性 α、资本产出弹性 β，得 `g_Y = g_A + αg_L + βg_K`。
- 意义：产出增长可分解为要素投入贡献与技术贡献；前两项有数据，于是技术进步率可作为**余值**算出：`g_A = g_Y − (αg_L + βg_K)`，这就是**索洛剩余**。

**7｜举例说明经济增长的直接原因和根本原因。**
- 直接原因：总量生产函数 `Y = AF(N, K)` 的三个自变量——**劳动、资本、技术**；规模报酬不变下 `y = f(k)`。
- 根本原因：决定"直接原因为何有差别"的更深层因素——**制度、文化、地理**；制度的作用链条是"制度 → 激励 → 积累要素与采用新技术的程度"。类比：服药治头痛是直接原因，炎症才是根本原因。

**8｜`Y = AK`：求内生增长率与内生增长的条件、初始消费与投资率。**
- `ΔK = sY − δK = sAK − δK`，由 `k = K/(AN)` 得 `g_k = sA − δ − g_A − n`，取 `g_A = 0` 即 `g_k = sA − (n+δ)`。
- 内生增长条件：`sA > n + δ`（资本边际报酬不变，故储蓄率能决定长期增长率，无需外生技术进步）。
- 若令 `g_k = 0`，则投资率 `s = (n+δ)/A`，初始消费 `C(0) = (1−s)k(0)`。

**9｜新古典增长理论如何解释有些国家的增长率高于另一些国家？**
- 设 `y = k^a`（0<a<1），则 `g_k = s k^{a−1} − (n+δ)`：k 越小，`g_k` 越高。
- 三个预言：①储蓄率相同而初始 k 不同 → **穷国增长更快**；②初始 k 相同而投资率不同 → 投资率高者增长更快；③一国提高投资水平 → 收入增长率提高。
- 两种趋同：**绝对趋同**（各国收敛到同一稳态，要求 s、n、δ、g 全同，现实不成立）与**条件趋同**（收敛到各自稳态）。

**10｜用本章的增长理论说明我国提出的创新驱动发展战略。**
- 索洛模型：资本只有**水平效应**，人均产出的持续增长只能来自**技术进步**；但模型把技术当外生，没解释技术从哪来。
- 内生增长理论：技术可在经济体内被创造，具有**非竞争性**且可无限积累；政府资助研发、保护创新可提高长期增长率，故"新古典认为会减速的地方，内生增长理论认为还能继续"。
- 结论：要素驱动不可持续，须转向**创新驱动**，靠科技创新提高全要素生产率。

## 二、考研真题精选（6 题）

**1｜经济增长** 〔广西民族大学2021研〕
- 考点：16.1 增长的含义与度量。
- 骨架：①两层含义：实际总产出的持续增长；人均实际产出的持续增长；②公式 `G_t = (Y_t − Y_{t−1})/Y_{t−1}`、`g_t = (y_t − y_{t−1})/y_{t−1}`；③总量增长率衡量经济实力增速，人均增长率衡量经济效率；④与经济发展的区别（质 vs 量）。

**2｜索洛剩余** 〔南京大学2021研；中国人民大学2019研；对外经济贸易大学2019研〕
- 骨架：①定义：不能为要素投入变化所解释的经济增长率，即剥离资本与劳动贡献后的剩余部分；②公式 `ΔA/A = ΔY/Y − αΔN/N − βΔK/K`；③通常视为**技术进步**对增长的贡献；④评价：反映超长期技术变动，短期含测量误差，故不精确。

**3｜资本的黄金律水平** 〔中央财经大学2013研；山东大学2011研〕
- 骨架：①定义：使**稳态人均消费最大化**的人均资本水平（费尔普斯 1961）；②条件 `f′(k) = n + δ`（有技术时 `MPK = n + g_A + δ`）；③几何：稳态人均消费是 `f(k)` 与 `(n+δ)k` 的垂直距离，最大处 `f(k)` 的切线平行于 `(n+δ)k`；④两性质：资本过多时减少资本可提高消费；资本过少时须先减消费、增储蓄；⑤黄金律最大化**消费**，不是产出。

**4｜内生增长理论** 〔东北财经大学2021研〕
- 骨架：①与新古典的分歧：抽掉资本边际报酬递减（`Y = AK`，MPK = A 不变），让**储蓄率决定长期增长率**；②两条内生化途径：把技术进步率内生化；让可积累要素有固定报酬；③含义：知识非竞争、可无限积累，增长不会因资本深化而必然减速；④政策：研发补贴、教育、产权保护可提高长期增长率。

**5｜"计划生育"的经济意义** 〔东北财经大学2011研〕
- 骨架：①模型：n 下降 ⇒ `(n+δ)k` 变平 ⇒ 稳态 k* 与 y* 上升；②结论一：人口增长率是决定稳态人均资本的**关键因素**，人口增长越慢，人均资本与人均收入越高；③结论二：控制人口能带来**短期增长**，但到达新稳态后增长率仍为零（无技术进步时），故无长期增长效应；④若同时提高储蓄率或技术进步率，效果叠加。

**6｜索洛模型与 AK 模型（内生增长理论）的根本不同** 〔中央财经大学2016研〕
- 骨架：①基本方程与稳态条件（索洛 `Δk = sy − (n+δ)k`；AK `Δk = (sA − δ)k`）；②根本区别：**资本边际报酬递减 vs 不变**——索洛 `f″(k) < 0` ⇒ 收敛到稳态，人均增长归零；AK 的 MPK = A 为常数 ⇒ `sA > δ` 时经济持续增长；③推论：索洛的稳态增长率只由外生技术进步决定，储蓄率只有水平效应；AK 中储蓄率有**增长效应**；④评价：索洛未能解释技术进步来源，且"储蓄率与增长率无关"的经验预言有偏差。

## 四、计算题精解（3 题）

**题 1**（索洛稳态与黄金律，〔中央财经大学2018研；中南财经政法大学2015研〕）`y = 2k − 0.5k²`，s = 0.3，n = 3%，δ = 0。
（1）经济均衡增长的 k；（2）黄金律要求的人均资本；并说明当前储蓄率是否过高。

**解**
① 稳态 `sy = nk`：`0.3(2k − 0.5k²) = 0.03k` ⇒ `0.6k − 0.15k² = 0.03k` ⇒ `0.57k = 0.15k²` ⇒ **k = 3.8**（k = 0 舍）。
② 此时 `y = 2×3.8 − 0.5×14.44 = 0.38`，人均消费 `c = (1−s)y = 0.266`。
③ 黄金律：`f′(k) = 2 − k = n + δ = 0.03` ⇒ **k_gold = 1.97**，`y_gold = 2×1.97 − 0.5×3.88 ≈ 2.0`。
④ `k* = 3.8 > k_gold = 1.97`，资本**过度积累**：黄金律储蓄率仅 `0.03×1.97/2.0 ≈ 3%`。降储蓄可把人均消费从 0.266 提到约 1.94，属**动态无效**。
**答：k* = 3.8；k_gold = 1.97；当前 30% 的储蓄率过高，降储蓄能提高人均消费。**

**题 2**（储蓄率与人口增长的比较静态，〔题库〕）`y = k^{0.5}`。（1）s = 28%，n = 1%，g = 2%，δ = 4%，求稳态产出；（2）s 降到 10%、n 升到 4%，其他不变，求新稳态产出。

**解**
① 稳态 `s f(k) = (δ + n + g)k`：`0.28k^{0.5} = (0.04+0.01+0.02)k = 0.07k` ⇒ `k^{0.5} = 4` ⇒ k = 16，`y = 4`。
② `0.10k^{0.5} = (0.04+0.04+0.02)k = 0.10k` ⇒ `k^{0.5} = 1` ⇒ k = 1，`y = 1`。
③ 人口增长率从 1% 升到 4% 使稳态产出从 4 掉到 1，说明 **n 是"稀释"人均资本的力量**；若把 s 提到 40%，则 `0.4k^{0.5} = 0.1k` ⇒ k = 16、y = 4。
**答：(1) k = 16、y = 4；(2) k = 1、y = 1。**

**题 3**（增长核算，〔中央财经大学2016研〕）`Y = AK^α L^{1−α}`，α = 0.4。2014—2015 年 `ΔK/K = 4%`、`ΔL/L = 2%`、`ΔY/Y = 8%`。求全要素生产率（TFP）的增长率。

**解**
① 增长核算方程：`ΔY/Y = ΔA/A + αΔK/K + (1−α)ΔL/L`。
② 代入：`8% = ΔA/A + 0.4×4% + 0.6×2% = ΔA/A + 1.6% + 1.2%`。
③ ⇒ `ΔA/A = 8% − 2.8% = 5.2%`，即 TFP 增长 5.2%，贡献了总增长的 65%。
**答：TFP 增长率为 5.2%；其余 2.8 个百分点来自资本（1.6）与劳动（1.2）的积累。**

**本章题眼**：索洛模型的计算都从 `sf(k) = (n+δ+g_A)k` 起步；问"储蓄率有没有用"，答案永远是**水平效应**而非增长效应。
