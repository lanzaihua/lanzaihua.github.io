# 第15章 练习与真题 — 宏观经济政策

> 题源：教材课后习题（笔记详解版）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10 题）

**1｜宏观经济政策目标有哪些？如何理解目标之间的一致性与冲突？**
- 四目标：**充分就业**（非自愿失业消除，即 u = u*）、**物价稳定**（总水平稳定，非固定不变）、**经济增长**（人均产出持续增加）、**国际收支平衡**（纠正差额趋衡）。
- 一致性：顺差过大 → 收购外汇 → 货币供给↑ → 物价涨；逆差过大 → 紧缩 → 增长放慢、失业增。
- 冲突两处：**米德冲突**——固定汇率制下汇率工具失效，"逆差＋国内疲软"或"顺差＋国内通胀"时取向左右为难，**实质是工具数 < 目标数**；**物价稳定 vs 充分就业**——降失业须提工资，涨幅超生产率即成本推进型通胀（菲利普斯曲线替代）。

**2｜如何用 IS-LM 模型解释财政政策的效应？**
- 调整链：G↑ → IS 右移（r 不变时收入可达 Y₂）→ Y↑ → 交易性货币需求↑ → 货币过度需求 → **r 由 r₀ 升至 r₁** → I↓ → 新均衡 (Y₁, r₁)，**Y₂ − Y₁ 即被挤掉的部分**。
- 斜率法则：LM 不变时 **IS 越陡**（d 越小）财政效应越大；IS 不变时 **LM 越平**（h 越大、k 越小）效应越大；LM 垂直时财政完全无效、乘数为 0。

**3｜货币政策工具有哪些？如何用 IS-LM 解释货币政策的效应？**
- 三工具（均为间接调控）：**公开市场业务**（最常用、最重要，买进扩张、卖出紧缩）、**法定准备金率**、**再贴现率**；辅助手段：信用控制、道义劝告、窗口指导。
- 方向口诀（最高频易错）：准备金率↑、再贴现率↑、**卖出**国债 ⇒ M↓；三者反向 ⇒ M↑。
- 效应：资产市场先动（M↑ → 买资产 → r↓），产品市场再跟（r↓ → I↑ → Y↑）。斜率法则：IS 不变时 **LM 越陡**（h 越小）效应越大；LM 不变时 **IS 越平**（d 越大）效应越大。
- 两种极端：**流动性陷阱**（LM 水平、h→∞，货币无效、财政完全有效）；**古典情形**（LM 垂直、h=0，货币最有效、财政无效）。

**4｜利用 IS-LM 模型分析 1929—1933 年大萧条的原因。**
- 支出假说：消费与住房投资外生大降、银行倒闭断融资 → IS 左移；银行惜贷、企业惜投、消费者惜购 → IS 继续左移、r 降乃至陷入**流动性陷阱**，产出进一步减少。
- 货币假说：货币收缩使 LM 左移。

**5｜什么是卢卡斯批评？它对宏观经济政策意味着什么？**
- 传统政策评估依赖历史计量模型，未考虑政策变动对**预期**的影响：政策一变，参数随之变（`y = f(x)` 成 `y = g(x)`），旧模型不能预测新后果。
- 意味着：政策问题本质是**对策问题**（政府与理性公众的博弈），不是"控制机器"，最优控制式的政策设计遂失去支持。

**6｜货币供给仅由中央银行决定，还是商业银行、非银行企业与公众也能影响？**
- 三方共同决定：央行定**基础货币** `H = C + R` 并经三工具影响原始存款；商业银行创造**派生存款**；企业与公众经现金-存款比率影响**货币乘数** `k = 1/(r_d + r_e + r_c)`。
- 故 `M = H × k` 不是央行能单独拍板的量——这正是货币政策局限的来源。

**7｜"相机抉择"与"规则"之争的焦点及各自依据是什么？**
- 焦点：政策应当**积极**还是**消极**。
- 相机抉择（凯恩斯）：价格与工资刚性 ⇒ 逆经济风向管理总需求。
- 规则（货币主义、新古典）：依据**动态不一致性**（政府有违约动机且公众能预期到，一旦摇摆就毁掉公信力）与**卢卡斯批评**。
- 四种规则：货币增长目标、名义 GDP 目标、通货膨胀目标、**泰勒规则** `r = 2% + π + 0.5(π − π*) + 0.5(Y − Y*)/Y*`。

**8｜我国在制定与执行宏观经济政策时应如何处理"相机抉择"与"规则"的关系？**
- 宜"规则为体、相机为用"：规则行事使央行受事先承诺约束，可引导预期、解决时间不一致；同时保留逆周期与跨周期调节的灵活性。
- 逐步探索符合中国实际的**泰勒型利率规则**，提高利率操作有效性；与宏观审慎政策配合，稳增长与防风险平衡。

**9｜中国近期实际采用的供给政策有哪些？用 AD-AS 模型分析其效果。**
- 政策要点：政府转变职能退出市场；减税让企业有活力；稳定宏观政策形成长期预期；对外开放倒逼改革；要素市场化；收入与财富体系改革启动家庭消费。
- AD-AS：减税 → 可支配收入↑ → 消费与投资↑ → **AD 右移** → 均衡价格↑、产出↑；若同时降低企业成本，还可推动 **AS 右移**，兼顾增长与稳物价。

**10｜如何认识西方宏观经济政策主张的局限性？**
- 稳定目标难实现：时滞、政治干扰、预测有限，政策可能反而加剧波动。
- 预算之争未决：传统观点认为赤字挤出储蓄与投资、给后代留债务；李嘉图等价认为公债只是延期的税收。
- 更根本：政策只在短期缓解危机，不能消除基本矛盾，故不能根除高失业。

## 二、考研真题精选（6 题）

**1｜挤出效应** 〔湖南大学2022研；中国人民大学2021研；厦门大学2017研〕
- 考点：15.3 财政政策效应。
- 骨架：①定义：政府支出增加引起的私人消费或投资减少；②机理：G↑ → Y↑ → 货币交易需求↑ → r↑ → I↓；③四因素：支出乘数、k、h（越小挤出越大）、d（越大挤出越大）；④决定因素 h 与 d；⑤流动性陷阱挤出为零，古典情形完全挤出。

**2｜自动稳定器** 〔中国海洋大学2022研；厦门大学2014研〕
- 骨架：①定义：经济系统本身存在、减少干扰对国民收入冲击的机制，繁荣时自动抑制通胀、衰退时自动减轻萧条，**无须政府行动**；②三项：失业保障、农产品价格维持制度、累进所得税；③力度：边际税率越高波动越小（见计算题 2）；④局限：只缓和、不改总趋势；地方受平衡预算约束会顺周期。

**3｜充分就业预算盈余** 〔对外经济贸易大学2015研；南京财经大学2014研〕
- 骨架：①定义：把产出固定在潜在水平上算出的预算盈余；②为何用它：私人投资增加会抬高产出与税收、使实际盈余增加，而政府未动政策，故实际盈余难判方向；③判读：该盈余增加（赤字减少）⇒ 紧缩，反之扩张；④缺陷：潜在产出难估算。

**4｜货币政策的局限性** 〔杭州电子科技大学2021研〕
- 骨架：①效果短期性：紧缩反通胀较显著，衰退期扩张不明显，流动性陷阱下松银根也不降利率；且只对**需求拉动型**通胀有效；②时滞：内部时滞短、**外部时滞长**（r→I→就业→收入）；③货币流通速度变动可能使正确的政策走向反面；④资金国际流动：紧缩抬高 r 吸引外资——浮动下本币升值抑出口、固定下央行投放本币收外币，都削弱效果。

**5｜弥补赤字的途径与李嘉图等价** 〔东北财经大学2013研〕
- 骨架：①赤字＝支出大于收入之差；弥补靠借债或出售政府资产；②举债两途：向央行借（货币筹资→基础货币增→乘数放大→通胀）、向公众与外国借（债务筹资，不直增基础货币，但利率上升后若央行维稳利率买入债券，仍可致通胀）；③国民看来不同：增税强制无偿、直接减可支配收入；买国债是投资理财、到期还本付息；④李嘉图等价：消费者理性前瞻、关心后代 ⇒ 减税所得被储蓄以备将来纳税，私人储蓄抵消公共储蓄，国民储蓄不变；⑤反对：30 年期债券把财富从下一代转移给当代，故仍刺激消费。

**6｜泰勒规则** 〔中国海洋大学2021研；中国人民大学2019研〕
- 骨架：①定义：泰勒 1993 年据美国经验提出的短期利率调整准则；②公式（同上）；③含义：通胀超目标或产出超潜在即上调名义利率，2% 为自然利率；④作用：预承诺机制，解决时间不一致、稳定预期。

## 四、计算题精解（2 题）

**题 1**（IS-LM 乘数与充分就业，〔题库〕）`C = 600 + 0.8Y`，`I = 400 − 50r`，G = 200，`L = 250 + 0.5Y − 125r`，M = 1250，P = 1。
（1）财政政策乘数与货币政策乘数；（2）Y* = 5000 时用增加政府购买实现充分就业需增多少？（3）改用增加货币供给呢？挤出效应多大？

**解**
① IS：`Y = 600 + 0.8Y + 400 − 50r + 200` ⇒ `Y = 6000 − 250r`；LM：`250 + 0.5Y − 125r = 1250` ⇒ `Y = 2000 + 250r`。联立：r = 8，Y = 4000。
② 财政乘数：`dY/dG = 1/[(1−β) + dk/h] = 1/(0.2 + 50×0.5/125) = 2.5`；货币乘数：`dY/dM = d/[h(1−β) + dk] = 50/(25 + 25) = 1`。
③ Y* = 5000 时 LM 给 r = 12；代入 IS：`5000 = 600 + 4000 + 400 − 600 + G` ⇒ G = 600，**ΔG = 400**。
④ 挤出：利率不变时乘数 5 可使收入增 2000，实际只增 1000 ⇒ **挤出 1000**（r 由 8 升到 12）。
⑤ 货币途径：Y* = 5000 时由 IS 得 r = 4；代入 LM：`M = 250 + 2500 − 500 = 2250` ⇒ **ΔM = 1000**。
**答：财政乘数 2.5、货币乘数 1；ΔG = 400；ΔM = 1000；挤出效应 1000。**

**题 2**（自动稳定器力度，〔题库例题改编〕）边际消费倾向 β = 0.8，比例所得税率 t。求 t = 0.1 与 t = 0.25 时 1 美元自发投资引起的总需求增量，并说明税率的稳定作用。

**解**
① 含所得税的乘数：`k = 1/[1 − β(1 − t)]`。
② t = 0.1：`k = 1/(1 − 0.8×0.9) = 1/0.28 ≈ 3.57`。
③ t = 0.25：`k = 1/(1 − 0.8×0.75) = 1/0.4 = 2.5`。
④ 税率提高使乘数变小，同样冲击带来的波动更小 ⇒ **较高边际税率本身就是稳定器**。
**答：t = 0.1 时增 3.57 美元；t = 0.25 时增 2.50 美元；边际税率越高，自动稳定作用越强。**
