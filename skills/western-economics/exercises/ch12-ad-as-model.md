# 第12章 练习与真题 — 国民收入的决定：AD-AS 模型

> 题源：教材课后习题（笔记详解）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10）

**1｜什么是总需求曲线的利率效应？**
- `P↑→` 货币名义需求↑（同交易量要更多现金）→ M 既定、`r↑→I↓→` 总支出与 Y↓。
- 一句话：**P 与 r 同向，r 与 I、Y 反向**。教材直觉：P=1.0 时社会需 1000 亿交易货币，P=1.2 时需 1200 亿。

**2｜什么是实际余额效应（财富效应）？**
- `P↑→` 手持货币与以货币计价的资产实际购买力↓ → 相对变穷 → 消费↓ → 总需求↓。
- 另有一条独立的**税档渠道**：`P↑→` 名义收入↑ → 进入更高税率档 → 税负↑ → 可支配收入↓ → 消费↓。它走财政口径，别与购买力混成一条。

**3｜在 AD-AS 模型中以价格变动代表供给冲击具有合理性吗？**
- 部分合理：AS 的位置取决于供给面（成本、技术、劳动市场），价格刚性／黏性／弹性分别对应三条形状不同的 AS；把供给冲击折算成 AS 移动、再读价格变动，是模型的标准用法。
- 但严格说价格是**结果**不是冲击源——冲击的源是成本与技术，价格是均衡的表现。两句都写上才完整。

**4｜价格水平变动从哪些方面影响总需求量？**
- 三条：①**利率效应**（投资）；②**实际余额效应＋税档渠道**（消费）；③**汇率效应**（净出口：`P↑→` 本国产品相对变贵 → 出口↓进口↑；同向第二渠道是本国生产成本↑→到外国投资更合算→国内投资↓）。
- 简答／选择的标准答法是**三条都写**；只写利率效应不完整。

**5｜引起总需求曲线、总供给曲线移动的因素各是什么？**
- AD 移动的总原则：**P 不变时**，IS-LM 中收入的变动 → AD 平移。右移：C₀、I₀、G、出口、名义 M 增加；左移：T、税率、进口、实际货币需求自发增加。
- AS 移动：技术进步（短期与长期 AS **都右移**）、劳动需求↑（资本存量↑→边际劳动生产率↑）、劳动供给↑、扩张性供给政策 → 右移；反向 → 左移。统一说法：凡引起生产函数或劳动市场变化的**供给冲击**。

**6｜教材算例：`C=600+0.8Y`，`I=400−50r`，G=200，`L=250+0.5Y−125r`，M=1250，P=1。求 IS、LM、均衡；充分就业 5000 需增多少货币；P 可变时的 AD；若 AS 为 `Y=2375+125P` 求均衡。**
- ①IS：`Y=600+0.8Y+400−50r+200` → `r=24−0.004Y`；LM：`250+0.5Y−125r=1250` → `r=0.004Y−8`。
- ②`24−0.004Y=0.004Y−8` → **Y=4000、r=8**。
- ③充分就业 5000 代入 IS 得 r=4；此时 `L=250+0.5×5000−125×4=2250`，故货币供给需 2250，**ΔM=1000**。
- ④P 可变：LM 为 `r=0.004Y−10/P+2`，与 IS 联立 → **AD：`Y=2750+1250/P`**。
- ⑤`2375+125P=2750+1250/P` → `125P²−375P−1250=0` → `P²−3P−10=0` → **P=5**（−2 舍）、**Y=3000**。
- 易错：④中 `1250/P` 是名义货币供给，别当成实际货币供给。

**7｜教材算例：`C=800+0.8Y_d`，T=0.25Y，`I=200−50r`，G=200，`L=0.4Y−100r`，M=900，AS：`Y=2350+400P`，充分就业收入 2850。求 AD、判断是否充分就业、给出政策。**
- ①IS：`Y=800+0.8(0.75Y)+200−50r+200` → `Y=3000−125r`；LM：`0.4Y−100r=900/P` → `Y=2250/P+250r`；消 r → **AD：`Y=2000+750/P`**。
- ②与 AS 联立：`2000+750/P=2350+400P` → `8P²+7P−15=0` → **P=1、Y=2750<2850**，**未实现充分就业**。
- ③政策：要 `Y=2850`，由 AS 得 `P=1.25`。财政路：LM（P=1.25）为 `Y=1800+250r` → `r=4.2`；IS 族 `Y=2500−125r+2.5G` → `2.5ΔG=375` → **ΔG=150**。货币路：IS 仍 `Y=3000−125r` → `r=1.2`；LM 给 `M/1.25=1020` → **ΔM=375**。
- 结论：财政扩张抬 r、挤出投资；货币扩张压 r。两条路都能到 `Y_f`，力度不同。

**8｜简单凯恩斯模型、IS-LM 模型、AD-AS 模型之间的内在联系。**
- 简单凯恩斯：P 与 r 都固定、只有产品市场，用乘数讲财政政策 → 纯**总需求**分析。
- IS-LM：P 固定、r 内生化，加入货币市场 → 仍是总需求分析，但多了挤出与货币政策。
- AD-AS：放开 P，加入劳动市场与总量生产函数 → 同时决定 Y 与 P，能讲价格效应与滞胀。
- 一句话升级链：**加市场、放价格、引入供给面**。

**9｜AS 曲线三个区域的含义；用 AD-AS 解释 1970 年代滞胀与 1990 年代新经济。**
- 三区域（自左向右）：**水平**（凯恩斯区域，价格刚性、只有数量调节）→ **右上倾斜**（中间区域，数量与价格调节并存）→ **垂直**（古典区域，只有价格调节）。
- **滞胀**：负向供给冲击（石油危机）使 AS **左移**，AD 不变 → P↑、Y↓，通胀与停滞并存。
- **新经济**：信息技术等正向供给冲击使 AS **右移** → 高增长、低通胀、低失业并存。
- 易错：滞胀的源头是 **AS 左移**，不是"需求不足使 AD 左移"。

**10｜利率上升如何经 AD-AS 影响物价？（中国情景）**
- 三条传导：①`r↑→I↓→` 总需求左移，压物价；②`r↑→` 储蓄↑消费↓ → 左移，压物价；③顺差巨大时 `r↑→` 外资流入 → 货币供给增 → 右移，推物价。
- 答法：先列三条，再判断——中国顺差大、内需不足，净效应未必压低物价。

## 二、考研真题精选（7 题）

**1｜总需求曲线**〔深圳大学2019研〕
- 骨架：①定义（产品市场与货币市场同时均衡时 P 与 Y 的关系）；②构成（C＋I＋G＋NX）；③右下倾斜的三效应；④区分：P 变是**沿 AD 移动**，其他因素变才**平移**。

**2｜凯恩斯主义的总供给曲线**〔西北大学2017研〕
- 骨架：①两假设（货币工资刚性、只升不降；货币幻觉）；②形状：倾斜段＋垂直段（教材近似为反 L 形：水平段＋垂直段）；③推导逻辑（P>P₀ 时 W 被抬高、W/P 复原→Y 不变；P<P₀ 时 W 降不下来→N↓→Y↓）；④政策含义：Y<Y_f 时扩张需求能增产量而价格基本不动。

**3｜滞胀**〔中南财经政法大学2019研〕
- 骨架：①定义（生产停滞＋失业增加＋物价居高并存）；②成因：负向供给冲击使短期 AS 左移；③图形语言（AD 不动、AS 左移 → 均衡点沿 AD 左上移，P↑、Y↓）；④与菲利普斯曲线的冲突（通胀与失业同升）。

**4｜作图推导 AD 并解释其向右下方倾斜**〔厦门大学2019研；南开大学2018研；四川大学2018研〕
- 骨架：①上栏 IS-LM、下栏 P-Y；②取 P₁ → `LM(P₁)` 交 IS 于 E₁ → 得 `(Y₁,r₁)` → 下栏标 D₁；③取更高的 P₂ → **LM 左移**（`M/P` 变小）→ E₂ → `Y₂<Y₁`、`r₂>r₁` → 标 D₂；④连点成 AD；⑤右下倾斜解释三效应（财富、利率、汇率）。
- 易错：**P 变不动 IS**（IS 中变量按实际量定义），只动 LM。

**5｜总供给曲线的类型及说明**〔中南财经政法大学2017、2011研〕
- 骨架：①古典（W、P 完全伸缩、劳动市场出清 → 垂直，位于潜在产量）；②凯恩斯（工资刚性＋货币幻觉 → 水平／反 L 形）；③常规（黏性、调整缓慢 → 右上倾斜）；④统一解释：三者只差"W 能否、多快随 P 调整"。

**6｜微观供求模型与 AD-AS 模型的比较**〔武汉大学2019研；中南财经政法大学2016研〕
- 骨架：①同：都是两条曲线（D 右下、S 右上）决定价格与数量；②异：对象（单个商品 vs 总量）、理论基础（消费者行为＋成本与市场理论 vs IS-LM＋劳动市场＋总量生产函数）、功能（局部解释 vs 解释波动与政策）。

**7｜1960 年代美国：战争支出＋"向贫困开战"却不加税，用 AD-AS 推断后果**〔东北财经大学2010研〕
- 骨架：①G↑ 而 T 不变 → AD 右移；②起点接近潜在产出 → 沿 AS 上移，**价格涨得多、产量增得少**，经济过热；③1960 年代末高通胀；④70 年代石油危机 → AS 左移 → **滞胀**。

## 四、计算题精解（3 题）

**题 1** `C=100+0.8Y`，`I=150−6r`，`L=0.2Y−4r`，M=150。求 AD；P=1 时的 (Y,r)；若 AS 为 `Y=800+150P`，求均衡。〔浙江财经大学2021研〕

**解** ①IS：`Y=100+0.8Y+150−6r` → `Y=1250−30r`；LM：`0.2Y−4r=150/P` → `Y=750/P+20r`。
②由 LM 得 `r=0.05Y−37.5/P`，代入 IS：`Y=1250−30(0.05Y−37.5/P)` → `2.5Y=1250+1125/P` → **AD：`Y=500+450/P`**。
③P=1：`Y=750+20r` 与 IS 联立 → **r=10、Y=950**。
④与 AS 联立：`500+450/P=800+150P` → `150P²+300P−450=0` → `P²+2P−3=0` → **P=1**（−3 舍）、**Y=950**。
**答：AD 为 `Y=500+450/P`；P=1 时 r=10、Y=950；均衡 P=1、Y=950。**

**题 2** `C=500+0.75(Y−T)`，`I=1000−500r`，`L=Y−200r`，G=1000，T=1000，M=6000，P=2。〔武汉大学2019研〕
(1) IS、LM 与均衡；(2) 减税 15% 且央行保持利率不变，求新 Y 与新 M；(3) 税收与 M 不变时的 AD。

**解** ①IS：`Y=500+0.75(Y−1000)+1000−500r+1000` → **`Y=7000−2000r`**；LM：`6000/2=Y−200r` → **`Y=3000+200r`**。
②联立：`2200r=4000` → **`r=20/11`**、**`Y=37000/11≈3363.6`**。
③`T'=850`：IS → **`Y=7450−2000r`**；r 不变则 `Y'=7450−2000×20/11=`**41950/11≈3813.6**；新 `M=2(Y'−200r)=`**6900**。
④P 可变：由 `Y=7000−2000r` 与 `6000/P=Y−200r` 消 r → **AD：`Y=(7000P+60000)/(11P)`**。
**答：r=20/11、Y=37000/11；减税后 Y=41950/11、M=6900；AD 见④。**

**题 3** 总供给为 `Y_s=500`，总需求为 `Y_d=600−50P`；若总需求上升 10%，求新旧均衡。〔题库〕

**解** ①`500=600−50P` → **P=2、Y=500**。
②AD 上升 10% → `Y_d=660−50P`；`500=660−50P` → **P=3.2、Y=500**。
**答：产量不变，价格由 2 升到 3.2**——垂直 AS 下需求扩张只体现为价格，即古典情形的"只有价格调节"。

**本章题眼**：AD-AS 题一律两步走——**先由 IS-LM 消 r 得 `Y=f(P)`（AD），再与 AS 联立解 `(Y,P)`**；判断政策／冲击效果只看一件事：移动的是 AD 还是 AS，以及交点落在 AS 的哪一段（水平=只动产量、垂直=只动价格）。
