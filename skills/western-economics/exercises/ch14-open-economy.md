# 第14章 练习与真题 — 开放条件下的宏观经济

> 题源：教材课后习题（笔记详解版）· 考研真题（笔记详解＋配套题库）· 题库章节自测

## 一、教材课后习题（10 题）

**1｜什么是名义汇率与实际汇率？两者关系如何表示？**
- 名义汇率 e：两国货币的相对价格，即一种货币兑换另一种货币的数量。两种标价法必须分清：**直接标价法**（1 单位外币折合多少本币，e↑ 为贬值）、**间接标价法**（1 单位本币折合多少外币，e↑ 为升值）；教材正文用间接标价法。
- 实际汇率 ε：用两国物价调整后的汇率，`ε = e·P/P_f`，衡量本国商品的相对价格，又称**贸易条件**；购买力平价成立（eP = P_f）时 ε = 1。
- 变动率关系：`e% = ε% + P_f% − P%`；ε↑ 意味着本国商品相对**昂贵**、净出口减少。

**2｜用蒙代尔-弗莱明模型说明扩张性财政政策与货币政策的影响。**
- **固定汇率**：财政**有效**——IS* 右移 → 本币面临升值压力 → 央行买外汇、放本币 → LM* 被动右移，Y↑（财政效果被货币扩张强化）；货币**无效**——M↑ → LM* 右移 → 贬值压力 → 央行抛外汇、收本币 → LM* 原路退回，Y 不变（**短期也不变**）。
- **浮动汇率**：财政**无效**——IS* 右移 → 升值 → NX↓，需求扩张被完全抵消（**国际挤出**）；货币**有效**——LM* 右移 → 贬值 → NX↑ → Y↑。
- 抓手：**LM* 垂直**，谁动 LM*（货币政策），谁就在固定汇率下失效。

**3｜关税或非关税壁垒对国民收入有什么影响？**
- 固定汇率：限制进口 → NX↑ → IS* 右移 → 升值压力 → 央行扩张货币 → **产出增加**，增量来自净出口。
- 浮动汇率：IS* 右移 → 本币升值 → NX 被压回 → **产出不变**。故贸易保护只在固定汇率下能增加产出。

**4｜蒙代尔-弗莱明模型是需求理论，还是也包含供给理论？**
- 兼有。它假定短期价格不变、产出由总需求决定（需求面），但实现了**产品、货币、外汇三个市场同时均衡**，已把货币供给与外汇市场供求写进模型；放开价格假设即得向右下倾斜的开放经济 AD 曲线，故不是单纯的需求分析。

**5｜封闭经济与开放经济的 IS-LM 模型有什么联系与区别？**
- 联系：开放模型以封闭模型的产品市场、货币市场均衡为前提，再加**外汇市场均衡**（IS-LM-BP）。
- 区别：①多了汇率 e 与净出口 NX，BP 斜率 `γ/σ` 反映资本流动性；②利率被世界利率钉住（`r = r_w`）；③政策效果随汇率制度**恰好对调**。

**6｜什么是不可能的三位一体？它的理论依据是什么？**
- **资本完全流动、固定汇率、独立货币政策**三者最多取二。理论依据就是 MF 模型的极端情形：资本完全流动的小型开放经济中，固定汇率下货币政策完全失效（LM* 被央行推回），浮动汇率下财政政策完全失效（IS* 被升值推回）。

**7｜有没有国家或地区同时实现这三个目标？举十个左右讨论。**
- 没有，都是"弃一保二"。①保独立货币政策＋资本流动、弃汇率稳定：美、英、日、加（浮动汇率）；②保独立货币政策＋汇率稳定、弃资本流动：朝鲜、古巴（资本管制）；③保资本流动＋汇率稳定、弃货币政策：德、法、意、荷（欧元区）。

**8｜国际经济联系包括哪些方面？理论上如何分析？**
- 商品与服务贸易：出口、进口，差额为**净出口**，是外汇储备的来源；资本流动：流入、流出，差额为**资本净流出**。
- 二者记入国际收支平衡表：**经常账户＋资本与金融账户＋平衡账户**；表形式恒平衡，"顺差/逆差"指自主性交易的差额 NX − F。

**9｜什么是国际收支平衡曲线（BP 曲线）？**
- 使 `NX = F` 成立的 (Y, r) 组合轨迹，即 `BP = NX − F = 0`。
- 斜率 `γ/σ > 0`，向右上倾斜：Y↑ → 进口↑ → NX↓ → 须提高 r 以减少资本外流。σ→∞ 时为水平线（`r = r_w`），σ = 0 时为垂直线，越平坦表示资本流动性越强；曲线左上方为顺差、右下方为逆差。

**10｜如何用马克思的国际价值理论认识经济全球化的新特征？**
- 商品越出国境进入世界市场，国别价值转化为**国际价值**，其尺度是"世界劳动平均单位"，而非一国社会必要劳动时间。
- 国际价值与国内价值的差异是贸易商的利润源泉与贸易动力，是各国调整产业结构、进出口结构的"无形之手"；全球化越充分，国际价值规律作用越充分。
- 结论：只有建立在劳动价值论上的开放经济理论才能揭示国际经济的**本质关系**，汇率、收支只是现象层面。

## 二、考研真题精选（6 题）

**1｜浮动汇率制** 〔广东财经大学2021研；中央财经大学2016研〕
- 考点：14.1 汇率制度。
- 骨架：①定义：不规定官方汇率，听任外汇市场供求自发决定；分自由浮动与管理浮动；②两个推论：国际收支可自动调节；**货币供给成为外生变量**（央行不再为守住汇率被动投放/回笼货币）；③政策含义：政策目标转向内部均衡（充分就业、物价稳定）。

**2｜实际汇率** 〔东北财经大学2017研；武汉大学2014研〕
- 骨架：①定义：两国产品的相对价格，反映本国商品在国际市场的竞争力，`ε = e·P/P_f`（间接标价法）；②ε = 1 ⇔ 购买力平价成立；③ε↑ ⇒ 本国商品相对昂贵 ⇒ 净出口减少。
- 易错：**先声明标价法**。直接标价法下 ε = e·P_f/P，符号与结论全部翻转；题库把"ε 高＝本国产品便宜"与"ε 高＝本国产品昂贵"两种口径混用过，答题时以教材式(14.1)为准。

**3｜经常账户** 〔中山大学2019研〕
- 骨架：①定义：实质资源流动的记录，含**货物和服务、收入、经常转移**三类；②与资本账户通过平衡项联系，构成国际收支平衡表；③顺差/逆差指自主性交易差额，平衡表本身恒平衡。

**4｜马歇尔-勒纳条件** 〔南京财经大学2009研〕
- 骨架：①进出口供给弹性趋于无穷大时，只有 `|η_x| + |η_m| > 1`，贬值才改善贸易收支；②机制：贬值使出口变便宜、进口变贵，但数量调整须足够大才能抵消价格效应；③局限：充分就业下"供给弹性无穷大"不成立，且短期弹性小，故有 J 曲线。

**5｜J 曲线** 〔中南财经政法大学2021研〕
- 骨架：①贬值后贸易收支**先恶化、后改善**，轨迹似字母 J；②三阶段：货币合同阶段（价量均不变，结果取决于合同计价货币）→ 传导阶段（价格变、数量未变）→ 数量调整阶段（数量变化远大于价格）；③成因：短期 `|η_x| + |η_m| < 1`，中长期 > 1。

**6｜资本完全流动的含义与小国/大国模型的差别** 〔东北财经大学2013研〕
- 骨架：①含义：居民可完全进入世界金融市场，政府不阻止国际借贷，想借/贷多少都可以；②小国：对世界利率无影响 ⇒ `r = r_w`，资本流动使国内利率迅速回归世界水平；③大国：足以影响世界利率，r 不由 r_w 外生给定——对外贷款越多，世界利率越低；④应用：MF 模型的"小国"假设就等价于 `r = r_w`。

## 四、计算题精解（2 题）

**题 1**（蒙代尔-弗莱明模型，〔中央财经大学2016研〕）小型开放经济：`IS: Y = 1000 + G − T + NX − 50r`，`LM: Y = M/P + 100r`，`NX = 2500 − 100e`；M = 2000，P = 1，世界利率 `r_w = 10`，G = 1000，T = 800。
（1）均衡收入与汇率；（2）浮动汇率下 T 降至 500 时；（3）固定汇率（钉在(1)的 e）且 T = 500 时，新收入与央行应设定的 M。

**解**
① r = r_w = 10。LM：`Y = 2000 + 1000 = 3000`。
IS：`Y = 1000 + 1000 − 800 + (2500 − 100e) − 500 = 3200 − 100e`；令 3000 = 3200 − 100e ⇒ `e = 2`。
② T = 500：IS 变为 `Y = 3500 − 100e`，LM 仍 3000 ⇒ `e = 5`，**Y 仍为 3000**（浮动汇率下财政政策无效，只推动汇率）。
③ 固定 e = 2：IS 给出 `Y = 3500 − 200 = 3300`；代入 LM：`3300 = M + 1000` ⇒ `M = 2300`。
**答：(1) Y = 3000、e = 2；(2) Y = 3000、e = 5（升值）；(3) Y = 3300，央行须把 M 从 2000 增至 2300（增 300），即被动扩张货币以守住汇率。**

**题 2**（储蓄—投资—贸易差额，〔题库〕）`Y = C + I + G + NX`，Y = 5000，G = 1000，T = 1000，`C = 250 + 0.75(Y − T)`，`I = 1000 − 50r`，`NX = 500 − 500ε`，`r = r^* = 5`。
（1）求国民储蓄、投资、贸易差额与均衡实际汇率；（2）G 增至 1250 时；（3）r* 升至 10% 时。

**解**
① `C = 250 + 0.75 × 4000 = 3250`，`S = Y − C − G = 5000 − 3250 − 1000 = 750`；`I = 1000 − 50×5 = 750`；`NX = S − I = 0` ⇒ `500 − 500ε = 0` ⇒ ε = 1。
② G = 1250：S = 500，I 仍 750（r 固定），`NX = 500 − 750 = −250` ⇒ ε = 1.5。**财政扩张挤出净出口：储蓄下降、投资不变，缺口靠资本流入弥补，本币实际升值。**
③ r* = 10：S = 750，`I = 1000 − 500 = 500`，`NX = 250` ⇒ ε = 0.5。**世界利率上升压低投资，储蓄相对过剩 → 资本流出 → 实际贬值。**
**答：(1) 750、750、0、ε=1；(2) 500、750、−250、ε=1.5；(3) 750、500、250、ε=0.5。**

**本章题眼**：任何"这个政策在开放经济下有没有用"的题，先定**汇率制度**，再看它动的是 IS*（财政、贸易）还是 LM*（货币）——动 IS* 的在浮动下失效，动 LM* 的在固定下失效。
