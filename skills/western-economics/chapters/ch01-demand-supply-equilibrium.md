# 第1章 需求、供给和均衡价格 (Demand, Supply, and Equilibrium Price)

> 马工程《西方经济学》(第二版) · 上册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

价格不是谁定的，是两类相反意愿碰出来的：消费者按需求规律在高价时少买，生产者按供给规律在高价时多供，数量相等的那一刻就是均衡。本章把价格机制拆成三件可算的东西——两个行为方程（需求、供给）、一个均衡条件（Qd=Qs），以及一个把"方向"升级成"程度"的度量（弹性）。弹性是全章重心：它决定税负落在谁身上、降价能否增收、丰收为什么反而减收。

考点权重（笔记详解标注）：需求 ★★★、供给 ★★★、市场均衡 ★★★、**弹性 ★★★★★**、**供求分析的应用 ★★★★★**。

## Frameworks Introduced / 核心框架

### 一、需求（★★★）

**需求（demand）**：其他条件不变、某一特定时期内，消费者在各种可能价格下**愿意并且能够**购买的数量。两个要件缺一不可：购买意愿 + 支付能力。它是对一系列价格制定的"计划"，不是某一次购买行为。

- **需求函数**（式1.1、式1.2）：Qd = D(P)；线性特例 **Qd = α − βP**（α, β > 0）。
  - 何时用：一切"给函数求均衡/求弹性"的题。
  - 关键点：β 是价格每升 1 单位需求量按固定比率减少的比例，故 β > 0 就是需求曲线下倾的代数写法。α 为横轴截距，纵轴截距为 α/β。
- **需求规律（law of demand）**：其他条件不变，需求量与自身价格反向变动；成立则曲线右下倾斜。
  - 机理：替代效应（相对变贵，转向他品）+ 收入效应（价格上升使实际收入变少）。
  - **三个特例**（教材图1-2 并排画三条线）：①垂直线——价格再高需求量也不变（食盐、观景台）；②水平线——价格略高需求即零、略低则需求无穷大；③向右上倾斜——价格越高买得越多，如炫耀性商品，以及 1845 年爱尔兰灾荒中价格上升而需求反增的土豆（**吉芬物品 / 吉芬难题**）。前两者是"极限状态"，第三者才是反例，但教材仍把右下倾斜视为"基本规律"：经济规律只是倾向性陈述（马歇尔"潮汐规律"之喻）。
- **需求量的变动 vs 需求的变动**（教材图1-3：同一曲线上点的移动 vs 整条曲线平移）
  - 需求量变动：**自身价格**变 → 沿同一条曲线移动。
  - 需求变动：**价格以外**因素（收入、偏好、相关品价格、预期、政策）变 → 整条曲线移动；右移为需求增加，左移为需求减少。
- **市场需求 = 个人需求的横向加总**（式1.5）：Qd = ΣDi(P)。要**横向**加（同一价格下加数量），并处理折点：某消费者在高于其保留价格时需求为零，市场曲线在该价格处出现拐点，函数必须**分段写**。计算题第一大失分点。
- 影响因素六条：自身价格、收入（正常品 / 低档品）、相关品价格（替代品 / 互补品）、偏好、预期、政策。正常品与低档品不是商品的固有属性，随消费者与收入水平而变（粗粮即例）。

### 二、供给（★★★）

**供给（supply）**：其他条件不变、特定时期内，生产者在各种可能价格下愿意并且能够出售的数量（供给意愿 + 供给能力）。

- **供给函数**（式1.6、式1.7）：Qs = S(P)；线性特例 **Qs = γ + δP**（δ > 0）。γ 可为负（价格太低就不供给），δ > 0 保证右上倾斜。
- **供给规律**：价格与供给量同向变动；成立则曲线右上倾斜。直观：价格上升 → 扩产更有利可图 → 增雇劳动、增加中间投入、更新设备。两个特例：①垂直线（数量固定：土地、观景台）；②水平线（某一价格下愿供任意数量：产能既定且单位成本稳定的厂商）。
- **供给量的变动 vs 供给的变动**（教材图1-7）：自身价格 → 沿曲线；技术、成本与要素价格、相关品价格、目标、预期、政策 → 曲线移动。**右下方移动 = 供给增加，左上方 = 供给减少**；供给的"上下"语言与需求相反，最易写反。
- **市场供给 = 单个供给的横向加总**（式1.10）。

### 三、市场均衡（★★★）

- **均衡（equilibrium）**：经济力量相互制约下达到的相对静止状态。**局部均衡**（单个市场）vs **一般均衡**（全部市场）。
- **均衡价格与均衡数量**（教材图1-9：右上的 S 与右下的 D 交于 E，E 的纵坐标为 PE、横坐标为 QE）
  - 机制不是命令而是纠错：P > PE → 超额供给 → 卖者降价 → P↓，同时 Qd↑、Qs↓，直至 Qd=Qs；P < PE → 超额需求 → 买者抬价 → P↑，直至相等。这条"超额供给/超额需求推动价格反向运动"的链条就是**市场机制的自发调节**。
  - 两个易漏限定：均衡数量只表示双方**意愿**交易量相等，不等于实际成交量（后者恒等于 min(Qd, Qs)）；均衡实现还需信息充分、交易无摩擦、无囤积。
- **供求定理**（教材表1-4）：单边变动方向确定；双边同时变动时，**价格或数量必有一个"不确定"**，取决于两边变动幅度。
- **经济模型的结构**（式1.11–式1.15）：需求、供给函数是**行为方程**，"市场需求 = 个人需求之和"是**定义式**，"Qd = Qs"是**均衡条件**。解得 PE = (α+γ+ηm)/(β+δ)，比较静态 ∂PE/∂m = η/(β+δ) > 0。问"静态分析与比较静态分析的区别"时，把三类方程摆出来即可。
- **蛛网模型（cobweb model）**（式1.16–式1.19）：供给有时滞 Qt^s = −γ + δP(t−1)，需求无时滞 Qt^d = α − βPt；递推式 Pt = (α+γ)/β − (δ/β)P(t−1)，令 λ = −δ/β。
  - **收敛 ⟺ δ < β ⟺ 需求的价格反应 |dQd/dP| 大于供给的 dQs/dP ⟺ 均衡点上 Ed > Es**；**发散 ⟺ δ > β ⟺ Ed < Es**；**封闭 ⟺ δ = β**（等幅振荡，轨迹走成封闭矩形）。
  - 几何读法：收敛型的图里需求曲线比供给曲线平坦（价格小变→需求量大变），故波动逐期收窄。判据请用 δ 与 β 的**代数比较**，别用"谁陡谁缓"——教材与笔记在这一点上的措辞互相打架，代数是唯一可靠口径。
  - 缺陷：假定供给只由上一期价格决定，忽略了生产者对预期的修正。

### 四、弹性（★★★★★）

**弹性一般定义**：e = (Δy/y)/(Δx/x) = (Δy/Δx)·(x/y)。纯量、与计量单位无关，内含"局部"含义（x 变动幅度不宜过大）。为什么不用 ΔQ/ΔP：带单位（彩电"台"与西装"件"没法比），且不反映初始价格（4→5 元的西瓜与 9→10 元的不可比）。

- **需求价格弹性**（式1.20）：**Ed = −(ΔQ/Q)/(ΔP/P)**。
  - **负号是定义的一部分**，用来把系数掰成非负：本章约定 0 ≤ Ed ≤ +∞。算出负数却不取绝对值，等于把"缺乏弹性"说成"负弹性"。
  - 五种类型（教材图1-17 并排画五条曲线，判据与总收益见速查表 A）：Ed=0 完全无弹性（垂直线）；0<Ed<1 缺乏弹性；Ed=1 单位弹性；1<Ed<∞ 富有弹性；Ed=∞ 完全弹性（水平线：提价则一件不买，降价则需求无限）。
  - 影响因素：①重要程度（必需品小、奢侈品大，食盐近于 0）；②可替代程度（替代品越多越大——"食品整体缺乏弹性，某品牌面包却未必"）；③支出占比（占比越大越大）；④调整时间（越长越大）。
- **弧弹性**（式1.21）：Ed = −[(Q2−Q1)/(Q2+Q1)] / [(P2−P1)/(P2+P1)]，即**中点**基期。
  - 为何要中点：同一段需求，以 P=1 为起点算得 0.5（缺乏弹性），以 P=2 为起点算得 2（富有弹性）——起点不同结论相反；中点法是折中。
- **点弹性**（式1.22）：**Ed = −(dQ/dP)(P/Q)**。核心：弹性 = 斜率 × 位置。
  - **同一条线性需求曲线上各点弹性不同**：由 Qd = α − βP 得 Ed = βP/(α−βP)，在 **P = α/(2β)（曲线中点）处 Ed = 1**，之上 Ed > 1，之下 Ed < 1，两端分别为 ∞ 与 0（教材图1-18）。
  - 只有比较**过同一点**的两条需求曲线时才能只看斜率：越平坦（|dQ/dP| 越大）弹性越大。
- **需求收入弹性**（式1.23）：Em = (ΔQ/Q)/(Δm/m) = (ΔQ/Δm)(m/Q)。Em > 0 正常品；0 < Em < 1 必需品；Em > 1 奢侈品；Em < 0 低档品。低档与否取决于**购买时的收入水平**，不是商品的物理属性。
- **需求交叉价格弹性**（式1.26）：Exy = (ΔQx/Qx)/(ΔPy/Py) = (ΔQx/ΔPy)(Py/Qx)。Exy > 0 替代品；Exy < 0 互补品；Exy = 0 无关；|Exy| 越大，替代或互补性越强。
- **供给价格弹性**（式1.29）：Es = (ΔQs/Qs)/(ΔP/P)，恒为正值。
  - 五类同构；**过原点的直线供给曲线 Es = 1**（ΔQ/Q = ΔP/P）。决定因素：调整时间（最关键）、生产技术类型（越复杂、周期越长越小）、产能利用程度（过剩产能越多越大）。

### 五、供求分析的应用（★★★★★）

- **支持价格 / 最低限价（price floor）**：政府为支持某产品生产而规定的**高于**均衡价格的最低价格（农产品保护价、最低工资）。
  - 图形逻辑（教材图1-20）：均衡 E(PE, QE)；P1 > PE 时，需求量落在 D 上的 A 点、供给量落在 S 上的 B 点，QS > QD，出现**过剩**（A、B 之间的水平距离）。
  - 维持手段：政府收购过剩、出口补贴、向消费者补贴（把 D 右移到 B）、增税限产（把 S 左移到 A）。不配套则市场力量会把价格压回 PE，政策失效。
- **限制价格 / 最高限价（price ceiling）**：为抑制价格过高而规定的**低于**均衡价格的最高价格（战时、灾荒的必需品）。
  - 图形逻辑（教材图1-21）：P2 < PE 时 QD > QS，出现**短缺**；配套手段是配给、排队、凭票供应。
  - **黑市上限**：P2 下生产者只愿供 QS，对应这一数量消费者愿付的最高价是需求曲线上的 P3（> PE），故黑市价最高可达 P3——这正是票证成为黑市交易对象的原因。副作用还有排队抢购、粗制滥造变相涨价。
- **税收归宿（tax incidence）**：向卖者征销售税与向买者征消费税**结果完全相同**——都是在买者支付的价格与卖者得到的价格之间插入一个**楔子 T**，分摊比例也相同。
  - 图形逻辑：向卖者征 → 供给曲线上移 T 到 S′；向买者征 → 需求曲线下移 T 到 D′。两种画法得到同一新数量，买价与卖价之差都等于 T。
  - **分摊公式**：消费者承担比例 = **Es/(Ed+Es)**；生产者 = **Ed/(Ed+Es)**。（推导：Pc = P0 + δT/(β+δ)，而 Ed = βP/Q、Es = δP/Q。）
  - 一句话记住：**弹性小的一方跑不掉，承担更多**——弹性衡量的是"条件变坏时离开市场的意愿"。食盐、香烟的税主要由消费者付；替代品丰富的轻工产品主要由生产者付。
- **弹性与总收益**：TR = PQ，故 **dTR/dP = Q(1 − Ed)**。
  - Ed > 1：dTR/dP < 0，**降价增收**（"薄利多销"成立）；Ed < 1：dTR/dP > 0，**降价减收，该提价**；Ed = 1：价格变动不影响 TR（TR 在此取极值）。
  - **谷贱伤农 / 菜贱伤农**：丰收使 S 右移，农产品需求缺乏弹性（曲线陡峭），价格大幅下跌而销量增幅有限，TR 下降。**注意方向**：这是"供给变动 + 需求缺乏弹性"，不是需求变动。

### 六、教材评析（马工程特色考点）

- **三个缺陷**：①假设不切实际（完全竞争、价格自由涨落、当事人只对价格信号反应）；②未说明均衡如何实现——蛛网模型表明稍加动态化就未必稳定，"调整速度"亦无解；③只是**局部均衡**。
- **与劳动价值论的区别**：均衡价格论不区分价值与价格，隐含把均衡价格当价值；它能说明价格围绕均衡价格波动，却解释不了"供求相等时这个数值为什么恰好如此"。马克思主义：价值由抽象劳动（社会必要劳动时间）决定，价格围绕价值波动。可取之处是它刻画了价格机制的作用形式。

## Key Concepts / 核心概念

**需求（demand）**：其他条件不变时，消费者在一系列可能价格下愿意并且能够购买的数量。
**需求规律（law of demand）**：其他条件不变，需求量与自身价格反向变动，需求曲线右下倾斜。
**供给（supply）**：其他条件不变时，生产者在一系列可能价格下愿意并且能够出售的数量。
**均衡价格（equilibrium price）**：使市场需求量恰好等于市场供给量的价格；对应数量为均衡数量。
**需求价格弹性（price elasticity of demand）**：需求量变动百分比与价格变动百分比之比，本章约定取非负。
**弧弹性与点弹性（arc / point elasticity）**：前者以两点均值为基期算两点之间的弹性；后者是 ΔP→0 的极限，Ed = −(dQ/dP)(P/Q)。
**需求收入弹性（income elasticity of demand）**：需求量变动百分比与收入变动百分比之比，符号区分正常品与低档品。
**需求交叉价格弹性（cross-price elasticity of demand）**：一种商品需求量变动百分比与另一商品价格变动百分比之比，符号区分替代品与互补品。
**供给价格弹性（price elasticity of supply）**：供给量变动百分比与价格变动百分比之比，正值。
**支持价格与限制价格（price floor / price ceiling）**：前者是高于均衡价的法定最低价（造成过剩），后者是低于均衡价的法定最高价（造成短缺与黑市）。
**税收归宿（tax incidence）**：单位税收在买者支付价与卖者实收价之间的最终分摊，比例由双方弹性决定。
**蛛网模型（cobweb model）**：供给取决于上一期价格的动态模型，用于判断均衡的动态稳定性。

## Mental Models / 思维模型

1. **均衡是"没有继续变的动力"，不是"好"**。供求相等只说明双方意愿协调、无人想再改价，与公平、效率无关。价格上限下的短缺同样是稳定僵局——这正是要区分"均衡"与"最优"的原因。
2. **弹性 = 议价力 = 退出能力**。弹性小意味着选择范围小、跑不掉。税负分摊、谷贱伤农、薄利多销、管制下谁受损，都是这一句的应用。
3. **沿曲线 vs 移曲线 = 内生 vs 外生**。只有自身价格能让点沿曲线走，其余因素平移曲线。做供求题先问"哪个变量变了、它是价格吗"。
4. **楔子模型**：税收与管制都是在买价与卖价之间插一个楔子，弹性决定楔子滑向哪边。把"谁付税"改写成"谁更难离开市场"，问题立刻变简单。

## Anti-patterns / 常见错误

- **把"需求减少"写成"需求量减少"**：小麦歉收是**供给**减少，价格上升后是**需求量**下降；说成"需求下降"就把曲线搬走了，后面全错。
- **丢弹性负号或不取绝对值**：Ed ≥ 0，负号是公式的一部分。用 (ΔQ/Q)/(ΔP/P) 算出 −1.5 却当成"缺乏弹性"，方向全反。
- **以为"曲线越陡弹性越小"可跨曲线通用**：跨曲线比较只在**过同一点**时成立；同一曲线上各点弹性不同（线性需求曲线中点 Ed=1）。
- **支持价格与限制价格记反**：支持=最低价=高于均衡→过剩；限制=最高价=低于均衡→短缺。记法：**支持**农民所以托住价格，**限制**物价所以压住价格。
- **以为"向谁征税就由谁承担"**：向卖者征与向买者征结果相同，分摊只由 Ed、Es 的相对大小决定。
- **蛛网收敛凭"谁陡"判断**：教材与笔记措辞不一致，务必回到 δ 与 β 的代数比较（收敛 ⟺ δ<β）。
- **弧弹性拿起点当基期**：必须用中点 (P1+P2)/2、(Q1+Q2)/2，否则同一段需求会算出两个相反结论。
- **把反需求函数的斜率当需求函数的斜率**：Qd = α−βP 中 dQ/dP = −β，在 P-Q 平面上 dP/dQ = −1/β；求弹性时用了 1/β 就整题错。

| ↓ | 不变 | ↓ | ↓ |
| 不变 | ↑ | ↓ | ↑ |
| 不变 | ↓ | ↑ | ↓ |
| ↑ | ↑ | **不确定** | ↑ |
| ↑ | ↓ | ↑ | **不确定** |
| ↓ | ↑ | ↓ | **不确定** |
| ↓ | ↓ | **不确定** | ↓ |

**表 C 税负分摊速判**（消费者份额 = Es/(Ed+Es)）

| 情形 | 消费者承担 | 生产者承担 |
|---|---|---|
| Ed < Es（需求更缺乏弹性） | 多 | 少 |
| Ed = Es | 各半 | 各半 |
| Ed > Es（供给更缺乏弹性） | 少 | 多 |
| Ed = 0（需求完全无弹性） | 全部 T | 0 |
| Es = ∞（供给完全弹性） | 全部 T | 0 |

**表 D 支持价格 vs 限制价格**

| | 支持价格（最低限价） | 限制价格（最高限价） |
|---|---|---|
| 与均衡价关系 | P0 > PE，托在均衡之上 | P0 < PE，压在均衡之下 |
| 市场状态 | 供大于求，**过剩** QS−QD | 供小于求，**短缺** QD−QS |
| 政府配套 | 收购过剩、出口补贴、补贴消费、限产 | 配给、排队、凭票供应、打击黑市 |
| 副作用 | 财政负担、资源错配、过度生产 | 黑市（上限为需求曲线上的 P3）、质量下降、排队成本 |

## Worked Example / 工作示例

**题**（题型取自题库计算题：均衡 + 弹性 + 税收归宿）：某产品 Qd = 50 − 2P，Qs = −25 + 3P。
（1）求均衡价格、均衡数量及该点的需求价格弹性、供给价格弹性；
（2）政府对每单位产品征 5 元销售税，买者与卖者各承担多少？
（3）求该税收造成的无谓损失。

**解（1）** 均衡条件 Qd = Qs：50 − 2P = −25 + 3P ⟹ 5P = 75 ⟹ **P = 15**，代回 Q = 50 − 30 = **20**。检验：Qs = −25 + 45 = 20 ✓（两条曲线给同一数量，说明解对了）。
Ed = −(−2)×(15/20) = **1.5**（富有弹性）；Es = 3×(15/20) = **2.25**。含义：价格提高 1%，需求量下降 1.5%，供给量上升 2.25%。

**解（2）** *路线甲（代数楔子）*：设买者支付 Pd、卖者实收 Ps，则 Pd − Ps = 5。卖者按实收价供给，供给变为 Qs = −25 + 3Ps = −25 + 3(Pd − 5) = 3Pd − 40。令 50 − 2Pd = 3Pd − 40 ⟹ 5Pd = 90 ⟹ **Pd = 18**，Ps = 13，Q = **14**。消费者多付 18 − 15 = **3** 元，生产者少收 15 − 13 = **2** 元。

*路线乙（弹性分摊）*：消费者份额 = Es/(Ed+Es) = 2.25/3.75 = **0.6**，即 5×0.6 = **3 元**；生产者 5 − 3 = **2 元**。两条路线一致。

*三重验算*：① 3 + 2 = 5 = T ✓；② Pd − Ps = 18 − 13 = 5 ✓；③ 数量由 20 降至 14，税收总额 5×14 = 70 = 3×14 + 2×14 ✓。

*解读*：Es(2.25) > Ed(1.5)，卖者比买者更容易退出市场，故税负更多落在买者（3 > 2），印证"弹性小者多担"。

**解（3）** 无谓损失 = ½ × T × ΔQ = ½ × 5 × (20 − 14) = **15**。含义：被税收"消灭"的那 6 单位交易，原本能给买卖双方合计带来 15 的剩余，现在谁也没得到。

## 解题套路 / Solution Patterns

**1｜名词解释（需求量变动 vs 需求变动、需求定理、需求价格弹性、交叉弹性、蛛网模型）**
四段式：①严格定义（必带"其他条件不变""愿意并且能够"）→ ②数学表达（弹性类写出公式并交代符号约定）→ ③几何表达（沿曲线 / 移曲线）→ ④与近邻概念的差别（需求变动 vs 需求量变动；交叉弹性正负 vs 替代互补）。易错点：定义漏前提；只答"是什么"不答"怎么表现"。

**2｜简答：影响某量的因素**
套骨架。需求侧六条——自身价格、收入、相关品价格、偏好、预期、政策；供给侧六条——技术、成本与要素价格、相关品价格、生产者目标、预期、政策。每条只写方向 + 曲线往哪边移。易错点：把"影响需求的因素"答成"影响需求量的因素"；只列名词不写方向。

**3｜计算题 I：均衡 + 点弹性**
①令 Qd = Qs 解 P、Q（两者形式不同先统一，注意 Qs 可能为 −γ+δP）→ ②Ed = |dQd/dP|·P/Q，Es = (dQs/dP)·P/Q，**Q 必须用均衡点的 Q** → ③补一句经济含义（>1 富有弹性）。易错点：把反需求函数的 1/β 当成 β；忘 Ed 的负号约定；用税前 Q 算税后弹性。

**4｜计算题 II：税收归宿**
两条路线任选，但**必须交叉验算**。路线甲：设 Pd、Ps，用 Pd − Ps = T 改写供给（对卖者征，Qs 中的 P 换成 P−T）或需求（对买者征，Qd 中的 P 换成 P+T），联立求新均衡，两价之差即分摊。路线乙：先算均衡点 Ed、Es，再按 Es/(Ed+Es) 分摊。易错点：改动错曲线；两种做法结果不一致却不去查符号。

**5｜论述：谷贱伤农 / 薄利多销 / 价格管制评价**
现象 → 工具（TR = PQ 或供求图）→ 分情形讨论 → 政策含义。谷贱伤农三层：①丰收使 S 右移；②农产品需求缺乏弹性（曲线陡峭），价格跌幅 > 数量增幅；③TR = PQ 下降。政策：保护价收购（本质是支持价格，须政府收购过剩）、按产量补贴、限产提价（组建农会可提高供给弹性）。易错点：把主因说成"供给弹性大"——教材的论证落在**需求**缺乏弹性上，供给弹性小只是让价格跌得更狠的辅因，主次必须分清。

## Key Takeaways / 关键结论

1. 价格机制题一律从三件套起手：两个行为方程 + 一个均衡条件；解出 P、Q 之后才谈弹性与福利。
2. 曲线移动口诀：只有**自身价格**能让点沿曲线走，其余因素一律平移曲线；需求右移=增加，供给右下移=增加（供给的"上下"与需求相反，务必写明）。
3. 弹性 = 斜率 × 位置，符号由定义给定。Ed 取非负；Em 与 Exy 的符号本身携带信息（正常/低档、替代/互补）。
4. 双边同时变动时必有一个结果"不确定"——供求定理唯一要背的例外条款，也是判断题常客。
5. 弹性小 = 跑不掉 = 承担税负、承担价格波动。"税负分摊""谷贱伤农""薄利多销"是同一句话的三个应用。
6. 价格管制答题永远是四步：先定均衡 → 再说 P0 偏离方向 → 再说数量缺口（过剩/短缺）→ 最后说配套与副作用。
