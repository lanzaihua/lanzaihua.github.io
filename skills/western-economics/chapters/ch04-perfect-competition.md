# 第4章 完全竞争市场 (Perfect Competition)

> 马工程《西方经济学》(第二版) · 上册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

第3章算清了成本，本章补上收益的另一半，并按"企业占市场份额的大小"把市场分成四种结构。完全竞争是份额小到可以忽略的极端：企业是价格接受者，面临水平的需求曲线，故 `P=AR=MR`，利润最大化条件 `MR=MC` 退化为 `P=MC`。本章是全部市场结构分析的**基准系**——凡这里成立的结论（水平需求线、`P=MC`、长期零经济利润、总剩余最大），第5章都要逐条打破。

## Frameworks Introduced / 核心框架

### 一、收益的三个概念（式4.1–4.3）

- **总收益** `R=P·Q=P(Q)·Q`（式4.1，假定销量=产量）；**平均收益** `AR=R/Q=P(Q)`（式4.2）——**AR 恒等于企业面临的需求曲线、也恒等于价格**，任何市场结构都成立；**边际收益** `MR=dR/dQ=P+Q·dP/dQ`（式4.3），第二项是"多卖一单位须对全部产量降价"的代价，它是否为零即完全竞争与不完全竞争的分水岭。
- **企业面临的需求 ≠ 市场需求**：后者是对市场上全部产品的需求，前者只是其中一部分；二者关系由企业的市场份额决定，只有垄断时重合（第5章）。

### 二、市场结构与划分依据（表4-1）

四个判据：**买卖双方的数量、产品的性质（有无差别）、市场主体之间的联系程度（信息是否充分）、进出的难易程度**；题库归纳为"厂商数目、产品差别、对价格的控制程度、进出壁垒"。

| 类型 | 厂商数目 | 产品差别 | 进出 | 企业对价格 |
|---|---|---|---|---|
| 完全竞争 | 很多 | 无 | 无 | 无影响，接受者 |
| 垄断竞争 | 很多 | 有 | 无 | 影响很小 |
| 寡头 | 少数几个 | 有或无 | 有 | 举足轻重 |
| 垄断 | 一个 | 无 | 有 | 单独决定 |

- 判据的实质是**市场份额**：企业是否完全竞争，不取决于其产品在**整个市场**中的份额，而取决于它在**与其完全相同的产品**中的份额。故"份额极小"与"产品同质"必须同时具备——只有前者是垄断竞争企业。寡头则要看对手反应。

### 三、利润最大化原则（式4.4、4.5）

`π(Q)=R(Q)−C(Q)`（式4.4）求导得 `π′(Q)=MR−MC`，令其为零即 `MR=MC`（式4.5）。它是**必要而非充分**条件，二阶条件 `MR′<MC′` 要求 **MC 从下方穿过 MR**——这就是"取右交点"的依据。**普适性**：教材明说该原理也适用于垄断、垄断竞争与寡头，市场结构只改变 `MR` 与 `P` 的关系（`MR=P` 还是 `MR<P`）。口径上利润指**经济利润**，正常利润已计入成本。

### 四、完全竞争市场的四个特征

① 买卖者人数极多，任一方相对市场总量微不足道；② 产品完全同质，单独提价即失去全部顾客；③ 资源完全流动，进出自由；④ 信息完全。推论：企业需求曲线的**需求价格弹性为无穷大**（题库标准答案 `ed=∞`）；由①②得"两个微不足道"，市场价格成为**外生参数**。教材声明：完全竞争是**理论抽象**，现实并不存在。

### 五、需求曲线与收益曲线（式4.6–4.9）

`P=P(Q)=P0`（式4.6）：在横轴产量 Q、纵轴价格 P 的图中是**位于 P0 高度的水平线**。企业改变产量只是在此线上左右移动（从 Q0 增到 Q2、减到 Q1），价格不变——水平线表达"企业是价格接受者"，**不是**"市场价格恒定"；价格由供求决定，供求一变整条线平移到新高度。于是 `R=P0Q`（式4.7，过原点、斜率 P0）、`AR=P0`（式4.8）、`MR=P0`（式4.9），**`P=AR=MR=d` 四线重合**。所有企业的 AR 都等于价格，完全竞争的特异之处只是 **MR 也等于价格**；第5章垄断 `MR<P=AR`，差异源于此。

### 六、短期均衡：`P=MC` 定产量

短期只能调产量，`P=MR=MC`。MC 为 U 形，与水平价格线一般交于两点：左交点（下降段）是**利润最小**，右交点（上升段）是**利润最大**——右交点左侧 `MR>MC` 增产有利、右侧 `MC>MR` 减产有利，先升后降。故**利润最大化产量必在 MC 最低点右边**。特例：价格恰等于 MC 最低点时两交点合一，该产量既非最大也非最小；此时价格已低于 `AVC`，企业停产，产量记为零。

### 七、短期均衡的五种状态（本章最重）

判据**两级**，顺序不可颠倒：**先以 `P` 与 `AC` 比定赚不赚，亏损时再以 `P` 与 `AVC` 比定干不干**。

| # | 价格位置 | 盈亏 | 决策 | 名称 |
|---|---|---|---|---|
| ① | `P>AC_min` | 盈利，得超额利润 | 生产 | 超额利润状态 |
| ② | `P=AC_min` | 经济利润为零，只得正常利润 | 生产 | **盈亏平衡点** |
| ③ | `AVC_min<P<AC_min` | 亏损，但能收回全部 VC 与部分 FC | 继续生产 | 亏损但经营 |
| ④ | `P=AVC_min` | 亏损额恰等于 FC | 生产与停产无差别 | **停止营业点** |
| ⑤ | `P<AVC_min` | 亏损额大于 FC | 停产，Q=0 | 停止营业 |

**盈亏平衡点**由 `AC` 最低点决定，回答"赚不赚钱"；**停止营业点**由 `AVC` 最低点决定，回答"开不开工"。`AVC_min` 必低于 `AC_min`（差额为 AFC），两者之间正是状态③。

**为什么看 AVC 不看 AC**（最易错，务必算清）：固定成本**沉没**，停产也照付，故不进"停不停"的比较；随决策变化的只有可变成本。停产损失 = FC；生产损失 = FC + (AVC−P)·Q*。两式相减，继续生产比停产**少亏** `(P−AVC)·Q*`：`P>AVC` 时每单位除收回全部 VC 还多收回 `P−AVC` 抵补 FC，应继续生产；`P<AVC` 时连 VC 都收不回，生产比停产多亏，应停产；`P=AVC` 时两者相等，无差别。一句话：**AC 决定划不划算，AVC 决定开不开**；高额固定成本可以是亏损原因，但**永远不会是停业原因**（题库判断题的标准结论）。又，**"利润最大化"不等于"盈利"**：价格太低时做到最好仍亏损，此时利润最大化 = **亏损最小化**。

### 八、短期供给曲线

`P≥AVC_min` 时供给曲线 = **MC 中 AVC 最低点以上的部分**；`P<AVC_min` 时供给量为 0，供给曲线是**纵轴上的相应线段**，两段**互不连接**。行业供给 = 各企业供给曲线的**水平相加** `S=ΣMCn`。**"加总错误"**：简单相加隐含假定"价格变动不改要素价格、因而不改 MC"；若全行业扩产推高要素价格，各企业 MC 上移，真实供给曲线比 MC **更陡**——对单个企业成立、对整个市场不一定成立。

### 九、长期均衡（第二个重心）

两层调整：**规模调整**（在所有短期利润最大化产量中挑最优的一个，条件 `LMR=LMC`；最优规模上必有 `LMC=MC*`），即"长期利润最大化就是在所有短期均衡中选一个最优的短期均衡"；**行业调整**（自由进出：有利润则进入 → 供给增 → 价格跌；亏损则退出 → 供给减 → 价格升）。故均衡条件为 `P*=LMR*=LAR*=LMC*=LAC*=MR*=AR*=MC*=AC*`，简记 **`P=MR=MC=AC_min`**，且 `SAC` 最低点与 `LAC` 最低点相切（LAC 是各规模 SAC 的包络线）。两个含义要分开：`LMC=LAC` 表示生产在 **LAC 最低点**（最有效率规模），`MC*=AC*` 表示生产在 **SAC 最低点**（该规模的最低成本）。

**为什么是零经济利润**（第二易错）：零的是**经济利润（超额利润）**，不是"没有利润"——正常利润已计入成本，故企业**恰好赚到全部正常利润**。机制是套利：有超额利润则进入、价格跌、利润被竞争掉；亏损则退出、价格升；均衡即两个动机同时消失处，而它只有一个——`P=LAC_min`，此时企业处于状态②，但用的是**最低的 AC**。教材第五节的批评：若以大于零的**平均利润率**而非零利润率为进出标准，长期仍可有正的经济利润（平均利润），故"长期零利润"依赖一个不现实的假定。

### 十、长期供给曲线

价格总等于 `LAC` 最低点，故路径为：需求变动 → 短期价格变动 → 进出调整 → **要素价格变动 → 整条 LAC 上移或下移** → 新均衡点仍是新 LAC 的最低点；把各期行业均衡点连起来即 `LS`。要素价格不变 ⇒ `LS` 水平（只有企业数量变）；上升 ⇒ 向右上倾斜（需求扩大使价格与产量同向变动，厂商数增加而单个厂商产量可增、可减、可不变）；下降（外部经济）⇒ 向右下方倾斜。注意"成本递增"指 **LAC 曲线整体上移**，不是指斜率为正。

### 十一、剩余与效率

- **生产者剩余** = 实际总支付 − 愿意接受的最小总支付 = **价格线以下、供给（MC）曲线以上的面积** = `TR−TVC`；**消费者剩余** = 需求曲线以下、价格线以上。**总剩余 = CS+PS** = 需求曲线以下、供给曲线以上，**完全竞争使其最大化**（产量小于 Q0 增产增剩余，大于 Q0 减产增剩余）。
- **效率两条**：`P=MC` ⇒ 多生产一单位所耗资源的价值 = 消费者愿为该单位支付的价格，故**产量最优**；`P=AC_min` ⇒ 收入恰好补偿成本、无超额利润、消费者不多付，且生产在现有技术的最低成本上，故**技术最优**。产品无差别，亦无非价格竞争的浪费。
- **评析三点**：① 完全竞争假定不是资本主义现实的反映；② 其政策不能解决两极分化、经济危机（根源在私人占有制度而非竞争不完全）；③ 不是社会主义市场经济的理想模式。但作为**分析基准**，先建完全竞争模型再讨论不完全竞争，方法论上必要。

## Key Concepts / 核心概念

- **完全竞争市场（perfect competition）**：买卖者极多、产品同质、资源完全流动、信息完全，因而不存在任何垄断因素的市场结构。
- **价格接受者（price taker）**：份额小到无法影响市价、只能按现行市价出售的企业。
- **盈亏平衡点（break-even point）**：`P=AC_min`，经济利润为零、只获正常利润。
- **停止营业点（shutdown point）**：`P=AVC_min`，收益恰好弥补全部可变成本，生产与停产损失相同；由此得**停业原则**：`P<AVC` 即停产（损失仅为 FC），`P>AVC` 则继续生产。
- **长期均衡**：`P=MR=MC=AC_min`、经济利润为零、无进出动机的状态。
- **生产者剩余（producer surplus）**：`PS=TR−TVC`，价格线以下、供给曲线以上。
- **成本不变／递增／递减行业**：行业扩产使要素价格不变／上升／下降，从而使 `LAC` 最低点不变／上移／下移的行业。
- **加总错误（aggregation error）**：把对单个企业成立的结论（供给曲线=MC）直接搬到整个市场。

## Mental Models / 思维模型

- **"价格是参数，产量是变量"**：企业手里只有一个旋钮——Q。`P` 给定，由 `MC(Q)=P` 定 Q，再用 `AC`、`AVC` 判断这笔产量值不值得做。第5章的企业多了一个旋钮（可定价），`MR` 不再等于 `P`，整套结论随之改写。
- **"两级判据"**：`AC` 管赚不赚，`AVC` 管干不干。看到"亏损"别直接跳到"停产"，再问一句"亏得比固定成本多吗"。题库的判断题、选择题、论述题反复考同一个分岔。
- **"沉没成本不进决策"**：把两个选择的**差额**列出来（停产损失 FC vs 生产损失 FC+(AVC−P)Q），FC 自动消掉——这是所有"该不该继续"问题的通用手法。
- **"进出是价格的负反馈"**：利润是信号，进出是执行机构，价格是反馈量。利润正 → 进入 → 供给增 → 价格跌；利润负 → 退出 → 供给减 → 价格升。收敛到的不动点就是 `P=LAC_min`；想通这个回路，"长期零利润"不必背。

## Anti-patterns / 常见错误

- **用 `AC` 而不 `AVC` 判停产**：`P<AC` 只说明亏损，不说明该停；`AVC_min<P<AC_min` 时应继续生产，因为还能收回部分固定成本。
- **把"零经济利润"说成"没有利润"或"亏损"**：零的是超额利润，正常利润照拿且已计入成本；长期均衡恰是不盈不亏。
- **认为 `P=MC` 就必然盈利**：它只保证"产量最优"，盈亏看 `P` 与 `AC`；此时利润最大化=亏损最小化。
- **把 `MR=MC` 当充分条件、取错交点**：MC 为 U 形时两交点，左交点是**利润最小**；必须取上升段（`MR′<MC′`）。
- **混淆企业需求曲线与行业需求曲线**：企业的是一条**水平线**（弹性无穷大），行业的是**向右下方倾斜**的曲线；水平线也只说"本企业产量不影响价格"。
- **把整条 MC 当供给曲线**：只有 `AVC` 最低点以上的 MC 段才是，以下部分是纵轴；判断题"供给曲线就是边际成本曲线"答案应为错。
- **认为长期供给曲线一定向右上方倾斜**：成本不变行业水平、成本递减行业向右下方倾斜；"成本递增"指 **LAC 整体上移**，不是斜率为正。
- **把"停产"与"退出"混谈**：停产是短期（Q=0，仍付 FC），退出是长期（规模缩到 0，离开行业）。

**速查：长期供给曲线三形状**　要素价格不变 ⇒ `LAC` 最低点不动 ⇒ `LS` 水平（特例，只有企业数量变）；要素价格上升 ⇒ 最低点上移 ⇒ `LS` 向右上方倾斜（最常见）；要素价格下降 ⇒ 最低点下移 ⇒ `LS` 向右下方倾斜。

**速查：三个关键点**　`MC_min < AVC_min < AC_min`；价格跌到 MC 最低点时企业早已在停产区间。

## Worked Example / 工作示例

**题目**：某完全竞争企业 `STC=0.04Q³−0.4Q²+8Q+9`，市场价格 `P=12`。求利润最大化产量、利润、生产者剩余，并判断是否应继续生产、停止营业价格是多少。

**① 边际成本。** `MC=dSTC/dQ=0.12Q²−0.8Q+8`。

**② 用 `P=MC` 定产量。** 完全竞争企业 `P=MR=12`，故 `0.12Q²−0.8Q+8=12`，化简 `3Q²−20Q−100=0`，得 `Q=10` 与 `Q=−10/3`，负根舍去，**Q\*=10**。（两正根时须分别算利润取大者。）

**③ 算利润并校验盈亏。** `TR=12×10=120`；`STC=0.04×1000−0.4×100+80+9=89`；`π=120−89=31>0`，**盈利**。第一级判据：`AC=8.9<12=P`，落在状态①；第二级此时不必启用，但可验证 `AVC=80/10=8<12`，即便亏损也应继续生产。两判据方向一致。

**④ 生产者剩余。** `PS=TR−TVC=120−80=40`（`TVC=89−9=80`）。几何上是价格线以下、MC 以上、0 到 10 的面积：`∫₀¹⁰(12−MC)dQ=120−80=40`，因为 `∫₀¹⁰MC dQ` 恰等于总可变成本。

**⑤ 停止营业价格。** `AVC=TVC/Q=0.04Q²−0.4Q+8`，令 `dAVC/dQ=0.08Q−0.4=0` 得 `Q=5`，代入 `AVC_min=1−2+8=7`。故 `P<7` 停产，`P=7` 生产与停产无差别。交叉验证：`Q=5` 处 `MC=3−4+8=7=AVC_min`，符合"MC 穿过 AVC 最低点"；又 `AC_min>AVC_min`，故存在 `7<P<AC_min` 的区间，企业亏损但仍应生产（状态③）。

**结论**：`Q*=10`，`π=31`，`PS=40`，停止营业价格 7，应继续生产。

## 解题套路 / Solution Patterns

**题型一：名词解释与判断题（概念题）。** 名词解释写法：**定义 → 条件或公式 → 图形语言 → 一句用途**。以生产者剩余为例：实际总支付减愿意接受的最小总支付 → `PS=TR−TVC` → 价格线以下、供给曲线以上的面积 → 衡量生产者参与市场的好处与政策福利损失。易错：只写定义不写公式与含义；把它当成"利润"（它比利润多出固定成本）。判断题高频命题：① `P=MC` 且 MC 向下倾斜 ⇒ 利润最小——**对**（二阶条件不满足）；② `AVC` 最低且等于价格 ⇒ 开工与不开工效果一样——**对**；③ 高固定成本是亏损原因、但永远不是停业原因——**对**；④ 短期均衡时 `SMC<SAC` ⇒ 其他企业会进入——**错**（该企业亏损）；⑤ 供给曲线就是边际成本曲线——**错**（须限定 AVC 最低点以上）。方法：见"一定/必然"先想反例；见"供给=MC"先查 AVC 限制；见"亏损"先问"亏得比 FC 多吗"。

**题型二：由成本函数求短期均衡（最高频）。** 步骤：`MC=dSTC/dQ` → 令 `MC=P` 解二次方程 → 舍负根、两正根比利润 → `π=PQ−STC` → 用 `AC` 与 `P` 比较说明盈亏 → 要判"是否生产"再比 `AVC_min`。易错：两根不取舍；用 `AC` 判停产；把 `π` 的正负当"是否停产"的依据。

**题型三：求短期供给函数。** 步骤：`SMC=dSTC/dQ` → 令 `P=SMC` 反解 `Q=f(P)`（取 `dMC/dQ>0` 的根）→ 令 `dAVC/dQ=0` 求 `AVC_min` → **分段写出**：`P≥AVC_min` 时 `Q=f(P)`，`P<AVC_min` 时 `Q=0`。易错：漏写定义域（最常见失分点）；把 `AVC_min` 算成 `AC_min`。（题库原题：`STC=0.04Q³−0.8Q²+10Q+5`，`Q=10` 处 `AVC_min=6`，故供给函数只在 `P≥6` 成立。）

**题型四：长期均衡价格与厂商数量。** 步骤：含常数项的总成本先剔除固定成本得 `LTC`（长期 FC=0）→ `LAC=LTC/Q` → `dLAC/dQ=0` 求 `q*` 并验 `d²LAC/dQ²>0` → `P*=LAC(q*)` → 代入需求求行业总量 → `n=Q/q*`。易错：忘剔固定成本；把行业产量当企业产量。（题库原题：`LTC=q³−20q²+100q` ⇒ `q*=10`、`LAC_min=0`；由 `Qd=2500−3P` 得 `Q=2500`，`n=250`。）

**题型五：剩余与税负的福利计算。** 步骤：联立求 `Pe`、`Qe` → 求两曲线在 `Q=0` 处的截距 → `CS=(P_d−Pe)Qe/2`、`PS=(Pe−P_s)Qe/2`、`SW=CS+PS` → 征税把供给函数中的 `P` 换成 `P−t`（需求不动）重解 → 差分求福利变化。易错：三角形的高取错（须减均衡价格）；错改需求函数。

**题型六：论述题（三选一）。** ① *长期供给曲线*：按成本不变／递增／递减三段，统一结构是"需求右移 → 价格升 → 短期有利润 → 进入 → 要素价格如何变 → LAC 如何移 → 新均衡 → 连两点得 LS"。② *长期均衡的实现与特点*：两层调整 → `MR=LMC=SMC=LAC=SAC` → 三特点（成本最低、只得正常利润、产量同时位于 SAC 与 LAC 最低点）。③ *效率评价*：`P=MC`、`P=AC_min`、价格自由波动、无非价格竞争浪费，再加第五节评析。易错：只列结论不写传导链条。

## Key Takeaways / 关键结论

1. **`MR=MC` 是通用判据，市场结构只改变 `MR` 与 `P` 的关系**：完全竞争 `MR=P`，不完全竞争 `MR<P`，第5章的全部差异由此而来。
2. **完全竞争企业的需求曲线是水平线**，故 `P=AR=MR=d` 四线合一；行业需求曲线仍向右下方倾斜，两者不可混。
3. **短期均衡是两级判断**：`P` 与 `AC` 比定盈亏，`P` 与 `AVC` 比定开工；`AC_min` 是盈亏平衡点，`AVC_min` 是停止营业点。
4. **停止营业点看 AVC 而非 AC**：固定成本沉没，停产与否只改变可变成本收支，`P>AVC` 时生产总比停产少亏。
5. **短期供给曲线 = `AVC` 最低点以上的 MC 段**（加纵轴线段）；市场供给是各企业供给曲线的水平相加，而非 MC 的简单加总。
6. **长期均衡 `P=MR=MC=AC_min`、经济利润为零**：自由进出的套利结果，零的是超额利润而正常利润照拿；长期供给曲线形状则只取决于"扩产如何影响要素价格"（不变→水平，递增→右上，递减→右下），二者共同构成完全竞争的效率结论。

## Connects To / 与其他章节的联系

- **第1章**：企业需求曲线的弹性为无穷大，是需求价格弹性分类的极端情形；消费者剩余、供求均衡、从量税的转嫁与福利损失，在这里以"总剩余"的形式重演。
- **第3章（成本）**：`MC`、`AC`、`AVC` 的 U 形及相互关系（MC 穿过两者最低点，`AC=AVC+AFC`）是本章全部判据的几何基础；`LAC` 作为 `SAC` 的包络线决定了长期均衡的相切性质。
- **第5章（不完全竞争）**：逐条对照——需求曲线由水平变右下倾斜、`MR<P`、`P>MC`、长期可有超额利润、产量更低而价格更高，由此产生无谓损失。
- **第6章（要素价格）**：企业的要素需求来自边际收益产品 `MRP=MR·MP`；完全竞争企业因 `MR=P`，故 `MRP=VMP`，这是要素需求曲线向右下方倾斜的起点。
- **第8章（福利经济学、公共物品）**：总剩余最大化与 `P=MC` 是判断市场失灵、计算无谓损失的基准；评析中"不能有效促进技术进步、不能充分提供公共物品"即指向后续章节。
- **数学分析**：`π′=MR−MC=0` 是极值的必要条件，`MR′<MC′` 是极大值的充分条件；`AVC` 的最小值用 `dAVC/dQ=0`、`d²AVC/dQ²>0` 判定；生产者剩余是积分 `∫₀^Q(P−MC)dQ=PQ−TVC`，与"`TVC` 是 MC 曲线下的面积"互为印证。
