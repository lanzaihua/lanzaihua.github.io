# 第0章 导论 (Introduction)

> 马工程《西方经济学》(第二版) · 上册  —  教材「导论」+ 笔记详解 + 配套题库 综合整理
>
> 考点权重：西方经济学的界定 ★ ｜ **由来与五阶段 ★★** ｜ **研究起点与对象 ★★** ｜ **研究方法（实证/规范、静态/比较静态/动态）★★**

## Core Idea / 核心思想

导论回答三件事：**这门学问研究什么、从哪儿来、用什么方法研究**。起点是一句判断——**资源稀缺**；由稀缺逼出**选择**，选择逼出**三大基本问题**（生产什么、如何生产、为谁生产）；于是经济学被定义为"在稀缺条件下有效配置资源与分配财富"的学问。从此分出两条腿：**微观**研究单个经济单位如何配置（中心是价格理论），**宏观**研究总量如何决定（中心是国民收入理论）。方法论上则是"四条根本假设（个人主义、理性、自利、均衡）+ 一堆具体工具（实证/规范、静态/比较静态/动态、边际分析、演绎/归纳）"。

马工程教材在这一章就亮明立场：**西方经济学以人与物的关系为研究对象，撇开了人与人的生产关系**——这是本章所有论述题的收尾落点，也是它区别于马克思主义政治经济学的根本。

## Frameworks Introduced / 核心框架

### 一、西方经济学的界定（★）

西方经济学 = **微观经济学 + 宏观经济学**。

| | 微观经济学 | 宏观经济学 |
|---|---|---|
| 研究对象 | **单个经济单位**（家庭、厂商） | **整个经济**（总量） |
| 解决的问题 | **资源配置**：生产什么、如何生产、为谁生产 | **资源利用**：为何闲置、如何充分就业 |
| 研究方法 | **个量分析** | **总量分析**（故又称总量经济学） |
| 中心理论 | **价格理论** | **国民收入（产出）理论** |
| 基本假设 | 价格机制自发调节、市场出清 | 价格黏性、需求管理 |
| 别称 | 价格理论 | 国民收入决定理论 / 总量经济学 |

⚠️ 三点不是"常识补充"，而是**必考简答**：区别要从"研究对象—解决问题—研究方法—中心理论"**四维**答，缺一维扣分。

### 二、由来与发展：五个阶段（★★）

1. **重商主义**（15～17 世纪中期）：财富=金银，靠**贸易顺差**积累；研究范围局限在**流通领域**。
2. **古典经济学**（17 世纪中叶～19 世纪中后期）：斯密 1776《国富论》为标志，李嘉图、马尔萨斯、萨伊、穆勒；研究领域从流通扩展到**生产**，主张"看不见的手"。
3. **新古典经济学**（19 世纪中后期～20 世纪初）：**边际三杰**——杰文斯、门格尔、瓦尔拉斯；马歇尔 1890《经济学原理》集大成；希克斯《价值与资本》、萨缪尔森《经济分析基础》推向成熟。核心是**边际效用价值论**（价值取决于单位满足程度），仍在完全竞争框架内，但工具升级、研究扩到消费与需求。
4. **凯恩斯主义**（20 世纪初～20 世纪 70 年代）：1936《就业、利息和货币通论》，大萧条证伪"市场自动出清"，主张**政府"看得见的手"**干预；从**需求**角度解释国民收入，失业源于**有效需求不足**。**凯恩斯革命宣告现代宏观经济学诞生。**
5. **后凯恩斯主义**（20 世纪 70 年代起）：70 年代**滞胀**证伪凯恩斯主义；弗里德曼（货币主义）、卢卡斯（理性预期）为代表，自由主义抬头，主张**政府作用有限**。

记忆链：**流通（重商）→ 生产（古典）→ 边际+消费（新古典）→ 需求+政府（凯恩斯）→ 反政府+预期（后凯恩斯）**。每一步都是"上一阶段被现实打脸"的结果：大萧条打脸新古典，滞胀打脸凯恩斯。

### 三、研究起点与研究对象（★★）

- **研究起点 = 资源的稀缺性（scarcity）**：相对于人类**无穷的欲望**，用于满足欲望的产品与生产要素**总是有限的**。稀缺是**相对**的，不是绝对数量少；它是一切经济问题的前提，也是"经济学"存在的理由。
- **研究对象 = 在稀缺条件下有效配置资源和分配财富**，落到**三大基本问题**：
  - **生产什么、生产多少**（what）——资源配置到哪些产品；
  - **如何生产**（how）——用什么技术、什么要素组合；
  - **为谁生产**（for whom）——产品如何分配。
- **与马克思主义政治经济学的比较（论述题必答）**：马克思主义的研究对象是**特定社会制度中的社会生产关系**（经济利益关系），揭示社会经济规律；西方经济学以稀缺为起点讨论**资源配置与财富分配**，把**生产中人与物的关系**作为对象，**撇开了人与人之间的生产关系**，因而自称为"超阶级""超历史"的科学——这正是它被批评为**庸俗经济学**的根据。

### 四、一般方法论：四条根本假设（★★）

- **方法论个人主义（methodological individualism）**：把社会看作许多个人的聚集，整体可化约为个体之和（化约主义）；它**不必然等于政治上的个人主义**。局限：**非社会性、非制度性、非历史性**，逻辑空间狭窄，常只能给出对策性、描述性说明。
- **理性行为假设**：人在追求利益时会收集利用信息、权衡比较各种抉择，挑出**最佳方案**以实现最大满足/最大效用。它是西方经济学体系的**逻辑起点**。
- **"经济人"假设 = 完全理性 + 自利**。注意：利己者可以理性，**利他者也可以理性**；"经济人"只是"既理性又自利"的那个抽象。
- **求解均衡**：把经济状态刻画为若干力量相互制约下的相对静止点，再问它如何被打破。

### 五、具体研究方法：工具层（★★）

- **实证分析 vs 规范分析（最高频）**
  - **实证**：回答"**是什么**"——描述、解释、预测经济运行，**不含价值判断**，结论可被事实检验，**具有客观性**；既有定性也有定量。
  - **规范**：以**价值判断**为出发点，提出行为标准，回答"**应该是什么**"；结论受价值标准影响，**没有客观性**。
  - 联系：**规范以实证为基础，实证以规范为指导**——实证的最终目标常含价值判断，规范的结论又常是实证的出发点。
- **静态 / 比较静态 / 动态分析**
  - **静态**：给定外生变量，求内生变量的**均衡状态**及其特征。
  - **比较静态**：外生变量变化后，**新旧均衡状态**的对比（不问调整过程）。
  - **动态**：引入**时间**，考察变量从一期到下一期的调整路径（如蛛网模型）。
- **边际分析**：数学化后即**导数/微分**——自变量微量变动引起的因变量变化；经济学说"边际"就是"多一单位"。
- **演绎 vs 归纳**：演绎从一般到个别（先推论后观察）；归纳从个别到一般（从观察开始）。
- **均衡分析、数学模型、博弈论**等为具体工具；对数学化应"**不简单否定、不片面夸大**"——模型只能刻画复杂经济世界的某一侧面。

### 六、教材评析（马工程立场，论述题收尾）

- **西方经济学的两重性**：它研究市场经济运行，形成了一套有用的分析工具与方法；但其方法论以**唯心史观与形而上学**为基础，从个人主义自利与完全理性假设出发，**撇开生产关系**，把经济学当作超阶级、超历史的科学。
- **为什么不能直接用西方经济学解释中国崛起**：它把经济发展视为经济自身运行的结果，甚至只从微观主体成本收益看效率；而**经济发展是整个社会系统运行的结果**。马克思主义关于**生产力与生产关系、经济基础与上层建筑**的论断把经济纳入社会系统，才解释得通"高储蓄、高投资、低成本"这类现象——西方经济学的"**节约悖论**"恰恰难以解释中国增长。
- **"斯密问题"**：《国富论》以**自利心**为出发点，《道德情操论》以**同理心**为出发点，看似矛盾；但二者不在同一层次（自利是"天性"，同理心是"能力/分析工具"），故斯密的思想体系内在一致。
- **1830 年以后的"庸俗经济学"**：阶级矛盾尖锐化后，主流经济学转向只关注效率与资源配置、回避阶级问题，马克思因此称之为庸俗经济学。

## Key Concepts / 核心概念

**稀缺性（scarcity）**：相对于人类无穷欲望而言，经济资源的供给总是不足的；是经济学的研究起点与前提。
**机会成本（opportunity cost）**：把一种资源用于某用途而放弃的其他用途中的最高收益。
**微观经济学（microeconomics）**：以单个经济单位为对象、以个量分析为方法、以价格理论为中心，研究资源配置。
**宏观经济学（macroeconomics）**：以整个经济为对象、以总量分析为方法、以国民收入理论为中心，研究资源利用。
**实证分析（positive analysis）**：回答"是什么"，描述、解释、预测经济现象，不含价值判断，结论可检验。
**规范分析（normative analysis）**：以价值判断为出发点回答"应该是什么"，提出行为标准。
**静态分析**：给定外生变量求解均衡状态。
**比较静态分析**：比较外生变量变动前后的两个均衡状态。
**动态分析**：引入时间，考察均衡的调整过程与路径。
**方法论个人主义**：把社会现象化约为个体行为的分析方法；是西方经济学最基本的方法论。
**经济人（economic man）**：完全理性 + 自利的人格化抽象，是西方经济学的基本假设。
**生产可能性边界（PPF）**：给定资源与技术下，两种产品最大产量组合的轨迹；边界上为有效率，内部为无效率。

## Mental Models / 思维模型

1. **稀缺 → 选择 → 机会成本 → 边际比较**，是一条单向推理链。任何"为什么要学经济学"式的题，沿着这条链答四步即可。
2. **"是什么"与"应该是什么"是两把尺子**。凡题干出现"应该""合理""公平""是否值得"，就在规范分析的地盘；凡出现"会怎样""为什么""预测"，就在实证分析的地盘。
3. **静态看照片、比较静态比两张照片、动态看录像**。三者的差别只在"有没有时间"和"问不问过程"，不在难度。
4. **五个阶段的更替 = 现实打脸理论**。大萧条打脸新古典（市场能自动出清），滞胀打脸凯恩斯（政府能熨平周期）。用"哪次危机推翻了谁"来记，比背年份牢。

## Anti-patterns / 常见错误

- **把稀缺性理解成"东西少"**：稀缺是**相对于欲望**的，空气不稀缺而钻石稀缺，不是因为数量多少，而是因为相对于需求。
- **实证/规范判断靠"有没有数字"**：错。实证可以有定性描述，规范也可以用数据；判据是**有没有价值判断**。"政府应该提高最低工资"是规范，"提高最低工资会减少青年就业"是实证。
- **微观/宏观只答"一个是个量一个是总量"**：四维答法（对象/问题/方法/中心理论）才完整。
- **把"经济学研究资源配置"与"宏观研究资源利用"混为一谈**：微观管**配置**（生产什么、如何、为谁），宏观管**利用**（为何闲置、怎样充分就业）。
- **静态分析当成"静止不变的分析"**：静态分析不排斥变化，只是**不考察调整过程**；外生变量也可以变（那是比较静态）。
- **新古典与古典混为一谈**：古典=斯密/李嘉图、劳动价值论、生产领域；新古典=边际三杰/马歇尔、边际效用价值论、消费与需求。
- **答"西方经济学的研究对象是资源稀缺"**：错，稀缺是**起点/前提**，研究对象是**稀缺条件下的资源配置与财富分配**。

## Worked Example / 工作示例

**题**（据中南大学 2016 研、兰州大学 2009 研改写）：(1) 简述实证分析与规范分析的区别与联系；(2) 简述西方经济学的发展历程。

**解（1）** 按"定义—区别三点—联系两条"作答：
- **定义**：实证回答"是什么"，描述、解释、预测，不含价值判断；规范以价值判断为出发点，回答"应该是什么"。
- **区别**：① 规范要立判别标准、作好坏判断，实证只描述运行过程；② 要解决的问题不同（是否符合价值标准 vs 变量间的规律）；③ 规范无客观性、结论受价值标准影响，实证有客观性、结论可被事实检验。
- **联系**：规范以实证为基础，实证以规范为指导；实证的最终目标常含价值判断，规范的结论又常是实证的出发点。
- **收尾一句**（马工程口径）：微观经济学既分析实证问题也分析规范问题，二者都是重要方法。

**解（2）** 用"五阶段 + 每阶段一句话"：
重商主义（金银、贸易顺差、流通）→ 古典（斯密《国富论》、看不见的手、生产）→ 新古典（边际三杰、马歇尔、边际效用价值论）→ 凯恩斯主义（《通论》、有效需求、政府干预）→ 后凯恩斯主义（滞胀、弗里德曼、卢卡斯、理性预期）。
**加分句**：每次更替都由现实危机推动——大萧条推翻新古典的自动出清，滞胀推翻凯恩斯的政府万能。

## 解题套路 / Solution Patterns

**1｜名词解释（稀缺、机会成本、经济人、实证分析、规范分析、静态/比较静态/动态、方法论个人主义）**
四段式：① 一句话定义（稀缺必带"相对于欲望"，实证/规范必带"价值判断"）→ ② 关键构成或公式（如机会成本=放弃的最高收益）→ ③ 一句例子或对比 → ④ 地位/局限（经济人是逻辑起点；个人主义有非社会性局限）。

**2｜简答：微观与宏观的区别**
固定四维：研究对象 → 解决问题 → 研究方法 → 中心理论。末尾补一句"二者相互联系：微观是宏观的基础，宏观为微观提供环境"。

**3｜简答/论述：西方经济学的研究对象及与马克思主义的比较**
三段：① 西方：稀缺条件下配置资源与分配财富，落到三大基本问题；② 马克思：特定社会制度中的生产关系、经济利益关系；③ 差异：西方研究**人与物**、撇开**人与人**，自称超阶级超历史——由此引出"庸俗经济学"的批评。

**4｜论述：如何对待西方经济学 / 为什么不能解释中国奇迹**
四段：① 有用性（分析市场经济的工具与方法）→ ② 局限性（方法论个人主义、撇开生产关系、静态均衡）→ ③ 中国奇迹需要整体视角（生产力与生产关系、经济基础与上层建筑）→ ④ 结论：批判借鉴，不照搬。

## Key Takeaways / 关键结论

1. 一条主线：**稀缺 → 选择 → 机会成本 → 边际比较**；导论所有概念都挂在这条链上。
2. **微观=配置（价格理论），宏观=利用（国民收入理论）**，四维对照记牢。
3. **五阶段 = 五次"现实打脸"**：流通→生产→边际→需求→预期；代表作与年份至少记住《国富论》1776、《经济学原理》1890、《通论》1936。
4. **实证/规范的唯一判据是有无价值判断**，不是有无数据；两者是"基础与指导"的双向关系。
5. **静态/比较静态/动态**的差别只在"问不问过程、有没有时间"。
6. 马工程立场要会复述：西方经济学研究**人与物**、撇开**人与人**，这是它与马克思主义政治经济学的分水岭，也是所有评析题的标准收尾。

## Connects To / 与其他章节的联系

- **第1章 需求、供给和均衡价格**：本章的"稀缺—选择"在这里落成第一个可算的模型（供求均衡），"均衡分析"从口号变成工具。
- **第2章 消费者选择**：理性行为与效用最大化假设在此正式展开（边际效用、无差异曲线）。
- **第7章 一般均衡与效率**：帕累托效率正是"资源配置有效"的严格化，回答导论留下的"怎样算配置得好"。
- **第9章 宏观经济的基本指标及其衡量**：宏观经济学从定义到度量的第一步，对应本章"宏观以国民收入为中心"。
- **第16章 经济增长**：回应本章末尾"为什么不能直接用西方经济学解释中国崛起"的长期增长议题。
