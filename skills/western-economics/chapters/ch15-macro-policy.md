# 第15章 宏观经济政策 (Macroeconomic Policy)

> 马工程《西方经济学》(第二版) · 下册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

第9—14章把宏观建成模型，本章把模型当工具箱：给定四个目标（充分就业、物价稳定、经济持续均衡增长、国际收支平衡），用财政与货币推动总需求，用人力、收入、指数化政策推动总供给。全章只有两个真问题：**工具能推动多少**——由 IS、LM 的斜率（h、d、k、乘数）决定，不由政策意愿决定；**目标打架时怎么配**——米德冲突与菲利普斯曲线替代是两处硬约束，工具数少于目标数时，任何单一政策都会顾此失彼。政策哲学的分野（相机抉择 vs 规则）由此展开。

## Frameworks Introduced / 核心框架

### 一、四大目标及其一致与冲突（★★）

**充分就业**：广义指一切生产要素都有机会以自己愿意的报酬参加生产，狭义指失业率等于自然失业率。凯恩斯定义为"不存在非自愿失业"（摩擦性、自愿失业仍存），货币主义用自然失业率说同一件事 ⇒ **充分就业从不是 100% 就业**。**稳定物价**：一般物价水平相对稳定；两条限定必写——指**物价总水平**而非个别商品，不是固定不变而是把涨幅控制在可承受幅度内。**经济增长**：较长时期内**人均**产出（人均收入）的持续增加。**国际收支平衡**：纠正差额使其趋于平衡；长期巨额逆差耗外汇储备、背债务利息，长期巨额顺差则资源与外汇闲置，且为收购外汇增发本币会引起或加剧国内通胀。

**一致性**：顺差过大 → 收购外汇 → 国内货币供应量增加 → 物价上升；逆差过大 → 货币紧缩 → 增长放慢、失业增加；长期均衡增长则失业率低。**冲突两处**：

- **米德冲突（Meade conflict）**：以财政、货币政策实现内部均衡、以汇率政策实现外部均衡的组合，在固定汇率制下因汇率工具失效而只剩两件工具够两个目标；"逆差 + 国内疲软"或"顺差 + 国内通胀"并存时取向左右为难。**实质是工具数 < 目标数。**
- **稳定物价 vs 充分就业**：降失业须提高货币工资，工资上涨率超过劳动生产率增长率即形成成本推进型通胀——即第14章菲利普斯曲线的替代。

**学派抉择**：凯恩斯主义选**短期稳定**（相机抉择管理总需求）；货币主义选**长期价格稳定**（相机抉择只把菲利普斯曲线越推越远，长期曲线垂直于自然失业率）。两条现实约束：目标须匹配周期（过热→稳物价，衰退→增长就业）；目标选择是**公共选择甚至政治过程**。

### 二、财政政策工具与两种操作方式（★★★★★）

**财政政策**：为促进就业、减轻波动、防止通胀、实现稳定增长，对政府收支、税收与借债水平所作的选择。工具四类（＋净利息支付与政府补贴）：

- **政府购买**：直接购买产品、服务与资本品，属**实质性支出**，有真实交易、直接形成总需求，是国民收入组成部分 ⇒ 乘数最强、**使用最多、效果最明显**。
- **转移支付**：无偿支付给个人或下级政府（社保、养老金、失业保险、福利、医保、国企补贴）。属**货币性支出**，不以取得本年度产品服务为报酬，**不是国民收入组成部分**，只做收入再分配、不改变总收入，经可支配收入间接影响消费。
- **税收**：政府收入最主要来源（美国约 90%）：个人所得税、社会保险税、产品和进口税、公司税；累进所得税自带稳定器功能。
- **公债**：以国家信用筹集的债务，债务人国家、债权人公众，不需担保；既弥补赤字，又能在资金市场流通调节货币供求 ⇒ 财政工具与货币工具的接口。

**自动稳定器（automatic stabilizer，内在稳定器）**：经济系统本身存在、减少干扰对国民收入冲击的机制：GDP 下降时使政府支出**自动**增、税收**自动**减，上升时反之。**"自动"＝不需识别形势、不需决策、不需立法，机制内置于制度，故内部时滞为零。**三项：①**失业保障**——衰退时申领者增多、救济金自动增加，托住可支配收入与消费；②**农产品价格维持制度**——萧条时按支持价格收购、繁荣时抛售；③**累进所得税体系**——衰退时税收降幅超过收入降幅。力度可算：边际消费倾向 0.8、税率 0.1 时 1 美元自发投资使总需求增 3.57 美元，税率 0.25 时只增 2.5 美元 ⇒ **边际税率越高，自发冲击的波动越小**。三条局限：走出衰退时**延缓复苏**、削弱自主政策效应；地方受平衡预算约束会**顺周期**（美国各州萧条减支提税、繁荣增支减税）；严重衰退或恶性通胀时作用有限，甚至**抵消**政府干预。

**相机抉择的财政政策**：分析形势后斟酌使用、**逆经济风向行事**——衰退扩大购买、增转移支付、降税率，过热反向。改变政府购买最常用最明显；改变转移支付与税率影响大但**不灵活**。交替使用即**补偿性财政政策**（汉森）：繁荣盈余补萧条赤字，把**年度平衡**换成**整个周期平衡**。

**功能财政 vs 平衡预算**：平衡预算分年度平衡与周期平衡，都以收支相抵为念；**功能财政（functional finance）**主张财政不以预算平衡为目的，而以发挥经济职能、保持稳定发展为目的——**需要赤字就赤字，需要盈余就盈余**。关系背准：**功能财政是相机抉择的指导思想，相机抉择是功能财政的实现**。

**充分就业预算盈余**：把产出固定在潜在水平上算出的盈余。**为何不能用实际盈余判方向**：私人投资增加 → 产出上升 → 税收增加 → 盈余增加，而政府什么都没做。故看它：增加或赤字减少 ⇒ 紧缩，反之扩张；缺陷是潜在产出难准确估算。

**赤字与公债**：弥补靠借债或出售政府资产；借债两途——向央行借（增发货币，等于**通货膨胀税**）、向公众与外国借（**债务筹资**，不直接增加基础货币，故不直接引发通胀，但留下债务负担）。**传统观点**：短期借债为减税筹资刺激消费，价格黏性下产量增、失业降，但利率上升抑制投资；长期储蓄减少、产量下降。**李嘉图等价（Ricardian equivalence）**：借债筹资＝征税筹资，公债只是延期的税收；消费者前瞻，把减税所得储蓄备将来纳税，故消费不增、总需求不受刺激。分歧落点是**后代**：30 年期债券把财富从下一代纳税人转移给当代人。

### 三、财政政策效应与挤出效应（★★★★★）

**财政政策效应**＝IS 移动对国民收入的影响。调整链要能口述：支出增加 → IS 右移（利率不变时收入可至 Y₂）→ 收入提高使交易性货币需求增加 → 货币供给既定下出现货币过度需求 → **利率由 r₀ 升至 r₁** → 投资下降 → 最终在 E₁ 两市场同时均衡（Y₁、r₁）。**Y₂−Y₁ 就是被挤掉的部分。**

**斜率法则**：LM 不变时 **IS 越陡**（投资利率弹性 d 越小）财政效应越大，IS 越平则挤出多、效应小；IS 不变时 **LM 越平**（h 越大或 k 越小）财政效应越大，**LM 越陡**效应越小；LM 垂直（L=kY）时 IS 右移只抬高利率、收入不变 ⇒ **财政政策完全无效，乘数为 0**。

**挤出效应（crowding-out）**：政府支出增加引起的私人消费或投资减少，机理是政府支出抬高利率；非充分就业只部分挤出，**充分就业完全挤出**。四因素：①**支出乘数**越大挤出越大（取决于边际消费倾向，稳定）；②**k**（货币需求对产出的敏感度）越大挤出越大（取决于支付习惯与制度，较稳定）；③**h**（货币需求对利率的敏感度）越小挤出越大；④**d**（投资对利率的敏感度）越大挤出越大。**前两者稳定，故决定性因素是 h 与 d**。学派分歧：凯恩斯主义 h 大 ⇒ 挤出不大；货币主义挤出大甚至 100% ⇒ 财政无用。教材另立**挤进效应（crowding-in）**：政府投资改善环境、社保改善预期，反诱导私人投资消费。

### 四、货币政策与三大工具（★★★★★）

**货币政策**：央行通过控制货币供应量调节金融市场信贷供给与利率，从而影响投资与总需求。三大工具均为**间接调控**：

- **公开市场业务（open market operations）**：在金融市场公开买卖政府债券以调节货币供给，**最常用也最重要**；分主动性（改变准备金与基础货币）与被动性（抵消其他因素对基础货币的影响）。链：买卖债券 → 货币供给 → 利率 → 消费与投资 → 产出与价格；扩张即**买进**，紧缩即**卖出**，优缺点见表 A。
- **法定准备金率**：吸收存款中必须向央行缴存的比例。存款创造量与它**成反比**、经货币乘数放大 ⇒ **提高准备金率 ⇒ 信用创造能力缩小 ⇒ 货币供给减少 ⇒ 利率上升 ⇒ 投资消费与收入下降**。**有超额准备金时调整它未必改变实际准备金率**，故效果只"可能"而非"必然"。
- **再贴现率**：商业银行把已贴现未到期票据卖给央行取得贷款为再贴现，央行收取的利率即再贴现率。**提高它 ⇒ 商业银行向央行借款减少 ⇒ 信贷规模缩减 ⇒ 货币供给减少**，且商业银行贷款利率随之提高、抑制投资消费；缺点是**被动**、见效慢，美国联邦基金利率已逐渐取代它。
- **辅助**：信用控制、道义劝告、窗口指导——均无法律约束力，但影响力不小。

**方向口诀（最高频易错）**：准备金率↑、再贴现率↑、**卖出**国债 ⇒ 货币供给↓；三者反向 ⇒ 货币供给↑。

**基础货币与货币乘数**：`H = C + R`（银行体系外现金 + 准备金，含法定与超额），能数倍派生货币故称强力/高能货币。`M = H × k`，`k = 1/(rd + re + rc)`。**货币供给不由央行单独决定**：央行定基础货币，商业银行存款创造，公众经现金-存款比率与存款结构影响乘数 ⇒ 这已预告货币政策的局限（现金漏损率、定期存款比率上升，超额准备金超常增长，都压低乘数、抵消扩张）。

### 五、货币政策效应、两种极端与规则之争（★★★★★）

**货币政策效应**＝LM 移动对收入的影响。资产市场先调整（货币供给增加 → 过度货币供给 → 买资产 → 利率下降至货币市场出清），产品市场再跟随（利率下降 → 总需求增加 → 产出沿 LM 上移）。**斜率法则**：LM 不变时 **IS 越平**（d 越大）效应越大；IS 不变时 **LM 越陡**（h 越小）效应越大。

**两种极端**：**流动性陷阱（liquidity trap，凯恩斯陷阱）**——LM 水平，货币的利率弹性无限大，居民在既定利率下愿持有任意数量货币，货币供给变动不移动 LM ⇒ **货币政策完全无效**，只能靠财政（财政完全有效、挤出为零）；其伴生状态是深度萧条、利率已降至最低而刺激失效。**古典情形**——LM 垂直、h=0，货币供给变动对收入影响达最大限度 ⇒ 货币政策最有效、财政无效。

**相机抉择 vs 规则**：焦点是"政策应积极还是消极"。凯恩斯依据**价格与工资刚性**，须逆风向干预；货币主义与新古典依据两条理论——**动态不一致性**（长期最优与每期短期最优冲突，政府有违背承诺的动机而公众会理性预期到，一旦摇摆就毁掉公信力，故守规则短期付代价、长期收获信誉）与**卢卡斯批评**（政策依据历史关系 `y=f(x)`，预期一变，改变 x 后关系成了 `y=g(x)`，效果与初衷截然不同；教材以菲利普斯曲线示意：当局想用更高通胀换更低失业，预期随之上调、曲线整体上移，结果通胀上去了而失业仍为自然失业率）。

**四种规则**：①**货币增长目标**（弗里德曼单一规则，增长率可在 2%、4%、5% 中选；缺陷是**忽略货币流通速度变化**）；②**名义 GDP 目标**（可应对流通速度变化）；③**通货膨胀目标**；④**泰勒规则**——式(15.1)：`r = 2% + π + 0.5(π − π*) + 0.5(Y − Y*)/Y*`，r 为名义利率、π* 为目标通胀率、Y* 为潜在产出，2% 是实际利率（在目标路径上时名义利率 = 实际利率 + 通胀率）；通胀超目标或产出超潜在都上调名义利率。

### 六、两种政策的局限性与协调（★★★）

**财政政策的局限**（四条 + 挤出）：①**时滞**——识别、决策（须经国会等审批，**往往很长**）、执行（**外在时滞较短**，出台后见效快且带强制性）；识别 + 决策 = **内在时滞**，执行 = **外在时滞**。②**形势不确定性**——乘数大小难定、生效时间难测，力度过大挤出太多、过小无效。③**公众阻力**——增税、减购买、减转移支付各得罪不同群体，且增支减税后人们未必把钱全用于消费。④**公众预期**——理性预期下的行动常抵消政策效果。

**货币政策的局限**（四条）：①**效果短期性**——紧缩反通胀较显著，衰退期扩张不明显，流动性陷阱下松银根也不降利率；且只对**需求拉动型**通胀有效。②**时滞**——内部时滞短，**外部时滞长**（利率 → 投资 → 就业 → 收入）。③**货币流通速度变动**——微小且未被预料的变动就可能使正确的政策走向反面。④**资金国际流动**——紧缩抬高利率吸引外资，浮动汇率下本币升值抑出口，固定汇率下央行投放本币收购外币，都削弱紧缩效果。

**时滞对比（最易错）**：财政**决策慢、执行快**；货币**决策快、传导慢**；自动稳定器内部时滞为 0。

**协调的客观性**：目标差异（财政以促进发展为首要、货币以货币稳定为第一）、机制不同（财政从收支两侧影响总需求，货币经货币供给影响消费与投资）、功能不同（财政对总量与**结构**都强，货币侧重**总量**）、且都有局限。协调有三：**目标协调、方向协调**（逆周期——过热双紧、萧条双松、过渡期总体中性）**、力度协调**。IS-LM 例证：单用财政把 IS₁ 推到 IS₂、利率升到 r₂；单用货币把 LM₁ 推到 LM₂、利率降到 r₃——都能到 Y*，但都让利率大起大落；**双松并用可使利率不变而收入达 Y***。

### 七、供给管理政策（★★）

**人力政策**：优化人力资源配置、增加就业、促进增长；理论基础是人力资本理论与新古典综合派就业理论。措施四条：**人力资本投资**、**完善劳动力市场**（人才市场、就业指导中心，减少结构性摩擦）、**协助流动**（迁移费与住房补贴）、**降低最低工资标准**。主旨是治理**结构性失业**。

**收入政策（工资与物价控制政策）**：以行政措施强制或非强制地限制工资与价格，目的是制止**工资成本推动型**通胀；理论基础是工会垄断导致"工资刚性"，故须在扩张性财政货币政策之外管制工资。四型：**工资-物价指导线**（政府定与增长相适应的工资、价格增长率，靠劝说推行）、**工资-物价冻结**（法律禁止上涨；能迅速制住通胀，但价格失去调节作用、配置失当、效率低下，长期反引起需求拉动型通胀）、**权威性劝说**、**以税收奖惩工资增长率**。评价：**效果不理想，最多是补充政策**——温和者无强制力，严厉者削弱价格机制，预期存在时人们还会变相提价。

**指数化政策**：通胀只改变名义变量，指数化让名义变量随物价调整以保住实际变量：**工资指数化**（"生活费用调整"，工资随消费价格指数同步调整，社保福利同理）、**税收指数化**（调整免征额与税率档次以消除"档次爬升"，如免征额 500 元在 10% 通胀下调为 550 元）、**利率指数化**（名义利率按通胀调整以保持实际利率不变）。风险是可能形成**工资-物价螺旋**，反而加速通胀。

**供给学派的减税主张**：以减税刺激供给与生产，与需求管理相对；教材评析须带上：它只关注供给、认为供给会自己创造需求，片面强调市场作用、主张削减社会福利，减税有利于富人；**中国的供给侧结构性改革与此有根本不同**——既强调供给又关注需求、既发挥市场决定性作用又更好发挥政府作用、以人民利益为中心、减税是为减轻企业负担。减税的需求效果可用 AD-AS 表述：提高可支配收入与消费、刺激投资 ⇒ AD 右移 ⇒ 价格与产出同时上升。

## Key Concepts / 核心概念

- **财政政策（fiscal policy）**：政府变动税收与支出以影响总需求、就业与国民收入的政策。
- **自动稳定器（automatic stabilizer）**：内置于制度、无须政府行动即随 GDP 反向调节支出与税收的机制。
- **相机抉择（discretionary policy）**：政府按形势主动斟酌变动支出与税收，逆经济风向行事。
- **功能财政（functional finance）**：不以预算平衡为目的，而以发挥财政经济职能、稳定经济为目的的财政思想。
- **充分就业预算盈余**：在潜在产出水平上衡量的预算盈余，用于判断政策方向。
- **挤出效应（crowding-out）**：政府支出增加抬高利率、减少私人投资与消费的效应。
- **货币乘数**：`k = 1/(rd + re + rc)`，基础货币派生出货币供给的倍数。
- **流动性陷阱（liquidity trap）**：LM 水平、货币利率弹性无限大，货币政策完全无效的状态。
- **米德冲突（Meade conflict）**：固定汇率下仅用财政与货币政策无法同时实现内外部均衡的困境。
- **卢卡斯批评（Lucas critique）**：政策改变会改变预期从而改变模型参数，历史关系不能用来评价新政策。

## Mental Models / 思维模型

- **"斜率即传导效率"**：不记结论，记两条链。财政走"支出 → 收入 → 货币需求 → 利率 → 投资被挤"，故 **IS 陡（d 小）+ LM 平（h 大）⇒ 财政强**；货币走"货币供给 → 利率 → 投资 → 产出"，故 **IS 平（d 大）+ LM 陡（h 小）⇒ 货币强**。所有"效果大小"的题都在问这两条链的阻尼有多大。
- **"两种时滞的分工"**：财政慢在**决策**、快在**执行**；货币快在**决策**、慢在**传导**。故衰退初起宜用货币、深度衰退宜用财政；自动稳定器把两段时滞都省掉，所以它是第一道防线而非主力。
- **"规则是承诺装置"**：动态不一致性说的是"事后最优"毁掉"事前可信"；规则本质是用短期灵活性换长期信誉，相机抉择不是错，错在没有信誉资本时反复使用。
- **"两件工具管两个目标"**：财政与货币对 (Y, r) 的推力方向不同（双松 Y 增而 r 不定、松财政紧货币 r 升而 Y 不定），要同时管产出与利率（或总量与结构）就得配着用——这就是协调的代数理由。

## Anti-patterns / 常见错误

- **三大工具方向记反**：准备金率↑、再贴现率↑、**卖出**债券都使货币供给↓；买进债券、降低准备金率与再贴现率才是扩张。
- **把货币乘数当定式 `1/rd`**：有超额准备金与现金漏损时是 `1/(rd+re+rc)`；且**有超额准备金时提高法定准备金率未必改变实际准备金率**。
- **时滞张冠李戴**：财政"决策慢、执行快"，货币"决策快、传导慢"，自动稳定器内部时滞为 0。
- **把自动稳定器当"自动回到充分就业"**：它只减缓波动幅度、不改趋势；走出衰退时反而延缓复苏，地方平衡预算约束下还会变成**顺周期**政策。
- **用实际预算盈余判断政策方向**：产出变动本身会改变盈余，须用充分就业预算盈余（增加=紧缩）。
- **以为流动性陷阱下财政也失效**：恰恰相反——LM 水平时财政完全有效、挤出为零；古典情形才反过来，财政乘数为 0。这是"两种极端"最标准的对调陷阱。
- **把挤出效应当必然 100%**：它由 h 与 d 决定，凯恩斯极端为 0、古典极端为 100%，且还有方向相反的挤进效应。

## Worked Example / 工作示例

**题目**：某国 `C = 600 + 0.8Y`、`I = 400 − 50r`、`G = 200`、`L = 250 + 0.5Y − 125r`、`M = 1250`、`P = 1`（亿美元）。求：(1) 两个政策乘数；(2) 若 `Y* = 5000`，增加政府购买需增多少？(3) 改用增加货币供给需增多少？

**① 建方程。** IS：`Y = 600 + 0.8Y + 400 − 50r + 200` ⇒ `0.2Y = 1200 − 50r` ⇒ **`Y = 6000 − 250r`**。LM：`0.5Y − 125r = 1000` ⇒ **`Y = 2000 + 250r`**。

**② 解均衡并校验。** 联立得 `r = 8`、`Y = 4000`；代回 LM `0.5×4000 − 125×8 = 1000` ✓。

**③ 求乘数。** 由 LM 得 `r = 0.004Y − 8` 代入 IS：`0.2Y = 1000 − 50(0.004Y − 8) + G` ⇒ `Y = 3500 + 2.5G` ⇒ **财政乘数 2.5**；同法得 `Y = 2250 + M + 2.5G` ⇒ **货币乘数 1**。两式在 `G=200, M=1250` 处都给 4000 ✓。

**④ 算缺口。** `ΔY = 1000` ⇒ `ΔG = 400`、`ΔM = 1000`。校验：在 `Y*=5000` 处货币市场需 `250 + 2500 − 125r = 1250` ⇒ `r = 12`，产品市场需 `5000 = 600 + 4000 + 400 − 600 + G` ⇒ `G = 600` ✓；只动货币时 IS 给 `r = 4`，LM 需 `M = 250 + 2500 − 500 = 2250` ✓。

**结论**：财政乘数 2.5、货币乘数 1；需增政府购买 400 亿或增货币供给 1000 亿。**两条路的差别正是挤出的价格**：财政路径把利率由 8% 推到 12%，货币路径把它压到 4%——想同时稳住利率，就得双松并用。

## 解题套路 / Solution Patterns

**题型一：名词解释与判断题。** 名词解释四段式：**定义 → 构成或类型 → 作用机制 → 局限/评价**。以自动稳定器为例：内置的减震机制 → 失业保障、农产品价格维持、累进所得税三项 → 随 GDP 反向自动调节支出与税收 → 只减缓波动、不改趋势且内部时滞为零。判断题固定陷阱：IS 越平坦财政效果越差（**对**）；LM 越陡财政效果越大（**错**）；流动性陷阱下挤出最小、财政完全有效（**对**）；挤出近 100% 时财政乘数近零（**对**）；古典情形财政乘数为 0（**对**）；凯恩斯区域货币政策更有效（**错**）。

**题型二：简答"挤出效应及其影响因素"。** 四步：定义（政府支出抬高利率、减少私人投资消费）→ IS-LM 机理（IS 右移、货币需求增加、r 上升、投资下降，`Y₂−Y₁` 即挤出量）→ 四因素（乘数、k、h、d，逐条说明越大/越小则挤出越大）→ 收尾（前两者稳定，故决定于 h 与 d；凯恩斯极端为 0、古典极端为 100%）。漏掉"决定性因素是 h 与 d"通常扣分。

**题型三：计算 IS-LM 政策乘数。** 写 IS、LM → 解均衡并代回校验 → 消去 r 得 `Y(G)` 与 `Y(M)`，斜率即乘数（亦可套 `ΔY/ΔG = 1/[(1−β) + kd/h]`、`ΔY/ΔM = d/[h(1−β) + kd]`）→ 缺口除以乘数 → **换一条路径复核**。易错：`M` 未除 `P`；漏掉 `L` 中的常数项；算出乘数后不检查是否与均衡点自洽。

**题型四：论述"两种政策的协调"。** 骨架：客观必要性（目标、机制、功能、局限四点差异）→ 方向协调（双紧/双松/中性对应过热/萧条/过渡）→ 四组合矩阵（指出"为何总有一项不确定"：IS 与 LM 对利率的推力相反）→ IS-LM 例证（单用财政 r 升到 r₂、单用货币 r 降到 r₃、双松使 r 不变达 Y*）→ 评析（财政局限四条、货币局限四条、时滞对比）。

**题型五：论述"相机抉择与规则之争"。** 五段：焦点（政策应积极还是消极）→ 凯恩斯依据（价格工资刚性、市场不完善，故逆风向干预必要且有效）→ 货币主义/新古典依据（动态不一致性 + 卢卡斯批评，故相机抉择反而制造不稳定）→ 四种规则（单一货币规则、名义 GDP 目标、通胀目标、泰勒规则，各说一句优缺点）→ 中国取向（重大决策定规则、偶发冲击与微调用相机抉择；时滞题顺带按"识别 → 决策 → 执行"三段作答）。

## Key Takeaways / 关键结论

1. **四个目标天然打架**：米德冲突（工具数 < 目标数）与菲利普斯曲线替代（物价 vs 就业）是两处硬约束，任何政策都是"目标取舍"而非"全面达标"。
2. **财政政策力度 = IS 陡 + LM 平**；挤出四因素中乘数与 k 稳定，**决定性因素是 h 与 d**；凯恩斯极端挤出为零，古典极端完全挤出、财政乘数为 0。
3. **货币政策力度 = IS 平 + LM 陡**；两端分别是流动性陷阱（完全无效）与古典情形（效果最大）。三大工具方向：准备金率↑、再贴现率↑、卖债券 ⇒ 货币供给↓。
4. **时滞决定工具选择**：财政决策慢执行快，货币决策快传导慢，自动稳定器内部时滞为零；政策帮倒忙的根源是外部时滞超过衰退本身。
5. **四种组合各有确定项**：双松收入增、双紧收入减，松财政紧货币利率升、紧财政松货币利率降——不确定的那一项永远是收入或利率之一，因为 IS 与 LM 对它的推力相反。
6. **功能财政否定平衡预算**，充分就业预算盈余才是判断政策方向的指标；赤字向公众发债不直接引发通胀，靠央行认购则等于通货膨胀税。
7. **相机抉择与规则的取舍是信誉问题**：动态不一致性与卢卡斯批评说明"事后最优"会摧毁"事前可信"；供给管理政策只是需求管理的补充，收入政策效果最不理想。

## Connects To / 与其他章节的联系

- **第10、11章（乘数与 IS-LM）**：支出乘数是挤出效应的第一个决定因素，也是财政政策乘数公式中 `(1−β)` 的来源；本章全部政策效应不过是 IS、LM 移动与斜率的比较静态，"均衡点调整"在此被拆成两条具体传导链。
- **第12章（AD-AS）**：政策冲击最终落在 AD 的移动上——减税、增购都是 AD 右移，供给管理政策作用于 AS（教材正是用 AD-AS 分析减税）。
- **第13、14章（失业与通胀）**：自然失业率是"充分就业"的操作口径；菲利普斯曲线短期替代与长期垂直，直接决定两个目标冲突的强度，也决定两派在目标抉择上的分歧。
- **第16章（经济增长）**：政府投资与人力资本投资是增长章里资本、劳动投入的政策对应物；本章"短期稳定"与增长章"长期供给"构成一对。
- **数学分析与线性代数**：`ΔY/ΔG`、`ΔY/ΔM` 是二元方程组的比较静态（全微分或克莱姆法则），解的存在唯一性对应两线不平行，LM 垂直时方程组退化、财政乘数为零正是"行列式为零、Y 无解"的读法；货币乘数 `1/(rd+re+rc)` 是等比级数求和；泰勒规则的偏导 `θ_π`、`θ_Y` 即"反应敏感度"。
