# 第12章 国民收入的决定：AD-AS 模型 (Aggregate Demand–Aggregate Supply Model)

> 马工程《西方经济学》(第二版) · 下册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

IS-LM 把价格锁死，只能回答"产出多少"，回答不了"价格多高"。本章把 P 放回模型：**AD 曲线是 IS-LM 在价格可变时留下的轨迹**（`P↑→M/P↓→LM 左移→Y↓`），**AS 曲线由总量生产函数加劳动市场推出**，斜率由货币工资与价格的调整速度决定。两线相交同时定出 `(Y,P)`——于是同一套工具既能讲萧条（AS 水平段）、又能讲滞胀（AS 左移）、还能讲长期货币中性（AS 垂直）。这是本书宏观部分唯一同时容纳供求两侧的模型。

## Frameworks Introduced / 核心框架

### 一、总需求函数与 AD 曲线的含义

- **总需求函数（aggregate demand function）**：产出（收入）与一般价格水平之间的关系；表示产品市场与货币市场**同时均衡**时，某一特定价格水平所对应的均衡产出（均衡总支出）水平。其几何表示即 **AD 曲线**。
- **坐标系**：横轴产出 Y、纵轴价格 P。AD **向右下方倾斜**——价格水平越高，需求总量越小。
- **构成**：消费需求 + 投资需求 + 政府需求 + 国外需求；任一项变动都可能移动 AD。
- **总开关是实际货币供给 `M/P`**：中央银行与银行体系提供的是**名义**货币供给 M，价格水平把同一个 M 换算成不同的 `M/P`。AD 的全部机制都从这个分母出发。
- 教材另有一句：AD 描述"与每一价格水平相对应的均衡总支出"，故也可由收入-支出模型理解；但**标准推导是 IS-LM 联立**，考试按 IS-LM 写。

### 二、价格变动的三个效应（★★★★｜"AD 为何右下"的标准答案）

- **利率效应（interest-rate effect，凯恩斯效应）**：`P↑ → 交易所需货币↑（货币名义需求是价格的增函数）→ 给定 M，r↑ → I↓ → 总支出与收入↓`。
  - 教材数值直觉：P=1.0 时社会需 1000 亿元交易货币，P=1.2 时需 1200 亿元——价格越高，同样交易量越费钱。
  - 一句话：**P 与 r 同向，r 与 I、Y 反向**。
- **实际余额效应（real balance effect，财富效应 / 庇古效应）**：`P↑ → 手持货币及以货币计价的资产实际购买力↓ → 相对变穷 → 消费↓ → 总需求↓`。
  - 另带一条**税档渠道**（教材与笔记都单列）：`P↑ → 名义收入↑ → 进入更高纳税档次 → 税负↑ → 可支配收入↓ → 消费↓`。它走财政口径而非财富口径，别与购买力混成一条。
- **汇率效应（exchange-rate effect，净出口效应）**：`P↑ → 本国产品相对变贵 → 出口↓、进口↑ → 净出口↓ → 总需求↓`；同向的第二渠道是 `P↑ → 本国生产成本↑ → 到外国投资更合算 → 对外投资↑、国内投资↓`。
- **答题要点**：教材正文重点写前两条，笔记与题库补上汇率效应凑成三条；选择题"AD 向右下方倾斜是因为（　）"的标准答案是"以上都是"。**只写利率效应是不完整的**。

### 三、AD 曲线的推导：从 IS-LM 到 `Y=f(P)`

- **代数路线（两部门）**：`IS: S(Y)=I(r)`；`LM: M/P=L_1(Y)+L_2(r)`。把 Y、r 当未知数、**把 P 当参数**联立，解出的 Y 必含 P，即总需求函数。
- **教材数值例**：`0.5Y+100r=3000` 与 `0.5Y+200r=1000/P` 联立消 r，得 `Y=12000−2000/P`。
- **图形路线（文字还原）**：上栏 IS-LM（横轴 Y、纵轴 r），下栏 AD（横轴 Y、纵轴 P）。取 `P₁`，`LM(P₁)` 与 IS 交于 `E₁`，得 `(Y₁, r₁)`，在下栏标点 `D₁=(P₁,Y₁)`；取更高的 `P₂`，**LM 左移（上移）到 `LM(P₂)`**——同样 M 下 P 更高即 `M/P` 更小；与 IS 交于 `E₂`，得 `Y₂<Y₁`、`r₂>r₁`，标出 `D₂`；重复取点连线，得右下倾斜的 AD。
- **关键细节**：**价格变化不移动 IS**——IS 中的变量被假定为实际变量，不随货币价格变动；P 只通过 `M/P` 移动 LM。这是判断题与简答题的高频陷阱。
- **斜率（可由隐函数求导验证）**：设 `Y=α(A−dr)`、`M/P=kY−hr`，消 r 得 `Y=[αA+αdM/(Ph)]/(1+αdk/h)`，故 `dY/dP=−αdM/(P²h)/(1+αdk/h)<0`。含义：**支出乘数越大、投资对利率越敏感（d 大）、货币需求对利率越不敏感（h 小，LM 越陡），AD 越平坦**。

### 四、AD 曲线的移动

- **总原则**：`物价水平固定不变时，其他因素导致 IS-LM 中收入的变动，就引起 AD 曲线移动`。P 变是**沿 AD 移动**；IS/LM 的其他因素变才是**AD 移动**。
- **扩张性财政政策**：`G↑（或减税）→ IS 右移 → 同一 P 下 r↑、Y↑ → AD 右移`。r 上升带来的挤出已内含在"右移幅度小于乘数×ΔG"中。
- **扩张性货币政策**：`M↑ → LM 右移 → 同一 P 下 r↓、I↑、Y↑ → AD 右移`。
- **紧缩性财政/货币**：反向，AD 左移。
- **因素清单**：消费、投资、政府支出、出口、**名义货币供给**自发增加 → 右移；税收额、税率、进口、**实际货币需求**自发增加 → 左移。
- **意义**：AD 把财政与货币政策统一译成"同一价格水平下总需求的位移"，这正是**需求管理政策**的理论依据。

### 五、总供给与 AS 曲线的含义

- **总供给（aggregate supply）**：经济社会的总产出（总收入），由总量的**劳动、生产性资本存量、技术水平**决定。
- **宏观（总量）生产函数（aggregate production function）**：`Y=f(N,K)`，N 为就业量、K 为资本存量。短期 `Y=f(N,K̄)`（K 与技术不变）；长期 `Y*=f(N*,K*)`（三者都可变）。
- **AS 曲线（总供给函数）**：总产量与一般价格水平之间的关系；横轴 Y、纵轴 P。
- **推导三步（所有 AS 曲线的统一骨架）**：① 劳动市场（`N_d` 是实际工资 W/P 的减函数、`N_s` 是增函数）定就业量 N；② 生产函数 `Y=F(N)` 把 N 译成 Y；③ 让 P 变动，看 W 跟不跟、跟多快，W/P 落在何处 → 得 `(Y,P)` 组合。
  - 教材用"图形转换"四联图完成：劳动市场 → 生产函数 → 45° 线把纵轴 Y 转到横轴 → 价格-产出平面。**斜率的分水岭只有一个：货币工资 W 能否随 P 调整、调得多快。**

### 六、三种 AS 曲线（★★★★）

- **凯恩斯主义总供给曲线（短期极端｜水平）**
  - 假设：① **货币工资刚性**——人们抵制 W 下降、欢迎 W 上升，故 W 只能升不能降；② **货币幻觉**——只盯票面数值，不抵抗"W 不变而 P 上升"造成的实际工资下降，却抵抗"P 不变而 W 下降"造成的同样后果。
  - 推导：设充分就业为 `(W/P₀, N₀)`。若 `P>P₀` 而 W 不变，W/P 低于均衡 → `N_d>N_s` → 企业争雇抬高 W，直到 W/P 回到原水平 → 仍为 `N₀、Y₀`，故 **`P≥P₀` 段是位于 `Y₀` 的垂线**。若 `P<P₀`，W/P 偏高 → `N_s>N_d`，但 W 降不下来 → 企业按利润最大化只雇 `N₂<N₀` → `Y₂<Y₀`，故 **`P<P₀` 段向左下方倾斜**。
  - **完整形状 = 倾斜段 + 垂直段**；教材再把倾斜段**近似为水平线**，得到**反 L 形**（水平段 + 垂直段），称简化的凯恩斯主义总供给曲线，也叫**凯恩斯萧条模型**：到达 `Y_f` 之前可按大致不变的价格提供任意产量，越过 `Y_f` 后产量不再增加，只出现通货膨胀。
  - 政策含义：`Y<Y_f` 时扩张性财政/货币政策能增加产出而价格基本不动。
- **古典（长期）总供给曲线（垂直）**
  - 假设：长期中人们掌握价格变化的充分信息，**W 与 P 完全伸缩**，劳动市场出清。
  - 推导：`P↑ → W` 同比例↑ → W/P 不变 → `N=N_f` → `Y=Y_f`。故 AS 是位于**潜在产量（充分就业产量）**上的垂线。
  - 政策含义：产出独立于价格，刺激需求只推高价格，甚至引发通货膨胀。
- **常规（短期）总供给曲线（右上倾斜）**
  - 假设：W 与 P 的调整介于两个极端之间——**黏性**、调整缓慢（合同、预期滞后）。
  - 机制：`P↑ → W/P` 短期下降 → 企业多雇劳动 → `Y↑`。于是斜率大于零，**数量调节与价格调节并存**。
  - 政策含义：需求↑ → `Y↑` 且 `P↑`；越靠近 `Y_f`，价格涨得越多、产量增得越少。
- **三段合一**（教材图12-13 的读法）：横轴 Y、纵轴 P，自左向右依次是**凯恩斯区域（水平，价格刚性、只有数量调节）→ 中间区域（右上倾斜，数量调节与价格调节并存）→ 古典区域（垂直，只有价格调节）**。看到 AS 的形状，就能判断经济处在什么状态、政策还有没有产量效果。

### 七、AS 曲线的变动（供给冲击）

- **技术进步**：AS 右移（题库选择题：**短期与长期 AS 都右移**）。它同时提高平均与边际劳动生产率，使劳动需求曲线与生产函数一并上移，右移幅度更大。
- **劳动需求增加**（资本存量↑ → 边际劳动生产率↑ → 劳动需求↑）：AS 右移。
- **劳动供给增加**（人口、劳动意愿↑）：AS 右移；若收入提高后更重视休闲、劳动供给减少，则 AS 左移。
- **统一说法**：凡引起生产函数或劳动市场变化的**供给冲击**都会移动 AS；政府若在资本投入、劳动投入、劳动生产率、技术进步上给激励（**扩张性供给政策**），AS 右移、总供给水平提高。
- **方向读法**：AS **右移＝同一价格下能供给更多**（也写作"下移"）；AS **左移＝同一产量要求更高价格**（也写作"上移"）。两种说法指同一件事，别把"上移"误读成产量增加。

### 八、AD-AS 模型：均衡 `(Y,P)` 的决定（★★★★★）

- **模型**：联立 `AD: Y=f(P)`（常见形如 `Y=a+b/P`）与 `AS: Y=g(P)`（常见形如 `Y=c+dP`），解出均衡价格 `P*` 与均衡产出 `Y*`。
- **图形**：横轴 Y、纵轴 P；AD 右下、AS 右上，交点 E 即 `(Y*,P*)`。这就是"总需求与总供给同时均衡"。
- **三类模型**：
  - **一般情况**（AS 右上倾斜）：供求双方的力量都能改变 Y 与 P。
  - **极端短期（萧条模型）**（AS 水平）：P 基本不动，**Y 完全由 AD 决定**——需求管理对产量最有效。
  - **极端长期（古典）**（AS 垂直）：**Y 固定在 `Y_f`**，AD 变动只改变 P——需求政策只有价格效应。
- **与 IS-LM 的差别（一句话）**：IS-LM 定 `(Y,r)`；AD-AS 定 `(Y,P)`，因此才谈得上通货膨胀与滞胀。

### 九、AD-AS 模型对外来冲击的反应（★★★★）

**（1）需求冲击——沿给定的 AS 移动均衡**

- 冲击源：消费、投资、政府支出、净出口、货币供给的变动；财政与货币政策是其中最主动的一类。
- **短期极端（AS 水平）**：AD 右移 → `Y↑`、**P 不变**。教材的财政扩张例：AD→AD′，均衡由 E 到 E′，只提高产量与就业。**但货币政策在此无效**：萧条时投资盈利差、投资对利率几乎不敏感，又存在"流动性陷阱"，AD 近乎垂直，M↑ 推不动 AD，产量不变。
- **长期极端（AS 垂直）**：AD 右移 → **P↑、Y 不变**。机制：需求增加 → 充分就业下无多余劳动 → 企业争雇抬高工资与成本 → 索取更高价格 → 均衡沿 AS 上移，直到涨价把实际货币存量 `M/P` 吞掉、r 回升、支出回落到与 `Y_f` 相符。
  - **货币中性（neutrality of money）**：长期中 M 增 x%，P 也升 x%，`M/P`、r、Y 全不变。教材特别指出，AD 上移的距离与名义货币增加**同比例**。
- **一般情况（AS 右上倾斜）**：AD 右移 → `Y↑` 且 `P↑`；且**越往 `Y_f` 靠，价格上升的比例越高于产量上升的比例**——这就是"接近充分就业时扩张政策主要在制造通胀"的模型表达。
- **动态调整**：本期价格由上一期的产量与总需求决定；给定价格，总需求决定均衡产出。均衡产出低于潜在产出 → 企业降价 → 需求↑；高于潜在产出 → 企业提价 → 需求↓；一轮不够就继续，**收敛回潜在产出**。价格与产量交替调整，构成总需求调整的动态过程。

**（2）供给冲击——移动 AS 本身**

- **不利供给冲击**（进口原材料与石油涨价、工资推动、灾害、产能破坏）：AS 左移 → **P↑ 且 Y↓**，即**滞胀（stagflation）**。
  - 教材机制：企业要生产与以前相同的产量，必须能接受更高的产品价格，故 AS 上移；即便经济中存在过剩产能（交点落在 AS 的水平部分），价格仍由 `P₀` 升到 `P₁`。
  - 教材案例：1973 年 OPEC 限制石油输出 → 油价暴涨 → 高度依赖石油的企业成本上升 → AS 左移 → 更高价格 `P₁` 与更低产量 `Y₁`。这正是"以价格变动代表供给冲击"的合理性所在（教材思考题③）。
- **有利供给冲击**（技术进步、新能源、计算机与网络）：AS 右移 → `Y↑、P↓`，即 20 世纪 90 年代美国的"新经济"（高增长、低失业、低通胀）。
- **幅度取决于所处区段**：若初始在 AS 的**陡峭段**且 AD 缺乏弹性，AS 右移使价格明显下降；若在**平坦段**（大量过剩产能），新增产能对均衡产量与价格的影响都很小。
- **极端模型对供给冲击的反应**：短期极端模型（水平 AS）**不作反应**——萧条期价格已到底、且很少遇到供给冲击；长期极端模型 AS 虽垂直，但遇大技术进步、石油危机、大灾害时**垂线本身会移动**（右移增产、左移减产）。

### 十、教材评析（本章立场，简）

- **正面**：AD-AS 兼顾供求，既解释收入决定也解释价格决定；既讲萧条与通胀，也讲滞胀；既有短期非充分就业，也有长期充分就业。萨缪尔森称其为"理解价格与国民产值总体变动的核心方法"。
- **局限（三点）**：① 宏观上并不存在可加总的"总供给曲线"——产品与服务多样化，**只能加总价值、不能加总数量**；② 同理不存在可加总的"总需求曲线"；③ 只看总量、看不到**结构**，对结构失调无能为力。
- **三模型比较**：三者都能定均衡国民收入；AD-AS 多出价格水平与供给面；IS-LM 只强调总需求，且流量（IS）与存量（LM）混在一个平面上，均衡点唯一性可疑；简单凯恩斯模型只讲需求，还忽略开放性。借鉴时须先交代假设与适用范围。

## Key Concepts / 核心概念

- **总需求函数（aggregate demand function）**：产出与价格水平之间的关系，表示产品市场与货币市场同时均衡时每个价格水平对应的均衡产出。
- **总需求曲线（AD curve）**：总需求函数的几何表示，横轴 Y、纵轴 P，向右下方倾斜。
- **利率效应（interest-rate effect）**：价格与利率同向、利率与投资和收入反向，故价格与产出反向。
- **实际余额效应（real balance effect / 财富效应 / 庇古效应）**：价格上升使货币资产实际购买力下降、人们变穷、消费减少；并含"名义收入上升→税档上升→可支配收入下降"的税负渠道。
- **汇率效应（exchange-rate effect）**：价格上升使出口减少、进口增加（并鼓励对外投资），净出口与总需求下降。
- **宏观生产函数（aggregate production function）**：`Y=f(N,K)`，总量投入与总产出之间的关系；短期 K 与技术不变。
- **总供给曲线（AS curve）**：总产量与一般价格水平之间的关系，形状取决于货币工资与价格的调整速度。
- **凯恩斯主义总供给曲线**：货币工资刚性与货币幻觉下的短期 AS，简化后为反 L 形（水平段 + 垂直段）。
- **古典总供给曲线**：W、P 完全伸缩、劳动市场出清下的长期 AS，是位于潜在产量上的垂线。
- **潜在产量（potential output）**：现有资本与技术下，潜在就业量（自然失业率下的充分就业量）所能生产的产量，记 `Y_f`。
- **滞胀（stagflation）**：产量下降（停滞、失业上升）与价格上升（通货膨胀）并存，由不利供给冲击造成。
- **货币中性（neutrality of money）**：货币存量变动只改变价格等名义变量，产量、就业等实际变量不变——长期 AS 垂直的推论。

## Mental Models / 思维模型

1. **"P 是实际货币供给的分母"**：所有 AD 故事都是同一句话的不同说法——P 动了 `M/P`，货币市场失衡，r 调整，实际支出跟着动。记不住三个效应时，先问"它走的是 r、财富，还是汇率"。
2. **"AS 的斜率是工资调整速度的刻度盘"**：W 完全伸缩 → 垂直（古典）；W 刚性 + 货币幻觉 → 水平（凯恩斯）；介于中间 → 右上倾斜（常规）。一条曲线、三种制度假设；换假设不换骨架（劳动市场 + 生产函数）。
3. **"需求冲击沿曲线走，供给冲击推曲线走"**：需求冲击在给定 AS 上移动均衡，P 与 Y **同向**；供给冲击移动 AS 本身，P 与 Y **反向**。判断题型的第一把钥匙就是这条方向差。
4. **"长期是名义变量的等比缩放"**：AS 垂直时，M 增多少 P 就涨多少，实际变量原地不动。凡见"长期""已实现充分就业"字样，先套这条，就不会答出"扩张政策提高长期产出"。

## Anti-patterns / 常见错误

- **把 AD 画成右上倾斜**：AD 必向**右下**（`P↑→Y↓`）。只有 AS 才右上倾斜，且长期 AS 还是**垂直**的。
- **说"价格上升使 IS 右移"**：IS 用实际变量，P 变动**只移动 LM**（`P↑ → M/P↓` → LM 左移/上移）。
- **答"AD 为何右下"只写利率效应**：必须三条齐上——利率效应、实际余额效应（含税档渠道）、汇率效应；选择题标准答案是"以上都是"。
- **混淆"沿 AD 移动"与"AD 移动"**：P 变是沿曲线；IS/LM 其他因素（G、M、C、I、T…）变才是整条曲线平移。
- **把供给冲击的方向搞反**：不利供给冲击是 AS **左移** → `P↑` **且** `Y↓`（滞胀）。若答成"`P↑、Y↑`"，那是需求冲击的图形。
- **把"AS 上移"当成产量增加**：同一产量要求更高价格才是上移，等价于**左移**＝供给减少；右移（下移）才是供给增加。
- **认为凯恩斯 AS 全程水平**：完整形式是"倾斜段 + 垂直段"（反 L 形），水平只是把倾斜段近似掉；且倾斜段出现在 `P<P₀`，方向朝左下。
- **认为长期扩张政策能提高产出**：长期 AS 垂直，需求管理只改变 P（货币中性）；提高潜在产出只能靠 AS 右移（技术、资本、劳动、供给激励）。另注意 `Y_f` 是自然失业率下的充分就业产量、不是产量的物理上限——实际产量可短期超过它，代价是价格上升压力加大。

## Worked Example / 工作示例

**题**（教材思考题 6 ／题库计算题 3 同题）：`C=600+0.8Y`，`I=400−50r`，`G=200`；`L=250+0.5Y−125r`，名义货币供给 `M=1250`。求 (1) IS、LM；(2) 均衡 Y 与 r；(3) 若 `Y_f=5000`，用扩张性货币政策实现充分就业需增加多少 M；(4) 价格可变时的总需求函数；(5) 若 `AS: Y=2375+125P`，求均衡 `(Y,P)`。

**第 1 步 产品市场 → IS。** `Y=C+I+G=600+0.8Y+400−50r+200` → `0.2Y=1200−50r` → **`Y=6000−250r`**。

**第 2 步 货币市场 → LM（P=1）。** `M/P=L`：`1250=250+0.5Y−125r` → `0.5Y=1000+125r` → **`Y=2000+250r`**。

**第 3 步 联立求均衡。** `6000−250r=2000+250r` → `r=8`，`Y=6000−2000=`**`4000`**。代回 LM：`2000+250×8=4000` ✓

**第 4 步 充分就业所需货币量。** 先由 IS 定利率：`5000=6000−250r` → `r=4`。此时 `L=250+0.5×5000−125×4=250+2500−500=2250`。P=1 时需 `M=2250`，故**需增加 1000**。校验：货币乘数 `dY/dM=d/[h(1−b)+kd]=50/(125×0.2+0.5×50)=1`，`ΔY=1000` → `ΔM=1000` ✓

**第 5 步 放开价格 → 总需求函数。** LM 改为 `1250/P=250+0.5Y−125r` → `Y=2500/P−500+250r`；IS 给出 `250r=6000−Y`，代入消 r：
`Y=2500/P−500+6000−Y` → `2Y=5500+2500/P` → **`Y=2750+1250/P`**。
检验：`P=1` 时 `Y=4000`，与第 3 步一致 ✓；`dY/dP=−1250/P²<0`，右下倾斜 ✓

**第 6 步 与 AS 联立。** `2750+1250/P=2375+125P` → 两边乘 P 整理得 `125P²−375P−1250=0` → 除 125 得 `P²−3P−10=0` → `P=5`（舍 `P=−2`，价格不能为负）。
`Y=2375+125×5=`**`3000`**；代回 AD：`2750+1250/5=3000` ✓

**判读**：均衡 `(Y,P)=(3000,5)`，而 `Y_f=5000`——经济离充分就业还很远。此时若只扩张 AD，均衡会沿右上倾斜的 AS 移动：产量增一点、价格涨很多。**瓶颈在供给面**，要真正靠近 `Y_f`，须让 AS 右移（技术进步、资本与劳动投入、供给激励政策）。

## 解题套路 / Solution Patterns

- **题型一：名词解释**（总需求曲线、利率效应、凯恩斯总供给曲线、滞胀、宏观生产函数）
  - 步骤：① 一句话定义，点明"哪两个市场同时均衡"或"哪两个变量之间的关系"；② 给机制链条（利率效应写 `P↑→M/P↓→r↑→I↓→Y↓`）；③ 补一句形状或性质（右下倾斜／反 L 形／P 与 Y 反向）。
  - 易错：只给定义不给链条；"滞胀"只写成"通胀加衰退"，漏掉**供给冲击**这个成因。

- **题型二：求总需求函数**（计算题最高频）
  - 步骤：① 由 `Y=C+I+G+(X−M)` 求 IS；② 由 `M/P=L` 求 LM（**必须写 M/P，不能写 M**）；③ 两式消 r，得 `Y=f(P)`；④ 用 `P=1` 或 `dY/dP<0` 验算。
  - 易错：LM 里漏掉 P；消元不干净、把 r 留在答案里；IS 未化成 `Y=` 就与 LM 硬联立导致错位。

- **题型三：AD-AS 联立求 `(Y,P)` 并判断充分就业**
  - 步骤：① 令 AD=AS，整理成 `aP²+bP+c=0`；② 解出正根（**舍负根**，价格不能为负）；③ 代回任一曲线求 Y，再用另一条交叉验算；④ 与 `Y_f` 比较 → 未充分就业则建议扩张性财政/货币政策，或指出 AS 侧瓶颈需供给政策。
  - 易错：不舍负根；只算 P 不算 Y；判断完不给政策。

- **题型四：简答/作图"AD 为何右下"或"AD 如何推导"**
  - 步骤：① 先给 AD 定义（两个市场同时均衡）；② 三条效应各一条链（利率／实际余额含税档／汇率）；③ 若是推导题，补 IS-LM 两栏转换：P↑ → LM 左移 → 交点沿 IS 上移 → Y↓ → 连点成线；④ 收尾一句"**P 只移动 LM，不动 IS**"。
  - 易错：只写一条效应；把 LM 的移动方向说反（P↑ 时 LM 左移/上移）。

- **题型五：冲击分析（论述题主线）**
  - 步骤：① 定性——冲击来自 AD 还是 AS；② 说明曲线移动方向及其原因；③ 读 `(P,Y)`：同向 = 需求冲击，反向且 `Y↓P↑` = 滞胀 = 供给冲击；④ 分短期与长期（长期回到 `Y_f`，只剩价格变化）；⑤ 政策：需求冲击用需求管理，供给冲击要讲"扩张需求会加剧通胀"的两难，落到供给政策。
  - 易错：两类冲击方向混用；忘长期调整；把 70 年代滞胀归因于需求不足（它是 AS 左移）。

- **题型六：比较题**（IS-LM 与 AD-AS；古典与凯恩斯 AD-AS；微观供求与宏观 AD-AS）
  - 步骤：按四栏对比——**假设（价格是否可变）→ 涉及市场 → 决定什么变量 → 政策效应（有无价格效应）**，末尾补一句联系（AD 由 IS-LM 推出，故 AD-AS 是 IS-LM 的"价格可变版"）。
  - 易错：只说区别不说联系；把 AD-AS 说成"三市场均衡"却漏掉劳动市场。

## Key Takeaways / 关键结论

1. **AD 是 IS-LM 在价格可变时的轨迹**：`P↑→M/P↓→LM 左移→r↑→I↓→Y↓`，故右下倾斜；三个效应（利率、实际余额含税档、汇率）是这条斜率的机制解释。
2. **P 只移动 LM，不移动 IS**——IS 用实际变量。这是 AD 推导中最容易被扣分的一句。
3. **AD 移动 ≠ 沿 AD 移动**：P 变是沿曲线；C、I、G、T、M、NX 变才平移。扩张性财政与扩张性货币**都**使 AD 右移。
4. **AS 的形状 = 工资与价格调整速度的函数**：刚性 + 货币幻觉 → 水平（凯恩斯）；完全伸缩 → 垂直（古典）；中间 → 右上倾斜（常规）。三段合起来就是"凯恩斯区域—中间区域—古典区域"。
5. **AD-AS 的唯一增量是同时定出 `(Y,P)`**：这是它能讲通胀、滞胀，而 IS-LM 不能的原因。
6. **需求冲击 P 与 Y 同向，供给冲击 P 与 Y 反向**；后者即滞胀，也是"以价格变动代表供给冲击"之所以合理。
7. **长期 AS 垂直 → 货币中性**：需求管理只改 P；想提高潜在产出只能让 AS 右移（技术、资本、劳动、供给激励）。

## Connects To / 与其他章节的联系

- **第11章（IS-LM 模型）**：本章的 AD 就是它的"价格可变版"。LM 的斜率（h、k）与 IS 的斜率（d、乘数）共同决定 AD 的斜率——h 越小，AD 越平坦。
- **第10章（收入-支出模型与乘数）**：决定 AD 水平位置的支出乘数；扩张财政右移 AD 的幅度要扣掉挤出。
- **上册第3章（生产函数）与第6章（劳动市场）**：教材明说 AS 的推导基础在此——`Y=F(N)` 与 `N_d、N_s` 对实际工资的反应。
- **第9章（宏观经济基本指标）**：产出、失业率的口径与"潜在产量"这条基准线来自该章的核算框架——长期 AS 就画在这条线上。
- **第13章（失业、通货膨胀和经济周期）**：自然失业率、滞胀、需求拉动型与成本推动型通胀在此接上；AD-AS 与菲利普斯曲线是同一枚硬币的两面（产量-价格平面 vs 失业-通胀平面）。
- **第14章（开放经济）**：净出口是 AD 的构成项，汇率效应即由此而来；开放条件下的政策效果还要叠加汇率与资本流动。
- **第15章（宏观经济政策）**：需求管理政策的有效性完全取决于 AS 处于哪一段——水平段有效于产量，垂直段只剩通胀。
- **数学工具**：IS-LM 联立是二元一次方程组；AD 是隐函数 `Y(P)` 的显式求解与 `dY/dP` 的符号判断；AD-AS 均衡是二次方程求解并**舍去负根**（价格的经济学约束）。
