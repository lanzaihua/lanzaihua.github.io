# 第3章 企业的生产和成本 (Production and Cost)

> 马工程《西方经济学》(第二版) · 上册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

上一章问"消费者怎么选"，本章问"生产者怎么选"，几何完全同构：等产量线对无差异曲线、等成本线对预算线、`MRTS=w/r` 对 `MRS=P₁/P₂`。技术一侧由生产函数定出 TP/AP/MP 的形状与三个阶段，成本一侧把技术关系翻成"产量—成本"关系，短期成本曲线全是产量曲线的镜像（`MC=w/MP_L`、`AVC=w/AP_L`），长期则由规模经济定出 U 形 LAC。核心一句：**边际报酬递减决定短期一切曲线，规模报酬由递增转递减决定长期一切曲线**，两者不可互换。

## Frameworks Introduced / 核心框架

### 一、企业及其目标（★）

- **三种形式**：个人独资（**无限责任**）、合伙制（**无限连带责任**）、公司（**法人财产权**，股东以出资额为限担责）；数量上独资与合伙占多数，销售额上公司制占大头。
- **利润最大化**：`π=TR−TC`。三条约定：价格由市场需求定、**销售量=产量**（略去库存）、成本只取决于产量，对第三方的成本（污染）留第8章。批评者主张企业求**令人满意的利润**、受**委托-代理**制约，另有销售收益最大化与增长最大化等替代假设，但主流仍以利润最大化为起点。

### 二、生产函数（★★）

- **定义（式3.1、3.2）**：`Q=f(L,K)`。三要点：**技术水平不变**、给出**最大产量**、隐含技术有效率且函数为**单值**。要素价格依次为工资率 w、租金率 r、地租、企业家才能报酬；要素配合比例即**技术系数**。
- **短期与长期**：唯一判据是**能否调整全部要素**，至少一种固定即短期。**无固定时间长度**：造汽车厂两年内是短期，早餐亭两天即长期。
- **固定比例函数（式3.4）**：`Q=A·min{L/a, K/b}`，两要素**完全不替代**，等产量线为直角折线；"1 车配 2 司机"即 2:1，单加司机或单加车都不增产。
- **柯布-道格拉斯（式3.5、3.6）**：`Q=A·L^α·K^β`，`0<α,β<1`；`lnQ=lnA+αlnL+βlnK` 可线性化。**A 为技术系数**，**α、β 是劳动与资本的产出弹性**（教材引美国制造业估算 `α≈0.75`、`β≈0.25`）。

### 三、短期生产函数（★★★★）

- **三个概念（式3.7—3.9）**：`TP_L=f(L,K̄)`；`AP_L=TP_L/L`；`MP_L=ΔTP_L/ΔL=dTP_L/dL`。MP 是 TP 的**斜率**，AP 是原点射向 TP 的**割线斜率**。
- **表3-1 的形态**（10 亩地、农机固定，L 由 0 到 8）：MP 由 1000 升至 **1500**（L=2），再经 1000、800、400 连续降至 100、**0**（L=7）、**−100**（L=8）；TP 达最大 **4800**（L=7）后回落；AP 在 L=2 见顶 1250 后降至 587.5。**三条曲线的全部特征都由这一组数长出来**。
- **边际报酬递减规律**：技术不变、其他要素不变，连续增加一种可变要素，**最初**边际产量递增，超过某点后**递减**。三个条件：① 技术不变（技术进步可使规律失效，如杂交水稻）；② 其他要素投入量不变（同时扩地则 MP 未必递减）；③ 递减**只发生在可变投入增加到一定程度之后**——可变投入少时固定要素相对过剩，加人让设备用得更充分；越过最佳配比后固定要素相对不足，MP 必降。
- **四条曲线关系**：① MP 在 `L₀` 最大、`L₂` 为零、其后为负；② TP 走向看 MP 符号——`MP>0` 升、`MP<0` 降、`MP=0` 处 TP 最高，拐点在 `L₀`；③ AP 恒为正，在射线与 TP 相切处最大（`L₁`）；④ **MP 与 AP 必交于 AP 最高点**——`MP>AP` 把 AP 拉上、`MP<AP` 把 AP 拉下，交点只能是 `L₁`。
- **三个阶段**：Ⅰ `(0,L₁)`：`MP>AP`，AP 递增，固定要素相对过多，属**不合理区**；Ⅱ `[L₁,L₂]`：`0<MP<AP`，AP 递减而 TP 仍升，是**合理投入区**；Ⅲ `(L₂,+∞)`：`MP<0`，TP 下降。
- **两个边界的判据**：`L₁` 是 **AP=MP 且 AP 最大**处（不是 MP 最大处），`L₂` 是 **MP=0 且 TP 最大**处。第二阶段只给**范围**：w 越高越靠近 `L₁`，w 越低越靠近 `L₂`，但绝不越过。

### 四、长期生产函数（★★★★）

- **等产量线（式3.10）**：`f(L,K)=Q₀`。四性质：① 无数条，**离原点越远产量越大**；② **两两不相交**；③ **向右下倾斜**，但仅在**合理投入区**内成立——边界是切线水平的点（`MP_L=0`）与切线垂直的点（`MP_K=0`）连成的脊线；④ **凸向原点**，由 MRTS 递减决定。
- **边际技术替代率（式3.11、3.12）**：`MRTS_{L,K}=−ΔK/ΔL|_{Q不变}=MP_L/MP_K`，几何上为等产量线斜率绝对值。推导：A→B 拆成 A→C（只减 K）与 C→B（只加 L），由 `MP_L·ΔL+MP_K·ΔK=0` 移项得；**与 MP_L 成正比、与 MP_K 成反比**。脊线上 `MP_L=0` 处 MRTS=0、`MP_K=0` 处 MRTS→∞——**长期合理区排除任一要素边际产量为负，与短期三阶段边界是同一件事**。
- **MRTS 递减规律**：L 增则 `MP_L` 降、K 减则 `MP_K` 升，分子降分母升，比值必降，曲线越来越平缓，这就是凸向原点。
- **两特例**：`Q=aL+bK`（式3.13）**完全替代**，等产量线为直线、`MRTS=a/b` 恒定；固定比例函数**完全不替代**，顶点处 MRTS 由 0 跳到 ∞。
- **等成本线（式3.14）**：`C=wL+rK`，斜率 `−w/r`，截距 `C/r` 与 `C/w`。C 变则平行移动；w 变则绕纵截距**旋转**（w 降逆时针）——与预算线同构。
- **生产者均衡（式3.15—3.19）**：成本既定求产量最大用 `MRTS=w/r` 加 `wL+rK=C`；产量既定求成本最小用 `MRTS=w/r` 加 `f(L,K)=Q₀`。**两种约束同一条件**，等价写法 `MP_L/w=MP_K/r`：每元钱花在任何要素上买到的边际产量相等（左为技术换算率、右为市场换算率）。若 `MRTS=2>w/r=1`，则**增劳动减资本可免费增产**。
- **扩展线（式3.20—3.22）**：`π=P·f(L,K)−wL−rK`，一阶条件 `P·MP_L=w`、`P·MP_K=r`，相除即回到 `MP_L/MP_K=w/r`——**"最优要素组合"与"利润最大化"是同一条件**。要素价格不变时成本连续外移，各切点连成**扩展线**（一条等斜线）。

### 五、短期成本函数（★★★★）

- **两种成本观**：会计成本记**实际支出**；经济成本按**机会成本**衡量，`经济成本=显性成本+隐性成本`。**正常利润属隐性成本**，故 `经济利润=收益−经济成本` 是**超额利润**，必有 `会计利润>经济利润`。教材例：自有办公楼若出租可得 100 万元，这 100 万元即经济成本，会计账上却是零。
- **三组定义（式3.23—3.28）**：`TC=FC+VC`；`AC=TC/Q`、`AFC=FC/Q`、`AVC=VC/Q`，故 `AC=AFC+AVC`；`MC=ΔTC/ΔQ=ΔVC/ΔQ`——**FC 不随产量变，故 MC 只反映 VC 的变动率**。
- **七条曲线**：FC 为水平线；VC 自原点先缓后陡；TC 与 VC 同形、上移 FC；AFC 单调递减趋 0 但**永不为 0**；AVC、AC、MC 均为 **U 形**（AFC/AVC/AC/MC 的对应关系见速查表B）。
- **镜像推导（式3.29、3.30）**：仅劳动可变时 `VC=wL`，故 `AVC=wL/Q=w/AP_L`、`MC=ΔVC/ΔQ=w/(ΔQ/ΔL)=w/MP_L`。这两式是**产量与成本对偶的全部内容**：w 不变时 AVC 与 AP 反向、MC 与 MP 反向。
- **MC 与 AC、AVC 的相交（最易错）**：AC 下降时新增一单位成本低于原有平均，故 **MC 在 AC 下方**；AC 上升时 MC 在上方；故 **MC 必穿 AC 最低点**。同理由 MC 也是 VC 的变动率，**MC 必穿 AVC 最低点**。两交点不同位：AVC 最低点在 `Q₁`（AP 最大处），AC 最低点在 `Q₁` 之右——AC 还背着递减的 AFC，AVC 见底后 AC 仍可再降一段。
- **对偶清单**：`MP` 最大↔`MC` 最小；`AP` 最大↔`AVC` 最小且此时 `MC=AVC`；`TP` 拐点↔`TC/TVC` 拐点。把产量图横轴换成由 L 反解的 Q，整图翻转 180° 即成成本图。

### 六、长期成本函数（★★★★）

- **三概念（式3.31、3.32）**：长期全部要素可变，**无 FC 与 VC 之分**，只有 `LTC`（生产某产量的**最低**总成本）、`LAC=LTC/Q`、`LMC=ΔLTC/ΔQ`。
- **LTC 是 STC 的下包络**：厂房只有 K₁、K₂、K₃ 三种规模时，产 `Q₁` 若 `TC₁(Q₁)<TC₂(Q₁)` 则改选 K₁，故 `LTC(Q₁)=TC₁(Q₁)`。规模可无限细分时 STC 有无穷多条，LTC 取每一点的最低值：位于全部 STC 下方，且**每点都与某条 STC 相切**，切点即该规模的最优产量。
- **LAC 是 SAC 的包络，但不是 SAC 最低点的连线**（判断与简答的高频陷阱）：对每个产量，LAC 取**所有 SAC 中生产该产量成本最低者**的值，那条 SAC 自身是否见底无关紧要。故只有 **LAC 最低点**才与某条 SAC 的**最低点**相切；最低点以左切点在 SAC 最低点**左上方**（LAC 递减），以右在**右上方**。
- **LMC 与 LAC**：LMC 穿 LAC **最低点**；`LMC<LAC` 时 LAC 降，`LMC>LAC` 时 LAC 升；最低点处 `LAC=LMC=SAC=SMC`。
- **LMC 不是 SMC 的包络**：完全可能某条 SMC 整段落在 LMC 下方（该规模在该产量上并非长期最优）。正确联系是：LAC 与某条 SAC 相切处 LTC 与该条 STC 也相切、斜率相等，故该产量上 **`LMC=SMC`**——LMC 与各条 SMC 的**交点**才对应切点产量。
- **规模经济**：产量翻倍而成本增加**小于**一倍为规模经济，**大于**一倍为规模不经济。投入扩 λ 倍使产量变 μ 倍（式3.33），`μ>λ` 即规模报酬递增；n 次齐次函数（式3.34）则 `n>1` 递增、`n=1` 不变、`n<1` 递减；柯布-道格拉斯 `f(λL,λK)=λ^(α+β)·AL^αK^β`，故 **`α+β` 与 1 比大小即判规模报酬**。来源：分工、大型设备、多级生产、营销研发分摊；反向来源：层级增多致管理成本上升、分工过细降低效率。
- **LAC 为 U 形与 SAC 的理由不同**：规模小时规模经济占主导、LAC 降；规模过大后规模不经济占主导、LAC 升，**不能用边际报酬递减解释**（该规律要求其他要素固定）。LAC 的**位置**由外在经济/外在不经济与学习效应决定，与形状无关。
- **范围经济**：`SC=[C(X)+C(Y)−C(X,Y)]/C(X,Y)`，`SC>0` 为范围经济、`<0` 为范围不经济、`=0` 为无影响。

## Key Concepts / 核心概念

- **生产函数（production function）**：技术不变时，要素投入量与所能生产的最大产量之间的关系。
- **短期/长期（short run / long run）**：按能否调整**全部**要素划分，不看时间长短。
- **TP / AP / MP**：`TP=f(L,K̄)`、`AP=TP/L`、`MP=ΔTP/ΔL`；MP 是 TP 斜率，AP 是原点割线斜率。
- **边际报酬递减规律（law of diminishing marginal returns）**：技术与其他要素不变时，可变要素增加到一定程度后其边际产量递减。
- **等产量线（isoquant）**：技术不变时生产同一产量的两种要素所有组合的轨迹，右下倾斜且凸向原点。
- **边际技术替代率（MRTS）**：产量不变时增 1 单位一种要素可替代的另一要素数量，`MRTS_{L,K}=−ΔK/ΔL=MP_L/MP_K`。
- **生产者均衡（producer equilibrium）**：`MRTS=w/r`，即 `MP_L/w=MP_K/r`，等产量线与等成本线相切。
- **机会成本（opportunity cost）**：资源用于某用途而放弃的其他用途中的**最高**收入。
- **规模经济（economies of scale）**：产量翻倍而成本增加不足一倍；反之为规模不经济。
- **范围经济（economies of scope）**：多产品联合生产的成本低于分别生产之和。

## Mental Models / 思维模型

- **"边际拉平均"**：平均量的走向只由边际量与平均量的相对位置决定，与边际量自身升降无关——`MP>AP` 则 AP 升，`MC<AC` 则 AC 降。故"MC 已在上升"推不出"AC 也在上升"。
- **"先约束，后相切"**：所有生产者最优化都是"在约束线上找与目标曲线相切处"——约束给数量关系，相切给斜率相等，联立即解。同一模板在第2、7、10章反复出现，只换曲线。
- **"镜像对偶"**：成本世界是产量世界的 180° 翻转，`w/MP_L` 与 `w/AP_L` 就是切换开关：知道产量曲线形状，成本曲线不必重推；只给成本函数也能反推生产状态（MC 最小处即 MP 最大处）。

## Anti-patterns / 常见错误

- **把 AP 最大处当成 MP 最大处**：MP 最大在 `L₀`（TP 拐点），AP 最大在 `L₁`（MP 与 AP 交点），`L₀<L₁`；三阶段的第一个边界是 `L₁`，而不是"MP 开始递减处"。
- **由"MC 递增"推出"AC 递增"**：只有 `MC>AC` 时 AC 才升；`MC` 递增但仍小于 `AC` 时 AC 继续降（判断题原设陷阱）。
- **认为 AC 与 AVC 会相交或相切**：距离恒为 AFC，AFC 递减但恒正。
- **把 LAC 说成"所有 SAC 最低点的连线"**：包络≠最低点连线，LTC 也不是 STC 最低点连线。
- **把 LMC 说成 SMC 的包络线**：SMC 可整段落于 LMC 下方；两者关系只是"在 LAC 与 SAC 切点处相交且相等"。
- **用边际报酬递减解释 LAC 的 U 形**：该规律要求部分要素固定，长期不成立。
- **把会计利润当经济利润**：`经济利润=会计利润−隐性成本`；经济利润为零时企业仍得正常利润。
- **认为规模报酬不变则 MRTS 不变**：两者无逻辑关系，`α+β=1` 时 MRTS 仍递减。

## Worked Example / 工作示例

**题目**：某企业短期 `MC=3Q²−12Q+10`，且 `Q=5` 时 `TC=55`。求（1）`TC`、`TVC`、`AC`、`AVC` 函数；（2）平均产量最大时的产量与该产量下的平均成本。

**第一步　由 MC 积分还原 TC。** `TC=∫(3Q²−12Q+10)dQ=Q³−6Q²+10Q+FC`。积分常数就是**固定成本**——凡"给 MC 求 TC"都靠这一步。

**第二步　用已知点定 FC。** 代入 `Q=5`、`TC=55`：`125−150+50+FC=25+FC=55`，得 `FC=30`。故 `TC=Q³−6Q²+10Q+30`、`TVC=Q³−6Q²+10Q`。

**第三步　按定义求平均量。** `AC=Q²−6Q+10+30/Q`、`AVC=Q²−6Q+10`。校验 `AC−AVC=30/Q=AFC` ✓。

**第四步　把"AP 最大"译成"AVC 最小"。** 由 `AVC=w/AP_L`，w 不变时两者同解。一阶条件 `dAVC/dQ=2Q−6=0` 得 `Q=3`，二阶导 `2>0` 确认极小。

**第五步　用 MC=AVC 复核（最快判据）。** AVC 最低点必有 `MC=AVC`：`3Q²−12Q+10=Q²−6Q+10` ⇒ `2Q²−6Q=0` ⇒ `Q=3`（`Q=0` 舍）。两条路径同解，说明"AP 最大 ⇔ AVC 最小 ⇔ MC=AVC"这条链可靠。

**第六步　求 AC 并校验。** `AC(3)=9−18+10+30/3=11`。**答案：Q=3 时 AC=11。**
`MC(3)=27−36+10=1`、`AVC(3)=9−18+10=1`，相等 ✓；`MC(3)=1<AC(3)=11` 且 `dAC/dQ=2Q−6−30/Q²=−1.33<0`，AC 仍在降 ✓——**这正是"AVC 已见底、AC 尚未见底"的实例**。

## 解题套路 / Solution Patterns

**题型一：名词解释（MRTS、规模报酬、边际报酬递减、机会成本、经济利润、扩展线）**

固定四段：**定义 → 公式或几何刻画 → 成因/机制 → 一句辨析**。例"MRTS"：产量不变下增 1 单位 L 可减的 K 量 → `MP_L/MP_K` → 递减源于 `MP_L` 降而 `MP_K` 升 → 与消费者 MRS 同形而不同义。易错：漏负号；把"MRTS 递减"与"边际报酬递减"混为一谈；规模报酬题忘记强调**属长期**、要素须**同比例**变化。

**题型二：简答——三阶段如何划分、为何选第二阶段**

① 声明前提（技术与其他要素不变、只有 L 可变）；② 用**两条边界**分段：`L₁` 处 `AP=MP` 且 AP 最大，`L₂` 处 `MP=0` 且 TP 最大；③ 逐段否证——Ⅰ 段 `MP>AP`，继续加人还能提高平均产量；Ⅲ 段 `MP<0`，加人反而减产；④ 收口：Ⅱ 段 `0<MP<AP` 且 TP 仍在增，具体点位由 w 与 P 决定。加分：`w=0` 则用至 `MP=0`（`L₂`）；`r=0` 则资本免费，把劳动压到 Ⅱ 段起点 `L₁`。

**题型三：简答/辨析——两条 U 形与包络线的三个陷阱**

识别："SAC 与 LAC 的 U 形成因是否相同""LAC 是否切于所有 SAC 最低点""LMC 是否为 SMC 的包络"。模板：先分因（SAC 由边际报酬递减、LAC 由规模经济转不经济），再定切点（仅 LAC 最低点切于 SAC 最低点，左侧切于左上方、右侧切于右上方），最后给联系（LTC 与 STC 相切处 `LMC=SMC`）。

**题型四：计算——已知生产函数求最优组合与最小成本**

给 `Q=f(L,K)` 与 w、r。① 求 `MP_L`、`MP_K`；② 由 `MP_L/MP_K=w/r` 得 K 与 L 的比例；③ 代入约束式解出数量；④ 代回成本式。拉格朗日等价：`F=wL+rK+λ(Q₀−f(L,K))`。**C-D 速算**：`Q=L^aK^b` 下必有 `wL/rK=a/b`。易错：把 `MP_L/MP_K` 写成倒数；约束式用错（问成本最小时约束是产量）。

**题型五：计算/论述——生产函数与成本函数互推（含对偶性）**

**正向**：长期用 `MP_L/MP_K=w/r` 解出 `L(Q)`、`K(Q)`，代入 `C=wL+rK` 得 LTC，再除 Q 得 LAC、求导得 LMC；短期给定 `K=K̄`，由生产函数反解 `L(Q)`，得 `STC=wL(Q)+rK̄`。**反向**：给 MC 积分得 TC（补 FC）；求"AP 最大"令 `dAVC/dQ=0` 或 `MC=AVC`；求"MP 最大"令 `dMC/dQ=0`。**对偶论述**：`TC=TVC+TFC=wL(Q)+TFC` → `MC=w/MP_L`（MP 最高点即 MC 最低点）→ `AVC=w/AP_L`（AP 最高点即 AVC 最低点且 `MC=AVC`）→ 两图互为 180° 镜像。易错：积分漏常数；把 MC 最小值误当 AC 最小值；短期题漏掉 `rK̄`；论述只写结论不给推导链。

## Key Takeaways / 关键结论

1. **短期与长期只按"能否调整全部要素"划分**，与日历时间无关；短期必有固定成本，长期没有。
2. **三阶段的两条边界是 `AP=MP`（AP 最大）与 `MP=0`（TP 最大）**；第二阶段只给范围，最优点还取决于 w 与 P。
3. **平均曲线的拐点全由边际量穿过造成**：MP 穿 AP 于 AP 最高点，MC 穿 AVC 与 AC 于各自最低点；AC 最低点在 AVC 最低点之右。
4. **生产者均衡只有一个条件**：`MRTS=MP_L/MP_K=w/r`，即 `MP_L/w=MP_K/r`；两种约束给出同一结果，且与 `P·MP_L=w`、`P·MP_K=r` 的利润最大化一致。
5. **`MC=w/MP_L`、`AVC=w/AP_L` 是产量与成本之间的桥**：MP 最高点即 MC 最低点，AP 最高点即 AVC 最低点。
6. **LAC 是 SAC 的包络而非最低点连线，LMC 更不是 SMC 的包络**；仅 LAC 最低点处 `LAC=LMC=SAC=SMC`。
7. **两条 U 形曲线的成因不可互换**：SAC 靠边际报酬递减，LAC 靠规模经济转规模不经济。

## Connects To / 与其他章节的联系

- **第2章（消费者选择）**：结构同构——无差异曲线↔等产量线、MRS↔MRTS、预算线↔等成本线、`MRS=P₁/P₂`↔`MRTS=w/r`；区别只在约束钉住效用还是产量。
- **第4—5章（市场结构）**：本章只造成本曲线，不说卖多少钱。第4章把 MC 与价格接上（`P=MC` 定产量、P 与 AC 比定盈亏），第5章讨论 `MR=MC`；没有 U 形 AC 与 MC，完全竞争企业的短期供给曲线与停业点无从谈起。第10章帕累托最优的生产条件 `MRTS^X=MRTS^Y` 亦直接沿用本章概念。
- **第7—8章（要素价格与市场失灵）**：`P·MP_L=w` 是要素需求的来源，其向下倾斜的原因就是边际报酬递减；本章刻意排除的生产外部成本，第8章以外部性补上，把"私人成本≠社会成本"作为失灵根源。
- **数学分析**：`MRTS=−(∂Q/∂L)/(∂Q/∂K)` 是隐函数求导；均衡是拉格朗日乘子法（λ 即"放松约束的边际价值"）；`MC=dTC/dQ` 与 `TC=∫MC dQ` 是微积分基本定理；包络线是包络定理的几何版（`dLAC/dQ=(LMC−LAC)/Q`，故 LMC 穿 LAC 最低点）。**线性代数**：齐次函数与欧拉定理（`α+β=1` 时 `MP_K·K+MP_L·L=Q`）、二阶条件（凸向原点 ⇔ 加边海塞矩阵负定）是"相切即最优"的保证。
