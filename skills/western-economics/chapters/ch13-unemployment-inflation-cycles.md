# 第13章 失业、通货膨胀和经济周期 (Unemployment, Inflation, and Economic Cycles)

> 马工程《西方经济学》(第二版) · 下册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

第12章的 AS-AD 只画产量与价格；本章换两个刻度盘重读同一台机器——横轴换成失业率 `u`、纵轴换成通货膨胀率 `π`，就得到菲利普斯曲线。三个"病"是一件事的三张面孔：失业是劳动市场没出清，通胀是价格水平持续上涨，周期是二者随时间的交替。主线：**短期 `u` 与 `π` 可互换（AS 倾斜），长期不能（AS 垂直，预期终会调整到位）；政策是否有效，只看它有没有骗过预期。**

## Frameworks Introduced / 核心框架

### 一、四种失业理论

失业＝处于法定劳动年龄、有劳动能力且有工作意愿却找不到岗位。四派分歧只在：这种"找不到"是常态还是故障？

- **古典（萨伊定律）**：供给自动创造需求，充分就业是始终存在的倾向。存在的只是**摩擦性失业**与**自愿失业**，属局部的、暂时的失调，不构成对劳动需求的不足。
- **凯恩斯**：承认**非自愿失业**（愿接受现行工资仍无岗位），根源是**有效需求不足**，微观基础为三大基本心理规律（边际消费倾向递减、资本边际效率递减、流动性偏好）同时压低消费与投资需求。图形：横轴 `Y`、纵轴 `AD`，45° 线与 `AD_f` 交于充分就业收入 `Y_f`；实际 `AD_0 < AD_f` ⇒ `Y_0 < Y_f`，二者之差即有效需求缺口。政策：国家干预。
- **新凯恩斯**：不问需求为何不足，问工资为何不降。以不完全竞争＋不完全信息为前提，用**工资黏性**解释非自愿失业。四条理由：**劳动工资合同论**（合同期内工资锁定、附生活费指数条款）、**隐含合同论**（风险回避的雇员与雇主达成工资稳定的默契）、**局内人-局外人理论**（培训由局内人承担，局内人抵制培训新人以保谈判地位，故只能新老同酬）、**效率工资理论**（高工资换队伍质量、努力程度与低流动率）。更朴素的工资刚性来源：最低工资法、工会垄断力量、效率工资。
- **现代货币主义**：**自然失业率假说**，否认 `u` 与 `π` 的长期替代。增发货币短期能骗出劳动供给（雇员未预见实际收入下降），长期价格涨上去、实际工资复原，失业不减而物价续涨。

对照：**古典说"没有失业"，凯恩斯说"需求不够"，新凯恩斯说"工资不降"，货币主义说"只有自然率"。**

### 二、自然失业率、周期性失业与奥肯定律

**自然失业率（natural rate of unemployment）**：没有货币因素干扰时，劳动力市场与商品市场的自发供求力量起作用、处于均衡状态下的失业率；等于**摩擦性＋结构性失业率**之和，此时即"充分就业"。三点必须说清：**是锚不是常数**（随劳动力市场组织、人口构成、救济制度、经济结构而变）；**决定因素两个**——失业**持续时间**（取决于周期与市场结构）与失业**频率**（一定时期内沦为失业者的平均次数），二者越高自然率越高；**充分就业 ≠ 零失业**，把失业压到自然率以下只会带来加速的通胀。

**周期性失业（cyclical unemployment）＝ 实际失业率 − 自然失业率**，源于总支出与产出下降、出现在萧条阶段，是唯一能被总需求政策消除的部分。

摩擦性 vs 结构性：前者"匹配需要时间"，失业者**能胜任**空缺；后者"技能、地点不匹配"，**失业与空位并存**，源于工资刚性，故更严重，只能靠培训、迁移、改善信息。

失业的影响三层：个人与家庭（收入中断、健康受损、声望下降）、社会稳定、经济发展（救济与税收的财政负担＋产出损失）。产出损失用机会成本度量：`失业的损失 = 潜在 GDP − 实际 GDP`。

**奥肯定律（Okun's law）**：失业率每高于自然失业率 1 个百分点，实际 GDP 将低于潜在 GDP 约 2 个百分点。`(Y − Y_f)/Y_f = −α(u − u*)`，`α > 0`；增长率形式 `ΔY/Y = 3% − 2Δu`（3% 为美国充分就业产出的平均增长率）。两条推论：GDP 未达充分就业时，实际 GDP 须与潜在 GDP **同速**增长才能不使失业率上升；想让失业率下降，实际增速必须**快于**潜在 GDP。`α` 是经验系数，因国因时而异。

### 三、通货膨胀：定义、度量与三型成因

通货膨胀＝一个经济体在一定时期内**价格水平普遍、持续地上升**。三个限定缺一不可：**总水平**（不是个别商品）、**持续**（不是一次性）、**达到一定幅度**。度量：`π_t = (P_t − P_{t−1})/P_{t−1}`，价格水平用 GDP 折算指数、消费者价格指数（CPI）或生产者价格指数（PPI）。**高价格 ≠ 通货膨胀**：前者是价格水平的**状态**，后者是**变化率**。

**① 需求拉上型（demand-pull）**：总需求超过总供给引起的一般价格水平持续显著上涨，即"过多的货币追逐过少的商品"。图形：横轴 `Y`、纵轴 `P`，`AS` 在 `Y < Y_f` 段水平，过 `Y_f` 附近转为向右上方倾斜，达充分就业产量后垂直；`AD` 沿此 `AS` 右移，价格由 `P₁` 升到 `P₄`，产量先增后止于 `Y_f`。**关键在最后一段：产量不变、只有价格上涨，这才是"真正的通货膨胀"。**

**② 成本推动型（cost-push）**：没有超额需求，仅因供给成本上升而涨价。图形：`AD` 不动，`AS` 左移，交点沿 `AD` 向左上方移动——**价格升、产量降**，即**滞胀**的标准图形。三个来源：**工资推动**（不完全竞争的劳动市场上工会集体议价，工资增长率超过生产率增长，形成"工资-物价螺旋"）、**利润推动**（垄断与寡头以超过成本上升的幅度提价）、**进口型**（进口原材料大涨，推高国内物价；程度取决于国内外价差、开放部门比重、政策灵敏度）。

**③ 结构型（structural）**：总供求大体平衡，仅因经济结构变动而涨价。两条机制：**需求结构的变动**（某些部门需求过度，经工资看齐传导至其他部门）、**各部门劳动生产率增速的差异**（工业快、服务业慢，但工资按"公平"同步上涨，慢部门成本持续上升）。

**④ 货币主义数量论**：`MV = PY`，取对数后对时间求导得 `π = m + v − y`（通胀率＝货币增长率＋流通速度变化率−产出增长率）。`V` 与 `y` 长期稳定 ⇒ **通胀主要源于货币供给过快**；弗里德曼称"通货膨胀是印钞机带来的现象"。

### 四、惯性、成本与再分配效应

**惯性／螺旋**：价格不是一次性跳升而是持续上升。图形：`AD` 右移（`AD₀→AD₁`）把 `P₀` 推到 `P₁`；工人据物价要求加薪，成本上升使 `AS` 左移（`AS₁→AS₂`）；加薪又抬高收入与需求，`AD₁→AD₂`；新 `AD₂` 与新 `AS₂` 之间仍有超额需求，循环重启。**一旦发生，成本推动与需求拉动就同时在场。**

**社会成本（预期到的）**：鞋底成本（减少货币持有、频繁跑银行）、菜单成本（重印价目表、换价签）、**税收扭曲**（名义资本利得被征税，实际收益为零仍要纳税）、价格体系中的"噪声"（名义涨价掩盖相对价格信号）。

**再分配效应（未预期到的）**，方向必须背准：**不利于固定收入者**（工薪层、公共雇员、领救济金与养老金者）；**不利于债权人、有利于债务人**（债务契约按签约时的预期通胀定名义利率，实际通胀更高则实际利率下降；银行存款人是债权人，故**储蓄者受损**，高通胀时实际利率甚至为负）；**对财产所有者未必不利**（实物财产升值、债务负担缩水）。

**产出效应**取决于两个维度："是否平衡"（各种价格是否同比例涨）与"是否预期到"。平衡且预期到 ⇒ 工资、利率、租金同比例调整，实际变量不变；非平衡且未预期到 ⇒ **分配、产出、就业全受影响**（四象限见速查表 C）。总规律：**越能被预期、越平衡，实际效应越小。**

### 五、菲利普斯曲线：三代形态与推导

- **原始版（1958，菲利普斯）**：据英国 1861—1957 年数据，失业率与**货币工资变化率**负相关；横轴 `u`、纵轴货币工资上涨率，曲线向右下方倾斜。
- **改造版（新古典综合派，萨缪尔森-索洛）**：用**通货膨胀率**替换货币工资上涨率，曲线仍在 `(u, π)` 平面向右下方倾斜。政策含义：一份"通胀-失业组合菜单"，政府可沿曲线取舍。
- **引申版（产出-物价）**：经奥肯定律用经济增长率替换失业率，得经济增长率与通胀率**同向**变动。

**菲利普斯曲线就是总供给曲线的另一种写法**（式 13.6→13.11）：`Y = Y* + α(P − P^e) + v`（13.6）⇒ `P = P^e + (Y − Y*)/α + v/α`（13.7）⇒ 两边减上期价格得 `P − P₋₁ = (P^e − P₋₁) + (Y − Y*)/α + v/α`（13.8）⇒ 令 `π = P − P₋₁`、`π^e = P^e − P₋₁`、`μ = v/α` 得 `π = π^e + (Y − Y*)/α + μ`（13.9）⇒ 用奥肯定律替换产出缺口 `(Y − Y*)/α = −β(u − u*)`（13.10）。

最终 `π = π^e − β(u − u*) + μ`，`β > 0`（13.11）。三项读法：**预期通胀**（决定曲线位置，预期上调则整条上移）、**周期性失业**（沿曲线移动）、**供给冲击**（不利冲击 `μ > 0`，曲线上移）。故它与 AS 曲线一样，描述的是**实际波动与未被预期到的价格波动**之间的关系。长期结论随即出来：预期正确时 `π = π^e`，代入得 `u = u*`——**无论通胀多高，只要被预期到，失业率就回到自然率**，曲线垂直。

### 六、短期与长期：适应性预期与理性预期

**适应性预期（adaptive expectations）**：按过去实际值与过去预期值的加权平均修正预期，只依赖该变量的历史信息；极端形式 `π^e = π₋₁`。

图形（横轴 `u`、纵轴 `π`）：初始 E 点 `u = u*`、`π = π^e = π₀`；通胀升至 `π₁` 而预期仍为 `π₀` ⇒ 实际工资下降而工人以为没降 ⇒ 就业增加、失业降到 `u₁`（**超充分就业**），到 F 点——E→F 即短期菲利普斯曲线 `PC(π^e = π₀)`。随后工人发现物价涨了，要求补足货币工资或减少劳动供给 ⇒ 失业升回 `u*`、预期上调至 `π₁`，到 A 点，过 A 又有 `PC(π^e = π₁)`。**连接 E 与 A 得垂直线**——长期菲利普斯曲线（LPC）：通胀从 `π₀` 升到 `π₁`，失业率仍是 `u*`。

**"不让通货膨胀加速的失业率"**：当 `π^e = π₋₁` 时 `π = π₋₁ − β(u − u*) + μ`，要让 `u < u*` 必须 `π > π₋₁`，即通胀**逐年加速**；若满足于 `u = u*` 且无供给冲击，则 `π = π₋₁`。故自然失业率又称**不让通货膨胀加速的失业率（NAIRU）**。政策含义：短期有效，长期无效，只换来更高通胀。

**理性预期（rational expectations）**：利用一切可得信息做最优处理求期望值，又称"与模型一致的预期"，"平均"而言正确、出错随机，**不存在系统性错误**。推论：政策可被预期 ⇒ `π = π^e` 立即成立 ⇒ `u = u*`，菲利普斯曲线**无论短期长期都垂直**，货币政策总体无效，等同于**货币中性在短期也成立**。卢卡斯：失业率不取决于通货膨胀，而取决于随机冲击。

### 七、通货紧缩与滞胀

**通货紧缩（deflation）**：与通胀相对，货币供应量少于流通所需，货币升值、物价普遍持续下跌。影响：加速衰退、财富缩水、分配负效应、可能引发银行危机。教材判断：比通胀**更难治理**（资产价格跌—财富缩水—需求再降的正反馈），主要靠调整优化产业结构、综合运用投资消费出口拉动。

**滞胀（stagflation）**：生产停滞、失业增加、物价居高并存。三类解释：①**菲利普斯曲线整体右移**（实际因素使自然失业率上升，或预期上调）；②**供给冲击**使 `AS` 左移；③**供给学派**：凯恩斯式扩张政策（高福利降低失业成本＋宽松货币）的结果。三者都表现为 PC 或 AS 上移。政策困境：紧缩则衰退加深，扩张则通胀加剧。

### 八、经济周期：定义、阶段与类型

**定义（伯恩斯与米切尔，1946《衡量经济周期》）**：以商业企业组织活动的国家的总体经济活动中所看到的波动——由几乎同时发生在许多经济活动中的扩张，以及随之而来的普遍衰退、收缩和与下一周期扩张相连接的复苏组成；反复出现但不定时；持续一年以上到十年或十二年。四个特征：市场经济不可避免；是**总体**波动而非局部；分**繁荣、衰退、萧条、复苏**四阶段（繁荣与萧条是主要阶段，衰退与复苏是过渡阶段）；长度差别很大。

**阶段特征**：繁荣＝高于正常水平，生产与投资增加、信用扩张、物价上升、就业增加，公众乐观；顶峰时就业与产出最高，但股价与商品价格已开始下跌、存货增加，情绪转悲观。衰退＝由顶峰下降但仍高于正常水平。萧条＝低于正常水平，投资减少、滞销、价格下跌、利润下降、信用紧缩、失业增加；谷底时就业与产出最低，但价格开始回升、情绪转乐观。复苏＝由谷底回升但仍未达正常水平。

**类型（熊彼特按持续时间归纳）**：**基钦周期**（短周期，2~4 年，源于存货变动，故称存货周期）、**朱格拉周期**（中周期，9~10 年）、**康德拉季耶夫周期**（长周期，50~60 年，平均约 54 年）。换算：**3 个基钦＝1 个朱格拉；18 个基钦＝1 个康德拉季耶夫**。

### 九、乘数-加速数模型（汉森-萨缪尔森）

**加速原理（acceleration principle）**：收入或消费需求的变动引起投资若干倍变动。前提两条：**不存在闲置过剩生产能力**、**资本-产出比不变**。核心式 `K_t = V·Y_t`，净投资 `I_t = K_t − K_{t−1} = V(Y_t − Y_{t−1})`，总投资 `G_t = D_t + I_t`。

五条含义（易考）：①投资是**产量变动率**的函数，不是产量绝对量的函数——产量按固定速率增长时投资总额不变；②投资率变动幅度**大于**产量变动率；③要保持投资不下降，产量必须**持续按一定比率**增长，增速放缓（哪怕产量仍增）也会引起投资缩减；④加速数与乘数一样**双向**起作用；⑤只有过剩生产能力全部消除时才正常发挥作用。

**周期机制**：外生冲击使总需求增加 → 乘数使产出加倍 → 产出增加要求资本存量增加 → 加速数带来投资 → 投资（相对上期）增加又通过乘数推高产出，扩张自我维持。但扩张**自动走向尽头**：投资增加的**幅度**递减（资本存量仍在增加，只是增量变小），一旦投资绝对减少，乘数反向作用使产出加倍收缩。**关键区分**：乘数讲"投资 → 收入"，加速数讲"收入 → 投资"。

### 十、实际经济周期理论（RBC）与 DSGE

**RBC（基德兰德与普雷斯科特，1982，属新古典）**：**根源**是**实际因素**而非货币因素——农业歉收、战争与政治动荡、人口增减、能源价格剧变、技术革新与新产品开发，其中最值得研究的是**技术冲击**。**传导机制**三条：**资本积累**（技术冲击影响新资本品形成，本期产量变动引起下期资本与产量变动）；**替代效应**（期内消费-闲暇替代＋跨期劳动替代：负向冲击降低工资，闲暇机会成本下降，人们减少劳动供给并用未来劳动替代今天，放大冲击）；**调整成本**（资本重置与劳动调整成本，使调整结果可能大于初始冲击）。

**性质**：微观基础、一般均衡（瓦尔拉斯）、动态随机、理性预期、偏离趋势仍是最优均衡（**不意味着无效率**）、打破长期与短期的二分法。**与凯恩斯、货币主义、理性预期的根本区别**：前三者都从**总需求**找波动原因，RBC 从**总供给（技术冲击）**找。

**DSGE 的两点修改**：①冲击既有实际因素也有货币因素，**货币非中性**；②存在各种不完善性，尤其工资与价格刚性（且**内生**，源于企业最优化），故波动在福利意义上意味着**资源配置缺乏效率**——与 RBC 的"仍有效率"正相反。

### 十一、本章评析（论述题的收尾）

西方四论都**在制度之外**找原因（自愿失业说、市场难出清说、只作现象描述），未触及资本主义制度缺陷：马克思把失业归为资本积累的必然产物（相对过剩人口是资本主义生产方式存在的一个条件），把周期归为生产社会化与私人占有制的矛盾（危机、萧条、复苏、高涨）。可借鉴者：失业率统计口径与结构性分析、人力培训与公共投资、周期的阶段划分与预测方法。

## Key Concepts / 核心概念

- **自然失业率（natural rate of unemployment）**：无货币因素干扰时，劳动与商品市场自发力量下均衡状态的失业率，等于摩擦性＋结构性失业率。
- **周期性失业（cyclical unemployment）**：实际失业率与自然失业率之差，源于总需求不足，可被扩张政策消除。
- **结构性失业（structural unemployment）**：劳动供求在技能、职业、地区上不匹配，**失业与空位并存**，不能靠扩大总需求解决。
- **非自愿失业（involuntary unemployment）**：愿意接受现行工资仍找不到工作，凯恩斯归因于有效需求不足。
- **奥肯定律（Okun's law）**：失业率每高于自然率 1 个百分点，实际 GDP 低于潜在 GDP 约 2 个百分点。
- **通货膨胀螺旋（inflationary spiral）**：工资与物价互为因果、交替上升，使通胀自我持续。
- **菲利普斯曲线（Phillips curve）**：`(u, π)` 平面上向右下方倾斜的曲线，表示短期失业与通胀的替代关系。
- **长期菲利普斯曲线（long-run Phillips curve）**：过 `u = u*` 的垂直线，表明长期不存在通胀-失业替代。
- **牺牲率（sacrifice ratio）**：通胀率每降低 1 个百分点所损失的 GDP 百分比。
- **加速原理（acceleration principle）**：`I = V·ΔY`，收入或消费需求的变动引起投资若干倍变动。

## Mental Models / 思维模型

- **"同一根 AS 曲线的两个投影"**：菲利普斯曲线的每次移动，都是 `(Y, P)` 平面上 AS 的一次移动。短期倾斜＝预期错了；长期垂直＝预期对了。看到"曲线移动"先问：是 AS 移了，还是预期移了？
- **"预期是唯一被治理的对象"**：扩张政策短期能降失业，全靠制造**未预期到**的通胀去压低实际工资；一旦被预期到，政策只剩涨价。判断"政策有效性"先问：能骗过预期吗、能骗多久？
- **"自然率是锚，不是常数"**：结构性因素移动锚，需求因素只在锚周围制造周期性波动。"降低失业"因此有两条路——移动锚（结构政策）与围绕锚（需求政策），不可混用。
- **"方向决定药方"**：需求拉上是 AD 右移（价格与产量同向升），成本推动是 AS 左移（价格升、产量降）。前者用紧缩需求，后者用收入政策与供给政策。

## Anti-patterns / 常见错误

- **把"长期菲利普斯曲线垂直"读成"长期没有失业"**：垂直的位置是 `u = u*`，长期失业率等于自然率，不是零。
- **把长期垂直的原因说成"长期价格有弹性"**：正确原因是**预期调整到位**（`π = π^e`）；价格灵活只是背景，机制是工人发现实际工资下降后重新议价。
- **需求拉上画成 AS 左移**：需求拉上是 AD 右移、沿 AS 移动，产量与价格同向；成本推动才是 AS 左移，二者产出方向相反。
- **未预期通胀的再分配方向搞反**：实际通胀**高于**预期时实际利率下降，**债务人获益、债权人受损**；低于预期才反过来。
- **把周期性失业等同于失业率本身**：周期性失业＝`u − u*`。若算出 `u = 16%`、`u* = 6%`，周期性失业只有 10 个百分点。
- **搞反乘数与加速数**：乘数是"投资变动 → 收入数倍变动"（说明收入的决定）；加速数是"收入变动 → 投资数倍变动"（说明投资的决定）。
- **以为扩张总需求能治结构性失业**：结构性失业是匹配失败，扩张只推高价格；摩擦性靠信息与服务机构，结构性靠培训与迁移。
- **把通货膨胀等同于高价格**：通胀是变化率、是总水平；高价格是水平、可指个别商品。

## Worked Example / 工作示例

**题目**：某经济的菲利普斯曲线为 `π_t = π_t^e − 3(u_t − u*)`，自然失业率 `u* = 5%`，预期为适应性预期 `π_t^e = π_{t−1}`。当前（第 t−1 期）通胀率 5%，央行宣布把下一年通胀目标定为 2%。求：(1) 实现目标当年的失业率；(2) 若次年继续维持 2% 目标，失业率是多少；(3) 这一过程的牺牲率；(4) 若预期改为理性预期，牺牲率是多少。

**① 定锚：先认出自然失业率。** 令 `π = π^e`，方程化为 `3(u − u*) = 0` ⇒ `u = u* = 5%`。这既是自然失业率，也是长期菲利普斯曲线的位置。

**② 第一年：预期是旧的，所以失业要上升。** 适应性预期下 `π^e = π_{t−1} = 5%`，目标 `π = 2%`，代入：

`2% = 5% − 3(u − 5%)` ⇒ `3(u − 5%) = 3%` ⇒ `u − 5% = 1%` ⇒ **`u = 6%`**

即通胀降 3 个百分点，需要失业率高出自然率 1 个百分点。

**③ 第二年：预期跟上了，失业回到自然率。** 此时 `π^e = π = 2%`，代入得 `2% = 2% − 3(u − 5%)` ⇒ **`u = 5% = u*`**。这就是"长期垂直"的具体算术：只要通胀被稳定在 2% 并被预期到，失业不需要任何代价就回到自然率。

**④ 牺牲率＝损失的 GDP ÷ 降低的通胀。** 用奥肯定律把失业换成产出：周期性失业 1 个百分点 ⇒ 实际 GDP 低于潜在 GDP 2 个百分点。故 `牺牲率 = 2% ÷ 3 ≈ 0.67`。读法：通胀每降 1 个百分点，要付约 0.67% 的 GDP；本题累计损失 2% 的 GDP。

**⑤ 理性预期的情形。** 若公众立刻相信央行并同步下调预期（`π^e = π = 2%`），第 ① 步直接给出 `u = u* = 5%`：**没有周期性失业，没有产出损失，牺牲率为 0**。这是"政策无效命题"的两面——可信的政策可以不付代价，但也就不能靠它降失业。

**⑥ 校验。** 回代：`u = 6%` 时 `π = 5% − 3 × 1% = 2%` ✓；`u = 5%` 时 `π = 2% − 0 = 2%` ✓。牺牲率是两个百分比之比，无量纲，写作 0.67 或 2/3，不要写成"0.67%"。

## 解题套路 / Solution Patterns

**题型一：名词解释（自然失业率、菲利普斯曲线、奥肯定律、四种失业理论）。** 四段式：**定义 → 构成或性质 → 机制 → 政策含义**。以自然失业率为例：无货币因素干扰时劳动与商品市场均衡状态的失业率 → 等于摩擦性＋结构性之和，是充分就业时的失业水平 → 由失业持续时间与失业频率决定 → 任何压低到其下的企图都带来加速通胀。答"菲利普斯曲线"必须点出**原始版是工资-失业、改造版才是物价-失业**，只答"通胀与失业负相关"丢一半分。

**题型二：计算——由菲利普斯曲线求自然失业率与所需失业率。** 两步：**令 `π = π^e` 解出 `u*`**；再代入目标通胀解 `u`。典型：`π_t = π_{t−1} − 0.5(u − 0.06)`，自然率 6%；要让通胀降 5 个百分点，需 `0.5(u − 0.06) = 0.05` ⇒ `u = 16%`，即**周期性失业 10 个百分点**（不是 16 个百分点）。易错：把解出的失业率直接当周期性失业；忘记 `π^e = π_{t−1}` 的"加速"含义。

**题型三：计算——牺牲率。** 三步串起来：菲利普斯曲线求出降通胀所需的周期性失业 → 奥肯定律（1 个百分点失业＝2 个百分点 GDP）换成产出损失 → 相除。易错：方向搞反（降通胀要**增加**失业）；把累计损失当牺牲率；忘答"理性预期下牺牲率为 0"。

**题型四：计算——加速数与净投资。** 步骤：`K_t = V·Y_t` 逐年算所需资本 → `I_t = K_t − K_{t−1}` → `G_t = D_t + I_t`。负净投资是允许的（资本存量下降），别不敢写。结论句要落到"净投资随产量**增量**同向变动，故总投资随产量增速放缓而下降"。

**题型五：论述——短期与长期菲利普斯曲线的区别。** 固定三段：**图形**（短期右下倾斜／长期垂直）→ **经济含义**（短期预期未调整故有替代；长期 `π = π^e`、`u = u*`，无替代）→ **政策含义**（短期总需求政策有效；长期无效，只推高通胀）。再补机制链：扩张 → 物价涨 → 实际工资降 → 就业增 → 工人发现并要求加薪 → 失业回升 → 预期上调 → 曲线整体上移 → 连接均衡点得垂直线。结尾补理性预期：连短期都垂直。

**题型六：论述——通货膨胀的成因与治理。** 三角度切入（总需求、总供给、预期），每个角度配一条政策与一项代价：需求面靠紧缩货币财政（代价是衰退与失业）；供给面陷入两难（恢复产出就得容忍更高通胀，压物价就得再减产）；预期面只能靠政策可信度重建（代价是过渡期动荡）。最后用菲利普斯曲线收口：`π = π^e − β(u − u*) + μ`，三项分别对应惯性、需求压力与供给冲击。

## Key Takeaways / 关键结论

1. **失业理论的分水岭是"劳动市场能否出清"**：古典否认非自愿失业，凯恩斯归给有效需求，新凯恩斯归给工资黏性，货币主义锁在自然率上。答题先报学派，再报机制。
2. **自然失业率＝摩擦性＋结构性失业率，是锚不是常数**；周期性失业＝`u − u*`，只有这一部分能被总需求政策消除。
3. **奥肯定律是失业与产出之间的汇率**：1 个百分点失业 ↔ 2 个百分点 GDP，它把菲利普斯曲线（`u` 空间）与 AS 曲线（`Y` 空间）接通。
4. **通胀三型看冲击方向**：AD 右移（产出与价格同向）／AS 左移（产出降价格升）／结构错位（工资看齐）。方向决定药方，药方决定代价。
5. **未预期通胀是一次任意的财富再分配**：债务人、非固定收入者、实物资产持有者获益；债权人、储蓄者、固定收入者受损。
6. **菲利普斯曲线短期倾斜、长期垂直，唯一变量是预期**；理性预期下连短期也垂直，货币政策无效。
7. **经济周期分两条解释路线**：需求侧（乘数-加速数、凯恩斯、货币主义）与供给侧（RBC 的技术冲击＋跨期劳动替代）；RBC 把增长与波动装进同一个一般均衡框架。
