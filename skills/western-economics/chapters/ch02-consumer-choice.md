# 第2章 消费者选择 (Consumer Choice)

> 马工程《西方经济学》(第二版) · 上册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

消费者手握既定收入、面对既定价格，要在"多买这个还是多买那个"之间找到一个不再想调整的位置——消费者均衡。全章用两套语言说同一件事：基数效用论比"最后一元钱买到的边际效用"（`MU/P = λ`），序数效用论看"无差异曲线与预算线相切"（`MRS₁₂ = P₁/P₂`）。目的是给第1章那条向下倾斜的需求曲线找行为基础；而这要求把价格变动拆成**替代效应**与**收入效应**，否则说不清为什么绝大多数商品的曲线向下、吉芬商品向上。

## Frameworks Introduced / 核心框架

### 一、效用论

- **效用**：消费商品、服务对欲望的满足程度，由主观评价决定，因人、因状态而异；不含伦理评价、是自我比较、不讨论负效用。
- **基数论 vs 序数论**：前者认为效用可用"尤特尔"度量、加总、人际比较，工具是边际效用；后者（希克斯）认为只能排序，用效用指数，工具是无差异曲线。序数论只取消"可计量"这一强假设，不改变结论。
- **TU 与 MU（式2.1、2.2）**：`TU=U(Q)`，`MU=ΔTU/ΔQ=U′(Q)`，MU 是 TU 的导数。`MU>0` 时 TU 递增但增速递减；`MU=0` 时 TU 最大（饱和点，切线水平）；`MU<0` 时 TU 递减。表2-1：6 盒时 MU=0、TU=30，第 7 盒 MU=−1、TU=29。
- **边际效用递减规律**：其他商品消费量不变，随该商品消费增加，每增加一单位所获效用增量递减。它是基数论的**心理假定**而非可观测规律（第七节因此批评它只能靠内省验证）。货币的 MU 也递减但极慢，故视为常数 `λ`——这是 `MU/P=λ` 成立的前提。

### 二、消费者均衡（基数路线）

- **一种商品（式2.3）**：`MU/P = λ`。收益 MU 对代价 `λP`：`MU>λP` 继续买，`MU<λP` 退回来。教材例 λ=2、P=3 时第 3 盒 MU=6=λP，故最优 3 盒。
- **两种商品（式2.7、2.8）**：在 `P₁Q₁+P₂Q₂=m` 下 `MU₁/P₁ = MU₂/P₂ = λ`。若不等，把一元钱从低 MU/P 挪到高 MU/P，支出不变而效用净增；调整中 MU₁ 降、MU₂ 升直至相等。**商品 2 若为货币（P₂=1），式(2.8) 退化为式(2.3)**。
- **n 种商品（式2.9）**：`MUᵢ/Pᵢ = λ`，配 `ΣPᵢQᵢ=m`；含义是最后一元钱花在哪都一样。

### 三、需求曲线与消费者剩余

- **反解需求曲线**：`P=MU/λ`；令 `λ=1`（以货币计量效用），则 `P=MU(Q)`，**需求曲线就是边际效用曲线**。价格升 → 须由更高 MU 补偿 → MU 递减下只能减少消费量来抬高 MU。故向下倾斜的根源是 MU 递减；也说明决定价格的是**边际**效用而非总效用（钻石与水悖论）。
- **消费者剩余（式2.10）**：`CS = TU(Q) − PQ`，愿付总额减实付总额；几何上是**价格线之上、需求曲线之下**的面积，常用作福利尺度（最低限价、垄断定价的福利损失）。

### 四、无差异曲线

- **偏好四假设**：完备性（任意两组合可比）、传递性、非饱和性（多比少好）、多样性（组合优于单一商品）。③ 排除"非意愿商品"，④ 对应"凸向原点"；另需连续性，因缺乏直观解释而省略。
- **四特征**：① 有无数条，**离原点越远效用越高**；② **任意两条不相交**；③ **向右下方倾斜**；④ **凸向原点**（斜率绝对值递减）。不相交的证明：若 U₁、U₂ 交于 A，从原点引射线交 U₁ 于 B、U₂ 于 C，C 的数量均多于 B 故 C≻B；但 B~A、C~A 由传递性得 B~C，矛盾——**同时用掉传递性与非饱和性**。
- **边际替代率（式2.11、2.12）**：`MRS₁₂ = −ΔQ₂/ΔQ₁|_{U不变}`，即无差异曲线斜率的绝对值；`MRS₁₂ = MU₁/MU₂`（推导：把 A→B 拆成 A→C 与 C→B，两段效用改变量之和为零，`MU₂ΔQ₂+MU₁ΔQ₁=0`）。**MRS 与商品 1 的 MU 成正比、与商品 2 的 MU 成反比。** 递减机制：Q₁ 增则 MU₁ 小、Q₂ 减则 MU₂ 大，比值必降，故曲线越来越平缓（教材注明这是"通常情况"的论证）。
- **特例**：`MRS=常数` ⇒ **直线**、**完全替代品**（2500ml 瓶装可乐对 355ml 听装的 MRS≈7.0）；`MRS=0`（水平线）、`MRS=∞`（垂直线）为另两种极端，**完全互补品**（鞋的左右脚）是直角折线；完全替代时均衡**可能是角点解**，除非价格比恰等于 MRS。

### 五、预算约束线

- `P₁Q₁+P₂Q₂=m`；斜率 `−P₁/P₂`（绝对值 = 价格比），横截距 `m/P₁`，纵截距 `m/P₂`；线外不可及、线内有余钱、线上恰好花完，故它给出最大数量组合。
- **三种变动**：收入变而价格不变 → 斜率不变、**平行移动**；P₁ 变而 m、P₂ 不变 → 绕纵截距**旋转**（P₁ 降则逆时针、横截距右移）；三者同变 → 平移 + 旋转，可先平移到过 I₂ 纵截距的辅助线、再旋转到 I₂。

### 六、消费者均衡（序数路线）

- **相切条件（式2.13、2.14）**：`MRS₁₂ = P₁/P₂` 与预算式联立。**必须在预算线上**：线内还有钱没花，由非饱和性可再提高效用；**必须相切**：若与某条无差异曲线有两个交点，则两交点之间的预算线点处在更高的曲线上，而无交点的曲线买不起。
- **经济含义**：左边是**主观**换算率（愿用多少 Q₂ 换 1 单位 Q₁），右边是**市场**换算率；均衡即"心中比价 = 市场比价"。
- **两路线合流**：`MRS₁₂ = MU₁/MU₂` 代入式(2.13) 即 `MU₁/P₁ = MU₂/P₂`（式2.8），故基数与序数之分不是实质分歧。

### 七、比较静态

- **收入-消费扩展线**：价格不变、收入变动时各切点的轨迹。三种形状：① 过原点的直线 → 同比例增加，均正常品、收入弹性为 1；② 越来越陡 → 均正常品，商品 1 是必需品、商品 2 是奢侈品；③ 向后弯曲 → 收入超过某点后商品 1 的消费反降，由正常品转为**低档品**。
- **恩格尔曲线与定律**：`Q=f(m)`；定律是食物支出占比随收入增加而下降，等价于**食物支出的收入弹性小于 1**。
- **价格-消费扩展线 → 需求曲线**：P₁ 变动使预算线绕纵截距旋转，各切点连成价格扩展线；把每个均衡点的 `(P₁,Q₁)` 搬到"价格—数量"平面即得需求曲线。**曲线上每一点都是某价格下的均衡点**，这就是"需求曲线有行为基础"的含义；但序数框架下不能直接用 MU 递减论证倾斜方向。

### 八、替代效应与收入效应（本章重心）

- **分解原则**：总效应 = 替代效应 + 收入效应，两者不得重叠。**替代效应**：相对价格变动引起、在**维持原有效用水平**下的调整；**收入效应**：实际收入变动引起、在**价格不变**下的调整。教材用**希克斯分解**（钉住效用），**斯勒茨基分解**钉住原消费束的购买力，区别只在辅助线位置，不影响方向结论。
- **希克斯分解步骤（式2.15、2.16）**：① 原价 P₁₁ 下均衡 E₁、需求 Q₁₁；② 价格降至 P₁₂，新均衡 E₂、需求 Q₁₂，`总效应 = Q₁₂−Q₁₁`；③ 作**补偿预算线**：与**新**预算线平行、与**原**曲线 U₁ 相切于 E′，其收入即"按新价格维持原有效用所需的最低收入"；④ 替代 `= Q′₁−Q₁₁`，收入 `= Q₁₂−Q′₁`，之和恰为总效应。

**三类商品的方向（以价格下降为例，教材表2-3）**：

| 商品类型 | 替代效应 | 收入效应 | 总效应 | 需求曲线 |
|---|---|---|---|---|
| 正常品 | + | + | + | 右下倾斜 |
| 普通低档品 | + | −（较弱） | + | 右下倾斜 |
| 吉芬商品 | + | −（**强于替代**） | − | 右上倾斜 |

- **替代效应恒与价格反向，正常品与低档品皆然**（补偿线总比原线更平缓，切点必在原切点右下方）；方向差异全在收入效应。**吉芬商品必是低档品，低档品不必是吉芬商品**。吉芬难题：土豆涨价使低收入家庭购买力骤降、买不起相对降价仍很贵的牛肉而多买土豆。

### 九、不确定性与风险

- **彩票式描述**：结果不唯一即存在不确定性，写作 `Q=(α₁,…,αₛ;q₁,…,qₛ)`，两结果情形 `Q=(α;q₁,q₂)`；教材按奈特的区分本应分"概率不可知"与"结果及概率已知"，但为简化统一在风险意义下使用。
- **期望效用（式2.17、2.18）**：`U(Q)=Σαᵢu(qᵢ)=E(u)`（NM 期望效用函数，`u` 称贝努利函数），不确定下最大化 `E(u)`。权重是概率，被加权的是**效用**而非金额；`U(Q)`（效用的期望）与 `u(EQ)`（期望值的效用）是两个量。
- **风险态度**（`EQ=αq₁+(1−α)q₂`）：`U(Q)<u(EQ)` 厌恶（曲线凹、MU 递减）；`=` 中性（直线）；`>` 喜好（凸）。风险厌恶与 MU 递减是同一件事，故为常态假设。
- **保险（式2.19–2.21）**：投保后净值为 `a−b−X+x`、`a−X`，不投保为 `a−b`、`a`；比较两张彩票的期望效用。令 `P=X/x`，对 x 求导得 `α(1−P)u′(a₁)=P(1−α)u′(a₂)`，即式(2.21)，与 `MU/P=λ` 同构。

### 十、本章评析（第七节）

- **评析口径**：基数论的缺陷在"单位不可证、递减只能内省、隐含收入均等化"；序数论在"排序要求过高、忽视需要层次、MRS 递减难保证"；两论共同以偏好外生为前提。效用价值论把价值归于使用价值或主观评价，回答不了价值尺度与价值源泉。

## Key Concepts / 核心概念

**效用（utility）**：消费者消费商品、服务对欲望的满足程度，是主观心理评价。

**边际效用（MU）**：增加一单位消费所得到的效用增加量，等于总效用对消费量的导数。

**消费者剩余（consumer surplus）**：愿付总额与实付总额之差，即总效用减总支出。

**无差异曲线（indifference curve）**：既定偏好下能给消费者带来相同效用水平的所有商品组合的轨迹。

**边际替代率（MRS）**：效用不变时增加一单位某商品所需放弃的另一商品数量，为无差异曲线斜率的绝对值。

**预算约束线（budget line）**：收入与价格既定下全部收入所能买到的两商品组合的轨迹，斜率绝对值为价格比。

**消费者均衡（consumer equilibrium）**：既定收入约束下实现效用最大化并维持不变的状态，几何上为预算线与无差异曲线的切点。

**替代效应（substitution effect）**：相对价格变动引起、维持原有效用水平不变时对需求量的调整。

**收入效应（income effect）**：实际收入变动引起、价格不变时对需求量的调整。

**吉芬商品（Giffen good）**：一种特殊低档品，价格下降的收入效应强于替代效应，总效应与价格同向，需求曲线向右上方倾斜。

## Mental Models / 思维模型

- **"最后一单位"思维**：不问"总共值不值"，只问"再买一个值不值"。所有最优化条件都是把总值问题切成边际比较——`MU` 对 `λP`，`MU₁/P₁` 对 `MU₂/P₂`；它绕开了"效用不可测"，只需知道再多一个会怎样。
- **"两种汇率"思维**：无差异曲线斜率是消费者心里的兑换率，预算线斜率是市场的兑换率；均衡即两个汇率相等，不等时"按市场换、按心里算"的套利总能提高效用。同一模型可搬到第3章的 `MRTS=w/r` 与第8章的劳动供给。
- **"补偿"思维**：要拆一个变化，就得造一个中间状态、让其中一条渠道被关掉。辅助预算线钉住效用（希克斯）或钉住购买力（斯勒茨基），都是把"只变相对价格"与"只变实际收入"分开；风险问题同理——先算期望值 EQ，再比较 `u(EQ)` 与 `E(u)`，两者之差就是风险的价格。

## Anti-patterns / 常见错误

- **把"边际效用递减"说成"总效用递减"**：MU 递减只意味着 TU 增长变慢，TU 仍在升；只有 MU<0 时 TU 才降。
- **把 MRS 写成 `ΔQ₁/ΔQ₂` 或丢掉负号**：定义是 `MRS₁₂=−ΔQ₂/ΔQ₁`，写成倒数就把替代方向弄反。
- **把低档品等同于吉芬商品**：低档品只是 `∂x/∂m<0`，收入效应反向但通常较弱，需求曲线仍向下；吉芬要求收入效应强于替代效应，正确关系是"吉芬 ⊆ 低档"。
- **用效用水平以外的标准认替代效应**：唯一标准是它是否沿同一条无差异曲线移动——沿 U₁ 从 E₁ 到 E′ 是替代效应，从 E′ 到 E₂ 是收入效应。
- **在序数框架下直接用 MU 递减论证需求曲线向下**：多商品情形存在替代，必须走"替代效应恒为负 + 收入效应的方向与强度"这条路。

## Worked Example / 工作示例

**题目**：月收入 m=120 元全部用于商品 1、2，效用函数 `U=√(x₁x₂)`，`P₁=3`，`P₂=12`。（1）求效用最大化的购买量与最大效用；（2）若 P₁ 翻倍为 6，收入须为原来的多少倍才能维持原有效用？（3）用希克斯分解求 P₁ 由 3 升到 6 的替代效应与收入效应，并判断商品 1 的性质。

**第一步　均衡条件。** `MU₁=0.5x₁^(−0.5)x₂^0.5`，`MU₂=0.5x₁^0.5x₂^(−0.5)`，故 `MRS₁₂=MU₁/MU₂=x₂/x₁`。由 `MRS₁₂=P₁/P₂=3/12` 得 `x₂=x₁/4`。

**第二步　联立预算线（第1问）。** `3x₁+12x₂=120` 代入 `x₂=x₁/4`：`x₁=20`，`x₂=5`，`U=√100=10`。校验：支出 `60+60=120`，两商品各占一半收入——柯布-道格拉斯 `x₁^a x₂^b` 的固定份额性质 `Pᵢxᵢ/m=a/(a+b)`。

**第三步　新价格下的均衡（第2问前半）。** P₁=6 时 `x₂/x₁=6/12`，即 `x₁=2x₂`；预算式给出 `x₂=5`、`x₁=10`、`U′=√50≈7.07`。注意 x₂ 没变：柯布-道格拉斯偏好下每种商品的需求只取决于自身价格与收入。

**第四步　维持原效用所需收入（第2问）。** 设收入 m′，新价格下 `x₁=m′/12`、`x₂=m′/24`；要求 `√(m′²/288)=10`，得 `m′=120√2≈169.7`，即须为原来的 **√2≈1.41 倍**（一般结论 `m′/m=√(P₁′/P₁)`）。

**第五步　希克斯分解（第3问）。** E₁=(20,5)、U=10；E₂=(10,5)，**总效应** `=10−20=−10`。补偿均衡 E′ 取**新价格** (6,12)、**原效用** U=10：由 `x₂=x₁/2` 与 `√(x₁²/2)=10` 得 `x₁=10√2≈14.14`。校验 `6×14.14+12×7.07=169.7=120√2`，与第四步一致——**补偿预算线就是新价格下恰好相切于原无差异曲线的那条线**。故**替代效应** `=−5.86`，**收入效应** `=−4.14`，两者之和 `=−10`。

**第六步　判断性质。** 价格上升时两种效应**同向为负**，故 x₁ 是**正常品**。若收入效应为正（涨价反而多买）才是低档品；若该正效应还强于 |替代效应|，才是吉芬商品。

## 解题套路 / Solution Patterns

**题型一：求需求函数 / 均衡购买量（最高频）**

识别：给出 `U(·)`、m、P₁、P₂，问最优组合、需求函数或最大效用。步骤：① 求 `MU₁`、`MU₂`（对数效用 `U=a ln x₁+b ln x₂` 更好导，`MU₁=a/x₁`）；② 由 `MU₁/MU₂=P₁/P₂` 得数量与价格的关系式；③ 与预算式联立；④ 代回效用函数；⑤ 要需求函数就写成 `xᵢ=f(Pᵢ,m)`（柯布-道格拉斯为 `x₁=[a/(a+b)]m/P₁`）。易错：把价格比写成 `P₂/P₁`；份额 `a/(a+b)` 算错；混淆幂效用与对数效用的 MU。

**题型二：支出最小化（给定效用求最小支出）**

识别："给定效用 U₀，求支出最小的购买量与最小支出"。步骤：均衡条件与题型一**完全相同**（`MRS=P₁/P₂`），只是约束换成 `U(x₁,x₂)=U₀`，解出数量后算 `M=P₁x₁+P₂x₂`。易错：把约束也写成预算式——本类题中收入是待求量。

**题型三：替代效应与收入效应的计算**

识别：给一次价格变动，问替代、收入、总效应。步骤：① 算原均衡 E₁；② 算新均衡 E₂，总效应 = 数量之差；③ 定中间点 E′：**新价格 + 原效用**（希克斯）或**新价格 + 原消费束仍可负担的收入**（斯勒茨基）；④ 替代 `=E′−E₁`，收入 `=E₂−E′`；⑤ 用"两效应之和 = 总效应"校验；⑥ 由符号判性质（同向为正常品，反向为低档品，反向且收入效应更强为吉芬商品）。易错：中间点用旧价格；符号写反（涨价时替代效应必为负）；漏掉性质判断。

**题型四：证明题（题库固定四类）**

① *无差异曲线不相交*：反证 + 传递性 + 非饱和性（射线法）。② *两商品不可能都是劣等品*：对 `p₁x₁+p₂x₂=m` 关于 m 求导得 `p₁∂x₁/∂m+p₂∂x₂/∂m=1`；若两者都小于 0，左边恒小于 0，矛盾。③ *完全替代*：证 `MU₁/MU₂` 为常数，如 `U=10(x₁²+2x₁x₂+x₂²)−50` 中 `MU₁=MU₂=20(x₁+x₂)`。④ *切点即均衡点*：左上方 `MRS>P₁/P₂`（多买 1 有利），右下方 `MRS<P₁/P₂`（多买 2 有利）。易错：证"不相交"只提传递性不提非饱和性。

**题型五：名词解释与简答**

名词解释骨架：**定义 → 公式/图形语言 → 经济含义 → 一句用途**（如 MRS：效用不变下换得的商品 2 数量；`=−ΔQ₂/ΔQ₁=MU₁/MU₂`；斜率的绝对值；递减即凸向原点）。简答骨架：先给判据，再分情形，最后收口（如"正常品曲线为何向下"= 替代反向 + 收入反向 + 叠加）。易错：只写定义不写含义；只给结论不给机制。

## Key Takeaways / 关键结论

1. **一切均衡条件都是"边际比价相等"**：`MU₁/P₁=MU₂/P₂=λ` 与 `MRS₁₂=P₁/P₂` 是同一条件的两种写法，`MRS₁₂=MU₁/MU₂` 是二者的桥。
2. **边际效用递减是需求规律的根基**：`P=MU/λ`，价格上升须由更高的 MU 补偿，而 MU 只在更小的消费量上才更高。
3. **无差异曲线的四条性质全部由偏好公理推出**："不相交"用传递性 + 非饱和性，"凸向原点"用 MRS 递减；曲线只随偏好变动。
4. **均衡点是预算线与无差异曲线的切点**，同时满足"钱花完"与"主观比价 = 市场比价"。
5. **替代效应恒与价格反向，方向差异只来自收入效应**：正常品同向、低档品反向、吉芬商品反向且更强，故只有吉芬商品的需求曲线向上倾斜。
6. **需求曲线上每一点都是均衡点**，由价格-消费扩展线导出，而不是把不同偏好下的点连起来。

## Connects To / 与其他章节的联系

- **第1章**：本章为"需求规律""需求价格弹性""消费者剩余""吉芬难题"提供行为基础。第1章的弹性是现象，本章的 MU/MRS 是机制；吉芬难题在第1章只作为悖论提出，第五节才给出解释。
- **第3章（企业的生产和成本）**：结构同构——无差异曲线 ↔ 等产量线，MRS ↔ 边际技术替代率 MRTS，预算线 ↔ 等成本线，`MRS=P₁/P₂` ↔ `MRTS=w/r`。要素最优组合可整段迁移，只把"效用水平"换成"产量水平"。
- **第4—7章**：个人需求曲线横向加总为市场需求曲线，构成厂商面临的需求约束；各市场结构的定价与福利分析都要用消费者剩余。
- **第8章（生产要素价格）**：劳动供给是"收入与闲暇"之间的选择。工资变动的替代效应（闲暇变贵→多工作）与收入效应（更富→多闲暇）方向相反，故劳动供给曲线可能向后弯曲——与吉芬商品逻辑同源。
- **第10章（一般均衡与福利经济学）**：消费者剩余的加总、帕累托最优的交换条件 `MRS^A=MRS^B` 都以本章均衡条件为零件。
- **数学分析**：本章是约束极值的一次完整演练——`L=U(x₁,x₂)+λ(m−P₁x₁−P₂x₂)`，一阶条件给出 `MUᵢ=λPᵢ`，乘子 λ 正是"货币的边际效用"（收入的影子价格）。`MU=U′(Q)` 是导数，`TU=∫MU dQ` 是积分，`MRS=−dQ₂/dQ₁` 是隐函数求导，MRS 递减是二阶条件。
- **线性代数**：二阶条件（曲线凸向原点 ⇒ 加边海塞矩阵负定）等价于"效用函数拟凹"，是"相切点即最大点"的严格保证。
