# 第14章 开放条件下的宏观经济 (The Open Economy)

> 马工程《西方经济学》(第二版) · 下册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理
>
> 考点权重 17★：国际收支与汇率 ★★★ ｜ **蒙代尔-弗莱明模型 ★★★★★** ｜ 固定汇率制政策效果 ★★★★ ｜ 浮动汇率制政策效果 ★★★★★

## Core Idea / 核心思想

封闭经济里利率内生、政策经由利率影响投资；一旦资本可跨国流动，**小国利率就被世界市场钉住（r = r_w）**，汇率接替利率成为吸收冲击的变量。蒙代尔-弗莱明模型（Mundell-Fleming model）就是把 IS-LM 的纵轴由 r 换成 e：IS* 与 LM* 的交点同时决定产出与汇率。全章结论都源于一个几何事实——**LM* 垂直**：给定 M/P 与 r_w，货币市场已把 Y 定死，政策是否有效取决于它能否移动 LM*。于是两种汇率制度下财政与货币政策的有效性**恰好对调**。

## Frameworks Introduced / 核心框架

**国际收支（balance of payments）**：居民与非居民之间全部经济往来的系统性货币记录。
- 三个限定：**流量**（区别于存量的外汇储备）；以货币记录**全部**交易（含物物交换与无偿转移）；只看**居民—非居民**而非国籍（自然人住满一年即本国居民；联合国、IMF 是任何国家的**非居民**）。
- 平衡表三块：**经常账户**（货物和服务、收入、经常转移）、**资本与金融账户**（资产交易）、**平衡账户**（官方储备、"错误与遗漏"）。表形式上恒平衡；"顺差/逆差"指**自主性交易**差额 NX − F 的正负。

**名义汇率与实际汇率**：e 是两国货币的相对价格；ε 是用两国物价调整后的汇率，**ε = e·P/P_f**（式14.1），又称**贸易条件**。购买力平价（PPP）即 eP = P_f，此时 ε = 1。变动率关系：**e% = ε% + P_f% − P%**。
- ⚠️ 先声明标价法：**直接标价法**（应付）= 1 单位外币折合多少本币，e↑ 为**贬值**；**间接标价法**（应收）= 1 单位本币折合多少外币，e↑ 为**升值**。教材正文用间接标价法，故"e↑ = 升值 = NX↓"。

**汇率制度**：固定汇率制把汇率限于很小波幅、由官方干预维持（布雷顿森林体系为"**双挂钩**"，波幅不超平价上下 **1%**）；浮动汇率制不规定平价与波幅、当局不承担维持义务。要害是：固定汇率制的实质不是"汇率不动"，而是**货币供给服从汇率目标**——第三节全部结论的伏笔。

**净出口函数**：NX = X − M（式14.2）；教材写作 **NX = q − γY + n·(eP/P_f)**（式14.3），γ 为**边际进口倾向**，n 为对实际汇率的反应系数。净出口**反向**取决于本国收入 Y，**反向**取决于本币币值；几何上纵轴 ε、横轴 NX，曲线**向右下方倾斜**（教材图14-1）。
- ⚠️ 符号随标价法翻转：式(14.3)按**直接标价法**写成 "+n·(eP/P_f)"；按正文的间接标价法则应作 "−n·(eP/P_f)"。先确认标价法再定符号。
- **马歇尔-勒纳条件**：进出口供给弹性趋于无穷大时，只有 **|η_x| + |η_m| > 1**，贬值才改善贸易收支。
- **J 曲线效应**：贬值后收支**先恶化、后改善**——货币合同阶段（价量皆不变，结果取决于合同计价货币）→ 传导阶段（价格变、数量未变）→ 数量调整阶段（数量变化远大于价格变化）。成因即短期 |η_x| + |η_m| < 1、中长期 > 1。

**资本净流出函数**：**F = σ(r_w − r)**（式14.4），σ > 0 反映资本流动的难易程度；资本由低利率国流向高利率国，故 F 是 r 的**减函数**（教材图14-3：纵轴 r、横轴 F，右下倾斜）。

**BP 曲线**：BP = NX − F（式14.5）；BP = 0 即 NX = F，解得 **r = (γ/σ)·Y + [r_w − (n/σ)(eP/P_f) − q/σ]**（式14.7）。
- **斜率 γ/σ > 0，向右上方倾斜**：Y↑→进口↑→NX↓→须提高 r 以减少资本外流。四象限推导（教材图14-4）：资本净流出曲线经 45° 线映射为所需 NX，再与净出口曲线共同投影出 (Y, r) 平面。左上方**顺差**（NX > F），右下方**逆差**。
- **三种形状**由 σ 定：σ→∞ 时 BP 为**水平线**且 r = r_w（资本流动可弥补任何经常账户失衡）；σ = 0 时为**垂直线**；0 < σ < ∞ 时正斜率，越平坦表示资本流动性越强。移动：P↑ → ε↓ → NX↓ → **BP 左移**。

**蒙代尔-弗莱明模型**：开放经济的短期 IS-LM。三假设——① 价格短期不变，产出由总需求决定；② 货币非中性，实际货币需求与 Y 正相关、与 r 负相关；③ 商品与资本完全自由流动，故 **r = r_w**（式14.8），这是"**小国**"假设的等价说法。
- **IS***：**Y = C(Y − T) + I(r_w) + G + NX(e)**（式14.9），在 (Y, e) 平面**向右下方倾斜**——e↑（升值）→NX↓→Y↓；投资项只含外生的 r_w，利率不出现在 IS* 中。
- **LM***：**M/P = L(r_w, Y)**（式14.10），在 (Y, e) 平面是**垂直线**——均衡收入与汇率无关。
- 均衡：两线交点给出 (Y*, e*)；T、G、M、r_w 外生，Y 与 e 内生。若价格可变，净出口写成 NX(ε)：P↓ → 实际货币余额↑ → LM* 右移、IS* 不动 → ε↓、Y↑，即得**向右下方倾斜的开放经济总需求曲线**（教材图14-11）。

**固定汇率制下的政策效果**：央行须把 e 钉在 e*，货币供给沦为内生变量。
- **财政政策有效**：G↑/T↓ → IS* 右移 → e 面临**升值压力** → 央行**买外汇、放本币** → LM* 被动右移直到 e 回到 e* → **Y↑**，财政效果被货币扩张**强化**（表14-1 记 ↑↑）。
- **货币政策无效**：M↑ → LM* 右移 → 资本外流 → e 面临**贬值压力** → 央行**抛外汇、收本币** → LM* 原路退回 → **Y 不变，短期也不变**。
- **贸易政策有效**：关税与非关税壁垒（配额、许可、技术壁垒等）压缩进口 → NX↑ → IS* 右移，与财政政策同构，区别只在 IS* 右移的**原因**。

**浮动汇率制下的政策效果**：央行不干预，e 自由浮动，M 外生。
- **财政政策无效（完全挤出）**：G↑ → IS* 右移 → e↑（升值）→ 本国商品相对昂贵 → NX↓，需求扩张被升值**完全抵消**，Y 不变。更硬的解释：r = r_w 与 M/P 固定 ⟹ L(r_w, Y) 固定 ⟹ **Y 不能变**。即**国际挤出效应**。
- **货币政策有效**：M↑ → LM* 右移 → 资本流出 → 本币供给增加 → e↓（贬值）→ 出口变便宜、进口变贵 → NX↑ → **Y↑**。作用渠道**由利率转向汇率**。
- **贸易政策无效**：NX↑ → IS* 右移 → e↑ → 升值反过来压低 NX → Y 不变；NX 只进 IS*、不进 LM*，故与财政政策同命运。

**不可能的三位一体（trilemma）**：**资本完全流动、固定汇率、独立货币政策**三者不可兼得，最多取二；由表14-1 直接推出。前提是**小型开放经济**：超大型经济体足以影响世界利率，其货币政策会带动 r_w 同向变动，悖论**失效**；若资本流动受限（σ→0），固定汇率下也可保有独立货币政策。

## Key Concepts / 核心概念

**国际收支**：居民与非居民之间一定时期内全部经济往来的系统性货币记录，流量概念。
**经常账户**：记录货物服务贸易、收入与经常转移，余额＝货物服务净出口＋国外净收入＋净单方面转移。
**名义汇率**：两国货币的相对价格，一种货币兑换另一种货币的数量。
**实际汇率**：ε = e·P/P_f，用两国物价调整后的汇率，衡量本国商品相对价格即贸易条件。
**购买力平价**：无运输成本与贸易壁垒时 eP = P_f，实际汇率等于 1。
**资本净流出**：F = 流向国外的本国资本 − 流向本国的国外资本 = σ(r_w − r)。
**BP 曲线**：使 NX = F 成立的 (Y, r) 组合轨迹，斜率 γ/σ。
**马歇尔-勒纳条件**：进出口需求价格弹性绝对值之和大于 1 时贬值才改善贸易收支。
**J 曲线**：贬值后贸易收支先恶化后改善的时间路径。
**冲销干预（sterilized intervention）**：外汇交易同时做数量相等、方向相反的国内资产交易，以抵消其对货币供给的影响。

## Mental Models / 思维模型

1. **LM* 垂直，战场只剩一条线**。M/P 与 r_w 一给定，Y 就锁死，能动的只有 e。于是"政策是否有效"等价于"它能否推动 LM*"：财政与贸易政策动 IS*，浮动下只推动 e；货币政策动 LM*，固定下被央行推回。也可把 e 读成"用外币标价的本国商品价格"：升值＝本国商品变贵＝卖不动＝净出口减少。
2. **固定汇率下的央行是被动的货币供给者**。看资产负债表比看曲线快：买外汇→放本币（M↑）；抛外汇→收本币（M↓）。"货币无效"的实质是**任何自主的 M 变动都被外汇占款反向冲销**。
3. **三元悖论是守恒定律**。别问"能否三个都要"，要问"这个经济体拿什么当名义锚"：选汇率锚，货币政策就是汇率政策的附属品。

## Anti-patterns / 常见错误

- **两种制度下有效性记反**：正确是"固定→财政有效、货币无效；浮动→货币有效、财政无效"。抓手：**谁动 LM*，谁在固定汇率下失效**。
- **说"固定汇率下货币政策短期有效、长期无效"**：错。资本完全流动下它**即使短期也完全失效**，冲销是瞬时的。
- **e 上升一律当贬值**：仅直接标价法如此。教材正文用间接标价法，e↑ 是升值。而题库"人民币对美元汇率下降"一题把它读作**人民币贬值**（中国商品变便宜、美国增加进口）——那是把本币放在前面、按本币价值计的口语说法，不是直接标价法。
- **ε 方向记反**：ε = e·P/P_f 下 ε↑ 意味着本国商品相对**昂贵**、NX**减少**。若说成"ε↑ 竞争力增强"，BP 与 NX 的符号全反。
- **忽略收入对 NX 的负向作用**：固定汇率下财政扩张使 Y↑，会经由进口压低 NX；浮动下贸易保护对 NX 的净影响同样取决于边际进口倾向，不确定。
- **把 r = r_w 当成"货币政策永远无效"**：r 被钉住只使货币政策失去**利率渠道**，浮动汇率下它改走**汇率渠道**。
- **把 BP 画成固定斜率**：斜率是 γ/σ，完全流动为水平、完全不流动为垂直；也不要把"平衡表恒平衡"与"国际收支平衡（NX = F）"混为一谈。

## Worked Example / 工作示例

**题目**（据中央财经大学 2016 研整理）：小型开放经济，
IS：Y = 1000 + G − T + NX − 50r；LM：Y = M/P + 100r；NX = 2500 − 100e；
M = 2000，P = 1，r_w = 10，G = 1000，T = 800（e 按间接标价法）。
(1) 求均衡 Y 与 e；(2) 浮动汇率下 T 降至 500，求新 Y 与 e；(3) 改为固定汇率并钉住 (1) 的 e，T = 500 时 Y 为多少？央行须把 M 设为多少？

**解**

**① 钉利率。** 资本完全流动的小国必有 r = r_w = 10。这步不写，后面全错。

**② 由 LM 单独定产出。** LM* 垂直，Y 与 e 无关：Y = 2000/1 + 100×10 = **3000**。

**③ IS 解汇率。** 代入 r = 10、Y = 3000：
3000 = 1000 + 1000 − 800 + (2500 − 100e) − 500 ⟹ 3000 = 3200 − 100e ⟹ **e = 2**。
验算：NX = 2500 − 200 = 2300，右端＝1000 + 1000 − 800 + 2300 − 500 = 3000 ✓。

**④ 浮动汇率 + 减税：产出不动、汇率动。** T = 500 只移 IS*：
Y 仍 **3000**；3000 = 1000 + 1000 − 500 + (2500 − 100e) − 500 = 3500 − 100e ⟹ **e = 5**。
本币从 2 升到 5，NX 从 2300 降到 2000，正好抵掉减税的 300 需求扩张——**完全的国际挤出**。

**⑤ 固定汇率 + 减税：汇率不动、产出动、货币被动扩张。** e 钉在 2，代入 IS：
Y = 1000 + 1000 − 500 + (2500 − 200) − 500 = **3300**；再由 LM 反解：3300 = M + 1000 ⟹ **M = 2300**，须增发 300。减税使 e 面临升值压力，央行必须买进外汇、投放本币 300，货币扩张**被动**发生，财政效果由此强化（表1 的 ↑↑）。

**小结**：同一冲击（T 从 800 降到 500），浮动下 ΔY = 0、Δe = +3；固定下 ΔY = +300、Δe = 0、ΔM = +300。**制度决定由哪个变量吸收冲击**。

## 解题套路 / Solution Patterns

**题型1｜名词解释（汇率、实际汇率、J 曲线、马歇尔-勒纳、经常账户、三元悖论）**
特征：单术语 4–6 分。步骤：① 一句话定义＋符号公式（ε = e·P/P_f、|η_x| + |η_m| > 1）；② 交代方向或构成要件（标价法、三阶段、三顶点取二）；③ 补一句地位或局限。易错：只给定义不给公式，漏掉标价法。

**题型2｜判断/选择：某政策在某制度下的效果**
特征：题面同时出现"固定/浮动汇率"与"资本完全流动"。步骤：① 锁定制度（谁承担调整）；② 定哪条线动（财政/贸易→IS*，货币→LM*）；③ 由交点读 ΔY、Δe 再译成升值/贬值。易错：财政扩张在浮动下 Y 不变但 e 上升，选项常写成"Y 上升"。

**题型3｜M-F 计算题（给 IS/LM/NX，求 Y、e，再换制度）**
步骤：① r = r_w；② LM 解 Y（垂直，与 e 无关）；③ IS 解 e；④ 换制度：浮动→LM 不动、只重解 e；固定→e 不动、代回 IS 解 Y，再用 LM 反解所需 M（ΔM 即被动扩张额）。变体（S − I 式）：S = Y − C − G，I = I(r_w)，NX = S − I，由 NX(ε) 解 ε；财政扩张压低 S→NX↓→升值，r_w 上升压低 I→NX↑→贬值。易错：固定汇率下仍用原 M 求解，忘了 M 内生。

**题型4｜贬值/升值对贸易余额与产出的传导链**
特征："人民币升值对我国产出与贸易余额有何影响"。步骤：① 写 NX = X(Y*, ε) − M(Y, ε)/ε；② 拆三渠道——出口需求降、进口替代升、进口单位成本（1/ε）变化；③ 汇总 NX↓；④ 由 Y = C + I + G + NX 得 Y↓；⑤ 用马歇尔-勒纳与 J 曲线时滞作限定。易错：只讲出口不讲进口，漏掉"进口值 = M/ε"。

**题型5｜三元悖论与国别论述**
步骤：① 定义三个顶点；② 给依据（固定汇率使货币政策失效）；③ 分类举例——美英日加：独立货币＋资本流动、弃汇率稳定；欧元区/香港：汇率稳定＋资本流动、弃独立货币；中国：汇率稳定＋独立货币、资本账户管理；④ 补前提（小型经济体）。易错：断言"某国三个都实现了"。

## Key Takeaways / 关键结论

1. **先钉利率，再谈其他**：资本完全流动的小国必有 r = r_w，M-F 里利率是参数不是变量。
2. **LM* 垂直是全章的发动机**：给定 M/P 与 r_w，货币市场单独决定 Y；政策能否改变 Y，看它能否移动 LM*。
3. **固定汇率下财政有效、货币无效；浮动汇率下完全相反**。锚点：固定汇率下货币供给内生，自主的 M 变动被外汇干预冲销。
4. **浮动汇率下财政扩张被汇率完全挤出**：Y 不变、本币升值、NX 减少——封闭经济"财政扩张→Y↑"在此失效。
5. **实际汇率才是竞争力的正确变量**：ε = e·P/P_f；讨论升值贬值前必须声明标价法，否则方向全反；贬值改善收支还需 |η_x| + |η_m| > 1 与 J 曲线的时滞。
6. **三元悖论是约束不是选择题**：资本完全流动、固定汇率、独立货币政策只能取二，且以小型开放经济为前提。

## Connects To / 与其他章节的联系

- **承接第10–13章**：IS* 就是第11章 IS 曲线在 r = r_w 处投影到 (Y, e) 平面，LM* 是第12章货币市场均衡的垂直投影。价格变动的 M-F 模型推出的向右下方倾斜的 AD，即第13章总需求曲线的开放版——同形不同渠道（封闭靠利率，开放靠汇率）。
- **开启第15章**：本章给出"政策有效性依赖制度环境"，第15章才谈政策组合与内外均衡冲突；蒙代尔"有效市场分类"原则（货币政策对对外均衡、财政政策对对内均衡）在此埋线。
- **微观基础在第2章**：马歇尔-勒纳条件即弹性理论的直接应用；边际进口倾向 γ 是边际消费倾向的"进口版"，外贸乘数 1/(1 − β + γ) 由第10章乘数公式改写；本章净出口即第9章四部门恒等式中的 NX 项。
- **数学工具**：BP 与 IS* 的斜率来自隐函数求导（对 NX = F 全微分得 dr/dY = γ/σ）；e% = ε% + P_f% − P% 是取对数后全微分。
