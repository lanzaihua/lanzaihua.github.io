# 第9章 宏观经济的基本指标及其衡量 (Macroeconomic Indicators and Their Measurement)

> 马工程《西方经济学》(第二版) · 下册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

宏观经济学先得有一把尺子。本章只做一件事：把"一国经济怎么样"翻译成三个可算的数字——总产出（GDP）、价格水平（CPI／GDP 平减指数）、失业率。三个指标背后是三个口径问题：一笔交易算不算 GDP、一个指数用基期还是当期数量加权、失业率的分母是谁。全章的价值不在背定义，而在**守住口径**——口径错一步，后面所有模型都错。

考点权重（笔记详解标注）：国内生产总值及其衡量 ★★★、价格水平及其衡量 ★★★、失业及其衡量 ★★★（合计 9★，全书权重最低，概念却最密集、最易混）。

## Frameworks Introduced / 核心框架

### 一、GDP 的含义：四个限定词各排除一类东西

**国内生产总值（gross domestic product, GDP）**：一定时期内在一国（或地区）境内生产的全部最终产品与服务的市场价值总和。

- **"市场价值"**：实物量不能相加（10 辆汽车 + 20 吨钢没有意义），故统一折成货币，价值 = 单价 × 数量（教材例：2018 年中国 GDP 为 900 309 亿元）。排除不经市场的活动——家务劳动、自给自足、地下经济。这解释了"主妇做饭"不计入而"餐馆厨师做饭"计入。
- **"最终产品与服务"**：最终产品直接出售给最终使用者；中间产品被另一家企业当作投入品（小汽车是最终产品，汽车上的耐磨轮胎是中间产品）。排除中间产品是为了**避免重复计算**，技术上靠增值法：只加总各环节的增加值。
  - 关键：最终／中间是**用途**属性，不是物品属性——面粉被家庭买去消费是最终产品，被面包厂买去烤面包就是中间产品（题库原题眼）。
- **"一国（或地区）境内"**：**国土原则**。耐克在中国生产的鞋计入中国 GDP，海尔在美国生产的冰箱计入美国 GDP。
  - 对照**国民生产总值（GNP）**：按**国民原则**，指一个特定经济体的公民所拥有的生产要素所生产的产出的市场价值。**GNP = GDP + 来自国外的要素报酬 − 支付给国外的要素报酬**（中国公民在纽约房产的租金：计入美国 GDP、中国 GNP）。
- **"一定时期内"**：一季度或一年，故 GDP 是**流量（flow）**，不是存量（stock）。存量是某一时点的量（货币存量、存款余额、国民财富），流量是某一时期的量（GDP、投资、储蓄、政府支出）。流量来自存量又归于存量，有存量必有对应流量，有流量未必有存量（工资、进口就没有）。

### 二、三种核算法：为什么必然相等

**生产法（增值法）、收入法、支出法**分别从产品形态、收入形态、价值形态量同一个东西。理论上三者相同，实践中的差额叫**统计误差**。

**循环流程图（教材图9-1）的逻辑**：设一个只用劳动生产包子的经济。方框图里两层循环：内层是实物流（劳动从家庭流向企业、包子从企业流向家庭），外层是货币流（家庭买包子的支出流向企业，企业以工资和利润付给家庭）。于是 GDP 既可数"买包子的总支出"，也可数"生产包子得到的总收入"，根据是会计规则——买者的支出必然等于卖者的收入。所以**产出 = 支出 = 收入**，GDP 有三个称谓：总产出、总支出、总收入，统一记作 **Y**。

**（1）支出法**：数一定时期内全社会购买最终产品和服务的总支出，按需求方分四部门：

- **消费 C**：耐用品（汽车、电视）+ 非耐用品（食品、服装）+ 服务（医疗、教育、旅游）。**不含个人购买住宅**。
- **投资 I**：企业厂房、设备、存货支出 **+ 家庭住宅支出**。**净投资 = 当年年终资本存量 − 上年年终资本存量**，**总投资 = 净投资 + 折旧**（折旧又称重置投资）；支出法的 I 是**总投资**，这正是 GDP 被称"总"产出的原因。排除股票、债券：产权转移，无新资本形成。
- **政府购买 G**：各级政府购买产品与服务的支出（国防、道路、学校）。**不含转移支付**（社会保障、福利、公债利息）——那是再分配已有收入，不交换产品与服务。判据是**购买者类型**而非产品类型：同一辆车，家庭买是 C、企业买是固定投资、政府买是 G；唯一例外是住宅，谁买都算投资。
- **净出口 NX = X − M**：进口要减（收入流向国外，且不是买本国产品），出口要加（收入从国外流入，买的是本国产品）。NX > 0 顺差、= 0 平衡、< 0 逆差。

**GDP = C + I + G + NX**（式9.1）。教材表9-1（2015 年美国）：C 占 68%、G 18%、I 17%、NX −3%——消费是最大一块，净出口可为负。

**（2）收入法**：用要素成本数——工资（雇员薪酬，含净工资与雇主额外福利）+ 利息（家庭收到的资本利息）+ 租金（含专利版权收入）+ 利润（税前，含公司所得税、红利、未分配利润）。四项之和 = 以要素成本衡量的**国内生产净值**，还须两项调整：要素成本 → 生产价格，**+ 间接税 − 补助金**；净产值 → 总产值，**+ 折旧**。

**GDP = 工资 + 利息 + 租金 + 利润 + 折旧 + 间接税 − 补助金**

**（3）生产法（增值法）**：加总各部门增加值，增加值 = 部门总产值 − 中间消耗。例：采矿 100、炼钢 420、轧钢轨 500，增值 100 + 320 + 80 = 500，恰等于最终产品钢轨的 500。

### 三、名义 GDP、实际 GDP 与 GDP 平减指数

- **名义 GDP（nominal GDP）**：用**现期（当年）价格**衡量的全部最终产品与服务价值；其上升可能来自产量，也可能只来自涨价。
- **实际 GDP（real GDP）**：用**一组不变价格（基年价格）**衡量的价值，即"价格不变、只有产量变化"时的产出。比较不同年份的产出与福利要用它——产量不变而价格翻倍时名义 GDP 也翻倍，但经济满足需求的能力没变。
- **实际人均 GDP = 实际 GDP ÷ 人口**，生活水平的常用代理（题库提醒：可作跨国劳动生产率比较，但不足以单独作政策目标，因为它不说明产量怎么用）。
- **GDP 平减指数（GDP deflator，又称折算指数）**（式9.3）：**平减指数 = 名义 GDP ÷ 实际 GDP × 100**。单产品（包子）情形化简为 **P / P基期**：价格相对基期上涨则 > 1，下跌则 < 1——这就是它能反映总体价格水平的原因。反解（式9.4）：**实际 GDP = 名义 GDP ÷ 平减指数 × 100**，即"缩减"名义值；该式对消费、投资、货币量同样适用。

### 四、与 GDP 相关的一串指标：一条减法链

定义与公式见速查表 B，主线是：**GNP = GDP + 国外要素净收入**，然后层层往下减——**GDP −折旧→ NDP −间接税→ NI −公司利润与社保 +转移支付→ PI −个人所得税→ DPI**（另有 NNP = GNP − 折旧；教材式9.2：可支配收入 = 家庭获得的市场收入 + 转移支付 − 个人税收）。每一刀都在剔掉"不属于家庭的钱"，DPI 才是家庭真正能花的钱。

### 五、价格水平：两个指数与一个变化率

**价格水平（price level）**：特定范围内产品和服务价格的总体平均水平，衡量货币购买力。不能拿一种商品的价格代表整体（以偏概全），也不能简单算术平均（鸡蛋与带鱼的权重要按购买量区分）——必须**加权**。**价格指数 = 同一组产品在某年的费用额 ÷ 它在基年的费用额**，基年指数定为 100（例：以 2013 年为基年，2015 年指数 152，意为同一组产品 2013 年花 100 元、2015 年要花 152 元）。

- **CPI（消费价格指数，consumer price index）**：消费者支出调查确定"商品篮子"→ 调查篮内价格 → 计算：**CPI = 现期价格下篮子的费用额 ÷ 基期价格下篮子的费用额 × 100**（式9.5）。篮子与基期一旦定下，分母就固定不变——这是 CPI 的全部要点。
- **GDP 平减指数**：覆盖全部国内生产的最终产品。
- **生产者价格指数（PPI）**：衡量生产者出厂（批发）环节的价格。教材正文只展开平减指数与 CPI 两个，PPI 属同一族指标——简答提一句"PPI 看生产端、CPI 看消费端"即可，不杜撰编制细节。
- **CPI 的三个偏差**（笔记详解）：**替代偏向**（未考虑消费者转向变便宜的商品）、**新产品引进**（未体现新产品提高单位货币购买力）、**无法衡量的质量变动**（质量提升被记成涨价）。

**通货膨胀（inflation）**：一定时期内价格水平**普遍、持续**上升。**通货膨胀率**（式9.6）：**π = (P_t − P_{t−1}) ÷ P_{t−1} × 100%**，P 可用 CPI 也可用平减指数。例：CPI 由 120 升到 140 → π = 20/120 = 16.7%。

**务必分出两个层级**：指数是"价格水平"，通胀率是"价格水平的**变动率**"。平减指数 133 不是通胀 133%，而是"比基期贵 33%"。

**CPI 与 GDP 平减指数的三点区别**（本章最高频简答）：
1. **覆盖范围**：平减指数含**生产出来的全部**产品与服务；CPI 只含**消费者购买**的，故企业或政府购买品涨价只进平减指数。
2. **是否含进口品**：平减指数只含国内生产的产品（进口品不是 GDP 的组成部分）；CPI 篮子里有进口消费品，故进口消费品涨价推高 CPI 而不影响平减指数。
3. **权数**：CPI 用**固定权数**（固定篮子 = 拉氏指数 laspeyres）；平减指数用**变动权数**（当期产量 = 帕氏指数 Paasche）。橘子歉收、产量归零时，橘子涨价退出平减指数，却仍留在 CPI 篮子里推高 CPI。

### 六、失业的衡量：三个条件、两个比率、三种类型

**失业的定义**（国际劳工组织口径）三个条件**同时**成立：①在某个年龄以上（劳动年龄内）；②考察期限内**没有工作**；③**有能力工作并且正在寻找工作**。缺一不算——全职学生、料理家务者、退休者不是失业者。

美国劳工统计局家庭调查把 16 岁及以上成年人分三类：**就业者**（有酬雇员、在自有或家族企业工作，以及有工作但因假期、疾病、坏天气临时缺勤者）；**失业者**（愿意工作而无工作、**此前 4 周内寻找过**，以及被解雇正在等候召回者）；**不属于劳动力者**（全职学生、料理家务者、退休者，以及**"沮丧劳动者"**——想工作但放弃寻找的人）。

指标（式9.7–9.10）：**劳动力 = 就业人数 + 失业人数**；**失业率 = 失业人数 ÷ 劳动力人数 × 100%**；**就业率 = 就业人数 ÷ 劳动力人数 × 100%**，两者之和为 1；**劳动力参与率 = 劳动力人数 ÷ 劳动年龄人口数 × 100%**。教材数字例（表9-3）：劳动年龄人口 2.474 亿、就业 1.457 亿、失业 0.097 亿 → 失业率 = 0.097/1.554 = **6.2%**，参与率 = 1.554/2.474 = **62.8%**；0.92 亿"不属于劳动力"既不进分子也不进分母。

**三种类型**：
- **摩擦性失业（frictional）**：工人与岗位**匹配需要时间**。技能与岗位要求各异，岗位不断被创造和消灭，故一定程度的摩擦性失业**不可避免**。
- **结构性失业（structural）**：**技能或地域**与岗位要求**持续不匹配**。教材例：三维动画取代手绘动画，手绘动画师失业。需重新学技能，持续期长于摩擦性失业；**工资刚性**是重要原因（笔记详解）。
- **周期性失业（cyclical）**：随衰退上升、随扩张下降，源于**总需求不足**。**政府最关注**——它是判断是否达到充分就业的指标，也是宏观经济学研究的主要失业类型。

**充分就业与自然失业率**：当经济中**不存在周期性失业**（只剩摩擦性与结构性）即达**充分就业**，此时的失业率称**自然失业率（natural rate of unemployment）**。恒等式（式9.11）：**实际失业率 = 摩擦性失业率 + 结构性失业率 + 周期性失业率 = 自然失业率 + 周期性失业率**。故"实际 = 自然"⟺ 周期性失业为零 ⟺ 充分就业。

**潜在 GDP（potential GDP）**：现有资本与技术下，经济在**充分就业状态**所能生产的 GDP；它不是实际产出，**产出缺口 = 实际产出 − 潜在产出**。

**奥肯定律（Okun's law）**：本章只搭好"潜在 GDP／产出缺口"这套参照系，教材未给奥肯系数。答法定性即可：**失业率高于自然失业率 ⟺ 负产出缺口**，两者反向背离、同向变动；题目给了系数就按题给数值代入，别把某个经验系数当教材结论。

### 七、本章评析（马工程特色）

- **GDP 的缺陷**（六条）：不反映收入分配；只覆盖市场活动，漏掉家庭劳动与地下经济；不反映增长方式付出的代价（污染、生态破坏）；不反映效率与效益；不反映生活质量（闲暇、健康）；不反映重要的非市场活动（自家做饭、照顾老人）。改进方向：联合国《人类发展报告》的"社会指标"、世界银行**绿色 GDP**（名义 GDP 扣除自然资源与环境损失后的国内生产净值，比重越高正面效应越高）。
- **CPI 的偏差**：替代倾向、质量变化、新产品进入 → 可能**高估**生活成本上涨。**失业率的偏差**：沮丧劳动者退出劳动力会**压低**失业率，市场并未真正缓解。
- **中国口径**：长期用**城镇登记失业率**（只统计有非农业户口、16 岁至退休年龄、有劳动能力、无业且**主动到就业服务机构登记**者），把农民工与未登记毕业生排除在外，结果**偏低**；现行官方指标转向**调查失业率**（抽样推算的失业人口占全部劳动力的比重），更接近真实水平。

## Key Concepts / 核心概念

**国内生产总值（GDP）**：一定时期内一国（地区）境内生产的全部最终产品与服务的市场价值总和。
**国民生产总值（GNP）**：一国（地区）公民所拥有的生产要素在一定时期内生产的最终产品市场价值，按国民原则统计。
**最终产品与中间产品**：前者直接出售给最终使用者，后者被其他企业当作投入品；区分依据是用途。
**支出法（expenditure approach）**：把消费、投资、政府购买、净出口加总核算 GDP：GDP = C + I + G + NX。
**收入法（income approach）**：用要素成本核算：GDP = 工资 + 利息 + 租金 + 利润 + 折旧 + 间接税 − 补助金。
**名义／实际 GDP**：前者用当年价格，后者用基年价格（剔除价格因素后的产出）。
**GDP 平减指数（GDP deflator）**：名义 GDP 与实际 GDP 之比，权数随当期产量变动，覆盖全部国内生产的产品。
**消费价格指数（CPI）**：固定"商品篮子"的现期费用与基期费用之比，固定权数，含进口消费品。
**失业率（unemployment rate）**：失业人数占劳动力人数的百分比，分母是劳动力而非总人口。
**劳动力参与率（labor force participation rate）**：劳动力人数占劳动年龄人口数的百分比。
**自然失业率（natural rate）**：不存在周期性失业时的失业率，即摩擦性失业率与结构性失业率之和。
**潜在 GDP（potential GDP）**：充分就业状态下所能生产的 GDP，与实际产出之差即产出缺口。

## Mental Models / 思维模型

1. **两条回路数同一笔钱**：同一经济体，从买者口袋数（支出）与从卖者账上数（收入）必然相等，因为每笔交易同时是某人的支出和另一人的收入。三种核算法打架，差额只可能是统计误差。
2. **GDP 是按"价格 × 数量"造出来的尺子，同一批产量能折出三个数**：名义 = 现价 × 现量；实际 = 基价 × 现量；平减指数 = 现价 ÷ 基价。故平减指数是"价格"，通胀率是"价格的变化率"。任何计算先问"手里是哪一个、要换成哪一个"。
3. **权数决定指数高低**：同一个价格变动，权重不同则结论不同。固定篮子（拉氏）会高估生活成本上涨——消费者会用变便宜的东西替代变贵的，而篮子假装他们不会。
4. **分母决定一切**：失业率的分母是劳动力，沮丧劳动者一放弃寻找就退出分母，失业率"下降"而市场未改善——失业率必须配着劳动参与率读。存量与流量同理：GDP 是水龙头流量，资本存量是水位，投资注水、折旧漏水。

## Anti-patterns / 常见错误

- **把二手货、古董、拍卖名画算进当年 GDP**：GDP 核算**当期生产**而非当期交易；这些货在生产当年已计入。注意**中介佣金**是当期新服务，要计入。
- **把买股票、债券当投资**：从个人看是投资，从经济学看只是产权转移，一方买必有一方卖，对社会总投资贡献为零；只有公司拿钱去建厂买设备才计入。
- **把家务劳动、自给自足算进 GDP**：GDP 是市场价值概念，非市场活动被排除——这是它的缺陷，不是定义漏洞。
- **名义与实际用错价格**：名义用当年价格、实际用基期价格。写成"实际 GDP 用当年价格"是全章最典型的口误。
- **把平减指数数值当通胀率**：指数 133 是比基期贵 33%，不是通胀 133%；只有基期为 100 时，指数减 100 才等于累计涨幅。
- **CPI 与平减指数只答两点区别**：必须答全范围、进口品、权数三条，且每条说清"为什么"（进口品不是 GDP 的组成部分，故不进平减指数）。
- **失业率分母用总人口或劳动年龄人口**：分母是劳动力；用劳动年龄人口会把学生、主妇、退休者算成失业者。
- **把沮丧劳动者算作失业者**：他们属"不属于劳动力者"，退出劳动力 → 失业率被**低估**。

## Reference Tables / 速查表

**表 A GDP 四个限定词与各自排除项**

| 限定词 | 管什么 | 排除（不计入 GDP） |
|---|---|---|
| 市场价值 | 折成货币，解决实物量不可加总 | 家务劳动、自给自足、地下经济 |
| 最终产品 | 只算最终使用，避免重复计算 | 中间产品（靠增值法扣除） |
| 一国境内 | 国土原则（GNP 用国民原则） | 本国企业在海外生产的产值 |
| 一定时期 | 流量而非存量 | 二手货、古董等存量资产再交易 |

**表 B 指标链与公式**

| 指标 | 公式 | 含义 |
|---|---|---|
| GDP | C + I + G + NX | 境内生产的最终产品市场价值 |
| GNP | GDP + 国外要素净收入 | 本国公民拥有的要素所得 |

## Worked Example / 工作示例

**题**（题型取自题库计算题，中国海洋大学 2020；数据照录、解法重写并加第三问）：某经济体只生产手机和蔬菜。2017 年：手机 10 部、单价 100 元，蔬菜 20 吨、单价 100 元。2018 年：手机 20 部、单价 50 元，蔬菜 25 吨、单价 200 元。

（1）计算两年名义 GDP；以 2017 年为基期，计算两年实际 GDP 与平减指数。（2）若消费者篮子 = 1 部手机 + 2 吨蔬菜，以 2017 年为基期算两年 CPI。（3）用平减指数与用 CPI 分别算 2018 年通胀率，为何不同？

**解（1）** 名义 GDP = 当年价格 × 当年数量：2017 年 10×100 + 20×100 = **3 000** 元；2018 年 20×50 + 25×200 = **6 000** 元。实际 GDP = 基期（2017）价格 × 当年数量：2017 年（基期年，名义 = 实际）**3 000** 元；2018 年 20×100 + 25×100 = **4 500** 元。平减指数 = 名义 ÷ 实际 × 100：2017 年 3 000/3 000 × 100 = **100**；2018 年 6 000/4 500 × 100 ≈ **133.3**。

**解（2）** 篮子固定，分母永远是**基期价格下的篮子费用**：1×100 + 2×100 = **300** 元。2017 年 CPI = 300/300 × 100 = **100**；2018 年篮子费用 = 1×50 + 2×200 = **450** 元 → CPI = 450/300 × 100 = **150**。对照（1）：2017→2018 名义 GDP 涨 100%，实际 GDP 只涨 50%，差额全是价格。

**解（3）** 平减指数口径 π = (133.3 − 100)/100 = **33.3%**；CPI 口径 π = (150 − 100)/100 = **50%**。根源在权数。把两个指数都改写成"价格相对数的加权平均"验算：手机价格相对数 = 0.5（跌 50%），蔬菜 = 2.0（涨 100%）。

- CPI（拉氏）权数 = 基期支出 p₀q₀：手机 1 000、蔬菜 2 000，各占 1/3、2/3 → (1/3)(0.5) + (2/3)(2.0) = **1.50**，涨 50% ✓
- 平减指数（帕氏）权数 = 基期价格 × **当期**数量 p₀q₁：手机 2 000、蔬菜 2 500，各占 44.4%、55.6% → (0.444)(0.5) + (0.556)(2.0) = **1.333**，涨 33.3% ✓

结论：手机产量翻倍而价格腰斩，变动权数下手机分量被放大（44.4% 对 33.3%），跌幅抵消了更多涨幅；CPI 的固定篮子却假装消费者仍按 1∶2 购买，把 50% 的涨幅全数记下——这就是"固定权数倾向高估生活成本上涨"的算术表现。

## 解题套路 / Solution Patterns

**1｜名词解释（GDP、GNP、NDP、平减指数、CPI、潜在 GDP、流量与存量）**
四段式：严格定义（GDP 必带"市场价值／最终产品／境内／一定时期"，GNP 必点"国民原则"）→ 公式或关系式 → 与近邻的差别（GDP vs GNP、平减指数 vs CPI、潜在 vs 实际）→ 一句评价。易错：漏限定词；把平减指数说成通胀率；把潜在 GDP 说成"技术上的最大产量"。

**2｜简答与论述：比较指标 / 列举缺陷 / 评价政策口径**
CPI vs 平减指数按"范围 → 进口品 → 权数"三条，每条写清"为什么"；GDP 缺陷按"分配—非市场—代价—效率—生活质量—福利"六条排，收尾补绿色 GDP 或新发展理念；失业类型三分法 + 成因 + "政府最关注周期性失业，因为它是充分就业的判据"；论述题（武汉大学真题式）走"核算原则三条（当年生产、境内、最终产品）→ 缺陷六条 → 绿色 GDP"。易错：只列名称不说成因；漏掉结构性失业的工资刚性。

**3｜计算 I：名义／实际／平减指数／CPI／通胀率**
①名义 = Σ 当期价 × 当期量；②实际 = Σ 基期价 × 当期量；③平减 = 名义 ÷ 实际 × 100（基期年为 100）；④CPI = 当期篮子费用 ÷ 基期篮子费用 × 100（**数量固定**）；⑤通胀率 = (本期指数 − 上期指数) ÷ 上期指数。易错：算 CPI 时用了当期数量（那就成了平减指数）；基期年平减指数写成 0；通胀率分母用本期值。

**4｜计算 II：GDP → NDP → NI → PI → DPI 与储蓄恒等式**
①折旧 = 总投资 − 净投资（题给两项时先减）；②GDP = C + I（总投资）+ G + NX，反求 NX = GDP − C − I − G；③NDP = GDP − 折旧；④NI = NDP − 间接税；⑤PI = NI − 公司未分配利润 − 公司所得税 − 社保 + 转移支付；⑥DPI = PI − 个人所得税；⑦S = DPI − C；⑧三部门恒等式 I = Sp + Sg + Sr（Sg = T − G = 预算盈余 BS）。易错：把净投资当 I；把政府购买当政府支出（T 要另算，T = BS + G）；缺间接税数据仍硬减。

**5｜判断／选择：这笔交易计入 GDP 吗**
四问依次过：①是**当期生产**的吗（排除二手、古董、拍卖）？②经过**市场**吗（排除家务、自给自足、地下经济）？③是**最终产品**吗（排除中间产品）？④是**生产行为**吗（排除股票债券、转移支付、公债利息）？四问全过再定归属 C／I／G／NX。库存增加归投资、外国政府购买归净出口，是最高频的两个正向例子。

## Key Takeaways / 关键结论

1. GDP 四个限定词各自排除一类东西：非市场活动、中间产品、本国企业海外产值、二手与存量交易。判断题先过这四关。
2. 三种核算法必然相等（产出 = 支出 = 收入），差额只是统计误差；Y 视场合叫总产出、总支出或总收入。
3. 支出法记 I 用**总投资**，记 C 时剔出住宅（归投资），记 G 时剔出转移支付。
4. 名义用当年价格、实际用基期价格；平减指数是**价格水平**，通胀率才是它的**变动率**。
5. CPI 与平减指数的三点区别是范围、进口品、权数；固定权数使 CPI 倾向高估生活成本上涨。
6. 失业率的分母是劳动力；沮丧劳动者退出劳动力会压低失业率，读数必须配劳动参与率。实际失业率 = 自然失业率 + 周期性失业率，政府盯的是周期性那一项。

## Connects To / 与其他章节的联系

- **上游**：本章是宏观部分第一章，经济学上无前置；数学上用到**加权平均与内积**——GDP 就是价格向量与数量向量的内积 Σpᵢqᵢ，价格指数是两个内积之比，这解释了"权数怎么定"为何能改变指数结果（线性代数的内积、数学分析的增长率与差分都在此出场）。

- **第13章 失业与通货膨胀**：教材在第二节末、第三节末两处自引——价格水平与失业在本章只做**描述与衡量**，原因与影响留到第13章；自然失业率与潜在 GDP 在那里成为菲利普斯曲线的锚，潜在 GDP 也是 AD-AS 中长期总供给的垂直位置。
