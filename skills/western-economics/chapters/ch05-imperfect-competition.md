# 第5章 不完全竞争市场 (Imperfect Competition)

> 马工程《西方经济学》(第二版) · 上册  —  教材 + 笔记详解 + 配套题库 + 习题解答 综合整理

## Core Idea / 核心思想

第4章的企业只有产量一个旋钮，价格由市场给定；本章把定价权交回企业，需求曲线向右下方倾斜，`MR<P` 成为全部结论的源头。垄断、垄断竞争、寡头的差别只在两点：**需求曲线有多陡**，**对手会不会反应**（一条线、d 与 D 两条线、取决于对手策略）。于是 `P>MC` 成为常态，价格歧视、策略行为、效率损失依次展开。本章是上册最重的一章（23★，独占四个五星考点）。

## Frameworks Introduced / 核心框架

### 一、总纲：右下倾斜 ⟹ `MR<P` ⟹ 无供给曲线

不完全竞争的共性：需求曲线向右下方倾斜（程度不同）。两条推论：

- **`MR<P`**：多卖一单位须对**全部产量**降价，MR 永远在需求曲线下方。
- **无供给曲线**。教材反证为"同一价格两个产量"：同一条 MC，需求为 `d₁` 时均衡 `(P*, Q₁)`，换成 `d₂` 后价格**仍是 `P*`**、产量却是 `Q₂`，违反"一个价格对应唯一供给量"的定义。故**所有**不完全竞争企业都没有供给曲线。

### 二、垄断：四类成因与自然垄断

垄断＝市场"只此一家"，产量占 100%，故面临的需求即市场需求。成因：**资源垄断**（关键资源独有）、**特许垄断**（政府授权，公用事业典型）、**专利垄断**（授予端属特许、性质端属资源）、**自然垄断**（规模经济）。

自然垄断：固定成本大、MC 极小 ⟹ LAC 随产量持续下降至"可盈利价格下满足市场"的充分大产量；多家生产谁都到不了最低成本 ⟹ 各自扩产降价（**价格战**）⟹ 胜者独占。此后不被进入打破（其 LAC 全场最低）：进入者产量低于最小有效规模 `Q₀` 时成本高于 `P*`，进入即亏；介于 `Q₀` 与 `Q*` 间时，在位者把价压到 `P₀` 仍有利可图；超过 `Q*` 时跟进同产量、按约等于自身 LAC 定价。**规模经济既是成因，也是护城河**。

### 三、收益曲线（式5.1–5.4）

`P=α−βQ` ⟹ `R=αQ−βQ²`（抛物线，`Q=α/2β` 处最大）、`AR=P=α−βQ`（**与需求曲线重合**）、`MR=α−2βQ`。

**几何必背**：MR 与 AR **纵截距同为 `α`**、**斜率是两倍**；MR 与横轴交于 `α/2β`，恰为 AR 交点 `α/β` 的**一半**。`MR>0` 时 TR 升、`=0` 最大、`<0` 降。

**为何 `MR<P`**：`MR=P+Q·dP/dQ`，第二项为负——多卖一单位**得到**该单位卖价，却因全部产量降价**损失** `Q|dP/dQ|`。由此得 `MR=P(1−1/e_d)`：`e_d>1` 才 MR>0，故**垄断只在 `e_d>1` 区间生产**。

### 四、短期均衡

`MR=MC` 定 `Q₀` → 由 `Q₀` 上需求曲线的高度定 `P₀`。**两者必须同时决定**：若在 `Q₀` 上定价不等于 `P₀`，`Q₀` 便不再是利润最大化产量（完全竞争只需定产量）。盈亏三种：`P₀>AC` 得利润 `(P₀−P₁)Q₀`；`P₀<AC` 亏损 `(P₁−P₀)Q₀`，停产仍比 `AR` 与 `AVC`；`P₀=AC` 不亏不盈属**偶然**。整条 `d` 低于 AC 时，垄断短期**也会亏损**。

### 五、长期均衡与低效率

规模调整：`LMR=LMC`，最优规模上 `LMC=MC*`、`LAC=AC*`。行业调整**只有退出、没有进入** ⟹ 长期有**两种**结果：不亏不盈**或盈利**（后者更常见），完全竞争只有一种。条件：`LMR=LMC=MR=MC*`、`LAR=AR≥LAC=AC*`（完全竞争取等）；产量也可能落在 LAC 最低点**右边**。

**低效率与无谓损失**：`d` 右下倾斜 ⟹ `MR<d` ⟹ `MR=MC` ⟹ **`MC<P`**：最后一单位的社会价值高于其边际成本，增产对社会有利却无人增。故 `Q*` 小于 `P=MC` 对应的效率产量 `Q_e`，二者之间需求曲线高于 MC 的面积即**无谓损失**。

### 六、价格歧视

把相同成本的产品以不同价格出售（可扩至"价差显著不同于成本差"）。两个条件：**企业侧**——有定价能力**且无其他企业竞争**（故垄断竞争、寡头企业一提高价，竞争者就把高价顾客抢走）；**消费者侧**——偏好**不同**且市场**隔离**（无转售）。

| | 定价单位 | 与 D 的关系 | 消费者剩余 | 效率 |
|---|---|---|---|---|
| **一级** | 每**单位**按最高意愿支付 | `MR` 与 `D` 重合 | 全夺（CS=0） | `P=MC`，有效率 |
| **二级** | 分"堆"、按堆定价 | 不重合 | 部分保留 | 无效率 |
| **三级** | 按**群体**（弹性不同） | 一般不重合 | 群体间再分配 | 无效率 |

**一级**：逐单位定价、无须对前面各单位让价 ⟹ `MR=D` ⟹ `MR=MC` 变为 `P=MC` ⟹ 产量达完全竞争水平而剩余全归企业；须掌握每单位意愿支付，属理想化。**二级**：`Q₃` 分 `OQ₁`、`Q₁Q₂`、`Q₂Q₃`，意愿支付 `P₁>P₂>P₃`，分段定价，消费者仍留部分剩余 ⟹ 无效率。**三级**：`MR_a=MR_b`（否则把销量挪向高 MR 群体即可增利）⟹ `P_a(1−1/E_a)=P_b(1−1/E_b)`（5.6）；`E_a>E_b` 必有 `P_a<P_b`；例 `E_a=3, E_b=2` ⟹ `P_a=(3/4)P_b`。**弹性大者低价**。

### 七、垄断竞争：两个"介于"

许多企业生产**有差别**的同种产品，份额微小、进出自由、规模不大、略有定价权。两个"介于"：**替代性**——完全竞争无穷大（需求水平）、垄断为 0（需求陡峭）、垄断竞争居中（向右下但平缓）；**地位**——"具有产品差异的完全竞争企业"，形成差异则升格、失去差异则降格。

**d 与 D**：`d` 是别家**不变价**时的（主观）需求曲线，较平缓，**决定收益曲线**；`D` 是别家**同幅变价**时的（实际）曲线，较陡。d 更平缓，因降价既改变老顾客购买量、又**抢来**别家顾客；`D` 下相对价格未变，只能改变老顾客购买量。二者只是两个极端，中间还有无数条——这正是"同一企业面临多条需求曲线"的答案。

**短期**：`MR=SMC` 定 `Q₀`、`d` 定 `P₀`，可盈可亏；另需 `d` 与 `D` 的**交点**所定销量恰等于利润最大化产量。

**长期**：可进可出 ⟹ 只有**不亏不盈**；`d` 与 `MR` 左下移，直到 `d` 与 `LAC` **相切**；条件 `LMR=LMC=MR=MC*`、`LAR=LAC=AR=AC*`。

**切点必在 LAC 最低点左侧**：相切要求斜率相等，`d` 为负斜率，而 LAC 只在最低点以左的下降段为负（切在最低点则 `d` 须水平，那便是完全竞争）。由此得**生产能力过剩**：均衡产量小于 LAC 最低点产量，且 `LMC≠LAC`、`SMC≠SAC`。

### 八、寡头：古诺、价格领袖、斯威齐

寡头＝少数大企业控制大部分产销，成因同垄断而数目为"少数"。**唯一共性是相互依赖**：其行为改变市场状况 → 对手反应 → 反应又改变最初行动的效果，即"**影响—反应**"链条；完全竞争与垄断竞争企业太小、垄断"只此一家"，都无须顾及对手。故**寡头无统一模型，只有关于"对手如何反应"的假定**：产量不变→古诺；同幅跟价→价格领袖；跟跌不跟涨→斯威齐。

**古诺**（双寡头、同质、成本为零、需求线性、各自把对方产量视为既定）：以市场需求减去对手的不变产量 `ΔQ` 得本企业需求；`MR₁=α−βQ₂−2βQ₁=0` ⟹ 反应函数 `Q₁=α/2β−Q₂/2`，联立得 `Q₁=Q₂=α/3β`、`Q=2α/3β`、`P=α/3`。**排序**：完全竞争 `α/β` > 古诺 `2α/3β` > 垄断 `α/2β`；**n 家**时每家 `Q_c/(n+1)`、行业 `nQ_c/(n+1)`。古诺均衡是**纳什均衡**的一例。

**价格领袖**：小企业按 `P=MC` 供给任意量，大企业供给**剩余需求**（`D−S` 得 `d`，再 `MR=MC` 定 `Q*`、`P₀`）；无支配地位而率先变价者称**测温计型企业**。

**斯威齐**：假定**跟跌不跟涨** ⟹ `P₀` 之上提价无人跟、顾客大量流失（需求平缓），之下降价人人跟、抢不来顾客（需求陡峭）⟹ 需求在 `P₀` **折弯**；两段各一条 MR，在折点**断开**成垂直缺口。**MC 穿过缺口则无交点** ⟹ **价格刚性**：成本与需求小幅变动不改 `P₀`、`Q₀`，只有 MC 越出缺口才变。缺陷：**不能解释 `P₀` 如何形成**。

### 九、卡特尔

以正式协议协调产量与价格、**像一个垄断者行动**的企业集团。`MR=MC`，需求即市场需求，而 **MC 是各成员 MC 的水平相加**——这是与垄断的唯一区别。零成本、`P=α−βQ` 时：卡特尔 `Q*=α/2β`、`P*=α/2`、`π*=α²/4β`；古诺合计 `2α²/9β`。故合谋**产量更低、价格更高、总利润更大**。分配的理想办法是**各成员 MC 相等**，现实按影响力、历史销售、生产潜力、区域。**不稳定源于激励**：他人守约时，偷降价者面对的需求**弹性很大**，小幅降价即大幅扩销 ⟹ 人人有破约动机。

### 十、博弈论与两个应用

**三要素**：参与人、策略（每一时点如何行动的规则）、支付。二人博弈写成**支付矩阵**，格内为 `(A, B)`。

**纳什均衡**：给定他人策略不变、**无人能单独改变策略增加支付**的组合。**划线法**：对 A 的每一策略，在 B 各策略下找 A 的最优支付划线；对 B 同做；**两数字都被划线**的格子即均衡。并非每个博弈都有均衡。

**占优策略 vs 条件（相对）优势策略**：后者是**给定对手已选某策略**时的最优（划线法找的就是它）；前者**无论对手怎么选**都最优，更强，有它则均衡可直接读出。

**卡特尔＝囚徒困境**：`(合作,合作)=(5,6)`、`(不合作,不合作)=(2,3)`、单方背叛得 7 ⟹ 唯一均衡 `(2,3)`，**劣于** `(5,6)`；但对方守约时我可从 5（或 6）增到 7 ⟹ 个体理性导致集体次优。

**序列博弈与逆向归纳**：先动者把后动者的**反应函数代入**自己目标再最优化（斯塔克尔伯格即此手法）；**策略性贸易政策**说明补贴可改变支付矩阵——补贴 5 使"生产"成为后动者的**占优策略**，其支付由 0 增至 13，**增量远大于补贴**。

### 十一、不同市场的比较（论述题固定考点）

基准：各自**长期利润最大化**状态，并假定需求曲线与成本曲线相同。

| 维度 | 完全竞争 | 垄断竞争 | 寡头 | 垄断 |
|---|---|---|---|---|
| 成本 | LAC **最低点** | 最低点之前的下降段 | 一般更高 | 常高于最低点 |
| 价格 | `=LAC` 最低值（最低） | `=LAC` 但 LAC 非最低 | 较高 | 最高（常 `>LAC`） |
| 行业产量 | 最大 | 较大 | 较低 | 最低 |
| 长期经济利润 | 无 | 无 | 有 | 有 |
| `P` 与 `LMC` | `=` | `>` | `>` | `>` |

- **产量陷阱**：就**单个企业**看，完全竞争产量未必更大（常小于垄断企业）；就**行业**看一定更大——因为价格更低。
- **`P=LMC` 即效率**：`P` 度量边际社会价值，`LMC` 近似边际社会成本；`P>LMC` 意味着增产对社会有利却未增。经济利润的存在意味着**分给该行业的资源太少**（源于进入障碍），故超额利润是进入障碍的信号。
- **动态**：**创新成本**——重大创新需巨资，小企业难提供，垄断的超额利润正好提供；**创新收益**——完全竞争下无人能阻止模仿、好处被瓜分，垄断者因壁垒能留住。故其技术进步可能更快，**足以抵消静态低效率而有余**。
- **评析**：四类成因"过于简单、表面化"，未看到**竞争导致垄断**——成本不同 → 盈利者扩产、亏损者退出 → 份额扩大 → 寡头 → 再联合成垄断；又，"垄断需求曲线＝市场需求曲线"未必成立：高价引来进入者，需求在**进入价格**处**再次扭折**（以下同市场需求、以上更平缓），均衡若在扭折点左侧，实际定价更**低**。

## Key Concepts / 核心概念

- **垄断（monopoly）**：全市场只有一家、产品无相近替代品、进入极难，故其面临的需求曲线就是市场需求曲线。
- **自然垄断（natural monopoly）**：规模经济使一家供给全市场的成本低于两家以上，一家的 LAC 即全场最低。
- **价格歧视（price discrimination）**：以不同价格出售相同成本的产品；需企业有定价能力且无竞争者、消费者偏好不同且市场隔离。
- **一级价格歧视**：对每一单位按最高意愿支付定价，`MR` 与 `D` 重合、`P=MC`，产量达完全竞争水平而消费者剩余为零，因而有效率。
- **三级价格歧视**：按可识别群体的弹性分组定价，`MR_a=MR_b`，弹性大者价低。
- **垄断竞争（monopolistic competition）**：众多企业生产有差别的同种产品、进出自由，需求曲线向右下倾斜但相当平缓。
- **d 曲线／D 曲线**：`d` 为"别家不变价"时的主观需求曲线（较平缓，决定收益曲线）；`D` 为"别家同幅变价"时的实际需求曲线（较陡）。
- **生产能力过剩（excess capacity）**：垄断竞争长期均衡产量小于 LAC 最低点产量，其差额即闲置能力。

## Mental Models / 思维模型

- **"需求曲线的斜率就是企业的权力"**：完全竞争水平（权力为零）→ 垄断竞争略斜 → 寡头取决于对手反应 → 垄断最陡。凡问"能否定价、能否歧视、是否有效率"，先看斜率，再看对手会不会反应。
- **"MR 是降价的代价表"**：多卖一单位赚一个 `P`，却要对已有产量让价。这一条同时给出 `MR<P`、`MR=P(1−1/e_d)`，以及一级价格歧视为何能消灭该差额。
- **"进出的对称性决定长期利润"**：进出都自由→零经济利润；只出不进→可能有利润；少数几家互相牵制→看是否合谋。问"长期能否有超额利润"，只问一句：**新企业进得来吗？**

## Anti-patterns / 常见错误

- **把 MR 的斜率写成与需求曲线相同**：`P=α−βQ` 对应 `MR=α−2βQ`——同截距、**两倍斜率**、与横轴交点减半。写成 `−β` 会使后续产量与价格全错。
- **以为"垄断无供给曲线"是因为"只有一家"**：真正原因是需求右下倾斜使 `MR≠P`，同一价格可对多个产量；故**所有**不完全竞争企业都没有供给曲线，包括企业众多的垄断竞争。
- **把垄断的"不亏不盈"当作长期必然**：那是偶然巧合；长期有两种结果（不亏不盈或盈利），因进入被阻断。
- **认为垄断竞争长期有经济利润、或把切点说成在 LAC 最低点**：进出自由 ⟹ `P=LAC` ⟹ 只有正常利润；`d` 向下倾斜，相切只能在最低点**左侧**，由此才有生产能力过剩。
- **古诺里把对手产量也当"会跟着变"**：古诺的核心是 `∂Q₂/∂Q₁=0`；对手会反应则是斯塔克尔伯格（代入反应函数）或斯威齐（跟跌不跟涨）。
- **把一级与三级价格歧视的效率结论混谈**：一级无福利损失，三级仍有 `P>MC`；"价格歧视必然降低效率"是错的。

**速查　`MR=P(1−1/e_d)`**：`e_d>1` 时 MR 为正、TR 升；`e_d=1` 时 TR 最大；`e_d<1` 时 MR 为负、TR 降。**三个"没有"**：不完全竞争没有供给曲线；垄断没有长期零利润的必然性；寡头没有统一模型。

## Worked Example / 工作示例

**题目**：某同质产品市场 `P=160−Q`（`Q=q₁+q₂`），两企业 `MC=40`、无固定成本。求①垄断、②古诺、③企业2先行动、④合谋并平分，并比较。

**① 垄断（基准）**：`MR=160−2Q`，令 `=MC=40` 得 `Q=60`，`P=100`，`π=(100−40)×60=3600`。此即"两步走"：`MR=MC` 只定产量，价格须回需求曲线取。

**② 古诺**：`π₁=(160−q₁−q₂)q₁−40q₁`，令 `∂π₁/∂q₁=0`：`160−2q₁−q₂−40=0` ⟹ 反应函数 `q₁=60−q₂/2`；对称 `q₂=60−q₁/2`。联立（或用对称性 `2q=120−q`）：`q₁=q₂=40`，`Q=80`，`P=80`，`π₁=π₂=1600`，合计 3200。校验：1600 < 1800（垄断利润之半）。

**③ 斯塔克尔伯格（企业2先动）**：后动者仍按 `q₁=60−q₂/2`。先动者把它**代入**自己利润（即逆向归纳），化得 `π₂=60q₂−q₂²/2`；令 `60−q₂=0` ⟹ `q₂=60`，回代 `q₁=30`，`Q=90`，`P=70`；`π₂=1800`、`π₁=900`，合计 2700。校验：先动者 1800 > 古诺 1600 > 后动者 900；但总利润 2700 < 3200。

**④ 卡特尔**：视两家为一家，`MR=160−2Q`；成员 MC 水平相加，两家均为 40 故仍为 40（各产 30、各自 MC=40，符合"各成员 MC 相等"）。`160−2Q=40` ⟹ `Q=60`，`P=100`，总利润 3600，平分各 1800。校验：与①完全相同——合谋就是"像一个垄断者行动"，只是 MC 由成员相加而来。

**⑤ 比较**：产量 `60<80<90`，价格 `100>80>70`，总利润 `3600>3200>2700`。卡特尔不稳定的数字依据：在 `(30,30)` 上任一方把产量提到 40 而对方不动，利润由 1800 升到 `(160−70−40)×40=2000`。

## 解题套路 / Solution Patterns

**题型一：名词解释与判断题。** 四段式：**定义 → 条件或公式 → 图形语言 → 一句用途**（例：古诺均衡＝两条反应曲线交点，由"对手产量既定"下 `MR=MC` 解出，是纳什均衡的一例）。判断题高频：① 垄断者可任意定价——**错**；② 一级价格歧视福利损失最大——**错**（反而有效率）；③ 自然垄断源于掌握自然资源——**错**（源于规模经济）；④ 三级价格歧视把消费者剩余转化为生产者剩余——**错**（可同时增加二者）；⑤ 可变成本为零时按收益最大定价——**对**。

**题型二：垄断均衡计算（含税、限价）。** 由需求求 `MR`（线性 `P=a−bQ` ⟹ `MR=a−2bQ`；给 `Q=c−dP` 先反解）→ `MR=MC` 解产量（两正根时舍去不满足二阶条件者）→ 回需求曲线得价格 → `π=PQ−TC`。**从量税**使 MC 加 `t`（价格涨幅小于 `t`）；**固定税**不改 MC，价格产量不变、只减利润；**限价**取 `P=MC` 或 `P=AC`。易错：把税加到 AC 上；限价时忘掉价格须落在需求曲线上。

**题型三：三态产量博弈。** 古诺：写 `π_i` → 对 `q_i` 求偏导令零得反应函数 → 联立（同成本用对称性）→ 回代求 `P`、`π`。斯塔克尔伯格：后动者反应函数代入先动者利润 → 求导 → 回代。卡特尔：合成一家，`MR` 等于成员 MC 的**水平相加** → 定 `Q`、`P` → 按"各成员 MC 相等"分产量。易错：古诺里把对手产量也当变量求导（丢掉 `∂q₂/∂q₁=0`）；把两家 MC 数值相加成 80（水平相加是"在每一产量上"加）。

**题型四：价格歧视。** 三级：`MR₁=MR₂=MC`，或用 `P(1−1/e)=MC` 分别解两市场价格——**先各自求 MR 再联立 MC**。一级与二级多考概念与剩余：一级夺走全部 CS，二级按"分堆"逐段算保留量。易错：把"弹性大者高价"记反（正确是**弹性大者低价**）；忘验证 `e>1`。

**题型五：垄断竞争长期均衡。** 由 LTC 求 LAC → 联立 `MR=LMC` 与 `P=LAC`（MR 由 d 曲线推出）→ 解 `Q`、`P` → 与 LAC 最低点比较，差额即过剩产能。易错：把 `P=LAC` 与 `MR=LAC` 混用；忘用"d 为负斜率、只能在 LAC 下降段相切"作检验。

**题型六：论述题（两个固定考法）。** ① *折弯需求曲线与价格刚性*：假定（跟跌不跟涨）→ 折点上下斜率不同 → 两段各一条 MR、断成垂直缺口 → MC 穿过缺口则价格产量不变 → 价格刚性 → 缺陷（不解释现行价格如何形成）。② *比较*：先声明基准，再按**成本—价格—产量—利润—`P` 与 `LMC`** 五项对照（第十一节表），补"单个企业产量未必更小、行业产量一定更小"，再加动态效率。易错：只列结论不写传导机制。

## Key Takeaways / 关键结论

1. **一切差异源于需求曲线的斜率**：右下倾斜 ⟹ `MR<P` ⟹ `P>MC` ⟹ 无供给曲线、有低效率、可能长期有利润。完全竞争只是斜率为零的特例。
2. **`P=α−βQ` 与 `MR=α−2βQ` 必须条件反射**：同截距、两倍斜率、与横轴交点减半；`MR=P(1−1/e_d)` 说明垄断只在 `e_d>1` 区间生产。
3. **垄断长期有两种结果，垄断竞争只有一种**：差别只在"新企业进不进得来"；前者可能保有垄断利润，后者必被磨到 `P=LAC`。
4. **垄断竞争的低效率不在利润而在产能**：切点在 LAC 最低点左侧（因 d 向下倾斜），成本非最低、产量非最大，差额即生产能力过剩。
5. **寡头没有模型，只有假定**：古诺（对手产量不变，`Q=2α/3β`）、价格领袖（剩余需求 `D−S`）、斯威齐（MR 缺口 ⟹ 价格刚性）；答题须先声明假定。
6. **卡特尔＝垄断＋成员 MC 水平相加，且天生不稳定**：`α²/4β > 2α²/9β` 的差额就是背叛的诱惑；矩阵划线得唯一均衡（不合作，不合作）。
7. **效率排序是论述题的标准答案**：完全竞争 > 垄断竞争 > 寡头 > 垄断，判据是 `P=LMC` 与 `P>LMC`；但须补上动态效率与规模经济、产品差别，结论才完整。

## Connects To / 与其他章节的联系

- **第1—2章**：弹性成为定价工具（`MR=P(1−1/e_d)`），消费者剩余是价格歧视的分配对象；需求右下倾斜的微观基础是边际效用递减，一级价格歧视正是把需求曲线读成"支付意愿表"。
- **第3—4章**：MC、AC、LAC 的 U 形与包络关系是本章均衡的几何底座；本章又逐条打破第4章——需求由水平变倾斜、`MR` 由 `=P` 变为 `<P`、长期利润由必零变可能为正、`P=MC` 变 `P>MC`、供给曲线由存在变不存在。
- **第6章**：要素需求来自 `MRP=MR·MP`；完全竞争下 `MR=P` 故 `MRP=VMP`，本章 `MR<P` 使 `MRP<VMP`——产品市场垄断扭曲要素市场的起点。**第8章**：`P>MC` 的无谓损失是福利分析的标准案例，自然垄断的价格管制（边际成本定价、平均成本定价、双重定价）是政府干预的典型场景。
- **数学分析**：`MR` 是 TR 的导数，MR 与横轴交点恰为 AR 之半源于线性函数性质；古诺是二元函数一阶条件加方程组求解，斯塔克尔伯格是代入消元（逆向归纳）；垄断竞争长期均衡是"`MR=LMC`"与"`P=LAC`"联立，即"相切 ⟹ 斜率相等"。
