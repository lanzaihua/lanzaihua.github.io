## 一、三种用法

**① 考前 3 天｜只刷高热度章**
主战场是真题 ≥15 条的五章：ch13（22）、ch15（21）、ch11（17）、ch03（15）、ch08（15）= 90 条，占全部真题 42%。每章：读 exercises「二、考研真题精选」默写骨架 → 「四、计算题精解」手算 1 道 → 考前 1 小时只翻第三部分。

**② 平时作业｜按章对号入座**
卡住先回 [chapters/](chapters/) 同章 `## Frameworks Introduced` 找公式，再看 exercises 同章「一、教材课后习题」的**要点 / 易错**。别抄答案：先列分点再对要点查漏。

**③ 名词解释突击｜三行封顶**
定义（1 句）→ 公式或分类（1 行）→ 结论（1 句），三行封顶。只背 Top 40，冷门术语用"定义 + 例子"临场编。

## 三、必背名词解释 Top 40

*格式：术语 + 一句话定义 +〔最热出处〕。*

**ch01** 1. **需求价格弹性**：需求量对价格变动的反应程度，`Ed=−(dQ/dP)(P/Q)`。〔厦大2017研〕 2. **需求收入弹性**：需求量对收入变动的反应程度，>0 正常品、0–1 必需品、<0 低档品。〔厦大2022研〕 3. **蛛网模型**：用弹性解释生产周期长的商品失衡后的波动，收敛/发散/封闭由 `δ`、`β` 定。〔中南财经政法2021研〕

**ch02** 4. **消费者剩余**：愿付最高总价与实际支付之差，需求曲线下、价格线上。〔人大2019研〕 5. **无差异曲线**：带来相同效用的两商品全部组合，凸向原点。〔中国海洋2022研〕 6. **边际替代率**：效用不变时增 1 单位商品 1 需放弃的商品 2，`MRS12=MU1/MU2`。〔华南理工2022研〕

**ch03** 7. **边际报酬递减规律**：技术与其他要素不变，可变要素超过某点后 MP 递减。〔人大2019研〕 8. **边际技术替代率**：产量不变时增 1 单位要素所减少的另一要素，`MRTS=MP_L/MP_K`。〔中央财经2015研〕 9. **机会成本**：资源用于某用途而放弃的其他用途中的**最高**收益。〔南大2021研〕

**ch04** 10. **生产者剩余**：实际总支付与愿接受的最小总支付之差，`PS=TR−TVC`。〔中南财经政法2022研〕 11. **完全竞争市场**：无任何垄断因素——买卖者极多、产品同质、资源自由流动、信息完全。〔北京理工2021研〕

**ch05** 12. **价格歧视**：同一产品对不同买者或数量索取不同价格，需市场可分割、防转卖。〔华南理工2022研〕 13. **自然垄断**：规模经济使一家企业供给成本最低而形成的垄断。〔四川2022研〕 14. **折弯的需求曲线**：斯威齐模型，解释寡头价格刚性（提价无人跟、降价人人跟）。〔中央民族2022研〕

**ch06** 15. **边际产品价值**：完全竞争产品市场下增 1 单位要素所增产出的价值，`VMP=MP·P`。〔广西民族2021研〕 16. **经济租金**：从要素全部收入中减去而不影响其供给的那部分收入。〔中南财经政法2018研〕

**ch07** 17. **帕累托最优状态**：任何改变都无法在不损害他人的前提下使某人变好。〔安徽2022研〕

**ch08** 18. **外部性**：主体行为给他人带来未通过价格反映的损益（私人成本≠社会成本）。〔武大2019研〕 19. **科斯定理**：产权明确且交易成本为零时，市场均衡结果有效、与初始归属无关。〔中央财经2022研〕 20. **公共物品**：非排他 + 非竞用，最优供给 `ΣMRS=MRT`，易搭便车。〔北京理工2021研〕 21. **逆向选择**：**事前**信息不对称，差品驱逐好品。〔中国海洋2022研〕 22. **道德风险**：**事后**信息不对称，一方减少谨慎而损害另一方。〔四川2022研〕

**ch09** 23. **GDP**：一国一定时期生产的**全部最终产品**的市场价值。〔广东外语外贸2022研〕 24. **GDP 折算指数**：名义 GDP / 实际 GDP。〔厦大2019研〕

**ch10** 25. **边际消费倾向**：`MPC=ΔC/ΔY`，0<MPC<1，`MPC+MPS=1`。〔厦大2022研〕 26. **投资乘数**：`k=1/(1−β)`，收入变动与投资变动之比。〔四川2022研〕 27. **平衡预算乘数**：政府购买与税收同额增加时 `ΔY/ΔG=1`。〔南大2022研〕

**ch11** 28. **IS 曲线**：产品市场均衡（I=S）的利率—收入组合，右下倾斜。〔浙大2019研〕 29. **LM 曲线**：货币市场均衡（`M/P=ky−hr`）的利率—收入组合，右上倾斜。〔东北大学2016研〕 30. **流动性陷阱**：利率极低时货币需求弹性无穷，LM 水平、货币政策失效。〔厦大2022研〕

**ch12** 31. **滞胀**：生产停滞、失业增加与物价上涨并存，源于供给冲击。〔中南财经政法2019研〕

**ch13** 32. **自然失业率**：无货币因素干扰、供求均衡时的失业率。〔湖南2022研〕 33. **奥肯定律**：失业率每高于自然率 1 个百分点，实际 GDP 约低 2%。〔西北大学2022研〕 34. **结构性通货膨胀**：部门间劳动生产率与工资攀比导致的一般物价上涨。〔东北财经2022研〕

**ch14** 35. **马歇尔-勒纳条件**：进出口需求弹性之和 >1 时贬值才改善贸易收支。〔南京财经2009研〕 36. **J 曲线**：贬值后贸易收支先恶化、后改善的时滞路径。〔中南财经政法2021研〕

**ch15** 37. **挤出效应**：政府支出增加推高利率、减少私人投资。〔湖南2022研〕 38. **自动稳定器**：系统内部自动减少冲击的机制（累进税、转移支付、农产品价格支持）。〔中国海洋2022研〕 39. **公开市场业务**：央行买卖政府债券以调节货币供给，三大工具之一。〔东北大学2019研〕

**ch16** 40. **索洛剩余**：不能由要素投入解释的增长率（全要素生产率）。〔南大2021研〕

**候补**：CPI、转移支付、准租金、MRP、实际汇率、相机抉择、货币乘数、资本黄金律水平。

## 四、论述题母题清单（15 条）

*格式：母题〔出处〕—— ①立论 ②展开 ③落点。*

1. **谷贱伤农与农业政策**〔浙江财经2021研〕—— ①需求缺乏弹性，S 右移使价格跌幅 > 产量增幅、TR 降；②伤的是收入不是产量；③保护价、产量补贴、农会限产。
2. **价格管制的福利分析**〔中南财经政法2019研〕—— ①最高限价 → 短缺、配给、黑市（黑市上限在需求曲线上）；②最低限价 → 过剩、政府收购；③两者都使数量偏离均衡、总剩余减少。
3. **生产三阶段与合理投入区**—— ①边界是 `AP=MP` 与 `MP=0`；②Ⅰ 固定要素过多、Ⅲ 可变要素过多；③Ⅱ 区只给范围，具体由 `w/r` 定。
4. **规模报酬与 LAC 的形状位置**—— ①形状由内在规模经济/不经济定（**不能**用边际报酬递减解释）；②位置由外在经济、学习效应定；③判据 `α+β` 与 1 比。
5. **完全竞争长期均衡与效率**—— ①两层调整使 `P=LAC_min`；②零的是经济利润，正常利润照拿；③`P=MC` 产量最优、`P=AC_min` 技术最优、总剩余最大。
6. **行业长期供给曲线的三种形状**〔中国海洋2019研〕—— ①成本不变 → 水平；②成本递增 → 右上（LAC 整体上移）；③成本递减（外部经济）→ 右下。
7. **四种市场结构比较**〔广西大学2018研〕—— ①需求曲线：水平/陡右下/平右下/折弯；②均衡：`P=MC` / `P>MC` / 切点左于 LAC 最低点 / 古诺-斯威齐；③效率排序与无谓损失。
8. **垄断的福利损失与管制**—— ①`P>MC` 造无谓损失；②价格歧视把 CS 转为利润（一/二/三级）；③管制：边际成本定价（需补贴）、平均成本定价、反托拉斯。
9. **一般均衡、帕累托最优与福利定理**—— ①瓦尔拉斯定律（n 个市场仅 n−1 独立）；②三条件：`MRS_A=MRS_B`、`MRTS_x=MRTS_y`、`MRS=MRT`；③两定理 + 帕累托最优 ≠ 公平。
10. **市场失灵的表现与矫正**〔大连理工2018研〕—— ①垄断 → 管制；②外部性 → 庇古税/科斯；③公共物品（`ΣMRS=MRT`）→ 政府供给；④信息不对称 → 信号与激励。
11. **污染治理手段比较**—— ①负外部性使私人成本 < 社会成本、产量过多；②关闭/庇古税/排污权/标准管制各有成本效率差异；③总量控制 + 市场化手段优于一刀切。
12. **乘数原理与政策含义**—— ①`1/(1−β)`、`−β/(1−β)`、平衡预算 1；②一轮轮收入-消费传导；③前提是资源闲置、价格不变。
13. **IS-LM 政策效果与挤出效应**〔人大2019研〕—— ①IS/LM 移动的传导；②LM 越陡、乘数越大，挤出越大；③流动性陷阱（财政有效）与古典区域（货币有效）两个极端。
14. **菲利普斯曲线的短期与长期**〔中央财经2019研〕—— ①短期右下 `π=π^e−ε(u−u_n)`；②长期垂直，预期调整后 `u=u_n`；③通胀只能"意外"起作用。
15. **蒙代尔-弗莱明与汇率制度**〔东北财大2019研〕—— ①小国 + 资本完全流动 `r=r*`；②固定汇率：财政有效、货币无效；③浮动汇率：财政无效、货币有效。

## 五、计算题类型速查

路径见上表；"练习"指向对应 exercises 文件的「四、计算题精解」。

| 类型 | 公式 / 套路 | 练习 |
|---|---|---|
| 均衡 + 弹性 | `Qd=Qs`；`Ed=−(dQ/dP)(P/Q)` | ch01 计算 1–3 |
| 税负与福利 | 消费者份额 `Es/(Ed+Es)`；`DWL=½·T·ΔQ` | ch01 计算 1、ch04 计算 4 |
| 消费者均衡 | `MU1/P1=MU2/P2`；C-D 份额 `a/(a+b)` | ch02 计算 1–3 |
| 成本反推 | `TC=∫MC dQ+FC`（用给定点定 FC）；`AP=MP` 定阶段边界 | ch03 计算 1 |
| 长短期成本函数 | `MRTS=w/r` → LTC；C-D 下 `LTC=2√(wr)·Q` | ch03 计算 2 |
| 竞争短期 / 长期 | `P=MC` 取上升段、`P≥AVC_min` 才生产；长期 `P=LAC_min`、`n=Q/q` | ch04 计算 1–3 |
| 垄断 / 歧视 | `MR=P(1−1/Ed)`，`MR=MC` | ch05 计算 1–4 |
| 古诺 / 卡特尔 | 反应函数 `q1=(a−c1−q2)/2`；合谋按 `MR=MC` | ch05 计算 2–3 |
| 要素市场 | `MRP=MFC`，完全竞争下 `VMP=W` | ch06 计算 1 |
| GDP 核算 | 支出法 `C+I+G+NX`；名义/实际与折算指数 | ch09 计算 1–3 |
| 乘数 | `1/(1−β)`、`−β/(1−β)`、平衡预算 1 | ch10 计算 1–3 |
| IS-LM | IS 由 `Y=C+I+G`，LM 由 `M/P=ky−hr` | ch11 计算 1–6 |
| AD 推导 | 联立 IS/LM 消去 r，得 `Y(P)` | ch12 计算 1–4 |
| 失业 / 菲利普斯 | `π=π_{−1}−ε(u−u_n)`，令 `π=π_{−1}` 求 `u_n` | ch13 计算 2 |
| 蒙代尔-弗莱明 | `Y=C+I+G+NX` + `r=r*` 分制度联立 | ch14 计算 2 |
| 索洛 / 黄金律 | `sf(k)=(n+δ)k`、`f′(k)=n+δ`、`gY=αgK+(1−α)gL+gA` | ch16 计算 1–3 |

**一句话**：真题反复考同一条主线（弹性→均衡→福利；`MR=MC`→市场结构；乘数→IS-LM→AD-AS；菲利普斯；索洛），背骨架比刷题量划算。
