# Glossary / 术语表

《高等代数》第六版第一章–第十章（**Ch 01–Ch 10**）。条目按英文术语字母序，括号内是章节号；术语保留中英对照。

> 教材正文的术语在前；《辅导书》里常用但正文不设定义的术语，见文件末尾「辅导书补充术语」。

- **adjugate `adj A` / 伴随矩阵 `A*`** — transpose of the cofactor matrix; `A⁻¹ = adj A / det A` (Ch 04)
- **algebraic multiplicity / 代数重数** — multiplicity of `λ` as a root of the characteristic polynomial (Ch 07)
- **basis / 基** — linearly independent spanning set (Ch 06)
- **bilinear function / 双线性函数** — `f(α,β)` linear in each argument separately (Ch 10)
- **Cauchy–Schwarz / 柯西–施瓦茨不等式** — `|⟨u,v⟩| ≤ ‖u‖‖v‖`, valid in every inner product space (Ch 09)
- **change-of-basis matrix / 过渡矩阵** — `P_{C←B} = [[c₁⋯cₙ]]⁻¹[[b₁⋯bₙ]]`; coordinates transform as `x = Ay` (Ch 06)
- **characteristic equation / 特征方程** — `det(λE − A) = 0`; roots are the eigenvalues (Ch 07)
- **characteristic polynomial / 特征多项式** — `det(λE − A)`; a similarity invariant (Ch 07)
- **cofactor `Cᵢⱼ` / 代数余子式 `Aᵢⱼ`** — `(−1)^(i+j) det Aᵢⱼ` (Ch 02)
- **companion matrix / 伴侣矩阵** — the matrix whose characteristic polynomial is a prescribed `d(λ)`; building block of the rational canonical form (Ch 08)
- **congruent / 合同** — `A` and `CᵀAC` with `C` invertible; preserves rank and inertia indices (Ch 05, Ch 10)
- **consistent / 相容（有解）** — at least one solution exists; `r(A) = r(A,b)` (Ch 03)
- **coordinate vector `[x]_B` / 坐标** — unique weights expressing `x` in basis `B` (Ch 06)
- **Cramer's rule / 克拉默法则** — `xᵢ = Dᵢ/D`; theory, not a solver (Ch 02)
- **determinant `det A` / 行列式** — signed alternating sum over permutations; scales area/volume (Ch 02)
- **determinantal divisor `Dₖ(λ)` / 行列式因子** — monic gcd of all `k`-order minors of a λ-matrix (Ch 08)
- **diagonalizable / 可对角化** — similar to a diagonal matrix; iff `n` independent eigenvectors ⟺ geometric = algebraic multiplicity ⟺ minimal polynomial has no repeated roots (Ch 07)
- **dimension `dim V` / 维数** — number of vectors in any basis (Ch 06)
- **direct sum `⊕` / 直和** — sum in which every decomposition is unique; `V₁ ∩ V₂ = {0}` (Ch 06)
- **distance / 距离** — `d(α,β) = ‖α − β‖` (Ch 09)
- **dual space `V*` / 对偶空间** — all linear functionals on `V`; `dim V* = dim V` (Ch 10)
- **echelon form / 阶梯形** — nonzero rows above zero rows, pivots stepping right (Ch 03)
- **eigenspace / 特征子空间** — `Nul(A − λE)` (Ch 07)
- **eigenvalue `λ` / 特征值** — `Ax = λx` has a nonzero solution (Ch 07)
- **eigenvector / 特征向量** — **nonzero** `x` with `Ax = λx` (Ch 07)
- **elementary divisors / 初等因子** — invariant factors split into powers of distinct linear factors; the complete similarity invariant for complex matrices (Ch 08)
- **elementary matrix / 初等矩阵** — `E` after one elementary operation; left-multiply = row op, right-multiply = column op (Ch 04)
- **equivalence (λ-matrices) / 等价** — mutually reachable by elementary operations; ⟺ same rank and same invariant factors (Ch 08)
- **Euclidean space / 欧几里得空间** — real linear space with an inner product (Ch 09)
- **free variable / 自由未知量** — variable in a non-pivot column (Ch 03)
- **geometric multiplicity / 几何重数** — `dim Nul(A − λE)`; always ≤ algebraic multiplicity (Ch 07)
- **Gram–Schmidt / 施密特正交化** — builds an orthogonal basis by subtracting projections (Ch 09)
- **Hermite matrix / Hermite 矩阵** — `A* = A` (conjugate transpose); complex analogue of a real symmetric matrix; all eigenvalues real (Ch 09)
- **homogeneous equation / 齐次方程组** — `Ax = 0`; always consistent; solution space has dimension `n − r` (Ch 03)
- **inertia index / 惯性指数** — `p` (positive) and `q` (negative) squared-term counts in a real quadratic form's normal form; unique by the Law of Inertia (Ch 05)
- **inner product / 内积** — `(α,β)`; symmetric, linear, positive definite (Ch 09)
- **invariant factor `dₖ(λ)` / 不变因子** — `dₖ = Dₖ/D_{k−1}` with `d₁ | d₂ | ⋯`; the diagonal of the Smith normal form (Ch 08)
- **invariant subspace / 不变子空间** — `𝒜W ⊆ W` (Ch 07)
- **invertible matrix / 可逆矩阵（非退化）** — nonsingular; `|A| ≠ 0`; a product of elementary matrices (Ch 04)
- **irreducible / 不可约**
  - (polynomial) cannot be factored into lower-degree factors; depends on the number field (Ch 11)
  - (Markov chain) exactly one communication class (Ch 10)
- **isotropic subspace / 迷向子空间** — `W ⊆ W^⊥` under a symplectic form; every vector is symplectically orthogonal to itself (Ch 10)
- **Jordan block `J(λ₀,k)` / 若尔当块** — `k×k`, `λ₀` on the diagonal, 1 on the superdiagonal (Ch 07, Ch 08)
- **Jordan canonical form / 若尔当标准形** — block-diagonal of Jordan blocks; exists and is unique up to block order for every complex matrix (Ch 07, Ch 08)
- **Lagrangian subspace / 拉格朗日子空间** — a迷向 subspace of dimension `n` in a `2n`-dimensional symplectic space (Ch 10)
- **least-squares solution `x̂` / 最小二乘解** — minimises `‖b − Ax‖`; solves `AᵀAx = Aᵀb`; `b − Ax̂ ⊥ Col A` (Ch 09)
- **linear functional / 线性函数** — a map `V → P` preserving linear combinations; `dim V* = dim V` (Ch 10)
- **linearly dependent / 线性相关** — some nontrivial combination equals `0` (Ch 03)
- **linear transformation / 线性变换** — preserves addition and scalar multiplication (Ch 07)
- **minimal polynomial / 最小多项式** — lowest-degree monic annihilating polynomial; divides the characteristic polynomial and has the same roots (Ch 07)
- **normal form / 规范形** — canonical representative of an equivalence class: Smith form (λ-matrices), Jordan form (similarity over ℂ), rational form (similarity over any `P`), `±1`/`0` diagonal (quadratic forms) (Ch 05, Ch 08)
- **null space `Nul A` / 零空间（核）** — solution set of `Ax = 0`; a subspace of ℝⁿ (Ch 07)
- **number field / 数域** — a subfield of ℂ containing ℚ; ℚ, ℝ, ℂ are; ℤ is not (Ch 01)
- **orthogonal / 正交** — `(α, β) = 0` (Ch 09)
- **orthogonal basis / 正交基** — mutually orthogonal; coordinates are `(y·uⱼ)/(uⱼ·uⱼ)` (Ch 09)
- **orthogonal complement `W⊥` / 正交补** — all vectors orthogonal to `W`; exists and is **unique** in a Euclidean space (Ch 09)
- **orthogonal matrix / 正交矩阵** — square with `AᵀA = E`; equivalently `A⁻¹ = Aᵀ` (Ch 09)
- **orthogonal transformation / 正交变换** — preserves inner products ⟺ preserves lengths ⟺ maps orthonormal bases to orthonormal bases ⟺ its matrix is orthogonal (Ch 09)
- **orthonormal basis / 标准正交基** — orthogonal unit vectors; coordinates are plain projections (Ch 09)
- **pivot position / 主元** — leading-entry location; marks a basic variable (Ch 03)
- **polynomial / 多项式** — `aₙxⁿ + ⋯ + a₀` over `P`; the ring `P[x]` is a vector space of infinite dimension (Ch 01)
- **positive definite / 正定** — `xᵀAx > 0` for all `x ≠ 0`; iff all eigenvalues `> 0` ⟺ all leading principal minors `> 0` ⟺ `p = n` (Ch 05)
- **primitive polynomial / 本原多项式** — integer coefficients with gcd 1 (Ch 01)
- **principal axes / 主轴** — eigenvector directions in which the quadratic form has no cross term (Ch 05)
- **quadratic form / 二次型** — `xᵀAx` with `A` symmetric (Ch 05)
- **rank / 秩** — `dim Col A` = number of pivot columns = highest order of a nonzero minor = 非零行数 (Ch 03)
- **Rank Theorem / 维数定理** — `rank A + dim Nul A = n`; equivalently `dim 值域 + dim 核 = n` (Ch 07)
- **rational canonical form / 有理标准形** — the unique similarity normal form over any number field `P`; built from companion matrices (Ch 08)
- **similar matrices / 相似矩阵** — `B = X⁻¹AX`; share characteristic polynomial, eigenvalues, determinant, trace, rank, minimal polynomial (Ch 07)
- **Smith normal form / Smith 标准形** — `diag(d₁,…,dᵣ,0)` with `dᵢ | d_{i+1}`; unique (Ch 08)
- **Spectral Theorem / 谱定理** — symmetric matrices have real eigenvalues and an orthonormal eigenvector basis; `TᵀAT = diag(λᵢ)` (Ch 09)
- **subspace / 子空间** — contains `0`, closed under addition and scalar multiplication (Ch 06)
- **symplectic space `(V,f)` / 辛空间** — non-degenerate **alternating** bilinear form; dimension must be even; every vector is isotropic (Ch 10)
- **symplectic transformation / 辛变换** — preserves the symplectic form; `KᵀJK = J`; `det K = 1`; eigenvalues come in reciprocal pairs (Ch 10)
- **transpose `Aᵀ` / 转置** — rows and columns interchanged; `(AB)ᵀ = BᵀAᵀ` (Ch 04)
- **unitary space / 酉空间** — complex linear space with a Hermitian inner product; the complex analogue of a Euclidean space (Ch 09)

## 辅导书补充术语

《高等代数辅导与习题解答》里比正文更常用、但教材正文不设定义的术语（章节号已并入新编号）。

- **bordering / 加边法（升阶法）** — 把 `n` 阶行列式扩成 `n+1` 阶、借新增的行列消元再展开；用于结构相似、直接展开无路的行列式 (Ch 02)
- **discriminant `D` / 判别式** — `D = ∏_{i<j}(xᵢ − xⱼ)²`，是系数（初等对称式）的多项式；`D = 0` ⟺ 有重根 (Ch 01)
- **elementary symmetric polynomial / 初等对称多项式 `σₖ`** — 一切 `k` 元对称和；不涉及同一变量的任意两个 `x` 相乘 (Ch 01)
- **rank-one matrix / 秩一矩阵** — 形如 `uvᵀ`；`det(I + uvᵀ) = 1 + vᵀu`，是加边法/行列式速算的核心 (Ch 02)
- **resultant / 结式** — 两多项式有公根的充要条件，由系数构成的判别式；用于消元与判定公因式 (Ch 03)
- **Schur complement / Schur 补** — 分块矩阵 `[[A, B], [C, D]]` 中 `D − CA⁻¹B`（或 `A − BD⁻¹C`）；分块求逆与秩估计的工具 (Ch 04)
- **Sylvester rank inequality / Sylvester 秩不等式** — `r(AB) ≥ r(A) + r(B) − n`；证明靠分块矩阵初等变换 (Ch 04)
- **synthetic division / 综合除法（霍纳法）** — 用 `x − c` 除多项式的表格算法，一次给出商式与余数 `f(c)`；也是求方幂和、判根的工具 (Ch 01)
- **Vandermonde determinant / 范德蒙德行列式** — `∏_{i<j}(xⱼ − xᵢ)`；线性无关插值结点、范德蒙德矩阵可逆性都靠它 (Ch 02)
