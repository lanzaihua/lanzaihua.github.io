# Cheatsheet — 决策与判据

做题时的第一页：**先认题，再选动作**。每行都是「看到 X → 走 Y」，不解释证明。

## 拿到题先问三句

1. **对象**是哪一类？（多项式 / 行列式 / 方程组 / 矩阵 / 二次型 / 线性空间 / 线性变换 / λ-矩阵 / 欧氏空间 / 双线性函数）
2. **要的结论**是哪一类？（算数值 / 证存在 / 证唯一 / 分类 / 求规范形）
3. **结构**长什么样？（零多不多、行和相等、三对角、分块、对称/反对称、含参）

三句答完，动作基本就唯一了。

## 判据选择表

### 可对角化（三挑一，按代价从低到高）
| 条件 | 怎么验 | 代价 |
|---|---|---|
| n 个互异特征值 | 算特征多项式 | 最低 |
| 几何重数 = 代数重数 | 每个 λ 解 (λE−A)x=0 数维数 | 中 |
| 最小多项式无重根 | 试 ∏(λ−λᵢ) 是否零化 A | 高，但一次定论 |

### 正定（四选一）
| 判据 | 适用 | 代价 |
|---|---|---|
| 全部顺序主子式 > 0 | 具体矩阵、含参 | 低，最常用 |
| 特征值全 > 0 | 已会求特征值 | 中 |
| 合同于 E（配方得 p = n） | 二次型给定 | 中 |
| A = CᵀC，C 可逆 | 构造性证明 | 高 |

> 半正定**不能**用顺序主子式，要全部主子式 ≥ 0 或配成平方和。

### 相似判定的三级强度
| 手段 | 能推出相似？ | 用途 |
|---|---|---|
| 特征多项式相同 | **不能** | 只能否定（不同则必不相似） |
| 秩、迹、行列式相同 | **不能** | 快速否定 |
| 不变因子（初等因子）相同 | **能**（充要） | 最终判据 |

### 合同 / 相似 / 等价
| 关系 | 变换 | 保持什么 | 只有何时重合 |
|---|---|---|---|
| 等价 | P A Q | 秩 | — |
| 相似 | P⁻¹AP | 特征值、迹、行列式、最小多项式 | 正交时与合同重合（实对称） |
| 合同 | CᵀAC | 秩、惯性指数 p,q | 正交时与相似重合（实对称） |

### 求行列式怎么选
| 结构 | 动作 |
|---|---|
| 某行(列)零多 | 直接按它展开 |
| n ≥ 4 一般 | 倍加化三角 |
| 三对角 / 二阶递推 | 按首行展开得递推 |
| 各行(列)和相等 | 全加到第一列，提出公因子 |
| 主对角 + 常数（秩一） | 加边法 / det(D+uvᵀ) |
| aᵢⱼ = xᵢ + yⱼ | 行相减造零 |
| Vandermonde 型 | 套 ∏(xⱼ − xᵢ) |

### 求逆怎么选
| 场合 | 动作 |
|---|---|
| n 小、要 A⁻¹ | (A\|E) 行变换 |
| 分块对角/三角 | 各块取逆 |
| 一般分块 | Schur 补 |
| 只解一个方程组 | 别求逆，直接消元 |

### 秩怎么算
最高阶非零子式阶数 = 非零行数 = 行秩 = 列秩。求数值用行变换；证不等式用分块矩阵；"r(A) = r(AᵀA)" 用两齐次方程组同解。

### 基础解系 vs 极大无关组
| 问什么 | 怎么排 | 取什么 |
|---|---|---|
| 解 Ax = 0 的基础解系 | 系数矩阵行变换 | 自由未知量取 1 得 n − r 个解 |
| 向量组的极大无关组 | 向量**按列**排 | 主元列对应的**原**向量 |

## 四类「规范形」别搞混

| 名称 | 变换 | 谁唯一 | 出现在 |
|---|---|---|---|
| 标准形（二次型） | 合同 | 不唯一；p, q 唯一 | ch05 |
| 规范形（二次型） | 合同 | **唯一**（diag(1…1,−1…−1,0…0)） | ch05 |
| Smith 标准形 | λ-矩阵初等变换 | **唯一**（不变因子组） | ch08 |
| 若尔当标准形 | 相似 | 唯一（不计块序） | ch08 |

## 按章高频错误（辅导书统计）

| 章 | 错误动作 | 正确动作 |
|---|---|---|
| ch01 | 「没有有理根 ⟹ 不可约」 | 只对次数 ≤ 3 成立 |
| ch01 | 辗转相除后不首一化 | (f,g) 取首一 |
| ch01 | (f,f′) ≠ 1 ⟹ 有重根 | 只推出有重因式 |
| ch02 | 用 \|A+B\| = \|A\|+\|B\| | 行列式只对**单独一行**可拆 |
| ch02 | 展开符号乱 | 先写 (−1)^{i+j} 再算余子式 |
| ch03 | 只算 r(A) 就下结论 | 必须比 r(A) 与 r(A,b) |
| ch03 | 含参直接除参数 | 先分 \|A\| = 0 / ≠ 0 |
| ch04 | 分块直接各块取逆 | 需各块可逆且 Schur 补可逆 |
| ch04 | 以为 r(AB) = r(A)r(B) | 只有 ≤ min；下界用 Sylvester |
| ch05 | 把合同当相似 | 合同保惯性，相似保特征值 |
| ch05 | 顺序主子式判半正定 | 半正定要全部主子式 ≥ 0 |
| ch06 | 以为补子空间唯一 | 只有正交补唯一（欧氏空间） |
| ch06 | 多个子空间只验两两交为 0 | 要 Vᵢ ∩ Σ_{j≠i}Vⱼ = {0} |
| ch07 | 特征值相同就相似 | 反例 diag(1,1) 与 [[1,1],[0,1]] |
| ch08 | 特征多项式相同就相似 | 要比不变因子 |
| ch09 | 非标准正交基套投影公式 | 只有标准正交基能用 (α, eᵢ) |
| ch10 | 以为辛空间有唯一正交补 | 迷向向量自正交，W ∩ W^⊥ 一般不平凡 |

## Tells & smells（闻到就别按常规做）

- 「**证明不存在**」——先假设存在，找不变量（秩、行列式、惯性、维数）矛盾。
- 「**对任意 n 成立**」——先验 n = 1, 2 定形式，再归纳；别一上来就强归纳。
- 「**含参数**」——先找临界值（行列式为零、主子式为零、分母为零），再分段。
- 「**求所有**」——先给必要条件缩小候选，再逐一验充分。
- 「**$dim$ 是奇数/偶数**」——往辛空间、反对称型上想（偶数维才有非退化反对称型）。
- 「**A² = E / A² = A**」——往最小多项式、秩不等式、对角化上想。
- 「**A 与所有矩阵可交换**」——代 Eᵢⱼ 探针，必是数量矩阵。
