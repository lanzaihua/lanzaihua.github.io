# Patterns & Techniques — 动作库

每个可复用的操作：**识别 → 步骤 → 易错**。按章排；做题时先在表里找动作名，再回章节文件看完整推导。

## 总则：判断先于计算

**识别**：任何一道题在动笔算之前。
**步骤**：
1. 问「对象是什么类型」——多项式？矩阵？二次型？线性变换？λ-矩阵？
2. 问「结构给了什么」——零多不多、行和是否相等、是否三对角/箭形、是否分块、是否对称/反对称。
3. 问「要的结论属于哪一类」——存在性？唯一性？数值？分类（相似/合同/等价）？
4. 再选动作。
**易错**：跳过 1–3 直接展开，通常算到一半才发现题目要的是「证明不存在」。

## 第一章 多项式

## 辗转相除法求最大公因式与贝祖等式
**识别**：「求 (f, g)」「求 u, v 使 uf + vg = (f, g)」。
**步骤**：f = q₁g + r₁；g = q₂r₁ + r₂；… 直到余 0；最后一个非零余式**首一化**即为 (f, g)。要求 u, v 就从不含分数的余式链**回代**消元。
**易错**：不首一化（答案不唯一）；回代时符号错；同次两式先相减降次可省一半计算。

## 综合除法（霍纳法）与方幂和
**识别**：除式是 x − c；或要把 f 表成 x − x₀ 的方幂和。
**步骤**：系数按降幂排齐、缺项补 0；逐位「乘 c 加下一位」；最后一位是余数 f(c)。求方幂和就**反复**综合除法，余数依次为 c₀, c₁, …
**易错**：缺项不补 0；余数读出顺序颠倒；除到商为常数就停会漏最高次。

## 判重因式 / 重根
**识别**：「有无重因式」「求参数使有重根」。
**步骤**：算 (f, f′)：=1 ⟺ 无重因式；≠1 则 (f, f′) 含全部重因式（重数减一），f/(f,f′) 与 f 同因式且全单。含参题用 f(α)=f′(α)=0 消参，不要带着参数做辗转相除。
**易错**：把「无重因式」当「无重根」（要数域）；把「有重根」当「有重因式」。

## 求有理根 / 判不可约
**识别**：整系数多项式求根、分解、判 ℚ 上可约。
**步骤**：候选 ±p/q，q | aₙ、p | a₀；综合除法逐个试，成功即降次。判不可约：次数 ≤ 3 看有理根；否则艾森斯坦（必要时先平移 x = y + a 或乘常数）；再不行用待定系数设二次×二次。
**易错**：只试整数；把艾森斯坦当充要；跨过平移技巧。

## 对称多项式化初等对称式
**识别**：把对称式写成 σ₁,…,σₙ 的多项式（韦达、判别式、幂和）。
**步骤**：① 首项消去法：按字典序取首项指数 (l₁,…,lₙ)，减去 σ₁^{l₁−l₂}⋯σₙ^{lₙ} 的倍数，循环到 0；② 待定系数法：列出不先于首项的分拆，代几组数解小方程组。
**易错**：项列不全（漏 σ₁σ₂σ₃）；忘了先看齐次性；判别式是 ∏(xᵢ−xⱼ)²，别漏平方。

## 第二章 行列式

## 展开前先选行/列
**识别**：任何行列式。
**步骤**：数每行每列的零；选零最多的一行（列）展开；必要时先用倍加把某行打成只剩一个非零元。
**易错**：忘了 Aᵢⱼ = (−1)^{i+j}Mᵢⱼ 的符号；展开后余子式阶数没降对。

## 性质化三角
**识别**：n ≥ 4 的数值行列式。
**步骤**：倍加不变 → 制造零 → 化成上三角 → 对角元相乘；换行记得变号，提公因子只能从一行提。
**易错**：把「提公因子」和「倍加」混用；换行忘变号。

## 三对角 / 递推行列式
**识别**：只有主对角与两条次对角非零，或 Dₙ 与 Dₙ₋₁, Dₙ₋₂ 同型。
**步骤**：按第一行（列）展开 → Dₙ = aDₙ₋₁ − bc·Dₙ₋₂；算 D₁, D₂ 定初值；递推或猜通项后归纳。
**易错**：第二次展开漏掉；符号错。

## 加边法（升阶法）
**识别**：各行(列)结构相似、直接展开无路；或矩阵可写成 D + uvᵀ（主对角 + 秩一）。
**步骤**：扩成 n+1 阶（补一行一列，令其等于原式），用新增行列消元后展开；秩一型用 det(I + uvᵀ) = 1 + vᵀu。
**易错**：加边后行列式的值变了（补的 1 与 0 位置不对）。

## 行（列）和相等
**识别**：每行元素之和相同。
**步骤**：其余各列全加到第一列 → 第一列元素全相等 → 提出 → 再用第一列把其余打 0 化三角。
**易错**：提公因子时从多列重复提。

## 范德蒙德与特殊结构
**识别**：形如 aⱼ^{i−1} 的矩阵 / 行列式；循环行列式；aᵢⱼ = xᵢ + yⱼ。
**步骤**：直接用公式 ∏_{i<j}(xⱼ − xᵢ)；循环行列式化成「对角 + 秩一」或按行求和后提；xᵢ + yⱼ 型用行相减造零。
**易错**：把范德蒙德的行列式符号搞反（取决于行序）。

## 克拉默法则的边界
**识别**：方程个数 = 未知数个数且 |A| ≠ 0。
**步骤**：xⱼ = Dⱼ/D；Dⱼ 是把第 j 列换成常数项。
**易错**：|A| = 0 时不能用；n ≥ 4 计算量爆炸——只作理论工具，实际用消元。

## 第三章 线性方程组

## 秩判据与解集结构
**识别**：任何线性方程组。
**步骤**：行变换化行阶梯 → 比较 r(A) 与 r(A,b)：不等无解；相等且 = n 唯一；< n 无穷多。无穷多时写「特解 + 基础解系」（n − r 个）。
**易错**：只算 r(A) 不看增广；基础解系个数写错；非齐次通解漏特解。

## 含参方程组分情况讨论
**识别**：系数含参数，问「何时有解/唯一/无穷多」。
**步骤**：先算 |A|；|A| ≠ 0 → 克拉默唯一解；|A| = 0 → 代入参数值做行变换，按秩讨论。行列式含参数时先因式分解出临界值。
**易错**：直接除参数；漏掉 |A| = 0 的某些参数值导致分母为零（b = 1 这类）。

## 求极大无关组与秩
**识别**：给一组向量，求秩、极大无关组、其余向量的表出。
**步骤**：向量**按列**排成矩阵 → 行变换到行最简形 → 主元列 = 极大无关组（对应**原**向量）；非主元列写出用主元列表出的系数。
**易错**：把行变换后的列当原向量；按行排。

## 结式判公共根
**识别**：两个多项式有公共根 / 消元。
**步骤**：写 Sylvester 矩阵（系数平移排），令其行列式为 0；或先求 (f, g)，公共根即 (f, g) 的根。
**易错**：结式为零只是必要条件层面的「有公根或首项退化」；行序会整体改变符号但不改变零点。

## 第四章 矩阵

## 初等变换求逆
**识别**：n 不大、需要 A⁻¹。
**步骤**：(A | E) 只做**行**变换 → (E | A⁻¹)；算完用 AA⁻¹ = E 验算。
**易错**：行列混用；不验算。

## 分块矩阵运算与求逆
**识别**：大矩阵有明显分块结构（对角、三角、[[A,B],[C,D]]）。
**步骤**：分块乘法按普通矩阵法则进行（块大小要对齐）；分块对角直接各块取逆；[[A,B],[0,D]] 用 [[A⁻¹, −A⁻¹BD⁻¹],[0, D⁻¹]]；一般分块用 Schur 补。
**易错**：块不可交换却随意换序；分块求逆条件不满足（某块不可逆）。

## 秩不等式
**识别**：证 r(AB) ≥ r(A) + r(B) − n（Sylvester）、r(A+B) ≤ r(A) + r(B)、r(A) = r(AᵀA)。
**步骤**：构造分块矩阵，用一种形状算秩（如 n + r(AB)），再用初等变换化成另一种形状（如 r(A) + r(B)），两侧相等即得。
**易错**：只记得 r(AB) ≤ min{r(A), r(B)} 而不会放下界；初等变换只做一侧。

## 第五章 二次型

## 配方法化标准形
**识别**：给二次型，求标准形 / 规范形 / 惯性指数。
**步骤**：有平方项 → 按该变量配方，消掉所有含它的交叉项；无平方项 → 先令 x₁ = y₁ + y₂, x₂ = y₁ − y₂ 造出平方项再配。
**易错**：交叉项系数忘记对半分；配方后没写出变换矩阵 C。

## 合同变换法
**识别**：要同时得到标准形与变换矩阵。
**步骤**：对 (A | E) 做**同一种**列变换与对应行变换（列变换用 C，行变换用 Cᵀ），化成 (D | Cᵀ)；D 即 CᵀAC。
**易错**：只做行或只做列；把相似变换 P⁻¹AP 的套路搬过来。

## 惯性定理与规范形
**识别**：问「规范形是什么」「p, q 是多少」。
**步骤**：标准形里正项个数 p、负项个数 q 唯一；规范形 diag(1,…,1,−1,…,−1,0,…,0)。
**易错**：标准形不唯一但 p, q 唯一——答案写标准形必须说明「不唯一」。

## 正定判据四选一
**识别**：判正定 / 求参数使正定。
**步骤**：① 顺序主子式全 > 0（最快）；② 特征值全 > 0；③ 合同于 E（配方得 p = n）；④ 存在可逆 C 使 A = CᵀC。
**易错**：用「所有主子式」代替「顺序主子式」（结论对但计算翻倍）；含参用二次型定义直接配平方有时更快；半正定必须用全部主子式 ≥ 0。

## 第六章 线性空间

## 判子空间
**识别**：「W 是否子空间」。
**步骤**：只验封闭：非空（0 ∈ W）、对加法封闭、对数乘封闭。
**易错**：逐条验八条公理（继承自母空间，不必验）；漏验非空。

## 求基与维数
**识别**：给生成元或子空间描述，求基、维数。
**步骤**：生成元按列排 → 行变换 → 主元列即基；由方程描述的用「解空间」：基础解系即基，维数 = n − r。
**易错**：把行变换后的向量当基；维数与秩混淆。

## 维数公式与直和
**识别**：「求交的维数」「证明是直和」。
**步骤**：dim(V₁+V₂) = dim V₁ + dim V₂ − dim(V₁∩V₂)；直和 ⟺ 交为 {0} ⟺ 分解唯一 ⟺ dim = 两者之和。
**易错**：多个子空间只验两两交为 0（不够，要 Vᵢ ∩ Σ_{j≠i} Vⱼ = {0}）。

## 过渡矩阵与坐标变换
**识别**：两组基之间换坐标。
**步骤**：写出 (η₁,…,ηₙ) = (ε₁,…,εₙ)A，A 的列是新基在旧基下的坐标；坐标满足 x_old = A x_new。A 可逆且 A = 旧基矩阵⁻¹·新基矩阵。
**易错**：方向写反（先写出等式再比系数，不要背）。

## 第七章 线性变换

## 求线性变换的矩阵
**识别**：给变换法则和一组基，求矩阵。
**步骤**：逐个算 𝒜εⱼ，用 ε 表出，系数按列写成矩阵。
**易错**：把像的坐标按行写；基的顺序与矩阵列不对应。

## 判可对角化（三挑一）
**识别**：「能否对角化」「求 P 使 P⁻¹AP 对角」。
**步骤**：① 有 n 个互异特征值 → 可；② 每个特征值几何重数 = 代数重数 → 可；③ 最小多项式无重根 → 可。三者任选最好算的。
**易错**：以为有重根就不可对角化（如 E 可对角化）；只算特征值不算特征向量个数。

## 求特征值与特征向量
**识别**：任何特征值问题。
**步骤**：解 |λE − A| = 0 得特征值；对每个 λ 解 (λE − A)x = 0 得特征子空间；对角化时按列拼 P。
**易错**：特征向量必须非零；重特征值的特征向量要取满几何重数才可对角化。

## 核与值域
**识别**：求 ker 𝒜、Im 𝒜、dim。
**步骤**：ker = 解 𝒜x = 0；Im = 列空间；dim ker + dim Im = n（维数定理）；要基就用原像/像的坐标。
**易错**：把「值域的基」写成行变换后的列。

## 最小多项式
**识别**：求最小多项式、判可对角化、求 Aᵏ。
**步骤**：最小多项式整除特征多项式且同根；先试 ∏(λ − λᵢ)（互异根）是否零化 A；对角化后用 Aᵏ = P Dᵏ P⁻¹。
**易错**：把特征多项式当最小多项式；忘验「整除」。

## 第八章 λ-矩阵

## 化 Smith 标准形
**识别**：求不变因子、初等因子、若尔当形。
**步骤**：只用初等行/列变换把 λE − A 化成对角形，每步取首一、保证 dᵢ | dᵢ₊₁；对角元即不变因子。
**易错**：阶数 ≥ 4 还想算全部子式；不保证整除链。

## 行列式因子 → 不变因子 → 初等因子
**识别**：题目给 λ-矩阵，要求各级不变量。
**步骤**：Dₖ = 所有 k 阶子式的首一最大公因式；dₖ = Dₖ/D_{k−1}；把 dₖ 拆成素幂即初等因子。
**易错**：把 Dₖ 与 dₖ 混；漏掉常数因子 1（D₁ = d₁ = 1 很常见）。

## 求若尔当标准形
**识别**：「求若尔当形」「求可逆 P 使 P⁻¹AP = J」。
**步骤**：求初等因子；每个 (λ − λ₀)ᵏ 配一个 k 阶块（本书约定 1 在上对角）；块可任意排序；验算阶数和 = n、特征值重数一致。
**易错**：两个相同的 (λ − λ₀) 是两个 1 阶块而不是一个 2 阶块；幂次定块大小、出现次数定块个数。

## 判相似
**识别**：「A 与 B 是否相似」。
**步骤**：比较 λE − A 与 λE − B 的不变因子（或初等因子）；相同即相似。
**易错**：只比特征多项式；只比秩。

## 第九章 欧几里得空间

## 施密特正交化
**识别**：给一组基，要标准正交基。
**步骤**：β₁ = α₁；βₖ = αₖ − Σ_{i<k} (αₖ, βᵢ)/(βᵢ, βᵢ) · βᵢ；最后逐个单位化。
**易错**：用了旧的 α 而不是新的 β；忘记单位化；分数算错。

## 求正交补
**识别**：「求 W⊥ 的基」。
**步骤**：把 W 的基当**行**向量解齐次方程组 Xα = 0（内积为 0）；解空间即 W⊥。
**易错**：把 W 的基当列；把一般补空间与正交补混（正交补唯一）。

## 判正交变换 / 正交矩阵
**识别**：「是否正交变换」「求正交矩阵」。
**步骤**：AᵀA = E ⟺ 列向量标准正交 ⟺ 保内积 ⟺ 保长度；正交变换的特征值模为 1，实特征值只能是 ±1。
**易错**：只验保长度不验线性；行列式 ±1 只是必要条件。

## 实对称矩阵正交对角化
**识别**：给实对称矩阵，求正交 P 使 PᵀAP = diag。
**步骤**：求特征值 → 各特征子空间取基 → 重特征值内部施密特正交化 → 单位化拼成 P；PᵀAP = diag(λᵢ)。
**易错**：重特征值的特征向量不正交就直接拼；不单位化。

## 最小二乘
**识别**：Ax = b 无解，求「最近」的解。
**步骤**：解正规方程 AᵀAx = Aᵀb；几何上 b − Ax̂ ⊥ Col A；残差范数即最小距离。
**易错**：把最小二乘解当原方程的解；忘记投影的几何解释。

## 第十章 双线性函数与辛空间

## 求对偶基
**识别**：给一组基，求对偶基。
**步骤**：若 (η₁,…,ηₙ) = (ε₁,…,εₙ)C，则对偶基 (g₁,…,gₙ) = (f₁,…,fₙ)C⁻ᵀ —— 是逆的**转置**，不是 C⁻¹ 本身；验算 gᵢ(ηⱼ) = δᵢⱼ。
**易错**：漏掉转置；行列向量约定混乱（写清是行向量组）。
**易错**：写成 C 而不是 C⁻¹；行列向量约定混乱（写清是行向量组）。

## 写度量矩阵 / 判双线性函数类型
**识别**：给双线性函数 f(α, β)，写矩阵、判对称/反对称/非退化。
**步骤**：A = (f(εᵢ, εⱼ))；对称 ⟺ Aᵀ = A；反对称 ⟺ Aᵀ = −A（对角元为 0）；非退化 ⟺ |A| ≠ 0。换基后 A′ = CᵀAC。
**易错**：用相似变换；把反对称的对角元写成非零。

## 辛基构造
**识别**：给非退化反对称双线性函数，造辛基 / 拉格朗日子空间。
**步骤**：取 e₁ ≠ 0，由非退化找到 f₁ 使 f(e₁, f₁) = 1；在 e₁, f₁ 的正交补上归纳，维数降 2；偶数维才可能。
**易错**：想找「标准正交」的辛基（不存在，每向量迷向）；维数是奇数时还硬做。
