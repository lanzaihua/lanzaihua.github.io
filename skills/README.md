# Skills · 五个开源技能包

本目录收录四科错题本网页使用的五个 skill：

| 目录 | 入口 | 用途 |
|---|---|---|
| `design-taste-frontend/` | [SKILL.md](design-taste-frontend/SKILL.md) | 前端版式、字体、留白与反模板化检查 |
| `advanced-algebra/` | [SKILL.md](advanced-algebra/SKILL.md) | 高等代数十章知识库、题型与习题解答层 |
| `mathematical-analysis/` | [SKILL.md](mathematical-analysis/SKILL.md) | 数学分析 23 章知识库、作业题库与检索协议 |
| `analytic-geometry/` | [SKILL.md](analytic-geometry/SKILL.md) | 解析几何六章知识库与课后习题解答库 |
| `western-economics/` | [SKILL.md](western-economics/SKILL.md) | 西方经济学导论 + 微观 + 宏观 17 章与练习层 |

## 完整内容

五个目录的章节、patterns、cheatsheet、solutions、exercises 等完整文件在：

**[skills-full.zip](skills-full.zip)**

解压后得到五个与目录同名的 skill 文件夹。网页构建用的内置技能包由 `skills.js` 与 `tools/build-skill-packs.js` 生成。
