# Skills · 四个学科开源技能包

本目录收录四科错题本网页使用的四个学科 skill：

| 目录 | 用途 |
|---|---|
| `advanced-algebra/` | 高等代数十章知识库、题型与习题解答层 |
| `mathematical-analysis/` | 数学分析 23 章知识库、作业题库与检索协议 |
| `analytic-geometry/` | 解析几何六章知识库与课后习题解答库 |
| `western-economics/` | 西方经济学导论 + 微观 + 宏观 17 章与练习层 |

## 使用

每个目录都以 `SKILL.md` 为入口，其余 `chapters/`、`patterns.md`、`cheatsheet.md`、`solutions/`、`exercises/` 按需读取。
