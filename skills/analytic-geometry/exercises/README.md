# 习题解答库（exercises/）

本目录是**教材习题的标准解答库**：按「章 → § → 题号」查题，直接拿到可抄到卷面上的「标准解答」。

## 为什么有这个库

用户的 `AGENTS.md` 规定：每答一道具体题目必须给全四件套——
① 考试标准解答 ② 详细解析 ③ 同类型模板（`Tnn`）④ 写入错题本。

第 ① 件最费时间、也最容易写歪。本库把《解析几何》(第五版) 课后答案整理成结构化的「题目 + 标准解答 + 答 + 考点 + 方法」，**第 ① 件直接取用**；第 ②③④ 件仍由答题时补写。

## 怎么查题

1. **按章节**：先打开对应 `ch0N-exercises.md`；
2. **按节**：`## 习题 x.y` 就是教材每节后的习题；
3. **按题号**：`### 题 N` 中的 N 就是教材上的题号；
4. **批量读**：文件较大（ch01 约 50 KB），用 `grep -n "^### 题"` 先定位行号，再 `read` 带 offset/limit 读那一段。

## 可信度与边界

- 内容由**扫描件 OCR 后按数学逻辑重建**，不是原书文字：题干与原书一致，解答由 OCR 线索 + 逐题验算重写。
- 有疑问处标了 `<!-- OCR存疑：… -->`；与纸书冲突时**以纸书为准**。
- 覆盖的是**教材习题**；辅导书自带的「复习与测试」题在各章文件的 `## 辅导书·复习与测试` 一节。
- 没有收录：教材正文例题（在各章 `## Worked Example` 与 `## 辅导书·例题分析`）、附录习题。

## 回填新题

新整理一道题时：
1. 找到对应章文件的对应节（没有该节就按节号插入）；
2. 用上面同一格式追加，`**方法**` 行尽量写「这题真正可迁移的那一步」；
3. 更新文件开头的「覆盖」与索引表里的题数。
