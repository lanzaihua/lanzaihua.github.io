## 题型 → 首选方法

| 看到什么题 | 先做什么 | 别做什么 |
|---|---|---|
| 证三点共线 / 三向量共面 | `a×b = 0` / 混合积 `(a,b,c) = 0` | 硬算坐标比例 |
| 求平面方程 | **先找法向量**（两点向量积） | 用三点式不验共线 |
| 求直线方程 | **先找方向向量** | 一般式下随手取方向向量（须取 `n₁×n₂`） |
| 直线与平面平行/垂直 | 比较方向向量与法向量 | 忘记 `l=0` 时点向式不能写比例式 |
| 空间两直线位置关系 | 算 `v₁×v₂` 与混合积 `(v₁,v₂,M₁M₂)` | 只比方向向量（会把异面误判为平行） |
| 异面直线的距离 | `d = \|(v₁,v₂,M₁M₂)\| / \|v₁×v₂\|` | 分母写成 `\|v₁\|\|v₂\|` |
| 点到平面的距离 | `d = \|Ax₀+By₀+Cz₀+D\| / √(A²+B²+C²)` | 漏绝对值 |
| 求过交线的平面 | **平面束** `π₁ + λπ₂ = 0` | 忘检 `λ=∞`（即 `π₂` 本身）会漏解 |
| 求柱面/锥面/旋转曲面方程 | 用母线参数表出准线点 → **消参数** | 旋转曲面换错"被替换的变量" |
| 化简二次曲线方程 | 有中心：先移轴后转轴 | 顺序颠倒 |
| 判定二次曲线类型 | 算三不变量 `I₁, I₂, I₃` 查表 | 只看 `I₂` 就下结论 |
| 求二次曲线主方向 | 解 `λ² − I₁λ + I₂ = 0` | 忘了不同特征根的主方向互相垂直（可自检） |
| 判定二次曲面类型 | 算 `I₁, I₂, I₃, I₄` 查表 | 死记 17 种标准方程 |
| 判断有无直母线 | 只可能是**单叶双曲面**与**双曲抛物面** | 在椭球面上找直母线 |

## 平面方程：五种形式怎么选

| 已知条件 | 用哪种形式 |
|---|---|
| 一点 + 两个方位向量 | 混合积 `(M₀M, a, b) = 0` |
| 一点 + 法向量 | 点法式 `A(x−x₀)+B(y−y₀)+C(z−z₀) = 0` |
| 三点 | 先 `n = M₀M₁ × M₀M₂`，再点法式 |
| 三个截距 | 截距式 `x/a + y/b + z/c = 1` |
| 一般位置 | 一般式 `Ax+By+Cz+D = 0`，**法向量直接读出** |
| 需要距离信息 | **法式方程** `x cosα + y cosβ + z cosγ − p = 0` |

## 直线方程：三种形式怎么选

| 已知条件 | 形式 | 方向向量 |
|---|---|---|
| 一点 + 方向向量 | 点向式 `(x−x₀)/l = (y−y₀)/m = (z−z₀)/n` | 直接读出 |
| 两点 | 两点式 | `M₁M₂` |
| 两平面交线 | 一般式 | **`v = n₁ × n₂`** |

⚠️ 点向式中若某个分母为 0，**必须**把对应式子单独写成 `x = x₀`，不能保留比例式。

## 空间两直线位置关系判定

| `v₁×v₂` | `(v₁,v₂,M₁M₂)` | 关系 |
|---|---|---|
| `≠ 0` | `≠ 0` | **异面** |
| `≠ 0` | `= 0` | 相交 |
| `= 0` | `≠ 0` | 平行 |
| `= 0` | `= 0` | 重合 |

（`M₁M₂` 是两直线上各取一点连成的向量。）**交集判据是混合积，不是方向向量。**

## 二次曲线分类表（用不变量）

| `I₂` | `I₃` | `I₁I₃` | 类型 |
|---|---|---|---|
| `> 0` | `≠ 0` | `< 0` | 椭圆 |
| `> 0` | `≠ 0` | `> 0` | 虚椭圆 |
| `> 0` | `= 0` | — | 一点（退化） |
| `< 0` | `≠ 0` | — | 双曲线 |
| `< 0` | `= 0` | — | 两相交直线 |
| `= 0` | `≠ 0` | — | 抛物线 |
| `= 0` | `= 0` | — | 用 `K₁` 细分：平行直线 / 重合直线 / 无轨迹 |

**`I₁ = a₁₁+a₂₂`，`I₂ = \|a₁₁ a₁₂; a₁₂ a₂₂\|`，`I₃ = \|A\|`（3×3）。**

## 二次曲面：先分"有无中心"

| `I₃` | 含义 | 特征根符号 | 类型 |
|---|---|---|---|
| `≠ 0` | **有唯一中心** | 全同号 | 椭球面型 |
| `≠ 0` | 有唯一中心 | 两正一负 | 单叶/双叶双曲面型 |
| `= 0` | **无中心** | 两正一零 | 椭圆抛物面型 |
| `= 0` | 无中心 | 一正一负一零 | 双曲抛物面型 |

再用 `I₄` 判断是否退化。**不要死记 17 种标准方程，记住这个分支结构。**

## 五种二次曲面标准方程

| 曲面 | 方程 | 直母线 |
|---|---|---|
| 椭球面 | `x²/a² + y²/b² + z²/c² = 1` | **无** |
| 单叶双曲面 | `x²/a² + y²/b² − z²/c² = 1` | **有两族** |
| 双叶双曲面 | `x²/a² + y²/b² − z²/c² = −1` | 无 |
| 椭圆抛物面 | `x²/a² + y²/b² = 2z` | **无** |
| 双曲抛物面 | `x²/a² − y²/b² = 2z` | **有两族** |

## 三种生成曲面的方程求法

| 曲面 | 生成方式 | 求法要点 |
|---|---|---|
| 柱面 | 母线平行定方向，过定准线 | 消去准线点的参数；**母线 ∥ z 轴 ⟹ 方程不含 z** |
| 锥面 | 母线过定点，过定准线 | 消参数；**顶点在原点 ⟹ 方程是齐次方程** |
| 旋转曲面 | 母线绕轴旋转 | **把垂直于轴的那个变量换成 `±√(另两变量平方和)`** |

## 化简二次曲线/曲面的标准流程

```
① 算 I₂（或 I₃）判断有无中心
   ├─ 有中心 → 移轴到中心（消一次项）
   └─ 无中心 → 直接转轴
② 解特征方程求主方向（曲线 λ²−I₁λ+I₂=0；曲面 λ³−I₁λ²+I₂λ−I₃=0）
③ 转轴使新轴沿主方向（消交叉项）
④ 得标准方程，查表定类型
```

**捷径**：若能熟练算不变量，可跳过坐标变换直接写出类型与标准方程（§5.7 / §6.7）。

## 常向量恒等式（背下来）

| 恒等式 | 用途 |
|---|---|
| `a·b = a₁b₁+a₂b₂+a₃b₃` | 数量积坐标式 |
| `a×b = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)` | 向量积坐标式 |
| `(a,b,c) = a·(b×c)` | 混合积 = 平行六面体体积 |
| `cos²α + cos²β + cos²γ = 1` | 方向余弦的关系 |
| `(a×b)×c = (a·c)b − (b·c)a` | 双重向量积展开 |

## Tells & smells（看到即警觉）

- **向量记号丢了箭头**（OCR 遗留）→ 重建时按上下文判断，别把向量当标量
- 点向式里分母出现 0 却写成比例式 → 错，须拆成 `x = x₀`
- 由一般式随手取方向向量 → 必须用 `n₁ × n₂`
- 判定两直线关系只比方向向量 → 会漏掉异面
- 异面直线距离公式分母写成 `|v₁||v₂|` → 应为 `|v₁×v₂|`
- 点到平面距离漏绝对值 → 距离为负
- 平面束设 `π₁ + λπ₂ = 0` 却不检查 `π₂` 本身 → 漏解
- 旋转曲面换错变量（绕 z 轴却替换 z）→ 方程全错
- 二次曲线分类只看 `I₂` → 必须三个不变量一起看
- `I₃ = 0` 的退化情形被忽略 → 把自己当成非退化曲线
- 移轴与转轴顺序颠倒 → 消不干净交叉项
- 圆的情形（`λ₁ = λ₂`）硬套"两主方向"公式 → 此时任何方向都是主方向
- 在椭球面或椭圆抛物面上找直母线 → 它们没有直母线
- 二次曲面的 17 种标准方程死记硬背 → 记分支结构（有无中心 → 特征根符号）即可
