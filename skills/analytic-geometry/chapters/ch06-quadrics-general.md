## Core Idea / 核心思想

二次曲面（quadric surface）是由三元二次方程
`F(x,y,z) ≡ a₁₁x²+a₂₂y²+a₃₃z²+2a₁₂xy+2a₁₃xz+2a₂₃yz+2a₁₄x+2a₂₄y+2a₃₄z+a₄₄ = 0` 所确定的图形。
本章把第五章二次曲线的一般理论逐条平移到空间：**方向**换成三维方向比 `X:Y:Z`，**直径**换成径面，
**中心/渐近方向/切线**逐字对应，最终用空间直角坐标变换把方程化成 17 种标准形。
关键的工具转换是：二次曲面的二次项部分 `Φ(x,y,z)` 是一个三维二次型，于是"主方向就是特征向量、
标准形系数就是特征值"——整章后半段其实是线性代数里**实对称矩阵正交对角化**的几何版本。

## Frameworks Introduced / 核心框架

### 0. 记号与两个恒等式（全章的书写基础）

- `F(x,y,z) ≡ xF₁(x,y,z) + yF₂(x,y,z) + zF₃(x,y,z) + F₄(x,y,z)`（恒等式一）
- `Φ(x,y,z) ≡ xΦ₁(x,y,z) + yΦ₂(x,y,z) + zΦ₃(x,y,z)`（恒等式二）

其中 `F₁,F₂,F₃,F₄` 分别是矩阵 `A*` 的第 1~4 行的行向量形式；`Φ₁,Φ₂,Φ₃` 是 `A*` 左上 3×3 的行形式。
**下标是本章最危险的地方**：`a₁₁…a₃₃` 共 6 个独立系数，`a₁₄,a₂₄,a₃₄` 是三个一次项系数的一半，
`a₄₄` 是常数项。重建矩阵时必须是对称的：

```
A* = [ a₁₁ a₁₂ a₁₃ a₁₄ ]        A = [ a₁₁ a₁₂ a₁₃ ]
     [ a₁₂ a₂₂ a₂₃ a₂₄ ]            [ a₁₂ a₂₂ a₂₃ ]
     [ a₁₃ a₂₃ a₃₃ a₃₄ ]            [ a₁₃ a₂₃ a₃₃ ]
     [ a₁₄ a₂₄ a₃₄ a₄₄ ]
```

拆成行向量就是：

- `F₁ ≡ a₁₁x+a₁₂y+a₁₃z+a₁₄`，`F₂ ≡ a₁₂x+a₂₂y+a₂₃z+a₂₄`，`F₃ ≡ a₁₃x+a₂₃y+a₃₃z+a₃₄`，`F₄ ≡ a₁₄x+a₂₄y+a₃₄z+a₄₄`
- `Φ₁ ≡ a₁₁x+a₁₂y+a₁₃z`，`Φ₂ ≡ a₁₂x+a₂₂y+a₂₃z`，`Φ₃ ≡ a₁₃x+a₂₃y+a₃₃z`，`Φ₄ ≡ a₁₄x+a₂₄y+a₃₄z`

> **OCR 陷阱**：教材扫描件把 `A*` 的 4×4 与 `A` 的 3×3 完全打散成零散下标行，
> 上标 `²` 大面积丢失，`α→a`、`λ→入/A/2`、`θ→0`、`Δ→A`、`ε→e`、`γ→y` 极为常见。
> 本文件所有公式均按标准记号重建，并把下标逐个核对过。

**不变量（invariants）与半不变量（semi-invariants）**：

- `I₁ = a₁₁+a₂₂+a₃₃`
- `I₂ = |a₁₁ a₁₂; a₁₂ a₂₂| + |a₁₁ a₁₃; a₁₃ a₃₃| + |a₂₂ a₂₃; a₂₃ a₃₃|`（`A` 的三个二阶主子式之和）
- `I₃ = det A`（三阶行列式）
- `I₄ = det A*`（**四阶**行列式，`I₄ = I₃·a₄₄ − (a₁₄,a₂₄,a₃₄)ᵀ` 与 `A⁻¹` 的配合项）
- `K₁ = |a₁₁ a₁₄; a₁₄ a₄₄| + |a₂₂ a₂₄; a₂₄ a₄₄| + |a₃₃ a₃₄; a₃₄ a₄₄|`（`I₁` 的三项各添第四行第四列两条"边"）
- `K₂`：把 `I₂` 的三个二阶行列式同样各添两条边，得三个三阶行列式，再求和

- 何时用：一切"判断类型 / 化简方程"的问题，都先算出 `I₁,I₂,I₃,I₄`（退化时再补 `K₂,K₁`）。
- 关键点：`I₁,I₂,I₃,I₄` 在**任意**空间直角坐标变换下不变；`K₁` 只在第 V 类上不变，
  `K₂` 只在第 III、IV、V 类上不变——这就是它们叫"半"不变量的原因。

### 1. §6.1 二次曲面与直线的相关位置

把直线 `x = x₀+Xt, y = y₀+Yt, z = z₀+Zt` 代入 `F = 0`，整理得关于 `t` 的方程

`Φ(X,Y,Z)t² + 2[XF₁(x₀,y₀,z₀)+YF₂(x₀,y₀,z₀)+ZF₃(x₀,y₀,z₀)]t + F(x₀,y₀,z₀) = 0`。

- **`Φ(X,Y,Z) ≠ 0`（非渐近方向）**：判别式 `Δ = [XF₁+YF₂+ZF₃]² − Φ(X,Y,Z)·F(x₀,y₀,z₀)`。
  `Δ>0` 两不同实交点；`Δ=0` 两重合实交点（相切）；`Δ<0` 一对共轭虚交点。
  **结论：非渐近方向的直线总与曲面有两个交点（实的、重合的或虚的）**。
- **`Φ(X,Y,Z) = 0`（渐近方向）**：方程退化为一次或矛盾或恒等——
  `XF₁+YF₂+ZF₃ ≠ 0` 时唯一交点；`=0` 而 `F(x₀,y₀,z₀) ≠ 0` 时无交点；
  两者同时为 0 时整条直线落在曲面上（该直线是直母线）。
- 何时用：判断直线与曲面的交点个数，或判断某方向是否渐近。

### 2. §6.2 渐近方向与中心

- **定义（渐近方向）**：满足 `Φ(X,Y,Z) = 0` 的方向 `X:Y:Z` 叫渐近方向（asymptotic direction），否则叫非渐近方向。
  过定点 `(x₀,y₀,z₀)` 且以渐近方向为方向的一切直线，其全体点构成锥面
  `Φ(x−x₀, y−y₀, z−z₀) = 0`，叫做**渐近方向锥面**。过定点的非母线方向都是非渐近方向。
- **定义6.2.2（中心）**：点 `C` 是曲面通过它的所有弦的中点，则 `C` 叫曲面的中心。
- **定理6.2.1**：`C(x₀,y₀,z₀)` 是中心的充要条件是中心方程组

  `F₁(x₀,y₀,z₀)=0, F₂(x₀,y₀,z₀)=0, F₃(x₀,y₀,z₀)=0`

  成立。**推论：原点是中心的充要条件是方程不含 `x,y,z` 的一次项。**
- 按中心方程组系数矩阵 `A` 与增广矩阵 `B` 的秩 `r,R` 分类：
  `r=R=3` 唯一中心；`r=R=2` 中心构成一条直线；`r=R=1` 中心构成一个平面；`r≠R` 无中心。
- **定义6.2.3**：有唯一中心的叫中心二次曲面；无中心的叫无心二次曲面；
  中心成一条直线的叫线心二次曲面；中心成一平面的叫面心二次曲面。
  后三者统称非中心二次曲面。
- **推论（判决性一步）**：曲面为中心二次曲面 `⟺ I₃ ≠ 0`；为非中心二次曲面 `⟺ I₃ = 0`。
- 何时用：求中心、判渐近方向、判断曲面有无对称中心。
- 关键点：`I₃` 就是中心方程组系数矩阵的行列式，所以"`I₃≠0` 有唯一中心"与线性方程组
  有唯一解是同一件事。

### 3. §6.3 切线与切平面

- **定义6.3.1**：与曲面交于两个重合点的直线叫切线，重合交点叫切点；整条落在曲面上的直线也是切线。
- **切线的充要条件**：过曲面上点 `(x₀,y₀,z₀)` 的直线以 `{X,Y,Z}` 为方向成为切线，当且仅当

  `XF₁(x₀,y₀,z₀) + YF₂(x₀,y₀,z₀) + ZF₃(x₀,y₀,z₀) = 0`。

- **切平面**：当 `F₁,F₂,F₃` 在 `(x₀,y₀,z₀)` 不全为零时，一切切线的点构成平面

  `(x−x₀)F₁(x₀,y₀,z₀) + (y−y₀)F₂(x₀,y₀,z₀) + (z−z₀)F₃(x₀,y₀,z₀) = 0`  (6.3-1)

  由恒等式一还可写成 `xF₁(x₀,y₀,z₀)+yF₂(x₀,y₀,z₀)+zF₃(x₀,y₀,z₀)+F₄(x₀,y₀,z₀)=0`  (6.3-2)
- **推论（对称式，算题首选）**：正则点处的切平面为

  `a₁₁x₀x + a₂₂y₀y + a₃₃z₀z + a₁₂(x₀y+xy₀) + a₁₃(x₀z+xz₀) + a₂₃(y₀z+yz₀) + a₁₄(x+x₀) + a₂₄(y+y₀) + a₃₄(z+z₀) + a₄₄ = 0`  (6.3-3)

  用法：把原方程中的 `x²` 换成 `x₀x`、`xy` 换成 `(x₀y+xy₀)/2` 再乘 2、`x` 换成 `(x+x₀)/2` 再乘 2。
- **定义6.3.3（奇点）**：曲面上满足 `F₁=F₂=F₃=0` 的点叫奇异点（奇点），非奇异点叫正则点。
  结合恒等式一，奇点就是**奇点方程组** `F₁=F₂=F₃=F₄=0` 的解。
- **定理6.3.1**：正则点处存在唯一切平面，即 (6.3-1)。
- 何时用：求切平面/切线、判断相切、找奇点。

### 4. §6.4 径面与奇向

- **定理6.4.1**：二次曲面一族平行弦的中点轨迹是一个平面。
- **径面方程**：方向 `X:Y:Z` 所共轭的径面为

  `XF₁(x,y,z) + YF₂(x,y,z) + ZF₃(x,y,z) = 0`  (6.4-1)

  或 `Φ₁(X,Y,Z)x + Φ₂(X,Y,Z)y + Φ₃(X,Y,Z)z + Φ₄(X,Y,Z) = 0`  (6.4-2)

- **定义6.4.1**：这个平面叫共轭于该平行弦族的径面，弦的方向叫径面的共轭方向。
- **定理6.4.2**：任何径面一定通过曲面的中心（若中心存在）。线心曲面的径面通过中心线；
  面心曲面的径面与中心平面重合。
- **奇向**：满足 `Φ₁(X,Y,Z)=Φ₂(X,Y,Z)=Φ₃(X,Y,Z)=0` 的渐近方向叫奇异方向（奇向）。
  **定理6.4.3：曲面有奇向 `⟺ I₃ = 0`**；推论：中心二次曲面而且只有中心二次曲面没有奇向。
- **定理6.4.4**：奇向平行于曲面的任意径面。
- 何时用：求径面、由"径面平行于某平面"反求共轭方向、求奇向。

### 5. §6.5 主径面、主方向、特征方程与特征根

- **定义6.5.1**：径面垂直于它所共轭的方向，就叫**主径面**（principal plane of the quadric）——主径面就是曲面的对称面。
- **定义6.5.2**：主径面的共轭方向（即垂直于主径面的方向），或曲面的奇向，叫**主方向**。
- **充要条件（核心）**：`X:Y:Z` 是主方向，当且仅当存在 `λ` 使

  `a₁₁X+a₁₂Y+a₁₃Z = λX,  a₁₂X+a₂₂Y+a₂₃Z = λY,  a₁₃X+a₂₃Y+a₃₃Z = λZ`  (6.5-1)

  即 `A·(X,Y,Z)ᵀ = λ(X,Y,Z)ᵀ`，写成齐次方程组即

  `(a₁₁−λ)X+a₁₂Y+a₁₃Z = 0,  a₁₂X+(a₂₂−λ)Y+a₂₃Z = 0,  a₁₃X+a₂₃Y+(a₃₃−λ)Z = 0`  (6.5-2)

  有非零解，故系数行列式为零：

  `| a₁₁−λ  a₁₂  a₁₃ ; a₁₂  a₂₂−λ  a₂₃ ; a₁₃  a₂₃  a₃₃−λ | = 0`  (6.5-3)

  展开即 **`−λ³ + I₁λ² − I₂λ + I₃ = 0`**  (6.5-4)，等价于标准的 `λ³ − I₁λ² + I₂λ − I₃ = 0`。
- **定义6.5.3**：(6.5-3) 或 (6.5-4) 叫**特征方程**，其根叫**特征根**。
  `λ=0` 对应的主方向是奇向；`λ≠0` 对应的主方向是非奇主方向。
- **定理6.5.1**：特征根都是实数。**定理6.5.2**：三个特征根至少有一个不为零，
  故曲面至少有一个非奇主方向；推论：曲面至少有一个主径面。
- **主径面公式（务必与"垂直于共轭方向"一致）**：对非奇主方向 `X:Y:Z`（对应 `λ≠0`），
  由于 `(Φ₁,Φ₂,Φ₃) = λ(X,Y,Z)`，主径面 (6.4-2) 就是
  `λ(Xx+Yy+Zz) + Φ₄(X,Y,Z) = 0`，**法向量正是主方向本身**。
  它与中心的距离 `d` 满足 `λ·d = −Φ₄(X,Y,Z)/|(X,Y,Z)|`，这正是"主径面到中心的距离 × λ = 常数"。
- 求主方向/主径面的三步：解特征方程得 `λᵢ` → 代回 (6.5-2) 求 `X:Y:Z` → 代入 (6.4-2) 得主径面。

### 6. §6.6 方程化简与分类

**空间直角坐标变换**：

- 移轴：`x = x′+x₀, y = y′+y₀, z = z′+z₀`；逆：`x′ = x−x₀, y′ = y−y₀, z′ = z−z₀`。
  移轴下**二次项系数不变**，一次项系数变为 `2F₁(x₀,y₀,z₀), 2F₂(·), 2F₃(·)`，常数项变为 `F(x₀,y₀,z₀)`。
  故把原点移到中心即消去一次项。
- 转轴（新轴对旧轴的方向余弦记为 `αᵢ,βᵢ,γᵢ`）：

  `x = x′cos α₁ + y′cos α₂ + z′cos α₃`，`y = x′cos β₁ + y′cos β₂ + z′cos β₃`，`z = x′cos γ₁ + y′cos γ₂ + z′cos γ₃`

  其系数矩阵是**正交矩阵**（同行/同列的平方和为 1，不同行/列的对应元乘积和为 0），行列式为 1。
- 一般变换：转轴后再移轴，`x = x′cos α₁+y′cos α₂+z′cos α₃+x₀`，……；逆变换
  `x′ = (x−x₀)cos α₁+(y−y₀)cos β₁+(z−z₀)cos γ₁`，……

  常用等价说法：以三个两两垂直的平面 `πᵢ: Aᵢx+Bᵢy+Cᵢz+Dᵢ=0` 为新坐标面时，
  `x′ = ±(A₁x+B₁y+C₁z+D₁)/√(A₁²+B₁²+C₁²)`（符号取法使系数行列式为 1）。

- **定理6.6.1**：适当选取坐标系，二次曲面方程总可化为五个简化方程之一：
  (I) `a₁₁x²+a₂₂y²+a₃₃z²+a₄₄=0`（`a₁₁a₂₂a₃₃≠0`）；(II) `a₁₁x²+a₂₂y²+2a₃₄z=0`（`a₁₁a₂₂a₃₄≠0`）；
  (III) `a₁₁x²+a₂₂y²+a₄₄=0`（`a₁₁a₂₂≠0`）；(IV) `a₁₁x²+2a₂₄y=0`（`a₁₁a₂₄≠0`）；
  (V) `a₁₁x²+a₄₄=0`（`a₁₁≠0`）。
- **化简思路（从主径面出发）**：取一个非奇主方向为新 `x′` 轴，共轭主径面为 `y′O′z′` 面；
  此时 `a₁₂=a₁₃=a₁₄=0`；再在 `y′O′z′` 平面内用**平面**二次曲线的化简（定理5.6.1）降到 (I)(II)(III)；
  若 `a₂₂=a₃₃=a₂₃=0` 再移轴得 (IV)(V)。
- **定理6.6.2**：总可写成 **17 种标准方程**之一（见速查表）。

### 7. §6.7 应用不变量化简

- **定理6.7.1**：空间直角坐标变换下，四个不变量 `I₁,I₂,I₃,I₄` 与两个半不变量 `K₁,K₂` 如上。
  推论：**特征方程不变，从而特征根不变**。
- **定理6.7.3（类型判别）**：
  I 类 `I₃≠0`；II 类 `I₃=0, I₄≠0`；III 类 `I₃=I₄=0, I₂≠0`；
  IV 类 `I₃=I₄=I₂=0, K₂≠0`；V 类 `I₃=I₄=I₂=K₂=0`。这五条互斥且穷尽。
- **定理6.7.4（简化方程，`λᵢ` 为非零特征根）**：
  1° `I₃≠0`：`λ₁x′²+λ₂y′²+λ₃z′² + I₄/I₃ = 0`
  2° `I₃=0, I₄≠0`：`λ₁x′²+λ₂y′² ± 2√(−I₄/I₂)·z′ = 0`（`I₂<0`，符号随 `I₄`）
  3° `I₃=I₄=0, I₂≠0`：`λ₁x′²+λ₂y′² + K₂/I₂ = 0`
  4° `I₃=I₄=I₂=0, K₂≠0`：`I₁x′² ± 2√(−K₂/I₁)·y′ = 0`
  5° `I₃=I₄=I₂=K₂=0`：`I₁x′² + K₁/I₁ = 0`
- **定理6.7.5**：直接用不变量判定 17 种曲面的条件，见速查表。
- 何时用：题目只问"是什么曲面 / 求简化方程与标准方程"，一律走这条路，比作坐标变换省一半计算。

## Key Concepts / 核心概念

- **二次曲面（quadric surface）**：三元二次方程所表示的图形，由对称矩阵 `A*`（4×4）与二次型矩阵 `A`（3×3）共同编码。
- **渐近方向（asymptotic direction）**：满足 `Φ(X,Y,Z)=0` 的方向；沿它出发，直线与曲面或相切、或无交点、或整条落在曲面上。
- **中心（center）**：所有弦的中点；由 `F₁=F₂=F₃=0` 决定。`I₃≠0` 时唯一，即中心二次曲面。
- **切线 / 切平面（tangent line / tangent plane）**：切线的方向 `{X,Y,Z}` 与 `(F₁,F₂,F₃)` 点积为零；正则点处全部切线张成切平面。
- **奇点（singular point）**：奇点方程组 `F₁=F₂=F₃=F₄=0` 的解；奇点处无唯一切平面。
- **径面（diametral plane）**：一族平行弦中点的轨迹平面；方向 `X:Y:Z` 与径面互为共轭。
- **奇向（singular direction）**：使 `Φ₁=Φ₂=Φ₃=0` 的渐近方向，即 `λ=0` 对应的主方向；存在 `⟺ I₃=0`。
- **主径面（principal plane）**：垂直于其共轭方向的径面，即曲面的对称面。
- **主方向（principal direction）**：垂直于主径面的方向（或奇向），即 `A` 的特征向量方向。
- **特征方程 / 特征根（characteristic equation / roots）**：`λ³−I₁λ²+I₂λ−I₃=0` 及其三个实根；根就是标准形的平方项系数。
- **不变量（invariant）**：`I₁,I₂,I₃,I₄`，任意直角坐标变换下不变；**半不变量** `K₁,K₂` 只在部分类型上不变。
- **标准方程（standard equation）**：17 种规范形式，按中心/无心/线心/面心归入五类。

## Mental Models / 思维模型

1. **把二次曲面看成"二次型 + 一次项 + 常数"**：`F = Φ(x,y,z) + 2(a₁₄x+a₂₄y+a₃₄z) + a₄₄`。
   平移原点可以杀掉一次项（移到中心），正交变换（转轴）可以杀掉交叉项。
   这和"配方法化简二次型"是同一件事，只是几何语言换了个名字。
2. **把主方向看成三维实对称矩阵的特征向量**：`A` 对称 ⇒ 特征值全实、特征向量可取成两两正交的单位向量。
   于是三个主径面必两两垂直（当三个特征根互异时），新坐标系就是"特征坐标系"。
3. **把不变量看成"变换下的指纹"**：曲面在空间中怎么摆放、怎么转，`I₁,I₂,I₃,I₄` 都不变，
   所以它们只能由曲面的**形状与大小**决定。判断类型就是"读指纹、查表"。
4. **把奇向/渐近方向看成"退化信号"**：`Φ(X,Y,Z)=0` 意味着沿该方向的直线与曲面的交点开始合并或消失；
   一旦 `I₃=0`，曲面就失去唯一中心，从"中心家族"掉进"无心/线心/面心家族"。

## Anti-patterns / 常见错误

- **错误做法**：把 OCR 里的 `a`、`X` 当作标量或普通数。`X:Y:Z` 是方向比（`{X,Y,Z}` 是方向向量），
  而 `a₁₁` 是系数；把 `X:Y:Z` 与 `(x₀,y₀,z₀)` 混写成同一个三重数是最常见的手滑。
- **错误做法**：下标错位。把 `a₁₃` 写成 `a₃₁`（对称矩阵下没错），但把 `a₁₄` 当二次项系数、
  或把 `F₂` 的行写成 `a₁₃x+a₂₃y+a₃₃z+a₃₄` 就全错了。
  **核对法**：`Fᵢ` 的第 `j` 个系数必须是 `a_{ij}`，且 `a_{ij}=a_{ji}`。
- **错误做法**：把"中心方程组"当成"奇点方程组"。中心只要求 `F₁=F₂=F₃=0`；
  奇点还多一条 `F₄=0`。所以 `5x²+y²−z²=1` 的中心方程组有唯一解 `(0,0,0)`，
  但 `F₄=−1≠0`，故 `(0,0,0)` 不在曲面上 ⇒ **无奇点**。混淆这两者会漏判。
- **错误做法**：认为 `Δ=0` 一律表示相切。当 `Φ(X,Y,Z)=0` 时方程根本不是二次方程，
  判别式 `Δ` 无从谈起——此时要改用 `XF₁+YF₂+ZF₃` 与 `F(x₀,y₀,z₀)` 是否为零来分类。
- **错误做法**：解出特征根后就认为任务结束。**`λ=0` 对应的主方向是奇向，没有共轭的主径面**；
  例如 `2xy+2xz+2yz+9=0` 的 `λ=−1`（二重）对应方向满足 `X+Y+Z=0`，是一整个平面方向族，
  此时"过中心的任意垂直于 `x+y+z=0` 的平面"都是主径面，不能只写一个。
- **错误做法**：只求出主方向而不把它**单位化**就去写转轴公式。转轴公式的系数是方向余弦，
  必须用单位向量；`X:Y:Z=1:0:−1` 要化成 `(1/√2, 0, −1/√2)`。
- **错误做法**：忘掉右手系条件。由三个两两垂直平面写变换时，三个 `±` 号的取法必须使系数行列式为 `+1`，
  否则会把曲面变成它的镜像，虽然标准形不变，但旋转方向反了。
- **错误做法**：把 17 种标准方程记成"椭球面/双曲面/抛物面"三五个名字。
  实际上除这五类二次曲面外还包括 6 种柱面与 5 种退化情形（含虚曲面、点、一对平面）。
  尤其别忘了 `[3]` 点（虚母线二次锥面）、`[11]` 交于一条实直线的一对共轭虚平面、`[16]` 一对平行共轭虚平面。

## 辅导书·学习辅导要点

> 依据《学习辅导书》第六章 6.3 学习辅导（书 p156–165，PDF p160–p169）。以下只收教材未展开的概念分界、容易误用的推理与可操作的延伸，与上文重复的定义、定理不再抄录。

### 章结构与学习要求（书 p154–p156）

- **主线**：本章是第五章平面情形向空间的**逐项推广**——记号从 `F,F₁,F₂,F₃,Φ` 变为 `F,F₁,…,F₄,Φ,Φ₁,…,Φ₃`，不变量从 `I₁,I₂,I₃,K₁` 增到 `I₁,…,I₄,K₁,K₂`；两条恒等式 `F = xF₁+yF₂+zF₃+F₄`、`Φ = xΦ₁+yΦ₂+zΦ₃` 是全部推导的起点。学本章随时回头对照第五章，能省一半力气。
- **三个单元**：① 渐近方向与中心、切线与切平面、径面与奇向、主径面与主方向（§6.1–§6.5，本章主体）；② 方程化简与分类（§6.6：空间直角坐标变换 → 最简方程 → **17 类**）；③ 应用不变量化简（§6.7：略去不变量的证明，直接用）。
- **与第五章的对照**：`A` 由 3×3 变 4×4；`I₁` 由二阶迹变为三阶迹；`K₁` 换成 `K₂`；主方向换成主径面；「有无中心」由 `I₂` 判变为由 `I₃` 判。

1. **渐近方向锥面与渐近锥面是两回事**：过任意定点 $M_0$ 且以渐近方向为方向的直线全体组成锥面 $\Phi(x-x_0,y-y_0,z-z_0)=0$，叫渐近方向锥面；只有当顶点取在**中心**时，它才叫渐近锥面。单叶双曲面与双叶双曲面共用同一个渐近锥面（$\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=\pm1$ 的渐近锥面都是 $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=0$）。（§6.3.1）
2. **中心方程组与奇点方程组只差一条**：中心只要 $F_1=F_2=F_3=0$；奇点还要满足 $F(x_0,y_0,z_0)=0$（由恒等式一，等价于 $F_4=0$）。所以有中心的曲面不一定过中心，中心一般不在曲面上，例如 $5x^2+y^2-z^2=1$ 的中心是原点但 $F(0,0,0)=-1\ne0$。（§6.3.1）
3. **切平面两种写法等价、适用场合不同**：点法式 $(x-x_0)F_1+(y-y_0)F_2+(z-z_0)F_3=0$ 便于验算，对称式 $a_{11}x_0x+a_{22}y_0y+a_{33}z_0z+a_{12}(x_0y+xy_0)+\cdots+a_{44}=0$ 便于与已知平面比较系数。前提是切点为正则点；奇点处 $F_1=F_2=F_3=0$，切平面不存在。（§6.3.1）
4. **径面有两种，第二种最容易误读**：共轭于非渐近方向的径面是普通平行弦中点的轨迹；共轭于「非奇渐近方向」时，因为 $\Phi=0$ 给出 $X\Phi_1+Y\Phi_2+Z\Phi_3=0$，这个径面与它的共轭方向**平行**而不是垂直。判断「径面与方向」的关系时先看该方向是否渐近。（§6.3.2）
5. **奇向就是径面消失的方向**：当 $\Phi_1(X,Y,Z)=\Phi_2(X,Y,Z)=\Phi_3(X,Y,Z)=0$ 时径面方程退化，这样的渐近方向叫奇向；奇向必是渐近方向，且「有奇向 $\iff I_3=0$」——与「没有唯一中心」是同一个行列式判据。（§6.3.2）
6. **主方向有两种来源**：非零特征根对应非奇主方向（垂直于主径面）；$\lambda=0$ 对应奇向，按定义也算主方向，但它没有共轭的主径面。单根给唯一主方向；二重根给一整个方向平面，任取其中两个互相垂直的方向即可。（§6.3.2、§6.3.3）
7. **主径面三步法**：解特征方程得 $\lambda_i$ → 对每个非零 $\lambda$ 代回 $(a_{11}-\lambda)X+a_{12}Y+a_{13}Z=0$ 等三式求 $X:Y:Z$ → 把方向代入径面方程 $\Phi_1x+\Phi_2y+\Phi_3z+\Phi_4=0$。由于 $(\Phi_1,\Phi_2,\Phi_3)=\lambda(X,Y,Z)$，主径面的**法向量恰是该主方向**。（§6.3.2）
8. **特征方程的两个写法只差一个负号**：教材写 $-\lambda^3+I_1\lambda^2-I_2\lambda+I_3=0$，等价于常用的 $\lambda^3-I_1\lambda^2+I_2\lambda-I_3=0$。试根后必须用韦达关系 $I_1=\sum\lambda_i$、$I_2=\sum\lambda_i\lambda_j$、$I_3=\lambda_1\lambda_2\lambda_3$ 自检，因为分类完全依赖这三个数。（§6.3.2）
9. **变换矩阵的行、列各读一层意思**：把旧坐标用新坐标表示（$x=\cdots$）时，系数矩阵第 $j$ 列是新基向量在旧系中的坐标；逆变换（$x'=\cdots$）的矩阵是它的转置，第 $i$ 行是旧基向量在新系中的坐标。算题时先分清「正变换代回原方程」与「逆变换求新坐标」，否则 $x,y,z$ 与 $x',y',z'$ 会对调。（§6.3.3）
10. **正交条件与右手系**：同行（列）平方和为 1、不同行（列）对应元乘积和为 0；行列式为 $\pm1$，右手系要求 $+1$。用三个两两垂直平面写变换时 $x'=\pm\frac{A_1x+B_1y+C_1z+D_1}{\sqrt{A_1^2+B_1^2+C_1^2}}$，三个 $\pm$ 必须调到系数行列式为 $+1$；行列式为 $-1$ 只相当于取镜像，化简结果不变但新系是左手的。（§6.3.3）
11. **以主径面为坐标面时，方程会「缺一整个变量的一次项」**：若主径面作 $yOz$ 面，则 $a_{11}\ne0$ 且 $a_{12}=a_{13}=a_{14}=0$（变量 $x$ 只留平方项）；三个主径面都作坐标面，则交叉项与一次项全消失，方程成 $a_{11}x'^2+a_{22}y'^2+a_{33}z'^2+a_{44}=0$。这是「主径面法」能化简的全部理由。（§6.3.3）
12. **主径面个数的分支处理**：有三个主径面就直接取它们为新坐标面；只有两个，就补一个与两者都垂直的平面（方向取两法向量的叉积）；只有一个（曲面至少有一个主径面），就任取两个与它垂直且互相垂直的平面。三种情形都能把流程走完，区别只在补平面的方式。（§6.3.3）
13. **不变量判别必须按阶梯走**：$I_3\ne0$（中心型）→ $I_3=0,I_4\ne0$（抛物面）→ $I_3=I_4=0,I_2\ne0$（柱面）→ $I_3=I_4=I_2=0,K_2\ne0$（抛物柱面）→ 全零再看 $K_1$（平行平面族）。$K_2$ 只在 III、IV、V 类上不变，$K_1$ 只在 V 类上不变；跳步会把抛物面误判成柱面。（§6.3.3 表6-2、表6-3）
14. **简化方程里的根号带负号**：第 II 类是 $\lambda_1x'^2+\lambda_2y'^2\pm2\sqrt{-I_4/I_2}\,z'=0$，第 IV 类是 $I_1x'^2\pm2\sqrt{-K_2/I_1}\,y'=0$。因为 II 类中 $I_2<0$，双曲抛物面时 $I_4>0$，$I_4/I_2<0$，根号内必须取相反数；抛物柱面同理。本章 §6.7.4 原式漏写负号，已按此订正。（§6.3.3 表6-2）

## 辅导书·例题分析

> 选自辅导书 6.4 例题分析（书 p166–179，PDF p170–p183），共 10 题。每题保留「分析—解—一题多解—易错」四栏；凡涉及分类的题，解中一律走「看 $I_3$ 判有无中心 → 解特征方程看根的符号 → 看 $I_4$（及 $K_2,K_1$）判是否退化」这条分支。

### 例 1（书 p166–167）· 单叶双曲面的判定、中心与渐近锥面

**题目**：证明二次曲面 $x^2+y^2+z^2+2xy+6xz-2yz+2x-6y-2z=0$ 是单叶双曲面，并求出它的中心与渐近锥面。<!-- OCR存疑：原题方程在 OCR 中只剩矩阵，此处按 A* 的系数逐项还原：a11=a22=a33=1，a12=1，a13=3，a23=-1，a14=1，a24=-3，a34=-1，a44=0。 -->

**分析**：先写 $A$ 与 $A^*$，按 $I_1,I_2,I_3,I_4$ 走分类分支；中心解 $F_1=F_2=F_3=0$；渐近锥面是把二次部分平移到中心，而不是把原方程齐次化。

**解**：由
$$A=\begin{pmatrix}1&1&3\\1&1&-1\\3&-1&1\end{pmatrix},\qquad
A^*=\begin{pmatrix}1&1&3&1\\1&1&-1&-3\\3&-1&1&-1\\1&-3&-1&0\end{pmatrix}$$
算得 $I_1=3,\ I_2=-8,\ I_3=-16,\ I_4=16$。分支：$I_3=-16\ne0$ ⇒ 有唯一中心，属中心二次曲面（无奇向）；$I_2=-8\le0$ 且 $I_4=16>0$ ⇒ 单叶双曲面。中心方程组
$$x+y+3z+1=0,\qquad x+y-z-3=0,\qquad 3x-y+z-1=0$$
解得中心 $C(1,1,-1)$。渐近锥面为
$$(x-1)^2+(y-1)^2+(z+1)^2+2(x-1)(y-1)+6(x-1)(z+1)-2(y-1)(z+1)=0.$$

**一题多解**：也可先移轴到中心：令 $x=X+1,\ y=Y+1,\ z=Z-1$，因 $F(C)=-1$，方程化为
$$X^2+Y^2+Z^2+2XY+6XZ-2YZ=1,$$
于是渐近锥面就是左端 $=0$；这与上面先算中心再写锥面是同一件事。移轴法还能立刻看出曲面关于中心对称。

**易错**：$I_4$ 是四阶行列式，逐项展开时符号最容易错（本题可用 $I_4=I_3a_{44}-I_3\,b^{\mathsf T}A^{-1}b$ 复算，$b=(a_{14},a_{24},a_{34})^{\mathsf T}$）；中心方程组的常数项是 $a_{14},a_{24},a_{34}$，不要写成 $2a_{14}$ 等；渐近锥面必须用**中心**代入二次部分，直接用原方程会多出一次项。

### 例 2（书 p167）· 平面与椭球面相切的充要条件

**题目**：求平面 $lx+my+nz-k=0$ 成为椭球面 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ 的切平面的充要条件。

**分析**：设切点写切平面，再与已知平面比较系数，最后让切点落在椭球面上；这是「切线/切平面」题的标准三步。另一条路是用原点到平面的距离与支撑函数比较。

**解**：设切点为 $(x_0,y_0,z_0)$，则切平面为
$$\frac{x_0x}{a^2}+\frac{y_0y}{b^2}+\frac{z_0z}{c^2}=1.$$
它与 $lx+my+nz=k$ 表示同一平面，故
$$\frac{l}{x_0/a^2}=\frac{m}{y_0/b^2}=\frac{n}{z_0/c^2}=k,$$
即 $x_0=\dfrac{a^2l}{k},\ y_0=\dfrac{b^2m}{k},\ z_0=\dfrac{c^2n}{k}$。代入椭球面方程得 $\dfrac{a^2l^2+b^2m^2+c^2n^2}{k^2}=1$，即
$$k^2=a^2l^2+b^2m^2+c^2n^2.$$

**一题多解**：原点到平面的距离为 $\dfrac{|k|}{\sqrt{l^2+m^2+n^2}}$；椭球面沿单位法向量 $\dfrac{\{l,m,n\}}{\sqrt{l^2+m^2+n^2}}$ 的支撑函数为 $\dfrac{\sqrt{a^2l^2+b^2m^2+c^2n^2}}{\sqrt{l^2+m^2+n^2}}$。相切 ⇔ 两数相等 ⇔ 同一条件。支撑函数法在「三个互相垂直切平面」类题中更好用（见例 3）。

**易错**：比较系数时 $k$ 也要参与比例，不能只比左侧三个系数；只写「法向量成比例」不够，必须再加「切点在曲面上」；若 $k=0$，平面过原点，不可能与椭球面相切（除非椭球面退化），条件式自动排除。

### 例 3（书 p167–168）· 椭球面三个两两垂直切平面交点的轨迹

**题目**：求椭球面 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ 的三个两两相互垂直的切平面的交点的轨迹。

**分析**：把切平面写成「单位法向量 · 点 = 距离」的形式，距离由例 2 确定为 $p_i^2=a^2l_i^2+b^2m_i^2+c^2n_i^2$；三个法向量两两正交构成正交矩阵，于是交点向量可由三个投影拼回，长度立刻算出。

**解**：设三个切平面的单位法向量为 $\vec n_i=\{l_i,m_i,n_i\}$，方程为
$$l_ix+m_iy+n_iz=p_i\qquad(i=1,2,3),$$
由例 2，$p_i^2=a^2l_i^2+b^2m_i^2+c^2n_i^2$。交点 $P(x,y,z)$ 满足三个方程，而 $\{\vec n_1,\vec n_2,\vec n_3\}$ 是正交矩阵的行，故
$$\overrightarrow{OP}=\sum_{i=1}^{3}p_i\vec n_i,\qquad
|\overrightarrow{OP}|^2=\sum_{i=1}^{3}p_i^2
=a^2\sum l_i^2+b^2\sum m_i^2+c^2\sum n_i^2=a^2+b^2+c^2.$$
轨迹为球面
$$x^2+y^2+z^2=a^2+b^2+c^2,$$
球心是椭球面中心，半径平方为三半轴平方和。

**一题多解**：辅导书先解出切点 $(x_i,y_i,z_i)$ 并引入参数 $\lambda_i$，得到 $x_i=\lambda_i a^2l_i$ 等，再证 $\lambda_i^2(a^2l_i^2+b^2m_i^2+c^2n_i^2)=1$，最后同样把三式平方相加。两种写法本质相同，用单位法向量 + 正交矩阵更短。

**易错**：切平面的「距离」$p_i$ 不是任意的，必须满足例 2 的关系式，否则轨迹不是球；「两两垂直」是三个法向量两两正交，不是三个平面两两相交；正交矩阵的行（或列）平方和为 1 这一步是结论成立的关键。

### 例 5（书 p169–170）· 母线平行于 z 轴的切柱面

**题目**：求切于曲面 $x^2+2y^2+2z^2+2xy-2x-4y-4z+2=0$ 且母线平行于 $z$ 轴的柱面方程。

**分析**：切柱面是「方向固定为 $0:0:1$ 的切线的全体」。把平行于 $z$ 轴的直线代入曲面，得到关于参数 $t$ 的二次方程；相切 ⇔ 二次方程有二重根 ⇔ 判别式为零。

**解**：设直线 $x=x_0,\ y=y_0,\ z=z_0+t$，代入曲面得
$$2t^2+4(z_0-1)t+(x_0^2+2y_0^2+2z_0^2+2x_0y_0-2x_0-4y_0-4z_0+2)=0.$$
相切条件为判别式为零：
$$16(z_0-1)^2-8(x_0^2+2y_0^2+2z_0^2+2x_0y_0-2x_0-4y_0-4z_0+2)=0,$$
化简（$z_0^2$ 项恰好抵消）得
$$x_0^2+2y_0^2+2x_0y_0-2x_0-4y_0=0.$$
因该条件与 $z_0$ 无关，母线上的任意点都满足它，故所求柱面为
$$x^2+2y^2+2xy-2x-4y=0.$$

**一题多解**：也可把它看成「切平面平行于 $z$ 轴」的平面族的包络，或先作移轴把二次部分配成 $X^2+2XY+2Y^2=2$ 再读出椭圆柱面；这里用判别式最直接。顺带验证类型：二次部分 $I_3=0,\ I_2=1>0$，确为椭圆柱面。

**易错**：判别式条件中的常数项含 $z_0$，展开后若 $z_0^2$ 没有抵消，说明代入或配方出错；切柱面方程里不能再出现 $z$（母线平行 $z$ 轴）；最后要把 $(x_0,y_0)$ 改回 $(x,y)$。

### 例 6（书 p170）· 椭球面切平面垂足的轨迹

**题目**：从原点向椭球面 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ 的切平面引垂线，求垂足的轨迹方程。

**分析**：设切点写切平面；垂足同时满足「在切平面上」与「$\overrightarrow{OP}$ 平行于切平面法向量」两个条件，联立消去切点坐标。

**解**：设切点为 $(x_0,y_0,z_0)$，切平面为
$$\frac{x_0x}{a^2}+\frac{y_0y}{b^2}+\frac{z_0z}{c^2}=1.$$
从原点作的垂线为
$$\frac{x}{x_0/a^2}=\frac{y}{y_0/b^2}=\frac{z}{z_0/c^2}.$$
设垂足 $P(x,y,z)$，令 $r^2=x^2+y^2+z^2$，由上述比例关系与切平面方程解得
$$x_0=\frac{a^2x}{r^2},\qquad y_0=\frac{b^2y}{r^2},\qquad z_0=\frac{c^2z}{r^2}.$$
代入切点条件 $\dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}+\dfrac{z_0^2}{c^2}=1$，得
$$\frac{a^2x^2+b^2y^2+c^2z^2}{r^4}=1,$$
即轨迹为
$$(x^2+y^2+z^2)^2=a^2x^2+b^2y^2+c^2z^2.$$

**一题多解**：也可把垂足写成 $P=p\vec n^0$ 的形式（$\vec n^0$ 为单位法向量，$p$ 为原点到切平面的距离），再消去切点；结果相同，但比例法更不易出错。

**易错**：比例常数是 $r^2$ 而不是 $r$（因为切平面方程里 $x_0/a^2$ 与 $x$ 相乘），代入后出现 $r^4$ 不要写成 $r^2$；垂线方向是切平面法向量 $\{x_0/a^2,y_0/b^2,z_0/c^2\}$，不是 $\{x_0,y_0,z_0\}$。

### 例 7（书 p170–171）· 平行于已知平面的径面与共轭方向

**题目**：已知二次曲面 $6x^2+9y^2+z^2+6xy-4xz-2y-3=0$，求平行于平面 $x+3y-z+5=0$ 的径面和与它共轭的方向。

**分析**：先写 $\Phi_1,\Phi_2,\Phi_3,\Phi_4$，径面方程随之写出；「平行于已知平面」就是两平面法向量成比例，得到关于 $X:Y:Z$ 的齐次方程组，解出共轭方向后代回。

**解**：$\Phi_1=6X+3Y-2Z$，$\Phi_2=3X+9Y$，$\Phi_3=-2X+Z$，$\Phi_4=-Y$，故径面为
$$(6X+3Y-2Z)x+(3X+9Y)y+(-2X+Z)z-Y=0.$$
它平行于 $x+3y-z+5=0$，故
$$\frac{6X+3Y-2Z}{1}=\frac{3X+9Y}{3}=\frac{-2X+Z}{-1},$$
解得 $X:Y:Z=2:(-1):5$。代回得
$$-x-3y+z+1=0,\quad\text{即}\quad x+3y-z-1=0.$$
（本题 $I_3=9\ne0$，是中心型曲面；径面必过中心。）

**一题多解**：也可先设径面法向量为 $\lambda\{1,3,-1\}$，即 $\Phi_1=\lambda,\ \Phi_2=3\lambda,\ \Phi_3=-\lambda$，解三元一次方程组同样得 $X:Y:Z=2:(-1):5$；比例式与方程组本质相同，比例式更快。

**易错**：三个分量要两两成比例，只列两条会漏解；$\Phi_4=-Y$ 不能漏（来自 $a_{24}=-1$）；解出方向后代回时注意整体符号，$-x-3y+z+1=0$ 与 $x+3y-z-1=0$ 是同一平面。

### 例 8（书 p171–173）· 由三个主径面与三点求二次曲面

**题目**：二次曲面通过 $O(0,0,0)$、$A(1,-1,1)$、$B(0,0,1)$，它的三个主径面为 $x+y+z=0$、$2x-y-z=0$、$y-z+1=0$，求这个二次曲面的方程。

**分析**：三个主径面即三个对称面，取它们为新坐标面后方程无交叉项、无一次项，形如 $\lambda x'^2+\mu y'^2+\nu z'^2=1$；把三点的新坐标代入定出 $\lambda,\mu,\nu$。也可直接用未归一化的主径面平方和设方程，省去开方。

**解**：取正交变换
$$x'=\frac{x+y+z}{\sqrt3},\qquad y'=\frac{2x-y-z}{\sqrt6},\qquad z'=\frac{y-z+1}{\sqrt2},$$
则三点的新坐标为 $O\left(0,0,\frac1{\sqrt2}\right)$、$A\left(\frac1{\sqrt3},\frac2{\sqrt6},-\frac1{\sqrt2}\right)$、$B\left(\frac1{\sqrt3},-\frac1{\sqrt6},0\right)$。设
$$\lambda x'^2+\mu y'^2+\nu z'^2=1,$$
代入三点得 $\nu=2,\ \lambda=-2\mu,\ \frac{\lambda}{3}+\frac{\mu}{6}=1$，解得 $\lambda=4,\ \mu=-2,\ \nu=2$。于是
$$4x'^2-2y'^2+2z'^2=1,$$
代回化简得
$$y^2+z^2+2xy+2xz+y-z=0.$$

**一题多解**：直接设
$$\lambda(x+y+z)^2+\mu(2x-y-z)^2+\nu(y-z+1)^2=1,$$
代入 $O,A,B$ 得 $\nu=1,\ \lambda+4\mu+\nu=1,\ \lambda+\mu=1$，解得 $\lambda=\frac43,\ \mu=-\frac13,\ \nu=1$，化简得上式。此法免去单位化，计算最短，推荐考场使用。

**易错**：把主径面当坐标面时，平方项前的系数是 $x'$ 的系数（要除以法向量模长），未归一化时系数比例不同但最终曲面相同；$O$ 点在新系中的 $z'=\frac1{\sqrt2}\ne0$，所以常数项不是 $0$，不能把方程设成 $\lambda x'^2+\mu y'^2+\nu z'^2=0$。

### 例 9（书 p173）· 无交叉项的抛物柱面化简

**题目**：作直角坐标变换，化简二次曲面 $x^2+4y+2z-3=0$ 的方程，并指出它是何种曲面。

**分析**：方程只含 $x^2$ 与 $y,z$ 的一次项，缺 $y^2,z^2,yz$：在 $yOz$ 平面内作转轴，把 $4y+2z$ 整体变成一个新变量；再用不变量确认类型。

**解**：取
$$x'=x,\qquad y'=\frac{4y+2z-3}{2\sqrt5},\qquad z'=\frac{2z-y}{\sqrt5},$$
这是正交变换（行列式为 $+1$）。因为 $4y+2z-3=2\sqrt5\,y'$，原方程直接化为
$$x'^2+2\sqrt5\,y'=0.$$
不变量验证：$I_3=I_4=I_2=0$，而 $K_2=-5\ne0$ ⇒ 第 IV 类退化无心二次曲面 ⇒ **抛物柱面**。

**一题多解**：也可配方 $x^2=-(4y+2z-3)$，把它看成抛物线「$x^2=-2\sqrt5\,Y$」沿直线族 $4y+2z=\text{常数}$ 平移生成的柱面，母线方向为 $\{0,1,-2\}$（即新 $z'$ 轴方向）；这与上面的变换一致。

**易错**：这类题容易误判成抛物面，注意 $I_4=0$ 是柱面、$I_4\ne0$ 才是抛物面；变换中 $y'$ 的常数项 $-3$ 必须带着（它决定移轴），漏掉会得到平移过的方程；$z'$ 的符号要调到行列式为 $+1$。

### 例 10（书 p173–176）· 用坐标变换化简两题

**题目**：化简下列二次曲面方程，并指出种类：(1) $5x^2+7y^2+6z^2-4xz-4yz-6x-10y-4z+7=0$；(2) $5x^2-16y^2+5z^2+8xy-14xz+8yz+4x+20y+4z-24=0$。

**分析**：两题都走「算不变量 → 解特征方程 → 求主方向与主径面 → 取三个主径面为新坐标面 → 代回 → 移轴」的流程。第 (1) 题 $I_3\ne0$ 有中心，移轴到中心即可；第 (2) 题 $I_3=0$ 无中心，$I_4\ne0$ 属抛物面类，$\lambda=0$ 是奇向、无主径面，只能取两个主径面再补一个垂直平面。

**解**：(1) 由 $A^*$ 算得 $I_1=18,\ I_2=99,\ I_3=162,\ I_4=-486$。分支：$I_3\ne0$ ⇒ 中心型；特征方程
$$-\lambda^3+18\lambda^2-99\lambda+162=0\quad\Longrightarrow\quad(\lambda-9)(\lambda-6)(\lambda-3)=0,$$
三根 $9,6,3$ 同号，且 $I_2>0,\ I_1I_3>0,\ I_4<0$ ⇒ **椭球面**。对应主方向与主径面：
$$\lambda=9:\ \{1,2,-2\},\ x+2y-2z-1=0;\quad
\lambda=6:\ \{2,-2,-1\},\ 2x-2y-z+1=0;$$
$$\lambda=3:\ \{2,1,2\},\ 2x+y+2z-5=0.$$
取它们为新坐标面（第三式乘 $-1$ 使行列式为 $+1$），代回并移轴（中心 $(1,1,1)$）得
$$9x'^2+6y'^2+3z'^2-3=0,\quad\text{即}\quad 3x'^2+2y'^2+z'^2=1.$$
(2) 算得 $I_1=-6,\ I_2=-216,\ I_3=0,\ I_4=7776$。分支：$I_3=0$ ⇒ 无中心（无心二次曲面）；$I_4=7776\ne0$ ⇒ 非退化无心，属抛物面类；$I_4>0$ ⇒ **双曲抛物面**。特征方程
$$-\lambda^3-6\lambda^2+216\lambda=0\quad\Longrightarrow\quad\lambda(\lambda-12)(\lambda+18)=0,$$
根为 $12,0,-18$。$\lambda=12$ 对应主方向 $\{1,0,-1\}$、主径面 $x-z=0$；$\lambda=-18$ 对应 $\{1,-4,1\}$、主径面 $x-4y+z+2=0$；$\lambda=0$ 是奇向、无主径面。补第三个平面 $2x+y+2z=0$（与两主径面都垂直）。作正交变换后代回得
$$12x'^2-18y'^2+12z'-20=0,$$
再移轴 $z'=z''+\frac53$ 得
$$12x''^2-18y''^2+12z''=0,\quad\text{即}\quad 2x''^2-3y''^2+2z''=0,$$
为双曲抛物面。

**一题多解**：(1) 也可不写出完整变换，直接用不变量：$I_3\ne0$ 时简化方程必为 $\lambda_1x'^2+\lambda_2y'^2+\lambda_3z'^2+I_4/I_3=0$，代入 $9,6,3$ 与 $I_4/I_3=-3$ 即得 $9x'^2+6y'^2+3z'^2-3=0$；题目若只要求「简化方程 + 类型」，不变量法可省去主方向计算。(2) 同理用定理 6.7.4 第 2° 直接写 $12x'^2-18y'^2\pm2\sqrt{-I_4/I_2}\,z'=0$，即 $12x'^2-18y'^2\pm12z'=0$。

**易错**：第 (1) 题三个主径面的法向量要与特征根一一对应，张冠李戴会得到错误的旋转；第三式取负号只是为凑右手系，不影响方程。第 (2) 题 $\lambda=0$ 不能求主径面，必须另补平面；$I_4$ 的符号决定是椭圆抛物面还是双曲抛物面（$I_4<0$ 椭、$I_4>0$ 双曲），不要与双曲面的 $I_4$ 判据混淆。

### 例 11（书 p177–179）· 用不变量判别五题（$I_1,I_2,I_3,I_4$ 与特征根主线）

**题目**：用不变量判断下列曲面为何种曲面，并求简化方程与标准方程：
(1) $4x^2+5y^2+6z^2-4xy+4yz+4x+6y+4z-27=0$；
(2) $4x^2+y^2+z^2+4xy+4xz+2yz-24x+32=0$；
(3) $4x^2+2y^2+3z^2+4xz-4yz+6x+4y+8z+2=0$；
(4) $36x^2+9y^2+4z^2+36xy+24xz+12yz-49=0$；
(5) $2x^2+2y^2-4z^2-5xy-2xz-2yz-2x-2y+z=0$。

**分析**：五题正好覆盖五类分支：$I_3\ne0$ 的中心型、$I_4\ne0$ 的抛物面、$I_2\ne0$ 的柱面、$K_2\ne0$ 的抛物柱面、只剩 $K_1$ 的平行平面族。每题的顺序都是「$I_3$ → 特征根 → $I_4$（再 $K_2,K_1$）」。

**解**：
(1) $I_1=15,\ I_2=66,\ I_3=80,\ I_4=-2560$（$I_4$ 的复算见 Worked Example）。$I_3\ne0$ ⇒ 中心型；$I_2>0,\ I_1I_3>0,\ I_4<0$ ⇒ **椭球面**。特征根 $8,5,2$，$I_4/I_3=-32$，
$$8x'^2+5y'^2+2z'^2-32=0,\qquad \frac{x'^2}{4}+\frac{y'^2}{32/5}+\frac{z'^2}{16}=1.$$
(2) $I_1=6,\ I_2=0,\ I_3=0,\ I_4=0,\ K_2=-288$。$I_3=0$ ⇒ 无中心；$I_4=0$、$I_2=0$、$K_2\ne0$ ⇒ 第 IV 类，**抛物柱面**。特征根 $6,0,0$，
$$6x'^2\pm2\sqrt{-K_2/I_1}\,y'=6x'^2\pm8\sqrt3\,y'=0,\qquad x'^2=\pm\frac{4\sqrt3}{3}y'.$$
(3) $I_1=9,\ I_2=18,\ I_3=0,\ I_4=-162$。$I_3=0,\ I_4\ne0$ ⇒ 抛物面类；$I_4<0$ ⇒ **椭圆抛物面**。特征根 $6,3,0$，$I_4/I_2=-9$，
$$3x'^2+6y'^2\pm2\sqrt{-I_4/I_2}\,z'=3x'^2+6y'^2\pm6z'=0,\qquad x'^2+2y'^2=\pm2z'.$$
(4) $I_1=49,\ I_2=I_3=I_4=K_2=0,\ K_1=-2401<0$。全零后看 $K_1$ ⇒ 第 V 类，**一对平行平面**。特征根 $49,0,0$，$K_1/I_1=-49$，
$$49x'^2-49=0,\qquad x'^2=1\ (x'=\pm1).$$
(5) $I_1=0,\ I_2=-\dfrac{81}{4},\ I_3=0,\ I_4=\dfrac{729}{16}$。$I_3=0,\ I_4\ne0$ ⇒ 抛物面类；$I_4>0$ ⇒ **双曲抛物面**。特征根 $\frac92,0,-\frac92$，$I_4/I_2=-\dfrac94$，
$$\frac92x'^2-\frac92y'^2\pm2\sqrt{-I_4/I_2}\,z'=\frac92x'^2-\frac92y'^2\pm3z'=0,\qquad
\frac{x'^2}{1/3}-\frac{y'^2}{1/3}=\pm2z'.$$

**一题多解**：五题都可先用「$I_3$ 与特征根符号」快速定名，再用定理 6.7.4 写简化方程，不必真的作坐标变换；若题目额外要求新坐标系，再补主方向与主径面（做法见例 10）。第 (1) 题也可用 Worked Example 的完整坐标变换复核。

**易错**：(1) $I_4$ 是四阶行列式，必须独立复算（分块公式或按行展开），本题原稿曾在 $I_4$ 上出错；(3) 抛物面判据是 $I_4\ne0$，不要看到 $I_3=0$ 就写「柱面」；(4) $K_2=0$ 之后才轮到 $K_1$，$K_1<0$ 是一对实平行平面、$K_1>0$ 是一对共轭虚平面；(5) 双曲抛物面的标准形分母为正，符号体现在右端 $\pm2z'$ 上。

## Worked Example / 工作示例

**题目**（教材 §6.7 习题第 4 题 / 辅导书例 11(1)）：用不变量判断
`4x² + 5y² + 6z² − 4xy + 4yz + 4x + 6y + 4z − 27 = 0`
为何种曲面，并求简化方程与标准方程。

**第一步：写矩阵、算不变量。** 由一次项系数 `4,6,4` 得 `a₁₄=2, a₂₄=3, a₃₄=2`，故

```
A* = [ 4  -2   0   2 ]        A = [ 4  -2   0 ]
     [-2   5   2   3 ]            [-2   5   2 ]
     [ 0   2   6   2 ]            [ 0   2   6 ]
     [ 2   3   2 -27 ]
```

- `I₁ = 4+5+6 = 15`
- `I₂ = |4 −2; −2 5| + |4 0; 0 6| + |5 2; 2 6| = (20−4) + 24 + (30−4) = 16+24+26 = 66`
- `I₃ = det A`：按第一行展开
  `4·(5·6−2·2) − (−2)·((−2)·6−2·0) + 0 = 4·26 + 2·(−12) = 104 − 24 = 80`
- `I₄ = det A*`：按第一行展开，`4·m₁₁ + 2·m₁₂ + 0·m₁₃ − 2·m₁₄`（各 `m` 均为余子式），其中
  `m₁₁ = |5 2 3; 2 6 2; 3 2 −27| = 5(−162−4) − 2(−54−6) + 3(4−18) = −830 + 120 − 42 = −752`
  `m₁₂ = |−2 2 3; 0 6 2; 2 2 −27| = −2(−166) − 2(−4) + 3(−12) = 332 + 8 − 36 = 304`
  `m₁₄ = |−2 5 2; 0 2 6; 2 3 2| = −2(−14) − 5(−12) + 2(−4) = 28 + 60 − 8 = 80`
  所以 `I₄ = 4(−752) + 2·304 − 2·80 = −3008 + 608 − 160 = −2560`。

**第二步：查表判类型。** `I₂ = 66 > 0`，`I₁I₃ = 15×80 = 1200 > 0`，`I₄ = −2560 < 0`
⇒ 满足表 B 第 1 行 ⇒ 曲面是**椭球面**。

**第三步：解特征方程求特征根。** 特征方程 `λ³ − 15λ² + 66λ − 80 = 0`。
试 `λ=2`：`8 − 60 + 132 − 80 = 0` ✓。除以 `(λ−2)` 得 `λ² − 13λ + 40`，
其根为 `λ = 5, 8`。故 `λ₁,λ₂,λ₃ = 8, 5, 2`。

**第四步：写简化方程与标准方程。** 由定理 6.7.4 情形 1°，
常数项 `= I₄/I₃ = −2560/80 = −32`，简化方程为

`8x′² + 5y′² + 2z′² − 32 = 0`

标准方程为 `x′²/4 + y′²/(32/5) + z′²/16 = 1`。

> **核验与订正**：不变量数值自洽——`I₁` 是 `A` 的迹，`I₃ = det A`，
> 特征根 `8,5,2` 满足 `8+5+2 = 15 = I₁`、`8·5+8·2+5·2 = 66 = I₂`、`8·5·2 = 80 = I₃`。
> 原稿按第一行展开 `I₄` 时把第 2、4 项的余子式符号算反，得 `−3664`；正确余子式为
> `m₁₂ = 304`、`m₁₄ = 80`，故 `I₄ = −2560`，与辅导书一致。
> 辅导书对同一题给出 `I₁=15, I₂=66, I₃=80, I₁I₃=1200`、特征根 `8,5,2`、简化方程
> `8x′²+5y′²+2z′²−32=0`，与本稿订正后完全一致（`I₄/I₃ = −2560/80 = −32`）。
> 可用 `I₄ = I₃·a₄₄ − I₃·(a₁₄,a₂₄,a₃₄)A⁻¹(a₁₄,a₂₄,a₃₄)ᵀ` 独立复算。

**结论**：`4x²+5y²+6z²−4xy+4yz+4x+6y+4z−27=0` 是椭球面，
简化方程形如 `8x′²+5y′²+2z′² = I₄/I₃`。

## 解题套路 / Solution Patterns

**题型 1：求中心、渐近方向锥面、径面、切平面等几何量**
- 识别特征：题目直接问"求中心 / 渐近锥面 / 切平面 / 径面 / 奇向"，方程已给。
- 步骤：① 把方程抄成标准系数形式，**逐个数出 `a₁₁…a₃₄`**，写出 `A` 与 `A*`；
  ② 中心 → 解 `F₁=F₂=F₃=0`，并用 `I₃` 判断是唯一中心/中心直线/中心平面/无中心；
  ③ 渐近锥面 → 过中心 `(x₀,y₀,z₀)` 写 `Φ(x−x₀,y−y₀,z−z₀)=0`；
  ④ 切平面 → 先验证 `(F₁,F₂,F₃)≠(0,0,0)`（正则点），再用对称式 (6.3-3) 或在点处算 `F₁,F₂,F₃` 用 (6.3-1)；
  ⑤ 径面 → 用 (6.4-2)：`Φ₁(X,Y,Z)x+Φ₂(X,Y,Z)y+Φ₃(X,Y,Z)z+Φ₄(X,Y,Z)=0`。
- 易错点：`Φ(X,Y,Z)` 与 `F(x₀,y₀,z₀)` 混用；切平面的点必须是**曲面上的点**（先代进去验算）；
  径面的共轭方向与径面法向量方向是**两回事**（前者是弦方向，后者是 `(Φ₁,Φ₂,Φ₃)`）。

**题型 2：用坐标变换化简（旋转消交叉项 → 平移消一次项 → 标准形）**
- 识别特征："作直角坐标变换化简下列二次曲面方程，并指出它是何种曲面"。
- 步骤：① 算 `I₁,I₂,I₃` 写特征方程，求特征根 `λᵢ`；
  ② 对每个**非零**特征根解 (6.5-2) 得主方向（`λ=0` 的那个是奇向，不产生主径面）；
  ③ 用 (6.4-2) 写主径面；把主方向**单位化**后作为新坐标轴的系数；
  ④ 若三个主径面两两垂直，直接取它们为三个新坐标面；
     若只有两个（一个 `λ` 是二重根），再补一个与两者都垂直的平面
     （用两主径面法向量的外积方向去取）；若只有一个，就任取两个与它垂直且互相垂直的平面；
  ⑤ 用 `x′=±(A₁x+B₁y+C₁z+D₁)/√(A₁²+B₁²+C₁²)` 写变换（调 `±` 使系数行列式为 `+1`），
     解出 `x,y,z` 代回原方程，即得不含交叉项的方程；
  ⑥ 若还有一次项，再作一次移轴（配平方），得简化方程；最后按标准形命名。
- 易错点：忘记单位化；二重特征根时只写一个主方向；
  符号取错导致行列式为 `−1`；代回时把旧坐标与新坐标弄反（正变换代入旧方程，逆变换用来化简目标式）。

**题型 3：用不变量直接分类（算 `I₁,I₂,I₃,I₄`，查表定类型与标准方程）**
- 识别特征："利用不变量判断……为何种曲面，并求简化方程与标准方程"。
- 步骤：① 写 `A`（3×3，对称）与 `A*`（4×4，对称），**下标逐个核对**；
  ② 算 `I₁`（迹）、`I₂`（三个二阶主子式之和）、`I₃ = det A`、`I₄ = det A*`；
  ③ 按表 A 的阶梯逐一判：先看 `I₃≠0`？再看 `I₄≠0`？再看 `I₂≠0`？再看 `K₂≠0`？
     都为零则是第 V 类（再用 `K₁` 细分 15/16/17）；
  ④ 解特征方程得 `λ₁,λ₂,λ₃`（对称矩阵 ⇒ 全实，可用 `I₁,I₂,I₃` 与根的关系自检）；
  ⑤ 按定理 6.7.4 写简化方程：`λ₁x′²+λ₂y′²+λ₃z′²+I₄/I₃=0`（`I₃≠0` 时）等；
  ⑥ 除以常数得标准方程，最后查表 B 说出曲面名称（注意虚曲面与退化情形）。
- 易错点：`I₄` 是**四阶**行列式，OCR 常把它拆成两行三列导致算错；
  算完 `I₄` 后要再用 `I₄ = I₃·a₄₄ − (a₁₄,a₂₄,a₃₄)A⁻¹(a₁₄,a₂₄,a₃₄)ᵀ` 或分块展开独立复算一次；
  类型判断必须严格按顺序（`I₃=0, I₄≠0` 才能进第 II 类，不能只看 `I₃=0` 就说抛物面）；
  第 V 类还要看 `K₁` 的符号区分"一对平行平面 / 一对平行共轭虚平面 / 一对重合平面"。

**题型 4：求切平面、切点、切锥面，或"某平面与曲面相切"的充要条件**
- 识别特征：出现"相切""切点""切锥面""通过某点的切线"。
- 步骤：① 设切点 `(x₀,y₀,z₀)` 在曲面上，用对称式 (6.3-3) 写切平面；
  ② 与已知平面比较系数（法向量成比例 + 常数项），联立"点在曲面上"共 4 个方程解 `(x₀,y₀,z₀)`；
  ③ 若是"过定点作切锥面"，则设方向 `{X,Y,Z}`，把切线条件 (6.3-1) 的变体
     `Δ = [XF₁+YF₂+ZF₃]² − Φ(X,Y,Z)·F(x₀,y₀,z₀) = 0` 写成关于 `X,Y,Z` 的二次齐次式，
     再以 `X:Y:Z = (x−x₀):(y−y₀):(z−z₀)` 回代，即得切锥面方程。
- 易错点：只用"法向量成比例"一个条件就下结论（切平面还要求切点在曲面上）；
  对椭球面 `x²/a²+y²/b²+z²/c²=1` 的相切条件要记成 `k² = a²l² + b²m² + c²n²`（平面 `lx+my+nz=k`）。

**题型 5：由主径面/主方向反求曲面方程**
- 识别特征："已知二次曲面过某些点，且以若干平面为主径面，求曲面方程"。
- 步骤：① 以给定的三个两两垂直主径面为新坐标面（写出变换公式，注意单位化）；
  ② 在新坐标系下设 `a₁₁x′²+a₂₂y′²+a₃₃z′²+a₄₄=0`（主径面为坐标面 ⇒ 无交叉项无一次项）；
  ③ 把已知点的**新坐标**代入，解出 `a₁₁:a₂₂:a₃₃:a₄₄`；
  ④ 把变换公式代回，得原坐标系下的方程。
  另解（更快）：直接设 `λ(π₁)²+µ(π₂)²+ν(π₃)²=1`（`πᵢ` 是主径面的左端标准化形式），
  代入已知点解 `λ,µ,ν`。
- 易错点：三个主径面必须真的两两垂直（题目给了就是能用的信号）；
  用 `πᵢ` 时忘了除以它的法向量模长，导致 `λ,µ,ν` 比例失真。

## Key Takeaways / 关键结论

1. **一切从矩阵开始**：先把方程整理成 `A`（3×3 对称）与 `A*`（4×4 对称），
   逐项核对 `a₁₁…a₃₄` 与 `F₁,F₂,F₃,F₄`，后面所有计算都在这个基础上做。
2. **`I₃` 决定"有没有唯一中心"**：`I₃≠0` ⇔ 中心二次曲面 ⇔ 没有奇向；
   `I₃=0` ⇔ 非中心二次曲面 ⇔ 必有奇向。
3. **主方向 = `A` 的特征向量**：`A·(X,Y,Z)ᵀ = λ(X,Y,Z)ᵀ`；特征方程
   `λ³−I₁λ²+I₂λ−I₃=0` 的三个实根就是标准形的三个平方项系数，`λ=0` 那个方向是奇向。
4. **不同特征根对应的主方向必相互垂直**（`A` 实对称）：这正是"可以用正交变换同时消去全部交叉项"的保证，
   也是三维实对称矩阵正交对角化的几何翻译。
5. **`I₁ = tr A`，`I₃ = det A`，`I₄ = det A*`**：这四个数在任意直角坐标变换下不变，
   所以判断曲面形状只需"算四个数 + 查表"，不必真的作变换。
6. **两类化简方法各有适用场景**：要求写出具体的新坐标系变换公式时走"坐标变换法"（题型 2）；
   只问类型、简化方程与标准方程时走"不变量法"（题型 3），后者计算量小、出错的环节少。
7. **退化情形最容易被漏掉**：`I₃=0` 之后还要继续看 `I₄`、`I₂`、`K₂`、`K₁`——
   抛物面（`I₄≠0`）、柱面（`I₂≠0`）、抛物柱面（`K₂≠0`）、平行平面族（只看 `K₁`）分属不同层，
   顺序不能跳。

## 辅导书·复习与测试（选）

> 选自辅导书 6.5 复习与测试（书 p180，PDF p184）。只收 5 题，答案要点仍按「$I_3$ 定中心 → 特征根定形状 → $I_4$ 定退化」的主线写。

### 第 2 题（书 p180）· 由定点作球面的切锥面

**题目**：已知球面 $x^2+y^2+z^2=16$，求以 $(5,0,0)$ 为顶点的切锥面方程。

**答案要点**：设过 $P(5,0,0)$ 的直线方向为 $\{X,Y,Z\}$。直线与球面相切 $\iff$ 球心到直线的距离等于半径 4：
$$\frac{|\overrightarrow{OP}\times\{X,Y,Z\}|}{|\{X,Y,Z\}|}=4.$$
由 $\overrightarrow{OP}\times\{X,Y,Z\}=\{0,-5Z,5Y\}$ 得 $25(Y^2+Z^2)=16(X^2+Y^2+Z^2)$，即 $9(Y^2+Z^2)=16X^2$。以 $X:Y:Z=(x-5):y:z$ 回代得切锥面
$$16(x-5)^2-9(y^2+z^2)=0.$$
（顶点 $(5,0,0)$，半顶角满足 $\sin\theta=\frac45$。）

### 第 3 题（书 p180）· 平行弦的中点轨迹

**题目**：证明平行于直线 $\begin{cases}x-y-1=0,\\ x-z+4=0\end{cases}$ 的所有直线和二次曲面 $3x^2+z^2-2xy-yz-x-1=0$ 都有两个交点，并求与已知直线平行的弦的中点轨迹。

**答案要点**：已知直线方向为两平面法向量的叉积
$$\{1,-1,0\}\times\{1,0,-1\}=\{1,1,1\}.$$
对二次曲面，$\Phi(1,1,1)=3+1-2-1=1\ne0$，故 $\{1,1,1\}$ 是非渐近方向；把平行线代入后得到真正的二次方程，因而总有两个交点（实的、重合的或共轭虚的）。共轭于该方向的径面为
$$\Phi_1x+\Phi_2y+\Phi_3z+\Phi_4=2x-\frac32y+\frac12z-\frac12=0,$$
即**平行弦中点的轨迹**为
$$4x-3y+z-1=0.$$

### 第 4 题（书 p180）· 不同特征根的主方向互相垂直

**题目**：证明：二次曲面的两个不同特征根决定的主方向一定相互垂直。

**答案要点**：设 $A\vec X=\lambda\vec X$，$A\vec Y=\mu\vec Y$，$\lambda\ne\mu$。由 $A$ 对称，
$$\lambda\,\vec X\cdot\vec Y=(A\vec X)\cdot\vec Y=\vec X\cdot(A\vec Y)=\mu\,\vec X\cdot\vec Y,$$
故 $(\lambda-\mu)\vec X\cdot\vec Y=0$，即 $\vec X\cdot\vec Y=0$。这正是实对称矩阵不同特征值的特征向量正交的三维版本。

### 第 5 题（书 p180）· 球面的主方向与主径面

**题目**：证明：球面的特征根是一个非零三重根，空间的任何方向都是球面的非奇主方向，球面的主径面就是过球心的一切平面。

**答案要点**：球面方程可写成 $x^2+y^2+z^2-R^2=0$，故 $A=E$（单位阵），特征方程 $(\lambda-1)^3=0$，特征根为三重根 $1\ne0$。对任意方向 $\vec v\ne\vec 0$ 都有 $A\vec v=1\cdot\vec v$，故任何方向都是主方向，且 $\lambda=1\ne0$ 为非奇主方向。方向 $\vec v$ 共轭的径面为 $\vec v\cdot(x,y,z)=0$，它过球心且法向量就是 $\vec v$，因而垂直于共轭方向，是主径面；$\vec v$ 取遍所有方向时得到过球心的一切平面。

### 第 7 题（书 p180）· 化简含交叉项的二次曲面

**题目**：化简二次曲面 $x^2+2yz-2y+2z-1=0$ 的方程。

**答案要点**：$I_1=1,\ I_2=-1,\ I_3=-1,\ I_4=-1$。$I_3\ne0$ ⇒ 中心型；特征方程
$$\lambda^3-\lambda^2-\lambda+1=(\lambda-1)^2(\lambda+1)=0,$$
特征根 $1,1,-1$。由 $I_4/I_3=1$，简化方程为
$$x'^2+y'^2-z'^2+1=0\quad(\text{即 }z'^2-x'^2-y'^2=1),$$
曲面为**双叶双曲面**。具体变换：中心为 $(0,-1,1)$，令 $Y=y+1,\ Z=z-1$，方程化为 $x^2+2YZ+1=0$；再在 $yOz$ 面内转 $45^\circ$，取 $y'=\frac{Y+Z}{\sqrt2},\ z'=\frac{Y-Z}{\sqrt2}$，即得 $x'^2+y'^2-z'^2+1=0$（$x'=x$）。
