## Core Idea / 核心思想

第二至四章处理的是已摆好位置的曲线（标准方程、中心在原点、轴平行坐标轴）。本章处理最一般的情形：平面上的实系数二元二次方程
`F(x,y) ≡ a₁₁x² + 2a₁₂xy + a₂₂y² + 2a₁₃x + 2a₂₃y + a₃₃ = 0`
所表示的曲线。全部工作归结为两件事：**用代数不变量刻画类型与形状**，以及**用直角坐标变换把它搬到标准位置**。

这与线性代数中**实对称矩阵的特征值问题**是同一件事：主方向即特征向量，标准形系数即特征值，`I₁` 是迹、`I₂` 是行列式。看穿这一层，全章公式都不必死记。

## Frameworks Introduced / 核心框架

### 1. 记号与矩阵

- `F₁ ≡ a₁₁x + a₁₂y + a₁₃`、`F₂ ≡ a₁₂x + a₂₂y + a₂₃`、`F₃ ≡ a₁₃x + a₂₃y + a₃₃` 依次是 `A` 第一、二、三行的元素组成的一次式（`F₁ = ½∂F/∂x`，`F₂ = ½∂F/∂y`）。
- `Φ(X,Y) ≡ a₁₁X² + 2a₁₂XY + a₂₂Y²` 是 `F` 的二次项部分。恒等式 `F(x,y) ≡ xF₁ + yF₂ + F₃` 是切线、渐近线公式的统一来源。

  ```
      ⎡ a₁₁  a₁₂  a₁₃ ⎤                  ⎡ a₁₁  a₁₂ ⎤
  A = ⎢ a₁₂  a₂₂  a₂₃ ⎥          A* =  ⎣ a₁₂  a₂₂ ⎦
      ⎣ a₁₃  a₂₃  a₃₃ ⎦
  ```

- **关键点**：`A` 必须写成**对称矩阵**。`xy`、`x`、`y` 项系数专门带 `2`，是为使 `A`、`A*` 对称、偏导数公式干净；看清这点才不会把 `2a₁₂` 误当 `a₁₂`。

### 2. §5.1 二次曲线与直线的相关位置

过 `(x₀,y₀)`、方向 `X:Y` 的直线代入 `F = 0` 得

`Φ(X,Y)t² + 2[F₁(x₀,y₀)X + F₂(x₀,y₀)Y]t + F(x₀,y₀) = 0`，判别式 `Δ = [F₁X + F₂Y]² − Φ(X,Y)·F(x₀,y₀)`。

- `Φ ≠ 0`：`Δ>0` 两不等实交点；`Δ=0` 相切；`Δ<0` 一对共轭虚交点。
- `Φ = 0`：`F₁X+F₂Y ≠ 0` 只有一个实交点；`F₁X+F₂Y = 0` 而 `F ≠ 0` 无交点；二者同时为零则方程为恒等式，**整条直线落在曲线上**。

### 3. §5.2 渐近方向、中心、渐近线

- **定义5.2.1**：满足 `Φ(X,Y) = 0` 的方向叫**渐近方向**；否则叫非渐近方向。
- **定义5.2.2（按渐近方向分类）**：`I₂ > 0` 椭圆型（一对共轭虚方向）；`I₂ = 0` 抛物型（一个实方向）；`I₂ < 0` 双曲型（两个实方向）。渐近方向最多两个，非渐近方向无穷多。
- **定理5.2.1（中心）**：`C(x₀,y₀)` 是中心 ⟺ `F₁(x₀,y₀) = F₂(x₀,y₀) = 0`。推论：原点是中心 ⟺ 方程不含一次项。
- **定义5.2.4（按中心分类）**：`I₂ ≠ 0` 唯一中心 ⇒ **中心二次曲线**；`I₂ = 0, I₃ ≠ 0` 无中心 ⇒ **无心二次曲线**；`I₂ = I₃ = 0` 有一条中心直线 ⇒ **线心二次曲线**。椭圆型、双曲型都是中心曲线，抛物型是非中心曲线。
- **定义5.2.5 / 定理5.2.2**：过中心、以渐近方向为方向的直线叫**渐近线**；它与曲线**或者没有交点，或者整条直线在曲线上**。

### 4. §5.3 切线、正则点与奇点

- **定义5.3.1（切线）**：与曲线交于两个重合点的直线；若整条直线在曲线上，也叫切线，其上每点都是切点。
- **定理5.3.1**：设 `(x₀,y₀)` 在曲线上。若 `F₁(x₀,y₀), F₂(x₀,y₀)` 不全为零（**正则点**），切线为 `(x−x₀)F₁(x₀,y₀) + (y−y₀)F₂(x₀,y₀) = 0`   (5.3-3)，等价对称式 `a₁₁x₀x + a₁₂(x₀y + xy₀) + a₂₂y₀y + a₁₃(x + x₀) + a₂₃(y + y₀) + a₃₃ = 0`   (5.3-4)；来源是把 `x², 2xy, y², 2x, 2y` 依次换成 `x₀x, x₀y+xy₀, y₀y, x+x₀, y+y₀`，即**"二次型 ↔ 双线性型"的替换**。若二者同时为零（**奇点**，定义5.3.2），则过该点的每条直线都是切线。
- **法线**：`(x−x₀)F₂(x₀,y₀) − (y−y₀)F₁(x₀,y₀) = 0`。

### 5. §5.4 直径与共轭方向

- **定理5.4.1 / 5.4.2**：一族平行弦的中点轨迹是一条直线；共轭于非渐近方向 `X:Y` 的直径方程为

  `XF₁(x,y) + YF₂(x,y) = 0`，即 `(a₁₁X + a₁₂Y)x + (a₁₂X + a₂₂Y)y + a₁₃X + a₂₃Y = 0`

  斜率为 `k` 时直径即 `F₁(x,y) + kF₂(x,y) = 0`。中心曲线的直径过中心；无心曲线的直径平行于渐近方向；线心曲线只有一条直径（即中心直线）。
- **共轭方向与共轭直径（定义5.4.2）**：`X′:Y′ = −(a₁₂X + a₂₂Y) : (a₁₁X + a₁₂Y)`，满足

  `a₁₁XX′ + a₁₂(XY′ + X′Y) + a₂₂YY′ = 0`   (5.4-5)，斜率式 `a₂₂kk′ + a₁₂(k + k′) + a₁₁ = 0`   (5.4-6)

  中心曲线的一对具有相互共轭方向的直径叫共轭直径。因 `Φ(X′,Y′) = I₂·Φ(X,Y)`，`I₂ = 0` 时共轭方向退化为渐近方向 —— 这就是**共轭直径只对中心曲线有意义**的原因；与自己共轭的方向就是渐近方向。
- **代入检验**：椭圆 `x²/a² + y²/b² = 1`（`a₁₁ = 1/a², a₂₂ = 1/b², a₁₂ = 0`）由 (5.4-6) 得 `kk′ = −b²/a²`；双曲线 `x²/a² − y²/b² = 1` 得 `kk′ = +b²/a²`。

### 6. §5.5 主直径与主方向（特征值问题）

- **定义5.5.1**：垂直于其共轭弦的直径叫**主直径**（即对称轴）；主直径的方向及垂直于主直径的方向都叫**主方向**。
- **主方向方程与特征方程（定义5.5.2）**：`X:Y` 为主方向 ⟺ 存在 `λ` 使 `a₁₁X + a₁₂Y = λX, a₁₂X + a₂₂Y = λY`   (5.5-1)，即

  ```
  ⎪a₁₁−λ  a₁₂ ⎪
  ⎪            ⎪ = 0     即     λ² − I₁λ + I₂ = 0
  ⎪a₁₂  a₂₂−λ ⎪
  ```

- **定理5.5.1~5.5.4**：特征根都是实数（`Δ = I₁² − 4I₂ = (a₁₁−a₂₂)² + 4a₁₂² ≥ 0`）；特征根不能全为零；`λ ≠ 0` 对应**非渐近主方向**、`λ = 0` 对应**渐近主方向**（因 `Φ(X,Y) = λ(X² + Y²)`）；中心曲线至少两条主直径（圆有无数条），非中心曲线只有一条。
- **求主方向**：`X:Y = a₁₂ : (λ − a₁₁) = (λ − a₂₂) : a₁₂`。两特征根不等时两主方向互相垂直；`I₂ = 0` 时 `λ₁ = I₁, λ₂ = 0`。

### 7. §5.6 坐标变换与方程化简

- **移轴** `x = x′ + x₀, y = y′ + y₀`；**转轴** `x = x′cos α − y′sin α, y = x′sin α + y′cos α`；一般变换 = 转轴 + 移轴（以两垂直直线定新轴的公式见教材 (5.6-5)，符号须使两式对应系数同号以保持右手系）。
- **系数变化规律**：移轴下二次项系数不变，一次项变为 `2F₁(x₀,y₀)`、`2F₂(x₀,y₀)`，常数项变为 `F(x₀,y₀)` ⇒ 有中心时把原点搬到中心，**一次项一次消失**。转轴下二次项、一次项系数一般改变（分别只与原二次项、原一次项及 `α` 有关），常数项不变 ⇒ **转轴消不掉一次项，也造不出一项**。
- **消交叉项的角度公式**：`cot 2α = (a₁₁ − a₂₂)/(2a₁₂)`   (5.6-8)

  用 `cot` 而非 `tan`，因为 `a₁₁ = a₂₂` 时 `tan 2α` 无意义而 `cot 2α = 0` 仍有意义。化成 `tan²α + ((a₁₁−a₂₂)/a₁₂)tan α − 1 = 0`，两根之积 `−1`，两解只差 `π/2`（横纵轴互换）。
- **定理5.6.1（简化方程）**：(I) `a₁₁x² + a₂₂y² + a₃₃ = 0`（中心曲线）；(II) `a₂₂y² + 2a₁₃x = 0`（无心曲线）；(III) `a₂₂y² + a₃₃ = 0`（线心曲线）。
- **定理5.6.2（九种标准方程）**：椭圆、虚椭圆、双曲线、点、两相交直线、抛物线、两平行直线、两平行共轭虚直线、两重合直线 —— 九种标准方程见速查表 A/B，判定条件由 `I₁, I₂, I₃, K₁` 完全给出。

### 8. §5.7 不变量与半不变量

- **定义5.7.1 / 定理5.7.1~5.7.2**：在直角坐标变换下不变（仅在转轴下不变）的系数函数叫**不变量**（**半不变量**）。三个不变量与一个半不变量：

  ```
  I₁ = a₁₁ + a₂₂
       ⎪a₁₁  a₁₂⎪              ⎪a₁₁  a₁₂  a₁₃⎪
  I₂ = ⎪        ⎪        I₃ =   ⎪a₁₂  a₂₂  a₂₃⎪
       ⎪a₁₂  a₂₂⎪              ⎪a₁₃  a₂₃  a₃₃⎪
       ⎪a₁₁  a₁₃⎪   ⎪a₂₂  a₂₃⎪
  K₁ = ⎪        ⎪ + ⎪        ⎪ = I₁a₃₃ − (a₁₃² + a₂₃²)
       ⎪a₁₃  a₃₃⎪   ⎪a₂₃  a₃₃⎪
  ```

  `I₁` 是 `A*` 的迹，`I₂` 是 `A*` 的行列式，`I₃` 是 `A` 的行列式；线心曲线时 `K₁` 也是不变量。
- **化简三定理（略去撇号）**：中心曲线（`I₂ ≠ 0`）`λ₁x² + λ₂y² + I₃/I₂ = 0`（定理5.7.3）；无心曲线（`I₂ = 0, I₃ ≠ 0`）`I₁y² ± 2√(−I₃/I₁)·x = 0`（定理5.7.4）；线心曲线（`I₂ = I₃ = 0`）`I₁y² + K₁/I₁ = 0`（定理5.7.5）。其中 `λ₁ + λ₂ = I₁`、`λ₁λ₂ = I₂`，故**不变量就是特征值的和与积**。
- **由不变量读几何量**：中心曲线半轴 `a² = −I₃/(λ₁I₂)`、`b² = −I₃/(λ₂I₂)`（按符号配对取舍使平方为正）；抛物线焦点参数 `p = √(−I₃/I₁³)`；两平行直线距离 `d = 2√(−K₁)/|I₁|`（由 `I₁y² + K₁/I₁ = 0` 得 `y = ±√(−K₁)/|I₁|`，间距为其两倍；例：`2y² − 5 = 0` 有 `I₁ = 2`、`K₁ = −10`，故 `d = 2√10/2 = √10`，与 `y = ±√(5/2)` 相符）。

## Key Concepts / 核心概念

- **渐近方向（asymptotic direction）**：使 `Φ(X,Y) = 0` 的方向，即与曲线"交于无穷远"的方向。
- **中心（center）**：所有弦的中点的公共点，由 `F₁ = F₂ = 0` 确定，存在性由 `I₂`、`I₃` 决定。
- **渐近线（asymptote）**：过中心且以渐近方向为方向的直线，即与自己共轭的直径。
- **正则点 / 奇异点（regular / singular point）**：曲线上 `F₁, F₂` 不全为零的点为正则点；`F₁ = F₂ = 0` 的点为奇点，该点处切线不确定。
- **直径（diameter）**：一族平行弦中点的轨迹直线，方程 `XF₁ + YF₂ = 0`。
- **共轭方向（conjugate directions）**：满足 `a₁₁XX′ + a₁₂(XY′ + X′Y) + a₂₂YY′ = 0` 的一对方向。
- **主方向与主直径（principal direction / principal diameter）**：特征方程的解所定的方向；主直径即对称轴，与曲线的交点叫顶点。
- **不变量（invariant）**：`I₁, I₂, I₃` 在任意直角坐标变换下不变；`K₁` 是**半不变量**（仅转轴下不变），线心曲线时也是不变量。
- **九种二次曲线（nine canonical conics）**：椭圆、虚椭圆、双曲线、点、两相交直线、抛物线、两平行直线、两平行共轭虚直线、两重合直线。

## Mental Models / 思维模型

- **把 `A` 看成实对称矩阵、`A*` 看成它的二次型部分。** 渐近方向 = 二次型取零的（迷向）方向，特征根 = `A*` 的特征值，主方向 = 特征向量，`cot 2α` 就是正交对角化的旋转角。化简二次曲线 = 正交对角化 + 配方。
- **把"平移"和"旋转"当成两个独立旋钮。** 平移只管一次项（把中心/顶点搬到原点），旋转只管交叉项（把轴转到与主方向平行）。有中心时先平移更省事；无中心（抛物线）时先旋转更省事。
- **把不变量当成曲线的身份证号。** 坐标系怎么换，`I₁, I₂, I₃` 都读得出来；算出这三个数就绕过了"求坐标变换"这一步。`I₃ = 0`（`det A = 0`）即曲线退化成两条直线，`I₂ = 0`（`det A* = 0`）即二次型退化、抛物线型 —— 把"退化"看成矩阵降秩。

## Anti-patterns / 常见错误

- **把方向数当标量。** OCR 会丢掉箭头与黑体。凡 `(X,Y)`、`X:Y` 出现在 `Φ(X,Y)`、`XF₁ + YF₂` 中，它都是**方向向量（direction vector）**的方向数，不是点的坐标。
- **`a₁₂` 错序，或把 `2a₁₂` 记成 `a₁₂`。** 方程里交叉项系数是 `2a₁₂`，矩阵里是 `a₁₂`。写矩阵前先把六个系数抄成一行 `(a₁₁,a₁₂,a₂₂,a₁₃,a₂₃,a₃₃)` 再落位。
- **`A` 写成非对称矩阵。** 必须 `A = Aᵀ`。把 OCR 打散的三行原样堆起来常得到非对称矩阵，`I₃` 随之算错。
- **用 `tan 2α` 而不用 `cot 2α`。** `a₁₁ = a₂₂` 时 `tan 2α = 2a₁₂/(a₁₁−a₂₂)` 分母为零无意义，而 `cot 2α = 0` 干净地给出 `α = π/4`。
- **有中心却先转轴。** 中心曲线应**先移轴到中心**（一次项全消、二次项不变）再转轴消交叉项；顺序颠倒会把一次项留在方程里。
- **对非中心曲线硬套"平移消一次项"。** 抛物型 `I₂ = 0` 没有中心，平移**不可能**同时消去两个一次项。同理，直径方程只在**非渐近方向**上有意义：方向取成渐近方向时 `t` 的二次项系数为零，中点条件 `t₁ + t₂ = 0` 失效。
- **混淆 `I₃ ≠ 0` 与 `I₃ = 0`。** `I₂ > 0, I₃ = 0` 是点（一对交于实点的共轭虚直线），不是"很小的椭圆"；`I₂ < 0, I₃ = 0` 是两相交直线，不是双曲线。
- **算 `I₃` 时不利用行列运算。** 直接展开三阶行列式容易错符号；先做行（列）相减补齐 `−x₀, −y₀` 之类，或按含 `0` 最多的行（列）展开。
- **把 `λ` 认成 `入`/`A`/`2`、`α` 认成 `a`、`θ` 认成 `0`、`Δ` 认成 `A`。** 判据是上下文：`λ² − I₁λ + I₂ = 0` 里的符号只能是 `λ`；`²` 丢失时靠"是否齐次二次"区分 `a₁₁X + a₁₂Y` 与 `a₁₁X² + 2a₁₂XY + a₂₂Y²`。

### 章结构与学习要求（书 p114–p115）

- **主线**：全章从「二次曲线与直线相交」一处切入——把 `{x=x₀+Xt, y=y₀+Yt}` 代入 `F(x,y)=0` 得 `Φ(X,Y)t² + 2[F₁X+F₂Y]t + F = 0`，由这个关于 `t` 的方程的解的个数与重数，依次引出交点、切线、渐近方向、中心、直径、主方向等全部性质。抓住这条线，概念就不散。
- **三个单元**：① 渐近线、切线与直径及相关概念（教材 §5.1–§5.5，全部由「与直线相交」引出）；② 方程化简与分类（§5.6：直角坐标变换 → 最简方程 → 标准方程 → **九类**）；③ 不变量及其应用（§5.7：证明 `I₁,I₂,I₃` 不变、`K₁` 对线心曲线不变，再用它们直接化简与判别）。
- **学习要求（书 p115）**：① 记号 `F, F₁, F₂, F₃, Φ, I₁, I₂, I₃, K₁` 必须记准不错（下标错位是本章第一大失分点）；② 熟悉二次曲线与直线相交的各种情况及成立条件；③ 会求渐近线、切线、直径；④ 弄清特征方程/特征根与主方向/主直径的关系并会求；⑤ 掌握移轴、转轴对系数的变换规律，会用坐标变换化简。
- **提示**：本章方法可整体推广到空间，下一章「二次曲面的一般理论」就是它的三维版本（矩阵 3×3 → 4×4）。

1. **渐近线有三种算法，用哪种取决于题目已经给了什么**（辅导书 §5.3.1 第 1 款）：① 定义法——先解中心、再由 `Φ(X,Y) = 0` 求渐近方向、最后写过中心的直线；② 公式法——`Φ(x−x₀, y−y₀) = 0`，只要中心，一次拿到两条渐近线，**不必先解方向**；③ 自共轭直径法——把渐近方向 `X:Y` 直接代入直径公式 `XF₁ + YF₂ = 0`，**连中心都不必求**。已知中心用 ②、已知方向用 ③、两者都没有用 ①。
2. **「有心才有渐近线」，三种曲线三种下场**（辅导书 §5.3.1 第 1 款）：无心曲线（抛物线）**没有**渐近线；线心曲线只有**一条**渐近线，就是它的中心直线；椭圆型虽有两条渐近方向，却是一对共轭虚方向，得到的是两条**虚渐近线** `(x−x₀)/a ± i(y−y₀)/b = 0`——代数上成立、画不出来。把虚渐近线当实直线画是本节的典型失分点。
3. **只改常数项，渐近线不动**（辅导书 §5.3.1 第 1 款）：中心与渐近方向都没变，渐近线自然不变，所以只差常数项的一族曲线 `a₁₁x²+2a₁₂xy+a₂₂y²+2a₁₃x+2a₂₃y+λ = 0` 的渐近线完全相同。推论：以两条相交直线 `A₁x+B₁y+C₁ = 0`、`A₂x+B₂y+C₂ = 0` 为渐近线的曲线一律可写成 `(A₁x+B₁y+C₁)(A₂x+B₂y+C₂) + λ = 0`；退化成员 `λ = 0` 是那两条直线本身。只以**一条**直线为渐近线时写成 `(A₁x+B₁y+C₁)(Ax+By+C) + λ = 0`，`Ax+By+C = 0` 可以是任一条与它相交的直线。
4. **奇点可以是一整条直线，不只是两个点**（辅导书 §5.3.1 第 2 款）：曲线退化为两条相交直线时，交点是奇点——过它的每条直线都与曲线交于两重合点；退化为二重直线 `(ax+by+c)² = 0` 时，**整条直线上每一点都是奇点**。所以「奇点」与「切点」不是一回事；辅导书明确：今后说的切线都是**正则点**处的切线，奇点处的切线不讨论。
5. **斜率式切线三公式要当公式背，且各自藏着适用条件**（辅导书 §5.3.1 第 2 款）：椭圆 `y = kx ± √(a²k²+b²)`；双曲线 `y = kx ± √(a²k²−b²)`（**须 `|k| > b/a`**，否则根号内为负——斜率必须比渐近线更陡）；抛物线 `y² = 2px` 为 `y = kx + p/(2k)`（**`k ≠ 0`**，竖直切线 `x = 0` 要另补）。公式里的 `±` 藏着的正是这些条件。
6. **直径在三种曲线上的三种面貌来自同一个式子**（辅导书 §5.3.1 第 3 款）：`XF₁ + YF₂ = 0` 对所有二次曲线都成立，但中心曲线的直径**全过中心**、无心曲线的直径**全平行于渐近方向**、线心曲线**只有一条**直径（中心直线）。于是「求过点 `M` 的直径」有统一答法：中心曲线就连 `M` 与中心的直线，无心曲线就过 `M` 作平行于渐近方向的直线。
7. **上面的结论反过来也成立，而反证的关键是「方向必须非渐近」**（辅导书 §5.3.1 第 3 款末；教材§5.4 习题6）：过中心的直线一定是直径——因为中心是 `F₁ = 0` 与 `F₂ = 0` 两直线的交点，过它的直线总可写成 `λF₁ + μF₂ = 0`，正好是共轭于方向 `λ:μ` 的直径；平行于渐近方向的直线一定是无心曲线的直径。证明后半句时必须验「所用方向不是渐近方向」：若是，`F₁ = 0` 与 `F₂ = 0` 两行成比例、曲线退化为线心，与 `I₃ ≠ 0` 矛盾。
8. **共轭直径的旋转图像：椭圆同向转、双曲线反向转**（辅导书 §5.3.1 第 4 款）：椭圆 `kk′ = −b²/a²` 异号，一对共轭直径分处**不同象限**，一条逆时针转时另一条也逆时针转；双曲线 `kk′ = +b²/a²` 同号，一对共轭直径在**同一象限**，一条逆时针转时另一条**顺时针**转。两者的共同点是：一条直径趋近渐近线时，它的共轭直径也趋近同一条渐近线——这就是**渐近线是与自己共轭的直径**的几何解释（教材是从 `Φ(X′,Y′) = I₂Φ(X,Y)` 代数地推的，辅导书从旋转方向给了解释）。
9. **「先移轴后转轴」不是习惯，是有根据的**（辅导书 §5.3.2 第 2 款）：转轴下常数项不变，一次项系数只是老一次项的旋转组合（`a₁₃′ = a₁₃cos α + a₂₃sin α`、`a₂₃′ = −a₁₃sin α + a₂₃cos α`），所以先移轴到中心把一次项清零之后，**再转轴不会把一次项造回来**。反过来先转轴再移轴也能做，只是多算一次一次项。这就是中心曲线「先移轴、后转轴」的全部理由；而无心曲线没有中心可移，只能先转轴、再配方移轴。
10. **`cot 2α` 的两个根对应「两轴互换」，两种转法都对**（辅导书 §5.3.2 第 2 款）：化成 `tan²α + [(a₁₁−a₂₂)/a₁₂]tan α − 1 = 0` 后，判别式 `[(a₁₁−a₂₂)/a₁₂]² + 4 > 0` 恒正，故总有两个不等实根；韦达定理给两根之积 `−1`，故 `α₁, α₂` 相差 `π/2`，横纵轴恰好对调——**任取一根即可**。两个省事特例：`a₁₂ = 0` 时根本不必转轴；`a₁₁ = a₂₂` 时 `cot 2α = 0` 直接给 `α = π/4`。
11. **不变量作图可以完全绕开「求中心」，但主方向与轴方程的足标是交叉的**（辅导书 §5.3.2 第 3 款）：中心曲线拿两条主直径当新轴，`x′` 轴的方程是 `X₂F₁ + Y₂F₂ = 0`、`y′` 轴的方程是 `X₁F₁ + Y₁F₂ = 0`，其中 `X₁:Y₁` 是 `λ₁`（`x′²` 项系数）确定的主方向、`X₂:Y₂` 是 `λ₂`（`y′²` 项系数）确定的主方向。**方向用谁的、方程写谁的，正好交叉**：`x′` 轴的方向由 `λ₁` 定，方程却用 `X₂, Y₂` 写。这是全节最容易张冠李戴的一处。
12. **无心曲线作图比中心曲线多两步：定顶点、定凹向**（辅导书 §5.3.2 第 3 款）：主方向是 `X₂:Y₂ = a₁₁:a₁₂`（由 `λ₂ = I₁` 确定的那个，非零特征根），共轭于它的直径 `a₁₁x + a₁₂y + (a₁₁a₁₃+a₁₂a₂₃)/I₁ = 0` 就是对称轴（取作 `x′` 轴）；对称轴与曲线联立得**顶点**，过顶点垂直于对称轴的是**顶切线**（`y′` 轴）。开口方向没有公式：在原方程上任取一个非顶点点，看它与原点是否在顶切线的**同侧**，抛物线就在含该点的那一侧。`x′` 轴的正向还与简化方程中 `±` 的取法有关：取负号时与开口同向，取正号时反向。
13. **`K₁` 的半不变性只需验移轴，因为「半不变量」的定义就是「只在移轴下不变」**（辅导书 §5.3.3）：线心情形用三个条件 `a₁₁a₂₂−a₁₂² = 0`、`a₂₂a₁₃−a₁₂a₂₃ = 0`、`a₁₁a₂₃−a₁₂a₁₃ = 0` 把移轴后的 `K₁′` 化简回 `K₁`，两三行就完。教材那条较长的证法不是白写的：它可以**逐字搬到空间**去证定理6.7.2（`K₂` 的半不变性）。「短证明」与「可推广的证明」在这里是两个不同的目标。

### 例 1（书 p132–133）· 求渐近线：定义法 / 公式法 / 自共轭直径（三解对比）

**题目**：求曲线 `3x² + 10xy + 7y² + 4x + 2y + 1 = 0` 的渐近线。

**分析**：先算 `I₂ = 21 − 25 = −4 < 0`，双曲型，确实有两条实渐近线。三条路的分水岭在**先求什么**：先求中心（解法一、二）要多解一个二元一次方程组，但渐近方向随后由 `Φ = 0` 因式分解即得；先求方向（解法三）省掉中心，一步写出方程。本题三种算法的步数接近，正好体会「公式法最省、定义法最稳、自共轭直径法最快」。

**解（解法二·公式法）**：`F₁ = 3x + 5y + 2`、`F₂ = 5x + 7y + 1`，解中心方程组得中心 `(9/4, −7/4)`。渐近线为 `Φ(x−9/4, y+7/4) = 0`，即
`3u² + 10uv + 7v² = (3u + 7v)(u + v) = 0`（`u = x − 9/4, v = y + 7/4`），
故 `3(x−9/4) + 7(y+7/4) = 0` 与 `(x−9/4) + (y+7/4) = 0`，整理得两条渐近线
`6x + 14y + 11 = 0` 与 `2x + 2y − 1 = 0`。

**一题多解**：解法一（定义法）先求中心，再由 `3X² + 10XY + 7Y² = (3X+7Y)(X+Y) = 0` 得渐近方向 `7:(−3)` 与 `1:(−1)`，最后用点向式 `(x−9/4)/7 = (y+7/4)/(−3)` 等写直线。解法三（自共轭直径法）**不求中心**：渐近线是与自己共轭的直径，把 `X:Y = 7:(−3)` 代入 `XF₁ + YF₂ = 0` 得 `7(3x+5y+2) − 3(5x+7y+1) = 0`，即 `6x + 14y + 11 = 0`；换成 `1:(−1)` 得 `(3x+5y+2) − (5x+7y+1) = 0`，即 `2x + 2y − 1 = 0`。**取舍**：解法三计算量最小，但要先"看穿"渐近线是自共轭直径；解法二最程序化、最不易错；解法一最不易把方向的比例写反。

**易错**：
- 渐近方向的比例写反：`3X + 7Y = 0` 给的是 `X:Y = 7:(−3)`（不是 `3:7`，也不是 `−3:7`）。
- 点向式 `(x−x₀)/X = (y−y₀)/Y` 里 `Y` 为负时丢掉符号，写成 `−3(x−9/4) = 7(y+7/4)` 之类。
- 中心算完要顺手用 `I₂` 校核系数行列式：`|3 5; 5 7| = −4 = I₂` ✓，不必重算。
- 不先验 `I₂ < 0` 就写"两条渐近线"：`I₂ > 0` 时得到的是两条虚渐近线（学习辅导要点第 2 条）。

### 例 2（书 p133–134）· 已知切线方向求切线：设切点 vs 共轭直径

**题目**：求曲线 `x² + 4xy + 3y² − 5x − 6y + 3 = 0` 的平行于直线 `x + 4y = 0` 的切线。（教材§5.3 习题2(1)）

**分析**：题眼是「只知道方向、不知道切点」，两条路正好互为对偶。解法一**设切点** `(x₀,y₀)`，用对称式切线公式写出切线，令它平行于 `x + 4y = 0` 得到一个一次条件，再与「切点在曲线上」联立；解法二把切线看成**两端点重合的弦**，于是切点就是「共轭于该方向的直径」与曲线的交点——少一次平方、几何意义更清楚。两解得到的那个一次条件其实是同一条直线（`2x + 5y − 7 = 0`），这一点本身就是很好的自检。

**解（解法二·共轭直径法）**：切线方向取 `x + 4y = 0` 的方向 `4:(−1)`。共轭于此方向的直径是 `4F₁ − F₂ = 0`，其中 `F₁ = x + 2y − 5/2`、`F₂ = 2x + 3y − 3`，即
`4(x + 2y − 5/2) − (2x + 3y − 3) = 2x + 5y − 7 = 0`。
与曲线联立（由 `2x + 5y − 7 = 0` 解出 `y = (7 − 2x)/5`）得 `x = 1` 或 `x = −4`，即切点 `(1,1)`、`(−4,3)`。由正则点切线公式得两条切线
`x + 4y − 5 = 0` 与 `x + 4y − 8 = 0`。

**一题多解（解法一·设切点）** 设切点 `(x₀,y₀)`，对称式切线为 `x₀x + 2(x₀y + xy₀) + 3y₀y − (5/2)(x + x₀) − 3(y + y₀) + 3 = 0`，即 `(x₀ + 2y₀ − 5/2)x + (2x₀ + 3y₀ − 3)y + (−5x₀/2 − 3y₀ + 3) = 0`。它平行于 `x + 4y = 0` ⟺ 两系数成 `1:4`，即 `4(x₀ + 2y₀ − 5/2) = 2x₀ + 3y₀ − 3`，化简得 `2x₀ + 5y₀ − 7 = 0`——正是解法二那条直径。再与曲线联立即得同一组切点。**取舍**：解法一不必知道「共轭直径」，但要求把对称式切线公式背准、比较系数时别漏常数项；解法二少一次平方，还顺带看出「切点集 = 直径与曲线的交点」。

**易错**：
- 方向数取反：`x + 4y = 0` 的方向是 `4:(−1)`（法向量才是 `(1,4)`）。取成 `1:4` 得到的是「法线方向」的直径，联立后无实交点。
- 共轭直径的系数抄错：`x² + 4xy + 3y² − 5x − 6y + 3` 有 `a₁₂ = 2`、`a₁₃ = −5/2`、`a₂₃ = −3`，故 `F₁ = x + 2y − 5/2`；写成 `x + 4y − 5/2` 就全错。
- 只写一条切线：直径与曲线一般交于两点，两条切线都要给。
- 不验平行：两条答案的法向量都应为 `(1,4)`，且 `(1,4)·(4,−1) = 0` ✓。

### 例 3（书 p134–137）· 椭圆两垂直切线的交点轨迹：斜率 / 法式 / 判别式加韦达

**题目**：求椭圆 `x²/a² + y²/b² = 1` 的两条互相垂直的切线的交点的轨迹。

**分析**：这是「轨迹 + 二次曲线」的混合题，三个解法代表三种参数化方式。解法一拿**斜率**当参数（两条切线斜率 `k` 与 `−1/k`）；解法二拿**法线的方位角** α 当参数（法式 `x cos α + y sin α = p`，垂直条件变成 α 与 `α + π/2`）；解法三拿**交点 `M₀(x₀,y₀)` 本身**当参数，用「过 `M₀` 的直线成为切线」的判别式条件，再用韦达定理把「两斜率之积 `= −1`」翻译成 `M₀` 的方程。解法一、二靠三角恒等式一步到位；解法三是通法——换掉 `F` 就能处理任何二次曲线的同类问题。

**解（解法一·斜率参数）**：斜率 `k` 的切线为 `y = kx ± √(a²k² + b²)`，即 `y − kx = ±√(a²k² + b²)`；与之垂直的切线斜率为 `−1/k`，方程为 `y = −x/k ± √(a²/k² + b²)`，两边乘 `k` 得 `ky + x = ±√(a² + b²k²)`。设交点为 `(x,y)`，两式平方后相加（左边的 `k` 交叉项正好抵消）：
`(y − kx)² + (ky + x)² = (a²k² + b²) + (a² + b²k²)`，
左边 `= (1 + k²)(x² + y²)`、右边 `= (1 + k²)(a² + b²)`，故轨迹为
`x² + y² = a² + b²`（圆心在椭圆中心、半径 `√(a² + b²)` 的圆）。

**一题多解**：解法二取切线法式 `x cos α + y sin α − p = 0`，它切椭圆的充要条件是 `p² = a²cos²α + b²sin²α`；与它垂直的切线方位角为 `α + π/2`，条件为 `p′² = a²sin²α + b²cos²α`。交点同时满足两直线方程，平方相加消去 α 即得 `x² + y² = p² + p′² = a² + b²`。解法三设交点为 `M₀(x₀,y₀)`，过 `M₀` 的直线 `x = x₀ + Xt, y = y₀ + Yt` 是切线 ⟺ `[XF₁ + YF₂]² − Φ(X,Y)F(x₀,y₀) = 0`；代入 `F₁ = x₀/a²`、`F₂ = y₀/b²`、`Φ = X²/a² + Y²/b²`、`F(x₀,y₀) = x₀²/a² + y₀²/b² − 1` 并整理，得关于斜率 `k = Y/X` 的二次方程
`(a² − x₀²)k² + 2x₀y₀k + (b² − y₀²) = 0`，
两切线垂直 ⟺ `k₁k₂ = (b² − y₀²)/(a² − x₀²) = −1` ⟺ `x₀² + y₀² = a² + b²`。**取舍**：解法一、二最快，但依赖「切线公式 / 法式」这一特定形式；解法三是通法，它把「垂直」完整地化成关于两斜率的韦达条件，最不容易漏解。

**易错**：
- 斜率参数的两个退化情形要单独交代：`k = 0` 时切线 `y = ±b`、垂直切线 `x = ±a`，交点为 `(±a, ±b)`，代入 `a² + b²` 仍成立——所以轨迹是完整的圆，不必补点，但要说明。
- 解法一第二式两边乘 `k` 时默认 `k ≠ 0`，正因如此上一条的退化情形必须先讨论。
- 把轨迹误判成椭圆：垂直条件是二次的，轨迹是**圆**（准圆），别写成 `x²/a² + y²/b² = 2`。
- 双曲线的同类结论是 `x² + y² = a² − b²`：`a = b` 时退化为一点，`a < b` 时无实轨迹（辅导书 p0137 的注），**不能照抄椭圆**。

### 例 4（书 p137）· 被定点平分的弦：共轭方向一次到位

**题目**：求双曲线 `x²/9 − y²/4 = 1` 被点 `(5,1)` 平分的弦的方程。

**分析**：题眼是「被 `M` 平分」 ⟺ 这条弦的**中点轨迹**（即直径）过 `M`。于是先找过 `M` 的直径，再取它的共轭方向当弦的方向。中心曲线这一步是免费的：过 `M` 与中心的连线就是直径（学习辅导要点第 6 条）。整题只用一次 `(5.4-5)`。

**解**：双曲线中心为原点，故过 `M(5,1)` 的直径就是 `OM`：`x − 5y = 0`，方向 `5:1`。设弦的方向为 `X′:Y′`，由共轭条件 `a₁₁XX′ + a₁₂(XY′ + X′Y) + a₂₂YY′ = 0`（`a₁₁ = 1/9`、`a₁₂ = 0`、`a₂₂ = −1/4`）得 `(5/9)X′ − (1/4)Y′ = 0`，即 `X′:Y′ = 9:20`。故所求弦为
`(x − 5)/9 = (y − 1)/20`，即 `20x − 9y − 91 = 0`。

**易错**：
- 把「平分弦的方向」当成直径方向：`5:1` 是**直径**的方向，被平分的弦本身的方向是它的共轭 `9:20`。
- `a₂₂` 的负号丢掉：`x²/9 − y²/4` 的 `a₂₂ = −1/4`，写成 `+1/4` 会得 `X′:Y′ = 9:(−20)`，弦的方向整个反掉。
- 验中点可用韦达定理：把 `y = (20x−91)/9` 代入得 `364x² − 3640x + 8605 = 0`，两根之和 `10`、中点横坐标 `5` ✓，判别式 `720720 > 0` 说明弦确实存在（点在双曲线右支外侧并不妨碍）。
- 不能把 `M` 直接代进 `XF₁ + YF₂ = 0` 解出 `X:Y` 就当弦：那个式子的解是**直径**，弦要用它的共轭方向。

### 例 6（书 p140–141）· 二次曲线束：过两曲线交点且过一点

**题目**：设一条二次曲线通过两条二次曲线 `x² + xy − 2y² + 6x − 1 = 0` 与 `2x² − y² − x − y = 0` 的交点，并且还通过点 `(2,−2)`，求它的方程。

**分析**：题眼是「过两曲线的四个交点」→ 用**二次曲线束**，绕开解四次方程组（解出四个交点既繁又要处理虚根）。束方程 `λF + μG = 0` 天然通过全部交点，再用「过 `(2,−2)`」定比例 `λ:μ`，一步收工。这是本章「参数选择」的另一种形态：不是选角、选时间，而是选**束参数**。

**解**：设所求曲线为 `λ(x² + xy − 2y² + 6x − 1) + μ(2x² − y² − x − y) = 0`。代入 `(2,−2)`：`F(2,−2) = 4 − 4 − 8 + 12 − 1 = 3`、`G(2,−2) = 8 − 4 − 2 + 2 = 4`，故 `3λ + 4μ = 0`，取 `λ:μ = 4:(−3)`。代回并展开：
`4(x² + xy − 2y² + 6x − 1) − 3(2x² − y² − x − y) = 0`，即
`2x² − 4xy + 5y² − 27x − 3y + 4 = 0`。（代回 `(2,−2)`：`8 + 16 + 20 − 54 + 6 + 4 = 0` ✓）

**易错**：
- 代入点的坐标算错：`F(2,−2)` 里 `xy = −4`、`−2y² = −8`，逐项加完再合并，别心算。
- 束方程写成 `F + λG = 0` 会**漏掉 `G = 0` 这一支**（它对任何有限的 λ 都取不到）；写成 `λF + μG = 0` 才完整。本题两支都不需要，但概念上要清楚。
- 展开时 `−3G` 的符号：`−3(−x − y) = +3x + 3y`，弄错会让一次项系数正好错位。
- 束参数只能定**比例**：`3λ + 4μ = 0` 说明这是一条直线上的解，任取 `λ = 4, μ = −3` 即可，不必求唯一值。

### 例 7（书 p141–143）· 三类方程的几何身份：平方和 / 平方差 / 平方加一次

**题目**：证明：(1) `(A₁x + B₁y + C₁)² + (A₂x + B₂y + C₂)² = 1`（其中 `A₁B₂ − A₂B₁ ≠ 0`、`A₁A₂ + B₁B₂ = 0`）表示一个椭圆；(2) `(A₁x + B₁y + C₁)² − (A₂x + B₂y + C₂)² = 1`（其中 `A₁B₂ − A₂B₁ ≠ 0`）表示一条双曲线，并求它的两条渐近线；(3) `(A₁x + B₁y + C₁)² + 2(A₂x + B₂y + C₂) = 0`（其中 `A₁B₂ − A₂B₁ ≠ 0`、`A₁A₂ + B₁B₂ = 0`）表示一条抛物线，并求它的对称轴与顶切线。

**分析**：题眼全在**给的两条直线能不能当坐标轴**。(1)(3) 多了垂直条件 `A₁A₂ + B₁B₂ = 0`，两直线相交且垂直 ⟹ 可以作**直角坐标变换**把它们变成两条坐标轴，方程立刻化成标准形；(2) **没有**垂直条件，只保证两直线相交，直角变换用不上，于是改用「平方差 = 两直线之积」的因式分解 + 「只差常数项 ⟹ 同渐近线」的结论。所以这三小题其实是在对比「能作直角变换」与「不能作直角变换」两种处理方式，也正是本章「不变量优先」的另一面：没有变换可作时，就回到代数结构。

**证（1）**：`A₁B₂ − A₂B₁ ≠ 0` 保证两直线相交，`A₁A₂ + B₁B₂ = 0` 保证垂直。令
`x′ = ±(A₂x + B₂y + C₂)/√(A₂² + B₂²)`、`y′ = ±(A₁x + B₁y + C₁)/√(A₁² + B₁²)`
（取符号使成右手系），则两直线变成 `x′ = 0` 与 `y′ = 0`，原方程化为 `(A₁² + B₁²)y′² + (A₂² + B₂²)x′² = 1`——标准椭圆。
（2）原方程可写成 `[(A₁ + A₂)x + (B₁ + B₂)y + (C₁ + C₂)]·[(A₁ − A₂)x + (B₁ − B₂)y + (C₁ − C₂)] = 1`。由 `A₁B₂ − A₂B₁ ≠ 0` 可算得这两条新直线的方向行列式为 `−2(A₁B₂ − A₂B₁) ≠ 0`，故它们相交；于是 `[·][·] = 0` 表示两条相交直线（退化双曲线，自身即其渐近线），而 `[·][·] = 1` 与 `[·][·] = 0` 只差常数项 ⟹ 同渐近线 ⟹ 原方程是非退化双曲线，渐近线为
`(A₁ + A₂)x + (B₁ + B₂)y + (C₁ + C₂) = 0` 与 `(A₁ − A₂)x + (B₁ − B₂)y + (C₁ − C₂) = 0`。
（3）同样作直角坐标变换（两直线分别为 `x′ = 0`、`y′ = 0`），原方程化为 `(A₁² + B₁²)y′² ± 2√(A₂² + B₂²)x′ = 0`，是抛物线。对称轴是 `y′ = 0`，即 `A₁x + B₁y + C₁ = 0`；顶切线是 `x′ = 0`，即 `A₂x + B₂y + C₂ = 0`。

**易错**：
- (2) 也去作直角坐标变换：两直线不垂直时「到直线的有向距离」不构成正交坐标，`x′² ± y′²` 的形式保不住，必须改用因式分解。
- 求对称轴 / 顶切线时张冠李戴：**被平方的那条直线 `A₁x + B₁y + C₁ = 0` 是对称轴**（`y′ = 0`），**只出现一次的 `A₂x + B₂y + C₂ = 0` 是顶切线**（`x′ = 0`）。
- 忘记用「两直线相交」：`A₁B₂ − A₂B₁ ≠ 0` 必须真的用上，(2) 里正是它保证 `[·][·] = 0` 不是一对平行线。
- (2) 的两条渐近线是 `A₁ ± A₂` 那一族（「和」与「差」两条），不是原来的 `A₁`、`A₂` 两条直线。

### 例 8（书 p143–145）· 化简 `8x² + 4xy + 5y² + 8x − 16y − 16 = 0`：移轴转轴 / 主直径 / 纯不变量

**题目**：化简二次曲线方程 `8x² + 4xy + 5y² + 8x − 16y − 16 = 0`，并作出它的图形。（**与本节「Worked Example / 工作示例」是同一题**，那里已给出坐标变换的完整流程与三处独立复核；此处只补三种解法的取舍与易错，计算不重复。）

**分析**：三种解法对应三种「找新轴」的方式。解法一按 **移轴 → 转轴** 的固定程序走（要解中心、要算 `cot 2α`、要解 `tan α` 的二次方程）；解法二直接求**两条主直径**当新轴（只需特征根与主方向，**不求中心**）；解法三**只用不变量**：`I₁, I₂, I₃` 给简化方程，主方向给轴方程，把坐标变换整条路绕开。题目的核心训练点是：**一旦只问「是什么曲线 / 标准方程 / 半轴」，就不该去求坐标变换**——那是最贵的一条路。

**解（解法三·不变量法）**：`I₁ = 8 + 5 = 13`，`I₂ = 8·5 − 2² = 36`，`I₃ = −1296`。特征方程 `λ² − 13λ + 36 = 0` 给 `λ₁ = 9`、`λ₂ = 4`。故简化方程为 `9x′² + 4y′² − 36 = 0`，标准方程 `x′²/4 + y′²/9 = 1`（椭圆，两半轴 2 与 3）。由 `I₂ > 0`、`I₁I₃ = 13×(−1296) < 0` 查表 A 亦判为椭圆。

**一题多解（三解取舍）**：解法一（移轴到中心 `(−1,2)` 得 `8x′² + 4x′y′ + 5y′² − 36 = 0`，再取 `tan α = 1/2` 转轴）全程约是解法三的三倍工作量，唯一的额外收获是**拿到了坐标变换公式**，作图必需。解法二（主直径 `x − 2y + 5 = 0`、`2x + y = 0` 直接当新轴）介于两者之间：**不必求中心**，但要算主方向、写两条直径方程，好处是作图时新轴位置一目了然。**取舍准则**：要作图或要变换公式 → 解法一 / 二；只要类型、标准方程、半轴 → 解法三（不变量法）；只要新轴在哪 → 解法二。
- 解法三的完整链条是：`I₁, I₂, I₃ → 特征根 → λ₁x² + λ₂y² + I₃/I₂ = 0 → 标准方程 → 半轴 a² = −I₃/(λ₁I₂) = 1296/(9×36) = 4`、`b² = −I₃/(λ₂I₂) = 1296/(4×36) = 9`。每一步都只用到三个数。

**易错**：
- 不变量法的第一坑是 `I₃` 的符号：本例 `I₃ = −1296`，若算成 `+1296`，则 `I₃/I₂ = +36`，简化方程变成 `9x² + 4y² + 36 = 0`（虚椭圆），与 `I₁I₃ < 0` 自相矛盾——用表 A 复核就是防这个。
- 半轴的足标：`x′²` 的分母是 `a² = −I₃/(λ₁I₂)`（对应 `λ₁ = 9`）而不是 `−I₃/(λ₂I₂)`；本例 `x′²/4 + y′²/9 = 1`，长轴沿 `y′`（半轴 3）。
- 解法二容易把主方向与轴方程配错（学习辅导要点第 11 条）：`x′` 轴方程要用 `X₂F₁ + Y₂F₂ = 0`，不是 `X₁F₁ + Y₁F₂`。
- 作图时 `y′` 轴的正向要按右手系定：`tan α = 1/2` 只定了 `x′` 的方向，`y′` 是把 `x′` 逆时针转 `π/2` 得到的，随手把椭圆画成「横的」是常见错。

### 例 9（书 p145–150）· 化简抛物线 `4x² − 4xy + y² + 6x − 8y + 3 = 0`：转轴配方 / 主直径 / 纯不变量 / 配方法

**题目**：化简二次曲线方程 `4x² − 4xy + y² + 6x − 8y + 3 = 0`，并作出它的图形。

**分析**：`I₂ = 4·1 − (−2)² = 0`，抛物型（非中心曲线），所以「先移轴到中心」这条路根本走不通——必须先转轴。四种解法是四个层次：解法一（转轴 + 配方 + 移轴）是标准程序；解法二（主直径 + 顶切线作新轴）几何意义最清楚，且**一次给出新轴位置**；解法三（纯不变量）最快得到简化方程与 `p`，但**轴还得另求**；解法四（配方法）把方程直接凑成 `(2x − y + 2)² = 2(x + 2y + 1/2)`，一步同时得到对称轴与顶切线，是本题最巧的路。题眼在 `Φ = (2x − y)²` 是**完全平方**：抛物型的一切都从「二次项是完全平方」出发。

**解（解法二·主直径法）**：`I₁ = 5`、`I₂ = 0`、`I₃ = −25 ≠ 0`，是抛物线。特征方程 `λ² − 5λ = 0` 给 `λ₁ = 5`、`λ₂ = 0`；非零根 `λ₁ = 5` 确定的主方向 `X₁:Y₁ = 2:(−1)`（非渐近），共轭于它的主直径即对称轴：
`2F₁ − F₂ = 2(4x − 2y + 3) − (−2x + y − 4) = 10x − 5y + 10 = 0`，即 `2x − y + 2 = 0`。
与曲线联立（`y = 2x + 2`）得顶点 `(−9/10, 1/5)`；过顶点垂直于对称轴的顶切线为 `x + 2y + 1/2 = 0`。取这两条线为新轴，写出坐标变换并代入，化简得 `5y′² − 2√5x′ = 0`，即 `y′² = (2√5/5)x′`，焦点参数 `p = √5/5`。

**一题多解**：解法一（`cot 2α = (4−1)/(2·(−2)) = −3/4` → `2tan²α − 3tan α − 2 = 0` → 取 `tan α = 2`）走「转轴 → 配方 → 移轴」，得 `5y″² − 2√5x″ = 0`（转轴后方程实为 `5y′² − (10/√5)x′ − (20/√5)y′ + 3 = 0`，配方即得；<!-- OCR存疑：p0150 该式三项前的正负号被拆行冲散，此处按直接代入重算并已用解法四的结果交叉验证 -->）；过程最长但每步都有通用公式，适合考场默写。解法三（纯不变量）只需 `I₁ = 5`、`I₃ = −25`：由 `p = √(−I₃/I₁³) = √(25/125) = √5/5` 与 `I₁y² ± 2√(−I₃/I₁)x = 0` 直接写出 `5y′² ± 2√5x′ = 0`——但 **`±` 号、轴的位置、开口方向都还得另求**，所以「纯不变量」只解决方程、不解决作图。解法四（配方法）最巧：把 `4x² − 4xy + y²` 看成 `(2x − y)²`，写成 `(2x − y + λ)² + 2(3 − 2λ)x − 2(4 − λ)y + 3 − λ² = 0`，令两直线 `2x − y + λ = 0` 与 `2(3 − 2λ)x − 2(4 − λ)y + 3 − λ² = 0` 垂直（`4(3 − 2λ) + 2(4 − λ) = 0`）得 `λ = 2`，于是 `(2x − y + 2)² = 2(x + 2y + 1/2)`——对称轴与顶切线**同时出现**，是本题最快的路。**取舍**：要作图 → 解法二或四；要通用程序 → 解法一；只要类型与 `p` → 解法三。

**易错**：
- 抛物型还去求中心：`F₁ = 0, F₂ = 0` 无解（或解出整条线），白费力气。
- 把 `λ₂ = 0` 对应的方向（`1:2`，渐近方向）拿去写主直径：主直径必须用**非零**特征根 `λ₁ = 5` 的方向 `2:(−1)`。
- 开口方向不能靠 `±` 猜：要在原方程上任取一个非顶点（如 `(0, 4 − √13)`），比较它与原点在顶切线 `x + 2y + 1/2 = 0` 左端的符号，同号 ⟹ 抛物线在含原点的一侧（本题正是如此）。
- `x′` 轴正向：简化方程取负号时与开口一致、取正号时相反，弄反会把抛物线画到轴的另一侧。

### 例 10（书 p150）· 参数方程判类型：把 (cos θ, sin θ) 当未知量解出来

**题目**：证明方程 `x = a cos θ + b sin θ`、`y = c cos θ + d sin θ`（`0 ≤ θ < 2π`，且 `|a b; c d| = ad − bc ≠ 0`）表示的曲线是一个椭圆。

**分析**：参数方程判类型只有一条路——**消参**。题眼是把它看成关于 `(cos θ, sin θ)` 的**线性方程组**：行列式非零保证唯一解，于是 `cos θ, sin θ` 被 `x, y` 内在地表出，再平方相加用 `cos² + sin² = 1` 把参数消干净。这也顺带解释了 `ad − bc ≠ 0` 为什么不能省：否则 `x, y` 线性相关，曲线退化成一条线段（椭圆的一个退化方向）。

**证**：由 `ad − bc ≠ 0`，用克拉默法则解出
`cos θ = (dx − by)/(ad − bc)`、`sin θ = (ay − cx)/(ad − bc)`。
平方相加得 `(dx − by)² + (ay − cx)² = (ad − bc)²`，展开即
`(c² + d²)x² − 2(bd + ac)xy + (a² + b²)y² − (ad − bc)² = 0`。
算不变量：`I₁ = a² + b² + c² + d²`、`I₂ = (a² + b²)(c² + d²) − (bd + ac)² = c²b² + d²a² − 2abcd = (ad − bc)² > 0`、`I₃ = −(ad − bc)⁴`。于是 `I₁I₃ = −(a² + b² + c² + d²)(ad − bc)⁴ < 0`，由表 A 判为**椭圆**。证毕。

**易错**：
- 解 `cos θ, sin θ` 时把分子写反：`cos θ` 是「右端列替换第一列」的行列式，故为 `dx − by`；`sin θ` 同理为 `ay − cx`。写反后平方和不变（本题的容错点），但**分母 `ad − bc` 不能漏**。
- `I₂` 的化简不能跳过：`(a² + b²)(c² + d²) − (bd + ac)² = a²c² + a²d² + b²c² + b²d² − (b²d² + 2abcd + a²c²) = a²d² + b²c² − 2abcd = (ad − bc)²`，直接断言 `I₂ > 0` 会被扣分。
- 平方相加不会增根：`cos²θ + sin²θ = 1` 是恒等式，且 `θ` 取遍 `[0,2π)` 时 `(cos θ, sin θ)` 跑遍单位圆，所以消参是**等价**的，不必另补范围。
- 若 `ad − bc = 0`，曲线退化为线段而不是椭圆——这正是条件不可省的理由，答题时要交代一句。

### 例 11（书 p150–151）· 含参数讨论类型：把分界点找全

**题目**：按实数 `λ` 的值，讨论方程 `x² − 4(1+λ)xy + 4y² − 2λx + 8y − (2λ−3) = 0` 表示何种二次曲线。

**分析**：含参数讨论只有一个原则：**把不变量全算成 `λ` 的函数，先解 `I₂ = 0` 与 `I₃ = 0` 这两个分界方程，再按分界点把数轴切成若干段**。本题 `I₁ = 5` 与 `λ` 无关，说明「迹」给不出任何分界；真正的分界全部来自 `I₂ = −4λ(λ+2)`（根 `0, −2`）与 `I₃ = 8(λ+2)(λ+1)(λ−1)`（根 `−2, −1, 1`）。两者并起来是 `−2, −1, 0, 1` 四个点、九段，逐段查表 A 即可。题眼：**分界点集 = `I₂` 的零点集 ∪ `I₃` 的零点集**，一个都不能漏。

**解**：`I₁ = 5`；`I₂ = 1·4 − 4(1+λ)² = −4λ(λ+2)`；`I₃ = 8λ³ + 16λ² − 8λ − 16 = 8(λ+2)(λ+1)(λ−1)`；`K₁ = I₁a₃₃ − (a₁₃² + a₂₃²) = −(λ² + 10λ + 1)`（只在 `I₂ = I₃ = 0` 时才需要）。分界点为 `λ = −2, −1, 0, 1`，逐段查表 A：
- `λ < −2`：`I₂ < 0, I₃ ≠ 0` ⟹ 双曲线；
- `λ = −2`：`I₂ = I₃ = 0`，`K₁ = 15 > 0` ⟹ 一对平行的共轭虚直线；
- `−2 < λ < −1`：`I₂ > 0, I₁I₃ > 0` ⟹ 虚椭圆；
- `λ = −1`：`I₂ > 0, I₃ = 0` ⟹ 一点；
- `−1 < λ < 0`：`I₂ > 0, I₁I₃ < 0` ⟹ 椭圆；
- `λ = 0`：`I₂ = 0, I₃ ≠ 0` ⟹ 抛物线；
- `0 < λ < 1`：`I₂ < 0, I₃ ≠ 0` ⟹ 双曲线；
- `λ = 1`：`I₂ < 0, I₃ = 0` ⟹ 两条相交直线；
- `λ > 1`：`I₂ < 0, I₃ ≠ 0` ⟹ 双曲线。

**易错**：
- 漏掉 `I₃ = 0` 的分界点（`λ = −2, −1, 1`）：只解 `I₂ = 0` 会漏掉「点」「两相交直线」「平行直线」这些退化情形，是本章最典型的失分。
- `I₂` 停在 `4 − 4(1+λ)²` 不再化简：必须化到 `−4λ(λ+2)` 才看得出根与符号。
- `λ = −2` 这一段必须算 `K₁`：`I₂ = I₃ = 0` 时「两平行实线 / 两平行虚线 / 两重合线」只能靠 `K₁` 的符号区分，本题 `K₁ = 15 > 0` 是虚的。
- 在分界点上「继承」两侧的类型：`λ = −1` 是**点**，两侧分别是虚椭圆与椭圆，退化点是独立类型。

## Worked Example / 工作示例

**题目**：化简 `8x² + 4xy + 5y² + 8x − 16y − 16 = 0`，写出坐标变换公式与标准方程。

**① 判类型。** `I₂ = |8 2; 2 5| = 40 − 4 = 36 ≠ 0`，是中心曲线。

**② 移轴（找中心）。** 由 `F₁ = 8x + 2y + 4 = 0`、`F₂ = 2x + 5y − 8 = 0` 解得中心 `(−1, 2)`。作移轴 `x = x′ − 1, y = y′ + 2`。移轴下二次项不变，一次项变为 `2F₁(x₀,y₀) = 2F₂(x₀,y₀) = 0`，常数项变为
`F(−1,2) = 8 − 8 + 20 − 8 − 32 − 16 = −36`。
得 `8x′² + 4x′y′ + 5y′² − 36 = 0`。（一次项果然消失，说明 `(−1,2)` 确为中心。）

**③ 转轴消交叉项。** `cot 2α = (a₁₁ − a₂₂)/(2a₁₂) = (8 − 5)/4 = 3/4`，即 `(1 − tan²α)/(2tan α) = 3/4`，得
`2tan²α + 3tan α − 2 = 0`，即 `(2tan α − 1)(tan α + 2) = 0`。取 `tan α = 1/2`，则 `sin α = 1/√5, cos α = 2/√5`，转轴公式为
`x′ = (2x″ − y″)/√5,  y′ = (x″ + 2y″)/√5`。

**④ 写简化方程。** 特征方程 `λ² − 13λ + 36 = 0` 给 `λ₁ = 9, λ₂ = 4`；新二次项系数就是特征根，故
`9x″² + 4y″² − 36 = 0`，标准方程 `x″²/4 + y″²/9 = 1`，是椭圆。

**⑤ 用不变量独立复核。** `I₁ = 13 = λ₁ + λ₂` ✓，`I₂ = 36 = λ₁λ₂` ✓。
`I₃ = |8 2 4; 2 5 −8; 4 −8 −16|`，按第一行展开：
`8(5(−16) − 64) − 2(2(−16) − (−8)(4)) + 4(2(−8) − 5·4) = 8(−144) − 0 + 4(−36) = −1296`。
由定理5.7.3，`I₃/I₂ = −1296/36 = −36`，故简化方程应为 `9x² + 4y² − 36 = 0` ✓，与④一致。
又 `I₂ > 0`、`I₁I₃ = 13×(−1296) < 0`，查表 A 得**椭圆** ✓。三处独立结果互相印证。

**⑥ 两条主直径（作图用）。** `x″` 轴方向为 `λ₁ = 9` 的主方向 `X₁:Y₁ = a₁₂ : (λ₁ − a₁₁) = 2 : 1`；`y″` 轴方向为 `λ₂ = 4` 的主方向 `X₂:Y₂ = 2 : (4 − 8) = 1 : (−2)`。由 `X₂F₁ + Y₂F₂ = 0` 与 `X₁F₁ + Y₁F₂ = 0`：
`(8x + 2y + 4) − 2(2x + 5y − 8) = 0 ⇒ x − 2y + 5 = 0`；
`2(8x + 2y + 4) + (2x + 5y − 8) = 0 ⇒ 2x + y = 0`。
③中取的 `tan α = 1/2` 对应新轴方向 `2:1`，与 `λ₁ = 9` 的主方向一致，可作交叉验证。

## 解题套路 / Solution Patterns

**题型 1：用坐标变换化简（"旋转 — 平移"标准流程）**

- **识别特征**：给出带 `xy` 项和一次项的一般方程，要求化简并作图 / 写标准方程与坐标变换公式。
- **步骤**：
  1. 算 `I₂ = a₁₁a₂₂ − a₁₂²`，分清中心曲线（`I₂ ≠ 0`）与非中心曲线（`I₂ = 0`）。
  2. **有中心**：解 `F₁ = F₂ = 0` 得中心，作移轴；只需算常数项 `F(x₀,y₀)`，其余系数不变。**无中心**：跳过此步，先转轴。
  3. 由 `cot 2α = (a₁₁ − a₂₂)/(2a₁₂)` 求 `α`（化成 `tan` 的二次方程，取一解即可），写出转轴公式。
  4. 用配方法或直接用特征根写新方程（新二次项系数即 `λ₁, λ₂`，交叉项为零）。
  5. 非中心曲线转轴后仍需配方再作一次移轴。
  6. 化标准形式读类型；作图前先由主方向与主直径公式写出新坐标轴。
- **易错点**：`I₂ ≠ 0` 却先转轴；用 `tan 2α` 导致除零；移轴漏算常数项；`cot 2α` 分子分母写反（`a₁₁ − a₂₂` 在上）；`sin α, cos α` 符号取错使新轴方向翻转（用 `X:Y = a₁₂ : (λ − a₁₁)` 交叉验证）。

**题型 2：用不变量直接分类（最实用）**

- **识别特征**：只问"判断为何种曲线、求简化方程与标准方程"，或"当 `λ` 取何值时表示两条直线 / 抛物线 / 椭圆"。
- **步骤**：
  1. 抄出六个系数，落成对称矩阵 `A`。
  2. 算 `I₁ = a₁₁ + a₂₂`、`I₂ = a₁₁a₂₂ − a₁₂²`；**需要时**才算 `I₃ = det A`。
  3. 查表 A：先由 `I₂` 符号定大类，再由 `I₃` 是否为零分流退化情形；仅当 `I₂ = I₃ = 0` 才算 `K₁ = I₁a₃₃ − (a₁₃² + a₂₃²)`。
  4. 写简化方程：中心曲线解 `λ² − I₁λ + I₂ = 0` 后代 `λ₁x² + λ₂y² + I₃/I₂ = 0`；无心曲线用 `I₁y² ± 2√(−I₃/I₁)x = 0`；线心曲线用 `I₁y² + K₁/I₁ = 0`。
  5. 化为标准方程，顺手读出半轴长 / 焦点参数 / 平行线距离。
- **易错点**：`I₃` 符号错；`I₂ > 0, I₃ = 0` 误报为椭圆；漏算 `K₁`；把 `I₃/I₂` 写成 `I₂/I₃`。**务必用 `λ₁ + λ₂ = I₁`、`λ₁λ₂ = I₂` 复核特征根。**
- **完整示范**：判断 `6xy + 8y² − 12x − 26y + 11 = 0`。
  系数 `a₁₁ = 0, a₁₂ = 3, a₂₂ = 8, a₁₃ = −6, a₂₃ = −13, a₃₃ = 11`。
  `I₁ = 0 + 8 = 8`，`I₂ = 0·8 − 3² = −9`。
  `I₃ = |0 3 −6; 3 8 −13; −6 −13 11|`，按第一行展开（首元为零）：
  `−3(3·11 − (−13)(−6)) + (−6)(3(−13) − 8(−6)) = −3(33 − 78) − 6(−39 + 48) = 135 − 54 = 81`。
  查表 A：`I₂ < 0, I₃ ≠ 0` ⇒ **双曲线**。
  特征方程 `λ² − 8λ − 9 = 0` ⇒ `λ₁ = 9, λ₂ = −1`（复核 `9 + (−1) = 8 = I₁` ✓，`9×(−1) = −9 = I₂` ✓）。
  简化方程 `9x² − y² + 81/(−9) = 0`，即 `9x² − y² − 9 = 0`；标准方程 `x²/1 − y²/9 = 1`，实半轴 `a = 1`、虚半轴 `b = 3`。
  作图：`x′` 轴方向为 `λ₁ = 9` 的主方向 `3 : 9 = 1 : 3`，`y′` 轴方向为 `λ₂ = −1` 的主方向 `3 : (−1 − 0) = 3 : (−1)`；由 `F₁ = 3y − 6`、`F₂ = 3x + 8y − 13` 及 `X₂F₁ + Y₂F₂ = 0`、`X₁F₁ + Y₁F₂ = 0` 写出两轴方程。

**题型 3：求切线（含过曲线外一点的切线）**

- **点在曲线上**：算 `F(x₀,y₀)` 确认在曲线上，再算 `F₁, F₂`。不全为零则套 (5.3-3) 或对称式 (5.3-4)；全为零则是奇点，切线不确定。
- **点在曲线外**：路 A —— 设切线 `x = x₀ + Xt, y = y₀ + Yt`，代入相切条件 `Δ = [XF₁ + YF₂]² − Φ(X,Y)F(x₀,y₀) = 0` 解出 `X:Y`，再用 `X:Y = (x − x₀) : (y − y₀)` 作比例代换得直线方程。路 B —— 设切点写对称式切线，令已知点在切线上得一个关系式，与"切点在曲线上"联立。
- **易错点**：把渐近方向当切线方向（**解出的 `X:Y` 必须验明不是渐近方向**）；点在曲线外时误用正则点公式；忘记验证切点在曲线上。

**题型 4：求渐近线**

- **步骤**：由 `F₁ = F₂ = 0` 得中心；由 `Φ(X,Y) = 0` 得渐近方向；用 `(x − x₀)/X = (y − y₀)/Y` 写两条渐近线。快捷等价式：直接解 `Φ(x − x₀, y − y₀) = 0`，它在 `I₂ < 0` 时可因式分解为两个一次式。
- **反向题（已知渐近线求曲线）**：以 `A₁x+B₁y+C₁ = 0`、`A₂x+B₂y+C₂ = 0` 为渐近线的曲线必可写成 `(A₁x+B₁y+C₁)(A₂x+B₂y+C₂) + λ = 0`，代一个已知点定 `λ`，**不要**去解四个交点。
- **易错点**：`I₂ > 0`（椭圆型）时硬求实渐近线（其实只有虚渐近线）；把线心曲线无数条平行弦中点误当渐近线。

**题型 5：直径、共轭方向与共轭直径**

- **思路**：方向 `X:Y` ⇒ 直径 `XF₁ + YF₂ = 0`；斜率 `k` ⇒ `F₁ + kF₂ = 0`。已知直径过点 `M`：中心曲线时连 `M` 与中心的直线即该直径；无心曲线时过 `M` 作平行于渐近方向的直线。共轭方向由 (5.4-5) 或斜率式 (5.4-6) 解出。"被点 `M` 平分的弦" = 过 `M` 的直径的共轭弦：先求直径方向，取共轭方向，再过 `M` 写直线。
- **易错点**：把"直径方向"与"共轭弦方向"张冠李戴（直径方向是 `X′:Y′`，共轭弦方向是 `X:Y`）；对非中心曲线使用"共轭直径"一词（它只对中心曲线定义）。

**题型 6：已知中心、渐近线、对称轴或共轭直径反求曲线方程**

- **步骤**：设一般方程，把每个条件翻译成关于 `a_ij` 的**齐次线性方程** —— 过点 `(p,q)` 得一个方程；中心是 `(x₀,y₀)` 得 `a₁₁x₀ + a₁₂y₀ + a₁₃ = 0`、`a₁₂x₀ + a₂₂y₀ + a₂₃ = 0`；以某直线为渐近线或切线则比较系数得比例式；两方向共轭用 (5.4-5)；以 `l` 为对称轴则需"轴方程与 `XF₁ + YF₂ = 0` 成比例"且"`X:Y` 为主方向（垂直条件 `XX′ + YY′ = 0`）"。最后解出**比例** `a₁₁ : a₁₂ : a₂₂ : a₁₃ : a₂₃ : a₃₃`。
- **易错点**：把六个系数当六个独立未知量（实际只有五个自由度，应求比例）；条件列重或漏列；对称轴的"方向共轭"与"垂直"只用一个。

**题型 7：含参数讨论曲线类型**

- **步骤**：把 `I₁, I₂, I₃`（必要时 `K₁`）全算成 `λ` 的函数；解 `I₂ = 0`、`I₃ = 0` 得分界点；按分界点分区间；每段查表 A。
- **示范**：`x² + axy + 4y² − 7x + y + 3 = 0`，`I₂ = 4 − a²/4`。故 `−4 < a < 4` 椭圆型，`a = ±4` 抛物型，`a < −4` 或 `a > 4` 双曲型。
- **易错点**：只解 `I₂ = 0` 而漏 `I₃ = 0`（退化为直线的分界往往来自 `I₃ = 0`）；不讨论分段直接给结论；在 `I₂ = I₃ = 0` 的分界点上忘记补算 `K₁`。

## Key Takeaways / 关键结论

1. **六个系数决定一切。** 先把 `(a₁₁,a₁₂,a₂₂,a₁₃,a₂₃,a₃₃)` 抄清楚、落成**对称**矩阵 `A`，再算任何东西。下标错位是本章第一大失分点。
2. **三个问题、三个答案。** 是什么类型看 `I₂` 与 `I₃`（表 A）；长什么样看 `λ₁x² + λ₂y² + I₃/I₂ = 0`；摆在哪看由主方向写出的主直径方程。
3. **`I₂ ≠ 0` 走"先移轴到中心、再转轴"；`I₂ = 0` 走"先转轴、后配方平移"。** 顺序搞反会白白多算一堆一次项。
4. **不变量就是特征值的和与积：`I₁ = λ₁ + λ₂`，`I₂ = λ₁λ₂`。** 算完特征根一定用这两条复核，并让 `I₃/I₂` 与直接展开 `I₃` 的结果对上。
5. **消交叉项用 `cot 2α = (a₁₁ − a₂₂)/(2a₁₂)`，不要用 `tan 2α`**（`a₁₁ = a₂₂` 时后者无意义）；两根只差 `π/2`，取哪个都行。
6. **共轭直径只属于中心曲线；抛物线的直径都平行于它唯一的渐近方向；线心曲线只有一条直径。**
7. **`I₃ = 0` 意味着曲线退化成直线**（实的/虚的/平行/相交/重合），必须单独分流，不能当成"很扁的椭圆"或"很扁的双曲线"。
8. **切线公式的本质是"二次型换成双线性型"**：`x² → x₀x`，`2xy → x₀y + xy₀`，`y² → y₀y`，`2x → x + x₀`，`2y → y + y₀`。记住这条替换规则，对称式切线公式就不用背。

## Connects To / 与其他章节的联系

- **第二章（轨迹与方程）、第三章（平面上的直线）**：§5.1 建立在直线的参数方程与"直线与曲线联立解二次方程"之上；§5.4 用到第三章关于直线束（中心直线束、平行直线束）的结论来讨论直径的分布。
- **第四章（二次曲线的标准方程）**：第四章给出椭圆、双曲线、抛物线的标准方程与几何性质；本章把它们作为 `I₂ ≠ 0` 或 `I₂ = 0` 的特例纳入统一框架，并说明"标准方程"为何能通过坐标变换达到。
- **第六章（二次曲面的一般理论）**：教材本章"结束语"指出，本章方法可直接推广到空间 —— `A` 从 3×3 变成 4×4，`I₁` 从二阶迹变成三阶迹，`K₁` 换成 `K₂`，主方向换成主径面。
- **与线性代数（实对称矩阵、二次型、特征值）**：这是本章最深的联系，也是学好本章最快的路径。
  - `A* = [a₁₁ a₁₂; a₁₂ a₂₂]` 是**实对称矩阵**，`Φ(X,Y) = XᵀA*X` 是它对应的**二次型**。
  - 特征方程 `λ² − I₁λ + I₂ = 0` 就是 `det(A* − λE) = 0`：`I₁ = tr(A*)` 是**迹**，`I₂ = det(A*)` 是**行列式**；主方向满足 `A*[X;Y]ᵀ = λ[X;Y]ᵀ`，即 `A*` 的**特征向量**，两个不等特征根对应的主方向互相垂直，正是实对称矩阵特征向量的**正交性**。
  - 转轴消交叉项 + 移轴消一次项合起来就是把二次型化为**标准形（对角形）**：化简后 `x²`、`y²` 的系数恰好是 `λ₁, λ₂`，这就是**正交对角化** `QᵀA*Q = diag(λ₁,λ₂)` 的几何翻译；`I₁, I₂` 不变对应的正是"迹与行列式是（正交）相似不变量"。
  - 二元二次型的正定 / 不定 / 半正定分类，对应本章的 `I₂ > 0`（椭圆型）/ `I₂ < 0`（双曲型）/ `I₂ = 0`（抛物型）；`I₃` 相当于把一次项与常数项一并装进 3×3 矩阵后的扩展行列式。

## 辅导书·复习与测试（选）

> 题源：辅导书 §5.5（PDF p0155–p0157，书 p151–p153）。只给题目与答案要点，完整流程可对照本文件「Reference Tables / 速查表」与「解题套路 / Solution Patterns」自查处。原卷还有填空 10 小题、计算/证明 9 题，其中「用不变量化简 `6xy + 8y² − 12x − 26y + 11 = 0`」（第 9 题）与「已知中心、渐近线反求方程」一类，前文「解题套路」与例 1、例 5 已给出同类示范。

**1. 填空题（书 p151）**：二次曲线 `3x² + 2xy − y² + 8x + 10y − 11 = 0` 的渐近方向是 ＿，渐近线方程是 ＿。
> **答案要点**：`Φ = 3X² + 2XY − Y² = (3X − Y)(X + Y) = 0` 给渐近方向 `1:3` 与 `1:(−1)`（先验 `I₂ = −4 < 0`，才有实渐近线）；中心由 `3x + y + 4 = 0`、`x − y + 5 = 0` 解得 `(−9/4, 11/4)`。用点向式得渐近线 `6x − 2y + 19 = 0` 与 `2x + 2y − 1 = 0`。**易错**：方向 `1:3` 不是 `3:1`；`Φ(x + 9/4, y − 11/4) = (3u − v)(u + v) = 0` 的两条直线是 `3x − y + 19/2 = 0` 与 `x + y − 1/2 = 0`，乘 2 后才是标准整系数式。

**2. 填空题（书 p152）**：设二次曲线为 `x² + 6xy + λy² + 3x + μy − 4 = 0`，那么曲线有唯一中心的条件是 ＿，没有中心的条件是 ＿，有一条中心直线的条件是 ＿。
> **答案要点**：`I₂ = λ − 9`，`I₃ = (144 − 25λ + 18μ − μ²)/4 = −(μ − 9)²/4`（当 `λ = 9` 时）。唯一中心 ⟺ `I₂ ≠ 0` ⟺ `λ ≠ 9`；没有中心 ⟺ `I₂ = 0, I₃ ≠ 0` ⟺ `λ = 9` 且 `μ ≠ 9`；一条中心直线 ⟺ `I₂ = I₃ = 0` ⟺ `λ = μ = 9`（此时方程化为 `(x + 3y + 4)(x + 3y − 1) = 0`，中心直线 `x + 3y + 3/2 = 0`）。**易错**：「没有中心」若只写 `I₂ = 0` 就漏了 `μ = 9` 这个例外——那一点上两平行线重合，中心成了整条直线。

**3. 计算题（书 p152）**：求经过点 `(−2,−1)` 与 `(0,−2)`，且以两直线 `x + y + 1 = 0`、`x − y + 1 = 0` 为对称轴的二次曲线方程。
> **答案要点**：两直线垂直、交于 `(−1,0)`（即中心）。取单位化的新坐标 `u = (x + y + 1)/√2`、`v = (x − y + 1)/√2`（两轴的单位化），由对称轴条件设曲线为 `λ₁u² + λ₂v² + c = 0`。`(−2,−1)` 给 `u = −√2, v = 0`；`(0,−2)` 给 `u = −1/√2, v = 3/√2`。代入得 `2λ₁ + c = 0`、`λ₁/2 + 9λ₂/2 + c = 0`，即 `λ₁ = 3λ₂`；取 `λ₂ = 1, λ₁ = 3, c = −6` 得 `3u² + v² = 6`，回代为
`x² + xy + y² + 2x + y − 2 = 0`（椭圆，`I₂ = 3/4 > 0`、`I₁I₃ = 2×(−9/4) < 0`）。**易错**：到两直线的距离要**单位化**再代（`√2` 不能丢）；只给中心与对称轴定不出大小，必须用那两个点。

**4. 计算题（书 p152）**：试求抛物线 `y² = 2px` 的两条相互垂直的切线的交点的轨迹。
> **答案要点**：斜率 `k` 的切线为 `y = kx + p/(2k)`（`k ≠ 0`）；与之垂直的切线斜率为 `−1/k`，即 `y = −x/k − pk/2`。由第二式得 `x = −ky − pk²/2`，代入第一式解得 `y = p(1 − k²)/(2k)`、`x = −p/2`。`k` 取遍非零实数时 `y = p(1 − k²)/(2k)` 取遍全体实数，故轨迹是整条直线
`x = −p/2`，即抛物线的**准线**（与例 3 的准圆是同一类结论）。**易错**：竖直切线 `x = 0` 的垂直方向是水平的，而水平线 `y = c` 只是「与抛物线交于一点」、并不是切线（它沿渐近方向）——所以不存在「竖直 + 水平」这一对，不必补点；另外 `k = 0` 要单独排除。

**5. 证明题（书 p152）**：利用不变量证明：(1) `2xy − 4x − 2y + 5 = 0` 是双曲线，并求实轴与虚轴的长；(2) `x² + 2xy + y² + 2x + 2y + λ = 0`（`λ < 0`）是两条平行直线，并求它们之间的距离。
> **答案要点**：(1) 系数 `a₁₁ = a₂₂ = 0`、`a₁₂ = 1`、`a₁₃ = −2`、`a₂₃ = −1`、`a₃₃ = 5`；`I₁ = 0`、`I₂ = −1`、`I₃ = −1`。`I₂ < 0, I₃ ≠ 0` ⟹ 双曲线。特征方程 `λ² − I₁λ + I₂ = λ² − 1 = 0`（此处 `I₁ = 0, I₂ = −1`）给 `λ₁ = 1, λ₂ = −1`；简化方程 `x² − y² + (−1)/(−1) = 0`，即 `y² − x² = 1`，故实半轴 = 虚半轴 = 1，**实轴长 = 虚轴长 = 2**。(2) `I₁ = 2`、`I₂ = 1 − 1 = 0`、`I₃ = 0`（前两行相同）、`K₁ = 2λ − 2`；`λ < 0 ⟹ K₁ < 0` ⟹ 两条平行实直线。简化方程 `2y² + (2λ − 2)/2 = 0` 即 `y² = (1 − λ)/2`，故
`d = 2√(−K₁)/|I₁| = 2√(2 − 2λ)/2 = √(2(1 − λ))`。
**易错**：(1) 两个特征根谁是实轴，要看配方后哪个平方项带正号，别硬按 `λ₁` 的足标套；(2) 必须先由 `λ < 0` 说明 `K₁ < 0`（实平行线），否则同样形如 `y² = 正数` 也可能是两条虚平行线；(3) 第 (2) 问也可以直接配方 `(x + y + 1)² + λ − 1 = 0` 核对：两直线 `x + y + 1 = ±√(1 − λ)` 的间距正是 `2√(1 − λ)/√2 = √(2(1 − λ))` ✓。
