# Patterns / 方法与算法

《解析几何》第五版的**具体技术**。格式：**何时用 → 怎么做 → 代价与陷阱**。
定理编号指向教材（如 `定理3.2`）；`辅导` 标记表示该套路来自学习辅导书的例题分析。

---

## 坐标法证几何命题
**何时用**：证明三点共线、三线共点、向量共面、垂直、平行等几何命题。
**How**：① 选一组**方便的基**（通常取直角标架的 `i, j, k`，或题中已知的两个向量）；② 把已知条件与结论全部翻译成向量等式或坐标等式；③ 用向量运算（数量积、向量积、混合积）化简；④ 回到几何结论。
**代价与陷阱**：坐标选得好坏决定计算量——**能取直角坐标就取直角坐标**。共线用 `a×b = 0`、共面用 `(a,b,c) = 0`、垂直用 `a·b = 0`，这三条是最常用的判据。

## 求平面方程
**何时用**：给定平面的一组确定条件。
**How**（按条件选形式）：
- 一点 + 两个方位向量 → `(M₀M, a, b) = 0`（混合积形式）
- 一点 + 法向量 → `A(x−x₀)+B(y−y₀)+C(z−z₀) = 0`
- 三点 → 用混合积或先求法向量 `n = M₀M₁ × M₀M₂`
- 截距已知 → `x/a + y/b + z/c = 1`
- 一般式 `Ax+By+Cz+D = 0` → 法向量直接读出 `(A,B,C)`
**代价与陷阱**：**法向量是平面问题的万能钥匙**——几乎所有平面问题都归结为求法向量。三点式忘验证三点不共线是常见错误。

## 求直线方程
**How**：一点 + 方向向量 → `(x−x₀)/l = (y−y₀)/m = (z−z₀)/n`（点向式）；两点 → 方向向量取差；一般式（两平面交线）→ 方向向量取 `v = n₁ × n₂`。
**代价与陷阱**：**方向向量是直线问题的万能钥匙**。点向式里分母可以为 0（对应 `l=0` 的情形），此时不能写成比例式而要用 `x = x₀` 单独列出——这是最常见的失分点。由一般式求方向向量必须用**两法向量的向量积**，不是随便取。

## 判定空间两直线的位置关系
**How**：取两直线的方向向量 `v₁, v₂` 与连接点向量 `M₁M₂`：① `v₁ × v₂ ≠ 0` 且 `(v₁, v₂, M₁M₂) ≠ 0` → **异面**；② `v₁ × v₂ ≠ 0` 且 `(v₁,v₂,M₁M₂) = 0` → **相交**；③ `v₁ × v₂ = 0` 且 `M₁M₂ × v₁ ≠ 0` → **平行**；④ 全为 0 → **重合**。
**代价与陷阱**：**混合积 `(v₁,v₂,M₁M₂) = 0` 是共面的判据**，异面当且仅当它不为 0。忘记检验最后一列（连接向量）而只比较方向向量，会把异面误判为平行。

## 求异面直线的距离与公垂线
**How**：距离 `d = |(v₁, v₂, M₁M₂)| / |v₁ × v₂|`（即混合积的绝对值除以向量积的模）；公垂线方向为 `v₁ × v₂`，再分别与两直线各定一个平面，两平面交线即公垂线。
**代价与陷阱**：**公式的记忆法是"体积 ÷ 底面积"**——平行六面体体积除以底面积得高。分母是 `|v₁×v₂|` 而不是 `|v₁||v₂|`。两直线平行时该公式失效（分母为 0），需另用点到直线距离。

## 点到平面的距离
**How**：`d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)`（定理3.2）；或用平面的**法式方程**读出常数项。
**代价与陷阱**：**分子必须加绝对值**。用非法式方程时不能直接取常数项。该公式是"化一般式为法式"的直接推论——理解这一点比背公式重要。

## 平面束的应用
**何时用**：待求平面**过一条已知直线**，或需要把"过交线"这一条件参数化。
**How**：设直线由 `π₁: A₁x+B₁y+C₁z+D₁=0` 与 `π₂: A₂x+B₂y+C₂z+D₂=0` 给出，则过该直线的平面束为 `π₁ + λπ₂ = 0`；代入另一个条件定出 `λ`。
**代价与陷阱**：**平面束会漏掉 `π₂` 本身**（`λ = ∞` 的情形）——若答案恰是 `π₂`，需单独讨论。这是本章最容易漏解的地方。

## 由母线方向与准线求柱面方程
**How**：设准线为 `{F(x,y,z)=0; G(x,y,z)=0}`，母线方向为 `(l,m,n)`。准线上任一点 `(x₀,y₀,z₀)` 满足准线方程，且母线为 `(x−x₀)/l = (y−y₀)/m = (z−z₀)/n`；**消去 `x₀,y₀,z₀`** 即得柱面方程。
**代价与陷阱**：**特别地，母线平行于 z 轴时柱面方程不含 z**（定理4.1）——这是最快的判据。消元步骤繁琐，容易在中途丢失参数。

## 由顶点与准线求锥面方程
**How**：设顶点 `A(x₀,y₀,z₀)`、准线上点 `P(x₁,y₁,z₁)`，则母线为直线 `AP`；把 `x₁,y₁,z₁` 用母线参数表出并代入准线方程，消参数即得锥面方程。
**代价与陷阱**：**以原点为顶点的锥面方程是齐次方程**（每一项关于 `x,y,z` 的总次数相同）——这是快速验证答案的方法。

## 由母线与轴求旋转曲面方程
**How**：设母线为 `f(y, z) = 0`（在 `yz` 平面），绕 `z` 轴旋转：把 `y` 换成 `±√(x²+y²)`，得 `f(±√(x²+y²), z) = 0`。
**代价与陷阱**：**关键是判断"绕哪根轴转、母线中哪个变量要被替换"**。绕 `z` 轴转时被替换的是 `y`（另一个垂直于轴的变量），不是 `z`。换错轴是本章最常见的错误。

## 求空间曲线的射影柱面
**How**：设空间曲线为 `{F(x,y,z)=0; G(x,y,z)=0}`，要消去 `z`（投影到 `xy` 平面）→ 从两式中消去 `z` 得到 `H(x,y) = 0`，它就是射影柱面方程。
**代价与陷阱**：**"消去哪个变量"取决于投影到哪个坐标面**。消元后的 `H(x,y)=0` 是柱面而不只是投影曲线——很多同学把两者混淆。

## 二次曲线与直线的位置关系
**How**：把直线的参数方程代入 `F(x,y) = 0`，得关于 `t` 的方程，按判别式分类：`Δ > 0` 两交点、`Δ = 0` 相切、`Δ < 0` 无实交点（或虚交点）。
**代价与陷阱**：**"无实交点"不等于"不相交"**——在复的意义下总有交点。教材按实交点分类。

## 求二次曲线的中心、渐近方向与渐近线
**How**：① **中心**由 `F₁(x,y) = 0` 与 `F₂(x,y) = 0` 联立解出（系数行列式 `I₂ ≠ 0` 时有唯一中心）；② **渐近方向**解 `Φ(X,Y) = a₁₁X² + 2a₁₂XY + a₂₂Y² = 0`；③ **渐近线**是过中心、以渐近方向为方向的直线。
**代价与陷阱**：**`I₂ = 0` 时无唯一中心**（无心型或线心型），不能套公式。渐近方向由二次齐次式给出，与 `a₁₃, a₂₃, a₃₃` 无关。

## 用坐标变换化简二次曲线
**How**：① 若有中心，先**移轴**把原点移到中心（消去一次项）；② 再**转轴**使新坐标轴沿主方向（消去交叉项）；③ 得标准方程。
**代价与陷阱**：**顺序很重要**——先移轴后转轴。转轴角 `θ` 由 `tan2θ = 2a₁₂/(a₁₁−a₂₂)` 定出，`a₁₁ = a₂₂` 时 `θ = π/4`。转轴公式里的正负号方向要与右手系一致。

## 用不变量化简与分类二次曲线
**How**：算 `I₁ = a₁₁+a₂₂`、`I₂ = |a₁₁ a₁₂; a₁₂ a₂₂|`、`I₃ = |A|`。① `I₂ > 0`：椭圆型（`I₁I₃ < 0` 椭圆、`I₃ = 0` 点、`I₁I₃ > 0` 虚椭圆）；② `I₂ < 0`：双曲型（`I₃ ≠ 0` 双曲线、`I₃ = 0` 两相交直线）；③ `I₂ = 0`：抛物型（再用 `K₁` 细分抛物线、平行直线、重合直线等）。
**代价与陷阱**：**这是最实用的分类法，但要避免只算 `I₂` 就下结论**——必须三个量一起看。`I₃ = 0` 的退化情形极易漏判。记不住表格时可用"标准方程反推不变量"来复核。

## 求二次曲线的主方向与主直径
**How**：解特征方程 `λ² − I₁λ + I₂ = 0` 得特征根 `λ₁, λ₂`；每个 `λᵢ` 代入 `(a₁₁−λᵢ)X + a₁₂Y = 0` 得主方向；过中心且以主方向为方向的直线即主直径（有心型）。
**代价与陷阱**：**两个主方向互相垂直**（不同特征根时），可用来自检。`λ₁ = λ₂` 时任何方向都是主方向（圆的情形）。

## 求二次曲面的中心、径面与主径面
**How**：中心由 `F₁=F₂=F₃=0` 解出；径面由共轭方向 `(X,Y,Z)` 决定，方程为 `X F₁ + Y F₂ + Z F₃ = 0`；主径面由特征根确定。
**代价与陷阱**：**径面方程的三个系数就是 `F₁, F₂, F₃` 的组合**；`I₃ ≠ 0` 才有唯一中心。

## 用不变量化简与分类二次曲面
**How**：算 `I₁, I₂, I₃, I₄`（`I₄ = det A*`）。按 `I₃ ≠ 0`（中心型）或 `I₃ = 0`（无中心型）分支，再据 `I₄` 的符号与 `I₁, I₂` 细分，对照 17 种标准方程。
**代价与陷阱**：**这是全书最长的分类表**——不要死记，记住结构：先分"有无中心"，再按特征根的符号分"椭球面型 / 双曲面型 / 抛物面型"。`I₄ = 0` 都是退化情形。

## 求单叶双曲面与双曲抛物面的直母线
**How**：把方程（如 `x²/a² + y²/b² − z²/c² = 1`）改写成 `(x/a + z/c)(x/a − z/c) = (1 − y/b)(1 + y/b)`，引入参数 `u, v` 得两族直线。
**代价与陷阱**：**单叶双曲面与双曲抛物面各有两族直母线**（异族相交、同族异面）。这是"二次曲面由直线族生成"的核心事实——椭球面与椭圆抛物面**没有**直母线，可用来快速排除。
