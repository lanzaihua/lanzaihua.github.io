## 它是什么

这份作业集**不是独立习题书**，而是教材每节「习题」的选编：把书里的习题挑出来、**重新连续编号 1–69**。
后果有两条，用的时候要记住：

1. **作业题号 ≠ 教材习题号**。作业题 4 对应的是 `习题1.3 第4题`，但作业题 5 对应的是 `习题1.3 第7题`——编号是错开的，只能按内容配。
2. **教材书末有官方答案**：上册「部分习题答案与提示」在书页 **289–310**（PDF 页 = 书页 + 12，即 301–322）。只有「部分」习题给了答案，没给的就是没有。

## 怎么用

**定位一道题**：
- 「作业第 34 题」→ 查上表落到 P14–P18 → 打开 `p05-ch05.md` 搜 `题 34`。
- 「6-3 作业」→ [../sections.md](../sections.md) 底部「作业编号 ↔ 教材节次」→ 6-3 是题 53–55。
- 「§6.3 的作业」→ 同上，§6.3 泰勒公式对应 6-3（题 53–55）。

**做题时**：先只看「题目 + 考点 + 第一步提示」，卡住了再看「解」。整段倒解答等于替自己写作业。

**错题回填**：错了一题，按 SKILL.md 的「错题本工作流」记进工作目录的 `错题本.md`（编号 `M-xxx`），
并把「教材对应 习题X.Y 第M题」一并抄进去——以后要查官方答案有据可依。

## 可信度

- **题面**：作业集 PDF 有清晰文字层，但分式、根式、指数、上下标被压平成多行；每道题都对照过 170 dpi 的页面图像判读，
  典型歧义（如 `arcsin(lg(x/10))` 被压成 `arcsin(lg x / 10)`）是靠教材官方答案反查确认的。
- **计算题**：导数、高阶导数、不定积分、极限、泰勒展开、极值/拐点/渐近线，全部用 sympy 复核（求导回去、`series` 比对、高精度数值代入）。
- **与教材答案比对**：能配上 `习题X.Y 第M题` 的题，都逐条对照过教材书末「部分习题答案与提示」，不一致的已改正。
  - 第 8 章：题 63–69 共 72 个小题，与教材答案 **72/72 一致**。
  - 第 1–3 章：25 题全部配到教材原题（24 题精确到第几题，题 16 是作业集改题），答案除 1 处题面误读外全部一致（该处已改正）。
  - 第 4–6 章：37 题里 23 题能在答案册查到并全部一致；其余 14 题书末没给答案（如整节 `习题6.1` 都没收），标为「题号待定」。
- 仍然**不要盲信**：交作业前用 `教材对应 习题X.Y 第M题` 回书上核一眼，尤其是 OCR 多解的地方。
