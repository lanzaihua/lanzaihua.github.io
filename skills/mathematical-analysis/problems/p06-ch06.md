## 作业 6-1（P19）· §6.1 拉格朗日定理和函数的单调性

### 题 47 ｜ 罗尔定理证根的唯一性
**题目** 证明：方程 x³ − 3x + c = 0（c 为常数）在区间 [0, 1] 内不可能有两个不同的实根。

**考点** `ch06 定理6.1 罗尔中值定理 / 定理6.4 严格单调`｜模板 `T-07`

**教材对应** 习题6.1（题号待定；教材书末未收录习题6.1 的答案）

**解** 反证：设 0 ≤ x₁ < x₂ ≤ 1 都是根，f(x) = x³ − 3x + c 在 [x₁, x₂] 上连续、(x₁, x₂) 内可导且 f(x₁) = f(x₂)，由定理6.1 存在 ξ ∈ (x₁, x₂) ⊂ (0, 1) 使 f′(ξ) = 3ξ² − 3 = 0，即 ξ = ±1，与 ξ ∈ (0, 1) 矛盾。
（等价的直接证法：f′(x) = 3(x² − 1) < 0 于 (0, 1)，f 在 [0, 1] 上严格递减，故至多一个根。）

**答案** 至多一个实根（证明题）。

**易错** 罗尔定理给出的 ξ 必须落在区间内部；这里 f′(x) = 0 的根恰在区间外。

### 题 48 ｜ 拉格朗日定理证利普希茨估计
**题目** 若 f 在 [a, b] 上可导且 |f′(x)| ≤ M，证明 |f(b) − f(a)| ≤ M(b − a)。

**考点** `ch06 定理6.2 拉格朗日中值定理`｜模板 `T-07`

**教材对应** 习题6.1（题号待定；教材书末未收录习题6.1 的答案）

**解** 由可导 ⇒ 连续（定理5.1），f 在 [a, b] 上连续、(a, b) 内可导，故存在 ξ ∈ (a, b) 使 f(b) − f(a) = f′(ξ)(b − a)。取绝对值：|f(b) − f(a)| = |f′(ξ)|(b − a) ≤ M(b − a)。∎

**答案** 成立（证明题）。

**易错** 闭区间连续是定理6.2 的条件，由可导性补出即可，但漏写不严谨。

### 题 49 ｜ 对数不等式
**题目** 应用拉格朗日中值定理证明 (b − a)/b < ln(b/a) < (b − a)/a，其中 0 < a < b。

**考点** `ch06 定理6.2`｜模板 `T-07`

**教材对应** 习题6.1（题号待定；教材书末未收录习题6.1 的答案）

**解** 对 f(x) = ln x 在 [a, b] 上用定理6.2：存在 ξ ∈ (a, b) 使 ln b − ln a = (b − a)/ξ。由 0 < a < ξ < b 得 1/b < 1/ξ < 1/a，乘以 b − a > 0 得 (b − a)/b < ln(b/a) < (b − a)/a。∎

**答案** 不等式成立。

**易错** 1/ξ 的上下界必须由 ξ 的范围夹出；注意 b − a > 0 才保号。

### 题 50 ｜ 单调区间
**题目** 确定函数 f(x) = √(2x − x²) 的单调区间。

**考点** `ch06 定理6.3、定理6.4 单调性判定`

**教材对应** 习题6.1（题号待定；教材书末未收录习题6.1 的答案）

**解** 定义域为 [0, 2]。在 (0, 2) 内 f′(x) = (1 − x)/√(2x − x²)，故 f′ > 0 ⇔ x < 1。由定理6.3/6.4，f 在 [0, 1] 上严格递增、在 [1, 2] 上严格递减。

**答案** 增区间 [0, 1]，减区间 [1, 2]。

**易错** 端点处 f′ 不存在，但由连续性可并入单调区间。

## 作业 6-2（P20）· §6.2 柯西中值定理和不定式极限

### 题 51 ｜ 柯西中值定理
**题目** 设 f 在 [520, 1314] 上可导。证明存在 ξ ∈ (520, 1314)，使 2ξ[f(1314) − f(520)] = (1314² − 520²)f′(ξ)。

**考点** `ch06 定理6.6 柯西中值定理`｜模板 `T-07`

**教材对应** 习题6.2（题号待定；书末只给第5、7题答案，本题不在其中）

**解** 取 g(x) = x²。f、g 在 [520, 1314] 上连续、(520, 1314) 内可导，g′(x) = 2x ≠ 0，g(1314) ≠ g(520)。由定理6.6 存在 ξ ∈ (520, 1314) 使
[f(1314) − f(520)]/(1314² − 520²) = f′(ξ)/(2ξ)，
两边乘 2ξ(1314² − 520²) 即得所证。∎

**答案** 结论成立（ξ 由定理6.6 给出）。

**易错** 需验证 g′ ≠ 0 与 g(a) ≠ g(b)；分别对 f、x² 用拉格朗日会得到两个不同的中间点。

### 题 52 ｜ 洛必达法则求极限（8 小题）
**题目** 计算下列极限（小题见下表）。

**考点** `ch06 定理6.7（0/0 型）、定理6.8（∞/∞ 型）`｜模板 `T-05`

**教材对应** 习题6.2（题号待定；书末只给第5、7题答案，这 8 题不在其中）

| 小题 | 极限 | 类型 | 结果 |
|---|---|---|---|
| 1 | lim_{x→0}(eˣ − e⁻ˣ)/sin 2x | 0/0 | 1 |
| 2 | lim_{x→0}(tan x − x)/(x − sin x) | 0/0 | 2 |
| 3 | lim_{x→0}(arcsin x − x)/sin³x | 0/0 | 1/6 |
| 4 | lim_{x→0}(eˣ + e⁻ˣ − 2)/(1 − cos x) | 0/0 | 2 |
| 5 | lim_{x→0}[1/x − 1/ln(1 + x)] | ∞ − ∞ → 0/0 | −1/2 |
| 6 | lim_{x→+∞}x²(e^{1/x} − 1) | 0·∞ | +∞（无有限极限） |
| 7 | lim_{x→1}(1 − x)tan(πx/2) | 0·∞ | 2/π |
| 8 | lim_{x→0}(sin x/x)^{1/sin²x} | 1^∞ | e^{−1/6} |

**代表题详解**
(2) 两次洛必达：原式 = lim(sec²x − 1)/(1 − cos x) = lim tan²x/(1 − cos x) = lim (1 − cos²x)/[cos²x(1 − cos x)] = lim(1 + cos x)/cos²x = 2。
(5) 通分化为 0/0：[ln(1 + x) − x]/[x ln(1 + x)]；用 ln(1 + x) = x − x²/2 + o(x²)，分子 = −x²/2 + o(x²)，分母 = x² + o(x²)，极限 = −1/2。
(7) 令 u = 1 − x → 0，则 tan(πx/2) = tan(π/2 − πu/2) = cot(πu/2)，故原式 = lim_{u→0} u·cot(πu/2) = lim (πu/2)/sin(πu/2)·cos(πu/2)·(2/π) = 2/π。
(8) 取对数：ln y = ln(sin x/x)/sin²x，而 ln(sin x/x) = ln(1 − x²/6 + o(x²)) ~ −x²/6，又 1/sin²x ~ 1/x²，故 ln y → −1/6，y → e^{−1/6}。

**答案** 1；2；1/6；2；−1/2；+∞（发散）；2/π；e^{−1/6}。

**易错** 用洛必达前必须先确认 0/0 或 ∞/∞；(6) 的结果是 +∞ 而非有限值；(8) 是 1^∞ 型，先取对数。

## 作业 6-3（P21）· §6.3 泰勒公式

### 题 53 ｜ 带佩亚诺型余项的麦克劳林公式
**题目** 求下列函数带佩亚诺型余项的麦克劳林公式：(1) f(x) = 1/√(1 + x)；(2) f(x) = arctan x 到含 x⁵ 的项；(3) f(x) = tan x 到含 x⁵ 的项。

**考点** `ch06 定理6.9（佩亚诺型余项）`｜模板 `T-08`

**教材对应** 习题6.3 第1题(1)(2)(3)（见 p298）

**解** (1) 由 (1 + x)^α 的公式（α = −1/2）：f(x) = Σ_{k=0}^{n} (−1)^k (2k − 1)‼/(2^k k!)·x^k + o(xⁿ)，即
f(x) = 1 − x/2 + 3x²/8 − 5x³/16 + 35x⁴/128 + o(x⁴)。
(2) arctan x = x − x³/3 + x⁵/5 + o(x⁵)。
(3) tan x = x + x³/3 + 2x⁵/15 + o(x⁵)。

**答案** 见「解」。

**易错** (1) 的系数符号交替且为 (2k − 1)‼/(2^k k!)；(3) 的 x⁵ 系数是 2/15，别写成 1/5。

### 题 54 ｜ 泰勒公式求极限
**题目** 求极限 lim_{x→+∞}[x − x²ln(1 + 1/x)]。

**考点** `ch06 定理6.9`｜模板 `T-08`

**教材对应** 习题6.3 第2题（小题号待定；该题三小问答 1/3、1/2、1/3，含本题的 1/2）

**解** 令 t = 1/x → 0⁺，原式 = [t − ln(1 + t)]/t²。由 ln(1 + t) = t − t²/2 + o(t²) 得分子 = t²/2 + o(t²)，故极限 = 1/2。

**答案** 1/2。

**易错** 对 x 直接洛必达会越算越繁，换元 t = 1/x 是标准动作。

### 题 55 ｜ 带拉格朗日余项的泰勒公式
**题目** 求 f(x) = 1/(1 + x) 在 x = 0 处带拉格朗日余项的泰勒公式。

**考点** `ch06 定理6.10（拉格朗日型余项）`

**教材对应** 习题6.3 第3题(2)（见 p298）

**解** f^{(k)}(x) = (−1)^k k!/(1 + x)^{k+1}，故 f^{(k)}(0) = (−1)^k k!，于是
f(x) = 1 − x + x² − … + (−1)ⁿxⁿ + (−1)^{n+1}x^{n+1}/(1 + θx)^{n+2}，0 < θ < 1（教材即写作 θx，等价于 ξ 介于 0 与 x 之间）。

**答案** 见上（余项为拉格朗日型，可用于定量误差估计）。

**易错** 余项分母是 (1 + θx)^{n+2}，对应 f^{(n+1)} 的阶数，写成 n+1 就错了。

## 作业 6-4（P22）· §6.4 函数的极值与最大(小)值

### 题 56 ｜ 求极值
**题目** 求函数 f(x) = 2x³ − x⁴ 的极值。

**考点** `ch06 定理6.11–6.13 极值判别`｜模板 `T-07`（求稳定点后看变号）

**教材对应** 习题6.4 第1题(1)（极大值 f(3/2) = 27/16，见 p298）

**解** f′(x) = 6x² − 4x³ = 2x²(3 − 2x)，稳定点为 x = 0、3/2。f″(x) = 12x(1 − x)，f″(3/2) = −9 < 0，故 x = 3/2 为极大值点，极大值 f(3/2) = 27/4 − 81/16 = 27/16。在 x = 0 两侧 f′ > 0（f′ = 2x²(3 − 2x) 不变号），故 x = 0 不是极值点。

**答案** 极大值 f(3/2) = 27/16；无极小值。

**易错** f′(0) = 0 不等于极值点，必须看 f′ 是否变号（此处不变号）。

### 题 57 ｜ 闭区间上的最值
**题目** 求函数 y = x⁵ − 5x⁴ + 5x³ + 1 在 [−1, 2] 上的最大值、最小值。

**考点** `ch06 §4 闭区间最值：稳定点 + 不可导点 + 端点`

**教材对应** 习题6.4 第4题(1)（见 p298）

**解** y′ = 5x²(x² − 4x + 3) = 5x²(x − 1)(x − 3)，[−1, 2] 内稳定点为 x = 0、1。计算：y(−1) = −10，y(0) = 1，y(1) = 2，y(2) = −7。

**答案** 最大值 2（x = 1），最小值 −10（x = −1）。

**易错** 只比较稳定点会漏掉端点；本题最小值在端点取到。

## 作业 6-5（P23）· §6.5 函数的凸性与拐点

### 题 58 ｜ 凸性区间与拐点
**题目** 确定下列函数的凸性区间与拐点：(1) y = 2x³ − 3x² − 36x + 25；(2) y = x + 1/x；(3) y = ln(x² + 1)。

**考点** `ch06 定理6.15 二阶导判据、定理6.17 拐点充分条件`

**教材对应** 习题6.5 第1题(1)(2)(4)（见 p299）

**解** (1) y″ = 12x − 6：x > 1/2 时 y″ > 0（凸），x < 1/2 时 y″ < 0（凹）；拐点 (1/2, 13/2)。
(2) y″ = 2/x³：x > 0 时凸，x < 0 时凹；x = 0 不在定义域，无拐点。
(3) y″ = 2(1 − x²)/(1 + x²)²：|x| < 1 时凸，|x| > 1 时凹；拐点 (±1, ln 2)。

**答案** 见「解」（拐点须写全坐标）。

**易错** 拐点必须同时给出 x 与 y 坐标；(2) 中 x = 0 是间断点而非拐点。

### 题 59 ｜ 由拐点定参数
**题目** 问 a 和 b 为何值时，点 (1, 3) 为曲线 y = ax³ + bx² 的拐点？

**考点** `ch06 定理6.16（必要）、定理6.17（充分）`

**教材对应** 习题6.5 第2题（a = −3/2，b = 9/2，见 p299）

**解** 点 (1, 3) 在曲线上：a + b = 3。拐点必要条件 y″(1) = 6a + 2b = 0，故 b = −3a，代回得 a = −3/2、b = 9/2。此时 y″ = 9(1 − x) 在 x = 1 两侧异号，由定理6.17 确为拐点。

**答案** a = −3/2，b = 9/2。

**易错** y″(1) = 0 只是必要条件，必须回验两侧变号。

### 题 60 ｜ 凸函数的运算封闭性
**题目** 证明：(1) 若 f 为凸函数、λ 为非负实数，则 λf 为凸函数；(2) 若 f、g 均为凸函数，则 f + g 为凸函数；(3) 若 f 为区间 I 上凸函数，g 为 J ⊃ f(I) 上凸增函数，则 g∘f 为 I 上凸函数。

**考点** `ch06 定义1（凸函数：f((x₁+x₂)/2) ≤ [f(x₁)+f(x₂)]/2）`

**教材对应** 习题6.5（题号待定；教材书末未给该题答案）

**解** 记 x₁, x₂ ∈ I，x̄ = (x₁ + x₂)/2。
(1) (λf)(x̄) = λf(x̄) ≤ λ[f(x₁) + f(x₂)]/2 = [(λf)(x₁) + (λf)(x₂)]/2。
(2) (f + g)(x̄) ≤ [f(x₁) + f(x₂)]/2 + [g(x₁) + g(x₂)]/2 = [(f + g)(x₁) + (f + g)(x₂)]/2。
(3) 令 u = f(x̄)，ū = [f(x₁) + f(x₂)]/2，则 u ≤ ū 且 u, ū ∈ J。g 在 J 上凸且增，故 g(u) ≤ g(ū) ≤ [g(f(x₁)) + g(f(x₂))]/2，即 (g∘f)(x̄) ≤ [(g∘f)(x₁) + (g∘f)(x₂)]/2。∎

**答案** 三条均成立。

**易错** (3) 中「g 为增函数」不可省，否则 g(u) ≤ g(ū) 不成立。

### 题 61 ｜ 用凸性证明不等式
**题目** 证明：(1) 对任意实数 a, b，有 e^{(a+b)/2} ≤ (eᵃ + eᵇ)/2；(2) 对任何非负实数 a, b，有 2arctan((a + b)/2) ≥ arctan a + arctan b。

**考点** `ch06 定理6.15 凸性判据 + 凸/凹函数定义`

**教材对应** 习题6.5（题号待定；教材书末未给该题答案）

**解** (1) (eˣ)″ = eˣ > 0，故 eˣ 在 ℝ 上为凸函数；取 x₁ = a、x₂ = b 代入凸函数定义即得。
(2) (arctan x)″ = −2x/(1 + x²)² ≤ 0（x > 0 时 < 0），故 arctan x 在 [0, +∞) 上为凹函数，于是 arctan((a + b)/2) ≥ [arctan a + arctan b]/2，两边乘 2 即得。

**答案** 两不等式成立。

**易错** 凹函数给的是「中点值 ≥ 两端平均」，方向别写反；端点 a = b 时取等号。

### 题 62 ｜ 按步骤作函数图像
**题目** 按函数作图步骤，作函数 y = x²/[2(1 + x)²] 的图像。

**考点** `ch06 §6 函数图象的讨论`（定义域→特殊点→单调极值→凹凸拐点→渐近线）

**教材对应** 习题6.6（题号待定；书末 p299–301 的作图题答案中没有本题）

**解** ① 定义域 x ≠ −1；y ≥ 0 且仅当 x = 0 时 y = 0；非奇非偶。
② y′ = x/(1 + x)³：在 (−∞, −1) 与 (0, +∞) 上 y′ > 0（增），在 (−1, 0) 上 y′ < 0（减）；x = 0 为极小值点，y(0) = 0。
③ y″ = (1 − 2x)/(1 + x)⁴：x < 1/2 时凸，x > 1/2 时凹；拐点 (1/2, 1/18)。
④ 渐近线：lim_{x→±∞} y = 1/2，水平渐近线 y = 1/2；lim_{x→−1} y = +∞，竖直渐近线 x = −1。
⑤ 图像：左支在 (−∞, −1) 上从 y = 1/2（自上方趋近）单调升到 +∞；右支在 (−1, 0) 上从 +∞ 单调降到极小值 0（x = 0），再在 (0, +∞) 上单调升并以 y = 1/2 为水平渐近线（自下方趋近）。凸性：在 (−∞, −1) 与 (−1, 1/2) 上凸，在 (1/2, +∞) 上凹，x = 1/2 为拐点横坐标。

**答案** 见「解」四步结论 + 图像描述。

**易错** 左支自 y = 1/2 上方趋近、右支自下方趋近；x = 0 是极小值点而不是拐点（y″(0) = 1 > 0）。
