**(12)** 由内向外合并根式：√x = x^(1/2)，x√x = x^(3/2)，√(x√x) = x^(3/4)，故 x·√(x√x) = x^(7/4)，再开方得 x^(7/8)。于是

∫x^(7/8)dx = x^(15/8)/(15/8) + C = (8/15)x^(15/8) + C。

∫(x² + x^(−2))/x³ dx = ∫(1/x + x^(−5))dx = ln\|x\| − 1/(4x⁴) + C。

### 题 64 ｜ 含绝对值被积函数的不定积分
**题目** 求不定积分 ∫e^(−|x|)dx。

**考点** `ch08 定理8.1–8.2 / 分段求原函数必须连续拼接` ｜方法 `去绝对值分段积分 + 连续性定常数`

**教材对应** 习题8.1 第6题(1)（教材书末 p302）

**解** 去掉绝对值分段积分：

x ≥ 0 时，∫e^(−x)dx = −e^(−x) + C₁；x < 0 时，∫eˣdx = eˣ + C₂。

被积函数 e^(−|x|) 在 ℝ 上连续，由定理8.1 其原函数存在且在 ℝ 上可导，从而必在 x = 0 处连续：

lim(x→0⁺) (−e^(−x) + C₁) = −1 + C₁，lim(x→0⁻) (eˣ + C₂) = 1 + C₂。

令二者相等得 C₂ = C₁ − 2。又左导数 e⁰ = 1、右导数 e⁰ = 1，两侧导数相等，故拼成的函数确实处处可导且导数为 e^(−|x|)。

**答案** F(x) = sgn(x)·(1 − e^(−|x|)) + C（即 x ≥ 0 时 1 − e^(−x) + C，x < 0 时 eˣ − 1 + C）。教材书末取等价写法 G(x) + C，其中 G(x) = 2 − e^(−x)（x ≥ 0）、G(x) = eˣ（x < 0），与上式只差常数 1。

**易错** 两段各自带独立的任意常数——原函数必须连续，两个常数被 x = 0 处的连续性锁死为一个自由常数。

### 题 65 ｜ 由 f′ 的复合式反求 f
**题目** 设 f′(arctan x) = x²，求 f(x)。

**考点** `ch08 定理8.2 / 不定积分是求导的逆运算` ｜方法 `先换元把 f′ 的自变量统一成 t，再积分`

**教材对应** 习题8.1 第7题（教材书末 p303，答案 tan x − x + C，与本解一致）

**解** 令 t = arctan x，则 x = tan t（t ∈ (−π/2, π/2)），代回已知式得

f′(t) = tan²t。

于是 f(t) = ∫tan²t dt = ∫(sec²t − 1)dt = tan t − t + C。把 t 换回 x，得 f(x) = tan x − x + C：

**答案** f(x) = tan x − x + C（x ∈ (−π/2, π/2)）。

**易错** 直接对 x² 积分得到 x³/3——f′ 的自变量是 arctan x 而非 x，必须先换元；另外末步要写回 f(x) 而不是停在 f(t)。

**考点** `ch08 定理8.4 / 第一换元（凑微分），定理8.5 / 第二换元` ｜方法 `凑微分优先；有根式时令根式为 t 或作三角代换`

**教材对应** 习题8.2 第1题(1)–(36)（教材书末 p303–p304）

**代表题详解**

**(5)** 拆成两个标准型。由基本公式 ∫du/√(a² − u²) = arcsin(u/a)（取 a = √3）得 ∫dx/√(3 − x²) = arcsin(x/√3) + C；第二个令 u = √3x，则 dx = du/√3，

∫dx/√(1 − 3x²) = (1/√3)∫du/√(1 − u²) = (1/√3)arcsin(√3x) + C。

**(13)** 观察 (csc x − cot x)′ = −csc x·cot x + csc²x = csc x(csc x − cot x)，即被积函数恰为"导数/原函数"之比：

∫csc x dx = ∫(csc x − cot x)′/(csc x − cot x)dx = ln\|csc x − cot x\| + C。

又 (1 − cos x)/sin x = tan(x/2)，故另一种常用形式为 ln\|tan(x/2)\| + C。

**(29)** 两个根式次数为 2、3，取最小公倍数 6：令 x = t⁶，则 √x = t³、∛x = t²、dx = 6t⁵dt，

∫√x/(1 − ∛x)dx = 6∫t⁸/(1 − t²)dt。

由 t⁸ = (t² − 1)(t⁶ + t⁴ + t² + 1) + 1 得 t⁸/(1 − t²) = −(t⁶ + t⁴ + t² + 1) + 1/(1 − t²)，而 ∫dt/(1 − t²) = (1/2)ln\|(1 + t)/(1 − t)\|。故原式

= −(6/7)t⁷ − (6/5)t⁵ − 2t³ − 6t + 3ln\|(1 + t)/(1 − t)\| + C，回代 t = x^(1/6)。

**(36)** 令 x = sec t（取 t 使 tan t 与 √(x² − 1) 同号），dx = sec t·tan t dt，√(x² − 1) = tan t：

∫dx/(x⁴√(x² − 1)) = ∫(sec t·tan t)/(sec⁴t·tan t)dt = ∫cos³t dt = sin t − (sin³t)/3 + C。

回代 sin t = √(x² − 1)/x：

sin t − (sin³t)/3 = (√(x² − 1)/x)·(1 − (x² − 1)/(3x²)) = (2x² + 1)√(x² − 1)/(3x³) + C。

**与教材答案对照** 36 条逐条核对**全部一致**。等价写法差异：(6) 教材作 2^(2x+2)/ln2（本表 2^(2x+3)/ln4，二者相等）；(13) 教材作 −ln|csc x + cot x|（与 ln|tan(x/2)| 相等）；(14) 教材即 −√(1 − x²)；(32) 教材作 (1/n)ln|xⁿ/(1 + xⁿ)|；(35) 教材首项写作 ln x（本表 ln(4x)，差常数 2ln2）；(36) 教材作 √(x² − 1)/x − (x² − 1)^(3/2)/(3x³)。

**答案** 见上表 36 条（每项均带 + C）

**易错** 第二换元最后必须把 t 回代为 x（否则答案不合格）；(28)(36) 这类含 √(1 − x²)、√(x² − 1) 的题，回代时靠直角三角形把三角量写成 x 的表达式，别残留 sin t、tan t；(32) 拆项方向要凑成"分子是分母导数"。
