## 作业 4-1（P11）· §4.1 连续性概念

### 题 26 ｜ 间断点定位与分类
**题目** 指出下列函数的间断点并说明类型：(1) f(x) = x + 1/x；(2) f(x) = (sin x)/|x|；(3) f(x) = [|cos x|]（[·] 为取整）；(4) f(x) = sgn|x|；(5) f(x) = sgn(cos x)；(6) f(x) = x（x ∈ ℚ），f(x) = −x（x ∉ ℚ）；(7) f(x) = 1/(x+7)（x < −7），f(x) = x（−7 ≤ x ≤ 1），f(x) = (x−1)sin(1/(x−1))（x > 1）。

**考点** `ch04 §1 连续性概念`（左右极限 + 间断点分类）｜模板 `T-03`

**教材对应** 习题4.1 第2题（答案见教材书末 p293）

**解** 判据：左右极限都存在 ⇒ 第一类（相等且等于函数值则可去，不等则跳跃）；否则第二类。
(1) x→0± 时 1/x→±∞ ⇒ 第二类（无穷）。(2) 左右极限 1 与 −1 ⇒ 跳跃。(3) |cos x| < 1 时 f = 0，f(kπ) = 1 ⇒ x = kπ 可去，余处连续。(4) x ≠ 0 时 sgn|x| = 1，f(0) = 0 ⇒ 可去。(5) x = π/2 + kπ 处左右极限 1、−1 ⇒ 跳跃。(6) |f(x)| = |x| ⇒ x = 0 连续；x₀ ≠ 0 时有理列给 x₀、无理列给 −x₀，由归结原则（定理3.9）极限不存在 ⇒ 除 0 外处处第二类（振荡）。(7) x = −7 左极限 −∞ ⇒ 第二类（无穷）；x = 1 左极限 1、右极限 0（无穷小 × 有界量）⇒ 跳跃。

**答案** (1) x=0 无穷；(2) x=0 跳跃；(3) x=kπ 可去；(4) x=0 可去；(5) x=π/2+kπ 跳跃；(6) 除 x=0 外处处第二类；(7) x=−7 无穷、x=1 跳跃。

**易错** 「无定义」≠「第二类」，分类只看左右极限是否存在。

### 题 27 ｜ |f|、f² 的连续性及其逆命题
**题目** 证明 f 在 x₀ 连续 ⇒ |f|、f² 在 x₀ 连续。又问：|f| 或 f² 在 I 上连续时 f 是否必连续？

**考点** `ch04 定理4.5 复合函数连续性`｜方法：复合 + 局部有界

**教材对应** 习题4.1（题号待定；教材书末未给该题答案）

**解** u↦|u|、u↦u² 连续，由定理4.5 与 lim f(x) = f(x₀) 得 lim|f(x)| = |f(x₀)|、lim f²(x) = f²(x₀)。
逆命题不真：f(x) = 1（x ∈ ℚ）、−1（x ∉ ℚ），则 |f| ≡ f² ≡ 1 连续；而 f 在每点极限不存在（归结原则），处处间断。

**答案** 正向成立；反向不真，反例即「有理点 1、无理点 −1」。

**易错** 由 f² 连续开方得 f 连续要附加 f 不变号。

## 作业 4-2（P12）· §4.2 连续函数的性质

### 题 28 ｜ 无穷远有极限的连续函数有界
**题目** 设 f 在 [a, +∞) 上连续，lim_{x→+∞} f(x) 存在，证明 f 在 [a, +∞) 上有界。

**考点** `ch04 有界性定理（引理）`｜方法：闭区间截断 + 尾部估计

**教材对应** 习题4.2（题号待定；教材书末未给该题答案）

**解** 设极限为 L。取 ε = 1 得 X > a，x > X 时 |f(x) − L| < 1 ⇒ |f(x)| < |L| + 1。f 在 [a, X] 上连续，由有界性定理有 |f| ≤ M₁。取 M = max{M₁, |L|+1}。∎

**答案** 有界（证明题）。

**易错** 尾部只覆盖 x > X，x = X 须并入闭区间。

### 题 29 ｜ 直接用连续性求极限
**题目** 求 (1) lim_{x→π/4}(π − x)tan x；(2) lim_{x→1⁺}[x√(1+2x) − √(x²−1)]/(x + 1)。

**考点** `ch04 定理4.12–4.13 初等函数在定义区间上连续`｜模板 `T-05`

**教材对应** 习题4.2 第8题（答案见 p293）

**解** (1) 二者在 π/4 连续、tan(π/4) = 1，故极限 = (π − π/4)·1 = 3π/4。
(2) 分子 → 1·√3 − 0 = √3，分母 → 2，极限 = √3/2。

**答案** (1) 3π/4；(2) √3/2。

**易错** 两题都不是未定式，代入即可。

### 题 30 ｜ x² 的一致连续性
**题目** 证明 f(x) = x² 在 [a, b] 上一致连续，在 (−∞, +∞) 上不一致连续。

**考点** `ch04 定理4.9 康托定理 / 利普希茨条件`｜模板 `T-06`

**教材对应** 习题4.2（题号待定；教材书末未给该题答案）

**解** ① |x² − y²| = |x + y||x − y| ≤ (|a| + |b|)|x − y|，取 δ = ε/(|a| + |b| + 1) 即可。
② 取 xₙ = n、yₙ = n + 1/n：|xₙ − yₙ| = 1/n → 0，而 |xₙ² − yₙ²| = 2 + 1/n² → 2，取 ε₀ = 1 即违反一致连续定义。∎

**答案** 结论成立（证明题）。

**易错** 反例须使两点距离 → 0 而函数值差**不** → 0。

## 作业 4-3（P13）· §4.2 连续函数的性质（续）

### 题 31 ｜ 开区间连续 + 两端有限单侧极限
**题目** 设 f 在 (a, b) 上连续，f(a+0)、f(b−0) 为有限值。证明：(1) f 在 (a, b) 上有界；(2) 若存在 ξ ∈ (a, b) 使 f(ξ) ≥ max{f(a+0), f(b−0)}，则 f 在 (a, b) 上取到最大值；(3) f 在 (a, b) 上一致连续。

**考点** `ch04 有界性定理、定理4.6、定理4.9`｜模板 `T-06`（连续延拓）

**教材对应** 习题4.2（题号待定；教材书末未给该题答案）

**解** 作延拓 F(a) = f(a+0)、F(b) = f(b−0)、F(x) = f(x)（a < x < b），则 F 在 [a, b] 上连续。
(1) F 有界 ⇒ f 有界。
(2) 设 M = max_{[a,b]} F = F(x₀)，由条件 M ≥ F(ξ) = f(ξ) ≥ max{F(a), F(b)}。若 x₀ ∈ (a, b)，则对 x ∈ (a, b) 有 f(x) = F(x) ≤ M = f(x₀)；若 x₀ 为端点，则 M = F(x₀) ≤ max{F(a), F(b)} ≤ f(ξ) ≤ M，故 F(ξ) = M，ξ 即最大值点。
(3) F 在 [a, b] 上一致连续（定理4.9），限制到 (a, b) 仍一致连续。∎

**答案** 证明题：(1) 有界；(2) 取到最大值；(3) 一致连续。

**易错** 不能对开区间直接用闭区间定理，须先补成闭区间。
