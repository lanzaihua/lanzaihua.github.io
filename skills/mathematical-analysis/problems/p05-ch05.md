## 作业 5-1（P14）· §5.1 导数的概念

### 题 32 ｜ 用导数定义求差商极限
**题目** 设 f(x₀) = 0，f′(x₀) = 4，求 lim_{Δx→0} f(x₀+Δx)/Δx。

**考点** `ch05 定义1（导数的增量形式）`｜方法：凑导数定义

**教材对应** 习题5.1 第3题（答案 4，见 p293）

**解** 由 f(x₀) = 0 得 f(x₀+Δx)/Δx = [f(x₀+Δx) − f(x₀)]/Δx，当 Δx→0 时趋于 f′(x₀) = 4。

**答案** 4。

**易错** 必须用 f(x₀) = 0 补出「减去 f(x₀)」，否则不是差商。

### 题 33 ｜ 分段点可导定参数
**题目** f(x) = x²（x ≥ 3），f(x) = ax + b（x < 3），确定 a、b 使 f 在 x = 3 处可导。

**考点** `ch05 定理5.1（可导 ⇒ 连续）、定理5.2（左右导数）`

**教材对应** 习题5.1 第4题（a = 6，b = −9，见 p293）

**解** 可导必连续：f(3−0) = 3a + b = 9 = f(3)。再令左右导数相等：f′₋(3) = a，f′₊(3) = 2x|_{x=3} = 6，故 a = 6，代回得 b = −9。

**答案** a = 6，b = −9。

**易错** 只让函数连续不够，还必须让左右导数相等。

### 题 34 ｜ 切线方程与法线方程
**题目** 求曲线在指定点 P 的切线、法线方程：(1) y = x²/4，P(2, 1)；(2) y = cos x，P(0, 1)。

**考点** `ch05 §1 导数的几何意义`｜方法：y − y₀ = f′(x₀)(x − x₀)

**教材对应** 习题5.1 第6题（见 p293）

**解** (1) y′ = x/2，k = 1：切线 y − 1 = x − 2 即 y = x − 1；法线斜率 −1，y = −x + 3。
(2) y′ = −sin x，k = 0：切线 y = 1；法线为竖直线 x = 0。

**答案** (1) 切线 y = x − 1，法线 y = −x + 3；(2) 切线 y = 1，法线 x = 0。

**易错** k = 0 时法线斜率是「负倒数无意义」，法线写成竖直直线 x = x₀。

### 题 35 ｜ x^m·sin(1/x) 的连续性与可导性
**题目** f(x) = x^m sin(1/x)（x ≠ 0），f(0) = 0，m 为正整数。问：(1) m 为何值时 f 在 0 连续；(2) m 为何值时 f 在 0 可导。

**考点** `ch05 定义1 + 定理5.1`｜方法：无穷小 × 有界量

**教材对应** 习题5.1 第8题（m ≥ 1；m ≥ 2，见 p294）

**解** (1) |x^m sin(1/x)| ≤ |x|^m → 0（m ≥ 1），故 m ≥ 1 时 f 在 0 连续（m 为正整数时即全部情形）。
(2) f′(0) = lim_{x→0} [f(x) − f(0)]/x = lim_{x→0} x^{m−1}sin(1/x)：m = 1 时为 lim sin(1/x)，不存在；m ≥ 2 时极限为 0。

**答案** (1) m ≥ 1（一切正整数）；(2) m ≥ 2。

**易错** m = 1 时 f 连续但不可导——差商振荡不收敛，不能用「无穷小 × 有界」蒙混。

## 作业 5-3（P17）· §5.3 参变量函数的导数

### 题 38 ｜ 幂指函数与对数求导法
**题目** 求下列函数的导数：(1) y = x^{sin x}；(2) y = x^{x^x}；(3) y = (x − a₁)^{a₁}(x − a₂)^{a₂}…(x − aₙ)^{aₙ}。

**考点** `ch05 §2 例11 对数求导法 + 定理5.8`｜方法：两边取对数再求导

**教材对应** 习题5.2 第3题(19)(20)(25)（答案见 p295）

**解** (1) ln y = sin x·ln x，y′/y = cos x·ln x + sin x/x，故 y′ = x^{sin x}(cos x·ln x + sin x/x)。
(2) 记 u = x^x = e^{x ln x}，则 y = e^{u ln x}，y′ = y[(u′ln x + u/x)]，其中 u′ = x^x(ln x + 1)，故 y′ = x^{x^x}·x^x[(ln x + 1)ln x + 1/x]。
(3) ln y = Σaᵢln(x − aᵢ)，y′/y = Σaᵢ/(x − aᵢ)，故 y′ = y·Σ_{i=1}^{n} aᵢ/(x − aᵢ)。

**答案** 见「解」三式。

**易错** 幂指函数必须取对数（或写成 e^{g ln f}），不能套幂函数公式。

### 题 39 ｜ 参变量函数的导数
**题目** 求由参数方程确定的 dy/dx：(1) x = cos⁴t，y = sin⁴t，在 t = π/3 处；(2) x = t/(1 + t)，y = (1 − t)/(1 + t)，在 t > 0 处。

**考点** `ch05 §3 参变量函数的导数`｜方法：dy/dx = (dy/dt)/(dx/dt)

**教材对应** 习题5.3 第1题（−3；−2，见 p295）

**解** (1) dy/dt = 4sin³t·cos t，dx/dt = −4cos³t·sin t，故 dy/dx = −tan²t；t = π/3 时为 −3。
(2) dy/dt = −2/(1 + t)²，dx/dt = 1/(1 + t)²，故 dy/dx = −2。

**答案** (1) −tan²t，在 t = π/3 处为 −3；(2) −2。

**易错** 求完后要代回参数 t 的值，不能留在分子分母里。

### 题 40 ｜ 参变量曲线的切线与法线
**题目** 曲线 x = 1 − t²，y = t − t²，求下列点处的切线与法线：(1) t = 1；(2) t = √2/2。

**考点** `ch05 §3 + §1 几何意义`

**教材对应** 习题5.3 第3题（见 p295–296）

**解** dy/dx = (1 − 2t)/(−2t) = (2t − 1)/(2t)。
(1) t = 1：点 (0, 0)，k = 1/2。切线 y = x/2；法线斜率 −2，y = −2x。
(2) t = √2/2：点 (1/2, (√2 − 1)/2)，k = 1 − √2/2 = (2 − √2)/2。法线斜率 −2/(2 − √2) = −(2 + √2)。切线 2y − (2 − √2)x = (3√2)/2 − 2；法线 2x + (2 − √2)y = (3√2)/2 − 1（教材所给形式）。

**答案** 见「解」两式。

**易错** 先算点坐标再算斜率，点坐标由参数 t 代入 x(t)、y(t) 得到，不是 (t, t²)。

## 作业 5-4（P18）· §5.4 高阶导数 与 §5.5 微分

### 题 41 ｜ 二阶、三阶导数
**题目** (1) f(x) = x ln x，求 f″(x)；(2) f(x) = e^{−x²}，求 f‴(x)。

**考点** `ch05 §4 高阶导数`｜模板 `T-05`

**教材对应** 习题5.4 第3题(1)(2)（见 p296）

**解** (1) f′ = ln x + 1，f″ = 1/x。
(2) f′ = −2xe^{−x²}，f″ = (4x² − 2)e^{−x²}，f‴ = [8x + (4x² − 2)(−2x)]e^{−x²} = 4x(3 − 2x²)e^{−x²}。

**答案** (1) 1/x；(2) 4x(3 − 2x²)e^{−x²}。

**易错** (2) 反复用积法则时别把 e^{−x²} 的系数 −2x 漏掉。

### 题 42 ｜ 抽象函数的二阶导数
**题目** 设 f 二阶可导，求 (1) y = f(ln x)；(2) y = f(f(x)) 的二阶导数。

**考点** `ch05 定理5.8 链式法则（反复使用）`

**教材对应** 习题5.4 第4题(1)(3)（见 p296）

**解** (1) y′ = f′(ln x)/x，y″ = [f″(ln x)/x·x − f′(ln x)]/x² = [f″(ln x) − f′(ln x)]/x²。
(2) y′ = f′(f(x))f′(x)，y″ = f″(f(x))[f′(x)]² + f′(f(x))f″(x)。

**答案** 见「解」两式。

**易错** (2) 是「积的导数 + 复合的导数」两层叠加，漏掉第二项 f′(f(x))f″(x) 最常见。

### 题 43 ｜ 有理函数的 n 阶导数
**题目** 求 y = 1/[x(1 − x)] 的 n 阶导数。

**考点** `ch05 §4 高阶导数 + 拆项`｜方法：部分分式 + 归纳

**教材对应** 习题5.4 第5题(3)（见 p296）

**解** y = 1/x + 1/(1 − x)。由 (1/x)^{(n)} = (−1)ⁿn!/x^{n+1}、[1/(1 − x)]^{(n)} = n!/(1 − x)^{n+1}，得
y^{(n)} = (−1)ⁿn!/x^{n+1} + n!/(1 − x)^{n+1}。

**答案** y^{(n)} = n![(−1)ⁿ/x^{n+1} + 1/(1 − x)^{n+1}]。

**易错** 直接对乘积用莱布尼茨公式会很繁；先拆成两项最省力。

### 题 44 ｜ 参变量函数的二阶导数
**题目** 求由 x = a cos³t，y = a sin³t 确定的函数的 d²y/dx²。

**考点** `ch05 §3 + §4`｜方法：d²y/dx² = (d/dt)(dy/dx)÷(dx/dt)

**教材对应** 习题5.4 第6题(1)（见 p296）

**解** dy/dx = (3a sin²t cos t)/(−3a cos²t sin t) = −tan t；d²y/dx² = (−sec²t)/(−3a cos²t sin t) = 1/(3a cos⁴t sin t)。

**答案** 1/(3a·cos⁴t·sin t)。

**易错** 不能把 dy/dx 直接再对 t 求导，必须再除以 dx/dt。

### 题 45 ｜ 求微分
**题目** 求下列函数的微分：(1) y = e^{ax}sin bx；(2) y = arcsin√(1 − x²)。

**考点** `ch05 定义（微分）+ 定理5.9 dy = f′(x)dx`

**教材对应** 习题5.5 第2题(5)(6)（见 p297）

**解** (1) y′ = e^{ax}(a sin bx + b cos bx)，故 dy = e^{ax}(a sin bx + b cos bx)dx。
(2) y′ = [1/√(1 − (1 − x²))]·(−x/√(1 − x²)) = −x/(|x|√(1 − x²))，故 dy = −sgn(x)/√(1 − x²)·dx。

**答案** (1) dy = e^{ax}(a sin bx + b cos bx)dx；(2) dy = −x dx/(|x|√(1 − x²))。

**易错** (2) 中 √(x²) = |x| 而非 x；由 y = π/2 − arcsin|x| 也能得到同一结果。

### 题 46 ｜ 用微分作近似计算
**题目** 利用微分求 ∛1.02 的近似值。

**考点** `ch05 §5 微分作近似：f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx`

**教材对应** 习题5.5 第4题(1)（教材答作 1.007，见 p297）

**解** 取 f(x) = x^{1/3}，x₀ = 1，Δx = 0.02。f(1) = 1，f′(1) = (1/3)x^{−2/3}|_{x=1} = 1/3，
故 ∛1.02 ≈ 1 + (1/3)(0.02) = 1.006 667 ≈ 1.006 7。

**答案** ∛1.02 ≈ 1.006 7（教材答作 1.007）。

**易错** 公式是 f(x₀) + f′(x₀)Δx；漏掉 f′(x₀) 或把 Δx 当成 x₀ + Δx 都会算错。
