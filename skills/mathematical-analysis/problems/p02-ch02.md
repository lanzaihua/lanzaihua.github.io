## 作业 2-1（P4）· §2.1 数列极限概念

### 题 9 ｜ ε-N 定义里 N 的求法
**题目** 设 aₙ = (1 + (−1)ⁿ)/n, n = 1, 2, …, a = 0。
(1) 对下列 ε 分别求出极限定义中相应的 N：ε₁ = 0.1, ε₂ = 0.01, ε₃ = 0.001；
(2) 对 ε₁, ε₂, ε₃ 可找到相应的 N，这是否证明了 aₙ 趋于 0？应该怎样做才对；
(3) 对给定的 ε 是否只能找到一个 N？

**考点** `ch02 §2.1 定义1（ε-N）` ｜方法：反解不等式 + 量词辨析

**教材对应** 习题2.1 第1题（教材原题即 aₙ = (1+(−1)ⁿ)/n, a = 0 的三小问，与本题逐字相同）

**解** 注意 aₙ = 2/n（n 偶），aₙ = 0（n 奇），故 |aₙ − 0| ≤ 2/n，最坏情形是 n 为偶数。
(1) 需 2/n < ε ⇔ n > 2/ε：
ε₁ = 0.1 → 2/ε = 20，取 **N = 20**；ε₂ = 0.01 → **N = 200**；ε₃ = 0.001 → **N = 2000**。
(2) **不能**。定义要求「对任给 ε > 0 都存在 N」，三个 ε 只是有限个特例，覆盖不了全体 ε > 0（反例思维：ε 取得更小，原来的 N 就失效）。正确做法：任给 ε > 0，由 2/n < ε 解得 n > 2/ε，取 N = [2/ε]，再对 n > N 写出 |aₙ − 0| ≤ 2/n < ε。
(3) **不是**。定义只要求 N 存在，不要求唯一；任何大于 2/ε 的数都可作 N，N 依赖 ε（记 N(ε)）但不被 ε 唯一确定。

**答案** (1) N = 20, 200, 2000；(2) 不能，须对任意 ε 一般地解出 N；(3) 不唯一。

**易错** 把「对几个 ε 验证过」当成证明（这正是本章 Anti-patterns 第一条）；另外 N 允许任意放大。

### 题 10 ｜ 按 ε-N 定义证明五个极限
**题目** 按 ε−N 定义证明：
(1) lim_{n→∞} n/(n+1) = 1；(2) lim_{n→∞} (3n²+n)/(2n²−1) = 3/2；(3) lim_{n→∞} n!/nⁿ = 0；(4) lim_{n→∞} sin(π/n) = 0；(5) lim_{n→∞} n/aⁿ = 0 (a > 1)。

**考点** `ch02 §2.1 定义1（ε-N）` ｜模板 `T-01`

**教材对应** 习题2.1 第2题（教材「按 ε-N 定义证明」下辖五小问，与本题逐条相同；答案页未收该题）

**解** 统一套路：先化简 |aₙ − a|，再**适当放大**成 g(n)，解 g(n) < ε 得 N。
(1) |n/(n+1) − 1| = 1/(n+1) < 1/n < ε ⟺ n > 1/ε，取 N = [1/ε]。
(2) |(3n²+n)/(2n²−1) − 3/2| = (2n+3)/(2(2n²−1))；n ≥ 2 时 2n²−1 > n²、2n+3 < 5n，故该式 < 5/(2n) < ε ⟺ n > 5/(2ε)，取 N = max{2, 5/(2ε)}。
(3) n!/nⁿ = (1/n)(2/n)⋯(n/n) ≤ (1/n)·1⋯1 = 1/n < ε ⟺ n > 1/ε，取 N = [1/ε]。
(4) |sin(π/n)| ≤ π/n < ε ⟺ n > π/ε，取 N = [π/ε]。
(5) 记 a = 1 + h (h > 0)，由二项式展开 aⁿ ≥ 1 + nh + n(n−1)h²/2 > n(n−1)h²/2，故
0 < n/aⁿ < 2/((n−1)h²) < ε ⟺ n > 1 + 2/(h²ε)，取 N = max{1, 1 + 2/(h²ε)}。

**答案** 五式均按定义成立；N 依次取 [1/ε]、max{2, 5/(2ε)}、[1/ε]、[π/ε]、max{1, 1+2/(h²ε)}。

**易错** 放大必须仍趋于 0；(5) 若用 aⁿ > 1 + nh 只能得到 n/aⁿ < 1/h，证不出 0，必须取到 h² 的二项式项。

## 作业 2-2（P5）· §2.2 收敛数列的性质

### 题 11 ｜ 六个数列极限
**题目** 求下列极限：
(1) lim (n³+3n²+1)/(4n³+2n+3)；(2) lim (1+2n)/n²；(3) lim ((−2)ⁿ+3ⁿ)/((−2)ⁿ⁺¹+3ⁿ⁺¹)；
(4) lim (√(n²+n) − n)；(5) lim (ⁿ√1 + ⁿ√2 + ⋯ + ⁿ√10)；(6) lim [(1/2 + 1/2² + ⋯ + 1/2ⁿ)/(1/3 + 1/3² + ⋯ + 1/3ⁿ)]。

**考点** `ch02 §2.2 定理2.7（四则运算）、定理2.6（迫敛性）、等比求和` ｜模板 `T-05`

**教材对应** 习题2.2 第1题（教材六小问与本题逐条相同，(2) 的分子教材印作 1 + 2n；教材答案 (1) 1/4、(2) 0、(3) 1/3、(4) 1/2、(5) 10、(6) 2 与本题**全部吻合**）

**解**
| 小题 | 关键一步 | 结果 |
|---|---|---|
| (1) | 分子分母同除 n³ → (1+3/n+1/n³)/(4+2/n²+3/n³) | 1/4 |
| (2) | 分子分母同除 n²：1/n² + 2/n → 0 | 0 |
| (3) | 同除 3ⁿ：((−2/3)ⁿ+1)/(3(−2/3)ⁿ⁺¹+3) → 1/(0+3) | 1/3 |
| (4) | 有理化：n/(√(n²+n)+n) = 1/(√(1+1/n)+1) | 1/2 |
| (5) | ⁿ√k → 1（k = 1,…,10 固定，§2.1 例5），有限项相加 | 10 |
| (6) | 分子 = 1 − 2⁻ⁿ → 1；分母 = (1/2)(1 − 3⁻ⁿ) → 1/2 | 2 |

**答案** (1) 1/4；(2) 0；(3) 1/3；(4) 1/2；(5) 10；(6) 2。

**易错** (2) 的分子是 1 + 2n（一次式）**不是** 1 + 2ⁿ：误把 2n 看成 2ⁿ 会把答案从 0 变成 +∞，这是本题最隐蔽的抄题坑（务必按印刷体确认 n 不在指数位置）；(3) 同除的基数要选绝对值大的 3ⁿ，除 (−2)ⁿ 会因符号振荡失手。

### 题 12 ｜ 四个需先求和/夹逼的极限
**题目** 求下列极限：
(1) lim [1/(1·2) + 1/(2·3) + ⋯ + 1/(n(n+1))]；(2) lim ⁿ√(1 − 1/n)；
(3) lim [1/n² + 1/(n+1)² + ⋯ + 1/(2n)²]；(4) lim [1/√(n²+1) + 1/√(n²+2) + ⋯ + 1/√(n²+n)]。

**考点** `ch02 §2.2 定理2.6（迫敛性）、定理2.7` ｜模板 `T-05`

**教材对应** 习题2.2 第3题（教材六小问答 1、2、3、1、0、1；本题集选编其中 (1)(4)(5)(6) 四问，值 1、1、0、1 与教材逐项一致，(3) 的表达式也与教材 3(5) 完全相同）

**解**
(1) 裂项 1/(k(k+1)) = 1/k − 1/(k+1)，和 = 1 − 1/(n+1) → 1。
(2) n ≥ 2 时 1/n ≤ 1 − 1/n < 1，故 (1/n)^{1/n} ≤ (1−1/n)^{1/n} < 1；而 (1/n)^{1/n} = 1/ⁿ√n → 1（ⁿ√n → 1），由迫敛性得极限 1。
(3) 共 n+1 项，每项 ≤ 1/n²，故 0 ≤ Sₙ ≤ (n+1)/n² → 0，由迫敛性 Sₙ → 0。
(4) 共 n 项，且 1/√(n²+n) ≤ 1/√(n²+k) ≤ 1/√(n²+1)，故
n/√(n²+n) ≤ Sₙ ≤ n/√(n²+1)，两端都 → 1，由迫敛性 Sₙ → 1。

**答案** (1) 1；(2) 1；(3) 0；(4) 1。

**易错** (4) 的项数恰好是 n，夹逼时别写成 n+1 项；(2) 用「ⁿ√a → 1」要求底数 a > 0 固定，而 1−1/n 随 n 变，必须先夹逼。

### 题 13 ｜ 收敛 ± 发散必发散；乘积与商未必
**题目** 设 {aₙ} 与 {bₙ} 中一个是收敛数列，另一个是发散数列。证明 {aₙ ± bₙ} 是发散数列。又问 {aₙbₙ} 和 {aₙ/bₙ} (bₙ ≠ 0) 是否必为发散数列？

**考点** `ch02 §2.2 定理2.7（四则运算）` ｜方法：反证 + 反例

**教材对应** 习题2.2 第4题（教材原题与本题逐字相同；该题未收在书末答案中。注：教材第二章总练习题第14题问的是「两数列都无界时乘积是否必无界」，另一题）

**解** 不妨设 {aₙ} 收敛于 A，{bₙ} 发散。
**反证**：若 {aₙ + bₙ} 收敛，则由定理2.7，bₙ = (aₙ + bₙ) − aₙ 是两收敛数列之差，必收敛，与 bₙ 发散矛盾。故 {aₙ + bₙ} 发散；对 aₙ − bₙ 完全同理（把和换差）。
**乘积与商都不必发散**：取 aₙ = 1/n（收敛于 0），bₙ = n（发散）。则 aₙbₙ = 1 收敛，aₙ/bₙ = 1/n² 收敛于 0。故 {aₙbₙ}、{aₙ/bₙ} 都可能收敛。

**答案** {aₙ ± bₙ} 一定发散；{aₙbₙ} 与 {aₙ/bₙ} 不一定发散。

**易错** 反证的核心是把发散的那个数列写成一个**收敛组合**：bₙ = (aₙ+bₙ) − aₙ，从而「若和收敛则 bₙ 收敛」；举反例时注意 bₙ ≠ 0 的前提，取 bₙ = n 天然满足。

## 作业 2-3（P6）· §2.3 数列极限存在的条件

### 题 14 ｜ 用 e 的定义求五个 1^∞ 型极限
**题目** 利用 lim_{n→∞} (1 + 1/n)ⁿ = e 求下列极限：
(1) lim (1 − 1/n)ⁿ；(2) lim (1 + 1/n)ⁿ⁺¹；(3) lim (1 + 1/(n+1))ⁿ；(4) lim (1 + 1/(2n))ⁿ；(5) lim (1 + 1/n²)ⁿ。

**考点** `ch02 §2.3 例4（e 的定义）、定理2.7` ｜方法：凑 (1 + 1/m)^m

**教材对应** 习题2.3 第1题（教材原题的五小问与本题逐条相同，答案 (1) 1/e、(2) e、(3) e、(4) √e、(5) 1 完全一致）

**解**
(1) (1−1/n)ⁿ = 1/(1 + 1/(n−1))ⁿ，而 (1 + 1/(n−1))ⁿ = (1 + 1/(n−1))ⁿ⁻¹·(1 + 1/(n−1)) → e·1 = e，故原式 → 1/e。
(2) (1+1/n)ⁿ⁺¹ = (1+1/n)ⁿ·(1+1/n) → e·1 = e。
(3) (1 + 1/(n+1))ⁿ = (1 + 1/(n+1))ⁿ⁺¹/(1 + 1/(n+1)) → e/1 = e。
(4) (1 + 1/(2n))ⁿ = [(1 + 1/(2n))²ⁿ]^{1/2}，方括号内 → e，故原式 → √e。
(5) 1 ≤ (1 + 1/n²)ⁿ = [(1 + 1/n²)^{n²}]^{1/n} ≤ 3^{1/n}（因 (1+1/n²)^{n²} 递增且 < e < 3），而 ⁿ√3 → 1，由迫敛性原式 → 1。

**答案** (1) 1/e；(2) e；(3) e；(4) √e；(5) 1。

**易错** (1) 必须先化到 (1 + 1/(n−1))^{n−1} 再取极限，直接写 (1−1/n)ⁿ → 1 是错的；(5) 不能只夹到 1 ≤ · ≤ e。

### 题 15 ｜ 用柯西收敛准则证收敛
**题目** 应用柯西收敛准则，证明 aₙ = sin1/2 + sin2/2² + ⋯ + sinn/2ⁿ 收敛。

**考点** `ch02 §2.3 定理2.11（柯西收敛准则）` ｜方法：几何级数优级数

**教材对应** 习题2.3 第5题(1)（教材原题：应用柯西收敛准则证明 aₙ = sin1/2 + sin2/2² + ⋯ + sinn/2ⁿ 收敛；同题 (2) 为 aₙ = 1 + 1/2² + ⋯ + 1/n²）

**解** 设 n > m，则
|aₙ − aₘ| = |Σ_{k=m+1}^{n} sin k/2^k| ≤ Σ_{k=m+1}^{n} 1/2^k < Σ_{k=m+1}^{∞} 1/2^k = 1/2^m。
任给 ε > 0，取正整数 N 使 1/2^N < ε（即 N > log₂(1/ε)）。则当 n > m > N 时
|aₙ − aₘ| < 1/2^m < 1/2^N < ε。
故 {aₙ} 是柯西数列，由定理2.11 收敛。∎

**答案** 收敛。（附：其和可算出为 2sin1/(5 − 4cos1) ≈ 0.5928，超出本章范围。）

**易错** 柯西准则只需估计 |aₙ − aₘ|，**不要**先去猜极限 a；放大的目标是要能任意小，用等比级数的尾项最省事。

### 题 16 ｜ 递推数列的单调有界法
**题目** 设 0 < c < 1, a₁ = c/2, aₙ₊₁ = c/2 + aₙ²/2。证明：{aₙ} 收敛，并求其极限。

**考点** `ch02 §2.3 定理2.9（单调有界定理）` ｜模板 `T-04`

**教材对应** 习题2.3（待定）。注：教材 习题2.3 第3题 是 (1) a₁=√2, aₙ₊₁=√(2aₙ)（答 2）、(2) a₁=√c, aₙ₊₁=√(c+aₙ)（答 (1/2)(1+√(1+4c))）、(3) aₙ=cⁿ/n!（答 0），其特征方程是 L² = c + L；本题递推的特征方程是 L² − 2L + c = 0、极限 1−√(1−c)，教材 习题2.3 与第二章总练习题 1–14 中均查不到本题递推，判为作业集改题

**解** 记 L = 1 − √(1−c)。由 0 < c < 1 得 0 < L < 1，且直接验证 **L = c/2 + L²/2**（即 L² − 2L + c = 0 的较小根）。
**第一步：归纳证明 0 < aₙ < L 且 {aₙ} 严格递增。**
n = 1：a₁ = c/2 < L ⟺ √(1−c) < 1 − c/2 ⟺ 1 − c < 1 − c + c²/4，成立（c > 0），故 0 < a₁ < L。
设 0 < aₙ < L，则 aₙ₊₁ = c/2 + aₙ²/2 < c/2 + L²/2 = L，且
aₙ₊₁ − aₙ = (aₙ² − 2aₙ + c)/2 = (aₙ − L)(aₙ − (1 + √(1−c)))/2 > 0，
因为两个因子都小于 0。故 0 < aₙ₊₁ < L 且 aₙ₊₁ > aₙ。
**第二步：取极限。** {aₙ} 递增且有上界 L，由单调有界定理收敛。设 lim aₙ = a，在递推式两边取极限得 a = c/2 + a²/2，即 a² − 2a + c = 0，a = 1 ± √(1−c)。又 aₙ < L 对一切 n 成立，取极限并由保不等式性得 a ≤ L，故 a = 1 − √(1−c)。

**答案** lim_{n→∞} aₙ = 1 − √(1−c)。

**易错** 必须先证「有界 + 单调」再取极限；直接对递推式取极限会得到两个根，必须用 aₙ < L 舍去 1 + √(1−c)。
