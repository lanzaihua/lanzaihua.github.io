## 作业 1-1/1-2（P1）· §1.1 实数、§1.2 数集·确界原理

### 题 1 ｜ 由 |a−b| < ε (∀ε>0) 推出 a = b
**题目** 设 a, b ∈ ℝ。证明：若对任何正数 ε 都有 |a − b| < ε，则 a = b。

**考点** `ch01 §1.1 绝对值与三角形不等式` ｜方法：反证 + ε 的任意性

**教材对应** 习题1.1 第3题（教材原题：设 a, b∈ℝ，证明若对任何正数 ε 有 |a−b| < ε，则 a = b——与本题逐字相同；该题未收在书末答案中）

**解** 反证。若 a ≠ b，则 d = |a − b| > 0。题设对**任何**正数成立，故对 ε = d/2 > 0 也有
d = |a − b| < d/2，
两边乘 2 得 d < 0，与 d > 0 矛盾。故 a = b。∎
（等价写法：0 ≤ |a − b| < ε 对一切 ε > 0 成立，令 ε → 0⁺ 得 |a − b| = 0。）

**答案** a = b。

**易错** 证明里必须取 ε = d/2 这种「比 d 小」的量；取 ε = d 只能得到 d < d，是错的。

### 题 2 ｜ 求上、下确界并依定义验证
**题目** 求下列数集的上、下确界，并依定义加以验证：
(1) S = {x | x² < 2}；
(2) S = {x | x = 1 − 1/2ⁿ, n ∈ ℕ₊}。

**考点** `ch01 §1.2 定义2（sup）、定义3（inf）` ｜方法：验证「是界」+「最性」两条

**教材对应** 习题1.2 第4题（教材 4 小问：S = {x | x²<2}、{x | x=n!, n∈ℕ₊}、(0,1) 上的无理数、{x | x = 1−1/2ⁿ}，sup / inf 依次答 √2 与 −√2、+∞ 与 1、1 与 0、1 与 1/2；本题集选编 (1)(4) 两问，答案一致）

**解**
(1) S = (−√2, √2)。
**sup S = √2**：(i) 对 x ∈ S 有 x² < 2，故 |x| < √2，从而 x < √2；(ii) 任取 α < √2：若 α < 0 取 x₀ = 0 ∈ S；若 0 ≤ α < √2 取 x₀ = (α + √2)/2，则 α < x₀ < √2 ⇒ x₀² < 2 ⇒ x₀ ∈ S 且 x₀ > α。两条成立，故 sup S = √2。
**inf S = −√2**：注意 −x ∈ S ⇔ x ∈ S（S 关于原点对称），同法（或对 −S 用 (1) 的结论）即得。
(2) 记 aₙ = 1 − 1/2ⁿ，则 aₙ 严格递增，a₁ = 1/2。
**sup S = 1**：(i) 1 − 1/2ⁿ < 1 对一切 n 成立；(ii) 任取 α < 1，由 1 − α > 0 及 1/2ⁿ → 0，存在 n 使 1/2ⁿ < 1 − α，即 aₙ > α。故 sup S = 1，且 1 ∉ S。
**inf S = 1/2**：(i) 由递增性 aₙ ≥ a₁ = 1/2；(ii) 对任何 β > 1/2 取 x₀ = a₁ = 1/2 ∈ S，有 x₀ < β。故 inf S = 1/2，且 inf S = min S。

**答案** (1) sup S = √2，inf S = −√2（二者都不属于 S）；(2) sup S = 1（∉ S），inf S = 1/2 = min S。

**易错** 只证「是上界」不证「最小」是最常见的漏步；另外 √2 本身不满足 x² < 2，别写成 sup S = max S。

### 题 3 ｜ inf S ∈ S 与 min S 等价
**题目** 设 S 为非空有下界数集。证明：inf S = ξ ∈ S ⇔ ξ = min S。

**考点** `ch01 §1.2 定义3（inf）+ 最小值的定义`

**教材对应** 习题1.2 第5题（教材原题与本题逐字相同：设 S 为非空有下界数集，证明 inf S = ξ ∈ S ⇔ ξ = min S）

**解**
(⇒) 设 ξ = inf S 且 ξ ∈ S。ξ 是 S 的下界，故对一切 x ∈ S 有 x ≥ ξ；又 ξ ∈ S，故 ξ 是 S 中最小者，ξ = min S。
(⇐) 设 ξ = min S。则 (i) 对一切 x ∈ S 有 x ≥ ξ，ξ 是下界；(ii) 对任何 β > ξ，取 x₀ = ξ ∈ S 就有 x₀ < β，即 β 不是下界。故 ξ = inf S，且 ξ ∈ S。∎

**答案** 结论成立（对偶形式：sup S = η ∈ S ⇔ η = max S）。

**易错** 两个方向都要用「ξ ∈ S」这一条件；只证下界性推不出最性。

## 作业 1-3（P2）· §1.3 函数概念（存在域与复合）

### 题 4 ｜ 初等函数的存在域
**题目** 确定下列初等函数的存在域：
(1) y = sin(sin x)；(2) y = lg(lg x)；(3) y = arcsin(lg(x/10))；(4) y = lg(arcsin(x/10))。
（本书 lg 表示以 10 为底的对数。注意 (3) 中 lg 作用于 x/10，(4) 中 arcsin 作用于 x/10。）

**考点** `ch01 §1.3 函数＝定义域＋对应法则、复合函数的存在域`

**教材对应** 习题1.3 第4题（教材答案：(1) (−∞, +∞)；(2) (1, +∞)；(3) [1, 100]；(4) (0, 10]，与下表一致；教材原文 (3) 印作 arcsin(lg(x/10))、(4) 印作 lg(arcsin(x/10))）

**解**
| 小题 | 约束条件 | 存在域 D |
|---|---|---|
| (1) | 内层 sin x ∈ [−1, 1] ⊂ ℝ，外层恒有定义 | ℝ |
| (2) | lg x > 0 | (1, +∞) |
| (3) | −1 ≤ lg(x/10) ≤ 1 ⇒ 10⁻¹ ≤ x/10 ≤ 10 | [1, 100] |
| (4) | arcsin(x/10) > 0 ⇒ 0 < x/10 ≤ 1 | (0, 10] |

**答案** (1) ℝ；(2) (1, +∞)；(3) [1, 100]；(4) (0, 10]。

**易错** 括号位置决定答案：(3) 是 lg 作用在 x/10 上而非 (lg x)/10，误读会把 [1, 100] 错算成 [10⁻¹⁰, 10¹⁰]；(4) 是 arcsin 作用在 x/10 上而非 (arcsin x)/10，误读会把 (0, 10] 错算成 (0, 1]。

### 题 5 ｜ 复合函数的分解
**题目** 试问下列函数是由哪些初等函数复合而成：
(1) y = (1 + x)²⁰；(2) y = (arcsin x²)²；(3) y = lg(1 + √(1 + x²))；(4) y = 2^(sin²x)。

**考点** `ch01 §1.3 复合函数（由外向内逐层拆）`

**教材对应** 习题1.3 第7题（教材原题与本题逐字相同，答案给出同样的四层复合链，符号记作 u、v、w，与下表一致）

**解**
| 小题 | 外层 → 内层 |
|---|---|
| (1) | y = u²⁰, u = 1 + x |
| (2) | y = u², u = arcsin v, v = x² |
| (3) | y = lg u, u = 1 + v, v = √w, w = 1 + x² |
| (4) | y = 2^u, u = v², v = sin x |

**答案** 见上表（各层都是基本初等函数）。

**易错** 拆解时每层都必须是六类基本初等函数或其简单四则运算；(3) 中 √(1+x²) 要拆成 v = √w、w = 1+x² 两层，别把 √(1+x²) 当成一个基本初等函数。

## 作业 1-4（P3）· §1.4 具有某些特性的函数

### 题 6 ｜ 证明 f(x) = x/(x²+1) 在 ℝ 上有界
**题目** 证明 f(x) = x/(x²+1) 是 ℝ 上的有界函数。

**考点** `ch01 §1.4 有界函数（∃M>0, ∀x∈D: |f(x)| ≤ M）`

**教材对应** 习题1.4 第1题（教材原题：证明 f(x) = x/(x²+1) 是 ℝ 上的有界函数——与本题逐字相同。注：教材 习题1.1 第4题是「设 x≠0，证明 x + 1/x ≥ 2」的另一题，勿混）

**解** 由 (|x| − 1)² ≥ 0 得 x² + 1 ≥ 2|x|，故当 x ≠ 0 时
|f(x)| = |x|/(x²+1) ≤ |x|/(2|x|) = 1/2；
又 f(0) = 0。故对一切 x ∈ ℝ 有 |f(x)| ≤ 1/2，即 f 在 ℝ 上有界。
事实上该界可取到：f(1) = 1/2，f(−1) = −1/2，故 sup f = 1/2，inf f = −1/2。

**答案** f 在 ℝ 上有界，|f(x)| ≤ 1/2（且 1/2 是最好上界）。

**易错** 不能只说「x → ±∞ 时 f → 0」就断言有界——那只是远端的趋势，必须给出对所有 x 一致的不等式。

### 题 7 ｜ 无界函数的定义与例子
**题目** (1) 叙述无界函数的定义；
(2) 证明 f(x) = 1/x² 为 (0, 1) 上的无界函数；
(3) 举出函数 f 的例子，使 f 为闭区间 [0, 1] 上的无界函数。

**考点** `ch01 §1.4 无界函数定义（有界定义取否）` ｜方法：量词否定

**教材对应** 习题1.4 第2题（教材三小问：叙述无界函数定义、证 1/x² 在 (0,1) 无界、举 [0,1] 上无界函数的例——与本题逐字相同）

**解**
(1) 设 f 定义在 D 上。若对**任何** M > 0 都存在 x₀ ∈ D 使 |f(x₀)| > M，则称 f 在 D 上**无界**。等价说法：不存在正数 M 使一切 x ∈ D 满足 |f(x)| ≤ M。
(2) 任给 M > 0，取 x₀ = 1/√(M+1)。则 0 < x₀ < 1，即 x₀ ∈ (0, 1)，且
f(x₀) = 1/x₀² = M + 1 > M。
按定义，f(x) = 1/x² 在 (0, 1) 上无界。
(3) 取 f(x) = 1/x（0 < x ≤ 1），f(0) = 0。任给 M > 0 取 x₀ = 1/(M+1) ∈ (0, 1]，则 f(x₀) = M + 1 > M，故 f 在闭区间 [0, 1] 上无界。

**答案** (2)(3) 见上；(3) 的 f 在 x = 0 处不连续。

**易错** 无界的否定叙述里「对任何 M 都存在 x₀」的量词顺序不能颠倒，x₀ 允许依赖 M；另外 (3) 说明**闭区间上连续函数有界定理的连续性前提不可省**。

### 题 8 ｜ sup 与 inf 在取负号下的对偶
**题目** 设 f 为定义在 D 上的有界函数，证明：
(1) sup_{x∈D} {−f(x)} = −inf_{x∈D} {f(x)}；(2) inf_{x∈D} {−f(x)} = −sup_{x∈D} {f(x)}。

**考点** `ch01 §1.2 定义2、定义3（sup / inf 的两条判据）`

**教材对应** 习题1.4 第9题（教材原题：设 f 为定义在 D 上的有界函数，证明 sup{−f(x)} = −inf f(x)、inf{−f(x)} = −sup f(x)——与本题逐字相同）

**解**
(1) 记 m = inf_{x∈D} f(x)（有界性保证存在）。∀x ∈ D 有 f(x) ≥ m，故 −f(x) ≤ −m，即 −m 是集合 {−f(x)} 的上界。再任取 α < −m，则 −α > m，由下确界定义存在 x₀ ∈ D 使 f(x₀) < −α，即 −f(x₀) > α，故 −m 是最小上界：sup{−f(x)} = −m = −inf f。
(2) 记 M = sup_{x∈D} f(x)。∀x ∈ D 有 f(x) ≤ M，故 −f(x) ≥ −M，−M 是 {−f(x)} 的下界；再任取 β > −M，则 −β < M，由上确界定义存在 x₀ ∈ D 使 f(x₀) > −β，即 −f(x₀) < β，故 −M 是最大下界：inf{−f(x)} = −M = −sup f。∎

**答案** 两式均成立。

**易错** 两条的「最性」方向相反：(1) 要对 α < −m 找元素**超过** α；(2) 要对 β > −M 找元素**低于** β。写反就推不出结论。
