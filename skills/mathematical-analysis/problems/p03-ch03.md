## 作业 3-1（P7）· §3.1 函数极限概念

### 题 17 ｜ 按定义证明三个函数极限
**题目** 按定义证明下列极限：
(1) lim_{x→+∞} (6x+5)/x = 6；(2) lim_{x→2} (x² − 6x + 10) = 2；(3) lim_{x→x₀} cos x = cos x₀。

**考点** `ch03 §3.1 定义1（ε-M）、定义2（ε-δ）` ｜模板 `T-02`

**教材对应** 习题3.1 第1题（教材「按定义证明」共五小问，本题集选编 (1)(2)(5)：lim (6x+5)/x = 6、lim (x²−6x+10) = 2、lim cos x = cos x₀；未选编的是教材 (3)(4) 两小问）

**解**
(1) 任给 ε > 0，取 M = 5/ε。当 x > M（此时 x > 0）时
|(6x+5)/x − 6| = |5/x| = 5/x < 5/M = ε。
按定义1 得 lim_{x→+∞} (6x+5)/x = 6。
(2) |x²−6x+10−2| = |x²−6x+8| = |x−2||x−4|。先限制 0 < |x−2| < 1，则 1 < x < 3，于是 |x−4| = 4−x < 3，从而 |f(x)−2| ≤ 3|x−2|。任给 ε > 0，取 δ = min{1, ε/3}，当 0 < |x−2| < δ 时 |f(x)−2| ≤ 3|x−2| < 3δ ≤ ε。
(3) 由和差化积与 |sin t| ≤ |t|：
|cos x − cos x₀| = 2|sin((x+x₀)/2)|·|sin((x−x₀)/2)| ≤ 2·1·|x−x₀|/2 = |x−x₀|。
任给 ε > 0，取 δ = ε，当 0 < |x−x₀| < δ 时 |cos x − cos x₀| ≤ |x−x₀| < ε。

**答案** 三式均按定义成立（δ = min{1, ε/3} 与 δ = ε 都是合法取法）。

**易错** (2) 里的「限制 |x−2| < 1」必须并入 δ = min{…}；(3) 若用 |cos x − cos x₀| ≤ |x − x₀| 就直接取 δ = ε，别漏掉 ≤ 与 < 的衔接。

### 题 18 ｜ 极限存在则绝对值极限存在
**题目** 证明：若 lim_{x→x₀} f(x) = A，则 lim_{x→x₀} |f(x)| = |A|。

**考点** `ch03 §3.1 定义2 + 反向三角不等式 ||f|−|A|| ≤ |f−A|`

**教材对应** 习题3.1 第4题（教材原题：若 lim f(x) = A，则 lim |f(x)| = |A|，并追问「当且仅当 A 为何值时反之也成立」——答 A = 0）

**解** 任给 ε > 0。由 lim_{x→x₀} f(x) = A，存在 δ > 0，当 0 < |x−x₀| < δ 时 |f(x) − A| < ε。由反向三角不等式
||f(x)| − |A|| ≤ |f(x) − A|，
故当 0 < |x−x₀| < δ 时也有 ||f(x)|−|A|| < ε。按定义2，lim_{x→x₀} |f(x)| = |A|。∎

**答案** 结论成立。教材同题追问「当且仅当 A 为何值时反之也成立」，答：**当且仅当 A = 0**。其余情形逆命题不真，如 f(x) = sgn x（x₀ = 0，|f| ≡ 1 → 1，但 f 在 0 处左右极限为 −1 与 1，极限不存在）。

**易错** 不能用 |f(x) − A| < ε 直接推 |f(x)| → A；成立的是 ||f|−|A|| ≤ |f−A|，方向是「绝对值函数压缩距离」。

## 作业 3-2（P8）· §3.2 函数极限的性质

### 题 19 ｜ 八个有理式的极限
**题目** 求下列极限：
(1) lim_{x→π/2} 2(sin x − cos x − x²)；(2) lim_{x→0} (x²−1)/(2x²−x−1)；(3) lim_{x→1} (x²−1)/(2x²−x−1)；
(4) lim_{x→0} [(x−1)³ + (1−3x)]/(x²+2x³)；(5) lim_{x→1} (xⁿ−1)/(xᵐ−1) (n, m 为正整数)；
(6) lim_{x→4} (√(1+2x) − 3)/(√x − 2)；(7) lim_{x→0} (√(a²+x) − a)/x (a > 0)；
(8) lim_{x→+∞} (3x+6)⁷⁰(8x−5)²⁰/(5x−1)⁹⁰。

**考点** `ch03 §3.2 定理3.7（四则运算）、初等函数连续性` ｜模板 `T-05`

**教材对应** 习题3.2 第1题（教材八小问与本题逐条相同，答案 (1) 2−π²/2、(2) 1、(3) 2/3、(4) −3、(5) n/m、(6) 4/3、(7) 1/(2a)、(8) 3⁷⁰8²⁰/5⁹⁰ 八项全对）

**解**
| 小题 | 关键一步 | 结果 |
|---|---|---|
| (1) | 在 x = π/2 处连续，直接代入 2(1 − 0 − π²/4) | 2 − π²/2 |
| (2) | 分母 → −1 ≠ 0，直接代入 (−1)/(−1) | 1 |
| (3) | 约去 x−1：(x+1)/(2x+1) → 2/3 | 2/3 |
| (4) | 分子 = x³−3x² = x²(x−3)，分母 = x²(1+2x)，约 x² | −3 |
| (5) | 拆成 [(xⁿ−1)/(x−1)]/[(xᵐ−1)/(x−1)] → n/m | n/m |
| (6) | 上、下分别有理化：2(x−4)/(√(1+2x)+3) ÷ (x−4)/(√x+2) → 2·4/6 | 4/3 |
| (7) | 有理化：x/[x(√(a²+x)+a)] → 1/(2a) | 1/(2a) |
| (8) | 同除 x⁹⁰：3⁷⁰8²⁰/5⁹⁰ | 3⁷⁰8²⁰/5⁹⁰ |

（(5) 也可用 (xⁿ−1)/(x−1) → n 这一基本极限，或作代换 x = 1 + t 后取极限；(6) 的有理化关键是分子、分母乘同一对共轭因式，其中 x − 4 恰为公因子。）

**答案** (1) 2 − π²/2；(2) 1；(3) 2/3；(4) −3；(5) n/m；(6) 4/3；(7) 1/(2a)；(8) 3⁷⁰·8²⁰/5⁹⁰。

**易错** 见 0/0 型就求导（洛必达还属第6章）不必要——(3)(4)(6) 都是约去零因子；(2) 不是 0/0，只能直接代入；(8) 分子次数 70+20 = 90 与分母相同，别漏乘系数。

### 题 20 ｜ 用迫敛性求极限
**题目** 利用迫敛性求极限：
(1) lim_{x→−∞} (x − cos x)/x；(2) lim_{x→+∞} x sin x/(x² − 4)。

**考点** `ch03 §3.2 定理3.6（迫敛性）` ｜模板 `T-05`

**教材对应** 习题3.2 第2题（教材答案：(1) 1、(2) 0，一致）

**解**
(1) (x−cos x)/x = 1 − cos x/x。当 x < 0 时 |cos x/x| ≤ 1/|x|，故
1 − 1/|x| ≤ (x − cos x)/x ≤ 1 + 1/|x|。
x → −∞ 时 1/|x| → 0，两端都 → 1，由迫敛性原极限 = 1。
(2) 当 x > 2 时 x²−4 > 0，且 |sin x| ≤ 1，故
−x/(x²−4) ≤ x sin x/(x²−4) ≤ x/(x²−4)，
而 x/(x²−4) = (1/x)/(1 − 4/x²) → 0，由迫敛性原极限 = 0。

**答案** (1) 1；(2) 0。

**易错** 迫敛必须凑出**两端都趋向同一值**的界；(1) 中 x < 0，把 1/x 直接写成 1/x 会弄错符号，用 1/|x| 统一处理最稳。

## 作业 3-3（P9）· §3.3 函数极限存在的条件、§3.4 两个重要的极限

### 题 21 ｜ 单调函数的极限存在 ⇔ 有界
**题目** 设 f 为定义在 [a, +∞) 上的增（减）函数。证明：lim_{x→+∞} f(x) 存在的充要条件是 f 在 [a, +∞) 上有上（下）界。

**考点** `ch03 §3.3 定理3.11（单调有界函数的极限）、ch01 定理1.1（确界原理）`

**教材对应** 习题3.3 第2题（教材原题与本题逐字相同；答案页未收 §3.3 习题）

**解** 以 f **递增**、结论为「有上界」的情形给出证明，递减情形把不等号全部反向、sup 换成 inf 即可。
(⇒) 设 lim_{x→+∞} f(x) = A。取 ε = 1，存在 M > a，当 x > M 时 |f(x) − A| < 1，特别 f(x) < A + 1。对 x ∈ [a, M]，由递增性 f(x) ≤ f(M)。故对一切 x ≥ a 有 f(x) ≤ max{f(M), A + 1}，f 有上界。
(⇐) 设 f 在 [a, +∞) 上有上界。由确界原理（定理1.1），A = sup_{x∈[a,+∞)} f(x) 存在。任给 ε > 0，由上确界定义存在 x₀ ≥ a 使 f(x₀) > A − ε。取 M = x₀，当 x > M 时由递增性
A − ε < f(x₀) ≤ f(x) ≤ A < A + ε，
即 |f(x) − A| < ε。按定义1，lim_{x→+∞} f(x) = A。∎

**答案** 充要条件成立，且极限值就是 sup f（递减时为 inf f）。

**易错** (⇒) 方向必须先取出 M 把区间截断成 [a, M] ∪ (M, +∞) 两段——有界性只在一个有界区间和一个尾部同时成立才叫整体有界。

### 题 22 ｜ 十个用 sin x/x → 1 的极限
**题目** 求下列极限：
(1) lim_{x→0} sin(2x)/x；(2) lim_{x→0} sin(x³)/(sin x)²；(3) lim_{x→π/2} cos x/(x − π/2)；(4) lim_{x→0} tan x/x；
(5) lim_{x→0} (tan x − sin x)/x³；(6) lim_{x→0} arctan x/x；(7) lim_{x→+∞} x sin(1/x)；
(8) lim_{x→a} (sin²x − sin²a)/(x − a)；(9) lim_{x→0} sin(4x)/(√(x+1) − 1)；(10) lim_{x→0} √(1 − cos(x²))/(1 − cos x)。

**考点** `ch03 §3.4 第一个重要极限、定理3.13（等价无穷小代换）` ｜模板 `T-05`

**教材对应** 习题3.4 第1题（教材十小问与本题逐条相同，答案 2、0、−1、1、1/2、1、1、sin 2a、8、√2 十项全对）

**解**
| 小题 | 关键一步 | 结果 |
|---|---|---|
| (1) | 2·(sin(2x)/(2x)) → 2·1 | 2 |
| (2) | [sin(x³)/x³]·x·(x/sin x)² → 1·0·1 | 0 |
| (3) | 令 t = x − π/2，cos x = −sin t ⇒ −sin t/t | −1 |
| (4) | (sin x/x)·(1/cos x) → 1·1 | 1 |
| (5) | tan x − sin x = tan x(1 − cos x) ⇒ (tan x/x)·((1−cos x)/x²) → 1·1/2 | 1/2 |
| (6) | 令 t = arctan x，则 x = tan t，t/tan t → 1 | 1 |
| (7) | 令 t = 1/x → 0⁺，sin t/t → 1 | 1 |
| (8) | sin²x − sin²a = sin(x+a)sin(x−a) ⇒ sin(x+a)·sin(x−a)/(x−a) → sin2a·1 | sin 2a |
| (9) | 分母有理化：sin(4x)(√(x+1)+1)/x → 4·2 | 8 |
| (10) | √(1−cos(x²)) = √2·|sin(x²/2)| ~ √2·x²/2，1−cos x ~ x²/2 | √2 |

**代表题详解**
(5) tan x − sin x = (sin x/cos x)(1 − cos x)，故
(tan x − sin x)/x³ = (sin x/x)·(1/cos x)·((1 − cos x)/x²) → 1·1·(1/2) = 1/2。
**注意不能在加减项里直接换 sin x ~ x、tan x ~ x**（那会得到 0），必须先提公因式。
(8) 由和差化积 sin²x − sin²a = sin(x+a)·sin(x−a)，故商 = sin(x+a)·[sin(x−a)/(x−a)] → sin(2a)·1 = sin 2a。
(10) 由 1 − cos u = 2sin²(u/2) 得 √(1−cos(x²)) = √2·|sin(x²/2)| ~ √2·x²/2，又 1 − cos x ~ x²/2，商 → √2。

**答案** (1) 2；(2) 0；(3) −1；(4) 1；(5) 1/2；(6) 1；(7) 1；(8) sin 2a；(9) 8；(10) √2。

**易错** 最典型的坑是 (5)：把 tan x、sin x 各自替换成 x 得 0；以及 (2) 把 sin(x³) 读成 (sin x)³（原题分子是 sin(x³)，分母是 (sin x)²，两者次数不同）。

### 题 23 ｜ 四个 1^∞ 型极限
**题目** 求下列极限：
(1) lim_{x→∞} (1 − 2/x)^{−x}；(2) lim_{x→0} (1 + tan x)^{cot x}；(3) lim_{x→0} ((1+x)/(1−x))^{1/x}；(4) lim_{x→+∞} ((3x+2)/(3x−1))^{2x−1}。

**考点** `ch03 §3.4 第二个重要极限 lim_{α→0}(1+α)^{1/α} = e` ｜方法：凑 e 的指数

**教材对应** 习题3.4 第2题（教材 6 小问答 e²、e^α、e、e²、e²、e^{αβ}；本题集选编其中 (1)(3)(4)(5) 四问，值 e²、e、e²、e² 与教材一致，但由于跳过了 (2) e^α 与 (6) e^{αβ} 两问，**小题号与教材不对应**）

**解**
(1) 令 t = −2/x → 0，则 (1−2/x)^{−x} = [(1+t)^{1/t}]² → e²。
(2) 令 t = tan x → 0，则 (1+tan x)^{cot x} = (1+t)^{1/t} → e。
(3) ((1+x)/(1−x))^{1/x} = (1+x)^{1/x}·(1−x)^{−1/x}；前者 → e，后者令 u = −x 得 (1+u)^{1/u} → e，故原式 → e·e = e²。
(4) 底 = 1 + 3/(3x−1)，记 u = 3/(3x−1) → 0⁺。由 (1+u)^{1/u} → e 与指数
(2x−1)u = 3(2x−1)/(3x−1) → 2，
得原式 → e²。

**答案** (1) e²；(2) e；(3) e²；(4) e²。

**易错** 1^∞ 型不能写成 1；正确套路是化 (1+α)^{1/α} 后把「剩余指数」单独求极限，(4) 中剩余的 3(2x−1)/(3x−1) 极限是 2 而不是 3。

## 作业 3-5（P10）· §3.5 无穷小量与无穷大量

### 题 24 ｜ 两个综合极限
**题目** 求下列极限：
(1) lim_{x→∞} x arctan(1/x)/(x − cos x)；(2) lim_{x→0} (√(1+x²) − 1)/(1 − cos x)。

**考点** `ch03 §3.2 定理3.7、定理3.13（等价无穷小）、§3.5 无穷小量阶` ｜模板 `T-05`

**教材对应** 习题3.5 第2题（教材原题两小问与本题相同，答案 (1) 0、(2) 1，一致）

**解**
(1) 分子分母同除 x：原式 = arctan(1/x)/(1 − cos x/x)。x → ∞ 时 1/x → 0，故 arctan(1/x) → arctan 0 = 0；又 |cos x/x| ≤ 1/|x| → 0。故原式 → 0/(1−0) = 0。
(2) 分子有理化：√(1+x²) − 1 = x²/(√(1+x²) + 1)；又 1 − cos x ~ x²/2。故
原式 = [x²/(√(1+x²)+1)]/(1−cos x) = 2/(√(1+x²)+1) → 2/(1+1) = 1。

**答案** (1) 0；(2) 1。

**易错** (1) 的答案是 0 而不是 1：分子 x arctan(1/x) → 1（无穷小 arctan(1/x) ~ 1/x 乘无穷大 x），而分母 x − cos x ~ x 趋于无穷；把 arctan(1/x) 换成 1/x 后必须**整体**同除 x，不能只缩分子。

### 题 25 ｜ 求曲线的渐近线
**题目** 求下列函数所表示曲线的渐近线：
(1) y = 1/x；(2) y = arctan x；(3) y = (3x³ + 4)/(x² − 2x)。

**考点** `ch03 §3.5 定义4（曲线的渐近线）、垂直/斜渐近线判定`

**教材对应** 习题3.5 第4题（教材原题三小问与本题相同，答案 (1) y = 0, x = 0；(2) y = π/2, y = −π/2；(3) y = 3x + 6, x = 0, x = 2，完全一致）

**解** 顺序：先看无定义点找垂直渐近线，再算 k = lim f(x)/x、b = lim (f(x) − kx)。
(1) lim_{x→0} 1/x = ∞ ⇒ 垂直渐近线 **x = 0**；lim_{x→∞} 1/x = 0 ⇒ 水平渐近线 **y = 0**（k = 0, b = 0，无斜渐近线）。
(2) 处处连续且 lim_{x→x₀} arctan x 有限 ⇒ 无垂直渐近线；lim_{x→+∞} = π/2、lim_{x→−∞} = −π/2 ⇒ 两条水平渐近线 **y = π/2**、**y = −π/2**（k = 0）。无斜渐近线。
(3) 分母零点 x = 0, 2 处分子分别等于 4 与 28（≠ 0）⇒ 垂直渐近线 **x = 0**、**x = 2**。
k = lim_{x→∞} (3x³+4)/(x³−2x²) = 3；
b = lim_{x→∞} [(3x³+4) − 3x(x²−2x)]/(x²−2x) = lim (6x²+4)/(x²−2x) = 6，
故斜渐近线 **y = 3x + 6**（因 f(x) − (3x+6) = (12x+4)/(x²−2x) → 0）。无水平渐近线。

**答案** (1) x = 0 与 y = 0；(2) y = π/2 与 y = −π/2；(3) x = 0、x = 2 与 y = 3x + 6。

**易错** 斜渐近线要先求 k 再求 b，b ≠ 0 时不能只写 y = kx；垂直渐近线的候选点必须验证「该点分母为 0 且分子不为 0」，否则可能只是可去间断点。
