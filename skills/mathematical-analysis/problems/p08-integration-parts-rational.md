## 作业 8-2（P29）· §8.2 分部积分专项

### 题 67 ｜ 分部积分法（10 小题）
**题目** 应用分部积分法求下列不定积分（∫u dv = uv − ∫v du；u 按"反对幂三指"的先后取）

| 小题 | 被积函数 | 取 u / dv | 结果 |
|---|---|---|---|
| (1) | arcsin x | u = arcsin x，dv = dx | x·arcsin x + √(1 − x²) + C |
| (2) | ln x | u = ln x，dv = dx | x ln x − x + C |
| (3) | x²cos x | u = x²，dv = cos x dx（两次分部） | x²sin x + 2x cos x − 2sin x + C |
| (4) | ln x/x³ | u = ln x，dv = x^(−3)dx | −ln x/(2x²) − 1/(4x²) + C |
| (5) | (ln x)² | u = (ln x)²，dv = dx（两次） | x(ln x)² − 2x ln x + 2x + C |
| (6) | x·arctan x | u = arctan x，dv = x dx | ((x² + 1)/2)arctan x − x/2 + C |
| (7) | ln(ln x) + 1/ln x | 拆成 ∫ln(ln x)dx + ∫dx/ln x，前者 u = ln(ln x) | x·ln(ln x) + C |
| (8) | (arcsin x)² | u = (arcsin x)²，dv = dx（两次） | x(arcsin x)² + 2√(1 − x²)·arcsin x − 2x + C |
| (9) | sec³x | u = sec x，dv = sec²x dx（移项解方程） | (1/2)sec x·tan x + (1/2)ln\|sec x + tan x\| + C |
| (10) | √(x² ± a²)（a > 0） | u = √(x² ± a²)，dv = dx（移项） | √(x²+a²)：(x/2)√(x²+a²) + (a²/2)ln(x + √(x²+a²)) + C；√(x²−a²)：(x/2)√(x²−a²) − (a²/2)ln\|x + √(x²−a²)\| + C |

**考点** `ch08 定理8.6 / 分部积分法` ｜方法 `"反对幂三指"定 u；出现同类项时移项解方程`

**教材对应** 习题8.2 第2题(1)–(10)（教材书末 p304）

**代表题详解**

**(8)** 第一次取 u = (arcsin x)²、dv = dx：

∫(arcsin x)²dx = x(arcsin x)² − ∫(2x·arcsin x)/√(1 − x²)dx。

对第二个积分再分部：取 u = arcsin x、dv = 2x/√(1 − x²)dx，则 v = −2√(1 − x²)，得

∫(2x·arcsin x)/√(1 − x²)dx = −2√(1 − x²)·arcsin x + 2∫dx = −2√(1 − x²)·arcsin x + 2x。

代回即得结果（第二次分部中 √(1 − x²)/√(1 − x²) = 1，积分立即完成，这是本题的关键）。

**(9)** 记 I = ∫sec³x dx。取 u = sec x、dv = sec²x dx，则 v = tan x：

I = sec x·tan x − ∫sec x·tan²x dx = sec x·tan x − ∫sec x(sec²x − 1)dx = sec x·tan x − I + ∫sec x dx。

移项得 2I = sec x·tan x + ln\|sec x + tan x\|，故 I = (1/2)sec x·tan x + (1/2)ln\|sec x + tan x\| + C。

**(10)** 以 √(x² + a²) 为例，记 J = ∫√(x² + a²)dx。取 u = √(x² + a²)、dv = dx：

J = x√(x² + a²) − ∫x²/√(x² + a²)dx。

把分子写成 x² = (x² + a²) − a²，则 ∫x²/√(x² + a²)dx = J − a²∫dx/√(x² + a²)，其中 ∫dx/√(x² + a²) = ln(x + √(x² + a²))。代回并移项：

2J = x√(x² + a²) + a²ln(x + √(x² + a²))，

J = (x/2)√(x² + a²) + (a²/2)ln(x + √(x² + a²)) + C。

√(x² − a²) 的情形完全相同：因 x² = (x² − a²) + a²，移项后 ln 项前变为减号。

**与教材答案对照** 10 条逐条核对**全部一致**。(4) 教材作 −(2ln x + 1)/(4x²)；(10) 教材把 ± 合并写成 ½(x√(x² ± a²) ± a²ln|√(x² ± a²) + x|) + C。

**答案** 见上表 10 条（每项均带 + C）

**易错** u 选错会越分部越复杂——幂函数乘三角函数时 u 必须取幂函数（降次），取三角函数则升次死循环；(9)(10) 分部后必须"移项解方程"，而不是继续分部。

## 作业 8-3（P30）· §8.3 有理函数和可化为有理函数的不定积分

### 题 68 ｜ 有理函数积分（3 小题）
**题目** 求下列不定积分：(1) ∫x³/(x − 1)dx；(2) ∫(x − 2)/(x² − 7x + 12)dx；(3) ∫dx/(1 + x³)。

**考点** `ch08 §8.3 部分分式分解流程（降次 → 分解分母 → 待定系数 → 逐项积分）` ｜方法 `有理函数积分（封闭算法）`

**教材对应** 习题8.3 第1题：(1)(2)(3) 依次对应作业 68(1)(2)(3)（教材书末 p304）

**解**

**(1)** 假分式先做多项式除法：x³ = (x − 1)(x² + x + 1) + 1，故

∫x³/(x − 1)dx = ∫(x² + x + 1)dx + ∫dx/(x − 1) = x³/3 + x²/2 + x + ln\|x − 1\| + C。

**(2)** 分母分解 x² − 7x + 12 = (x − 3)(x − 4)。设 x − 2 = A(x − 4) + B(x − 3)，代 x = 3 得 A = −1，代 x = 4 得 B = 2。故

∫(x − 2)/(x² − 7x + 12)dx = −ln\|x − 3\| + 2ln\|x − 4\| + C = ln((x − 4)²/\|x − 3\|) + C。

**(3)** 1 + x³ = (1 + x)(x² − x + 1)，且 x² − x + 1 的判别式 −3 < 0，不可再分解。设

1/((1 + x)(x² − x + 1)) = A/(1 + x) + (Bx + C)/(x² − x + 1)，

两边乘分母：1 = A(x² − x + 1) + (Bx + C)(x + 1)。令 x = −1 得 A = 1/3；比较 x² 系数得 B = −1/3；令 x = 0 得 C = 2/3。于是被积式

= (1/3)/(1 + x) − (1/3)(x − 2)/(x² − x + 1) = (1/3)/(1 + x) − (1/6)(2x − 1)/(x² − x + 1) + (1/2)/(x² − x + 1)，

其中第一、二项直接给出对数，第三项配方 x² − x + 1 = (x − 1/2)² + 3/4，故

∫dx/(x² − x + 1) = (2/√3)arctan((2x − 1)/√3)。

合并：

∫dx/(1 + x³) = (1/3)ln\|1 + x\| − (1/6)ln(x² − x + 1) + (1/√3)arctan((2x − 1)/√3) + C。

**答案** (1) x³/3 + x²/2 + x + ln\|x − 1\| + C；(2) 2ln\|x − 4\| − ln\|x − 3\| + C；(3) (1/3)ln\|1 + x\| − (1/6)ln(x² − x + 1) + (1/√3)arctan((2x − 1)/√3) + C

**与教材答案对照** 三条均与教材书末答案一致：(1) 完全相同；(2) 教材作 ln((x − 4)²/|x − 3|)；(3) 教材把两个对数合并为 (1/6)ln[(1 + x)²/(x² − x + 1)]。

**易错** (1) 除法商里的常数项 1 极易漏（x³/(x − 1) 的商是 x² + x + 1，不是 x² + x）；(3) 分解后二次项必须先拆成"分母导数型 + 标准 arctan 型"，直接积分会卡住。

### 题 69 ｜ 三角有理式与无理根式（3 小题）
**题目** 求下列不定积分：(1) ∫dx/(5 − 3cos x)；(2) ∫x²/√(1 + x − x²)dx；(3) ∫(1/x²)√((1 − x)/(1 + x))dx。

**考点** `ch08 §8.3 万能代换 t = tan(x/2)；配方后三角代换；根式代换` ｜方法 `三角有理式化有理函数 / 二次根式配方`

**教材对应** 习题8.3 第2题：作业 69(1)(2)(3) 依次对应教材 2.(1)、2.(4)、2.(6)（教材书末 p305；中间的 2.(2)(3)(5) 未入选作业集）

**解**

**(1)** 这是 cos x 的有理式，用万能代换 t = tan(x/2)：cos x = (1 − t²)/(1 + t²)，dx = 2dt/(1 + t²)，于是

5 − 3cos x = [5(1 + t²) − 3(1 − t²)]/(1 + t²) = (2 + 8t²)/(1 + t²) = 2(1 + 4t²)/(1 + t²)，

∫dx/(5 − 3cos x) = ∫(1 + t²)/(2(1 + 4t²))·2dt/(1 + t²) = ∫dt/(1 + 4t²) = (1/2)arctan(2t) + C。

所以原式 = (1/2)arctan(2tan(x/2)) + C（在每个不跨 x = π 的区间上成立）。

**(2)** 先配方：1 + x − x² = 5/4 − (x − 1/2)²。令 u = x − 1/2、a = √5/2，则 x = u + 1/2、x² = u² + u + 1/4，原式化为

∫(u² + u + 1/4)/√(a² − u²)du。

三个标准积分（均由 u = a sin θ 立得）：

∫u²/√(a² − u²)du = (a²/2)arcsin(u/a) − (u/2)√(a² − u²)，∫u/√(a² − u²)du = −√(a² − u²)，∫du/√(a² − u²) = arcsin(u/a)。

合并（a² = 5/4）：arcsin 前系数为 (5/4)/2 + 1/4 = 7/8；根式项为 −(u/2)√(a² − u²) − √(a² − u²) = −((2x + 3)/4)√(1 + x − x²)。故

原式 = (7/8)arcsin((2x − 1)/√5) − ((2x + 3)/4)√(1 + x − x²) + C。

**(3)** 令 t = √((1 − x)/(1 + x))，平方解得 x = (1 − t²)/(1 + t²)，dx = −4t/(1 + t²)²dt，且 1/x² = (1 + t²)²/(1 − t²)²，于是

∫(1/x²)√((1 − x)/(1 + x))dx = −∫4t²/(1 − t²)²dt。

部分分式分解：4t²/(1 − t²)² = −1/(1 − t) + 1/(1 − t)² − 1/(1 + t) + 1/(1 + t)²，逐项积分得

−∫4t²/(1 − t²)²dt = ln\|(1 + t)/(1 − t)\| − 2t/(1 − t²) + C。

回代：由 1 − t² = 2x/(1 + x) 得 2t/(1 − t²) = t(1 + x)/x = √(1 − x²)/x；又 (1 + t)/(1 − t) = (1 + √(1 − x²))/x。故

原式 = −√(1 − x²)/x + ln\|(1 + √(1 − x²))/x\| + C。

**答案** (1) (1/2)arctan(2tan(x/2)) + C；(2) (7/8)arcsin((2x − 1)/√5) − ((2x + 3)/4)√(1 + x − x²) + C；(3) −√(1 − x²)/x + ln\|(1 + √(1 − x²))/x\| + C

**与教材答案对照** 三条与教材书末答案 2.(1)(4)(6) **完全一致**。

**易错** (1) 万能代换后别忘 dx 的 2/(1 + t²) 因子；(2) 拆 ∫u²/√(a² − u²)du 时 arcsin 系数 a²/2 与根式项 −u/2 都要除以 2；(3) 分解 4t²/(1 − t²)² 的符号最容易反（t = 0 处两边都应为 0，可用特值验算）。
