# Cheatsheet / 决策速查

做题时摊在手边的那一页。每一条都用来**做决定**，不是术语表（术语查 [glossary.md](glossary.md)）。

## 求极限：走哪条路

| 看到什么 | 先做什么 | 别做什么 |
|---|---|---|
| 代入后是 `0/0` 或 `∞/∞` | 洛必达，**或**泰勒展开 | 不验证前提就用洛必达 |
| 含 `sin x, eˣ, ln(1+x)` 的加减 | **泰勒展开**到足够阶 | 在加减中做等价无穷小替换 |
| 乘除结构 | 等价无穷小替换 | 替换后忘记检查是否仍定型 |
| 数列递推式 `aₙ₊₁ = f(aₙ)` | 先证有界 → 再证单调 → 取极限 | 先取极限后证有界 |
| 含 `Σf(i/n)` | 化为 `∫₀¹f(x)dx` | 忘记除以 `n` |
| 放缩能夹住 | 迫敛性（定理3.6） | 两边极限不相等 |
| 证明**不存在** | 归结原则：找两个子列极限不同 | 只算一个方向的极限 |

| 对象 | 判据 | 章 |
|---|---|---|

**多元函数极限不存在的最快证法**：找两条路径极限不同（如沿 `y = kx`）。**累次极限存在推不出重极限存在**。

## 级数敛散性：判定流程

```
Σuₙ
 ├─ uₙ ↛ 0 ?  → 发散，结束
 ├─ uₙ ≥ 0 ?  → 正项级数
 │   ├─ 含 n! → 比值法（定理12.7）
 │   ├─ 含 n 次幂 → 根式法（定理12.8）
 │   ├─ 可与 1/nᵖ 比 → 比较原则（定理12.6）
 │   ├─ 是 f(n) 形式 → 积分判别法（定理12.9）
 │   └─ 比值/根式得 ρ = 1 → 拉贝判别法（定理12.10）
 └─ uₙ 变号 → 先查 Σ|uₙ|
     ├─ Σ|uₙ| 收敛 → 绝对收敛 ⇒ 收敛，结束
     └─ 只是条件收敛 →
         ├─ 交错级数 → 莱布尼茨判别法（定理12.11）
         ├─ 单调因子 × 有界部分和 → 狄利克雷（定理12.16）
         └─ 单调有界因子 × 收敛级数 → 阿贝尔（定理12.15）
```

⚠️ **比值法/根式法得 `ρ = 1` 时结论为零**，必须换方法。**不绝对收敛 ≠ 发散**。

## 反常积分：两类不能混

| 类型 | 形式 | 判敛基准 | 收敛条件 |
|---|---|---|---|
| 无穷积分 | `∫_a^∞ f` | `∫₁^∞ dx/xᵖ` | **`p > 1`** 收敛 |
| 瑕积分 | `∫_a^b f`（`f` 无界） | `∫₀¹ dx/xᵖ` | **`p < 1`** 收敛 |

**这两个条件是反的**——本章最容易记混的一点。

## 一致收敛：三个性质的条件强弱

| 性质 | 定理 | 条件 |
|---|---|---|
| 和函数连续 | 定理13.12 | 级数一致收敛 |
| 逐项求积 | 定理13.13 | 级数一致收敛 |
| **逐项求导** | 定理13.14 | **求导后的级数**一致收敛（更严！） |

**判定一致收敛的优先级**：`sup|fₙ−f| → 0` > 魏尔斯特拉斯 M 判别法 > 阿贝尔/狄利克雷。

**点态收敛 ⇏ 一致收敛**（反例 `xⁿ` 在 `[0,1]`）。

## 不定积分：方法选择

| 被积函数形状 | 方法 |
|---|---|
| 能凑成 `f(u)u′dx` | 第一换元法 |
| `√(a²−x²)` | `x = a sin t` |
| `√(a²+x²)` | `x = a tan t` |
| `√(x²−a²)` | `x = a sec t` |
| 多项式 × 指数/三角/对数 | 分部积分（`u` 按「反对幂指三」顺序优先） |
| 有理函数 `P(x)/Q(x)` | 部分分式（先化成真分式！） |
| 三角有理式 | 先化简；不得已才用万能代换 `t = tan(x/2)` |

**分部积分口诀**：`∫u dv = uv − ∫v du`，`u` 的优先级 **反**三角函数 > **对**数 > **幂**函数 > **指**数 > **三**角。

## 定积分 → 三大公式对照

| 公式 | 定理 | 联系 | 方向要求 |
|---|---|---|---|
| **格林** | 21.11 | 平面闭曲线 ↔ 二重积分 | `L` 正向（逆时针） |
| **高斯** | 22.5 | 闭曲面 ↔ 三重积分 | 曲面取**外侧** |
| **斯托克斯** | 22.6 | 空间闭曲线 ↔ 曲面积分 | 右手法则匹配 |

三者是**同一个定理的不同维数**。**方向取反则整体变号**；`Q_x − P_y` 的顺序不能写反。

## 微元法：常用微元

| 量 | 微元 |
|---|---|
| 平面面积（直角） | `dA = \|y₂ − y₁\|dx` |
| 平面面积（极坐标） | `dA = ½r²dθ` |
| 旋转体体积（圆盘） | `dV = πy²dx` |
| 旋转体体积（柱壳） | `dV = 2πx\|y\|dx` |
| 弧长 | `ds = √(1+y′²)dx` |
| 旋转曲面面积 | `dS = 2π\|y\|ds` |
| 曲率 | `K = \|y″\| / (1+y′²)^{3/2}` |

极坐标与球坐标的**雅可比不能漏**：极坐标 `J = r`，球坐标 `J = r²sin φ`。

## 实数完备性：六定理等价

```
确界原理 ⇔ 单调有界定理 ⇔ 区间套定理
   ⇔ 聚点定理 ⇔ 有限覆盖定理 ⇔ 柯西收敛准则
```

| 定理 | 典型用途 |
|---|---|
| 确界原理 | 构造性证明（取 sup/inf） |
| 单调有界 | 递推数列 |
| 区间套 | 存在唯一性（唯一公共点） |
| 聚点 | 抽子列（致密性） |
| 有限覆盖 | 局部性质 → 整体性质 |
| 柯西准则 | 不知道极限值时判收敛 |

## 求导：看到什么用什么

| 看到什么 | 用什么 | 别做什么 |
|---|---|---|
| `u(x)^{v(x)}`（`x^x`、`x^{sin x}`） | **对数求导法**（或 `e^{v ln u}`） | 套 `(xⁿ)′ = n xⁿ⁻¹` |
| 多因子连乘 / 带根号的分式 | 对数求导法 | 硬套乘积法则 |
| `x = x(t), y = y(t)` | `dy/dx = y′_t/x′_t` | — |
| 参数方程要**二阶导** | 一阶结果对 `t` 求导**再除 `x′_t`** | 漏掉最后那次除法 |
| `F(x, y) = 0` 隐函数 | `dy/dx = −F_x/F_y` | 漏负号 |
| 分界点处的分段函数 | **回到导数定义**算左右导数 | 直接对两段套公式 |
| 求 `f^{(n)}(x)` | 有理分式先**拆项**；一个因子是多项式用**莱布尼茨** | 只算前 3 阶就写通项 |

## 极值 / 拐点 / 渐近线：判据

| 要判什么 | 判据 | 失效时 |
|---|---|---|
| 单调区间 | `y′` 的符号 | — |
| 极值点 | 驻点或不可导点 + `y′` **变号**（一阶充分条件） | `y″` 判别：`y″>0` 极小、`y″<0` 极大 |
| 凹凸区间 | `y″` 的符号（教材：`y″>0` 为**凹**） | — |
| 拐点 | `y″` **变号**的点（`y″=0` 只是候选） | 二阶不可导点也要查 |
| 竖直渐近线 | `x → a` 时 `f → ∞` | — |
| 水平 / 斜渐近线 | 分别算 `x → +∞` 与 `x → −∞`：`k = lim f/x`，`b = lim (f − kx)` | `k` 不存在则无斜渐近线 |

**凹凸记号警告**：本书「凹」= 下凸（`y″ > 0`），「凸」= 上凸（`y″ < 0`），与部分教材相反。答题按本部教材的习惯写。

## 不定积分：三类「非标准」被积函数

| 被积函数 | 打法 | 关键动作 |
|---|---|---|
| `P(x)/Q(x)` 有理函数 | 部分分式 | **先做多项式除法化成真分式**；重根项数不能设少 |
| `R(sin x, cos x)` 三角有理式 | 先凑微分，不行再万能代换 | `t = tan(x/2)`；`∫R(sin x)cos x dx` 直接令 `u = sin x` |
| 含 `ⁿ√(ax+b)` 或 `√(x²±a²)` | 根式代换 / 三角代换 | 令 `t = ⁿ√(ax+b)`；三角代换后**换回原变量** |

**拆项套路**：`1/[x(1+x)] = 1/x − 1/(1+x)`、`1/[x(xⁿ+1)]` 分子分母同除 `xⁿ`、`1/(1−x²) = ½[1/(1−x)+1/(1+x)]`。

## 分段函数三个「必须回定义」的地方

1. **连续性**：分界点算左右极限，`f(a−0) = f(a+0) = f(a)`。
2. **可导性**：分界点用**导数定义**算 `f′₋(a)`、`f′₊(a)`，都存在且相等才可导（连续是可导的必要条件，先查连续）。
3. **原函数**：分段积分后**在分界点把常数拼到连续**——原函数连续是硬要求。
## Tells & smells（看到即警觉）

- 洛必达用完还是 `0/0` → 可能循环，改用**泰勒**
- 加减法里做了等价无穷小替换 → **错**（`sin x − x` 不能换成 0）
- 比值法/根式法算出 `ρ = 1` 就下结论 → 结论为零，必须换法
- 把「不绝对收敛」当成「发散」→ 条件收敛也是收敛
- 逐项求导只验证了原级数一致收敛 → **条件不足**，要验导数级数
- 换元后积分限没换 → 定积分最常见错误
- 重积分忘乘雅可比 → 极坐标漏 `r`、球坐标漏 `r²sin φ`
- 格林公式 `Q_x − P_y` 写成 `P_y − Q_x` → 符号反
- 曲线积分区域不单连通却用「与路线无关」→ 前提不成立
- 闭区间连续函数的性质用到开区间上 → 最值定理/一致连续**都要求闭区间**
- 多元函数只沿一条路径算出极限就下结论 → 必须证明**所有路径**一致，或找两条路径反证
- 海赛判别式 `AC − B² > 0` 却不看 `A` 的符号 → 分不出极大极小
- 极限计算里把 `δ` 写成依赖 `x` 的表达式 → 那是一致连续性，不是逐点极限
- 泰勒展开阶数不够 → 关键项抵消后余项阶不到位，重展开到足够阶
- 分段函数在分界点只算了一侧导数 → 可导必须**左右导数都存在且相等**，且先要连续
- 求分段函数的原函数时没把常数拼齐 → `F` 在分界点跳了，不是原函数
- 幂指函数 `x^{sin x}` 直接写成 `sin x · x^{sin x − 1}` → 那是把指数当常数，必须取对数
- 参数方程二阶导只写出 `d/dt(dy/dx)` → 漏了**再除一次 `x′(t)`**
- `∫dx/x` 写成 `ln x` → 漏绝对值，应为 `ln|x|`
- 有理函数积分忘了多项式除法的商 → 少了整式那一项（如 `x³/(x−1)`）
- 三角代换做完把 `t` 留在结果里 → 必须换回原变量
- 求斜渐近线只算 `x → +∞` → `x → −∞` 要单独算，两边可以不同
