## 二、题型 / 方法索引

- **极限**：ε-N / ε-δ 先写「对任意 ε>0，取 N/δ=…」；夹逼、单调有界、Stolz、等价无穷小。
- **连续性**：分段点先算左右极限；一致连续用 `|f(x)-f(y)|≤L|x-y|` 或 Cantor 定理。
- **导数**：定义域优先；隐函数/参数方程用链式法则；高阶导数用 Leibniz。
- **不定积分**：先看能否凑微分，再换元/分部/有理函数/三角有理式；结果求导验算。
- **定积分**：换元必换限；对称区间看奇偶；变上限积分求导。
- **级数**：正项级数先看通项是否趋 0，再比值/根值/比较/积分判别；交错级数看 Leibniz；绝对收敛优先。
- **函数项级数**：先找一致收敛（Weierstrass M / Dirichlet / Abel），再谈逐项积分、逐项求导。
- **多元微分**：偏导存在 ≠ 可微；可微看全增量 `Δz=AΔx+BΔy+o(ρ)`；方向导数与梯度。
- **隐函数**：先验证 `F_y≠0`，再写 `dy/dx=-F_x/F_y`。
- **重积分 / 线面积分**：先画区域、选坐标；Green / Gauss / Stokes 先检查定向与条件。
