## Core Idea / 核心思想

本章用 ε-N 语言把「n 无限增大时 aₙ 无限接近 a」翻译成可以运算、可以否证的精确命题，并由此建立收敛数列的一整套性质（唯一性、有界性、保号性、保不等式性、迫敛性、四则运算）。随后解决更根本的问题——**极限的存在性**：单调有界定理与柯西收敛准则分别给出两个方向的判据，前者依赖确界原理，后者只依赖数列自身的特征。

## Frameworks Introduced / 核心框架

- **定义1（数列极限的 ε-N 定义）**：设 {aₙ} 为数列，a 为定数。若对任给的正数 ε，总存在正整数 N，使得当 n > N 时有 |aₙ − a| < ε，则称 {aₙ} **收敛于** a，记 limₙ aₙ = a 或 aₙ → a (n → ∞)；没有极限的数列称**发散数列**。
  - 何时用：一切「按定义证明」的场合，也是全部后续定理的出发点。
  - 关键点：ε 任给，一经给出就暂时固定以便求出 N；N 依赖 ε（常记 N(ε)）但不被 ε 唯一确定，重要的是**存在性**。|aₙ − a| < ε 可换成 ≤ ε，n > N 可换成 n ≥ N，N 不必是正整数而只需是正数。
- **定义1′（等价定义）**：任给 ε > 0，若在 U(a; ε) 之外数列中的项至多只有有限个，则称 {aₙ} 收敛于 a。
  - 何时用：证明**发散**时最好用——只需找到一个 ε₀ > 0，使 U(a; ε₀) 之外有无穷多项。
  - 关键点：与定义1 等价，因此「改变、增加或删去有限项」不改变收敛性与极限值（例9）。
- **定理2.1**：{aₙ} 收敛于 a 的充要条件是 {aₙ − a} 为无穷小数列。
  - 关键点：这是定义1 与「无穷小数列」定义的直接翻译，「收敛到 a」由此化归为「收敛到 0」。
- **定理2.2（唯一性）**：若 {aₙ} 收敛，则它只有一个极限。
  - 关键点：设 b ≠ a，取 ε₀ = |b − a|/2，则 U(a; ε₀) 与 U(b; ε₀) 不相交；由定义1′ 知 U(b; ε₀) 内至多有限项，故 b 不是极限。
- **定理2.3（有界性）**：若 {aₙ} 收敛，则 {aₙ} 有界，即存在正数 M 使一切 n 有 |aₙ| ≤ M。
  - 关键点：取 ε = 1 得 a − 1 < aₙ < a + 1 (n > N)，再把前 N 项与 |a ± 1| 一起放进 max。**有界只是必要条件**：{(−1)ⁿ} 有界但不收敛。
- **定理2.4（保号性）**：若 lim aₙ = a > 0（或 < 0），则对任何 a′ ∈ (0, a)（或 a′ ∈ (a, 0)），存在正数 N，当 n > N 时有 aₙ > a′（或 aₙ < a′）。
  - 何时用：由极限符号反推项的符号；证商的极限时保证分母不趋于 0。应用中常取 a′ = a/2。
  - 关键点：取 ε = a − a′ > 0 即可。
- **推论（保序性）**：设 lim aₙ = a，lim bₙ = b 且 a < b，则存在 N，当 n > N 时有 aₙ < bₙ。
  - 关键点：取中间值 (a + b)/2，对两个数列分别用保号性，再取 N = max{N₁, N₂}。
- **定理2.5（保不等式性）**：设 {aₙ}, {bₙ} 均收敛。若存在正数 N₀，当 n > N₀ 时 aₙ ≤ bₙ，则 lim aₙ ≤ lim bₙ。
  - 何时用：由项的不等式得极限的不等式；也用于排除不可能的极限值（如 §3例2 中舍去 a = −1）。
  - 关键点：**条件加强为严格不等式，结论不能加强**。aₙ < bₙ 仍只能得 lim aₙ ≤ lim bₙ（如 0 < 1/n 而两极限都是 0）。
- **定理2.6（迫敛性）**：设 {aₙ}, {bₙ} 都以 a 为极限，且存在 N₀ 使 n > N₀ 时 aₙ ≤ cₙ ≤ bₙ，则 {cₙ} 收敛且 lim cₙ = a。
  - 何时用：通项难算但能夹在两个已知极限之间（如 {ⁿ√n}：1 ≤ aₙ < 1 + 2/(n − 1)）。
  - 关键点：取 N = max{N₀, N₁, N₂}，使三组不等式在同一下标之后同时成立。
- **定理2.7（四则运算法则）**：若 {aₙ}, {bₙ} 收敛，则 {aₙ ± bₙ}, {aₙbₙ} 收敛，且 lim(aₙ ± bₙ) = lim aₙ ± lim bₙ，lim(aₙbₙ) = lim aₙ · lim bₙ，lim(caₙ) = c lim aₙ；若另有 bₙ ≠ 0 且 lim bₙ ≠ 0，则 {aₙ/bₙ} 收敛且 lim(aₙ/bₙ) = lim aₙ / lim bₙ。
  - 关键点：只需证和、积、倒数三种。积的证明调用定理2.3（|bₙ| < M），倒数的证明调用定理2.4（|bₙ| > |b|/2）。
- **定理2.8（子列）**：{aₙ} 收敛的充要条件是它的任何子列都收敛。
  - 何时用：**判断发散的有力工具**——有一个子列发散，或两个子列收敛于不同极限，则原数列发散。
  - 关键点：子列满足 n_k ≥ k，故 k > N 时 n_k ≥ k > N 使 |a_{n_k} − a| < ε 自动成立。「任何子列都收敛」须理解为都收敛且**同一极限**。
- **定理2.9（单调有界定理）**：在实数系中，有界的单调数列必有极限。
  - 何时用：通项复杂、无法直接算极限时的首选；也可先证收敛再对递推式两边取极限。
  - 关键点：设 {aₙ} 递增有上界，取 a = sup{aₙ}。对任给 ε > 0，由上确界定义存在 a_N > a − ε，再由递增性得 n ≥ N 时 a − ε < aₙ ≤ a，故 |aₙ − a| < ε。递减有下界时极限即 inf{aₙ}。
- **定理2.10（致密性定理）**：任何有界数列必定有收敛的子列。
  - 关键点：先证任何数列都存在单调子列（例5：按「每个尾段 {a_{k+n}} 是否有最大项」分两种情形），再对有界数列的单调子列用定理2.9。
- **定理2.11（柯西收敛准则）**：{aₙ} 收敛的充要条件是 {aₙ} 为**柯西数列**，即对任给 ε > 0 存在正整数 N，当 n, m > N 时 |aₙ − a_m| < ε。
  - 何时用：不需事先猜出极限值 a，只看数列是否「越到后面越挤在一起」。
  - 关键点：必要性用 |aₙ − a_m| ≤ |aₙ − A| + |a_m − A| < ε/2 + ε/2。充分性先用 ε₀ = 1 证有界，再用致密性定理取出收敛子列 a_{n_k} → ξ，最后在 |aₙ − a_{n_k}| < ε/2 中令 k → ∞ 得 |aₙ − ξ| ≤ ε/2 < ε。

## Key Concepts / 核心概念

- **数列（sequence）**：定义域为全体正整数集 ℕ₊ 的函数 f : ℕ₊ → ℝ，记作 {aₙ}，aₙ 为通项。
- **无穷小数列（infinitesimal sequence）**：满足 lim aₙ = 0 的数列。
- **非正常极限**：lim aₙ = ∞ 指对任意 M > 0 存在 N，当 n > N 时 |aₙ| > M；lim aₙ = +∞ 指 aₙ > M。
- **无穷大数列（infinitely large sequence）**：以 ∞、+∞ 或 −∞ 为非正常极限的数列。
- **单调数列（monotone sequence）**：aₙ ≤ aₙ₊₁（递增）或 aₙ ≥ aₙ₊₁（递减），两者统称单调。
- **子列（subsequence）**：取 ℕ₊ 的无限子集 n₁ < n₂ < … < n_k < … 构成的 {a_{n_k}}，恒有 n_k ≥ k。
- **柯西数列（Cauchy sequence）**：对任给 ε > 0 存在 N，当 n, m > N 时 |aₙ − a_m| < ε。
- **自然对数的底 e**：e = lim(1 + 1/n)ⁿ ≈ 2.718 281 828 459，ln x = log_e x。
- **无界数列 ≠ 无穷大数列**：{[1 + (−1)ⁿ]n} 无界（奇数项无界），但偶数项恒为 0。

## Mental Models / 思维模型

- **把 ε-N 证明看成「倒推 + 放大」两个动作**：先从 |aₙ − a| < ε 解出 n 大致要多大，再把 |aₙ − a| 放大成更好解的式子。放大必须**适当**——放大后仍能由给定 ε 定出 N。
- **遇到「证明极限存在」先分类**：能看出单调且有界 → 定理2.9；看不出单调但能估两项之差 → 柯西准则；两边能夹 → 迫敛性。
- **把「改写有限项」看成不变量**：凡只涉及「n 充分大之后」的性质都对增加、减少或改变有限项免疫，这解释了例8、例9 与定义1′ 的等价性。
- **证发散就去找两个子列**：{(−1)ⁿ} 的偶子列趋 1、奇子列趋 −1 是最标准的模板；{sin(nπ/2)} 用奇子列 {(−1)^{k−1}} 发散即得结论。

## Anti-patterns / 常见错误

- **只对几个 ε（如 0.1, 0.01, 0.001）求出 N 就断言收敛**：定义要求对**任给**的 ε 都存在 N，有限次验证不构成证明（§1习题1 正是针对这一点）。
- **由有界推出收敛**：{(−1)ⁿ} 有界而发散；有界性只是必要条件。
- **由 aₙ < bₙ 推出 lim aₙ < lim bₙ**：反例 aₙ = 0 < bₙ = 1/n，两者极限都为 0。定理2.5 的结论只能是 ≤。
- **由无界推出是无穷大数列**：aₙ = [1 + (−1)ⁿ]n 无界，但偶数项恒为 0，不满足 |aₙ| > M 对充分大的 n 成立。
- **认为「任何子列都收敛」不要求极限相同**：若偶子列趋 1、奇子列趋 −1，每个子列各自收敛，原数列却发散。
- **用递推式两边取极限前不先证极限存在**：设 aₙ = 2ⁿ 并令 lim aₙ = a，由 aₙ = 2aₙ₋₁ 得 a = 2a，于是 a = 0——结果荒谬，错在极限根本不存在（§3习题2）。
- **把单调有界定理用到非单调数列上**：定理要求单调性这一前提，仅有界不足以使用；同理 lim aₙ = +∞ 只要求最终超过任意给定的 M，不要求单调。

## Worked Example / 工作示例

**例（ε-N 证明，对应本章 §1例3）** 按定义证明 lim 3n²/(n² − 3) = 3。

**第一步：化简差值。** 当 n ≥ 3 时 n² − 3 > 0，于是

|3n²/(n² − 3) − 3| = |(3n² − 3(n² − 3))/(n² − 3)| = 9/(n² − 3)。

**第二步：适当放大。** 目的是把分母换成更容易解出 n 的形式。当 n ≥ 3 时 n² − 3 ≥ n²/2，当 n ≥ 18 时 n² ≥ n，故

9/(n² − 3) ≤ 18/n² ≤ 18/n (n ≥ 18)。

这里做了两次放大：先用 n²/2 替换 n² − 3，再用 n 替换 n²。放大是「适当」的——结果 18/n 关于 n 递减且趋于 0，故对任给 ε 都能定出 N。

**第三步：解出 N。** 对任给的 ε > 0，取 N = max{18, 18/ε}。则当 n > N 时 n ≥ 18 且 n > 18/ε，于是

|3n²/(n² − 3) − 3| = 9/(n² − 3) ≤ 18/n < ε。

按定义1，即得 lim 3n²/(n² − 3) = 3。∎

**验证与说明**：取 N 时把放大过程用到的全部条件（n ≥ 3 与 n ≥ 18）一并纳入 max，否则放大的合理性在小的 n 处不成立。N 不必是正整数（定义只要求 N 是正数），也不必由 ε 唯一确定——取 19/ε 或更大同样可行。书写时通常先写「分析」（前两步）再写「证」（第三步），因为放大过程中的条件必须在最终取 N 时可见。

## Key Takeaways / 关键结论

1. **ε-N 定义的两个自由度**：ε 任意（可换成 ε/2、3ε、ε² 或限定 ε < 1），N 只需存在（可任意放大，n > N 与 n ≥ N 等价）。
2. **定义1′ 是理解收敛的最佳图像**：邻域之外至多有限项，因此收敛性与极限值对改变有限项免疫。
3. **六条性质成链条使用**：唯一性与有界性是四则运算证明积与倒数的前提，保号性则是倒数部分的依据。
4. **保不等式性只给 ≤**：严格不等式无法传递到极限；反之由 a < b 可推出 n 充分大时 aₙ < bₙ，方向是一定的。
5. **单调有界定理把存在性问题化为确界问题**：递增有上界时极限恰为 sup{aₙ}，递减有下界时恰为 inf{aₙ}。
6. **柯西准则的价值在于「无需外部候选值」**：它只看数列内部两项之差；由此可证无限十进小数的不足近似数列必收敛（例7）。
7. **e = lim(1 + 1/n)ⁿ 由二项式展开 + 单调有界得到**：展开后逐项比较得严格递增，再用几何级数估出上界 3。它是第3章第二个重要极限的来源。
