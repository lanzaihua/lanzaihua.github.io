## Core Idea / 核心思想

本章把数列极限的 ε-N 语言推广成 ε-M 与 ε-δ 语言，覆盖 x → +∞、x → −∞、x → ∞、x → x₀、x → x₀⁺、x → x₀⁻ 六种类型，并证明其性质与数列极限逐条平行。枢纽是**归结原则（海涅定理）**：函数极限存在当且仅当所有趋于 x₀ 的数列对应的函数值数列都收敛于同一值——它把函数极限还原为已解决的数列极限问题。由此导出两个重要极限 lim(sin x/x) = 1 与 lim(1 + 1/x)ˣ = e，以及无穷小量阶的比较这套计算工具。

## Frameworks Introduced / 核心框架

- **定义1（x → +∞ 的 ε-M 定义）**：设 f 定义在 [a, +∞) 上，A 为定数。若对任给 ε > 0 存在正数 M（≥ a），使得当 x > M 时有 |f(x) − A| < ε，则称 f 当 x → +∞ 时以 A 为极限，记 lim_{x→+∞} f(x) = A。
  - 关键点：M 相当于 ε-N 中的 N，但「x > M」覆盖全体实数而非仅正整数。几何上：任给带形区域 A − ε < y < A + ε，曲线在直线 x = M 右侧的部分全落在带内。把「x > M」改为「x < −M」或「|x| > M」即得 x → −∞ 与 x → ∞ 的定义；若 f 定义在 U(∞) 上，则 lim_{x→∞} f(x) = A ⇔ lim_{x→+∞} f(x) = lim_{x→−∞} f(x) = A。
- **定义2（x → x₀ 的 ε-δ 定义）**：设 f 在点 x₀ 的某个空心邻域 U°(x₀; δ′) 内有定义，A 为定数。若对任给 ε > 0 存在正数 δ（< δ′），使得当 0 < |x − x₀| < δ 时 |f(x) − A| < ε，则称 f 当 x → x₀ 时以 A 为极限，记 lim_{x→x₀} f(x) = A。
  - 何时用：考察函数在一点附近的局部趋势，是全书使用频率最高的定义。
  - 关键点：条件 0 < |x − x₀| 意味着**不考虑 f 在 x₀ 处是否有定义或取什么值**（§1例3 中 f 在 x = 2 无定义而极限存在为 4）。等价邻域写法：任给 ε > 0 存在 δ > 0 使 f(U°(x₀; δ)) ⊂ U(A; ε)。几何上：任给宽 2ε 的横带必存在宽 2δ 的竖带，曲线在竖带内的部分落在横带内，但点 (x₀, f(x₀)) 可能例外。
- **定义3（单侧极限）**：设 f 在 U₊(x₀; δ′) 或 U°₋(x₀; δ′) 上有定义。若对任给 ε > 0 存在正数 δ（< δ′），使得当 x₀ < x < x₀ + δ（或 x₀ − δ < x < x₀）时 |f(x) − A| < ε，则称 A 为 f 当 x → x₀⁺（或 x → x₀⁻）时的**右（左）极限**，记 f(x₀ + 0) = lim_{x→x₀⁺} f(x)，f(x₀ − 0) = lim_{x→x₀⁻} f(x)。
  - 何时用：分段函数在分界点、函数在定义区间端点（如 √(1 − x²) 在 x = ±1）。
- **定理3.1（双侧与单侧的关系）**：lim_{x→x₀} f(x) = A ⇔ lim_{x→x₀⁺} f(x) = lim_{x→x₀⁻} f(x) = A。
  - 何时用：**证极限不存在比证存在更常用**。sgn x 在 x = 0 处左右极限为 −1 与 1，故 lim_{x→0} sgn x 不存在。
- **定理3.2~3.7（函数极限的性质，以 x → x₀ 为代表；其余五种类型作相应修改即可）**：
  - **3.2 唯一性**：极限存在则唯一。
  - **3.3 局部有界性**：极限存在则 f 在 x₀ 的某空心邻域上有界。注意这是**局部**性质，不含整体有界性。
  - **3.4 局部保号性**：若 lim f(x) = A > 0（或 < 0），则对任何正数 r < A（或 r < −A）存在 U°(x₀)，使其中一切 x 有 f(x) > r > 0（或 f(x) < −r < 0）。取 ε = A − r；应用时常取 r = A/2。
  - **3.5 保不等式性**：两个极限都存在且在某个 U°(x₀; δ′) 上 f(x) ≤ g(x)，则 lim f(x) ≤ lim g(x)。结论同样只能是 ≤。
  - **3.6 迫敛性**：lim f(x) = lim g(x) = A 且在某个 U°(x₀; δ′) 上 f(x) ≤ h(x) ≤ g(x)，则 lim h(x) = A。
  - **3.7 四则运算法则**：两极限都存在时 f ± g 与 f·g 的极限存在且等于对应运算；若 lim g(x) ≠ 0，则 f/g 的极限存在且等于商的极限之比。
- **定理3.8（复合函数极限）**：设 lim_{x→x₀} f(x) = u₀，lim_{u→u₀} g(u) = A，且存在 x₀ 的某空心邻域 U°(x₀; δ)，使得对任意 x ∈ U°(x₀; δ) 有 f(x) ≠ u₀，则 lim_{x→x₀} g(f(x)) = A。
  - 关键点：**条件 f(x) ≠ u₀ 不可省略**，否则 g 在 u₀ 处的值会干扰结论。作变量代换（如 §4例1 令 t = π − x）时用它。
- **定理3.9（归结原则 / 海涅定理）**：设 f 在 U°(x₀; δ′) 上有定义。lim_{x→x₀} f(x) 存在的充要条件是：对任何含于 U°(x₀; δ′) 且以 x₀ 为极限的数列 {xₙ}，lim f(xₙ) 都存在且相等。
  - 何时用：证**极限不存在**——找出两个数列给出不同极限，或一个数列使 f(xₙ) 发散；也用于把函数极限的命题搬回数列极限去证。
  - 关键点：充分性用反证——若极限不是 A，则存在 ε₀ > 0，对每个 δ = δ′/n 可取到 xₙ 使 0 < |xₙ − x₀| < δ′/n 而 |f(xₙ) − A| ≥ ε₀，与假设矛盾。标准反例：lim_{x→0} sin(1/x) 不存在，取 xₙ′ = 1/(2nπ + π/2) 得 f(xₙ′) = 1，取 xₙ″ = 1/(2nπ) 得 f(xₙ″) = 0。
- **定理3.10（单侧极限的加强归结原则）**：设 f 在 U°₊(x₀) 上有定义。lim_{x→x₀⁺} f(x) = A 的充要条件是：对任何以 x₀ 为极限的**递减**数列 {xₙ} ⊂ U₊(x₀)，有 lim f(xₙ) = A。充分性的反证中要对 δ 的取法作修改，以保证所找到的数列能**递减地**趋于 x₀。
- **定理3.11（单调有界函数的单侧极限）**：设 f 为定义在 U₊(x₀) 上的单调有界函数，则 lim_{x→x₀⁺} f(x) 存在。与数列的单调有界定理平行：设 f 递增，取 A = inf_{U₊(x₀)} f(x)，对任给 ε > 0 由下确界定义取 x′ 使 f(x′) < A + ε，令 δ = x′ − x₀，则 x ∈ (x₀, x′) 时 A − ε < f(x) ≤ f(x′) < A + ε。
- **定理3.12（函数极限的柯西准则）**：设 f 在 U°(x₀; δ′) 上有定义。lim_{x→x₀} f(x) 存在的充要条件是：任给 ε > 0 存在正数 δ（< δ′），使得对任何 x′, x″ ∈ U°(x₀; δ) 有 |f(x′) − f(x″)| < ε。
  - 何时用：不预知极限值 A 时判断存在性。
  - 关键点：充分性取 xₙ → x₀，先证 {f(xₙ)} 是柯西列因而收敛于某 A，再令 n → ∞ 得 |f(x) − A| ≤ ε，最后用归结原则。否命题形式：存在 ε₀ > 0，对任何 δ > 0 总可找到 x′, x″ ∈ U°(x₀; δ) 使 |f(x′) − f(x″)| ≥ ε₀。
- **两个重要极限**：
  - **lim_{x→0} (sin x)/x = 1**：由 §1例4 的不等式 sin x < x < tan x (0 < x < π/2) 除以 sin x 得 cos x < (sin x)/x < 1；用 −x 代 x 知该式对 −π/2 < x < 0 也成立，故对一切 0 < |x| < π/2 成立。由 lim_{x→0} cos x = 1 与迫敛性即得。
  - **lim_{x→∞} (1 + 1/x)ˣ = e**：等价于同时证明 x → +∞ 与 x → −∞ 两个极限都等于 e。正向利用数列极限 lim(1 + 1/n)ⁿ = e，对给定 ε 取 X = N，当 x > X 时令 n = [x]，用 (1 + 1/(n+1))ⁿ < (1 + 1/x)ˣ < (1 + 1/n)^{n+1} 夹逼；负向作代换 x = −y，把 (1 + 1/x)ˣ 化为 (1 + 1/(y−1))^{y−1}·(1 + 1/(y−1))，由 y → +∞ 得极限 e。等价形式 lim_{α→0} (1 + α)^{1/α} = e（令 α = 1/x 即可互推），代换时更常用。
- **无穷小量的阶**：设 x → x₀ 时 f, g 均为无穷小量。f = O(g) 指存在 L 使 |f(x)/g(x)| ≤ L 在某个 U°(x₀) 上成立；f = o(g) 指 lim f(x)/g(x) = 0，称 f 是 g 的**高阶**无穷小量；**同阶**指存在正数 K, L 使 K ≤ |f/g| ≤ L（特别当 lim f/g = c ≠ 0 时）；**等价**指 lim f/g = 1，记 f ∼ g。无穷小量记 f = o(1)，有界量记 f = O(1)。
  - 关键点：o 与 O 的等号表示「属于某个函数类」而非通常的相等。若 f/g 与 g/f 都不是有界量，则两个无穷小量**不能进行阶的比较**（如 x → 0 时的 x sin(1/x) 与 x²）。
- **定理3.13（等价无穷小量代换）**：设 f, g, h 在 U°(x₀) 上有定义且 f ∼ g (x → x₀)。(i) 若 lim f(x)h(x) = A 则 lim g(x)h(x) = A；(ii) 若 lim h(x)/f(x) = B 则 lim h(x)/g(x) = B。证明只用 lim g/f = 1 与四则运算。**只允许对相乘或相除的因式作替换**。
- **定理3.14（无穷大量与无穷小量互化）**：(i) 设 f 在 U°(x₀) 上有定义且不为 0，若 f 是无穷小量则 1/f 是无穷大量；(ii) 若 g 是无穷大量则 1/g 是无穷小量。由此对无穷大量的研究可归结为无穷小量。
- **曲线的渐近线（定义4）**：若曲线 C 上的动点 P 沿曲线无限远离原点时 P 与某定直线 L 的距离趋于 0，则称 L 为 C 的**渐近线**。**斜渐近线 y = kx + b** 由 k = lim_{x→+∞} f(x)/x、b = lim_{x→+∞} (f(x) − kx) 相继求出；**垂直渐近线 x = x₀** 当 lim_{x→x₀} f(x) = ∞（或单侧为 ∞）时成立。先求 k（无有限极限则无斜渐近线），再求 b；垂直渐近线的候选点先看分母零点与无定义点。

## Key Concepts / 核心概念

- **函数极限的六种类型**：lim_{x→+∞}、lim_{x→−∞}、lim_{x→∞}、lim_{x→x₀}、lim_{x→x₀⁻}、lim_{x→x₀⁺}；性质通用，记号各异。
- **U(∞) 与 U°(x₀)**：U(∞) = {x | |x| > M}；U°(x₀; δ) = {x | 0 < |x − x₀| < δ}。
- **无穷小量（infinitesimal）**：lim_{x→x₀} f(x) = 0。任何无穷小量必是有界量。
- **有界量（bounded quantity）**：g 在某 U°(x₀) 上有界。
- **无穷大量（infinitely large quantity）**：对任给 G > 0 存在 δ > 0，当 x ∈ U°(x₀; δ) 时 |f(x)| > G，记 lim f(x) = ∞；把 |f(x)| > G 换成 f(x) > G 或 f(x) < −G 得 +∞ 与 −∞。定义3 把以 ∞、±∞ 为非正常极限的函数统称无穷大量。
- **无穷小量与极限的关系**：lim_{x→x₀} f(x) = A ⇔ f(x) − A 是当 x → x₀ 时的无穷小量。
- **高阶 / 同阶 / 等价无穷小量**：核心是考察比值 f/g 的极限或界。
- **非初等函数的极限实例**：狄利克雷函数 D(x) 在任一点 x₀ 处极限不存在；黎曼函数 R(x) 在 [0,1] 上任一点满足 lim_{x→x₀} R(x) = 0。

## Mental Models / 思维模型

- **把 M 与 δ 看成同一角色的两种戏服**：M 控制「x 离原点足够远」，δ 控制「x 离 x₀ 足够近」，确定方式与 ε-N 中的 N 完全同构。
- **证极限不存在时优先动用归结原则**：只要能构造两个趋于 x₀ 的数列使 f 的值数列极限不同（或一个发散），结论立刻成立。lim_{x→0} sin(1/x)、lim_{x→0} D(x) 都用此法。
- **遇到 1^∞ 型幂式极限先写成 [(1 + u)^{1/u}]^{指数}**：(1 + 1/x)ˣ 与 (1 + 2x)^{1/x} 一类问题统一用 (1 + α)^{1/α} → e。
- **看到「x₀ 处的函数值」立刻分开处理**：定义只关心空心邻域；分段函数在分界点必须走单侧极限。
- **求渐近线按「垂直 → 斜」的顺序扫描**：先用分母零点找垂直渐近线，再算 f(x)/x 与 f(x) − kx 找斜渐近线。

## Anti-patterns / 常见错误

- **用 f(x₀) 的值判断 lim_{x→x₀} f(x)**：定义2 的条件是 0 < |x − x₀| < δ；§1例3 的 f(x) = (x² − 4)/(x − 2) 在 x = 2 无定义，但极限存在且为 4。
- **在加减项中随意使用等价无穷小替换**：tan x ∼ x、sin x ∼ x 都成立，但 lim (tan x − sin x)/x³ ≠ lim (x − x)/x³ = 0；应先提取因式（tan x − sin x = (sin x/cos x)(1 − cos x)）再替换。
- **由 lim |f(x)| = |A| 反推 lim f(x) = A**：一般只能得 |f(x)| → |A|，不能得符号信息；只有 A = 0 时反过来才成立。
- **只验证一个数列就断言函数极限存在**：归结原则要求「任何」以 x₀ 为极限的数列都给出同一极限，单个数列只够用来否定。
- **忽略复合函数极限定理中 f(x) ≠ u₀ 的条件**：若 f 在 x₀ 附近恒取 u₀，则 g(f(x)) 恒为 g(u₀)，与 lim_{u→u₀} g(u) 无关。
- **把「无界」等同于「无穷大量」**：f(x) = x sin x 在 U(+∞) 上无界（取 xₙ = 2nπ + π/2），但取 xₙ = 2nπ 得 f(xₙ) = 0，故 lim_{x→+∞} x sin x ≠ ∞。
- **在 x → x₀ 的题里用单侧极限代替双侧极限**：左右极限都存在但不相等时（如 sgn x）双侧极限不存在。

## Worked Example / 工作示例

**例（ε-δ 证明，对应本章 §1例5）** 按定义证明 lim_{x→1} (x² − 1)/(2x² − x − 1) = 2/3。

**第一步：化简差值。** 当 x ≠ 1 时，分子 x² − 1 = (x − 1)(x + 1)，分母 2x² − x − 1 = (2x + 1)(x − 1)，故

(x² − 1)/(2x² − x − 1) = (x + 1)/(2x + 1)，

从而

|(x² − 1)/(2x² − x − 1) − 2/3| = |(x + 1)/(2x + 1) − 2/3| = |3(x + 1) − 2(2x + 1)| / (3|2x + 1|) = |x − 1| / (3|2x + 1|)。

**第二步：限制 x 的范围，把分母控制住。** 先限制 0 < |x − 1| < 1，此时 0 < x < 2，于是 2x + 1 > 1，即 |2x + 1| > 1。代入上式得

|(x² − 1)/(2x² − x − 1) − 2/3| < |x − 1|/3。

**第三步：解出 δ。** 对任给的 ε > 0，取 δ = min{3ε, 1}。则当 0 < |x − 1| < δ 时，|x − 1| < 1（第二步的限制成立）且 |x − 1| < 3ε，于是

|(x² − 1)/(2x² − x − 1) − 2/3| < |x − 1|/3 < (3ε)/3 = ε。

按定义2，即得 lim_{x→1} (x² − 1)/(2x² − x − 1) = 2/3。∎

**验证与说明**：δ = min{3ε, 1} 是 ε-δ 证明的标准结构——先把 δ 限制在便于估算的范围内（此处 |x − 1| < 1），在该范围内把 |f(x) − A| 放大成 C|x − x₀| 的形状，再令 C|x − x₀| < ε 反解出 |x − x₀| < ε/C，最后用 min 把两个要求合并。定义2 只要求 δ 存在，取得更小（如 min{ε, 1}）同样有效。另注意 x = 1 处原函数无定义，但定义2 只要求 f 在某个空心邻域内有定义，故不影响结论——这正是条件 0 < |x − x₀| 的意义。

## Key Takeaways / 关键结论

1. **六种极限类型共用一套量词结构**：ε 恒为「任给」，控制量（M 或 δ）恒为「存在」。
2. **f 在 x₀ 处是否有定义、取什么值，与 lim_{x→x₀} f(x) 无关**，定义只使用空心邻域。
3. **双侧极限存在 ⇔ 左右极限存在且相等**（定理3.1），这是证明极限不存在的最常用手段。
4. **归结原则（定理3.9）是本章枢纽**：函数极限的所有性质都可通过它从数列极限搬来，同时它是构造反例的利器。
5. **两个重要极限是后续计算的引擎**：lim (sin x)/x = 1 依赖不等式 sin x < x < tan x 与迫敛性；lim (1 + 1/x)ˣ = e 依赖数列版本与夹逼，等价形式 lim (1 + α)^{1/α} = e 更适合代换。
6. **等价无穷小量代换只对乘除因式有效**（定理3.13），加减项必须先变形提取因式。
7. **无穷大量与无穷小量互为倒数**（定理3.14）；无穷大量必无界，但无界函数未必是无穷大量。
