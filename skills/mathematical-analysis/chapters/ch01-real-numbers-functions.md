## Core Idea / 核心思想

本章给出全书唯一的公理基础——**确界原理**：非空有上界的实数集必有上确界。实数系的完备性由此进入分析，极限的存在性判定、单调有界定理乃至连续函数的全部性质都靠它支撑。同时把「函数」从中学的公式观念提升为「定义域 + 对应法则」的集合论对象，并建立有界、单调、奇偶、周期这套后续反复调用的性态分类。

## Frameworks Introduced / 核心框架

- **定义2（上确界 sup，§2）**：设 S ⊂ ℝ。若数 η 满足 (i) 对一切 x ∈ S 有 x ≤ η；(ii) 对任何 α < η 存在 x₀ ∈ S 使 x₀ > α，则称 η 为 S 的**上确界**，记 η = sup S。
  - 何时用：凡要证「某数是最小上界」必须逐条验证 (i)(ii)。
  - 关键点：(ii) 是「最小性」的载体，等价说法是「η − ε 不再是上界」。把两条的不等号整体反向即得**下确界** ξ = inf S（§2定义3）。sup 与 inf 若存在必唯一，且 inf S ≤ sup S。

- **定理1.1（确界原理）**：设 S 为非空数集。若 S 有上界则必有上确界；若 S 有下界则必有下确界。
  - 何时用：凡需把某个上界「压到最小」的证明，第一步往往是取 c = sup E（如 §3例2 证 √a 存在）。
  - 关键点：证明用十进小数逼近——把 [n₀, n₀+1) 不断 10 等分，第 k 步选 n_k ∈ {0,…,9} 使「∀x ∈ S, x < n₀.n₁…n_k + 10⁻ᵏ」且「∃a_k ∈ S, a_k ≥ n₀.n₁…n_k」。令 η = n₀.n₁n₂…，(i) 用 x > η 时取 x 的 k 位不足近似导出与上式矛盾；(ii) 用 η 的不足近似夹出 a′ > α。这是本书**唯一不加证明的公理**；推广形式：任一非空数集必有确界（正常的或非正常的 ±∞）。

- **定理1.2（严格单调必有反函数）**：设 y = f(x), x ∈ D 严格增（减），则 f 必有反函数 f⁻¹，且 f⁻¹ 在 f(D) 上也严格增（减）。
  - 何时用：判断反函数存在只需验证严格单调，不必解出显式表达式。
  - 关键点：唯一性靠严格单调——x₁ ≠ x 时，x₁ < x 给 f(x₁) < y，x₁ > x 给 f(x₁) > y，总之 f(x₁) ≠ y。反函数的单调性设 y₁ < y₂ 反推 x₁ < x₂。

- **实数指数幂（§3定义2）**：对 a > 0, a ≠ 1 与无理数 x 规定 aˣ = sup{aʳ | r < x, r 为有理数}（a > 1）或 inf{aʳ | r < x, r 为有理数}（0 < a < 1）。
  - 何时用：证指数函数单调性、第3章例4 的 aˣ → 1 (x → 0) 都要回到这个确界式。
  - 关键点：先由有理数稠密性取 r₀ > x 说明该数集有上界，确界原理才保证右边是确定的数。把 r < x 改为 r ≤ x 后有理与无理情形可统一表示。

- **绝对值与三角形不等式**：||a| − |b|| ≤ |a ± b| ≤ |a| + |b|；|ab| = |a||b|；|a/b| = |a|/|b| (b ≠ 0)；|a| < h ⇔ −h < a < h。
  - 何时用：一切 ε 论证的基本工具，把 |a − b| < ε 展开成区间夹逼是最常用的一步。
  - 关键点：右半由 −(|a| + |b|) ≤ a + b ≤ |a| + |b| 加性质3 得；左半由 |a| = |a − b + b| ≤ |a − b| + |b| 得。

## Key Concepts / 核心概念

- **实数（real number）**：有理数与无理数统称实数；约定有限小数写成 9 的循环形式（如 2.001 = 2.000999…），使每个实数有唯一的无限小数表示。
- **阿基米德性（Archimedean property）**：对任何 b > a > 0 存在正整数 n 使 na > b。
- **稠密性（density）**：任意两不等实数之间必有实数，且既有有理数也有无理数。
- **邻域（neighborhood）**：U(a; δ) = (a − δ, a + δ)；**空心邻域** U°(a; δ) = {x | 0 < |x − a| < δ}，不含 a 本身。另有右邻域 U₊(a; δ) = [a, a + δ)、左邻域 U₋(a; δ) = (a − δ, a]、∞ 邻域 U(∞) = {x | |x| > M}。
- **有界集（bounded set）**：既有上界又有下界的数集；有限区间有界，无限区间无界。
- **不足近似与过剩近似**：x_n = a₀.a₁…a_n，x̄_n = x_n + 10⁻ⁿ；x_n 随 n 不减，x̄_n 随 n 不增。
- **函数（function）**：给定实数集 D, M 与法则 f，使每个 x ∈ D 对应唯一的 y ∈ M，记 f : D → M；D 为定义域，f(D) 为值域。定义域与法则是确定函数的两个要素。
- **复合函数（composite function）**：y = f(g(x)), x ∈ E*，E* = {x | g(x) ∈ D} ∩ E；E* ≠ ∅（即 D ∩ g(E) ≠ ∅）是能复合的充要条件。
- **反函数（inverse function）**：f 在 D 与 f(D) 间一一对应时存在 f⁻¹，且 f⁻¹(f(x)) ≡ x、f(f⁻¹(y)) ≡ y。
- **初等函数（elementary function）**：由常量、幂、指数、对数、三角、反三角六类基本初等函数经有限次四则运算与复合所得。
- **狄利克雷函数与黎曼函数**：D(x) = 1（x 有理）、0（x 无理）；R(x) = 1/q（x = p/q 为既约真分数）、0（x = 0, 1 或无理数）。两者都非初等函数。

## Mental Models / 思维模型

- **把「最小上界」看成一次逼近过程的极限**：M 是上界说明「压得住」，α < η 时能找到 x₀ > α 说明「压不更低」。任何确认界的题都同时做这两件事。
- **遇到「求某数的存在性」先做确界**：从 √a 的存在性到无理指数幂，都是先构造数集、用确界原理取到候选值，再验证它恰好满足要求。
- **把「界可能取不到」当成默认情形**：sup S ∈ S 只是特例；凡要用 max S 的地方先问「确界是否属于集合」。
- **把函数看成「定义域 + 法则」而非一条公式**：f(x) = 1, x ∈ ℝ 与 g(x) = 1, x ∈ ℝ∖{0} 是不同函数；而 |x| 与 √(x²) 是同一个函数。

## Anti-patterns / 常见错误

- **由 f(x) ≤ M 断定 M = sup f**：这只说明 M 是上界。如 f(x) = x 在 (0,1) 上，M = 5 也是上界，但 sup f = 1。
- **以为确界一定属于集合**：inf{1/n} = 0 ∉ {1/n}；sup{x | x² < 2} = √2 甚至不是有理数。
- **由 a < b + ε 对一切 ε > 0 推出 a < b**：正确结论是 a ≤ b（§1例2）。同理 aₙ < bₙ 只能推出 lim aₙ ≤ lim bₙ，不能推出严格不等。
- **把 sup(A ∪ B) = max{sup A, sup B} 误推广到任意并集或交集**：这条结论依赖 S = A ∪ B 的特定结构（例5）。
- **忘记复合的前提**：以外函数 f(u) = √u, u ∈ [0, +∞) 与内函数 g(x) = −x² − 1 复合不成立，因为 [0, +∞) ∩ (−∞, −1] = ∅。
- **误以为单调函数一定有反函数**：y = [x] 在 ℝ 上递增但不严格递增（[0] = [1/2] = 0），故无反函数。
- **用一点的值否定奇偶性**：证 f(x) = sin x + cos x 非奇非偶需指出某点使两条等式同时不成立；只算 f(0) ≠ 0 不足以排除偶函数。

## Worked Example / 工作示例

**例（对应本章例2）** 设 S = {x | x 为区间 (0,1) 上的有理数}。按定义验证 sup S = 1，inf S = 0。

**验证 sup S = 1**，需验证定义2 的两条。

**(i) 1 是上界。** 对一切 x ∈ S，按 S 的构成有 0 < x < 1，故 x ≤ 1，即 x ≤ η（η = 1）成立。

**(ii) 1 是最小上界。** 任取 α < 1，要找 x₀ ∈ S 使 x₀ > α。分两种情形：

- α ≤ 0：任取 x₀ ∈ S（如 x₀ = 1/2），则 x₀ = 1/2 > 0 ≥ α，得 x₀ > α。
- 0 < α < 1：由有理数在实数中的稠密性，开区间 (α, 1) 内必有有理数 x₀。此时 0 < x₀ < 1 且 x₀ 有理，故 x₀ ∈ S，且 x₀ > α。

两条验证完毕，故 sup S = 1。

**验证 inf S = 0 同理**：对一切 x ∈ S 有 x > 0，故 0 是下界；又对任何 β > 0，由稠密性在 (0, min{β, 1}) 内可取有理数 x₀ ∈ S 使 x₀ < β。故 inf S = 0。

**要点与验证**：关键在 α ≤ 0 与 α > 0 必须分开——前者任取元素即可，后者才需要稠密性。另注意 1 ∉ S、0 ∉ S，可见确界可以不属于所论数集；若换成 [0,1]，则 sup 与 inf 分别为 1 和 0 且都属于集合，这正是例3 的结论：sup S ∈ S ⇔ sup S = max S。

## Key Takeaways / 关键结论

1. **确界原理是全书公理**：非空有上（下）界的实数集必有上（下）确界，一切极限存在性定理最终都回溯到它。
2. **验证确界必须做两件事**：证它是界，证它是最小的界（inf 则为最大的界），缺一不可。
3. **确界未必属于集合**，sup S ∈ S 恰好等价于 sup S = max S。
4. **实数六条基本性质**：四则运算封闭、有序性、传递性、阿基米德性、稠密性、与数轴一一对应。
5. **严格单调 ⇒ 存在反函数**，且反函数同向严格单调；反之不成立。
6. **无理指数幂用确界定义**：aˣ = sup_{r<x} aʳ (a > 1)，使有理指数幂的性质被完整继承。
7. **函数相等的判据是定义域与对应法则同时相同**，表示形式不同不构成差异。
