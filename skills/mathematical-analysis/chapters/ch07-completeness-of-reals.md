# 第七章 实数的完备性 (Completeness of the Real Numbers)

> 《数学分析》第六版（上册）· 华东师范大学数学科学学院 编
>
> 📝 **本章作业**：作业集里**没有** 7-x 的题——本章练习回教材 `习题7.1`、`习题7.2`（教材书末 p301 有部分答案）。

## Core Idea / 核心思想

实数集最本质的性质不是"有序"，而是**完备性（completeness）**：数轴上没有"洞"。本章把这一性质提炼为六个互相等价的定理——确界原理、单调有界定理、区间套定理、有限覆盖定理、聚点定理（及致密性定理）、柯西收敛准则——并给出它们之间的循环证明路线。它们的真正价值不在于单独某一条，而在于**面对不同问题时你可以挑最好用的那一条**：要"存在某个点"，用区间套；要把局部性质拼成整体性质，用有限覆盖；要判断数列收敛而不必预知极限，用柯西准则。

## Frameworks Introduced / 核心框架

- **定理1.1（确界原理）**：非空有上界的数集必有上确界；非空有下界的数集必有下确界。
  - 何时用：需要论证某个数"存在"（上确界、下确界、公共点）的出发点。
  - 关键点：这是本书**第一个**被证明的完备性命题，其他五条都可由它推出。有理数集上它不成立（习题7.1第4题）。
- **定理2.9（单调有界定理）**：单调有界数列必收敛。
  - 何时用：数列有单调性可验证时，用它直接断言收敛，无需估计极限值。
  - 关键点：只保证"存在"，不给极限值；证明区间套定理就靠它。
- **定理7.1（区间套定理）**：若闭区间列 $\{[a_n,b_n]\}$ 满足 $[a_n,b_n]\supset[a_{n+1},b_{n+1}]$ 且 $\lim_{n\to\infty}(b_n-a_n)=0$，则存在**唯一**一点 $\xi$ 使 $\xi\in[a_n,b_n]$（$n=1,2,\dots$）。
  - 何时用：用二分法构造"越来越小的闭区间"来搜索某个点（方程的根、聚点、覆盖失败的区间）。
  - 关键点：两个条件缺一不可——必须是**闭**区间、长度必须趋于 0。开区间列 $\{(0,\frac1n)\}$ 无公共点。
- **推论（区间套的邻域性质）**：若 $\xi$ 是区间套 $\{[a_n,b_n]\}$ 确定的点，则对任意 $\varepsilon>0$ 存在 $N$，当 $n>N$ 时 $[a_n,b_n]\subset U(\xi;\varepsilon)$。
  - 何时用：把"区间套的公共点落在某个邻域里"变成合法的一步——这是区间套定理能推出另外几条定理的**唯一通道**。
- **定理7.2（魏尔斯特拉斯聚点定理）**：实轴上任一**有界无限**点集 $S$ 至少有一个聚点。（$\xi$ 是 $S$ 的聚点 $\iff$ $\xi$ 的任意邻域含 $S$ 中无穷多个点。）
  - 何时用：需要从点集里"捞出"一个收敛子列或一个极限点时。
  - 关键点：证法一不断二等分区间，保留"含 $S$ 中无穷多点"的一半，得到区间套；证法二直接调用致密性定理。致密性定理只是它的特殊情形（把数列的项看成点）。
- **定理7.3（海涅–博雷尔有限覆盖定理）**：设 $H$ 为闭区间 $[a,b]$ 的一个（无限）开覆盖，则从 $H$ 中可选出**有限**个开区间覆盖 $[a,b]$。
  - 何时用：要把逐点的局部结论升级为整个区间上的整体结论（有界性、一致连续性、根的存在性）。
  - 关键点：反证 + 二分。结论**只对闭区间成立**；$(0,1)$ 的开覆盖 $\{(1/(n+1),\,1/n)\}$ 就选不出有限子覆盖。
- **定理2.10（致密性定理）**：有界数列必有收敛子列。
- **定理2.11（柯西收敛准则）**：数列 $\{x_n\}$ 收敛 $\iff$ 对任意 $\varepsilon>0$ 存在 $N$，当 $m,n>N$ 时 $|x_m-x_n|<\varepsilon$。
  - 何时用：无法预知极限值、但能控制"项与项之间"的距离时。
  - 关键点：**只对完备空间成立**；有理数列可满足柯西条件却不收敛（逼近 $\sqrt2$ 的有理数列）。
- **等价性路线图**：$\text{确界原理}\Rightarrow\text{单调有界}\Rightarrow\text{区间套}\Rightarrow\text{有限覆盖}\Rightarrow\text{聚点}\Rightarrow\text{柯西准则}\Rightarrow\text{确界原理}$。
  - 已给：$1\Rightarrow2$（定理2.9）、$2\Rightarrow3$（定理7.1）、$3\Rightarrow4$（定理7.3）；$4\Rightarrow5$ 与 $5\Rightarrow6$ 留作习题7.1第8、9题；$6\Rightarrow1$ 见例3。
  - 关键点：六条**两两等价**。写证明时先想清"手头这条最擅长产出什么"。
- **定义2（数列的聚点）**：若数 $a$ 的任一邻域含数列 $\{x_n\}$ 中无穷多个**项**，称 $a$ 是数列的聚点。
  - 关键点：与**点集**的聚点不同——数列的聚点就是它某个收敛子列的极限，重复取值的项分开计数（$\{\sin\frac{n\pi}{4}\}$ 作为数列有 5 个聚点，作为点集没有聚点）。
- **定理7.4**：有界数列至少有一个聚点，且**存在最大聚点与最小聚点**。
- **定义2′（上极限、下极限）**：有界数列的最大聚点 $\overline{A}=\varlimsup_{n\to\infty}x_n$ 称为上极限，最小聚点 $\underline{A}=\varliminf_{n\to\infty}x_n$ 称为下极限。
- **定理7.7（上极限的 $\varepsilon$ 刻画）**：$\overline{A}=\varlimsup x_n$ $\iff$ 任给 $\varepsilon>0$，**（i）**存在 $N$，当 $n>N$ 时 $x_n<\overline{A}+\varepsilon$；**（ii）**存在子列 $\{x_{n_k}\}$ 使 $x_{n_k}>\overline{A}-\varepsilon$。
  - 何时用：验证某个数是上极限——(i) 说明"上方至多有限个项越界"，(ii) 说明"下方有无穷多项接近它"。
  - 关键点：把定理7.7′的形式记住更省事：对任何 $\alpha>\overline{A}$，$\{x_n>\alpha\}$ 至多有限项；对任何 $\beta<\overline{A}$，$\{x_n>\beta\}$ 有无穷多项。下极限把不等号反向。
- **定理7.6**：$\lim_{n\to\infty}x_n=A$ $\iff$ $\varlimsup x_n=\varliminf x_n=A$。上下极限相等正是"极限存在"的判据。
- **定理7.8（保不等式性）**：若存在 $N_0$，当 $n>N_0$ 时 $a_n\le b_n$，则 $\varlimsup a_n\le\varlimsup b_n$，$\varliminf a_n\le\varliminf b_n$。
- **定理7.9**：$\overline{A}=\lim_{n\to\infty}\sup_{k\ge n}\{x_k\}$，$\underline{A}=\lim_{n\to\infty}\inf_{k\ge n}\{x_k\}$。

## Key Concepts / 核心概念

- **完备性（completeness）**：实数集相对有理数集多出的那条性质——凡"应该收敛"的都被收敛到，表现为六条等价定理。
- **上确界（supremum）**：数集 $S$ 的最小上界，记 $\sup S$。
- **区间套（nested intervals）**：闭区间列前一个包含后一个，且长度趋于 0。
- **聚点（limit point / accumulation point）**：任意邻域含该集合无穷多个点的点。
- **开覆盖（open cover）**：一族开区间，使 $S$ 中每点至少落在一个开区间内。
- **致密性（compactness in the sequential sense）**：有界数列必有收敛子列。
- **柯西列（Cauchy sequence）**：项与项的距离最终可任意小，即 $\forall\varepsilon>0,\exists N,m,n>N\Rightarrow|x_m-x_n|<\varepsilon$。
- **上极限（limit superior）**：有界数列的最大聚点，记 $\varlimsup_{n\to\infty}x_n$。
- **下极限（limit inferior）**：有界数列的最小聚点，记 $\varliminf_{n\to\infty}x_n$。
- **非正常上下极限**：把 $+\infty,-\infty$ 也允许为聚点后，无界数列也有上下极限。

## Mental Models / 思维模型

- **把"存在某个点"的问题看成二分搜索**：只要你能在每一步把区间砍半并保留"有希望"的一半，就得到区间套，公共点就是你要的点。区间套定理是**存在性证明的通用引擎**。
- **遇到"局部成立推到整体成立"先想有限覆盖**：连续函数在每点附近有界 $\Rightarrow$ 整区间有界；每点附近一致连续 $\Rightarrow$ 整区间一致连续。步骤固定：①写出依赖点的开邻域族 ②断言它覆盖闭区间 ③抽出有限个 ④对这有限个取下确界/最大值。
- **背循环链，别背六份证明**：写不出某条定理的证明时，先问"沿循环链上一条是谁"，往往两三行就能接上。
- **"用反证逼出区间套"**：假设结论不成立，就不断二分并保留"仍然反例"的那一半，最后让公共点落进某个邻域/覆盖，制造矛盾。定理7.3、定理7.2 证法一都是这个套路。
- **上下极限是极限的"备用件"**：数列没极限时，用 $\varlimsup/\varliminf$ 代替 $\lim$；只要两者相等，极限就存在（定理7.6）。

## Anti-patterns / 常见错误

- **把区间套定理用在开区间上**：$\{(0,1/n)\}$ 递减、长度趋于 0，但没有公共点。"闭"这个字不能丢。
- **忘了验证 $b_n-a_n\to0$**：只验证嵌套不够。$[a_n,b_n]=[0,1]$ 是嵌套的，但公共点是一整个区间，唯一性失效。
- **用柯西准则却不检查空间**：在有理数集上论证"柯西列必收敛"是错的，这正是完备性的内容。
- **混淆数列聚点与点集聚点**：数列的聚点是"有多少项聚集"，点集的聚点是"有多少个点聚集"，$\{\sin\frac{n\pi}{4}\}$ 是典型反例。
- **以为 $\varlimsup(a_n+b_n)=\varlimsup a_n+\varlimsup b_n$**：只有 $\le$ 成立。取 $a_n=(-1)^n,b_n=(-1)^{n+1}$：左边 $=0$，右边 $=1+1=2$。当 $\lim a_n$ 存在时才取等。
- **把"有界"当成"可积/收敛"的充分条件**：狄利克雷函数有界但不可积；有界数列也未必收敛——有界只保证有聚点。
- **在有限覆盖证明中忘记"闭区间"是结论成立的关键**：换成 $(a,b)$ 或 $[a,b)$，定理即失效。

## Worked Example / 工作示例

**例1（用区间套定理证明连续函数根的存在性定理）**：设 $f$ 在 $[a,b]$ 上连续，$f(a)f(b)<0$，证明存在 $\xi\in[a,b]$ 使 $f(\xi)=0$。

**构造**：记 $[a_1,b_1]=[a,b]$，令 $c_1=\dfrac{a_1+b_1}{2}$。若 $f(c_1)=0$ 则已得结论。否则 $f(a_1)f(c_1)$ 与 $f(c_1)f(b_1)$ 中恰有一个小于零（因为二者之积 $=[f(a_1)f(b_1)]\cdot f(c_1)^2<0$），不妨设 $f(a_1)f(c_1)<0$，取 $[a_2,b_2]=[a_1,c_1]$。对 $[a_2,b_2]$ 重复同样操作，得到 $c_2$；若 $f(c_2)=0$ 即止，否则在 $[a_2,c_2]$ 与 $[c_2,b_2]$ 中取端点值异号的那个记为 $[a_3,b_3]$。

**无限重复**：过程要么在某步得到 $f(c_k)=0$，结论成立；要么得到闭区间列 $\{[a_n,b_n]\}$，满足
1. $[a_n,b_n]\supset[a_{n+1},b_{n+1}]$，$n=1,2,\dots$；
2. $b_n-a_n=\dfrac{b-a}{2^{\,n-1}}\to0$（$n\to\infty$）；
3. $f(a_n)f(b_n)<0$，$n=1,2,\dots$。

由 (1)(2) 知 $\{[a_n,b_n]\}$ 是区间套，据**定理7.1**存在**唯一**的 $\xi\in[a_n,b_n]$（$\forall n$），且 $\lim a_n=\lim b_n=\xi$。

**取极限**：由 $f$ 在 $\xi$ 处连续，$\lim f(a_n)=f(\xi)$，$\lim f(b_n)=f(\xi)$。对 (3) 式两边取极限，由极限的保号性，
$$f(\xi)^2=\lim_{n\to\infty}f(a_n)f(b_n)\le0 .$$
因 $f(\xi)^2\ge0$，故 $f(\xi)^2=0$，即 $f(\xi)=0$。又 $\xi\in[a_1,b_1]=[a,b]$，所以 $\xi$ 就是 $f$ 在 $[a,b]$ 上的一个零点。 $\square$

**验证**：取 $f(x)=x^2-2$ 于 $[1,2]$，$f(1)=-1<0<f(2)=2$。区间套依次给出 $[1,2]\to[1,1.5]\to[1.25,1.5]\to\cdots$，公共点 $\xi=\sqrt2\approx1.41421$，确有 $f(\xi)=0$。

**要点**：证明中真正起作用的是"闭"（嵌套不失效）与"长度趋于 0"（唯一性），以及连续性把端点符号的极限传到 $\xi$。若 $f$ 只在一个点连续，结论可能不成立。

## Key Takeaways / 关键结论

1. 实数完备性 = 六条互相等价的定理，记住循环链 $1\Rightarrow2\Rightarrow3\Rightarrow4\Rightarrow5\Rightarrow6\Rightarrow1$ 即可掌握全局。
2. 区间套定理要求**闭**区间且**长度趋于 0**，两个条件都不可省。
3. 有限覆盖定理的结论只对**闭**区间成立，它是"局部性质 $\Rightarrow$ 整体性质"的唯一标准工具。
4. 柯西收敛准则是唯一不必预知极限值的收敛判据，但它依赖实数系的完备性（在 $\mathbb{Q}$ 上失效）。
5. 数列的聚点 $\ne$ 点集的聚点；数列的聚点恰为其收敛子列的极限。
6. 任何有界数列都有上、下极限，且 $\varliminf x_n\le\varlimsup x_n$；等号成立 $\iff$ 极限存在（定理7.6）。
7. 上极限只满足**次可加性** $\varlimsup(a_n+b_n)\le\varlimsup a_n+\varlimsup b_n$（定理7.8 与例2），不要写成等号。
