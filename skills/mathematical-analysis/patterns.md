# Patterns / 方法与算法

《数学分析》第六版 的**具体技术**。格式：**何时用 → 怎么做 → 代价与陷阱**。
编号指向原书定理（如 `定理9.3`）。

---

## ε-N 证明（数列极限）
**何时用**：要证 `lim aₙ = a`。
**How**：① 从 `|aₙ − a| < ε` 出发**反解** `n`；② 反解困难时**适当放大** `|aₙ − a| ≤ g(n)`，再解 `g(n) < ε`；③ 取 `N = ⌈…⌉`，写出「当 `n > N` 时」的完整推导。
**代价与陷阱**：放大必须**仍然趋于 0**——放得太大就证不出来。`N` 只要求存在，不必最小；含 `max{…}` 的 `N` 是常态（如 `N = max{18, 18/ε}`）。

## ε-δ 证明（函数极限）
**何时用**：要证 `lim_{x→x₀} f(x) = A`。
**How**：① 从 `|f(x) − A| < ε` 反解 `|x − x₀| < δ`；② 通常需**先限制** `|x−x₀| < 1` 之类来控界，再取 `δ = min{…, …}`。
**代价与陷阱**：`δ` 可以依赖 `ε` 但**不能依赖 `x`**（那会变成一致连续性）。取 `δ = min{3ε, 1}` 这类写法是标准动作。

## 求极限的方法选择
**何时用**：拿到一个极限。
**How**（按此顺序试）：① 代入，看是否定型；② **等价无穷小替换**（乘除可换，加减慎用）；③ 洛必达（**先验证 `0/0` 或 `∞/∞` 且 `f′/g′` 极限存在**，定理6.7/6.8）；④ 泰勒展开（洛必达多次求导麻烦时的首选）；⑤ 夹逼（迫敛性，定理3.6）；⑥ 单调有界（数列递推式）；⑦ 定积分定义（`Σf(i/n)/n → ∫₀¹f`）。
**代价与陷阱**：**加减法中不能用等价无穷小替换**（`sin x − x ~ 0` 是错误的替换）；洛必达可能循环或使式子更复杂，此时改用泰勒。

## 判断数列收敛（递推型）
**How**：① 用数学归纳法证**有界**；② 证**单调**；③ 由单调有界定理（定理2.9）得收敛；④ 在递推式两边取极限解出 `a`。
**代价与陷阱**：**先证有界再取极限**——顺序不能反。单调性常用 `aₙ₊₁ − aₙ` 的符号或作商 `aₙ₊₁/aₙ` 判断。

## 判别正项级数敛散性
**何时用**：`uₙ ≥ 0` 的级数 `Σuₙ`。
**How**（按代价从低到高）：① 必要条件 `uₙ → 0`（不满足即发散）；② **比较原则**（定理12.6）——与 `Σ1/nᵖ`（`p>1` 收敛）或几何级数比；③ **比值法** `lim uₙ₊₁/uₙ = ρ`（定理12.7）；④ **根式法** `lim ⁿ√uₙ = ρ`（定理12.8）；⑤ **积分判别法**（定理12.9）；⑥ `ρ = 1` 时用**拉贝判别法**（定理12.10）。
**代价与陷阱**：比值法与根式法在 `ρ = 1` 时**完全失效**（如 `Σ1/n` 与 `Σ1/n²` 都是 `ρ=1`）——必须换方法，不能下结论。含 `n!` 用比值法，含 `n` 次幂用根式法。

## 判别一般项级数敛散性
**How**：① 先查 `uₙ → 0`；② 试**绝对收敛**（对 `Σ|uₙ|` 用上面的正项判别法）；③ 绝对收敛 ⟹ 收敛（定理12.12），**结束**；④ 若只是条件收敛，用**莱布尼茨判别法**（交错级数，定理12.11）、**阿贝尔判别法**（定理12.15）或**狄利克雷判别法**（定理12.16）。
**代价与陷阱**：**绝对收敛只是充分条件**——判断出不绝对收敛不能推出原级数发散。

## 判别反常积分敛散性
**How**：① 分清**无穷积分**（`∫_a^∞`）还是**瑕积分**（被积函数无界）；② 用**比较原则**（定理11.2/11.6）与 `∫₁^∞ dx/xᵖ`（`p>1` 收敛）比对；③ 极限形式：`lim_{x→∞} xᵖ|f(x)| = l`，据 `p` 与 `l` 判定；④ 一般项用**狄利克雷/阿贝尔判别法**（定理11.3/11.4/11.7/11.8）；⑤ 区分绝对收敛与条件收敛（如 `∫₁^∞ sin x / x dx` 条件收敛）。
**代价与陷阱**：`∫₁^∞ dx/xᵖ` 与 `∫₀¹ dx/xᵖ` 的收敛条件**相反**（前者 `p>1`，后者 `p<1`）——最容易记混的一点。

## 一致收敛的判定
**何时用**：函数列 `{fₙ}` 或函数项级数 `Σuₙ(x)`。
**How**：① 先求极限函数 `f(x)`，再算 `sup|fₙ(x) − f(x)|`，验证是否 → 0（定理13.2）；② 或直接用**柯西准则**（定理13.1/13.3）；③ 函数项级数用**魏尔斯特拉斯 M 判别法**（定理13.5，`|uₙ(x)| ≤ Mₙ` 且 `ΣMₙ` 收敛）；④ 或用**阿贝尔/狄利克雷判别法**（定理13.6/13.7）。
**代价与陷阱**：**点态收敛推不出一致收敛**（经典反例 `fₙ(x) = xⁿ` 在 `[0,1]`）。M 判别法要求**与 `x` 无关**的优级数 `ΣMₙ`。

## 一致收敛后的三件事（交换运算）
**何时用**：已知（或已证）`Σuₙ(x)` 一致收敛，要处理极限、积分、导数。
**How**：① **连续性**（定理13.12）：和函数连续；② **逐项求积**（定理13.13）：`∫Σ = Σ∫`；③ **逐项求导**（定理13.14）：要求**逐项求导后的级数一致收敛**。
**代价与陷阱**：**逐项求导的条件最严**——原级数一致收敛不够，必须「导数级数」一致收敛。忘记这一点是本章最常见的错误。

## 求幂级数的收敛半径
**How**：① 缺项或一般情形用**柯西-阿达马定理**（定理14.3）`R = 1/lim sup ⁿ√|aₙ|`；② 相邻系数比存在时用 `R = lim|aₙ/aₙ₊₁|`；③ **端点必须单独判别**（`x = ±R` 处收敛性各不相同）。
**代价与陷阱**：比值公式**在缺项级数上失效**（如 `Σx^{2n}`）——此时必须用柯西-阿达马或作变量替换。

## 求不定积分的策略
**How**（按此顺序）：① 查**基本积分表**（14 条，Ch 08）；② 能凑微分就用**第一换元法**（定理8.4）；③ 含根式 `√(a²−x²)`、`√(x²±a²)` 用**第二换元法**（三角代换，定理8.5）；④ 乘积形式用**分部积分**（定理8.6，`∫u dv = uv − ∫v du`，"反对幂指三"定 `u` 的优先级）；⑤ 有理函数用**部分分式分解**（真分式 → 拆成四类最简分式）；⑥ 三角有理式用**万能代换** `t = tan(x/2)`。
**代价与陷阱**：万能代换**总能成功但常把式子变复杂**——先用 `sin²+cos²=1` 化简再决定。部分分式必须先化**真分式**（分子次数 < 分母次数）。

## 定积分的计算
**How**：① 用**牛顿-莱布尼茨公式** `∫_a^b f = F(b) − F(a)`（定理9.1）；② 换元时**必须同时换限**（定理9.12）；③ 对称区间上利用奇偶性 `∫_{−a}^{a}` 化简；④ 含参变量的定积分用**积分号下求导**（定理19.3/19.4，须验证条件）。
**代价与陷阱**：**换元不换限**是最高频的计算错误。被积函数有奇点时不能直接用 N-L 公式（那是瑕积分）。

## 定积分的应用（微元法）
**How**：① 选积分变量，取小区间 `[x, x+dx]`；② 写出**微元** `dA`（面积）、`dV`（体积）、`dS`（面积）、`ds`（弧长）；③ 积分。
**常用微元**：面积 `dA = |y₂−y₁|dx`；旋转体体积 `dV = πy²dx`（圆盘法）或 `dV = 2πx|y|dx`（柱壳法）；弧长 `ds = √(1+y′²)dx`；旋转曲面面积 `dS = 2π|y|ds`；极坐标面积 `dA = ½r²dθ`。
**代价与陷阱**：**先把微元写对再积分**——直接套公式容易选错（旋转体绕 `y` 轴与绕 `x` 轴的公式不同）。

## 化重积分为累次积分
**How**：① 画出积分区域 `D`；② 判断是 `X` 型（竖条）还是 `Y` 型（横条）；③ 写出内外层积分限——**外层必须是常数，内层可以是外层变量的函数**；④ 必要时**交换积分次序**（原次序积不出来时）。
**代价与陷阱**：积分限写反或内层出现外层变量以外的变量都直接导致错误。交换次序时**必须重画区域**重新定限。

## 重积分的变量变换
**How**：① 选变换 `x = x(u,v)`，`y = y(u,v)`；② 算**雅可比行列式** `J = ∂(x,y)/∂(u,v)`；③ `∬_D f dxdy = ∬_{D'} f(x(u,v),y(u,v)) |J| dudv`。
**常用变换**：极坐标 `J = r`；柱坐标 `J = r`；球坐标 `J = r²sin φ`。
**代价与陷阱**：**忘乘雅可比**是最常见的错误；球坐标的 `sin φ` 不能漏。

## 格林公式的使用
**何时用**：闭曲线上的第二型曲线积分，或要把它化为二重积分（反之亦然）。
**How**：① 确认 `L` 是**正向**（逆时针）闭曲线且 `P, Q` 有连续偏导；② 套 `∮_L Pdx+Qdy = ∬_D (Q_x − P_y)dxdy`（定理21.11）；③ 曲线不闭时**补线**成闭曲线再减去补线部分；④ 区域有洞时**挖洞**处理。
**代价与陷阱**：**方向反了要变号**。**`Q_x − P_y` 的顺序不能写反**。区域不是单连通时不能直接用「与路线无关」的结论（定理21.12 要求单连通）。

## 曲线积分与路线无关
**何时用**：`∫_L Pdx + Qdy` 是否只依赖起点终点。
**How**：① 在**单连通**区域上验证 `∂P/∂y = ∂Q/∂x`（定理21.12）；② 成立则可选最方便的路径（常取折线）；③ 或求势函数 `u` 使 `du = Pdx + Qdy`，则积分 `= u(B) − u(A)`。
**代价与陷阱**：**单连通是前提**——`(−y dx + x dy)/(x²+y²)` 在挖去原点的区域上满足 `P_y = Q_x` 但沿绕原点的闭曲线积分不为 0。

## 高斯公式与斯托克斯公式
**How**：① **高斯**（定理22.5）：闭曲面上的第二型曲面积分 → 三重积分，`∯ = ∭(P_x+Q_y+R_z)`，曲面须取**外侧**；② **斯托克斯**（定理22.6）：空间闭曲线上的积分 → 曲面积分，方向由**右手法则**与曲线方向匹配。
**代价与陷阱**：三条公式（格林—高斯—斯托克斯）是**同一个定理的不同维数**，符号方向规则一致。**方向取反则全部变号**。

## 隐函数求导
**How**：① 一元情形：`F(x,y)=0`，则 `dy/dx = −F_x/F_y`（定理18.2）；② 方程组情形：用雅可比行列式与克莱姆法则解出 `∂u/∂x` 等（定理18.4）。
**代价与陷阱**：公式里的**负号**最易漏；前提是 `F_y ≠ 0`。

## 条件极值（拉格朗日乘数法）
**How**：① 写出目标函数 `f` 与约束 `φᵢ = 0`；② 构造 `L = f + Σλᵢφᵢ`；③ 解方程组 `∂L/∂xⱼ = 0` 与 `φᵢ = 0`；④ 比较各驻点的函数值（紧集上必有最值，可只比大小）。
**代价与陷阱**：解出的是**驻点**，不是极值点——必须比较或补充判别。约束为不等式时需另外讨论边界与内部。

## 极值判定（多元）
**How**：① 求驻点（`f_x = f_y = 0`，定理17.10）；② 算海赛矩阵 `H` 的三个二阶偏导；③ **判别式** `AC − B²`：`>0` 且 `A>0` 极小、`A<0` 极大；`<0` 非极值（鞍点）；`=0` 失效需另法（定理17.11）。
**代价与陷阱**：`AC − B² > 0` 时**必须再看 `A` 的符号**才能区分极大极小。

## 对数求导法（幂指函数与连乘积）
**何时用**：`y = u(x)^{v(x)}`（幂指函数，如 `x^{sin x}`、`x^x`），或 `y` 是很多因子连乘/连除/带根号。
**How**：① 两边取绝对值再取对数：`ln|y| = v ln|u|`；② 两边对 `x` 求导，左边得 `y′/y`；③ 解出 `y′ = y·(右边导数)`。也可直接改写 `u^v = e^{v ln u}` 再求导。
**代价与陷阱**：**幂指函数不能套 `(xⁿ)′ = n xⁿ⁻¹`**——底和指数都在变。对数列项 `n!`、`x(x−1)…(x−n)` 连乘型先取对数再求导，比硬用乘积法则快得多。本题型见作业集题 38。

## 参数方程求导（一阶与二阶）
**何时用**：`x = x(t), y = y(t)` 给的是曲线而要求 `dy/dx` 或 `d²y/dx²`。
**How**：① 一阶 `dy/dx = y′(t)/x′(t)`（要求 `x′(t) ≠ 0`）；② 二阶 `d²y/dx² = [d/dt(dy/dx)] / x′(t)`——**先把一阶结果对 t 求导，再除以一次 `x′(t)`**。
**代价与陷阱**：二阶导最常见的错误是**漏掉最后那一次除以 `x′(t)`**，得到 `d²y/dx²` 的 `t` 表达式却没换成对 `x` 的导数。见作业集题 39、40、44。

## 高阶导数：三条路
**何时用**：求 `f^{(n)}(x)` 的一般表达式。
**How**：① **拆项**：有理分式先做部分分式（如 `1/[x(1−x)] = 1/x + 1/(1−x)`），再用 `(1/(a−x))^{(n)} = n!/(a−x)^{n+1}`；② **莱布尼茨公式** `(uv)^{(n)} = Σ C(n,k) u^{(k)} v^{(n−k)}`（一个因子是多项式时特别快，如 `x²e^x`、`x ln x`）；③ **找规律**：算前 3–4 阶、归纳出通项，再用数学归纳法验证（如 `e^{ax} sin bx`、`ln x`）。
**代价与陷阱**：只算前几阶就写通项不做归纳，是证明题的大忌；有理分式**不先拆项**直接求 `n` 阶导数基本做不出来。见作业集题 41–44。

## 有理函数积分（部分分式四步）
**何时用**：`∫P(x)/Q(x) dx`。
**How**：① **先化真分式**——`deg P ≥ deg Q` 时做多项式除法（商 + 余）；② 分母 `Q` 在实数范围内**因式分解**成一次与二次不可约因式之积；③ 按因式类型设**部分分式**：一次因式 `(x−a)^k` 设 `A₁/(x−a)+…+A_k/(x−a)^k`；不可约二次 `(x²+px+q)^m` 设 `(Bx+C)/(x²+px+q)+…`；④ 定系数（通分比较或代特殊值），逐项积分：`∫dx/(x²+px+q)` 用**配方 + arctan**。
**代价与陷阱**：**漏掉多项式除法的商是最高频错误**（作业集题 68(1) 就踩了）；分母有重根时部分分式的项数容易设少。见作业集题 68。

## 三角函数有理式与简单根式积分
**何时用**：被积函数只含 `sin x, cos x` 的有理式；或含 `√(a²−x²)`、`√(x²±a²)`、`ⁿ√(ax+b)`。
**How**：① 三角有理式**先试凑**：`∫R(sin x)cos x dx` 令 `u = sin x`；`∫R(tan x)sec²x dx` 令 `u = tan x`；都不行才用**万能代换** `t = tan(x/2)`（`sin x = 2t/(1+t²)`、`cos x = (1−t²)/(1+t²)`、`dx = 2dt/(1+t²)`）。② 根式 `√(a²−x²)` 令 `x = a sin t`；`√(a²+x²)` 令 `x = a tan t`；`√(x²−a²)` 令 `x = a sec t`；③ 同时含 `x` 与 `ⁿ√(ax+b)` 时令 `t = ⁿ√(ax+b)` 把根号整个换掉。
**代价与陷阱**：万能代换**一定能把三角有理式化为有理函数，但常常很繁**——先试凑微分，实在不行再万能。三角代换完**必须换回原变量**，别把 `t` 留在答案里。见作业集题 66、69。

## 函数作图（五步）
**How**：① 定义域、奇偶性/周期性、与坐标轴的交点；② 求 `y′`，定**单调区间与极值**；③ 求 `y″`，定**凹凸区间与拐点**；④ 求**渐近线**（竖直：分母为零且函数趋于无穷；水平/斜：`lim f(x)/x = k`、`lim[f(x)−kx] = b`）；⑤ 列表描点作图。
**代价与陷阱**：渐近线要求 `x → ±∞` **两个方向分别算**；斜渐近线先求 `k` 再求 `b`，顺序不能反。见作业集题 62 与教材习题6.6。

## 用导数证不等式 / 定单调性
**How**：① 把不等式移项成 `F(x) ≥ 0`（`x` 在某区间上）；② 求 `F′(x)`，用 `F′` 的符号定 `F` 的单调性；③ 用区间端点值（常是 `F(a) = 0`）收尾；④ 若能看出凸性，改用**凸函数定义/琴生不等式**一步到位（如 `e^{(a+b)/2} ≤ (e^a+e^b)/2`）。
**代价与陷阱**：`F′(x)` 符号看不出来时再求 `F″`；端点是开区间时要取极限。见作业集题 48、49、60、61。

## 分段函数的连续、可导与原函数
**How**：① **连续**：分界点处算左右极限，相等且等于函数值；② **可导**：分界点处**分别算左右导数**（用导数定义，不是求导公式），都存在且相等才可导；③ **原函数**：分段积分后，**在分界点把两段的常数拼到连续**（只有一个自由常数）。
**代价与陷阱**：分界点直接对两段套求导公式是最常见的错——那里必须回到定义。求原函数时忘调常数，得到的 `F` 在分界点会跳。见作业集题 33、35、64。
